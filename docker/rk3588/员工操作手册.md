## 🏭 批量部署（多台工控机）

### 方式 1：使用脚本批量部署

1. **准备工控机列表**
   创建 `machines.txt` 文件，每行一个IP:
   ```
   192.168.10.170
   192.168.10.171
   192.168.10.172
   ```

2. **创建批量部署脚本** `batch-deploy.bat`:
   ```batch
   @echo off
   for /f %%i in (machines.txt) do (
       echo 正在部署到 %%i ...
       scp belt-control-runtime.tar deploy.sh docker-compose.yml pi@%%i:/tmp/
       ssh pi@%%i "chmod +x /tmp/deploy.sh && sudo /tmp/deploy.sh"
       echo ✅ %%i 部署完成
   )
   pause
   ```

3. **运行批量部署**
   ```
   双击运行: batch-deploy.bat
   ```

### 方式 2：U盘离线部署（适合工厂现场）

1. **准备 U盘**
   - 复制 `belt-control-runtime.tar` 到 U盘
   - 复制 `deploy.sh` 和 `docker-compose.yml` 到 U盘

2. **在每台工控机上**
   ```bash
   # 插入 U盘（通常自动挂载到 /media/pi/USB）

   # 复制文件
   cp /media/pi/USB/belt-control-runtime.tar /tmp/
   cp /media/pi/USB/deploy.sh /tmp/
   cp /media/pi/USB/docker-compose.yml /tmp/

   # 执行部署
   chmod +x /tmp/deploy.sh
   sudo /tmp/deploy.sh
   ```

## ❓ 常见问题

### Q1: 连接不上工控机

**解决方法:**
1. 检查网络连接
2. 检查 IP 地址是否正确
3. Ping 测试: `ping 192.168.10.170`

### Q2: 密码输入多次还是失败

**解决方法:**
1. 确认密码是: `pi`
2. 检查键盘输入法（英文输入）
3. 尝试直接 SSH 登录: `ssh pi@192.168.10.170`

### Q3: Docker 安装失败

**解决方法:**
1. 检查工控机网络是否正常
2. 检查磁盘空间: `df -h`
3. 手动登录工控机安装:
   ```bash
   ssh pi@192.168.10.170
   curl -fsSL https://get.docker.com | sudo sh
   ```

### Q4: 容器启动失败

**解决方法:**
1. 查看日志: `view-logs.bat`
2. 检查容器状态: `view-status.bat`
3. 重启容器:
   ```bash
   ssh pi@192.168.10.170 "cd /opt/belt_control && docker-compose restart"
   ```

### Q5: 系统运行一段时间后无响应

**解决方法:**
1. 重启容器: `docker-compose restart`
2. 如果无效，重启工控机: `sudo reboot`

# 铃声文件说明

## 需要的铃声文件

请在此目录下放置名为 `ringtone.wav` 的铃声文件，用于来电提示。

## 文件要求

- **文件名**: `ringtone.wav`
- **格式**: WAV 格式（推荐）
- **时长**: 建议 2-5 秒（会循环播放）
- **采样率**: 44100 Hz 或 48000 Hz
- **声道**: 单声道或立体声均可

## 获取铃声

您可以：
1. 使用 Windows 系统自带的提示音（位于 `C:\Windows\Media\`）
2. 从网上下载免费铃声（搜索 "free ringtone wav"）
3. 使用音频编辑软件（如 Audacity）自己制作

## 示例命令

从 Windows 系统目录复制一个提示音：
```bash
copy "C:\Windows\Media\Ring01.wav" ringtone.wav
```

或者使用任意其他 WAV 文件重命名为 `ringtone.wav` 即可。

## 注意事项

- 如果没有铃声文件，程序仍然可以正常运行，只是来电时不会播放声音
- 铃声音量可以在代码中调整（当前设置为 0.8）

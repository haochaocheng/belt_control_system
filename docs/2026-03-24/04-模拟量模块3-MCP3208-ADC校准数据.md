## 线性拟合结果（0-17mA 有效段）

### 拟合公式

```
ADC = 196.14 × mA + 73.49
```

### 校准公式（ADC → 实际 mA）

```
actual_mA = (raw_adc - 73.49) / 196.14
```

### 拟合精度
- **有效范围**：0-17mA（ADC 0-3409）
- **最大校准误差**：±0.032 mA
- **线性度**：极好（R² ≈ 0.9999+）

### 与原始公式对比

原始公式：`current_mA = raw_adc × 3.33 / 4095 / 160 × 1000`

| mA | 原始误差 | 校准后误差 |
|---:|--------:|---------:|
| 0 | +0.403 | +0.030 |
| 4 | +0.343 | -0.018 |
| 10 | +0.315 | -0.027 |
| 17 | +0.327 | +0.007 |

**原始公式平均偏差约 +0.35mA，校准后误差 < ±0.032mA，精度提升 10 倍。**

## 误差分析

### 1. 增益误差（主要原因）
- 原始公式假设：`V = ADC × 3.33 / 4095`，`I = V / 160Ω`
- 理论斜率：4095 / 3.33 × 0.160 = **196.79 ADC/mA**
- 实测斜率：**196.14 ADC/mA**
- 偏差：-0.33%（可接受）

### 2. 零点偏移（主要原因）
- 理论零点（0mA时 ADC）：**0**
- 实测零点：**73.49**（约 0.06V）
- 原因：MCP3208 输入偏置 + 1N4148 漏电 + PCB 漏电流

### 3. ADC 饱和（硬件限制）
- **18mA 时 CH0 ≈ 3.28V**，接近 Vref = 3.33V
- ADC 在 ~17.5mA 后饱和，无法区分 18/19/20mA
- 根因：R1 = 160Ω 导致 20mA 时 V = 3.20V，加上零点偏移后超过 Vref
- **4-20mA 工业应用**：有效范围 4-17mA，18-20mA 饱和

### 4. 噪声
- ADC spread 平均约 300-400 LSB（约 ±1mA 峰峰值）
- 截尾均值滤波有效抑制尖峰噪声
- 建议：增大滤波窗口或增加硬件去耦

## 饱和问题解决方案

### 方案A：更换 R1 为 120Ω（推荐）
- 20mA × 120Ω = 2.40V（远低于 Vref 3.33V）
- 新校准需重新采集
- 缺点：需要更换硬件

### 方案B：软件限制有效范围
- 将 18-20mA 的 ADC 读数线性外推
- `if (adc > 3400) actual_mA = (adc - 73.49) / 196.14`（仍用线性公式，接受误差）
- 对于 4-20mA 传感器，17mA 以上的工况较少

### 方案C：降低 Vref（不推荐）
- 将 MCP3208 Vref 从 3.3V 提高到 3.6V（需要外部基准源）

## 软件校准实施

### mqtt_ai_publisher.py 修改

```python
# 校准参数（2026-03-24 实测）
CAL_SLOPE = 196.14    # ADC per mA
CAL_OFFSET = 73.49    # ADC at 0mA

# 校准后电流计算（替代原始公式）
# 原始：current_mA = voltage / R_SAMPLE * 1000.0
# 校准：current_mA = (raw - CAL_OFFSET) / CAL_SLOPE
def calibrate_current(raw_adc):
    if raw_adc <= CAL_OFFSET:
        return 0.0
    return (raw_adc - CAL_OFFSET) / CAL_SLOPE
```

### 16 位转换公式更新

MQTT 发布时将 12-bit ADC 转为 16-bit value：
```python
# 原始：value16 = int(voltage / VREF * 65535)
# 校准后：先算真实电流，再映射到 16-bit
calibrated_mA = calibrate_current(raw_adc)
value16 = int(max(0, min(65535, calibrated_mA / 20.0 * 65535)))
```

这样上位机收到的 16-bit 值直接线性映射 0-20mA，无需额外校准。

## 🔍 可能的崩溃原因

### 假设 A: `formatCtx->nb_streams` 值损坏
- 值为超大数字（如 0xFFFFFFFF）→ 循环越界
- 验证方法：检查 `nb_streams` 的实际值

### 假设 B: `formatCtx->streams` 数组指针为 NULL
- 访问 `formatCtx->streams[0]` 立即崩溃
- 验证方法：检查 `streams` 指针是否为 NULL

### 假设 C: `formatCtx->streams[i]` 某个元素为 NULL
- 循环能开始，但访问某个索引时崩溃
- 验证方法：每次循环检查 `streams[i]` 是否为 NULL

### 假设 D: `formatCtx->streams[i]->codecpar` 为 NULL
- `streams[i]` 有效，但 `codecpar` 为 NULL
- 验证方法：检查 `codecpar` 指针是否为 NULL

### 假设 E: FFmpeg 内存损坏
- `avformat_find_stream_info()` 导致内存损坏
- 验证方法：检查 `formatCtx` 结构体各字段

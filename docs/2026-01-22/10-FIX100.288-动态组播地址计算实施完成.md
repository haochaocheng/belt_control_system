## 🎯 问题描述

**原始问题**：
- 组播地址硬编码为 `224.1.1.1:8800`
- 不符合音频模块期望的动态计算规则
- 用户 IP 192.168.10.188 → 应使用 224.1.10.1，而非 224.1.1.1

**音频模块计算规则**：
```c
DIP[2] = tnet->ConfigMsg.lip[2];  // 提取本地 IP 的第3字节
// 组播地址格式：224.1.{IP[2]}.1
```

**影响**：
- Wireshark 过滤器错误：`ip.dst == 224.1.1.1` 无法抓到正确的音频包
- 音频模块可能无法接收到网络音频流

```cpp
// ========================================
// 辅助方法实现
// ========================================
// ✅ 2026-01-22 11:00 [动态计算] 获取本地 IP 地址

QHostAddress AudioNetworkSender::getLocalIPAddress()
{
    // 获取所有网络接口的地址
    const QList<QHostAddress> addresses = QNetworkInterface::allAddresses();

    // ========== 策略 1: 优先选择 192.168.x.x 网段 ==========
    // 这是最常见的局域网地址段，音频模块通常部署在此网段
    for (const QHostAddress& address : addresses) {
        if (address.protocol() == QAbstractSocket::IPv4Protocol &&
            !address.isLoopback() &&
            address.toString().startsWith("192.168.")) {
            qDebug() << "   ✅ 找到 192.168.x.x 网段地址:" << address.toString();
            return address;
        }
    }

    // ========== 策略 2: 选择第一个非回环 IPv4 地址 ==========
    // 如果没有 192.168.x.x，选择任意非回环地址（如 10.x.x.x、172.16-31.x.x）
    for (const QHostAddress& address : addresses) {
        if (address.protocol() == QAbstractSocket::IPv4Protocol &&
            !address.isLoopback()) {
            qDebug() << "   ⚠️ 未找到 192.168.x.x，使用备选地址:" << address.toString();
            return address;
        }
    }

    // ========== 策略 3: 兜底 - 返回 localhost ==========
    // 这种情况通常不会发生，除非网络完全不可用
    qWarning() << "   ❌ 无法获取本地 IP，使用 127.0.0.1（localhost）";
    qWarning() << "   ⚠️ 组播地址将计算为 224.1.0.1（可能不正确）";
    return QHostAddress::LocalHost;
}
```

## 🔧 技术实现

### IP 地址提取算法

**IPv4 地址存储**：
- Qt 使用 `quint32` 存储 IPv4 地址（32位无符号整数）
- 大端序（Big-Endian）：192.168.10.188 = 0xC0A80ABC

**第3字节提取**：
```cpp
quint32 ipv4 = localIP.toIPv4Address();  // 0xC0A80ABC
quint8 thirdByte = (ipv4 >> 8) & 0xFF;   // 右移8位 → 0x00C0A80A
                                          // 掩码0xFF → 0x0A = 10
```

**字节位置**：
```
IP地址: 192     .168    .10     .188
字节:   IP[0]   IP[1]   IP[2]   IP[3]
十六进制: C0     A8      0A      BC
          ↑      ↑       ↑       ↑
        Byte3  Byte2  Byte1  Byte0  (Big-Endian)
```

### 网络接口选择策略

1. **优先策略**：192.168.x.x 网段
   - 最常见的局域网地址
   - 音频模块通常部署在此网段
   - 用户设备 192.168.10.188 符合此条件

2. **备选策略**：任意非回环 IPv4
   - 支持 10.x.x.x、172.16-31.x.x 等私有网段
   - 适用于特殊网络环境

3. **兜底策略**：localhost (127.0.0.1)
   - 网络完全不可用时的降级方案
   - 会产生警告日志

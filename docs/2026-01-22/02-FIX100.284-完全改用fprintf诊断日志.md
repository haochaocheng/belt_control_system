# FIX 100.284 - 完全改用 fprintf() 诊断日志

**时间**: 2026-01-22 08:15
**版本**: VERSION 2026-01-22-08:10
**问题**: av_log(codecCtx, ...) 仍然不显示
**结论**: **只有 fprintf(stderr) + fflush() 可靠输出应用层日志**

---

## 🚨 问题分析

### 三次尝试失败历史

#### 尝试 1: av_log(nullptr, ...)  ❌
```cpp
av_log(nullptr, AV_LOG_ERROR, "...");
```
**结果**: 完全不显示

#### 尝试 2: av_log(codecCtx, ...)  ❌
```cpp
av_log(codecCtx, AV_LOG_ERROR, "...");
```
**结果**: 仍然不显示（voip.md 实测证明）

#### 尝试 3: fprintf(stderr, ...) 函数入口  ✅
```cpp
fprintf(stderr, "...");
fflush(stderr);
```
**结果**: 成功显示（voip.md Line 439-443）

### 根本原因

**应用层的 av_log() 无法输出日志**，无论第一个参数是什么：
- FFmpeg 内部调用 av_log() → ✅ 正常显示
- 应用层调用 av_log() → ❌ 完全不显示

**可能原因**：
1. av_log() 的日志回调未正确初始化
2. 应用层 av_log() 被重定向或过滤
3. 日志级别设置导致过滤

**解决方案**：**完全放弃 av_log()，使用 fprintf(stderr) + fflush()**

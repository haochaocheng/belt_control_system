## 二、解决方案

### 删除旧的 sendNextFrame() 函数

**文件**：`src/audio_network/AudioNetworkSender.cpp`

**删除内容**：第 845-910 行（整个函数）

**替换为**：
```cpp
// ❌ 2026-01-22 23:50 [已删除] 旧的主线程 sendNextFrame() 函数

// 原因：使用了不存在的 m_sendStartTime 成员变量，导致编译错误
```

### 为什么可以安全删除

1. **playAudioToNetwork() 已改用独立线程**：

```cpp

```

3. **旧函数没有任何调用点**：
   - `playAudioToNetwork()` 已改为调用 worker

## 五、总结

### 问题根源

在重构代码时，**只修改了调用点，忘记删除被替代的旧函数**，导致：
- 旧函数使用已删除的成员变量
- 编译错误

### 解决方法

**彻底删除旧代码**，而不是仅仅注释或废弃。

### 经验教训

**代码重构清单**：
1. ✅ 实现新功能（独立线程）
2. ✅ 修改调用点（playAudioToNetwork）
3. ✅ 删除旧成员变量（m_sendStartTime）
4. ⚠️ **删除旧函数**（sendNextFrame）← 本次遗漏
5. ✅ 添加废弃注释（说明删除原因）

**防范措施**：
- 使用编译器警告（`-Wunused-function`）检测未使用函数
- 代码审查时检查是否有"孤儿函数"
- 删除注释掉的代码，不要留着"以备后用"

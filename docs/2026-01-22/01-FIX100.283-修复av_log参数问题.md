# FIX 100.283 - 修复 av_log() 参数问题

**时间**: 2026-01-22 08:05
**版本**: VERSION 2026-01-22-08:00
**问题**: av_log(nullptr, ...) 日志不显示

---

## 🚨 问题分析

### 从 voip.md 日志发现的问题

**Line 439-443**: 函数入口标记出现 ✅
```
[APP-VERSION-CHECK] decodeAudioFile() 函数入口
代码版本: 2026-01-21-22:00-ENTRY
```

**Line 446-530**: FFmpeg avcodec_open2() 内部日志全部出现 ✅

**Line 284-290**: `[APP-TRACE] avcodec_open2() 调用前` **没有出现** ❌

### 根本原因

**错误的用法**:
```cpp
av_log(nullptr, AV_LOG_ERROR, "...");  // 第一个参数是 nullptr
```

**FFmpeg 内部的用法** (voip.md Line 489 等):
```cpp
av_log(avctx, AV_LOG_ERROR, "...");  // 第一个参数是 AVCodecContext*
```

**结论**: `av_log(nullptr, ...)` 的日志被过滤或者不显示。

---

## 🔧 修复内容

### 1. 函数入口标记 (Line 219-228)

**修改前**:
```cpp
av_log(nullptr, AV_LOG_ERROR, "╔═════════════════════════╗\n");
av_log(nullptr, AV_LOG_ERROR, "║ [APP-VERSION-CHECK] ... ║\n");
av_log(nullptr, AV_LOG_ERROR, "║ 代码版本: 2026-01-21-22:00-ENTRY ║\n");
```

**修改后**:
```cpp
fprintf(stderr, "╔═════════════════════════╗\n");
fprintf(stderr, "║ [APP-VERSION-CHECK] ... ║\n");
fprintf(stderr, "║ 代码版本: 2026-01-22-08:00-ENTRY-v2 ║\n");
fflush(stderr);
```

**原因**: 函数入口时还没有 codecCtx，使用 fprintf(stderr) 更可靠。

---

### 2. avcodec_open2() 前后诊断日志 (Line 281-329)

**修改前**:
```cpp
av_log(nullptr, AV_LOG_ERROR, "║ [APP-TRACE] avcodec_open2() 调用前 - VERSION 2026-01-21-21:45 ║\n");
av_log(nullptr, AV_LOG_ERROR, "║   codecCtx 指针: %p ║\n", (void*)codecCtx);
// ...
int openResult = avcodec_open2(codecCtx, codec, nullptr);
// ...
av_log(nullptr, AV_LOG_ERROR, "║ [APP-TRACE] avcodec_open2() 调用后 ║\n");
```

**修改后**:
```cpp
av_log(codecCtx, AV_LOG_ERROR, "║ [APP-TRACE] avcodec_open2() 调用前 - VERSION 2026-01-22-08:00 ║\n");
av_log(codecCtx, AV_LOG_ERROR, "║   codecCtx 指针: %p ║\n", (void*)codecCtx);
// ...
int openResult = avcodec_open2(codecCtx, codec, nullptr);
// ...
av_log(codecCtx, AV_LOG_ERROR, "║ [APP-TRACE] avcodec_open2() 调用后 ║\n");
```

**原因**: 使用 codecCtx 作为第一个参数，与 FFmpeg 内部日志保持一致。

---

### 3. 其他诊断日志 (Line 303-329)

**所有 `av_log(nullptr, ...)` 都改为 `av_log(codecCtx, ...)`**:
- Line 303: 错误日志
- Line 307-323: codecCtx 成员读取前的诊断
- Line 326-329: 音频格式输出

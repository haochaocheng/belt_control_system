## 三、根本原因

### 架构问题：重复创建未连接的发送器

**问题代码**（`SherpaOnnxTTS.cpp:38-40`）：
```cpp
// ✅ 2026-01-22 23:30 [网络传输] 初始化音频网络发送器
m_tcpSender = new AudioNetworkTcpSender(this);  // ← 创建新实例
m_udpSender = new AudioNetworkSender(this);
```

**问题分析**：
1. SherpaOnnxTTS 在构造函数中创建**独立的** `AudioNetworkTcpSender` 实例
2. 这个新实例从未调用 `startDiscovery()`，没有连接 WebSocket
3. `sayToNetwork()` 调用 `m_tcpSender->playAudioToNetwork()`
4. 发送器检查：`if (!m_webSocket->isValid()) { return; }`
5. 输出错误：`❌ "WebSocket 未连接，无法播放音频"`

**对比：CommonControl 的发送器**（已连接）：
```cpp
// CommonControl.cpp:38
m_audioNetworkTcpSender = new AudioNetworkTcpSender(this);

// CommonControl.cpp:145
m_audioNetworkTcpSender->startDiscovery();  // ← 启动服务发现，连接 WebSocket
```

### 架构图

```
创建顺序：
1. CommonControl 构造函数
   └─ m_audioNetworkTcpSender = new AudioNetworkTcpSender()  ← 实例 A
   └─ m_audioNetworkTcpSender->startDiscovery()  ← ✅ 已连接

2. CommonControl 构造函数
   └─ m_tts = new SherpaOnnxTTS()
      └─ m_tcpSender = new AudioNetworkTcpSender()  ← 实例 B（未连接）

调用流程：
CommonControl::playWarningOnce()
  → m_tts->sayToNetwork("1号皮带启动")
    → m_tcpSender->playAudioToNetwork()  ← 使用实例 B（未连接）❌
      → 检查：if (!m_webSocket->isValid()) { return; }
      → 错误："WebSocket 未连接，无法播放音频"
```

**问题**：
- CommonControl 和 SherpaOnnxTTS 各自创建独立的发送器
- 只有 CommonControl 的发送器连接了 WebSocket
- TTS 使用的是未连接的发送器

## 四、解决方案

### 方案：网络发送器共享模式

**核心思路**：让 SherpaOnnxTTS **复用** CommonControl 已连接的网络发送器，而不是创建新的实例。

**实现策略**：
1. 保留 SherpaOnnxTTS 构造函数中创建默认发送器（保持独立性）
2. 提供 setter 方法**替换**为共享的发送器
3. 在 setter 中断开旧连接，删除旧发送器，连接新发送器
4. CommonControl 在初始化后调用 setter 共享已连接的发送器

### 修改 2：SherpaOnnxTTS.cpp - 实现 setter 方法

**位置**：文件末尾（第527行后）

**添加内容**：
```cpp
// ✅ 2026-01-23 01:30 [网络共享] 设置共享的 TCP 音频发送器
// 原因：避免 TTS 创建未连接的发送器实例，复用 CommonControl 已连接的 WebSocket
// 背景：
//   - TTS 构造函数创建独立的 AudioNetworkTcpSender 实例（SherpaOnnxTTS.cpp:39）
//   - 这个新实例没有连接到 WebSocket（日志：❌ "WebSocket 未连接，无法播放音频"）
//   - CommonControl 的发送器已成功连接（日志：✅ "WebSocket 已连接到 192.168.1.4:8000"）
// 解决方案：
//   - 删除 TTS 自己创建的发送器
//   - 复用 CommonControl 的已连接发送器
//   - 正确处理信号连接（断开旧的，连接新的）
void SherpaOnnxTTS::setTcpSender(AudioNetworkTcpSender* sender)
{
    if (!sender) {
        qWarning() << "⚠️ SherpaOnnxTTS: 尝试设置 nullptr TCP 发送器";
        return;
    }

    // 断开旧发送器的信号连接
    if (m_tcpSender) {
        disconnect(m_tcpSender, &AudioNetworkTcpSender::playbackFinished,
                   this, &SherpaOnnxTTS::onNetworkTransmissionFinished);

        // 如果旧发送器是自己创建的（parent 是 this），删除它
        if (m_tcpSender->parent() == this) {
            qDebug() << "   删除旧的 TCP 发送器（自己创建的）";
            delete m_tcpSender;
        }
    }

    // 设置新的共享发送器
    m_tcpSender = sender;

    // 连接新发送器的信号
    connect(m_tcpSender, &AudioNetworkTcpSender::playbackFinished,
            this, &SherpaOnnxTTS::onNetworkTransmissionFinished);

    qDebug() << "✅ SherpaOnnxTTS: 已设置共享的 TCP 发送器";
}

void SherpaOnnxTTS::setUdpSender(AudioNetworkSender* sender)
{
    if (!sender) {
        qWarning() << "⚠️ SherpaOnnxTTS: 尝试设置 nullptr UDP 发送器";
        return;
    }

    // 断开旧发送器的信号连接
    if (m_udpSender) {
        disconnect(m_udpSender, &AudioNetworkSender::playbackFinished,
                   this, &SherpaOnnxTTS::onNetworkTransmissionFinished);

        // 如果旧发送器是自己创建的（parent 是 this），删除它
        if (m_udpSender->parent() == this) {
            qDebug() << "   删除旧的 UDP 发送器（自己创建的）";
            delete m_udpSender;
        }
    }

    // 设置新的共享发送器
    m_udpSender = sender;

    // 连接新发送器的信号
    connect(m_udpSender, &AudioNetworkSender::playbackFinished,
            this, &SherpaOnnxTTS::onNetworkTransmissionFinished);

    qDebug() << "✅ SherpaOnnxTTS: 已设置共享的 UDP 发送器";
}
```

**关键逻辑**：
1. **空指针检查**：防御性编程
2. **断开旧连接**：避免信号连接泄漏
3. **删除旧发送器**：仅删除自己创建的（parent 检查）
4. **设置新发送器**：替换为共享实例
5. **连接新信号**：确保 `onNetworkTransmissionFinished()` 正常工作

**优点**：
- ✅ 保持 SherpaOnnxTTS 的独立性（可以在没有 CommonControl 的地方使用）
- ✅ 支持运行时替换发送器
- ✅ 自动清理旧资源（内存安全）
- ✅ 正确处理 Qt 信号连接

### 资源共享模式

**模式定义**：
多个组件共享同一个网络连接资源，避免重复创建和连接。

**实现关键**：
```cpp
// 1. 创建资源（CommonControl）
m_audioNetworkTcpSender = new AudioNetworkTcpSender(this);
m_audioNetworkTcpSender->startDiscovery();  // 连接 WebSocket

// 2. 共享资源（SherpaOnnxTTS）
m_tts->setTcpSender(m_audioNetworkTcpSender);  // 复用连接

// 3. 自动清理（SherpaOnnxTTS setter）
if (m_tcpSender->parent() == this) {
    delete m_tcpSender;  // 删除自己创建的旧实例
}
m_tcpSender = sender;  // 使用共享实例
```

**优势**：
- ✅ **节省资源**：一个连接 vs 多个连接
- ✅ **简化管理**：统一的连接状态
- ✅ **避免冲突**：不会出现多个连接竞争
- ✅ **易于扩展**：新组件可以同样方式复用

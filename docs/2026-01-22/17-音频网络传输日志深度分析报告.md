## ⚠️ 发现的问题

### **问题 1: 频繁的不必要重连** (严重性: **中等**)

**问题描述**:
每隔 ~30 秒收到 UDP 广播就重连一次，即使已经连接到同一服务器。

**日志证据**:
```
行 437:  [WARNING] ⚠️ 已经连接到服务器，先断开
行 445:  [WARNING] QAbstractSocket::waitForDisconnected() is not allowed in UnconnectedState
行 470:  [WARNING] ⚠️ 已经连接到服务器，先断开
行 497:  [WARNING] ⚠️ 已经连接到服务器，先断开
...
```

**出现频率**: 每 30 秒 1 次（与上位机 UDP 广播周期一致）

**根本原因**:
`AudioNetworkTcpSender::onUdpDatagramReady()` 无条件断开重连：
```cpp
void AudioNetworkTcpSender::onUdpDatagramReady()
{
    // ...解析 UDP 数据报...

    // ❌ 问题：无条件连接，即使已连接到同一服务器
    connectToServer(serverIp, port);
}

void AudioNetworkTcpSender::connectToServer(const QString &ip, quint16 port)
{
    // ❌ 问题：无条件断开
    if (m_wsClient->isConnected()) {
        qWarning() << "⚠️ 已经连接到服务器，先断开";
        m_wsClient->disconnectFromServer();
        m_wsClient->waitForDisconnected(1000);  // ← 导致警告
    }

    m_wsClient->connectToServer(ip, port);
}
```

**影响**:
1. 增加网络开销（每 30 秒重新握手）
2. 可能导致短暂音频中断
3. 日志充斥重复警告信息
4. Socket 状态检查警告

**修复优先级**: **P1** (尽快修复)

## 🎯 用户需求：TCP/UDP 智能切换策略

### **需求描述**

**使用策略**:
1. **优先使用 TCP**:
   - 如果连接上位机的服务端，**不使用 UDP 广播**（只用 TCP）

2. **自动降级到 UDP**:
   - 如果 TCP 端口 **2-3 秒无响应**，自动切换到 UDP 组播

### **架构设计**

```

│         AudioNetworkTcpSender 智能切换逻辑             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  [状态机]                                                │
│    ┌──────────────┐                                     │
│    │  IDLE        │ ← 初始状态                          │
│    └──────┬───────┘                                     │
│           │ UDP 服务发现成功                             │
│           ↓                                             │
│    ┌──────────────┐                                     │
│    │ TCP_CONNECT  │ ← 尝试 TCP 连接                     │
│    └──────┬───────┘                                     │
│           │                                             │
│       ┌───┴───┐                                        │
│       │       │                                        │

│    ┌────┐  ┌────┐                                      │
│    │TCP │  │UDP │ ← 降级模式                           │
```

### **实施细节**

#### 1. 状态枚举
```cpp
enum class TransportMode {
    IDLE,           // 空闲，等待 UDP 服务发现
    TCP_CONNECTING, // 正在连接 TCP
    TCP_MODE,       // TCP 模式（优先）
    UDP_MODE        // UDP 模式（降级）
};
```

#### 2. 连接超时检测
```cpp
class AudioNetworkTcpSender : public QObject
{
    Q_OBJECT

private:
    TransportMode m_transportMode = TransportMode::IDLE;
    QTimer *m_tcpConnectTimer;      // TCP 连接超时定时器
    QTimer *m_tcpRetryTimer;        // TCP 重连定时器

    static constexpr int TCP_CONNECT_TIMEOUT_MS = 2500;  // 2.5 秒超时
    static constexpr int TCP_RETRY_INTERVAL_MS = 10000;  // 10 秒后重试
};
```

#### 3. 智能发送逻辑
```cpp
void AudioNetworkTcpSender::sendOpusFrame(const QByteArray &opusData)
{
    switch (m_transportMode) {
    case TransportMode::TCP_MODE:
        // 优先使用 TCP
        if (m_wsClient->isConnected()) {
            m_wsClient->sendBinaryFrame(opusData);  // TCP 发送
        } else {
            // TCP 连接断开，降级到 UDP
            qWarning() << "⚠️ TCP 连接断开，降级到 UDP 模式";
            m_transportMode = TransportMode::UDP_MODE;
            sendUdpMulticast(opusData);  // UDP 发送

            // 启动 TCP 重连定时器
            m_tcpRetryTimer->start(TCP_RETRY_INTERVAL_MS);
        }
        break;

    case TransportMode::UDP_MODE:
        // 降级模式：使用 UDP
        sendUdpMulticast(opusData);
        break;

    default:
        qWarning() << "⚠️ 传输模式未就绪，丢弃音频帧";
        break;
    }
}
```

#### 4. 连接流程
```cpp
void AudioNetworkTcpSender::onUdpDatagramReady()
{
    // ...解析 UDP 数据报...

    // 检查是否需要重连
    if (m_transportMode == TransportMode::TCP_MODE &&
        m_wsClient->isConnected() &&
        m_wsClient->getServerIp() == serverIp &&
        m_wsClient->getServerPort() == port) {
        qDebug() << "✅ 已连接到相同服务器，忽略 UDP 广播";
        return;  // ← 解决问题 1：频繁重连
    }

    // 尝试 TCP 连接
    m_transportMode = TransportMode::TCP_CONNECTING;
    m_wsClient->connectToServer(serverIp, port);

    // 启动超时定时器
    m_tcpConnectTimer->start(TCP_CONNECT_TIMEOUT_MS);
}

void AudioNetworkTcpSender::onTcpConnected()
{
    // 连接成功
    m_tcpConnectTimer->stop();
    m_tcpRetryTimer->stop();
    m_transportMode = TransportMode::TCP_MODE;

    qDebug() << "✅ TCP 连接成功，使用 TCP 模式";
}

void AudioNetworkTcpSender::onTcpConnectTimeout()
{
    // 连接超时（2-3 秒）
    m_wsClient->disconnectFromServer();
    m_transportMode = TransportMode::UDP_MODE;

    qWarning() << "⚠️ TCP 连接超时（2.5秒），降级到 UDP 模式";

    // 启动 TCP 重连定时器（10 秒后重试）
    m_tcpRetryTimer->start(TCP_RETRY_INTERVAL_MS);
}

void AudioNetworkTcpSender::onTcpRetryTimerTimeout()
{
    // 定期重试 TCP 连接
    if (m_transportMode == TransportMode::UDP_MODE) {
        qDebug() << "🔄 尝试从 UDP 模式恢复到 TCP 模式...";
        // 重复 UDP 服务发现流程
        // （重用现有 UDP 广播数据）
    }
}
```

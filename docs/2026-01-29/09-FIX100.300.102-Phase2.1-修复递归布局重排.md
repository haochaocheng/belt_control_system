## 🔍 根本原因分析

### 问题代码
**文件**: `src/qml/components/device_info/pages/SwitchInputPage.qml`
**位置**: Line 279

```qml
RowLayout {
    width: parent.width - 20
    spacing: 20

    // ❌ 问题：手动计算 implicitHeight 导致循环依赖
    implicitHeight: Math.max(leftColumn.implicitHeight, rightColumn.implicitHeight)

    ColumnLayout {
        id: leftColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12
        // ...
    }

    ColumnLayout {
        id: rightColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12
        // ...
    }
}
```

### 循环依赖链

```
RowLayout.implicitHeight
    ↓ 依赖
leftColumn.implicitHeight + rightColumn.implicitHeight
    ↓ 依赖
leftColumn 子元素的布局计算
    ↓ 依赖
RowLayout 的布局完成
    ↓ 触发
RowLayout.implicitHeight 重新计算
    ↓ 循环
...
```

**结果**: Qt Quick Layouts 检测到递归重排，中止布局计算，导致程序卡住。

---

## ✅ 解决方案

### 修复代码

```qml
RowLayout {
    width: parent.width - 20
    spacing: 20

    // ✅ 2026-01-29 [FIX 100.300.102 Phase 2.1]: 移除 implicitHeight 计算，避免递归布局重排
    // implicitHeight 会自动根据子元素计算，不需要手动设置

    ColumnLayout {
        id: leftColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12
        // ...
    }

    ColumnLayout {
        id: rightColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12
        // ...
    }
}
```

### 修复原理

1. **Qt Quick Layouts 自动计算**：
   - `RowLayout` 会自动根据子元素（`leftColumn` 和 `rightColumn`）计算 `implicitHeight`
   - 不需要手动设置 `implicitHeight`

2. **避免循环依赖**：
   - 移除手动计算后，布局系统可以正常工作
   - 子元素的 `implicitHeight` 会自动向上传播到父元素

3. **ScrollView 自动适应**：
   - `ScrollView` 会根据 `RowLayout` 的 `implicitHeight` 自动调整滚动区域
   - 无需手动干预

## 🎓 经验教训

### 1. Qt Quick Layouts 自动计算
- `implicitHeight` 和 `implicitWidth` 通常不需要手动设置
- 布局系统会自动根据子元素计算这些值
- 只有在特殊情况下才需要手动设置（如固定大小的容器）

### 2. 避免循环依赖
- 不要在父元素中引用子元素的 `implicitHeight/Width`
- 不要在子元素中引用父元素的 `implicitHeight/Width`
- 使用 `Layout.preferredWidth/Height` 代替直接设置尺寸

### 3. 调试布局问题
- 查看控制台警告信息
- 使用 `console.log` 输出布局尺寸
- 使用 Qt Quick Layouts 的调试工具

### 4. ScrollView 使用
- `ScrollView` 会自动根据内容的 `implicitHeight` 调整滚动区域
- 不需要手动计算内容高度
- 确保内容使用 `Layout` 属性正确设置尺寸

## 🎉 总结

**问题**: 手动计算 `implicitHeight` 导致递归布局重排，程序卡住

**原因**: `RowLayout.implicitHeight` 依赖子元素的 `implicitHeight`，形成循环依赖

**解决**: 移除手动计算，让 Qt Quick Layouts 自动计算

**结果**:
- ✅ 程序不再卡住
- ✅ 布局正常工作
- ✅ 交叉导航功能正常

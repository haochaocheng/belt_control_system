## 🎯 实施内容

### 导航系统设计

**目标**：实现类似电视机 APP 的遥控器导航，支持上下左右键在所有控件之间自由移动

**设计原则**：
1. **可扩展性**：使用 `getParamFieldCount()` 动态获取参数数量
2. **两列交叉导航**：参数区域左列和右列独立导航
3. **智能跨区域**：到达边界时自动进入下一个区域

---

## 📊 导航逻辑

### 参数区域（GridLayout 两列）

**上下键**：同列导航
- **左列**：0→2→4→6→8（步长=2）
- **右列**：1→3→5→7（步长=2）

**左右键**：同行导航
- 0↔1, 2↔3, 4↔5, 6↔7

**下键边界**：
- 左列最后一个 → 底部按钮区域（添加输入，索引0）
- 右列最后一个 → 底部按钮区域（删除输入，索引1）

### 底部按钮区域（两行，5个按钮）

**布局**：
```
第一行：[添加输入(0)] [删除输入(1)]
第二行：[保存(2)] [删除(3)] [重置(4)]
```

**上下键**：跨行导航
- 0→2（添加输入 → 保存）
- 1→3（删除输入 → 删除）
- 2→0（保存 → 添加输入）
- 3→1（删除 → 删除输入）
- 4→1（重置 → 删除输入）

**左右键**：同行导航
- 第一行：0↔1
- 第二行：2→3→4

**上键边界**：
- 第一行按上键 → 返回参数区域最后一行

## 🔧 技术实现

### 1. 上键处理（Keys.onUpPressed）

**参数区域**：
```javascript
// 同列向上移动2步
if (isRightColumn) {
    // 右列：1→3→5→7
    if (currentIndex >= 2) {
        currentPage.focusParamIndex = currentIndex - 2
    }
} else {
    // 左列：0→2→4→6→8
    if (currentIndex >= 2) {
        currentPage.focusParamIndex = currentIndex - 2
    }
}
```

**底部按钮区域**：
```javascript
// 按钮布局：第一行(0,1) 第二行(2,3,4)
if (buttonIndex >= 2) {
    // 第二行 → 第一行
    if (buttonIndex === 2) currentPage.focusButtonIndex = 0  // 保存 → 添加输入
    else if (buttonIndex === 3) currentPage.focusButtonIndex = 1  // 删除 → 删除输入
    else if (buttonIndex === 4) currentPage.focusButtonIndex = 1  // 重置 → 删除输入
} else {
    // 第一行 → 返回参数区域
    currentPage.focusSubArea = 1
    var paramCount = currentPage.getParamFieldCount()
    if (buttonIndex === 0) {
        // 从添加输入返回 → 左列最后一个
        currentPage.focusParamIndex = (paramCount % 2 === 0) ? paramCount - 2 : paramCount - 1
    } else {
        // 从删除输入返回 → 右列最后一个
        currentPage.focusParamIndex = (paramCount % 2 === 0) ? paramCount - 1 : paramCount - 2
    }
}
```

### 2. 下键处理（Keys.onDownPressed）

**参数区域**：
```javascript
// 同列向下移动2步
if (isRightColumn) {
    // 右列：1→3→5→7
    var nextIndex = currentIndex + 2
    if (nextIndex < paramCount) {
        currentPage.focusParamIndex = nextIndex
    } else {
        // 已到达右列最后一个 → 进入底部按钮区域
        currentPage.focusSubArea = 2
        currentPage.focusButtonIndex = 1  // 删除输入（右侧按钮）
    }
} else {
    // 左列：0→2→4→6→8
    var nextIndex = currentIndex + 2
    if (nextIndex < paramCount) {
        currentPage.focusParamIndex = nextIndex
    } else {
        // 已到达左列最后一个 → 进入底部按钮区域
        currentPage.focusSubArea = 2
        currentPage.focusButtonIndex = 0  // 添加输入（左侧按钮）
    }
}
```

**底部按钮区域**：
```javascript
// 按钮布局：第一行(0,1) 第二行(2,3,4)
if (buttonIndex < 2) {
    // 第一行 → 第二行
    if (buttonIndex === 0) currentPage.focusButtonIndex = 2  // 添加输入 → 保存
    else if (buttonIndex === 1) currentPage.focusButtonIndex = 3  // 删除输入 → 删除
}
```

### 3. 左键处理（Keys.onLeftPressed）

**参数区域**：
```javascript
// 两列交叉导航：左列（0,2,4,6,8） vs 右列（1,3,5,7）
if (currentIndex % 2 === 1) {
    // 当前在右列，切换到左列
    var prevIndex = currentIndex - 1
    currentPage.focusParamIndex = prevIndex
} else {
    // 当前在左列，返回列表区域
    currentPage.focusSubArea = 0
}
```

**底部按钮区域**：
```javascript
// 按钮布局：第一行(0,1) 第二行(2,3,4)
if (buttonIndex === 1) currentPage.focusButtonIndex = 0  // 删除输入 → 添加输入
else if (buttonIndex === 3) currentPage.focusButtonIndex = 2  // 删除 → 保存
else if (buttonIndex === 4) currentPage.focusButtonIndex = 3  // 重置 → 删除
```

### 4. 右键处理（Keys.onRightPressed）

**参数区域**：
```javascript
// 两列交叉导航：左列（0,2,4,6,8） vs 右列（1,3,5,7）
if (currentIndex % 2 === 0) {
    // 当前在左列，切换到右列
    var nextIndex = currentIndex + 1
    if (nextIndex < paramCount) {
        currentPage.focusParamIndex = nextIndex
    }
}
```

**底部按钮区域**：
```javascript
// 按钮布局：第一行(0,1) 第二行(2,3,4)
if (buttonIndex === 0) currentPage.focusButtonIndex = 1  // 添加输入 → 删除输入
else if (buttonIndex === 2) currentPage.focusButtonIndex = 3  // 保存 → 删除
else if (buttonIndex === 3) currentPage.focusButtonIndex = 4  // 删除 → 重置
```

## 🎯 可扩展性设计

### 动态参数数量

**使用 `getParamFieldCount()` 获取参数数量**：
```javascript
var paramCount = currentPage.getParamFieldCount()
```

**自动适配导航逻辑**：
- 新增参数时，只需更新 `getParamFieldCount()` 返回值
- 导航逻辑自动适配新的参数数量
- 无需修改导航代码

**示例**：
```javascript
// 当前：9个参数
function getParamFieldCount() {
    return 9
}

// 新增参数后：11个参数
function getParamFieldCount() {
    return 11  // 只需修改这里
}
// 导航逻辑自动适配：左列(0,2,4,6,8,10) 右列(1,3,5,7,9)
```

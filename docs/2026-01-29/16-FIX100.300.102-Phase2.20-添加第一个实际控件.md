## 🐛 问题描述

**用户反馈**: "开关量列表显示了，但是从开关量输入切换到开关量列表按左键，焦点没有转移到开关量列表"

### 问题分析

Phase 2.19 成功解决了程序卡住的问题，但导航不工作，原因：
1. GridLayout 中只有两个测试 Text 元素
2. 这些 Text 元素没有焦点逻辑
3. 没有实际的控件（TextField, ComboBox, SpinBox 等）
4. 没有焦点指示器

---

## ✅ 解决方案

### 实施步骤

**Step 1**: 从注释掉的 RowLayout 代码中提取保护名称控件

**原始代码**（Line 327-359）：
```qml
RowLayout {
    Layout.fillWidth: true
    spacing: 10

    Text {
        text: "保护名称:"
        font.pixelSize: 14
        color: "#9E9E9E"
        Layout.preferredWidth: 100
    }

    Item {
        Layout.fillWidth: true
        implicitHeight: nameField.implicitHeight

        DeviceInfo.CustomTextField {
            id: nameField
            anchors.fill: parent
            keyboardManager: root.keyboardManager
        }

        // 焦点指示器
        Rectangle {
            anchors.fill: parent
            color: "transparent"
            border.color: (root.focusSubArea === 1 && root.focusParamIndex === 0) ? "#2196F3" : "transparent"
            border.width: (root.focusSubArea === 1 && root.focusParamIndex === 0) ? 3 : 0
            radius: 4
            z: 10
        }
    }
}
```

**Step 2**: 适配到 GridLayout 格式

**修改后代码**（Line 292-323）：
```qml
// ✅ 2026-01-29 [FIX 100.300.102 Phase 2.20]: 添加第一个实际控件 - 保护名称（左列第一行，索引0）
Text {
    text: "保护名称:"
    font.pixelSize: 14
    color: "#9E9E9E"
    Layout.column: 0
    Layout.row: 0
    Layout.preferredWidth: 100
}

Item {
    Layout.fillWidth: true
    Layout.column: 0
    Layout.row: 1
    implicitHeight: nameField.implicitHeight

    DeviceInfo.CustomTextField {
        id: nameField
        anchors.fill: parent
        keyboardManager: root.keyboardManager
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusSubArea === 1 && root.focusParamIndex === 0) ? "#2196F3" : "transparent"
        border.width: (root.focusSubArea === 1 && root.focusParamIndex === 0) ? 3 : 0
        radius: 4
        z: 10
    }
}
```

### 关键修改

1. **标签 Text**：
   - 添加 `Layout.column: 0`（左列）
   - 添加 `Layout.row: 0`（第一行）
   - 保留 `Layout.preferredWidth: 100`

2. **输入框 Item**：
   - 添加 `Layout.column: 0`（左列）
   - 添加 `Layout.row: 1`（第二行）
   - 保留 `Layout.fillWidth: true`
   - 保留焦点指示器逻辑

3. **焦点指示器**：
   - 条件：`root.focusSubArea === 1 && root.focusParamIndex === 0`
   - 焦点时：蓝色边框（#2196F3），宽度 3
   - 非焦点时：透明边框，宽度 0

## 📊 GridLayout 布局说明

### 两列交叉导航模式

**左列（column: 0）**：
- 索引 0: 保护名称 ✅ **已实现**
- 索引 2: 模块类型
- 索引 4: 寄存器地址
- 索引 6: 通道编号
- 索引 8: 保护延时

**右列（column: 1）**：
- 索引 1: 播放次数
- 索引 3: 播放时长
- 索引 5: TTS文字
- 索引 7: 音频文件

### GridLayout 定位规则

**标签和控件分开定位**：
```qml
// 标签
Text {
    Layout.column: 0  // 左列
    Layout.row: 0     // 第一行
}

// 控件
Item {
    Layout.column: 0  // 左列
    Layout.row: 1     // 第二行
}
```

**为什么分开**：
- 标签和控件需要独立定位
- 便于控制间距和对齐
- 焦点指示器只在控件上显示

## 🎓 经验教训

### 1. 逐步添加控件的重要性

**原则**：
- 不要一次性添加所有控件
- 每次添加一个控件，测试验证
- 确认不卡住后再添加下一个

**好处**：
- 快速定位问题
- 避免大量返工
- 确保每一步都是正确的

### 2. GridLayout 的定位规则

**关键点**：
- 使用 `Layout.column` 和 `Layout.row` 明确定位
- 标签和控件分开定位
- 避免使用 `Layout.preferredWidth: parent.width / 2`（会导致循环依赖）

### 3. 焦点指示器的实现

**最佳实践**：
- 使用 Rectangle 作为焦点指示器
- 使用 `z: 10` 确保在最上层
- 使用条件绑定控制显示/隐藏
- 边框颜色：#2196F3（蓝色）
- 边框宽度：3（焦点时）

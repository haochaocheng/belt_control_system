## 🎨 美化建议

### 参考 CuteKeyboard 的设计元素

**颜色方案**：
```qml
// 背景色
backgroundColor: "#1a2332"           // 深蓝灰色
keyboardBackground: "#0a1628"       // 更深的背景

// 按钮色
normalKeyColor: "#34495e"           // 普通按键（灰蓝色）
specialKeyColor: "#2c3e50"          // 特殊按键（更深）
pressedKeyColor: "#3d5a80"          // 按下状态（亮蓝灰）

// 文字色
textColor: "#ecf0f1"                // 主文字（浅灰白）
accentColor: "#00d4ff"              // 强调色（科技蓝）
```

**按键样式**：
```qml
Rectangle {
    color: "#34495e"
    radius: 6                        // 圆角
    border.color: "#00d4ff"
    border.width: 1

    // 阴影效果
    layer.enabled: true
    layer.effect: DropShadow {
        horizontalOffset: 0
        verticalOffset: 2
        radius: 4
        samples: 9
        color: "#80000000"
    }
}
```

**动画效果**：
```qml
// 按键按下缩放
scale: pressed ? 0.95 : 1.0
Behavior on scale {
    NumberAnimation { duration: 100; easing.type: Easing.OutQuad }
}

// 键盘弹出动画
NumberAnimation {
    properties: "y"
    duration: 250
    easing.type: Easing.OutCubic
}
```

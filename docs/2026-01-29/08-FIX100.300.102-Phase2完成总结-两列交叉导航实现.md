## 🏗️ 技术实现

### 布局结构

**旧结构**（单列）:
```qml
ColumnLayout {
    // 保护名称（索引 0）
    // 模块类型（索引 1）
    // 寄存器地址（索引 2）
    // 通道编号（索引 3）
    // 保护延时（索引 4）
    // 播放次数（索引 5）
    // 播放时长（索引 6）
    // TTS文字（索引 7）
    // 音频文件（索引 8）
}
```

**新结构**（两列）:
```qml
RowLayout {
    spacing: 20

    // 左列
    ColumnLayout {
        id: leftColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12

        // 保护名称（新索引 0）
        // 模块类型（新索引 2）
        // 寄存器地址（新索引 4）
        // 通道编号（新索引 6）
        // 保护延时（新索引 8）
    }

    // 右列
    ColumnLayout {
        id: rightColumn
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 10
        spacing: 12

        // 播放次数（新索引 1）
        // 播放时长（新索引 3）
        // TTS文字（新索引 5）
        // 音频文件（新索引 7）
    }
}
```

### 焦点指示器索引更新

**示例 - 模块类型字段**（索引从 1 改为 2）:
```qml
// 焦点指示器
// ✅ 2026-01-29 [FIX 100.300.102 Phase 2]: 索引从 1 改为 2（交叉导航）
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusSubArea === 1 && root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusSubArea === 1 && root.focusParamIndex === 2) ? 3 : 0
    radius: 4
    z: 10
}
```

**所有字段的焦点指示器索引都已更新**：
- 保护名称: `focusParamIndex === 0` (不变)
- 模块类型: `focusParamIndex === 2` (从 1 改为 2)
- 寄存器地址: `focusParamIndex === 4` (从 2 改为 4)
- 通道编号: `focusParamIndex === 6` (从 3 改为 6)
- 保护延时: `focusParamIndex === 8` (从 4 改为 8)
- 播放次数: `focusParamIndex === 1` (从 5 改为 1)
- 播放时长: `focusParamIndex === 3` (从 6 改为 3)
- TTS文字: `focusParamIndex === 5` (从 7 改为 5)
- 音频文件: `focusParamIndex === 7` (从 8 改为 7)

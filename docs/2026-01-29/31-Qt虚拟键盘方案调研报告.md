# Qt 虚拟键盘方案调研报告

**日期**: 2026-01-29
**目标**: 寻找开源的、适配 Qt 6.5.3 的、美观的虚拟键盘

---

## 📊 调研结果

### 1. **CuteKeyboard** ⭐⭐⭐

**GitHub**: [amarula/cutekeyboard](https://github.com/amarula/cutekeyboard)
**官网**: [amarula.github.io/cutekeyboard](https://amarula.github.io/cutekeyboard/)

**特点**：
- ✅ MIT 许可证，可商业使用
- ✅ 现代化、美观的界面设计
- ✅ 支持多语言
- ✅ 只需修改一个 QML 文件即可定制

**缺点**：
- ❌ **是一个 Qt 输入法插件（Input Context Plugin）**
- ❌ 需要编译成 `.so` 插件并安装到 Qt 系统中
- ❌ 需要在 `main.cpp` 中设置 `QT_IM_MODULE` 环境变量
- ❌ 对于嵌入式项目来说集成复杂

**集成难度**: ⭐⭐⭐⭐ (困难)

---

### 2. **QtFreeVirtualKeyboard** ⭐⭐⭐

**GitHub**: [githubuser0xFFFF/QtFreeVirtualKeyboard](https://github.com/githubuser0xFFFF/QtFreeVirtualKeyboard)

**特点**：
- ✅ 专为嵌入式 QML 应用设计
- ✅ 轻量级
- ✅ 支持字符预览弹窗
- ✅ 自动滚动功能

**缺点**：
- ❌ **也是一个 Qt 输入法插件**
- ❌ 需要编译成 `.so` 插件
- ❌ 界面设计较为简单（黑色背景）
- ❌ 集成复杂度高

**集成难度**: ⭐⭐⭐⭐ (困难)

---

### 3. **Qt 官方 Virtual Keyboard（自定义样式）** ⭐⭐

**文档**: [Qt Virtual Keyboard Overview](https://doc.qt.io/qt-6.5/qtvirtualkeyboard-overview.html)

**特点**：
- ✅ Qt 官方支持
- ✅ 功能完善（手写输入、多语言、预测输入）
- ✅ 可以自定义样式

**缺点**：
- ❌ **商业版或 GPL 许可证**
- ❌ 开源版功能受限
- ❌ 自定义样式需要深入了解 Qt Virtual Keyboard 架构

**集成难度**: ⭐⭐⭐ (中等)

---

## 💡 推荐方案

### **方案 1：美化现有虚拟键盘** ⭐⭐⭐⭐⭐ 强烈推荐

**理由**：
1. ✅ **无需编译插件**，直接修改 QML 代码
2. ✅ **集成简单**，已经在项目中工作
3. ✅ **完全可控**，可以根据工业控制界面风格定制
4. ✅ **性能好**，纯 QML 实现

**实施步骤**：

#### 1. 参考 CuteKeyboard 的设计风格

**颜色方案**：
```qml
// CuteKeyboard 风格
property color backgroundColor: "#1a2332"        // 深蓝灰色背景
property color btnBackgroundColor: "#34495e"     // 按钮背景
property color btnSpecialBackgroundColor: "#2c3e50"  // 特殊按钮背景
property color btnTextColor: "#ecf0f1"           // 按钮文字颜色
property color btnBorderColor: "#00d4ff"         // 按钮边框（科技蓝）
```

#### 2. 添加现代化效果

**按钮样式**：
```qml
Rectangle {
    id: keyButton
    color: pressed ? "#2c3e50" : (hovered ? "#3d5a80" : "#34495e")
    radius: 6  // 圆角
    border.color: "#00d4ff"
    border.width: 1

    // 添加阴影效果
    layer.enabled: true
    layer.effect: DropShadow {
        horizontalOffset: 0
        verticalOffset: 2
        radius: 4
        samples: 9
        color: "#80000000"
    }

    // 添加按下动画
    Behavior on scale {
        NumberAnimation { duration: 100 }
    }
    scale: pressed ? 0.95 : 1.0
}
```

#### 3. 添加动画效果

**键盘弹出动画**：
```qml
states: State {
    name: "visible"
    when: root.visible
    PropertyChanges {
        target: root
        y: parent.height - root.height
    }
}

transitions: Transition {
    from: ""
    to: "visible"
    reversible: true
    ParallelAnimation {
        NumberAnimation {
            properties: "y"
            duration: 250
            easing.type: Easing.OutCubic
        }
        NumberAnimation {
            properties: "opacity"
            duration: 200
        }
    }
}
```

#### 4. 改进字体和图标

**使用 Font Awesome 图标**：
```qml
FontLoader {
    id: fontAwesome
    source: "qrc:/fonts/FontAwesome.otf"
}

Text {
    text: "\uf060"  // Font Awesome 退格图标
    font.family: fontAwesome.name
    font.pixelSize: 20
    color: "#ecf0f1"
}
```

### **方案 2：提取 CuteKeyboard 的 QML 组件** ⭐⭐⭐

**理由**：
- CuteKeyboard 的 QML 组件设计美观
- 可以提取 `InputPanel.qml`、`Key.qml` 等组件
- 修改为不依赖插件的纯 QML 实现

**实施步骤**：
1. 复制 `libs/cutekeyboard/src/qml/` 目录到项目中
2. 移除对 `CuteKeyboard` 插件的依赖
3. 修改为使用 `VirtualKeyboardManager` 管理
4. 调整样式以匹配工业控制界面

**难度**: ⭐⭐⭐ (中等)

### **方案 3：使用 Qt Quick Controls 2 样式** ⭐⭐

**理由**：
- Qt Quick Controls 2 提供了多种样式（Material、Universal、Fusion）
- 可以应用到虚拟键盘按钮上

**实施步骤**：
```qml
import QtQuick.Controls 2.15
import QtQuick.Controls.Material 2.15

Button {
    text: "A"
    Material.theme: Material.Dark
    Material.accent: Material.Blue
    Material.elevation: 6
}
```

## 🎨 美化建议

### 1. 颜色方案（工业控制风格）

**深色主题**：
```qml
// 背景色
backgroundColor: "#0a1628"           // 深蓝黑色
keyboardBackground: "#1a2332"       // 键盘背景

// 按钮色
normalKeyColor: "#34495e"           // 普通按键
specialKeyColor: "#2c3e50"          // 特殊按键（Shift、Enter）
pressedKeyColor: "#3d5a80"          // 按下状态

// 文字色
textColor: "#ecf0f1"                // 主文字
accentColor: "#00d4ff"              // 强调色（科技蓝）
```

### 2. 字体建议

**推荐字体**：
- **Roboto**：现代、清晰
- **Noto Sans**：支持多语言
- **Source Sans Pro**：开源、专业

**字体大小**：
```qml
font.pixelSize: 18  // 按键文字
font.weight: Font.Medium
```

### 3. 动画效果

**按键按下效果**：
```qml
// 缩放动画
scale: pressed ? 0.95 : 1.0
Behavior on scale {
    NumberAnimation { duration: 100; easing.type: Easing.OutQuad }
}

// 颜色过渡
Behavior on color {
    ColorAnimation { duration: 150 }
}
```

**键盘弹出效果**：
```qml
// 从底部滑入
NumberAnimation {
    properties: "y"
    duration: 250
    easing.type: Easing.OutCubic
}
```

### 4. 阴影和边框

**按键阴影**：
```qml
layer.enabled: true
layer.effect: DropShadow {
    horizontalOffset: 0
    verticalOffset: 2
    radius: 4
    samples: 9
    color: "#80000000"
}
```

**边框效果**：
```qml
border.color: "#00d4ff"
border.width: 1
radius: 6  // 圆角
```

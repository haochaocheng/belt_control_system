# FIX 100.300.102 Phase 2.24 - 参数区域布局调整（标签和输入框左右排列，占70%宽度）

**日期**: 2026-01-29
**状态**: 已实施 ✅

---

## 🐛 问题描述

**用户反馈**: "名称和输入框不要上下排列，左右排列，两列的位置全部都在左侧，需要平均分配，占据整个参数输入的70%"

### 问题分析

**当前布局**（GridLayout 2列，上下排列）：
```
左列                    右列
-----------------      -----------------
保护名称:              播放次数:
[输入框______]         [输入框_____]
```

**问题**：
1. 标签和输入框是上下排列（标签在 row 0，输入框在 row 1）
2. 左右两列各占50%宽度
3. 没有预留右侧30%区域给操作按钮

**期望布局**（标签和输入框左右排列，占70%宽度）：
```
左侧70%区域                                    右侧30%区域
----------------------------------------      ----------
保护名称: [输入框]  播放次数: [输入框]       [操作按钮]
模块类型: [下拉框]  播放时长: [输入框]       [操作按钮]
```

---

## ✅ 解决方案

### 实施内容

**文件**: `src/qml/components/device_info/pages/SwitchInputPage.qml`

**修改位置**: Line 279-363

### 关键修改

#### 1. 修改 GridLayout 列数和宽度（Line 280-284）

```qml
// ✅ 修改前（2列，上下排列）
GridLayout {
    width: parent.width - 20
    columns: 2  // 固定两列
    columnSpacing: 20
    rowSpacing: 12
}

// ✅ 修改后（4列，左右排列，占70%宽度）
GridLayout {
    width: parent.width * 0.7  // 占70%宽度，右侧留30%给操作按钮
    columns: 4  // 4列：标签1、输入框1、标签2、输入框2
    columnSpacing: 10
    rowSpacing: 12
}
```

**说明**：
- 从2列改为4列
- 宽度从 `parent.width - 20` 改为 `parent.width * 0.7`
- 每行包含：标签1（column 0）、输入框1（column 1）、标签2（column 2）、输入框2（column 3）

#### 2. 调整保护名称布局（Line 292-324）

```qml
// ✅ 修改前（上下排列）
Text {
    text: "保护名称:"
    Layout.column: 0
    Layout.row: 0  // 标签在第0行
    Layout.preferredWidth: 100
}

Item {
    Layout.column: 0
    Layout.row: 1  // 输入框在第1行
    implicitHeight: nameField.implicitHeight
    // ...
}

// ✅ 修改后（左右排列）
Text {
    text: "保护名称:"
    Layout.column: 0  // 第1列（标签）
    Layout.row: 0
    Layout.preferredWidth: 80
    Layout.alignment: Qt.AlignVCenter
}

Item {
    Layout.column: 1  // 第2列（输入框）
    Layout.row: 0     // 同一行
    implicitHeight: nameField.implicitHeight
    // ...
}
```

**说明**：
- 标签从 `column: 0, row: 0` 移到 `column: 0, row: 0`（不变）
- 输入框从 `column: 0, row: 1` 移到 `column: 1, row: 0`（同一行）
- 标签宽度从100减少到80，添加垂直居中对齐

#### 3. 调整播放次数布局（Line 326-362）

```qml
// ✅ 修改前（上下排列）
Text {
    text: "播放次数:"
    Layout.column: 1  // 第2列
    Layout.row: 0     // 标签在第0行
    Layout.preferredWidth: 100
}

Item {
    Layout.column: 1  // 第2列
    Layout.row: 1     // 输入框在第1行
    implicitHeight: playCountSpin.implicitHeight
    // ...
}

// ✅ 修改后（左右排列）
Text {
    text: "播放次数:"
    Layout.column: 2  // 第3列（标签）
    Layout.row: 0
    Layout.preferredWidth: 80
    Layout.alignment: Qt.AlignVCenter
}

Item {
    Layout.column: 3  // 第4列（输入框）
    Layout.row: 0     // 同一行
    implicitHeight: playCountSpin.implicitHeight
    // ...
}
```

**说明**：
- 标签从 `column: 1, row: 0` 移到 `column: 2, row: 0`
- 输入框从 `column: 1, row: 1` 移到 `column: 3, row: 0`
- 标签和输入框在同一行，左右排列

## 📊 新布局结构

### GridLayout 布局

**4列布局**：
```
列0（标签1）  列1（输入框1）  列2（标签2）  列3（输入框2）
------------ -------------- ------------ --------------
保护名称:     [输入框]       播放次数:     [输入框]
模块类型:     [下拉框]       播放时长:     [输入框]
寄存器地址:   [输入框]       TTS文字:      [输入框]
通道编号:     [输入框]       音频文件:     [输入框+按钮]
保护延时:     [输入框]
```

**宽度分配**：
- GridLayout: 70%
- 右侧操作按钮区域: 30%

### 导航索引不变

虽然布局改变，但导航索引保持不变：
- 索引0: 保护名称（第1行，列1）
- 索引1: 播放次数（第1行，列3）
- 索引2: 模块类型（第2行，列1）
- 索引3: 播放时长（第2行，列3）
- ...

**导航逻辑**：
- 下键：索引 0 → 2 → 4 → 6 → 8（左侧列）
- 下键：索引 1 → 3 → 5 → 7（右侧列）
- 右键：索引 0 → 1（左→右）
- 左键：索引 1 → 0（右→左）

## 🎓 经验教训

### 1. GridLayout 的灵活性

**关键点**：
- 使用 `columns` 属性控制列数
- 使用 `Layout.column` 和 `Layout.row` 明确定位
- 同一行的元素使用相同的 `row` 值
- 相邻列使用连续的 `column` 值

**最佳实践**：
- 标签和输入框在同一行：`Layout.row: 0`
- 标签在左，输入框在右：`column: 0` vs `column: 1`
- 使用 `Layout.alignment` 对齐标签

### 2. 宽度分配策略

**70/30分配**：
- GridLayout: `width: parent.width * 0.7`
- 操作按钮区域: `width: parent.width * 0.3`

**好处**：
- 明确的宽度分配
- 不依赖复杂的绑定表达式
- 避免循环依赖

### 3. 导航逻辑的独立性

**关键点**：
- 导航逻辑基于索引，不依赖布局
- 布局改变不影响导航索引
- 索引0仍然是保护名称，索引1仍然是播放次数

**好处**：
- 布局修改不需要修改导航逻辑
- 代码更易于维护

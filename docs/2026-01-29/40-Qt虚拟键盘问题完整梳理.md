## 🐛 问题分析

### 可能的原因

#### 原因 1：`onLoaded` 中的 `root` 不是 DeviceSettingsDialog

**检查方法**：
```qml
onLoaded: {
    console.log("✅ [DEBUG] 设置 parentDialog:", root)
    console.log("✅ [DEBUG] root.qtVirtualKeyboard:", root.qtVirtualKeyboard)
}
```

**预期结果**：
- `root` 应该是 `DeviceSettingsDialog` 的主 Rectangle
- `root.qtVirtualKeyboard` 应该存在

**实际结果**：
- 待测试

---

#### 原因 2：`parentDialog` 属性没有被正确传递

**检查方法**：
```qml
// SwitchInputPage.qml
Component.onCompleted: {
    console.log("✅ [SwitchInputPage] parentDialog:", parentDialog)
}
```

**预期结果**：
- `parentDialog` 应该不是 `null`

**实际结果**：
- `parentDialog` 是 `null`

---

#### 原因 3：Loader 的作用域问题

**可能的问题**：
- Loader 中的 `root` 可能不是 DeviceSettingsDialog 的 `root`
- 可能是 Loader 所在的某个父容器的 `root`

**解决方案**：
- 使用明确的 ID 引用，而不是 `root`
- 例如：`item.parentDialog = dialogRoot`

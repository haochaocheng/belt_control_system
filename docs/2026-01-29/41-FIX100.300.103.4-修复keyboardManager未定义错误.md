# FIX 100.300.103.4 - 修复 keyboardManager 未定义错误

**日期**: 2026-01-29
**状态**: ✅ 已完成

---

## 🐛 问题根本原因

### 错误信息

```
ReferenceError: keyboardManager is not defined
```

### 问题分析

**在 DeviceSettingsDialog.qml 的 onLoaded 中**：
```qml
onLoaded: {
    if (item) {
        item.deviceId = root.deviceId
        item.deviceName = root.deviceName
        item.keyboardManager = keyboardManager  // ❌ keyboardManager 不存在
        item.parentDialog = root  // ← 这行代码没有被执行！
    }
}
```

**问题流程**：
1. `onLoaded` 开始执行
2. 执行到 `item.keyboardManager = keyboardManager`
3. ❌ **抛出 ReferenceError 异常**
4. ❌ **后续代码全部不执行**
5. ❌ `item.parentDialog = root` 没有被设置
6. ❌ `parentDialog` 保持为 `null`
7. ❌ 虚拟键盘无法打开

---

## ✅ 解决方案

### 注释掉 keyboardManager 赋值

**修改 DeviceSettingsDialog.qml**：

**原代码**（导致错误）：
```qml
onLoaded: {
    if (item) {
        item.deviceId = root.deviceId
        item.deviceName = root.deviceName
        item.keyboardManager = keyboardManager  // ❌ 导致异常
        item.parentDialog = root  // ← 没有被执行
    }
}
```

**新代码**（修复后）：
```qml
onLoaded: {
    if (item) {
        item.deviceId = root.deviceId
        item.deviceName = root.deviceName
        // ✅ 2026-01-29 [Qt 虚拟键盘]: keyboardManager 已废弃，注释掉
        // item.keyboardManager = keyboardManager
        // ✅ 2026-01-29 [Qt 虚拟键盘]: 设置父对话框引用
        item.parentDialog = root  // ✅ 现在可以正常执行
        console.log("✅ [DEBUG] 设置 parentDialog:", root)
        console.log("✅ [DEBUG] root.qtVirtualKeyboard:", root.qtVirtualKeyboard)
    }
}
```

**修改位置**: 第 876-881 行

## 🔧 技术说明

### 为什么 keyboardManager 不存在

**历史原因**：
1. 之前使用自定义虚拟键盘 `EnhancedVirtualKeyboard`
2. 需要 `VirtualKeyboardManager` 来管理
3. 在 DeviceSettingsDialog 中定义了 `keyboardManager`

**现在的情况**：
1. 改用 Qt 官方虚拟键盘 `QtVirtualKeyboardIntegration`
2. 不再需要 `VirtualKeyboardManager`
3. 移除了 `keyboardManager` 的定义
4. 但是忘记移除 `onLoaded` 中的赋值

### 为什么异常会阻止后续代码执行

**JavaScript 异常处理**：
```javascript
try {
    item.keyboardManager = keyboardManager  // 抛出 ReferenceError
    item.parentDialog = root  // 不会执行
} catch (e) {
    // QML 会捕获异常并打印警告
    // 但是后续代码不会执行
}
```

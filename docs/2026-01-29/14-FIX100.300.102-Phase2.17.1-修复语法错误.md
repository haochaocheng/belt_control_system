## 🔍 根本原因分析

### Phase 2.17 的错误修改

**文件**: `src/qml/components/device_info/pages/SwitchInputPage.qml`

**问题代码**（Line 289-840）:
```qml
// // ✅ 2026-01-29 [FIX 100.300.102 Phase 2]: 改为两列交叉导航布局
// RowLayout {
    width: parent.width - 20  // ❌ 这行没有被注释！
    spacing: 20               // ❌ 这行没有被注释！

    // ✅ 左列：保护名称(0)、模块类型(2)、寄存器地址(4)、通道编号(6)、保护延时(8)
    ColumnLayout {
        // ... 大量未注释的代码 ...
    }

    // ✅ 右列：播放次数(1)、播放时长(3)、TTS文字(5)、音频文件(7)
    ColumnLayout {
        // ... 大量未注释的代码 ...
    }
// }  // 右列结束
// }  // RowLayout 结束
```

### 为什么会出错？

1. **只注释了开始标签**：
   - Line 290: `// RowLayout {` ✅ 已注释
   - Line 291-838: **所有内容都未注释** ❌
   - Line 839-840: `// }  // 右列结束` 和 `// }  // RowLayout 结束` ✅ 已注释

2. **导致语法错误**：
   - RowLayout 的开始标签被注释，但内容没有被注释
   - 这些内容（width, spacing, ColumnLayout 等）成为了孤立的代码块
   - 它们没有父容器，导致语法错误
   - QML 解析器在 Line 1067 报错：`Expected token '}'`

3. **为什么页面空白？**：
   - 语法错误导致 SwitchInputPage 加载失败
   - DeviceSettingsDialog 的 Loader 无法加载 SwitchInputPage
   - 右侧内容区域显示为空白

## ✅ 解决方案

### 修复代码

**使用块注释 `/* */` 注释掉整个 RowLayout 内容**：

```qml
// // ✅ 2026-01-29 [FIX 100.300.102 Phase 2]: 改为两列交叉导航布局
// // ✅ 2026-01-29 [FIX 100.300.102 Phase 2.17.1]: 使用块注释注释掉整个 RowLayout 内容
/*
RowLayout {
    width: parent.width - 20
    spacing: 20

    // ✅ 左列：保护名称(0)、模块类型(2)、寄存器地址(4)、通道编号(6)、保护延时(8)
    ColumnLayout {
        // ... 所有内容 ...
    }

    // ✅ 右列：播放次数(1)、播放时长(3)、TTS文字(5)、音频文件(7)
    ColumnLayout {
        // ... 所有内容 ...
    }
}  // 右列结束
}  // RowLayout 结束
*/
```

### 修复原理

1. **块注释的优势**：
   - 使用 `/* */` 可以一次性注释大段代码（500+ 行）
   - 不需要逐行添加 `//`
   - 块注释内部可以包含行注释 `//`，不会冲突

2. **完整注释范围**：
   - Line 291: `/*` 开始块注释
   - Line 292-842: 整个 RowLayout 及其所有内容
   - Line 843: `*/` 结束块注释

3. **保留测试代码**：
   - Line 280-287: 测试 Text 组件（未被注释）
   - 用于验证移除 RowLayout 后程序是否还卡住

## 🎓 经验教训

### 1. 注释大段代码的正确方法

**错误方式**（Phase 2.17）：
```qml
// RowLayout {
    width: parent.width - 20  // ❌ 未注释
    spacing: 20               // ❌ 未注释
    // ... 大量未注释的代码 ...
// }
```

**正确方式**（Phase 2.17.1）：
```qml
/*
RowLayout {
    width: parent.width - 20  // ✅ 被块注释包裹
    spacing: 20               // ✅ 被块注释包裹
    // ... 所有代码都被块注释包裹 ...
}
*/
```

### 2. 块注释 vs 行注释

**块注释 `/* */`**：
- ✅ 适合注释大段代码（几十行到几百行）
- ✅ 一次性注释，不需要逐行添加
- ✅ 可以包含行注释 `//`
- ⚠️ 不能嵌套（`/* /* */ */` 会出错）

**行注释 `//`**：
- ✅ 适合注释单行或少量代码
- ✅ 可以嵌套使用
- ❌ 注释大段代码时需要逐行添加，容易遗漏

### 3. 修改代码时的检查清单

**注释代码块时**：
1. ✅ 确认开始标签已注释
2. ✅ 确认所有内容已注释
3. ✅ 确认结束标签已注释
4. ✅ 检查语法错误（QML 解析器会报错）
5. ✅ 测试验证（实际运行）

**使用块注释时**：
1. ✅ 确认块注释的开始位置 `/*`
2. ✅ 确认块注释的结束位置 `*/`
3. ✅ 确认没有嵌套块注释
4. ✅ 确认块注释内部的行注释不会影响

### 4. 调试语法错误的方法

**症状**：
- QML 解析器报错：`Expected token '}'`
- 页面加载失败
- 页面显示空白

**排查方法**：
1. **查看错误日志**：确定错误位置（行号）
2. **检查括号匹配**：确认 `{` 和 `}` 是否匹配
3. **检查注释完整性**：确认注释是否完整
4. **逐步恢复代码**：从简单到复杂，逐步添加代码

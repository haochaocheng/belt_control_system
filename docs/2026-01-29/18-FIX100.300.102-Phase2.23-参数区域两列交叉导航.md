# FIX 100.300.102 Phase 2.23 - 参数区域两列交叉导航

**日期**: 2026-01-29
**状态**: 已实施 ✅

---

## 🐛 问题描述

**用户反馈**: "导航键在保护名称时，再按右键并没有进入播放次数，而是进入底部的添加输入了"

### 问题分析

Phase 2.22 成功添加了播放次数控件，但导航逻辑有问题：

1. **当前行为**：
   - 焦点在保护名称（索引0，左列）
   - 按右键 → 进入底部按钮区域（区域3）❌

2. **期望行为**：
   - 焦点在保护名称（索引0，左列）
   - 按右键 → 进入播放次数（索引1，右列）✅

3. **根本原因**：
   - 导航逻辑只处理了从列表区域（focusSubArea === 0）切换到参数区域（focusSubArea === 1）
   - 但没有处理参数区域内部的两列交叉导航
   - 当焦点在参数区域时，按右键直接跳到了底部按钮区域

### 实施内容

**文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

**修改位置**:
1. Keys.onRightPressed（Line 248-285）
2. Keys.onLeftPressed（Line 203-246）

### 关键修改

#### 1. 右键导航逻辑（Line 257-274）

```qml
case 2:  // 右侧内容 → 检查当前页面是否支持子区域导航
    var currentPage = getCurrentPage(currentCategory)
    if (currentPage && typeof currentPage.focusSubArea !== "undefined") {
        if (currentPage.focusSubArea === 0) {
            // 从列表区域切换到参数区域
            currentPage.focusSubArea = 1
            currentPage.focusParamIndex = 0
            console.log("✅ [导航] 从列表区域切换到参数区域")
            return
        } else if (currentPage.focusSubArea === 1) {
            // ✅ 2026-01-29 [FIX 100.300.102 Phase 2.23]: 参数区域内部的两列交叉导航
            var currentIndex = currentPage.focusParamIndex
            var paramCount = currentPage.getParamFieldCount()

            // 两列交叉导航：左列（0,2,4,6,8） vs 右列（1,3,5,7）
            if (currentIndex % 2 === 0) {
                // 当前在左列，切换到右列
                var nextIndex = currentIndex + 1
                if (nextIndex < paramCount) {
                    currentPage.focusParamIndex = nextIndex
                    console.log("✅ [导航] 参数区域：左列 → 右列，索引:", currentIndex, "→", nextIndex)
                    return
                }
            }
        }
    }
    // 否则切换到底部按钮
    currentFocusArea = 3
    break
```

**说明**：
- 检查当前是否在参数区域（focusSubArea === 1）
- 如果当前索引是偶数（左列：0,2,4,6,8）
- 切换到下一个索引（右列：1,3,5,7）
- 例如：0 → 1, 2 → 3, 4 → 5

#### 2. 左键导航逻辑（Line 217-234）

```qml
case 2:  // 右侧内容 → 检查是否在参数区域
    var currentPage = getCurrentPage(currentCategory)
    if (currentPage && typeof currentPage.focusSubArea !== "undefined") {
        // ✅ 2026-01-29 [FIX 100.300.102 Phase 2.23]: 参数区域内部的两列交叉导航
        if (currentPage.focusSubArea === 1) {
            var currentIndex = currentPage.focusParamIndex

            // 两列交叉导航：左列（0,2,4,6,8） vs 右列（1,3,5,7）
            if (currentIndex % 2 === 1) {
                // 当前在右列，切换到左列
                var prevIndex = currentIndex - 1
                currentPage.focusParamIndex = prevIndex
                console.log("✅ [导航] 参数区域：右列 → 左列，索引:", currentIndex, "→", prevIndex)
                return
            } else {
                // 当前在左列，返回列表区域
                currentPage.focusSubArea = 0
                console.log("✅ [导航] 从参数区域返回列表区域")
                return
            }
        }
    }
    // 否则切换到左侧类别
    currentFocusArea = 1
    break
```

**说明**：
- 检查当前是否在参数区域（focusSubArea === 1）
- 如果当前索引是奇数（右列：1,3,5,7）
  - 切换到上一个索引（左列：0,2,4,6,8）
  - 例如：1 → 0, 3 → 2, 5 → 4
- 如果当前索引是偶数（左列：0,2,4,6,8）
  - 返回列表区域（focusSubArea = 0）

## 📊 两列交叉导航模式

### 导航区域定义

- **区域 1** (`currentFocusArea === 1`): 左侧类别列表（基本配置、开关量输入、模拟量输入等）
- **区域 2** (`currentFocusArea === 2`): 右侧内容区域
  - **子区域 0** (`focusSubArea === 0`): 开关量列表（急停、跑偏等）
  - **子区域 1** (`focusSubArea === 1`): 参数区域（保护名称、播放次数等）
- **区域 3** (`currentFocusArea === 3`): 底部按钮（添加、删除、保存、取消）

### 参数区域布局

**左列（column: 0）**：
- 索引 0: 保护名称 ✅ **已实现**
- 索引 2: 模块类型
- 索引 4: 寄存器地址
- 索引 6: 通道编号
- 索引 8: 保护延时

**右列（column: 1）**：
- 索引 1: 播放次数 ✅ **已实现**
- 索引 3: 播放时长
- 索引 5: TTS文字
- 索引 7: 音频文件

### 导航流程

**右键导航**：
```
保护名称(0) → 播放次数(1) → 模块类型(2) → 播放时长(3) → ...
   左列          右列          左列          右列
```

**左键导航**：
```
播放次数(1) → 保护名称(0) → 列表区域
   右列          左列
```

**上下键导航**：
```
保护名称(0) → 模块类型(2) → 寄存器地址(4) → ...
   左列          左列            左列

播放次数(1) → 播放时长(3) → TTS文字(5) → ...
   右列          右列          右列
```

## 🎓 经验教训

### 1. 两列交叉导航的实现

**关键点**：
- 使用索引奇偶性判断当前在左列还是右列
- 左列索引：0, 2, 4, 6, 8（偶数）
- 右列索引：1, 3, 5, 7（奇数）
- 右键：偶数 → 奇数（左列 → 右列）
- 左键：奇数 → 偶数（右列 → 左列）

**最佳实践**：
- 在导航逻辑中明确检查当前所在的子区域
- 使用 `return` 语句避免继续执行后续逻辑
- 添加详细的调试日志，便于定位问题

### 2. 导航逻辑的层次结构

**层次**：
1. **区域级别**：左侧类别（1）↔ 右侧内容（2）↔ 底部按钮（3）
2. **子区域级别**：列表区域（0）↔ 参数区域（1）
3. **参数级别**：左列（0,2,4,6,8）↔ 右列（1,3,5,7）

**实现原则**：
- 从内到外检查：先检查参数级别，再检查子区域级别，最后检查区域级别
- 使用 `return` 语句避免跨层级跳转
- 每个层级都有明确的导航规则

### 3. 焦点指示器的同步

**关键点**：
- 焦点指示器依赖 `focusSubArea` 和 `focusParamIndex`
- 导航逻辑必须正确更新这两个属性
- 使用 Connections 信号槽机制同步焦点状态

**最佳实践**：
- 在导航逻辑中直接更新焦点属性
- 不要依赖绑定表达式自动更新
- 添加调试日志验证焦点属性是否正确更新

### 导航规则

**右键**：
- 左列（偶数索引）→ 右列（奇数索引）
- 例如：0→1, 2→3, 4→5, 6→7
- 索引8（保护延时）→ 底部按钮区域

**左键**：
- 右列（奇数索引）→ 左列（偶数索引）
- 例如：1→0, 3→2, 5→4, 7→6
- 左列（偶数索引）→ 开关量列表区域

**下键**：
- 左列：0→2→4→6→8
- 右列：1→3→5→7

**上键**：
- 左列：8→6→4→2→0
- 右列：7→5→3→1

## 🔧 技术实现

### GridLayout 配置

```qml
GridLayout {
    width: paramScrollView.width * 0.7  // 占 ScrollView 宽度的 70%
    columns: 4  // 4列：标签1、输入框1、标签2、输入框2
    columnSpacing: 10
    rowSpacing: 12
}
```

### 控件模板

**标签**：
```qml
Text {
    text: "标签名称:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.column: 0 或 2  // 左列=0, 右列=2
    Layout.row: 0-4        // 行号
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}
```

**输入框容器**：
```qml
Item {
    Layout.column: 1 或 3  // 左列=1, 右列=3
    Layout.row: 0-4        // 行号
    Layout.fillWidth: true
    Layout.maximumWidth: 300
    implicitHeight: control.implicitHeight

    // 控件（TextField/SpinBox/ComboBox）
    DeviceInfo.CustomXXX {
        id: control
        anchors.fill: parent
        keyboardManager: root.keyboardManager
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusSubArea === 1 && root.focusParamIndex === N) ? "#2196F3" : "transparent"
        border.width: (root.focusSubArea === 1 && root.focusParamIndex === N) ? 3 : 0
        radius: 4
        z: 10
    }
}
```

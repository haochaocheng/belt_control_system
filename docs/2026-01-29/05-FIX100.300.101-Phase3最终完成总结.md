## 🏗️ 技术实现

### 焦点指示器模式

所有参数字段使用统一的焦点指示器模式：

```qml
// 包裹模式
Item {
    Layout.fillWidth: true
    implicitHeight: inputComponent.implicitHeight

    // 输入组件
    DeviceInfo.CustomTextField {
        id: inputComponent
        anchors.fill: parent
        keyboardManager: root.keyboardManager
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusSubArea === 1 && root.focusParamIndex === [索引]) ? "#2196F3" : "transparent"
        border.width: (root.focusSubArea === 1 && root.focusParamIndex === [索引]) ? 3 : 0
        radius: 4
        z: 10  // 放在输入框前面
    }
}
```

### 关键属性

**SwitchInputPage.qml**:
- `focusSubArea`: 0=列表区域, 1=参数区域
- `focusParamIndex`: 参数字段焦点索引（0-8）
- `getParamFieldCount()`: 返回参数字段总数（9）

**DeviceSettingsDialog.qml**:
- `currentFocusArea`: 0=顶部, 1=左侧, 2=右侧, 3=底部
- `currentContentItemIndex`: 列表项焦点索引
- 智能检测：`typeof currentPage.focusSubArea !== "undefined"`

# FIX 100.300.102 Phase 2.25 - 修复 GridLayout 宽度问题

## 🐛 问题描述

**用户反馈**：
- 保护名称后面没有输入框
- 播放次数只有上下两个黑色三角形（SpinBox），没有输入框
- 所有控件都靠近参数输入区左侧

**视觉效果**：
```
参数输入区（应该占 70% 宽度）
┌─────────────────────────────────────────────────┐
│ 保护名称: [输入框不显示]  播放次数: [▲▼]       │
│                                                 │
│ ← 所有控件挤在左侧，输入框被压缩不显示          │
└─────────────────────────────────────────────────┘
```

## 🔍 根因分析

### 1. 日志证据

**pjsip.md Line 127-131**：
```
Debug: ✅ [DEBUG] SwitchInputPage ScrollView 宽度: 530
Debug: ✅ [DEBUG] SwitchInputPage ScrollView 高度: 460
Debug: ✅ [DEBUG] GridLayout 加载完成
Debug:    宽度: 250 高度: 60
Debug:    parent.width: 270
```

**问题分析**：
- ScrollView 宽度：530px ✅
- GridLayout parent 宽度：270px ❌（应该是 530px）
- GridLayout 实际宽度：250px (= 270 - 20) ❌（应该是 371px，即 530 * 0.7）

### 2. 根本原因

**代码问题**（Line 281）：
```qml
GridLayout {
    width: parent.width - 20  // ❌ parent 是 ScrollView 的 contentItem，宽度只有 270
    columns: 4
    columnSpacing: 10
    rowSpacing: 12
}
```

**为什么 parent.width 只有 270？**

ScrollView 的结构：
```
ScrollView (width: 530)
  └── contentItem (width: 270)  ← GridLayout 的 parent
        └── GridLayout (width: 250 = 270 - 20)
```

**原因**：
- GridLayout 直接放在 ScrollView 里
- GridLayout 的 parent 是 ScrollView 的 contentItem
- contentItem 的宽度被 ScrollView 的内部逻辑限制为 270px
- 不是 ScrollView 的实际宽度 530px

### 3. 宽度计算

**期望宽度**：
- ScrollView 宽度：530px
- GridLayout 应占 70%：530 * 0.7 = 371px
- 每列宽度：(371 - 10 * 3) / 4 ≈ 85px（标签 + 输入框）

**实际宽度**：
- GridLayout 宽度：250px ❌
- 每列宽度：(250 - 10 * 3) / 4 ≈ 55px ❌
- 输入框被压缩，无法显示

---

## ✅ 解决方案

### 修改内容

**文件**：`src/qml/components/device_info/pages/SwitchInputPage.qml`

**Line 265-287**：

#### 1. 给 ScrollView 添加 ID

```qml
ScrollView {
    id: paramScrollView  // ✅ 添加 ID，便于引用
    Layout.fillWidth: true
    Layout.fillHeight: true
    clip: true
    // ...
}
```

#### 2. 修改 GridLayout 宽度计算

```qml
// ❌ 修改前
GridLayout {
    width: parent.width - 20  // parent.width = 270
    columns: 4
    columnSpacing: 10
    rowSpacing: 12
}

// ✅ 修改后
GridLayout {
    width: paramScrollView.width * 0.7  // 530 * 0.7 = 371
    columns: 4
    columnSpacing: 10
    rowSpacing: 12
}
```

#### 3. 添加详细调试日志

```qml
Component.onCompleted: {
    console.log("✅ [DEBUG] GridLayout 加载完成")
    console.log("   宽度:", width, "高度:", height)
    console.log("   parent.width:", parent.width)
    console.log("   paramScrollView.width:", paramScrollView.width)
    console.log("   计算宽度 (70%):", paramScrollView.width * 0.7)
}
```

## 🎓 经验教训

### 1. ScrollView 的 parent 陷阱

**问题**：
- 在 ScrollView 内部直接使用 `parent.width` 不可靠
- parent 是 ScrollView 的 contentItem，不是 ScrollView 本身
- contentItem 的宽度可能被限制

**解决**：
- 给 ScrollView 添加 ID
- 使用 `scrollViewId.width` 获取实际宽度
- 不要依赖 `parent.width`

### 2. GridLayout 宽度计算

**问题**：
- `Layout.fillWidth: true` 在 GridLayout 中不可靠
- 需要明确指定宽度

**解决**：
- 使用固定宽度：`width: scrollViewId.width * 0.7`
- 或使用绑定：`width: Qt.binding(() => scrollViewId.width * 0.7)`
- 避免使用 `Layout.fillWidth`

### 3. 调试日志的重要性

**关键日志**：
```qml
Component.onCompleted: {
    console.log("   parent.width:", parent.width)
    console.log("   scrollViewId.width:", scrollViewId.width)
    console.log("   计算宽度:", scrollViewId.width * 0.7)
}
```

**价值**：
- 快速定位宽度问题
- 验证修复效果
- 便于后续调试

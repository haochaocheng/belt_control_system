# FIX 100.300.103.2 - 修复虚拟键盘访问问题

**日期**: 2026-01-29
**状态**: ✅ 已完成

---

## 🐛 问题描述

### 错误信息

```
Warning: ⚠️ [SwitchInputPage] 未找到 Qt 虚拟键盘实例
```

### 问题原因

**通过 parent 链无法找到 qtVirtualKeyboard**：

1. `qtVirtualKeyboard` 在 `root` (Rectangle) 内部定义
2. 但是它的 `parent` 被设置为 `Overlay.overlay`
3. 通过 `parent` 链向上查找无法找到它

**原代码**：
```qml
// DeviceSettingsDialog.qml
Rectangle {
    id: root

    VirtualKeyboard.QtVirtualKeyboardIntegration {
        id: qtVirtualKeyboard
        parent: Overlay.overlay  // ❌ parent 不是 root
        z: 2000
    }
}

// SwitchInputPage.qml
function triggerParamInput(paramIndex) {
    // 通过 parent 链查找
    var dialog = root
    while (dialog && !dialog.hasOwnProperty("qtVirtualKeyboard")) {
        dialog = dialog.parent  // ❌ 无法找到
    }
}
```

---

## ✅ 解决方案

### 修改 SwitchInputPage.qml

**文件**: [SwitchInputPage.qml](../../src/qml/components/device_info/pages/SwitchInputPage.qml)

**修改内容**：

#### 直接通过 root 访问

**原代码**（通过 parent 链查找）：
```qml
// 获取父对话框的 qtVirtualKeyboard
var dialog = root
while (dialog && !dialog.hasOwnProperty("qtVirtualKeyboard")) {
    dialog = dialog.parent
}

if (dialog && dialog.qtVirtualKeyboard) {
    dialog.qtVirtualKeyboard.openForField(inputField, callback, inputMode)
}
```

**新代码**（直接访问）：
```qml
// ✅ 2026-01-29 [修复]: 通过 root.qtVirtualKeyboard 直接访问
// root 是 DeviceSettingsDialog 的主 Rectangle
if (root.qtVirtualKeyboard) {
    root.qtVirtualKeyboard.openForField(inputField, function(newValue) {
        console.log("✅ [SwitchInputPage] 虚拟键盘输入完成:", newValue)
    }, inputMode)
} else {
    console.warn("⚠️ [SwitchInputPage] 未找到 Qt 虚拟键盘实例")
    console.warn("   root:", root)
    console.warn("   root.qtVirtualKeyboard:", root.qtVirtualKeyboard)
}
```

**修改位置**: 第 1495-1506 行

## 🔧 技术说明

### 为什么 parent 链查找失败

**QML 对象树结构**：
```
modalContainer (Item)
└── modalOverlay (MouseArea)
    └── dialogFocusScope (FocusScope)
        └── root (Rectangle)  ← DeviceSettingsDialog 主容器
            ├── qtVirtualKeyboard (QtVirtualKeyboardIntegration)
            │   └── parent: Overlay.overlay  ← 不在 root 的子树中
            ├── categoryList (ListView)
            └── contentArea (StackLayout)
                └── SwitchInputPage
```

**问题**：
- `qtVirtualKeyboard.parent` 被设置为 `Overlay.overlay`
- 它不在 `root` 的子树中
- 通过 `parent` 链向上查找无法找到

**解决**：
- `qtVirtualKeyboard` 仍然是 `root` 的子对象（在 QML 对象树中）
- 可以通过 `root.qtVirtualKeyboard` 直接访问
- 不需要通过 `parent` 链查找

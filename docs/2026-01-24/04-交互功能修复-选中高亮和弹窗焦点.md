## 1. 概述

1. ✅ 设备选中状态视觉反馈（改用图片切换）

## 2. 问题描述

### 2.1 问题1：选中状态视觉反馈

**用户反馈**：
> "选中的边框不使用绿色边框而是使用 images/IN_Data_OK.png 这个图片"

**需求变更**：
- ~~原方案：使用 3px 绿色边框 (#00FF00)~~
- **新方案**：使用图片切换
  - 未选中状态：显示 `images/IN_Data.png`
  - 选中状态：显示 `images/IN_Data_OK.png`

**技术要求**：
- 使用 QML 状态系统（state）
- 尽量不使用 JavaScript
- 保持 QDS 兼容性

### 2.2 问题2：弹窗打开后键盘仍作用于背景

**用户反馈**：
> "弹窗设置出现后，导航键还是对模块状态界面里的4*3组件起作用，不应该起作用，现在设置的是弹窗里的参数"

**预期行为**：
- 弹窗打开时，方向键应该用于弹窗内的参数设置
- 背景的设备选中不应响应键盘事件

**实际行为**：
- 弹窗打开后，方向键仍然切换背景的设备选中状态
- 弹窗无法捕获键盘事件

---

## 3. 根本原因分析

### 3.1 选中状态视觉反馈

**原实现**：
- 使用 QML 状态系统改变 Rectangle 的 border 属性
- 选中状态：`border.color: "#00FF00"`, `border.width: 3`
- 未选中状态：`border.color: "transparent"`, `border.width: 0`

**需求变更原因**：
- 用户希望使用自定义图片表示选中状态
- 图片可以提供更丰富的视觉效果（如发光、阴影等）
- 更符合设计规范

**新实现方案**：
- 使用 QML 状态系统改变 Image 的 source 属性
- 选中状态：`source: "images/IN_Data_OK.png"`
- 未选中状态：`source: "images/IN_Data.png"`
- 完全声明式，无 JavaScript，QDS 兼容

### 3.2 弹窗焦点问题

**根本原因**：
- **焦点管理缺失**：弹窗打开时没有获取焦点
- **事件传播**：Input1Page 的 Keys 处理器仍然捕获键盘事件
- **没有条件检查**：键盘处理器没有检查弹窗是否可见

## 4. 修复方案

### 4.1 修复1：图片切换实现选中状态

**文件**: `src/qml/Input1/Input1Content/MyIN_Data.ui.qml`

**修改内容**：使用 QML 状态系统切换背景图片

**修改前（绿色边框方案）**：
```qml
Rectangle {
    id: root
    color: "transparent"
    border.color: "transparent"  // 默认无边框
    border.width: 0
    radius: 8

    states: [
        State {
            name: "selected"
            when: isSelected
            PropertyChanges {
                target: root
                border.color: "#00FF00"  // 绿色边框
                border.width: 3
            }
        },
        State {
            name: "normal"
            when: !isSelected
            PropertyChanges {
                target: root
                border.color: "transparent"
                border.width: 0
            }
        }
    ]

    Image {
        id: backgroundImage
        anchors.fill: parent
        source: "images/IN_Data.png"
        fillMode: Image.Stretch
        smooth: true
    }
}
```

**修改后（图片切换方案）**：
```qml
Rectangle {
    id: root
    color: "transparent"
    radius: 8  // ✅ 移除 border 相关属性

    // ✅ 背景图片移到前面，作为状态切换的目标
    Image {
        id: backgroundImage
        anchors.fill: parent
        source: "images/IN_Data.png"  // 默认未选中状态图片
        fillMode: Image.Stretch
        smooth: true
    }

    // ✅ 状态系统切换图片 source
    states: [
        State {
            name: "selected"
            when: isSelected
            PropertyChanges {
                target: backgroundImage  // ✅ 目标改为 backgroundImage
                source: "images/IN_Data_OK.png"  // 选中状态图片
            }
        },
        State {
            name: "normal"
            when: !isSelected
            PropertyChanges {
                target: backgroundImage
                source: "images/IN_Data.png"  // 未选中状态图片
            }
        }
    ]
}
```

**关键变更**：
1. **移除 border 属性**：不再需要 `border.color` 和 `border.width`
2. **调整元素顺序**：Image 移到 states 前面，便于理解
3. **修改 PropertyChanges 目标**：从 `target: root` 改为 `target: backgroundImage`
4. **修改属性**：从改变 `border.color/width` 改为改变 `source`
5. **完全声明式**：无 JavaScript，QDS 完全兼容

### 4.2 修复2：弹窗打开时阻止背景键盘事件

**文件**: `src/qml/pages/Input1Page.qml`

**修改内容**：在所有键盘处理器中添加弹窗可见性检查

```qml
Keys.onLeftPressed: {
    // ✅ 2026-01-24 [FIX] 弹窗打开时不处理键盘事件
    if (settingsDialog && settingsDialog.visible) {
        return
    }
    if (currentDeviceIndex > 0) {
        currentDeviceIndex--
        updateDeviceSelection()
    }
}

Keys.onRightPressed: {
    // ✅ 2026-01-24 [FIX] 弹窗打开时不处理键盘事件
    if (settingsDialog && settingsDialog.visible) {
        return
    }
    if (currentDeviceIndex < 11) {
        currentDeviceIndex++
        updateDeviceSelection()
    }
}

// ... 其他方向键和 Enter 键类似
```

**原理**：
- 在处理键盘事件前，检查 `settingsDialog.visible`
- 如果弹窗可见，直接返回，不处理事件
- 确保弹窗打开时背景不响应键盘

### 4.3 修复3：弹窗焦点管理和键盘捕获

**文件**: `src/qml/pages/Input1Page.qml`

**修改内容**：弹窗添加焦点管理和键盘事件捕获

```qml
Rectangle {
    id: settingsDialog
    anchors.fill: parent
    color: "#80000000"  // 半透明黑色背景
    visible: false
    z: 1000  // 确保在最上层

    property int deviceId: 1
    property string deviceName: ""

    // ✅ 2026-01-24 [FIX] 弹窗打开时获取焦点，捕获键盘事件
    focus: visible

    // ✅ 2026-01-24 [FIX] Escape 键关闭弹窗
    Keys.onEscapePressed: {
        settingsDialog.visible = false
    }

    // ✅ 2026-01-24 [FIX] 捕获所有其他键盘事件，防止传播到背景
    Keys.onPressed: {
        event.accepted = true
    }

    // ... 其他内容
}
```

**功能**：
1. **自动焦点**：`focus: visible` 确保弹窗可见时自动获取焦点
2. **Escape 关闭**：按 Escape 键关闭弹窗
3. **事件捕获**：`Keys.onPressed` 捕获所有键盘事件，防止传播到背景

## 7. 技术亮点

### 7.1 图片切换方案优势

**QML 状态系统**：
```qml
states: [
    State {
        name: "selected"
        when: isSelected
        PropertyChanges {
            target: backgroundImage
            source: "images/IN_Data_OK.png"
        }
    }
]
```

**优势**：
- ✅ **完全声明式**：无 JavaScript，QDS 完全兼容
- ✅ **自动响应**：`when: isSelected` 自动监听属性变化
- ✅ **平滑切换**：QML 自动处理图片加载和切换
- ✅ **易于维护**：只需替换图片文件，无需修改代码
- ✅ **视觉效果丰富**：图片可以包含发光、阴影、动画等效果

**对比边框方案**：
- 边框方案：只能改变颜色和宽度，视觉效果单一
- 图片方案：可以实现任意复杂的视觉效果

### 7.2 事件捕获机制

**捕获所有键盘事件**：
```qml
Keys.onPressed: {
    event.accepted = true
}
```
- 防止事件传播到背景
- 确保弹窗完全控制键盘输入

**Escape 键快捷关闭**：
```qml
Keys.onEscapePressed: {
    settingsDialog.visible = false
}
```
- 符合用户习惯
- 提供快速退出方式

### 7.3 调试增强

**详细日志输出**：
```qml
console.log("   设备", i, "isSelected =", deviceItems[i].isSelected, "(期望:", shouldSelect, ")")
```
- 输出实际值和期望值对比
- 便于快速定位问题
- 发现 null 引用问题

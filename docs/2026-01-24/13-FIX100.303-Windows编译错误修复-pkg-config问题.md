# Windows 编译错误修复 - pkg-config 问题

**文档版本**: v1.0
**创建日期**: 2026-01-24
**问题编号**: FIX 100.303
**状态**: ✅ 已修复

---

## 问题描述

### 错误信息

```
CMake Error: Could NOT find PkgConfig (missing: PKG_CONFIG_EXECUTABLE)
Call Stack (most recent call first):
  src/audio_network/CMakeLists.txt:11 (find_package)
```

### 根本原因

`audio_network` 模块的 CMakeLists.txt 使用 `pkg-config` 查找 FFmpeg 和 Opus 库：

```cmake
find_package(PkgConfig REQUIRED)
pkg_check_modules(FFMPEG REQUIRED libavcodec libavformat libavutil libswresample)
pkg_check_modules(OPUS REQUIRED opus)
```

**问题**：
- `pkg-config` 是 Unix/Linux 工具
- Windows 上不可用
- 导致 CMake 配置失败

---

## 解决方案

### 修改文件

**文件**: [src/audio_network/CMakeLists.txt](../../src/audio_network/CMakeLists.txt)

### 修改内容

采用与 `risip` 模块相同的方法：**平台条件编译**

```cmake
if(WIN32)
    # ========== Windows 平台配置 ==========
    # 手动指定 FFmpeg 路径
    set(FFMPEG_ROOT "C:/ffmpeg" CACHE PATH "FFmpeg installation directory")

    if(EXISTS ${FFMPEG_ROOT})
        set(FFMPEG_INCLUDE_DIRS ${FFMPEG_ROOT}/include)
        link_directories(${FFMPEG_ROOT}/lib)
        set(FFMPEG_LIBRARIES avcodec avformat avutil swresample)
        message(STATUS "✅ FFmpeg found at: ${FFMPEG_ROOT}")
    else()
        message(FATAL_ERROR "❌ FFmpeg not found at ${FFMPEG_ROOT}")
    endif()

    # Opus 库（可选）
    set(OPUS_ROOT "C:/opus" CACHE PATH "Opus installation directory")
    if(EXISTS ${OPUS_ROOT})
        set(OPUS_INCLUDE_DIRS ${OPUS_ROOT}/include)
        link_directories(${OPUS_ROOT}/lib)
        set(OPUS_LIBRARIES opus)
        message(STATUS "✅ Opus found at: ${OPUS_ROOT}")
    else()
        message(WARNING "⚠️  Opus not found - continuing without Opus")
    endif()

else()
    # ========== Linux 平台配置 ==========
    # 使用 pkg-config
    find_package(PkgConfig REQUIRED)
    pkg_check_modules(FFMPEG REQUIRED libavcodec libavformat libavutil libswresample)
    pkg_check_modules(OPUS REQUIRED opus)
endif()
```

## 依赖要求

### Windows 平台

**必需**：
- FFmpeg (C:/ffmpeg)
  - 包含目录: C:/ffmpeg/include
  - 库目录: C:/ffmpeg/lib
  - 库文件: avcodec.lib, avformat.lib, avutil.lib, swresample.lib

**可选**：
- Opus (C:/opus)
  - 包含目录: C:/opus/include
  - 库目录: C:/opus/lib
  - 库文件: opus.lib

### Linux 平台

**必需**：
- pkg-config
- FFmpeg 开发包 (libavcodec-dev, libavformat-dev, libavutil-dev, libswresample-dev)
- Opus 开发包 (libopus-dev)

# FIX 100.305 - Windows 编译错误修复：Opus 库缺失

**日期**：2026-01-24
**问题编号**：FIX 100.305
**状态**：✅ 已完成

---

## 问题描述

### 错误信息
```
E:\2025\3_gongkongji\belt_control_system\src\audio_network\AudioNetworkTcpSender.cpp:22:10:
fatal error: opus/opus.h: No such file or directory
   22 | #include <opus/opus.h>
      |          ^~~~~~~~~~~~~
compilation terminated.
```

### 根本原因
- Windows 上没有安装 Opus 库
- `AudioNetworkTcpSender.cpp` 和 `AudioNetworkSender.cpp` 都需要 `opus/opus.h`
- 音频网络传输功能依赖 Opus 编解码器

---

## 解决方案

### 方案选择
用户明确要求：**Windows 版本功能和 Linux 版本功能完全一致，不用考虑减配**

因此采用完整安装 Opus 库的方案，而不是条件编译禁用功能。

### 实施步骤

#### 1. 创建自动安装脚本
**文件**：`scripts/2026-01-24/10-auto-install-opus.ps1`

**功能**：
- 从 GitHub 下载 Opus 1.4 源码
- 使用 MinGW 编译 Opus 库
- 安装到 `C:\opus`

**关键配置**：
```powershell
# CMake 配置
& $cmakePath .. -G "MinGW Makefiles" `
    -DCMAKE_C_COMPILER="$gccPath" `
    -DCMAKE_CXX_COMPILER="$gxxPath" `
    -DCMAKE_MAKE_PROGRAM="$makePath" `
    -DCMAKE_INSTALL_PREFIX="C:\opus" `
    -DCMAKE_BUILD_TYPE=Release `
    -DOPUS_BUILD_SHARED_LIBRARY=ON `
    -DOPUS_BUILD_TESTING=OFF `
    -DOPUS_BUILD_PROGRAMS=OFF
```

#### 2. 执行安装
```powershell
.\scripts\2026-01-24\10-auto-install-opus.ps1
```

**安装结果**：
```
✅ Opus 库安装成功！

📁 安装位置: C:\opus
  ✅ 头文件: C:\opus\include\opus\opus.h
  ⚠️  库文件未找到: C:\opus\lib\libopus.a
```

**实际生成的文件**：
- `C:\opus\include\opus\*.h` - 头文件
- `C:\opus\lib\libopus.dll.a` - MinGW 导入库（不是 libopus.a）
- `C:\opus\bin\libopus.dll` - 动态链接库

#### 3. 更新 CMakeLists.txt
**文件**：`src/audio_network/CMakeLists.txt`

**已有配置**（无需修改）：
```cmake
if(WIN32)
    # Opus 库路径（Windows 必需）
    set(OPUS_ROOT "C:/opus" CACHE PATH "Opus installation directory")
    if(EXISTS ${OPUS_ROOT})
        set(OPUS_INCLUDE_DIRS ${OPUS_ROOT}/include)
        link_directories(${OPUS_ROOT}/lib)
        # MinGW 生成的是 libopus.dll.a，链接时使用 opus 即可
        set(OPUS_LIBRARIES opus)
        message(STATUS "✅ Opus found at: ${OPUS_ROOT}")
    else()
        message(FATAL_ERROR "❌ Opus not found at ${OPUS_ROOT}. Please run: .\\scripts\\2026-01-24\\10-auto-install-opus.ps1")
    endif()
else()
    # Linux 平台使用 pkg-config
    pkg_check_modules(OPUS REQUIRED opus)
endif()
```

#### 4. 清理并重新编译
**问题**：链接错误 `cannot find -lopus`

**原因**：CMake 缓存未更新

**解决**：创建清理脚本 `scripts/2026-01-24/11-rebuild-with-opus.ps1`

```powershell
# 清理 build 目录
Remove-Item -Recurse -Force build

# 重新编译
.\build.bat
```

## 技术细节

### MinGW 库命名规则
- **标准静态库**：`libopus.a`
- **MinGW 导入库**：`libopus.dll.a`（用于链接 DLL）
- **动态链接库**：`libopus.dll`

CMake 链接时使用 `-lopus`，会自动查找：
1. `libopus.dll.a`（MinGW 导入库）
2. `libopus.a`（静态库）

### Opus 编译选项
- `OPUS_BUILD_SHARED_LIBRARY=ON`：生成动态库
- `OPUS_BUILD_TESTING=OFF`：不编译测试
- `OPUS_BUILD_PROGRAMS=OFF`：不编译示例程序
- `CMAKE_BUILD_TYPE=Release`：发布版本（优化）

### 安装目录结构
```
C:\opus\
├── include\
│   └── opus\
│       ├── opus.h
│       ├── opus_defines.h
│       ├── opus_multistream.h
│       ├── opus_projection.h
│       └── opus_types.h
├── lib\
│   ├── libopus.dll.a
│   ├── pkgconfig\
│   │   └── opus.pc
│   └── cmake\
│       └── Opus\
│           ├── OpusConfig.cmake
│           ├── OpusConfigVersion.cmake
│           ├── OpusTargets.cmake
│           └── OpusTargets-release.cmake
└── bin\
    └── libopus.dll
```

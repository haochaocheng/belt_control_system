## 2. 核心功能

### 2.1 左侧类别按钮（7个）

| 序号 | 类别名称 | 说明 |
|------|---------|------|
| 0 | **基本配置** | 设备基本信息、网络配置 |
| 1 | **开关量输入** | 数字输入信号配置 |
| 2 | **模拟量输入** | 模拟输入信号配置 |
| 3 | **电机控制** | 电机启停、速度控制 |
| 4 | **制动器控制** | 制动器参数配置 |
| 5 | **张紧控制** | 张紧装置参数配置 |
| 6 | **逻辑控制** | 联锁逻辑、保护逻辑 |

### 2.2 StackLayout 页面切换

**实现代码**：
```qml
StackLayout {
    id: contentStack
    anchors.fill: parent
    currentIndex: root.currentCategory  // 自动切换

    // 7个页面（当前为占位符）
    Rectangle { /* 基本配置 */ }
    Rectangle { /* 开关量输入 */ }
    Rectangle { /* 模拟量输入 */ }
    Rectangle { /* 电机控制 */ }
    Rectangle { /* 制动器控制 */ }
    Rectangle { /* 张紧控制 */ }
    Rectangle { /* 逻辑控制 */ }
}
```

**优势**：
- ✅ **零延迟切换**：所有页面预加载，切换即时响应
- ✅ **状态保持**：用户输入的参数在切换后保留
- ✅ **代码简洁**：一行代码 `currentIndex: root.currentCategory` 实现切换

| 类别 | 底部按钮 |

| **模拟量输入** | 添加输入、删除输入、校准 |
| **电机控制** | 启动测试、停止测试、参数校验 |
| **制动器控制** | 制动测试、释放测试、参数校验 |
| **张紧控制** | 张紧测试、释放测试、参数校验 |
| **逻辑控制** | 添加逻辑、删除逻辑、测试逻辑 |

### 2.4 键盘导航

| 按键 | 功能 |
|------|------|
| **上键** ↑ | 选择上一个类别（0-6） |
| **下键** ↓ | 选择下一个类别（0-6） |
| **左键** ← | 选择上一个底部按钮 |
| **右键** → | 选择下一个底部按钮 |
| **回车** ⏎ | 触发当前选中的底部按钮 |
| **Escape** | 关闭弹窗 |

## 4. 使用方式

### 4.1 打开弹窗
- 双击设备卡片
- 或选中设备后按 Enter 键

2. **切换底部按钮**：使用左右键
3. **触发操作**：按回车键

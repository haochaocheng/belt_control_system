# QML 桌面测试项目 - 快速配置指南

## 快速开始（3分钟配置）

### 1. 创建项目
```powershell
.\scripts\2026-01-24\02-create-qml-preview-project.ps1
```

### 2. 用 Qt Creator 打开
```
Qt Creator → 文件 → 打开文件或项目
选择：QmlPreview/CMakeLists.txt
配置 Kit：选择桌面 MinGW 或 MSVC
```

### 3. 配置 CMakeLists.txt

将以下内容替换到 `QmlPreview/CMakeLists.txt`：

```cmake
cmake_minimum_required(VERSION 3.16)
project(QmlPreview VERSION 1.0 LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

find_package(Qt6 REQUIRED COMPONENTS Core Quick)

qt_standard_project_setup()

qt_add_executable(QmlPreview
    main.cpp
)

qt_add_qml_module(QmlPreview
    URI QmlPreview
    VERSION 1.0
    QML_FILES
        main.qml
        # ✅ 添加 DeviceSettingsDialog 及其依赖
        ../src/qml/components/device_info/DeviceSettingsDialog.qml
        ../src/qml/components/device_info/pages/BasicConfigPage.qml
        ../src/qml/components/parameter_settings/BasicParametersSection.qml
        ../src/qml/components/parameter_settings/NetworkParametersSection.qml
    RESOURCES
        # ✅ 添加图片资源
        ../src/qml/components/device_info/images/deviceInfo40.png
        ../src/qml/components/device_info/images/351.png
        ../src/qml/components/device_info/images/042.png
        ../src/qml/components/parameter_settings/images/039.png
)

target_link_libraries(QmlPreview PRIVATE
    Qt6::Core
    Qt6::Quick
)

set_target_properties(QmlPreview PROPERTIES
    WIN32_EXECUTABLE TRUE
)
```

### 4. 配置 main.qml

将以下内容替换到 `QmlPreview/main.qml`：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import QtQuick.Window 2.15

Window {
    width: 1024
    height: 768
    visible: true
    title: "DeviceSettingsDialog 测试"
    color: "#2c3e50"

    // ✅ 模拟 systemConfig 对象
    QtObject {
        id: mockSystemConfig
        property int machineNumber: 1
        property int workMode: 0
        property int warningTimeSeconds: 10
        property int warningPlayCount: 3
        property string localDeviceName: "测试设备"
        property int warningMode: 0
    }

    // ✅ 加载 DeviceSettingsDialog
    Loader {
        id: dialogLoader
        anchors.centerIn: parent
        width: 800
        height: 550
        source: "../src/qml/components/device_info/DeviceSettingsDialog.qml"

        onLoaded: {
            if (item) {
                console.log("✅ DeviceSettingsDialog 加载成功")
                item.deviceId = 1
                item.deviceName = "1号皮带（测试）"
                item.visible = true

                // 给弹窗焦点，以便测试键盘导航
                item.forceActiveFocus()
            }
        }

        onStatusChanged: {
            if (dialogLoader.status === Loader.Error) {
                console.error("❌ DeviceSettingsDialog 加载失败")
            }
        }
    }

    // ✅ 提示信息
    Text {
        anchors.top: parent.top
        anchors.horizontalCenter: parent.horizontalCenter
        anchors.topMargin: 20
        text: "测试说明：\n" +
              "• 上下键：切换左侧类别\n" +
              "• 左右键：切换底部按钮\n" +
              "• 回车键：触发按钮\n" +
              "• Escape：关闭弹窗"
        font.pixelSize: 14
        color: "#ecf0f1"
        horizontalAlignment: Text.AlignHCenter
    }
}
```

## 常见问题

### Q1: 图片显示不出来？
**A**: 确保在 CMakeLists.txt 的 RESOURCES 中添加了所有图片文件。

### Q2: 组件找不到？
**A**: 确保在 CMakeLists.txt 的 QML_FILES 中添加了所有依赖的 QML 文件。

### Q3: 键盘导航不工作？
**A**: 确保在 main.qml 中调用了 `item.forceActiveFocus()` 给弹窗焦点。

### Q4: 修改后没有效果？
**A**:
1. 确认保存了文件（Ctrl+S）
2. 重新运行（Ctrl+R）
3. 如果还是没效果，清理构建目录后重新编译

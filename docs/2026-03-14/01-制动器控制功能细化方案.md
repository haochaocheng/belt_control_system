## 二、制动器保护功能说明

### 皮带运输机制动器工作原理

皮带运输机制动器一般采用**盘式制动器**（液压或电磁），工作模式为**常闭式**（断电抱闸、通电松闸）：

- **松闸（释放制动）**：给制动器通电/加压 → 制动器打开 → 皮带可以运行
- **抱闸（制动）**：断电/泄压 → 弹簧力使制动器闭合 → 皮带停止

### 制动器操作流程

```
皮带启动流程：松闸 → 确认松闸到位 → 启动电机
皮带停止流程：停止电机 → 延时 → 抱闸 → 确认抱闸到位
```

### 制动器状态信号（DI 反馈）

| 信号 | 说明 | DI通道 |
|------|------|--------|
| 松闸到位 | 制动器完全打开，限位开关触发 | 需配置 |
| 抱闸到位 | 制动器完全闭合，限位开关触发 | 需配置 |

### 制动器故障类型

| 故障 | 触发条件 | 语音报警 |
|------|----------|----------|
| 松闸失败 | 发出松闸命令后，在反馈延时内未收到"松闸到位"信号 | "X号皮带X号制动器松闸失败" |
| 抱闸失败 | 发出抱闸命令后，在反馈延时内未收到"抱闸到位"信号 | "X号皮带X号制动器抱闸失败" |

## 三、修改方案

### 3.1 新增参数（参照电机 BasicConfigTab）

在现有10个参数基础上，新增以下配置项：

| 序号 | 新增参数 | 类型 | 默认值 | 说明 |
|------|----------|------|--------|------|
| A | 松闸输出通道 | SpinBox | 0 | DO模块输出通道（控制松闸） |
| B | 抱闸输出通道 | SpinBox | 0 | DO模块输出通道（控制抱闸），如果和松闸共用同一通道（反向逻辑），则设为-1 |
| C | 使用松闸到位反馈 | Switch | 关闭 | 是否启用松闸到位DI反馈检测 |
| D | 松闸到位反馈通道 | SpinBox | 0 | DI模块反馈通道（仅C启用时有效） |
| E | 松闸反馈超时时间 | SpinBox | 10秒 | 松闸后超时未收到反馈则判定松闸失败 |
| F | 使用抱闸到位反馈 | Switch | 关闭 | 是否启用抱闸到位DI反馈检测 |
| G | 抱闸到位反馈通道 | SpinBox | 0 | DI模块反馈通道（仅F启用时有效） |
| H | 抱闸反馈超时时间 | SpinBox | 10秒 | 抱闸后超时未收到反馈则判定抱闸失败 |
| I | 松闸预警语音 | TextField | "制动器X松闸" | 松闸前预警音频文件名 |
| J | 松闸失败语音 | TextField | "制动器X松闸失败" | 松闸失败音频文件名 |
| K | 抱闸失败语音 | TextField | "制动器X抱闸失败" | 抱闸失败音频文件名 |

### 3.2 新增状态指示区域

在参数区域上方（使用状态下方），新增状态指示行：

```
┌─────────────────────────────────────────────────┐
│  运行状态:  ● 松闸到位(绿/灰)   ● 抱闸到位(绿/灰) │
└─────────────────────────────────────────────────┘
```

- **松闸到位 LED**：读取 DI 反馈通道，绿色=到位，灰色=未到位
- **抱闸到位 LED**：读取 DI 反馈通道，绿色=到位，灰色=未到位

### 3.3 新增操作按钮

底部按钮区域（保存/重置已在右上角，此处不再重复）：

```
┌──────────────────────────────────────────────────────────┐
│  [松闸] [抱闸] [停止]                                     │
└──────────────────────────────────────────────────────────┘
```

| 按钮 | 动作 | 说明 |
|------|------|------|
| 松闸 | 播放预警语音 → 延时 → 发送 DO 松闸命令 → 如启用反馈：等待松闸到位 → 超时则播放"松闸失败"并自动抱闸 | 参照电机启动流程 |
| 抱闸 | 发送 DO 抱闸命令 → 如启用反馈：等待抱闸到位 → 超时则播放"抱闸失败"并自动松闸释放 | 抱闸一般不需要预警 |
| 停止 | 立即发送停止命令（松闸和抱闸通道���置0） | 紧急停止 |

### 3.4 反馈超时自动关闭

与电机启动失败自动停止逻辑一致：
- **松闸失败自动抱闸**：松闸命令发出后，如启用松闸反馈且超时未收到"松闸到位"信号，**自动发送抱闸命令**，播放"松闸失败"语音
- **抱闸失败自动松闸**：抱闸命令发出后，如启用抱闸反馈且超时未收到"抱闸到位"信号，**自动发送松闸释放命令（通道置0）**，播放"抱闸失败"语音
- 未启用反馈时，不做超时检测，仅发送命令

### 3.5 批量音频生成

在 `BatchAudioGenerator.cpp` 的 `generateBrakeTasks` 中新增：

| 现有音频 | 新增音频 |
|----------|----------|
| 制动器X松闸.wav | — (已有) |
| — | 制动器X松闸失败.wav |
| — | 制动器X抱闸失败.wav |

检查现有 `generateBrakeTasks` 是否已包含这些文件名。

## 六、MQTT 命令格式

松闸和抱闸通过 DO 模块控制，MQTT 命令格式与电机一致：

```json
// 松闸（DO通道置1）
{"action": "set", "channel": <松闸输出通道>, "value": 1}

// 抱闸（DO通道置0，或抱闸通道置1）
{"action": "set", "channel": <松闸输出通道>, "value": 0}

// 如果松闸和抱闸是独立通道：
// 松闸：松闸通道=1, 抱闸通道=0
// 抱闸：松闸通道=0, 抱闸通道=1
```

Topic: `belt_control/do/module1/cmd`

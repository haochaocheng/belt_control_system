# FIX 100.300.112.8.25.2 - 修复故障保护类型行号错误

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.25.2
**状态**: ✅ 已完成

---

## 🎯 问题描述

用户反馈截图显示"保护类型错位"，经检查发现：

**故障保护类型输入框的 `Layout.row` 设置错误**：
- 错误值：`Layout.row: 1`
- 正确值：`Layout.row: 2`

这导致故障保护类型输入框与报警类型输入框（row 0）重叠，造成布局错位。

---

## 🔧 修复内容

**修复位置**: Line 338

**修改内容**:
```qml
// 修复前
Item {
    Layout.column: 3
    Layout.row: 1  // ❌ 错误：应该是 2
    ...
}

// 修复后
Item {
    Layout.column: 3
    Layout.row: 2  // ✅ 正确
    ...
}
```

---

## 💡 问题原因

在之前的批量更新脚本中，故障保护类型的行号没有被正确更新：
- 标签的 `Layout.row` 正确更新为 2
- 但输入框的 `Layout.row` 仍然是 1（旧值）

这是因为脚本的正则表达式没有匹配到输入框的 `Layout.row` 设置。

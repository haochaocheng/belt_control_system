# FIX 100.300.112.8.25 - 电流保护参数区细化需求实施计划

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.25

## 🎯 需求概述

对 CurrentProtectionTab（电流保护）的参数区进行细化，改进交互方式和输入控件类型。

---

## 📋 详细需求

### 1. 是否投入（索引 0）

**当前状态**：
- 类型：RadioButton 组（投入/禁用）
- 交互：鼠标点击选择

**需求**：
- 焦点在上面时，按回车键在投入和禁用之间来回切换

**实施方案**：
- 保持 RadioButton 组的视觉样式
- 添加键盘事件处理：按回车键切换状态
- 或者改为 CustomComboBox，选项：投入、禁用

### 2. 报警类型（索引 1）

**当前状态**：
- 类型：CustomComboBox
- 选项：预警、故障

**需求**：
- 保持不变 ✅

### 3. 动作保护类型（索引 2）

**当前状态**：
- 类型：CustomReadOnlyField
- 显示：立即停机

**需求**：
- 改为下拉框
- 按回车键下拉可选项
- 选项：预警停机、预警不停机、立即停机

**实施方案**：
- 改为 CustomComboBox
- 选项：["预警停机", "预警不停机", "立即停机"]

### 4. 故障保护类型（索引 3）

**当前状态**：
- 类型：CustomReadOnlyField
- 显示：紧急停机

**需求**：
- 和动作保护类型一致（下拉框）
- 选项：预警停机、预警不停机、立即停机

**实施方案**：
- 改为 CustomComboBox
- 选项：["预警停机", "预警不停机", "立即停机"]

### 5. 电流量程（索引 4）

**当前状态**：
- 类型：CustomReadOnlyField
- 显示：0-100A

**需求**：
- 可直接输入数据
- 不用写 "0-100A"
- 单位在输入框外部

**实施方案**：
- 改为 CustomSpinBox
- 范围：0-1000（或其他合理范围）
- 单位 "A" 显示在输入框右侧

### 6. 电流上限（索引 5）

**当前状态**：
- 类型：CustomReadOnlyField + 单位 "A"
- 显示：80

**需求**：
- 和电流下限一致（可输入）

**实施方案**：
- 改为 CustomSpinBox
- 范围：0-1000
- 单位 "A" 显示在输入框右侧

### 7. 电流下限（索引 6）

**当前状态**：
- 类型：CustomReadOnlyField + 单位 "A"
- 显示：20

**需求**：
- 可以任意输入

**实施方案**：
- 改为 CustomSpinBox
- 范围：0-1000
- 单位 "A" 显示在输入框右侧

### 8. 输入点选择（索引 7）

**当前状态**：
- 类型：CustomSpinBox
- 显示：0

**需求**：
- AI0.0~AI0.7, AI1.0~AI1.7

**实施方案**：
- 改为 CustomComboBox
- 选项：["AI0.0", "AI0.1", "AI0.2", "AI0.3", "AI0.4", "AI0.5", "AI0.6", "AI0.7", "AI1.0", "AI1.1", "AI1.2", "AI1.3", "AI1.4", "AI1.5", "AI1.6", "AI1.7"]

### 9. 过滤干扰延时（索引 8）

**当前状态**：
- 类型：CustomSpinBox
- 单位：秒

**需求**：
- 可输入任意数
- 单位 0.1秒

**实施方案**：
- 保持 CustomSpinBox
- 修改单位显示为 "0.1秒" 或 "100ms"
- 或者修改步长为 0.1，单位显示为 "秒"

## 💡 关键决策

### 1. 是否投入控件选择

**RadioButton vs CustomComboBox**：

| 方案 | 优点 | 缺点 |
|------|------|------|
| RadioButton + 键盘事件 | 保持原有视觉样式 | 需要额外的键盘事件处理 |
| CustomComboBox | 简单一致，易于导航 | 改变视觉样式 |

**决策**：使用 CustomComboBox，因为：
- 与其他参数控件一致
- 键盘导航更简单
- 代码更简洁

### 2. 电流量程输入范围

**建议范围**：0-1000A
- 覆盖大部分工业应用场景
- 可根据实际需求调整

### 3. 过滤干扰延时单位

**选项**：
- 方案 A：单位显示 "0.1秒"，步长 1，实际值 = 显示值 × 0.1
- 方案 B：单位显示 "秒"，步长 0.1，实际值 = 显示值

**决策**：方案 B（单位 "秒"，步长 0.1）
- 更直观
- 符合用户习惯

# FIX 100.300.112.8.24.5.1 - 修复 MouseArea onClicked 参数声明错误

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.24.5.1
**状态**: ✅ 修复完成

---

## 🎯 问题描述

**用户反馈**: "基本配置参数区不显示"

**日志错误** (Line 228-229):
```
Debug: ✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/BasicConfigTab.qml:240:21: Parameter "mouse" is not declared. Injection of parameters into signal handlers is deprecated. Use JavaScript functions with formal parameters instead.
```

---

## 🔍 根本原因

在 FIX 100.300.112.8.24.5 中添加调试日志时，MouseArea 的 `onClicked` 信号处理器使用了旧的语法：

```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        // ... 日志代码 ...
        mouse.accepted = false  // ❌ 使用了 mouse，但没有声明参数
    }
}
```

**问题**:
1. QML 不推荐在信号处理器中隐式注入参数
2. 应该使用 JavaScript 函数语法显式声明参数
3. 这个警告可能导致 BasicConfigTab 无法正常加载

---

## 🔧 解决方案

### 修改 MouseArea 的 onClicked 语法

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

#### 1. 模块地址 MouseArea（Line 240-261）

**修改前**:
```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        console.log("========== [BasicConfigTab] 鼠标点击模块地址 ==========")
        // ... 日志代码 ...
        mouse.accepted = false  // ❌ 隐式参数
    }
}
```

**修改后**:
```qml
MouseArea {
    anchors.fill: parent
    onClicked: function(mouse) {  // ✅ 显式声明 mouse 参数
        console.log("========== [BasicConfigTab] 鼠标点击模块地址 ==========")
        // ... 日志代码 ...
        mouse.accepted = false  // ✅ 正确使用参数
    }
}
```

#### 2. 反馈通道 MouseArea（Line 382-403）

**同样的修改**:
```qml
MouseArea {
    anchors.fill: parent
    onClicked: function(mouse) {  // ✅ 显式声明 mouse 参数
        console.log("========== [BasicConfigTab] 鼠标点击反馈通道 ==========")
        // ... 日志代码 ...
        mouse.accepted = false  // ✅ 正确使用参数
    }
}
```

---

## 💡 关键修改点

### 旧语法 vs 新语法

**旧语法（不推荐）**:
```qml
onClicked: {
    mouse.accepted = false  // 隐式参数注入
}
```

**新语法（推荐）**:
```qml
onClicked: function(mouse) {
    mouse.accepted = false  // 显式参数声明
}
```

**或者使用箭头函数**:
```qml
onClicked: (mouse) => {
    mouse.accepted = false
}
```

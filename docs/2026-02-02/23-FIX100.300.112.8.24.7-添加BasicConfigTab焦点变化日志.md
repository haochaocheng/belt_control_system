## 🎯 目标

添加 BasicConfigTab 的 `onFocusParamIndexChanged` 监听器，确认属性变化是否正确从 MotorControlPage 传递到 BasicConfigTab。

---

## 🔍 问题分析

从日志分析发现：
- Line 298-307：第一次按下键后，focusParamIndex 从 2 → 4
- MotorControlPage 的 `onFocusParamIndexChanged` 触发（Line 303）
- **但是反馈通道焦点指示器的日志没有输出**

**可能原因**：
1. BasicConfigTab 的 `focusParamIndex` 没有正确更新
2. `Connections` 的 `onFocusParamIndexChanged` 没有触发
3. 条件 `root.focusParamIndex === 4` 不满足

**属性传递链**：
```
MotorControlPage.focusParamIndex
  → MotorConfigPanel.focusParamIndex (Qt.binding)
    → BasicConfigTab.focusParamIndex (Qt.binding)
```

## 🔧 解决方案

### 添加 BasicConfigTab 根元素的 onFocusParamIndexChanged 监听器

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

**修改位置**: Line 22-29

**修改内容**:
```qml
// ✅ 2026-01-30 [FIX 100.300.106]: 导航焦点索引（从父页面传递）
property int focusParamIndex: 0  // 参数区域焦点索引

// ✅ 2026-02-02 [FIX 100.300.112.8.24.7]: 监听 focusParamIndex 变化，确认属性传递

}
```

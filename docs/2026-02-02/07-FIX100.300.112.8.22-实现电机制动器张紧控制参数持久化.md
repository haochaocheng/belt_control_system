### Phase 1: 数据库表设计 ✅

#### 1.1 电机配置表（device_motor_config）

**表结构**:
```sql
CREATE TABLE IF NOT EXISTS device_motor_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,           -- 设备ID（1-12）
    motor_index INTEGER NOT NULL,         -- 电机索引（0-7，对应1-8号电机）
    tab_index INTEGER NOT NULL,           -- Tab索引（0-9）
    tab_name TEXT NOT NULL,               -- Tab名称（基本配置、电流保护等）

    -- 保护参数
    protection_name TEXT,                 -- 保护名称
    protection_delay INTEGER DEFAULT 0,   -- 保护延时（秒）
    upper_limit REAL,                     -- 上限值
    lower_limit REAL,                     -- 下限值
    unit TEXT,                            -- 单位

    -- 语音报警
    voice_alarm_enabled BOOLEAN DEFAULT 0,  -- 是否启用语音报警
    voice_alarm_type TEXT DEFAULT 'tts',    -- 语音类型（tts/audio）
    tts_text TEXT,                          -- TTS文字
    audio_file TEXT,                        -- 音频文件路径
    play_count INTEGER DEFAULT 1,           -- 播放次数
    play_duration INTEGER DEFAULT 5,        -- 播放时长（秒）

    -- 元数据
    enabled BOOLEAN DEFAULT 1,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (device_id) REFERENCES devices(device_id) ON DELETE CASCADE,
    UNIQUE(device_id, motor_index, tab_index)
);
```

**索引**:
```sql
CREATE INDEX idx_motor_config_device ON device_motor_config(device_id);
CREATE INDEX idx_motor_config_motor ON device_motor_config(device_id, motor_index);
```

## 💡 技术要点

### 1. 数据库设计原则
- **外键约束**: 所有配置表都使用 `FOREIGN KEY` 关联到 `devices` 表
- **级联删除**: `ON DELETE CASCADE` 确保删除设备时自动删除相关配置
- **唯一约束**: `UNIQUE(device_id, motor_index, tab_index)` 防止重复记录
- **索引优化**: 为常用查询字段创建索引，提高查询性能

### 2. 默认值设计
- **电机配置**: 上限100.0，下限0.0，单位"A"
- **制动器配置**: 制动力50.0，温度上限80.0，压力上限10.0
- **张紧控制配置**: 张紧力50.0，位置上限100.0，压力上限10.0，温度上限80.0

### 3. Q_INVOKABLE 方法
- 所有公开方法都使用 `Q_INVOKABLE` 宏，使其可以从 QML 调用
- 参数使用 `QVariantMap` 传递，灵活且易于扩展
- 返回值使用 `QVariantMap` 或 `QVariantList`，方便 QML 处理

### 4. 错误处理
- 所有数据库操作都检查执行结果
- 失败时发出 `databaseError` 信号
- 使用 `qCritical()` 记录错误日志

## 🐛 问题描述

### 用户反馈

> voip.md调试日志，测试完成，在电机控制栏中，不显示电机列表，在QDS上正常显示，在设备上不显示。

### 具体问题

**日志显示文件找不到错误**（voip.md:999）：
```
qrc:/qt/qml/BeltControlQml/components/device_info/pages/MyMotorListPanel.qml: No such file or directory
```

**影响范围**：
- 电机控制页面无法显示电机列表
- QDS预览正常（因为QDS直接读取文件系统）
- 设备部署后无法显示（因为qrc资源中没有该文件）

---

## 🔍 根本原因

### 问题分析

**CMakeLists.txt 中的文件名错误**！

**实际文件名**：`MyMotorListPanel.qml`
**CMakeLists.txt 中的文件名**：`MotorListPanel.qml`

**Qt 资源系统**：
- Qt 使用 `qrc://` 协议加载资源
- 只有在 CMakeLists.txt 的 QML_FILES 中声明的文件才会被打包到 qrc 资源中
- 如果文件名不匹配，Qt 无法加载该文件

**为什么 QDS 正常，设备不正常**：
- **QDS**：直接从文件系统读取 QML 文件，不依赖 qrc 资源
- **设备部署**：使用 qrc 资源系统，必须在 CMakeLists.txt 中正确声明

---

## 💡 经验教训

### 1. 文件名一致性

**问题**：
- CMakeLists.txt 中的文件名与实际文件名不一致
- 导致 qrc 资源中缺少该文件

**教训**：
- 添加新 QML 文件时，必须确保 CMakeLists.txt 中的文件名与实际文件名完全一致
- 文件名区分大小写
- 建议使用 IDE 的自动补全功能，避免手动输入文件名

### 2. QDS 和设备部署的差异

**问题**：
- QDS 预览正常，但设备部署后不正常
- 容易误以为代码没有问题

**原因**：
- QDS 直接从文件系统读取 QML 文件
- 设备部署使用 qrc 资源系统

**教训**：
- QDS 预览正常不代表设备部署正常
- 必须在实际设备上测试
- 检查 CMakeLists.txt 中的资源声明

### 3. 调试日志的重要性

**问题**：
- 用户通过 voip.md 日志发现了 "MyMotorListPanel.qml: No such file or directory" 错误
- 这个错误直接指出了问题所在

**教训**：
- 启动日志和运行日志非常重要
- 应该定期检查日志中的警告和错误
- 文件找不到错误通常是资源配置问题

### 4. 资源系统的工作原理

**Qt 资源系统**：
- Qt 使用 `qrc://` 协议加载资源
- 只有在 CMakeLists.txt 的 QML_FILES 中声明的文件才会被打包
- 如果文件没有在 QML_FILES 中，或者文件名不匹配，Qt 无法加载

**教训**：
- 添加新 QML 文件时，必须同时更新 CMakeLists.txt
- 文件名必须完全匹配
- 可以使用 `qrc:/` 路径检查资源是否正确打包

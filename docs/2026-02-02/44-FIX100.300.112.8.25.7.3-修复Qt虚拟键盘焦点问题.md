## 🎯 问题描述

用户反馈：**电流保护，次数设置选项，回车键并没有弹出纯数字虚拟键盘**

**根本原因**：
- 我们调用的是 `root.forceActiveFocus()`，这会把焦点设置到 SpinBox 上
- 但 Qt Virtual Keyboard 需要 **TextInput 获得焦点** 才会显示
- SpinBox 的焦点和内部 TextInput 的焦点是不同的

### Qt Virtual Keyboard 工作原理

1. **TextInput 获得焦点**（不是 SpinBox）
2. **Qt 检测 inputMethodHints**（Qt.ImhDigitsOnly）

### 焦点层级对比

| 组件 | 焦点设置 | Qt Virtual Keyboard 是否显示 |
|------|---------|----------------------------|
| **SpinBox** | `root.forceActiveFocus()` | ❌ 不显示（焦点不在 TextInput） |

## 💡 关键知识点

### 1. SpinBox 的焦点 vs TextInput 的焦点

**SpinBox 组件结构**：
```
SpinBox (root)
├── TextInput (contentItem)
├── Up Button (up.indicator)
└── Down Button (down.indicator)
```

**焦点传递**：
- `root.forceActiveFocus()` → 焦点在 SpinBox 上
- `textInput.forceActiveFocus()` → 焦点在 TextInput 上

**Qt Virtual Keyboard 要求**：
- 必须是 **TextInput 或 TextField** 获得焦点
- SpinBox 的焦点不会触发虚拟键盘

### 2. 为什么需要 activateVirtualKeyboard() 函数？

**问题**：
- CustomSpinBox 的 TextInput 是私有的（contentItem）
- 外部代码无法直接访问 `textInput`

**解决方案**：
- 添加公开函数 `activateVirtualKeyboard()`
- 函数内部调用 `textInput.forceActiveFocus()`
- 外部代码通过函数间接激活虚拟键盘

### 3. Qt Virtual Keyboard 的触发条件

**必要条件**：
1. ✅ main.cpp 中设置 `qputenv("QT_IM_MODULE", QByteArray("qtvirtualkeyboard"));`
2. ✅ main.qml 中有 InputPanel 组件
3. ✅ TextInput/TextField 设置 `inputMethodHints`
4. ✅ **TextInput/TextField 获得焦点**（关键！）

**可选条件**：
- InputPanel 的 `visible` 属性绑定到 `Qt.inputMethod.visible`
- InputPanel 的位置和大小设置

## 🎯 问题描述

用户反馈两个问题：

1. **导航键索引没有更新**：
   - `getParamFieldCount()` 仍然返回 9，应该是 11
   - `triggerParamInput()` 的 switch-case 仍然是旧的索引映射（0-8），应该是新的索引映射（0-10）
   - 导致导航键会跳过最后一排参数

2. **灰色不够明显**：
   - 禁用状态的颜色 `#5E5E5E` 与正常状态的 `#9E9E9E` 对比不够明显
   - 用户难以区分启用和禁用状态

## 💡 设计说明

### 为什么条件启用的参数需要条件判断？

在 `triggerParamInput()` 中，对于次数设置和时间设置，我们添加了条件判断：

```qml
case 2:  // 次数设置
    if (alarmTypeField.currentIndex === 0) {
        countSettingField.forceActiveFocus()
    }
    break
case 3:  // 时间设置
    if (alarmTypeField.currentIndex === 1) {
        timeSettingField.forceActiveFocus()
    }
    break
```

**原因**：
- 如果参数被禁用（`enabled: false`），调用 `forceActiveFocus()` 不会生效
- 添加条件判断可以避免无效的焦点切换尝试
- 提高代码的健壮性

### 颜色选择原则

1. **对比度要足够**：
   - 启用和禁用状态的颜色差异应该至少 30%
   - 新的颜色方案差异达到 38%，符合要求

2. **保持可读性**：
   - 禁用状态虽然变暗，但仍然可读
   - `#3E3E3E` 在深色背景上仍然清晰可见

3. **符合UI规范**：
   - 禁用状态通常使用更暗的颜色
   - 与其他UI元素的禁用状态保持一致

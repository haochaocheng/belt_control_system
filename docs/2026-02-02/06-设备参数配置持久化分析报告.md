## 🎯 需要实现的工作

### Phase 1: 数据库表设计

#### 1.1 电机配置表（device_motor_config）

```sql
CREATE TABLE IF NOT EXISTS device_motor_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,           -- 设备ID（1-12）
    motor_index INTEGER NOT NULL,         -- 电机索引（0-7，对应1-8号电机）
    tab_index INTEGER NOT NULL,           -- Tab索引（0-9）
    tab_name TEXT NOT NULL,               -- Tab名称（基本配置、电流保护等）

    -- 保护参数
    protection_name TEXT,                 -- 保护名称
    protection_delay INTEGER DEFAULT 0,   -- 保护延时（秒）
    upper_limit REAL,                     -- 上限值
    lower_limit REAL,                     -- 下限值
    unit TEXT,                            -- 单位

    -- 语音报警
    voice_alarm_enabled BOOLEAN DEFAULT 0,  -- 是否启用语音报警
    voice_alarm_type TEXT DEFAULT 'tts',    -- 语音类型（tts/audio）
    tts_text TEXT,                          -- TTS文字
    audio_file TEXT,                        -- 音频文件路径
    play_count INTEGER DEFAULT 1,           -- 播放次数
    play_duration INTEGER DEFAULT 5,        -- 播放时长（秒）

    -- 元数据
    enabled BOOLEAN DEFAULT 1,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (device_id) REFERENCES devices(device_id) ON DELETE CASCADE,
    UNIQUE(device_id, motor_index, tab_index)
);
```

#### 1.2 制动器配置表（device_brake_config）

```sql
CREATE TABLE IF NOT EXISTS device_brake_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,           -- 设备ID（1-12）
    brake_index INTEGER NOT NULL,         -- 制动器索引（0-3）

    -- 基本参数
    brake_name TEXT,                      -- 制动器名称
    brake_delay INTEGER DEFAULT 0,        -- 制动延时（秒）
    brake_force REAL,                     -- 制动力设置

    -- 保护参数
    temperature_upper_limit REAL,         -- 温度上限
    temperature_lower_limit REAL,         -- 温度下限
    pressure_upper_limit REAL,            -- 压力上限
    pressure_lower_limit REAL,            -- 压力下限

    -- 语音报警
    voice_alarm_enabled BOOLEAN DEFAULT 0,
    voice_alarm_type TEXT DEFAULT 'tts',
    tts_text TEXT,
    audio_file TEXT,
    play_count INTEGER DEFAULT 1,
    play_duration INTEGER DEFAULT 5,

    -- 元数据
    enabled BOOLEAN DEFAULT 1,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    FOREIGN KEY (device_id) REFERENCES devices(device_id) ON DELETE CASCADE,
    UNIQUE(device_id, brake_index)
);
```

#### 1.3 张紧控制配置表（device_tension_config）

// 加载电机配置
function loadMotorConfig() {
    var config = deviceConfigMgr.loadMotorConfig(currentDeviceId, currentMotorIndex, currentTabIndex)

    nameField.text = config["protection_name"] || ""
    delaySpin.value = config["protection_delay"] || 0
    upperLimitSpin.value = config["upper_limit"] || 0
    lowerLimitSpin.value = config["lower_limit"] || 0
    unitCombo.currentIndex = unitCombo.find(config["unit"] || "")

### AnalogInputPage 虚拟键盘实现（参考标准）

**文件**: `src/qml/components/device_info/pages/AnalogInputPage.qml`

**关键特性**:
1. ✅ CustomSpinBox 有 `keyboardManager` 属性
2. ✅ CustomTextField 有 `keyboardManager` 属性
3. ✅ `triggerParamInput()` 函数使用 `virtualKeyboard.openForField()`
4. ✅ 支持不同输入模式（numeric, chinese, english）
5. ✅ RadioButton 组不打开虚拟键盘，直接切换状态

**代码示例**:
```qml
DeviceInfo.CustomSpinBox {
    id: delaySpin
    from: 0
    to: 600
    editable: true
    anchors.fill: parent
    keyboardManager: root.keyboardManager  // ✅ 关键属性
}

function triggerParamInput(paramIndex) {
    var inputField = null
    var inputMode = "numeric"

    switch(paramIndex) {
    case 1:  // 保护延时
        inputField = delaySpin
        inputMode = "numeric"
        break
    }

    // 打开虚拟键盘
    if (virtualKeyboard && inputField) {
        virtualKeyboard.openForField(inputField, function(newValue) {
            console.log("✅ 虚拟键盘输入完成:", newValue)
        }, inputMode, root)
    }
}
```

## 💡 技术要点

### keyboardManager vs virtualKeyboard

**keyboardManager**:
- 传递给 CustomSpinBox/CustomTextField
- 用于控件内部的键盘管理
- 必须从父组件传递

**virtualKeyboard**:
- 用于 `triggerParamInput()` 函数
- 调用 `openForField()` 方法
- 由 DeviceSettingsDialog 传递

**两者关系**:
- `keyboardManager` 是控件级别的属性
- `virtualKeyboard` 是页面级别的引用
- 两者都需要，缺一不可

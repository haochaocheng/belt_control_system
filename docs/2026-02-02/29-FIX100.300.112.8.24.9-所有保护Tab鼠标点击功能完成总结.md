## 🔧 修改内容

### 1. 为每个 Tab 添加信号声明

在每个 Tab 的根元素中添加：

```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.24.9]: 信号 - 请求更新焦点索引
// 用于鼠标点击时通知父组件，避免直接赋值打破 Qt.binding
signal requestFocusParamIndex(int paramIndex)
```

### 2. 为每个参数添加 MouseArea

每个 Tab 的 9 个参数都添加了 MouseArea：

```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.24.9]: 鼠标点击发射信号
MouseArea {
    anchors.fill: parent
    onClicked: function(mouse) {
        console.log("✅ [TabName] 鼠标点击[参数名]，发射信号: requestFocusParamIndex([index])")
        root.requestFocusParamIndex([index])
        mouse.accepted = false
    }
}
```

### 3. 更新焦点指示器

所有焦点指示器的 z 值从 10 增加到 1000，并添加 `enabled: false`：

```qml
// 焦点指示器
// ✅ 2026-02-02 [FIX 100.300.112.8.24.9]: 增加 z 值到 1000
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === [index]) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === [index]) ? 3 : 0
    radius: 4
    z: 1000  // ✅ 从 10 增加到 1000
    enabled: false
}
```

### 4. 在 MotorConfigPanel 连接所有信号

为所有 9 个 Tab 的 Loader 添加信号连接：

```qml
onLoaded: {
    if (item) {
        item.motorIndex = root.motorIndex
        item.focusParamIndex = Qt.binding(function() { return root.focusParamIndex })
        item.virtualKeyboard = Qt.binding(function() { return root.virtualKeyboard })

        // ✅ 2026-02-02 [FIX 100.300.112.8.24.9]: 连接信号
        item.requestFocusParamIndex.connect(function(paramIndex) {
            console.log("✅ [MotorConfigPanel] 转发信号: requestFocusParamIndex(" + paramIndex + ")")
            root.requestFocusParamIndex(paramIndex)
        })
    }
}
```

## 🔄 信号流程

```
1. 用户鼠标点击参数输入框
   ↓
2. Tab.MouseArea 发射信号: requestFocusParamIndex(index)
   ↓
3. MotorConfigPanel 接收信号，转发: requestFocusParamIndex(index)
   ↓
4. MotorControlPage 接收信号，更新: NavigationManager.paramIndex = index
   ↓
5. NavigationManager.paramIndex 变化 → MotorControlPage.focusParamIndex 变化
   ↓
6. MotorControlPage.focusParamIndex 变化 → Tab.focusParamIndex 变化（通过 Qt.binding）
   ↓
7. Tab.focusParamIndex 变化 → 焦点指示器显示
```

## 💡 关键经验

### 1. 批量处理策略

**问题**：需要为 9 个 Tab × 9 个参数 = 81 个参数添加 MouseArea。

**解决方案**：
- 先手动完成 1 个 Tab，确认模式正确
- 创建通用批量处理脚本
- 一次性处理所有剩余 Tab

**优点**：
- 大幅减少重复劳动
- 保持代码风格一致
- 减少人为错误

### 2. 脚本设计

**关键点**：
- 使用正则表达式匹配和替换
- 检测是否已存在，避免重复添加
- 为不同类型的 Tab 提供参数名称映射
- 提供清晰的进度反馈

**脚本列表**：
1. `add-mousearea-currentprotection.ps1`：为 CurrentProtectionTab 添加 MouseArea
2. `batch-add-mousearea-all-tabs.ps1`：批量为所有 8 个 Tab 添加 MouseArea
3. `connect-signals-motorconfig.ps1`：为 MotorConfigPanel 添加信号连接（未成功，改为手动）

### 3. 信号机制的优势

**优势**：
- 保持 Qt.binding 完整
- 单向数据流清晰
- 易于调试和维护
- 解耦子组件和父组件

**关键原则**：
- 子组件不直接修改通过 Qt.binding 传递的属性
- 使用信号通知父组件
- 父组件统一管理状态

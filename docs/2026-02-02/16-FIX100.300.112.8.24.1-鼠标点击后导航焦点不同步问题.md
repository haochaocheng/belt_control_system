# FIX 100.300.112.8.24.1 - 鼠标点击后导航焦点不同步问题

**状态**: 🔍 问题分析

---

## 🎯 问题描述

**测试场景**:
1. 使用方向键导航到"模块地址"
2. 按回车键 → 虚拟键盘弹出 ✅
3. 按 ESC 退出虚拟键盘 ✅
4. 鼠标点击"模块地址" → `focusParamIndex = 2` ✅
5. 按向下键 → **焦点应该到"反馈通道"（索引4），但实际没有** ❌

---

## 📊 日志分析

```
Debug: ✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2
Debug: ✅ [NavigationManager] 方向键: Down 当前区域: C 当前索引: 2
Debug: ✅ [MotorControlPage] 参数索引变化: 4
Debug: ✅ [NavigationManager] 参数索引: 4
```

**分析**:
1. 鼠标点击后，`root.focusParamIndex = 2` ✅
2. NavigationManager 的 `当前索引` 仍然是 2（旧值）
3. 按向下键，NavigationManager 计算：`2 + 2 = 4`（两列布局，下键 +2）
4. 焦点跳到索引 4（反馈通道）✅

**但是**：用户期望的是从"模块地址"（索引2）按下键到"反馈通道"（索引4），这个行为是正确的！

**重新分析用户问题**：用户说"焦点应该出现反馈地址，但是实际上没有出现"。

让我重新查看日志，看看焦点指示器是否正确显示...

---

## 🔍 根本原因

**问题不是导航逻辑，而是焦点指示器没有显示！**

从日志看，`focusParamIndex` 已经正确更新为 4，但是焦点指示器（蓝色边框）可能没有显示。

**可能原因**:
1. **MouseArea 拦截了焦点**：鼠标点击后，SpinBox 获得了真实焦点（activeFocus），导致焦点指示器被覆盖
2. **z-index 问题**：焦点指示器的 z 值可能不够高，被 SpinBox 覆盖

---

## 🔧 解决方案

### 方案 A: 调整焦点指示器的 z-index

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

**当前代码**（Line 247-255）:
```qml
// 焦点指示器
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 2) ? 3 : 0
    radius: 4
    z: 10  // ❌ 可能不够高
}
```

**修改后**:
```qml
// 焦点指示器
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 2) ? 3 : 0
    radius: 4
    z: 100  // ✅ 提高 z 值，确保在最上层
}
```

### 方案 C: 同步 NavigationManager 的内部状态（推荐）⭐⭐⭐

**问题**：MouseArea 只更新了 `root.focusParamIndex`，但没有通知 NavigationManager。

**解决方案**：通过 MotorControlPage 的信号通知 NavigationManager。

**实施步骤**:

#### 1. 在 MotorControlPage 添加信号

**文件**: `src/qml/components/device_info/pages/MotorControlPage.qml`

```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.24.1]: 添加参数索引同步信号
signal paramIndexSyncRequested(int newIndex)

// 监听信号，同步 NavigationManager
Connections {
    target: root
    function onParamIndexSyncRequested(newIndex) {
        console.log("✅ [MotorControlPage] 同步参数索引到 NavigationManager:", newIndex)
        navigationManager.syncParamIndex(newIndex)
    }
}
```

#### 2. 在 NavigationManager 添加同步方法

**文件**: `src/qml/components/device_info/NavigationManager.qml`

```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.24.1]: 同步参数索引
function syncParamIndex(newIndex) {
    console.log("✅ [NavigationManager] 同步参数索引:", currentIndex, "→", newIndex)
    currentIndex = newIndex
}
```

#### 3. 在 BasicConfigTab 的 MouseArea 中发射信号

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        console.log("✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2")
        root.focusParamIndex = 2
        // ✅ 2026-02-02 [FIX 100.300.112.8.24.1]: 通知父页面同步 NavigationManager
        if (root.parent && root.parent.parent && root.parent.parent.paramIndexSyncRequested) {
            root.parent.parent.paramIndexSyncRequested(2)
        }
        mouse.accepted = false
    }
}
```

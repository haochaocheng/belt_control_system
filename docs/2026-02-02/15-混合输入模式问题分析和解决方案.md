# 混合输入模式问题分析和解决方案

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.24
**状态**: 📋 问题分析

---

## 🎯 问题描述

### 用户需求

1. **数字输入优化**: 对于数字输入框（SpinBox），只弹出数字键盘，不需要英文输入法
2. **混合输入模式支持**:
   - **纯键盘模式**: 方向键导航 + 回车键弹出虚拟键盘
   - **纯鼠标模式**: 鼠标点击 SpinBox + 直接输入数字（不弹虚拟键盘）
   - **混合模式**: 键盘和鼠标混用

### 当前问题

**场景重现**:
1. 使用方向键导航到"模块地址"
2. 按回车键 → 虚拟键盘弹出 ✅
3. 按 ESC 退出虚拟键盘 ✅
4. 用鼠标点击"模块地址" → SpinBox 获得焦点
5. 按上下键 → 数字增减 ✅
6. 再按回车键 → **虚拟键盘不弹出** ❌

**根本原因**:
- 鼠标点击后，SpinBox 获得了**真实焦点**（activeFocus）
- 导航系统的焦点索引没有同步更新
- 回车键事件被 SpinBox 拦截，用于确认输入，而不是触发虚拟键盘

---

## 📊 技术分析

### CustomSpinBox 的焦点行为

**文件**: `src/qml/components/device_info/CustomSpinBox.qml`

**当前行为**:
1. **鼠标点击**: SpinBox 获得 activeFocus
2. **键盘输入**:
   - 上下键：增减数值
   - 回车键：确认输入（默认行为）
   - **不会触发虚拟键盘**

### 导航系统的焦点管理

**文件**: `src/qml/components/device_info/pages/MotorControlPage.qml`

**当前行为**:
1. **方向键导航**: 更新 `focusParamIndex`，显示焦点指示器
2. **回车键**: 调用 `triggerParamInput(focusParamIndex)`
3. **鼠标点击**: **不会更新 `focusParamIndex`** ❌

**问题**: 鼠标点击后，导航系统不知道用户点击了哪个控件，`focusParamIndex` 仍然是旧值。

---

## 🔧 解决方案

### 方案 A: 统一使用虚拟键盘（推荐）⭐⭐⭐

**原理**: 禁用 SpinBox 的直接键盘输入，所有输入都通过虚拟键盘。

**优点**:
- ✅ 行为一致：键盘和鼠标都弹出虚拟键盘
- ✅ 实现简单：只需修改 CustomSpinBox
- ✅ 用户体验统一

**缺点**:
- ❌ 鼠标点击后也需要弹虚拟键盘（可能不符合用户习惯）

**实施步骤**:

#### 1. 修改 CustomSpinBox，禁用直接键盘输入

**文件**: `src/qml/components/device_info/CustomSpinBox.qml`

```qml
SpinBox {
    id: control
    // ... 其他属性 ...

    // ✅ 禁用键盘输入，强制使用虚拟键盘
    Keys.enabled: false

    // ✅ 鼠标点击时弹出虚拟键盘
    MouseArea {
        anchors.fill: parent
        onClicked: {
            if (root.keyboardManager) {
                root.keyboardManager.openForField(control, function(newValue) {
                    control.value = parseInt(newValue) || control.value
                }, "numeric")
            }
        }
    }
}
```

---

### 方案 B: 鼠标点击同步焦点索引（推荐）⭐⭐⭐⭐⭐

**原理**: 鼠标点击 SpinBox 时，同步更新导航系统的 `focusParamIndex`。

**优点**:
- ✅ 支持混合输入模式
- ✅ 鼠标点击后，回车键可以弹出虚拟键盘
- ✅ 保留 SpinBox 的上下键增减功能

**缺点**:
- ⚠️ 需要为每个 SpinBox 添加 MouseArea
- ⚠️ 实现复杂度较高

**实施步骤**:

#### 1. 为 BasicConfigTab 的每个 SpinBox 添加 MouseArea

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

**示例（模块地址）**:

```qml
// 模块地址输入
Item {
    Layout.column: 1
    Layout.row: 1
    Layout.fillWidth: true
    Layout.maximumWidth: 300
    implicitHeight: moduleAddressSpin.implicitHeight

    DeviceInfo.CustomSpinBox {
        id: moduleAddressSpin
        anchors.fill: parent
        from: 1
        to: 8
        value: 1
        editable: true
        keyboardManager: root.keyboardManager
    }

    // ✅ 2026-02-02 [混合输入模式]: 鼠标点击同步焦点索引
    MouseArea {
        anchors.fill: parent
        onClicked: {
            console.log("✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2")
            root.focusParamIndex = 2  // 模块地址的参数索引
            mouse.accepted = false  // 让事件继续传递给 SpinBox
        }
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 2) ? 3 : 0
        radius: 4
        z: 10
    }
}
```

**对所有 SpinBox 重复此操作**:
- 模块地址（索引 2）
- 输出通道（索引 3）
- 反馈通道（索引 4）

## 🎯 数字键盘优化

### 问题

当前虚拟键盘会显示英文输入法，但数字输入框只需要数字键盘。

### 解决方案

**文件**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

**triggerParamInput() 函数**:

```qml
function triggerParamInput(paramIndex) {
    var inputField = null
    var inputMode = "numeric"  // ✅ 默认数字模式

    switch(paramIndex) {
    case 2:  // 模块地址
        inputField = moduleAddressSpin
        inputMode = "numeric"  // ✅ 只显示数字键盘
        break
    case 3:  // 输出通道
        inputField = outputChannelSpin
        inputMode = "numeric"  // ✅ 只显示数字键盘
        break
    case 4:  // 反馈通道
        inputField = feedbackChannelSpin
        inputMode = "numeric"  // ✅ 只显示数字键盘
        break
    }

    // 打开虚拟键盘
    if (virtualKeyboard && inputField) {
        console.log("✅ [BasicConfigTab] 打开 Qt 虚拟键盘 - 控件:", inputField, "模式:", inputMode)
        virtualKeyboard.openForField(inputField, function(newValue) {
            console.log("✅ [BasicConfigTab] 虚拟键盘输入完成:", newValue)
        }, inputMode, root)
    } else {
        console.log("⚠️ [BasicConfigTab] 虚拟键盘或输入控件不可用")
    }
}
```

**说明**:
- `inputMode = "numeric"` 会告诉虚拟键盘只显示数字键盘
- 不会显示英文输入法

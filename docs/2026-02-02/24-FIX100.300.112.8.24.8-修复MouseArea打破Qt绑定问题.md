### 异常流程（鼠标点击后，Line 292-320）

```
Line 292: ========== [BasicConfigTab] 鼠标点击模块地址 ==========
Line 255: root.focusParamIndex = 2  // ❌ 直接赋值，打破 Qt.binding

// ❌ 没有反馈通道焦点指示器的日志！
```

**流程异常**：
- 鼠标点击时，MouseArea 直接赋值 `root.focusParamIndex = 2`
- **这个赋值操作打破了 Qt.binding**
- 之后 MotorControlPage 的 focusParamIndex 变化不再传递到 BasicConfigTab
- BasicConfigTab 的 focusParamIndex 永远停留在 2
- 焦点指示器不再更新

## 🔍 Qt.binding 机制

### Qt.binding 的工作原理

在 MotorConfigPanel.qml Line 277：
```qml
item.focusParamIndex = Qt.binding(function() { return root.focusParamIndex })
```

这行代码创建了一个**绑定**：
- BasicConfigTab.focusParamIndex 绑定到 MotorConfigPanel.focusParamIndex
- 当 MotorConfigPanel.focusParamIndex 变化时，BasicConfigTab.focusParamIndex 自动更新

### 绑定被打破

当在 BasicConfigTab 中直接赋值：
```qml
root.focusParamIndex = 2  // ❌ 直接赋值
```

**Qt 会认为这是一个新的值，不再是绑定**：
- 绑定被永久打破
- 之后 MotorConfigPanel.focusParamIndex 的变化不再传递到 BasicConfigTab
- BasicConfigTab.focusParamIndex 永远停留在最后一次赋值的值

---

## 🔧 解决方案

### 方案 1：移除 MouseArea 的赋值操作（推荐）

**原理**：
- 不在 BasicConfigTab 中修改 focusParamIndex
- 让 MotorControlPage 的 NavigationManager 统一管理焦点状态
- 鼠标点击只是触发事件，不直接修改状态

**实施**：
1. 移除 BasicConfigTab 中所有 MouseArea 的 `root.focusParamIndex = X` 赋值
2. 鼠标点击时，通过信号通知 MotorControlPage
3. MotorControlPage 更新 NavigationManager.paramIndex
4. NavigationManager.paramIndex 变化 → MotorControlPage.focusParamIndex 变化 → BasicConfigTab.focusParamIndex 变化

**优点**：
- 保持 Qt.binding 完整
- 焦点状态由 NavigationManager 统一管理
- 键盘和鼠标的行为一致

**缺点**：
- 需要添加信号机制
- 代码稍微复杂一些

### 方案 2：使用 Qt.binding 重新绑定

**原理**：
- 每次赋值后，立即重新创建绑定

**实施**：
```qml
MouseArea {
    onClicked: function(mouse) {
        // 临时打破绑定，设置新值
        root.focusParamIndex = 2

        // 立即重新绑定
        root.focusParamIndex = Qt.binding(function() {
            return /* 从父组件获取 */
        })

        mouse.accepted = false
    }
}
```

**优点**：
- 代码改动较小

**缺点**：
- 需要访问父组件的属性
- 代码不够清晰
- 容易出错

### 方案 3：完全移除 MouseArea（最简单）

**原理**：
- 移除所有 MouseArea
- 只依赖键盘导航
- 鼠标点击 SpinBox 会自动获得焦点，但不更新 focusParamIndex

**优点**：
- 代码最简单
- 不会打破绑定

**缺点**：
- 鼠标点击后无法同步焦点状态
- 用户体验不一致

## 💡 推荐方案：方案 1（信号通知）

### 实施步骤

#### Step 1: 在 BasicConfigTab 中添加信号

```qml
Rectangle {
    id: root

    // 信号：请求更新焦点索引
    signal requestFocusParamIndex(int paramIndex)

    // ...
}
```

#### Step 2: MouseArea 发射信号而不是直接赋值

```qml
MouseArea {
    anchors.fill: parent
    onClicked: function(mouse) {
        console.log("========== [BasicConfigTab] 鼠标点击模块地址 ==========")

        // ✅ 发射信号，而不是直接赋值
        root.requestFocusParamIndex(2)

        mouse.accepted = false
    }
}
```

#### Step 3: MotorConfigPanel 连接信号

```qml
Loader {
    id: basicConfigLoader
    source: "BasicConfigTab.qml"

    onLoaded: {
        if (item) {
            item.motorIndex = root.motorIndex
            item.focusParamIndex = Qt.binding(function() { return root.focusParamIndex })
            item.virtualKeyboard = Qt.binding(function() { return root.virtualKeyboard })

            // ✅ 连接信号
            item.requestFocusParamIndex.connect(function(paramIndex) {
                // 通知父组件（MotorControlPage）更新焦点
                root.requestFocusParamIndex(paramIndex)
            })
        }
    }
}
```

#### Step 4: MotorControlPage 处理信号

```qml
Loader {
    id: motorConfigPanel
    source: "MotorConfigPanel.qml"

    onLoaded: {
        item.motorIndex = Qt.binding(function() { return root.currentMotorIndex })
        item.focusSubArea = Qt.binding(function() { return root.focusSubArea })
        item.focusTabIndex = Qt.binding(function() { return root.focusTabIndex })
        item.focusParamIndex = Qt.binding(function() { return root.focusParamIndex })
        item.virtualKeyboard = Qt.binding(function() { return root.virtualKeyboard })

        // ✅ 连接信号
        item.requestFocusParamIndex.connect(function(paramIndex) {
            // 更新 NavigationManager
            navigationManager.paramIndex = paramIndex
            // NavigationManager 会自动触发 focusParamIndex 的更新
        })
    }
}
```

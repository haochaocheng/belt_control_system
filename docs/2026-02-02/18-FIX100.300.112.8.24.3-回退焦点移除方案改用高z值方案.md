# FIX 100.300.112.8.24.3 - 回退焦点移除方案，改用高 z 值方案

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.24.3
**状态**: ✅ 修复完成

---

## 🎯 问题描述

**用户反馈**:
"还是不正常，如果焦点再模块地址，在按下键，焦点没有出现在反馈通道，再按一次焦点出现再添加输入得按钮上了"

**测试场景**:
1. 鼠标点击"模块地址"
2. 按下键 → **焦点指示器应该显示在"反馈通道"上，但没有显示** ❌
3. 再按下键 → 焦点跳到"添加输入"按钮

---

## 📊 日志分析

```

Debug: ✅ [NavigationManager] 方向键: Down 当前区域: C 当前索引: 2
Debug: ✅ [MotorControlPage] 参数索引变化: 4

Debug: ✅ [NavigationManager] 方向键: Down 当前区域: C 当前索引: 4
Debug: ✅ [NavigationManager] 切换区域: C → D
```

**分析**:
1. `focusParamIndex` 正确更新为 4 ✅
2. NavigationManager 的 `paramIndex` 也正确更新为 4 ✅
3. 但是焦点指示器没有显示 ❌

---

## 🔍 根本原因

**FIX 100.300.112.8.24.2 的方案（移除 SpinBox 焦点）导致了新问题**:

```qml
moduleAddressSpin.focus = false
root.focus = true  // 将焦点返回给父容器
mouse.accepted = true  // 不让事件传递给 SpinBox
```

**问题**:
1. `root.focus = true` 让 BasicConfigTab 获得焦点，而不是 MotorControlPage
2. 导致方向键事件可能无法正确传递给 NavigationManager
3. 焦点指示器仍然无法显示

---

## 🔧 解决方案

### 方案：回退到原始方案 + 大幅增加 z 值

**原理**:
1. 不移除 SpinBox 的焦点（保持原始行为）
2. 大幅增加焦点指示器的 z 值（从 10 → 1000）
3. 添加 `enabled: false` 确保焦点指示器不拦截鼠标事件

**修改位置**: `src/qml/components/device_info/pages/BasicConfigTab.qml`

#### 1. 模块地址（Line 237-257）

**修改前**（FIX 100.300.112.8.24.2）:
```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        console.log("✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2")
        root.focusParamIndex = 2
        // ✅ 2026-02-02 [FIX 100.300.112.8.24.1]: 移除 SpinBox 的焦点,显示焦点指示器
        moduleAddressSpin.focus = false
        root.focus = true  // 将焦点返回给父容器
        mouse.accepted = true  // 不让事件传递给 SpinBox
    }
}

Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 2) ? 3 : 0
    radius: 4
    z: 10
}
```

**修改后**（FIX 100.300.112.8.24.3）:
```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.24]: 鼠标点击同步焦点索引
MouseArea {
    anchors.fill: parent
    onClicked: {
        console.log("✅ [BasicConfigTab] 鼠标点击模块地址，同步焦点索引: 2")
        root.focusParamIndex = 2
        mouse.accepted = false  // 让事件继续传递给 SpinBox
    }
}

// 焦点指示器
// ✅ 2026-02-02 [FIX 100.300.112.8.24.2]: 大幅增加 z 值，确保在所有元素之上
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 2) ? 3 : 0
    radius: 4
    z: 1000  // ✅ 2026-02-02 [FIX 100.300.112.8.24.2]: 从 10 增加到 1000
    enabled: false  // ✅ 不拦截鼠标事件
}
```

#### 2. 输出通道（Line 289-309）

**同样的修改**:
- 回退 MouseArea 到原始方案（`mouse.accepted = false`）
- 焦点指示器 z 值从 10 → 1000
- 添加 `enabled: false`

#### 3. 反馈通道（Line 343-363）

**同样的修改**:
- 回退 MouseArea 到原始方案（`mouse.accepted = false`）
- 焦点指示器 z 值从 10 → 1000
- 添加 `enabled: false`

---

## 💡 关键修改点

1. **回退 MouseArea**:
   - `mouse.accepted = false`（让事件传递给 SpinBox）
   - 移除 `moduleAddressSpin.focus = false`
   - 移除 `root.focus = true`

2. **大幅增加 z 值**:
   - 从 `z: 10` 改为 `z: 1000`
   - 确保焦点指示器在所有元素之上

3. **添加 enabled: false**:
   - 确保焦点指示器不拦截鼠标事件
   - 鼠标事件可以正常传递给 SpinBox

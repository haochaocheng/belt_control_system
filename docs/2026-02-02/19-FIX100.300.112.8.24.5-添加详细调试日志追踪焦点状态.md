## 💡 关键检查点

### 1. 鼠标点击后 SpinBox 是否获得焦点？

**检查日志**:
```
点击后 - moduleAddressSpin.activeFocus: true
```

**如果是 true**:
- SpinBox 获得了真实焦点
- 可能覆盖了焦点指示器

**如果是 false**:
- SpinBox 没有获得焦点
- 焦点指示器应该可以显示

---

### 2. focusParamIndex 是否正确更新？

**检查日志**:
```
点击后 - root.focusParamIndex: 2
🔶 [MotorControlPage] focusParamIndex 变化: 2
```

**如果更新正确**:
- 绑定系统工作正常
- 问题可能在 Rectangle 渲染

**如果没有更新**:
- 绑定系统有问题
- 需要检查属性传递链路

---

### 3. Rectangle 的 border.color 是否变化？

**检查日志**:
```
🔵 [模块地址焦点指示器] border.color 变化: #2196F3
```

**如果有变化**:
- Rectangle 正在响应 focusParamIndex 变化
- 问题可能是 z-index 或可见性

**如果没有变化**:
- Rectangle 没有响应 focusParamIndex 变化
- 绑定表达式可能有问题

---

### 4. Rectangle 的尺寸和位置是否正确？

**检查日志**:
```
  - width: 300 height: 40
  - x: 0 y: 0
```

**如果尺寸为 0**:
- Rectangle 没有正确填充父容器
- anchors.fill 可能失效

**如果位置不对**:
- Rectangle 可能被移到了屏幕外
- 需要检查布局系统

## 🎯 需求描述

用户反馈"还缺一个时间设置"，并要求：
- 次数设置和时间设置应该**始终显示**
- 但在不满足条件时**变成灰色（禁用状态）**
- 而不是完全隐藏（`visible: false`）

## 🔧 修改内容

### 1. 次数设置（参数2）

**修改前**：
```qml
// 标签
Text {
    text: "次数设置:"
    color: "#9E9E9E"
    visible: alarmTypeField.currentIndex === 0  // 完全隐藏
}

// 输入框
Item {
    visible: alarmTypeField.currentIndex === 0  // 完全隐藏

    DeviceInfo.CustomSpinBox {
        id: countSettingField
        // 没有 enabled 属性
    }

    MouseArea {
        // 没有 enabled 属性
    }

    // 焦点指示器索引错误
    border.color: (root.focusParamIndex === 10) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 10) ? 3 : 0
}
```

**修改后**：
```qml
// 标签

    text: "次数设置:"
    color: alarmTypeField.currentIndex === 0 ? "#9E9E9E" : "#5E5E5E"  // 条件变色
    // 移除 visible 属性，始终显示
}

// 输入框
Item {
    // 移除 visible 属性，始终显示

    DeviceInfo.CustomSpinBox {
        id: countSettingField
        enabled: alarmTypeField.currentIndex === 0  // 条件启用
    }

    MouseArea {
        enabled: alarmTypeField.currentIndex === 0  // 条件启用
    }

    // 修复焦点指示器索引
    border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === 2) ? 3 : 0
}
```

## 💡 设计说明

### 为什么使用 `enabled` 而不是 `visible`？

1. **用户体验更好**：
   - 用户可以看到所有可用的参数选项
   - 灰色状态清楚地表明该参数当前不可用
   - 避免布局跳动（参数显示/隐藏时）

2. **符合UI设计规范**：
   - 禁用状态（灰色）是标准的UI交互模式
   - 比完全隐藏更直观

3. **保持布局稳定**：
   - GridLayout 的行列结构保持不变
   - 不会因为参数显示/隐藏而导致其他参数位置变化

### 颜色选择

- **正常色**: `#9E9E9E`（中灰色，可读性好）
- **禁用色**: `#5E5E5E`（深灰色，明显变暗）

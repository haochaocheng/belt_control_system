## 🔍 Qt官方示例分析

**关键代码**（Line 97-104）：
```qml
TextField {
    id: digitsField
    width: parent.width
    placeholderText: "Digits only field"
    inputMethodHints: Qt.ImhDigitsOnly  // ✅ 设置输入提示
    enterKeyAction: EnterKeyAction.Next
    onAccepted: textArea.focus = true   // ✅ 回车键切换焦点

```

**关键点**：
1. ✅ 使用`inputMethodHints: Qt.ImhDigitsOnly`
2. ✅ 使用`onAccepted`处理回车键
3. ✅ 直接设置`focus = true`，不是`forceActiveFocus()`

## 💡 根本原因分析

### 问题1：Qt.inputMethod.visible不会自动变化

**原因**：
- `Qt.inputMethod.visible`是一个**只读属性**
- 它由Qt的输入法系统自动管理
- **鼠标点击**TextField会触发Qt.inputMethod
- **键盘导航**+`forceActiveFocus()`可能不会触发Qt.inputMethod

**证据**：
- Qt官方示例使用`inputPanel.active`，不是`Qt.inputMethod.visible`
- `inputPanel.active`是InputPanel自己的属性，会自动管理

### 问题2：forceActiveFocus() vs focus = true

**forceActiveFocus()**：
- 强制设置焦点，即使父组件没有焦点
- 可能不会触发所有焦点相关的信号

**focus = true**：
- 正常的焦点设置
- 会触发所有焦点相关的信号和事件

### 问题3：键盘导航 vs 鼠标点击

**鼠标点击**：
- 触发MouseArea的点击事件
- 触发TextField的点击事件
- 触发Qt.inputMethod

**键盘导航**：
- 只设置焦点
- 可能不会触发Qt.inputMethod
- 需要手动调用`Qt.inputMethod.show()`

## 🔧 修复方案

### 方案A：使用inputPanel.active（推荐）

**参考Qt官方示例**，使用`inputPanel.active`而不是`Qt.inputMethod.visible`。

**修改main_qds.qml**：
```qml
InputPanel {
    id: virtualKeyboard
    z: 99
    x: 0
    width: root.width

    property real yPositionWhenHidden: root.height

    states: State {
        name: "visible"
        when: virtualKeyboard.active  // ✅ 绑定到 active
        PropertyChanges {
            target: virtualKeyboard
            y: root.height - virtualKeyboard.height
        }
    }

    transitions: Transition {
        from: ""
        to: "visible"
        reversible: true
        NumberAnimation {
            properties: "y"
            duration: 250
            easing.type: Easing.InOutQuad
        }
    }
}
```

**优点**：
- ✅ 与Qt官方示例一致
- ✅ `inputPanel.active`会自动管理
- ✅ 支持动画效果

**缺点**：
- ❓ 不确定键盘导航是否会触发`inputPanel.active`

### 方案B：手动调用Qt.inputMethod.show()

**在CustomSpinBox中手动显示虚拟键盘**。

**修改CustomSpinBox.qml**：
```qml
function activateVirtualKeyboard() {
    textInput.forceActiveFocus()
    Qt.inputMethod.show()  // ✅ 手动显示虚拟键盘
    console.log("✅ [CustomSpinBox] activateVirtualKeyboard() 调用，手动显示虚拟键盘")
}
```

**优点**：
- ✅ 直接控制虚拟键盘显示
- ✅ 适用于键盘导航场景

**缺点**：
- ❌ 不是Qt官方推荐的方式
- ❌ 可能与Qt的输入法系统冲突

### 方案C：模拟鼠标点击

**在TextInput上模拟鼠标点击事件**。

**修改CustomSpinBox.qml**：
```qml
function activateVirtualKeyboard() {
    textInput.forceActiveFocus()
    // 模拟鼠标点击
    var mouseEvent = Qt.createQmlObject('import QtQuick 2.0; MouseEvent {}', textInput)
    textInput.clicked(mouseEvent)
    console.log("✅ [CustomSpinBox] activateVirtualKeyboard() 调用，模拟鼠标点击")
}
```

**优点**：
- ✅ 模拟Qt官方示例的行为

**缺点**：
- ❌ 复杂且不可靠
- ❌ 不是推荐的方式

## 🎯 推荐方案

### 综合方案：方案A + 方案B

1. **修改main_qds.qml**：使用`inputPanel.active`（方案A）
2. **修改CustomSpinBox.qml**：添加`Qt.inputMethod.show()`（方案B）
3. **测试验证**：确保两种方式都能工作

**理由**：
- Qt官方示例使用`inputPanel.active`是有原因的
- 键盘导航可能需要手动调用`Qt.inputMethod.show()`
- 两种方式结合，确保虚拟键盘能够显示

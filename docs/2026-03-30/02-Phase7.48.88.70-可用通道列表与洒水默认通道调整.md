# Phase 7.48.88.70 - 可用通道列表显示与洒水默认通道调整

## 变更内容

### 1. 冲突提示增加可用通道列表

所有4个设备配置面板（电机/制动器/张紧/洒水）在通道冲突提示时，下方同时显示当前可用的通道列表：

```
⚠ 保存失败：通道 5 已被「2号电机」占用，请先释放原通道
可用通道: 0, 7, 8, 9, 10, 15
```

- 冲突提示橙色文字（已有）
- 可用通道绿色文字（新增，`#4CAF50`）
- 提示条高度从 32/36px 增加到 56px 容纳两行
- 4秒后自动隐藏（与冲突提示同步）

### 2. 洒水默认通道从5个改为4个

| 洒水编号 | 旧默认通道 | 新默认通道 |
|---------|-----------|-----------|
| 洒水1 | 11 | 11 |
| 洒水2 | 12 | 12 |
| 洒水3 | 13 | 13 |
| 洒水4 | 14 | 14 |
| 洒水5 | 15 → | -1（未分配） |
| 洒水6 | -1 | -1 |
| 洒水7 | -1 | -1 |
| 洒水8 | -1 | -1 |

这样16通道分配：
- 通道 0-4: 电机1-5
- 通道 5-9: 制动器1-5松闸
- 通道 10: 张紧控制
- 通道 11-14: 洒水1-4
- 通道 15: 未分配（可自由分配）

### 3. 同类设备间也要求先释放

确认行为：同类设备之间更换通道也必须先释放原通道，不再自动替换。这在 Phase 7.48.88.69 中已实现（废弃了 `releaseConflictingChannels`）。

## 修改文件

1. **MotorControlPage.qml** - 添加 `availableChannelsText` 属性、`getAvailableChannelsText()` 函数、UI显示
2. **BrakeConfigPanel.qml** - 同上
3. **TensionControlConfigPanel.qml** - 同上
4. **SprinklerConfigPanel.qml** - 同上 + 默认通道从5改为4（`sprinklerIndex < 5` → `sprinklerIndex < 4`）

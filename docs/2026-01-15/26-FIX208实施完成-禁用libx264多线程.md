# FIX 100.208 实施完成 - 禁用 libx264 多线程初始化

**时间**: 2026-01-16 07:25（北京时间）
**状态**: ✅ **代码实施完成，等待测试**
**方案**: 强制 libx264 使用单线程初始化，确保主上下文被正确初始化

---

## 🎯 核心问题：100% 确定

### 问题描述

libx264 使用 FFmpeg 多线程帧编码器（FF_THREAD_FRAME），导致：

1. **FFmpeg 创建 9 个子线程上下文**
   - 每个子线程调用 X264_init()
   - 每个子线程的 x4->enc 都被正确初始化

2. **主上下文（PJSIP 使用的）从未被初始化**
   - 主上下文的 X264_init() 从未被调用
   - 主上下文的 x4->enc = NULL

3. **编码失败**
   - PJSIP 使用主上下文编码
   - x4->enc = NULL → avcodec_send_frame() 返回 -22 (EINVAL)

## ✅ FIX 100.208 解决方案

### 修改文件

**文件**: `cross-compile/src/pjproject-2.16/pjmedia/src/pjmedia-codec/ffmpeg_vid_codecs.c`
**行号**: Line 2863-2914（在 AVCODEC_OPEN 之前）

### 核心代码

```c
/* ✅ 2026-01-16 07:20 [FIX 100.208] 禁用 libx264 多线程初始化 */
if (ff->enc && pj_ansi_strstr(ff->enc->name, "libx264") != NULL) {
    PJ_LOG(1,(THIS_FILE, "[FIX 100.208] Disabling libx264 threading"));
    PJ_LOG(1,(THIS_FILE, "  Encoder: %s", ff->enc->name));
    PJ_LOG(1,(THIS_FILE, "  Reason: Multi-threading leaves main context uninitialized"));
    PJ_LOG(1,(THIS_FILE, "  Current thread_count: %d, thread_type: %d",
               ff->enc_ctx->thread_count, ff->enc_ctx->thread_type));

    /* 禁用多线程 */
    ff->enc_ctx->thread_count = 1;  /* 强制单线程 */
    ff->enc_ctx->thread_type = 0;   /* 不使用任何线程类型 */

    PJ_LOG(1,(THIS_FILE, "  Modified thread_count: %d (single-threaded)",
               ff->enc_ctx->thread_count));
    PJ_LOG(1,(THIS_FILE, "  Expected: Main context will be initialized by X264_init()"));
}
```

### 工作原理

1. **检测 libx264 编码器**
   - 使用 `pj_ansi_strstr(ff->enc->name, "libx264")`
   - 只对 libx264 应用此修复

2. **禁用多线程**
   - `thread_count = 1` → 强制单线程编码
   - `thread_type = 0` → 不使用任何线程类型（包括 FF_THREAD_FRAME）

3. **预期结果**
   - FFmpeg 不会创建子线程上下文
   - 主上下文直接调用 codec->init()（X264_init）
   - 主上下文的 x4->enc 被正确初始化
   - PJSIP 编码时 x4->enc != NULL → 编码成功

| 项目 | 多线程（原来） | 单线程（FIX 100.208） |
|------|--------------|---------------------|
| **编码性能** | 可并行处理多帧 | 只能串行处理 |
| **CPU 占用** | 多核心分布 | 单核心集中 |
| **延迟** | 略低 | 略高 |
| **可靠性** | ❌ 主上下文未初始化 | ✅ 主上下文正确初始化 |

**预期 CPU 占用**：
- 多线程：2-5%（分布在多个核心）

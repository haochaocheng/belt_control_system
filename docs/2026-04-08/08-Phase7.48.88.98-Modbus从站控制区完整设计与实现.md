# Phase 7.48.88.98 Modbus从站控制区完整设计与实现

## 修复日期
2026-04-08

## 背景
TCPDataAdapter的Modbus从站原本只有读取状态区域（离散输入400个 + 输入寄存器300个），写入控制区域仅有基础功能：
- 线圈区：DO控制(0-7)、启/停/急停(8-10)，共11个
- 保持寄存器区：工作模式(0)、本机编号(1)、DO控制字(2-9)、心跳(10)，共11个

缺少：电机独立启停、洒水控制、保护复位、系统参数配置、保护阈值远程修改、TTS/音频配置等控制功能。

用户要求"全功能"设计。

### 3. 保护参数远程修改确认流程

1. PLC写 HR21 = 0x5A5A → 系统检查集控模式，设 HR22 = 1(就绪)
2. PLC写 HR23-33 参数数据
3. PLC写 HR34 = 0x1234 → 系统校验并执行
4. 系统设 HR22 = 2(成功) 或 3(错误)
5. HR21/HR34 自动清零，防止重复执行

### 5. 新增依赖注入

TCPDataAdapter新增4个数据管理器指针：
- `MqttProtectionMonitor` — 电机/洒水控制、速度保护复位
- `ProtectionLogicController` — 保护复位
- `DeviceRuntimeTracker` — 故障复位
- `DeviceConfigManager` — 保护参数修改

| 紧急停车 | ✗ | ✗ | ✓ |
| 电机启停 | ✓ | ✗ | ✗ |
| 洒水启停 | ✓ | ✗ | ✗ |
| 保护/故障复位 | ✓ | ✗ | ✗ |
| 系统配置(B组) | ✗ | ✗ | ✓ |
| 保护阈值修改(D组) | ✓ | ✓(双重) | ✗ |

### 7. 目标皮带编号覆盖 (HR20)

- HR20=0: 使用本机编号（默认）
- HR20=1-8: 覆盖本机编号，指定目标皮带
- 影响所有线圈命令（启停、电机、序列等）

# Phase 7.48.88.49 - 设备卡片布局重设计（水平优先）

## 日期
2026-03-28

## 需求描述

卡片高度受限但宽度充裕，原垂直堆叠布局浪费大量高度空间。重新设计为全面水平化布局：
- 参数区改为2行×2列，每个参数名+进度条+数值在同一行
- 在线/离线和今日运行时间合并到顶部状态栏
- 设备LED放大，LED和文字水平同行
- 保护指示移到底部，LED和文字水平同行

## 实现方案

### 文件
`src/qml/Input1/Input1Content/MyIN_Data.ui.qml` — 完全重写内容区布局

### 新布局结构
```
┌──────────────────── 480px ────────────────────┐
│              设备 01 (标题栏)                    │
├───────────────────────────────────────────────┤
│ ●停止 [就地][连锁][允许] ●在线│今日00:12:34   │ ← 顶部合并一行
├─────────────────────────────────��─────────────┤
│ 速度 ━━━━━━━━━ 12.5m/s │ 电流 ━━━━━━━ 15.2A │ ← 2行×2列

│───────────────────────────────────────────────│

└───────────────────────────────────────────────┘
```

### 关键变化

| 区域 | 旧布局 | 新布局 |
|------|--------|--------|
| 参数区 | 2×2网格垂直堆叠，118px | 2行×2列水平，70px |
| 顶部状态栏 | 状态/模式/连锁/允许 | +在线/离线 +今日时间 |
| 设备LED | 10×10px，Column上下 | 14×14px，Row水平 |
| 保护指示 | 中间，Column上下 | 底部，Row水平 |
| 底部信息栏 | 单独20px行 | 已删除(合并到顶部) |

### 高度节省

- 参数区: 118→70px (-48px)
- 底部信息栏: 20→0px (-20px)
- 设备LED行: 32→28px (-4px)
- 保护栏: 38→28px (-10px)
- 总节省: ~82px → 更多留白，不再有溢出裁剪风险

## 保留功能

- 序列执行覆盖模式（Mode B）：启停序列时显示阶段名+倒计时，覆盖参数区
- 故障红色遮罩闪烁
- 保护三态指示（绿/红/琥珀）
- 左侧状态指示条
- 选中态背景切换

4. 保护指示在最底部，LED和名字同行

## 🎓 经验教训

### 1. QML 组件创建完整流程

创建使用自定义组件的 QML 文件时，必须确保：

- ✅ 创建主 QML 文件
- ✅ **创建所有被引用的组件文件**（容易遗漏！）
- ✅ 添加到 CMakeLists.txt
- ✅ 测试验证

### 2. 为什么会遗漏组件文件

**原因**：
- 在设计阶段计划使用独立组件
- 实现时直接写了主文件，忘记创建组件
- 导入语句被遗留，但组件从未创建

**教训**：
- 创建 QML 文件时，立即检查所有 import 语句
- 确保所有导入的目录和组件都存在
- 或者先用占位符，后续再实现

### 3. 错误信息解读

**错误信息**：
```
qrc:/qt/qml/BeltControlQml/pages/VoiceManagement.qml:4:1: "../components/voice_management": no such directory
```

**含义**：
- Line 4 的 import 语句试图导入一个目录
- 该目录不存在
- QML 引擎无法加载该模块

**排查步骤**：
1. 检查 import 语句 → 发现导入 `../components/voice_management`
2. 检查目录是否存在 → ❌ 不存在
3. **解决方案**：注释掉导入 + 替换组件使用

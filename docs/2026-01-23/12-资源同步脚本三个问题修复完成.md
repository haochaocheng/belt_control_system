## 🔍 根本原因分析

### 问题 1 & 2: 缺少进度反馈
**原因**:
- 本地复制模型时，使用 `Copy-Item` 没有输出
- 远程解压时，使用 `unzip -q` 静默模式

### 问题 3: PowerShell Heredoc 变量展开
**根本原因**: 使用了双引号 heredoc `@"..."@`

**技术细节**:
```powershell
# ❌ 错误写法（会被 PowerShell 解析）
$deployScript = @"
TTS_COUNT=\$(find /home/${DeviceUser}/... | wc -l)
"@
```

**问题链**:
1. `@"..."@` 允许 PowerShell 变量展开
2. `\$` 转义在 PowerShell heredoc 中**不起作用**
3. PowerShell 尝试解析 `wc` 为 cmdlet → 失败
4. PowerShell 尝试解析 `TTS_COUNT` 为变量 → 失败
5. 脚本卡死，bash 脚本从未被传递给 SSH

### 问题 4: /tmp 目录空间不足
**根本原因**: `/tmp` 目录通常是小分区

**技术细节**:
- `/tmp` 目录在嵌入式设备上通常只有几百 MB
- 资源文件压缩后约 1.2GB，超过 `/tmp` 容量
- SCP 上传失败：`write remote "/tmp/...": Failure`

**为什么会满**:
- 之前的上传尝试可能留下了部分文件
- 系统临时文件占用空间
- `/tmp` 分区本身就很小

### 修复 3: 修复 Bash 脚本转义问题（核心修复）

**位置**: Lines 293-368

**旧代码（错误）**:
```powershell
$deployScript = @"
#!/bin/bash
TTS_COUNT=\$(find /home/${DeviceUser}/... | wc -l)
echo "    ✅ TTS 模型部署完成（\$((TTS_COUNT - 1)) 个模型）"
"@
```

**新代码（正确）**:
```powershell
# ✅ 2026-01-23 15:30 [FIX] 修复 PowerShell heredoc 变量展开问题
# 原因：@"..."@ 会展开变量，导致 bash 脚本被 PowerShell 解析
# 方案：使用 @'...'@ 单引号 heredoc，然后手动替换变量
$deployScript = @'
#!/bin/bash
TTS_COUNT=$(find /home/DEVICE_USER/... | wc -l)
echo "    ✅ TTS 模型部署完成（$((TTS_COUNT - 1)) 个模型）"
'@

# 手动替换变量（避免 PowerShell 解析 bash 脚本）
$deployScript = $deployScript -replace 'DEVICE_USER', $DeviceUser
$deployScript = $deployScript -replace 'REMOTE_ZIP_PATH', $remoteZipPath
```

**关键技术点**:

1. **使用单引号 heredoc** `@'...'@`
   - 完全禁止 PowerShell 变量展开
   - Bash 脚本内容原样保留

2. **占位符替换**
   - 在 bash 脚本中使用 `DEVICE_USER` 和 `REMOTE_ZIP_PATH` 占位符
   - 创建字符串后，使用 PowerShell `-replace` 手动替换

3. **Bash 变量保持原样**
   - `$TTS_COUNT` 不再需要转义为 `\$TTS_COUNT`
   - `$(...)` 命令替换正常工作
   - `wc` 命令不会被 PowerShell 解析

## 🎓 技术要点总结

### PowerShell Heredoc 最佳实践

1. **嵌入 Bash 脚本时，必须使用单引号 heredoc**
   ```powershell
   # ✅ 正确
   $script = @'
   #!/bin/bash
   COUNT=$(wc -l file.txt)
   '@

   # ❌ 错误
   $script = @"
   #!/bin/bash
   COUNT=\$(wc -l file.txt)
   "@
   ```

2. **需要 PowerShell 变量时，使用占位符 + 替换**
   ```powershell
   $script = @'
   echo "User: PLACEHOLDER_USER"
   '@
   $script = $script -replace 'PLACEHOLDER_USER', $actualUser
   ```

3. **不要依赖 `\$` 转义**
   - 在 PowerShell heredoc 中，`\$` 转义**不可靠**
   - 使用单引号 heredoc 是唯一可靠方案

### 进度反馈设计原则

1. **长时间操作必须有反馈**
   - 复制大文件 → 显示文件名和进度
   - 网络传输 → 显示速度和剩余时间
   - 解压文件 → 显示当前文件名

2. **进度信息要具体**
   - ✅ `[3/7] vits-zh-aishell3...`
   - ❌ `正在处理...`

3. **给用户预期**
   - ✅ `提示：解压大文件可能需要 1-2 分钟，请耐心等待...`
   - ❌ 无提示，用户不知道要等多久

### 磁盘空间管理原则

1. **避免使用 /tmp 存储大文件**
   - `/tmp` 通常是小分区（几百 MB）
   - 适合小临时文件，不适合 GB 级文件

2. **使用用户主目录**
   - `/home/user/` 通常在主存储分区
   - 空间充足，适合大文件临时存储

3. **及时清理**
   - 使用完毕立即删除临时文件
   - 避免占用长期存储空间

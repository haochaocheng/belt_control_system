```cpp
void AudioManagementController::testTts(const QString &text)
{
    qDebug() << "🔊 [AudioMgmt] 测试TTS语音，文本:" << text;

    if (!m_tts) {
        qWarning() << "❌ [AudioMgmt] TTS引擎未设置";
        emit errorOccurred("TTS引擎未初始化");
        return;
    }

    // 使用Test场景的配置
    int modelIndex = m_config->modelIndex(TTSConfigManager::Test);
    int speakerId = m_config->speakerId(TTSConfigManager::Test);
    double rate = m_config->rate(TTSConfigManager::Test);
    double volume = m_config->volume(TTSConfigManager::Test);

    qDebug() << "  模型索引:" << modelIndex;
    qDebug() << "  说话人ID:" << speakerId;
    qDebug() << "  语速:" << rate;
    qDebug() << "  音量:" << volume;

    // 生成测试音频
    QString outputPath = "/tmp/tts_test.wav";
    bool success = m_tts->generateSpeech(text, outputPath, speakerId, rate);

    if (success) {
        qDebug() << "✅ [AudioMgmt] TTS测试音频生成成功:" << outputPath;
        emit errorOccurred("TTS测试音频已生成: " + outputPath);
    } else {
        qWarning() << "❌ [AudioMgmt] TTS测试音频生成失败";
        emit errorOccurred("TTS测试失败");
    }
}
```

## 🎓 技术要点

### 1. SpinBox editable 属性

**定义**:
```qml
SpinBox {
    editable: true  // 允许直接输入数字
}
```

**效果**:
- `editable: false`（默认）- 只能用箭头调整
- `editable: true` - 可以点击输入框直接输入数字

**使用场景**:
- 需要快速输入大范围数值
- 提高用户体验
- 减少点击次数

### 2. Q_INVOKABLE 方法调用

**C++ 声明**:
```cpp
Q_INVOKABLE void testTts(const QString &text);
```

**QML 调用**:
```qml
audioManagementController.testTts("测试文本")
```

**参数传递**:
- QString → JavaScript String
- int → JavaScript Number
- bool → JavaScript Boolean
- QVariantList → JavaScript Array

### 3. TTS 测试流程

**流程图**:
```
用户点击测试按钮
    ↓
QML 调用 testTts()
    ↓
读取 Test 场景配置
    ↓
调用 TTS 引擎生成音频
    ↓
保存到 /tmp/tts_test.wav
    ↓
发送 Toast 提示
```

**关键点**:
- 使用 Test 场景配置（不影响其他场景）
- 生成临时文件（/tmp/tts_test.wav）
- 通过 errorOccurred 信号显示 Toast

## 🔍 根本原因

### 问题 1: SpinBox 样式不一致

**原因**：
- Qt Quick Controls 2 的 SpinBox 默认样式因平台而异
- Windows 平台：可能显示 +- 按钮
- Linux 平台：显示上下箭头
- 当前代码只自定义了 `background` 和 `contentItem`，没有自定义 `up.indicator` 和 `down.indicator`

**Qt Quick Controls 2 SpinBox 结构**：
```qml
SpinBox {
    background: Rectangle { }      // 背景
    contentItem: TextInput { }     // 中间输入框
    up.indicator: Rectangle { }    // 上/右按钮（未自定义则使用平台默认）
    down.indicator: Rectangle { } // 下/左按钮（未自定义则使用平台默认）
}
```

### 问题 2: 路径硬编码

**原因**：
- 路径直接硬编码为 Windows 路径
- 没有根据运行平台动态选择路径
- Qt 提供 `Qt.platform.os` 可以检测平台

**平台检测**：
```qml
Qt.platform.os === "windows"  // Windows 平台
Qt.platform.os === "linux"    // Linux 平台（工控机）
```

## ✅ 修复方案

### 修复 1: 自定义 SpinBox 按钮样式

**文件**: `src/qml/pages/VoiceManagement.qml`

**修改位置**: Lines 215-252

**实现**：
```qml
SpinBox {
    id: speakerSpinBox
    // ... 其他属性 ...

    // ✅ 2026-01-23 16:05 [FIX 100.300.9] 自定义 +- 按钮样式（统一显示）
    up.indicator: Rectangle {
        x: speakerSpinBox.mirrored ? 0 : parent.width - width

            text: "+"
            font.pixelSize: 18
            font.bold: true
            color: "#ecf0f1"

    }

    down.indicator: Rectangle {
        x: speakerSpinBox.mirrored ? parent.width - width : 0
```

## 🎓 技术要点

### 1. Qt Quick Controls 2 SpinBox 完整自定义

**SpinBox 组件结构**：
```
┌─────────────────────────────────┐
│  down.indicator  │  contentItem  │  up.indicator  │
│      (-)         │   (数字输入)   │      (+)       │
└─────────────────────────────────┘
        ↑                                    ↑
    background (整体背景)
```

**自定义层级**：
1. **Level 1**: 只自定义 `background` - 改变整体背景
2. **Level 2**: 自定义 `contentItem` - 改变输入框样式
3. **Level 3**: 自定义 `up.indicator` 和 `down.indicator` - 完全控制按钮样式 ✅

### 2. Qt.platform.os 平台检测

**可用值**：
- `"windows"` - Windows 平台
- `"linux"` - Linux 平台
- `"osx"` - macOS 平台
- `"android"` - Android 平台
- `"ios"` - iOS 平台

**使用场景**：
- 平台相关的默认路径
- 平台相关的功能开关
- 平台相关的 UI 调整

### 3. QML 属性绑定

**动态属性**：
```qml
property string defaultAudioPath: {
    // JavaScript 表达式
    if (condition) {
        return value1
    } else {
        return value2
    }
}
```

**使用属性**：
```qml
TextField {
    text: root.defaultAudioPath  // 绑定到属性
}
```

**优点**：
- 集中管理配置
- 易于维护和修改
- 自动响应变化

### 4. SpinBox 按钮位置计算

**RTL (Right-to-Left) 支持**：
```qml
up.indicator: Rectangle {
    x: speakerSpinBox.mirrored ? 0 : parent.width - width
    // mirrored=false (LTR): 右侧
    // mirrored=true (RTL): 左侧
}

down.indicator: Rectangle {
    x: speakerSpinBox.mirrored ? parent.width - width : 0
    // mirrored=false (LTR): 左侧
    // mirrored=true (RTL): 右侧
}
```

## 🎯 技术要点

### CMake 子目录编译
```cmake
add_subdirectory(src/tts_service)
```

**作用**：
1. 进入 `src/tts_service/` 目录
2. 执行 `src/tts_service/CMakeLists.txt`
3. 编译 `sherpa_tts_service` 可执行文件
4. 安装到 `bin/` 目录

### 为什么之前没有发现？
1. **TTS 服务是独立进程**：不是主程序的一部分
2. **旧二进制文件存在**：Docker 镜像中有旧版本，能正常运行
3. **工作模型正常**：vits-zh-aishell3 等模型能正常工作，掩盖了问题
4. **只有 HuggingFace 模型崩溃**：问题只在特定模型上出现

### 教训
- **修改独立进程代码时**：必须确认该进程被编译系统包含
- **验证编译结果**：检查二进制文件的修改时间
- **调试日志不出现**：首先检查代码是否真的被编译

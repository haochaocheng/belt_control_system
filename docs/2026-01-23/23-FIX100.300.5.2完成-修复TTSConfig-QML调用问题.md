## 🔍 根本原因

### 问题 1: 函数未标记为 Q_INVOKABLE

**TTSConfigManager.h** 中的函数没有标记为 `Q_INVOKABLE`，导致 QML 无法调用：

```cpp
// ❌ 错误：QML 无法调用
int modelIndex(Scene scene) const;
QStringList modelNames() const;
```

**原因**：
- C++ 函数默认不暴露给 QML
- 需要 `Q_INVOKABLE` 宏标记才能被 QML 调用
- 或者使用 Q_PROPERTY 或 slots

### 问题 2: 枚举访问错误

**VoiceManagement.qml** 中使用了错误的枚举访问方式：

```qml
// ❌ 错误：TTSConfigManager 是类名，不是 QML 单例名
currentIndex: TTSConfig.modelIndex(TTSConfigManager.Test)
```

**原因**：
- 单例在 QML 中注册为 `TTSConfig`（不是 `TTSConfigManager`）
- 枚举应该通过单例实例访问：`TTSConfig.Test`
- 不能使用类名 `TTSConfigManager.Test`

## 🎓 技术要点

### 1. Q_INVOKABLE 宏的作用

**定义**：
```cpp
Q_INVOKABLE ReturnType functionName(Args...);
```

**作用**：
- 标记 C++ 函数可被 QML 调用
- 自动生成元对象信息
- 支持参数和返回值的自动转换

**使用场景**：
- QML 需要调用的 C++ 函数
- 不需要信号通知的函数
- 不需要属性绑定的函数

**替代方案**：
1. **Q_PROPERTY** - 用于属性绑定
2. **public slots** - 用于信号槽机制
3. **Q_INVOKABLE** - 用于普通函数调用

### 2. QML 单例枚举访问

**注册代码**（main.cpp:188）：
```cpp
qmlRegisterSingletonType<TTSConfigManager>(
    "com.belt.control", 1, 0, "TTSConfig",
    [](QQmlEngine *engine, QJSEngine *scriptEngine) -> QObject * {
        Q_UNUSED(engine)
        Q_UNUSED(scriptEngine)
        return TTSConfigManager::instance();
    }
);
```

**QML 访问规则**：
```qml
// ✅ 正确：使用单例名称
TTSConfig.Test           // 访问枚举
TTSConfig.modelNames()   // 调用函数

// ❌ 错误：使用类名
TTSConfigManager.Test    // ReferenceError
```

**关键点**：
- 单例名称 = 注册时的第 4 个参数（`"TTSConfig"`）
- 枚举通过单例实例访问，不是类名
- 类名 `TTSConfigManager` 在 QML 中不可见

### 3. Q_ENUM 宏的作用

**定义**（TTSConfigManager.h:30）：
```cpp
enum Scene {
    StartupWarning = 0,
    FaultAlarm = 1,
    Test = 2
};
Q_ENUM(Scene)
```

**作用**：
- 将枚举暴露给 Qt 元对象系统
- 允许 QML 访问枚举值
- 支持枚举与字符串的转换

**QML 访问**：
```qml
// 通过单例实例访问
TTSConfig.Test           // 值为 2
TTSConfig.StartupWarning // 值为 0
TTSConfig.FaultAlarm     // 值为 1
```

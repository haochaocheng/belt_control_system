## 🔌 后端集成架构

### 数据流向

```
┌─────────────────────────────────────────────────────────────┐
│                         QML 前端                             │
├─────────────────────────────────────────────────────────────┤
│  VoiceManagement.qml                                        │
│  ├─ TTSConfigSection.qml → TTSConfig (单例)                 │
│  ├─ 扫描按钮 → audioManagementController.scanDirectory()    │
│  ├─ 批量识别 → audioManagementController.recognizeAll()     │
│  ├─ 批量生成 → audioManagementController.generateAllTts()   │
│  └─ 进度显示 ← audioManagementController.progress           │
└─────────────────────────────────────────────────────────────┘
                              ↕
┌─────────────────────────────────────────────────────────────┐
│                        C++ 后端                              │
├─────────────────────────────────────────────────────────────┤
│  AudioManagementController                                  │
│  ├─ scanDirectory()      → 扫描音频文件                     │
│  ├─ recognizeAll()       → 批量识别（STT）                  │
│  ├─ generateAllTts()     → 批量生成（TTS）                  │
│  ├─ stopProcessing()     → 停止处理                         │
│  └─ Q_PROPERTY 信号      → 更新 QML UI                      │
│                                                              │
│  TTSConfigManager (单例)                                    │
│  ├─ setModelIndex()      → 设置模型                         │
│  ├─ setSpeakerId()       → 设置说话人                       │
│  ├─ setRate()            → 设置语速                         │
│  └─ setVolume()          → 设置音量                         │
│                                                              │
│  SherpaOnnxTTS (通过 CommonControl)                         │
│  ├─ synthesizeToFile()   → 生成 TTS 文件                    │
│  └─ switchModel()        → 切换模型                         │
└─────────────────────────────────────────────────────────────┘
```

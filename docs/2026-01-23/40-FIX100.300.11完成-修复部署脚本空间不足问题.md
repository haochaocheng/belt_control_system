## 🎓 技术要点

### 1. Linux 临时目录空间问题

**常见临时目录**：
- `/tmp` - 通常是 tmpfs（内存文件系统），空间有限
- `/var/tmp` - 磁盘文件系统，但可能也较小
- `/home` - 用户主目录，通常空间最大

**空间对比**（典型配置）：
```bash
/tmp        500MB - 2GB   (tmpfs)
/var/tmp    1GB - 5GB     (磁盘)
/home       10GB - 100GB+ (磁盘)
```

### 2. 为什么使用 /home 目录

**优点**：
- ✅ 空间充足（通常几十 GB）
- ✅ 持久化存储（不会重启丢失）
- ✅ 用户有完整权限

**缺点**：
- ⚠️ 需要手动清理（不像 /tmp 自动清理）
- ⚠️ 可能影响用户配额（如果有限制）

**解决方案**：
- 脚本在部署完成后自动删除临时文件
- 使用 `rm -rf $EXTRACT_DIR` 清理解压目录
- 使用 `rm -f REMOTE_ZIP_PATH` 清理上传的 zip 文件

### 3. 变量替换机制

**PowerShell Heredoc**：
```powershell
# 使用单引号 heredoc（不展开变量）
$deployScript = @'
EXTRACT_DIR="/home/DEVICE_USER/resources-extract"
'@

# 手动替换变量
$deployScript = $deployScript -replace 'DEVICE_USER', $DeviceUser
```

**为什么不用双引号 heredoc**：
- `@"..."@` 会被 PowerShell 解析，展开 `$变量`
- Bash 脚本中的 `$EXTRACT_DIR` 会被误解析
- 使用单引号 `@'...'@` 避免 PowerShell 解析

### 4. 用户名动态替换

**问题**：用户名不总是 "pi"，可能是 "linaro" 或其他

**解决方案**：
```powershell
# 脚本参数
param(
    [string]$DeviceIP,
    [string]$DeviceUser = "pi"  # 默认 pi，可覆盖
)

# Bash 脚本中使用占位符
EXTRACT_DIR="/home/DEVICE_USER/resources-extract"

# PowerShell 替换
$deployScript = $deployScript -replace 'DEVICE_USER', $DeviceUser
```

**效果**：
- `linaro@192.168.10.188` → `/home/linaro/resources-extract`
- `pi@192.168.1.8` → `/home/pi/resources-extract`

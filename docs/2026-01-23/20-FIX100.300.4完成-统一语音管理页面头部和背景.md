## 🔍 前5个页面的标准模式

### 标准结构（以 ControlPanel.qml 为例）

```qml
import "../Input1/Input1Content"  // 导入 Back 和 Head 组件

Item {
    id: root
    width: 1920   // 默认宽度（设计尺寸 1920x1080）
    height: 1080  // 默认高度（设计尺寸 1920x1080）

    property int currentPageIndex: 0  // 接收当前页面索引

    // 1. 使用 Back 组件作为背景
    Back {
        anchors.fill: parent
        z: 0  // 确保在最底层
        enabled: false  // 不接收鼠标事件，只作为视觉背景
    }

    // 2. 使用 Head 组件作为头部（包装在 headerContainer 中处理缩放）
    Item {
        id: headerContainer
        anchors.top: parent.top
        anchors.left: parent.left
        width: 1920
        height: 80
        clip: true

        transform: Scale {
            property real scaleFactor: root.width / 1920
            xScale: scaleFactor
            yScale: scaleFactor
            origin.x: 0
            origin.y: 0
        }

        Head {
            id: header
            width: 1920
            height: 80
            currentPageIndex: root.currentPageIndex
        }
    }

    // 3. 主内容区域从 headerContainer.bottom 开始
    // ...
}
```

### 关键要点

1. **根元素**: `Item`（不是 `Rectangle`）
2. **背景**: `Back` 组件（来自 `Input1/Input1Content`）
3. **头部**: `Head` 组件（来自 `Input1/Input1Content`），有缩放处理
4. **属性**: `currentPageIndex` 属性（接收当前页面索引）
5. **尺寸**: 默认 1920x1080（设计尺寸）

## 🎓 经验教训

### 1. QML 页面标准化的重要性

**问题**：
- 创建新页面时，使用了自定义样式
- 与现有页面的样式不一致
- 用户体验不统一

**教训**：
- 创建新页面时，**先查看现有页面的模式**
- 遵循现有的组件和样式标准
- 保持应用的视觉一致性

### 2. 组件复用

**正确做法**：
```qml
// ✅ 使用现有的 Back 和 Head 组件
import "../Input1/Input1Content"

Back { anchors.fill: parent }
Head { currentPageIndex: root.currentPageIndex }
```

**错误做法**：
```qml
// ❌ 自定义头部和背景
Rectangle {
    color: "#1a1a1a"  // 自定义背景色

    Rectangle {
        id: header
        color: "#2c3e50"  // 自定义头部
        Text { text: "🎵 语音管理" }  // 自定义标题
    }
}
```

### 3. 页面属性的一致性

所有页面都应该有：
- ✅ `property int currentPageIndex: 0`（接收当前页面索引）
- ✅ 默认尺寸（`width: 1920, height: 1080`）
- ✅ 使用 `Item` 作为根元素（不是 `Rectangle`）

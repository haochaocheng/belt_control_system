### 问题根源

**错误流程**：
```
1. 第一个模型测试成功 → TTS 服务进程运行中（PID: 37）
2. 用户切换模型 → 调用 switchModel()
3. switchModel() 调用 stop() → 只停止播放器，进程仍在运行
4. switchModel() 调用 initialize() → 尝试启动新进程
5. QProcess::start() 失败 → "Process is already running"
6. 代码继续发送 init 命令 → 旧进程收到命令
7. 旧进程尝试加载新模型 → 崩溃（可能是内存问题或模型不兼容）
```

**为什么会崩溃？**
- TTS 服务进程已经加载了第一个模型
- 收到 init 命令后尝试加载第二个模型
- 可能是内存未释放、资源冲突或模型格式不兼容
- 导致进程崩溃

## ✅ 修复方案

### 修复：正确停止 TTS 服务进程

**文件**: `src/control/SherpaOnnxTTS.cpp`

**修改位置**: Lines 631-686

**修改前**：
```cpp
bool SherpaOnnxTTS::switchModel(const QString &modelDir)
{
    // 停止当前TTS服务
    if (m_ttsProcess->state() != QProcess::NotRunning) {
        stop();  // ❌ 只停止播放
        QThread::msleep(500);
    }

    // 重新初始化
    bool success = initialize(modelDir);
    return success;
}
```

**修改后**：
```cpp
bool SherpaOnnxTTS::switchModel(const QString &modelDir)
{
    // ✅ 正确停止 TTS 服务进程
    if (m_ttsProcess->state() != QProcess::NotRunning) {
        // 停止播放
        stop();

        // 停止 TTS 服务进程
        qDebug() << "   停止 TTS 服务进程...";

        // 发送停止命令
        QJsonObject stopCmd;
        stopCmd["command"] = "stop";
        QJsonDocument doc(stopCmd);
        QByteArray jsonData = doc.toJson(QJsonDocument::Compact);
        jsonData.append('\n');

        m_ttsProcess->write(jsonData);
        m_ttsProcess->waitForBytesWritten(1000);

        // 等待进程自然退出
        if (!m_ttsProcess->waitForFinished(2000)) {
            qWarning() << "   ⚠️  TTS服务进程未正常退出，强制终止";
            m_ttsProcess->terminate();  // 先尝试温和终止

            if (!m_ttsProcess->waitForFinished(1000)) {
                m_ttsProcess->kill();  // 强制杀死
            }
        }

        qDebug() << "   ✅ TTS 服务进程已停止";
    }

    // 重新初始化
    bool success = initialize(modelDir);
    return success;
}
```

**关键改进**：
1. **发送停止命令**：`{"command":"stop"}` 让 TTS 服务优雅退出
2. **等待进程退出**：`waitForFinished(2000)` 等待最多 2 秒
3. **温和终止**：如果未退出，先 `terminate()`
4. **强制杀死**：如果还未退出，最后 `kill()`
5. **确保进程停止**：再调用 `initialize()` 启动新进程

## 🎓 技术要点

### 1. QProcess 生命周期管理

**正确的停止流程**：
```cpp
// 1. 发送停止命令（让进程优雅退出）
process->write(stopCommand);
process->waitForBytesWritten(1000);

// 2. 等待进程自然退出
if (!process->waitForFinished(2000)) {
    // 3. 温和终止（SIGTERM）
    process->terminate();

    if (!process->waitForFinished(1000)) {
        // 4. 强制杀死（SIGKILL）
        process->kill();
    }
}
```

**为什么需要这个流程？**
- 优雅退出：让进程有机会清理资源
- 温和终止：给进程时间响应 SIGTERM
- 强制杀死：确保进程一定停止

### 2. stop() vs 停止进程

**stop() 的职责**：
- 停止当前播放
- 重置状态为 Ready
- **不负责**停止 TTS 服务进程

**停止进程的职责**：
- 发送停止命令
- 等待进程退出
- 必要时强制终止

**为什么分开？**
- stop() 是用户操作（停止播放）
- 停止进程是内部操作（切换模型、析构）
- 职责分离，避免混淆

### 3. 进程状态检查

**QProcess 状态**：
- `NotRunning` - 进程未运行
- `Starting` - 进程正在启动
- `Running` - 进程正在运行

**检查方法**：
```cpp
if (m_ttsProcess->state() != QProcess::NotRunning) {
    // 进程正在运行或启动中
}
```

### 4. 为什么旧进程会崩溃？

**可能的原因**：
1. **内存未释放**：第一个模型占用的内存未释放
2. **资源冲突**：两个模型共享某些资源
3. **模型不兼容**：TTS 服务不支持运行时切换模型
4. **状态错误**：进程状态机错误

**正确做法**：
- 停止旧进程
- 释放所有资源
- 启动新进程
- 加载新模型

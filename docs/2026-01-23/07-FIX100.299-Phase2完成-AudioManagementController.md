### 创建 AudioManagementController 类

**文件**:

**核心功能**:

#### 1. 音频文件管理
```cpp
// 扫描音频文件
Q_INVOKABLE void scanDirectory(const QString &dirPath);

// 获取文件列表
Q_INVOKABLE QVariantList getFileList() const;

// 清除文件列表
Q_INVOKABLE void clearFileList();
```

**支持格式**: `.wav`, `.mp3`, `.ogg`, `.flac`

#### 2. STT识别管理
```cpp
// 识别单个文件
Q_INVOKABLE void recognizeFile(int index);

// 批量识别
Q_INVOKABLE void recognizeAll();
```

**当前实现**: 占位实现（使用文件名作为识别文本）
**待实施**: 集成Sherpa-ONNX ASR引擎

#### 3. TTS生成管理
```cpp
// 生成单个TTS
Q_INVOKABLE void generateTts(int index, const QString &text);

// 批量生成TTS
Q_INVOKABLE void generateAllTts();
```

**功能**:
- 调用SherpaOnnxTTS引擎合成语音
- 自动创建输出目录 (`generated_tts/`)
- 保存生成的音频文件

#### 4. 进度管理
```cpp
Q_PROPERTY(int totalFiles READ totalFiles NOTIFY totalFilesChanged)
Q_PROPERTY(int processedFiles READ processedFiles NOTIFY processedFilesChanged)
Q_PROPERTY(int progress READ progress NOTIFY progressChanged)
Q_PROPERTY(QString currentFile READ currentFile NOTIFY currentFileChanged)
Q_PROPERTY(bool isProcessing READ isProcessing NOTIFY isProcessingChanged)
```

**功能**:
- 实时进度跟踪
- 当前处理文件显示
- 处理状态管理

#### 5. 批量处理控制
```cpp
// 停止处理
Q_INVOKABLE void stopProcessing();
```

**功能**:
- 用户可随时停止批量处理
- 自动清理状态

## 📊 数据结构

### AudioFileInfo 结构
```cpp
struct AudioFileInfo {
    QString filePath;           // 文件路径
    QString fileName;           // 文件名
    QString recognizedText;     // 识别的文本
    QString generatedPath;      // 生成的TTS文件路径
    enum Status {
        Pending,                // 待处理
        Recognizing,            // 识别中
        Recognized,             // 已识别
        Generating,             // 生成中
        Generated,              // 已生成
        Failed                  // 失败
    };
    Status status;
    QString errorMessage;       // 错误信息
};
```

## 🔔 信号机制

```cpp
void fileListUpdated();                 // 文件列表更新
```

### 进度信号

```cpp
void processedFilesChanged();           // 已处理文件数变化
```

## 🔧 工作流程

### 1. 扫描音频文件
```cpp
controller->scanDirectory("E:/2025/3_gongkongji/belt_control_system/AUDIO/1#PD");
// → 扫描目录
// → 添加到文件列表
// → 发送 fileListUpdated 信号
```

### 2. 批量识别
```cpp
controller->recognizeAll();
// → 设置处理模式为 RecognizeAll
// → 逐个识别文件
// → 更新进度
// → 发送 recognitionCompleted 信号
// → 完成后发送 processingFinished 信号
```

### 3. 批量生成TTS
```cpp
controller->generateAllTts();
// → 设置处理模式为 GenerateAll
// → 逐个生成TTS
// → 更新进度
// → 发送 generationCompleted 信号
// → 完成后发送 processingFinished 信号
```

## 🎯 QML集成

### Q_PROPERTY 绑定
```qml
// QML中可以直接绑定属性
Text {
    text: "总文件数: " + audioController.totalFiles
}

ProgressBar {
    value: audioController.progress / 100
}

Text {
    text: "当前文件: " + audioController.currentFile

}
```

### Q_INVOKABLE 调用
```qml
Button {
    text: "扫描目录"
    onClicked: audioController.scanDirectory(dirPathInput.text)
}

Button {
    text: "批量识别"
    onClicked: audioController.recognizeAll()
}

Button {
    text: "批量生成"
    onClicked: audioController.generateAllTts()
}
```

### 信号连接
```qml
Connections {
    target: audioController

    function onFileListUpdated() {
        fileListModel.clear()
        var files = audioController.getFileList()
        for (var i = 0; i < files.length; i++) {
            fileListModel.append(files[i])
        }
    }

    function onProgressChanged() {
        progressBar.value = audioController.progress / 100
    }

    function onErrorOccurred(message) {
        errorDialog.text = message
        errorDialog.open()
    }
}
```

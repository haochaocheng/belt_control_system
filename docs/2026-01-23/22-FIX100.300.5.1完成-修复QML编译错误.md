
**原因分析**：

2. 内层双引号使用 `\"` 转义
3. qmlcachegen 编译器在解析转义字符时出现语法错误
4. 在第 46 列（第二个 `\"` 附近）期望找到逗号

**修复后代码**（Line 580）：
```qml
text: '暂无文件\n请点击"扫描"按钮扫描音频文件'
```

**修复要点**：
1. ✅ 改用单引号作为外层字符串
2. ✅ 内层双引号无需转义
3. ✅ `\n` 作为换行符（不是 `\\n`）
4. ✅ 符合 QML 字符串字面量语法规范

## 📝 技术说明

### QML 字符串字面量规则

**双引号字符串**：
```qml
// ❌ 错误：需要转义内层双引号
text: "点击\"按钮\""

// ✅ 正确：使用单引号避免转义
text: '点击"按钮"'
```

**转义字符**：
- `\n` - 换行符
- `\t` - 制表符
- `\\` - 反斜杠
- `\"` - 双引号（仅在双引号字符串内需要）
- `\'` - 单引号（仅在单引号字符串内需要）

**最佳实践**：
- 字符串包含双引号 → 使用单引号作为外层
- 字符串包含单引号 → 使用双引号作为外层
- 避免过度转义，提高可读性

## 🎓 经验教训

### 1. QML 字符串最佳实践

**规则**：
- 包含双引号 → 用单引号
- 包含单引号 → 用双引号
- 避免过度转义

### 2. 转义字符注意事项

**常见错误**：
```qml
// ❌ 错误：双重转义
text: "第一行\\n第二行"  // 显示：第一行\n第二行

// ✅ 正确：单次转义
text: "第一行\n第二行"   // 显示：第一行（换行）第二行
```

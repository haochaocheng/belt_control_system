## 🎯 技术要点

### 为什么使用 stderr 而不是 stdout？
- **stdout**：用于 JSON 响应（Qt 进程通信）
- **stderr**：用于调试日志（不干扰 JSON 解析）
- **flush()**：确保日志立即输出，即使进程崩溃

### 为什么每行都 flush()？
- 进程崩溃时，缓冲区可能丢失
- 立即刷新确保崩溃前的日志都能看到
- 性能影响可忽略（调试代码）

### Linux 目录遍历 API
```cpp
DIR* dir = opendir(path);           // 打开目录
struct dirent* entry;                // 目录项
while ((entry = readdir(dir)) != nullptr) {  // 遍历
    entry->d_name;                   // 文件名
}
closedir(dir);                       // 关闭目录
```

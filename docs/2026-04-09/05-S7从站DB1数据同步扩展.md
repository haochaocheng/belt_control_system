# S7从站DB1数据同步扩展——与Modbus输入寄存器完全对齐

## 日期
2026-04-09

## 问题描述
S7从站DB1状态区数据全部为0，使用Snap7 Client Demo读取DB1时看到的值全是零。

**根因**：两个问题叠加
1. `onSyncTimer()`中检查S7用`property("isConnected")`，但`S7ServerController`只有`isRunning`属性，导致`syncS7DB1()`从未被调用
2. 即使修复属性名，`syncS7DB1()`只覆盖Byte 0-139（基本状态），缺少环境模拟量、电机1-2扩展Tab、电机3-8完整数据块——这些数据在Modbus`syncInputRegisters()`中已有

## 修复方案

### 1. 修复同步定时器（上一次提交已完成）
`onSyncTimer()`中：`property("isConnected")` → `isRunning()`

### 2. 扩展DB1数据区（本次修改）

| 区域 | 字节范围 | 内容 | 对应Modbus IR |
|------|---------|------|--------------|
| 基本数据 | 0-139 | DO/DI/AI/电机1-2基本/绕组/沿线保护 | IR 0-61 |
| 环境模拟量 | 140-203 | 16个FLOAT32（温度/湿度/甲烷等）| IR 62-93 |
| 电机1-2扩展 | 204-251 | 12个FLOAT32（前后轴承/堵转/功率等）| IR 94-117 |
| 电机3-8数据 | 252-587 | 6×14个FLOAT32（完整Tab值）| IR 120-287 |

### 3. DB1大小扩展
`S7_DB1_SIZE`: 256 → **640** 字节（588字节实际使用，预留空间）

### 4. 新增头文件常量
```cpp
static constexpr int S7_DB1_ENV_START = 140;          // 16个环境FLOAT32
static constexpr int S7_DB1_MOTOR12_EXT_START = 204;  // 电机1-2扩展Tab
static constexpr int S7_DB1_MOTOR_BLOCK_START = 252;  // 电机3-8完整数据块
static constexpr int S7_DB1_MOTOR_BLOCK_SIZE = 56;    // 每电机56字节
```

## 修改文件

| 文件 | 修改内容 |
|------|---------|
| `src/control/TCPDataAdapter.h` | S7_DB1_SIZE 256→640，新增4个DB1偏移常量 |
| `src/control/TCPDataAdapter.cpp` | syncS7DB1()扩展：环境值+电机1-2扩展+电机3-8数据块 |
| `src/control/TCPDataAdapter.cpp` | getS7DB1Map()扩展：新增环境/电机映射表条目，getDBData读取640字节 |
| `docs/2026-04-09/03-Snap7-Client-Demo读写测试指南.md` | DB1读取Amount 140→640，新增扩展区字节偏移表 |

## 验证方法
1. Snap7 Client Demo → Area: DB, DB#: 1, Start: 0, Amount: 640, WordLen: Byte → Read
2. 确认Byte 140+有环境数据（温度、湿度等非零值）
3. 确认Byte 252+有电机3-8数据
4. 设备QML映射表查看S7 DB1，确认新增条目显示正确值

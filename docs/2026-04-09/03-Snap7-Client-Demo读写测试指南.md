# Snap7 Client Demo 读写测试指南

## 日期
2026-04-09

## 连接配置

在 Snap7 Client Demo 中：
- **IP**: `192.168.10.151`
- **Rack**: `0`
- **Slot**: `2`（如截图所示）
- 点击 **Connect** 按钮

> 注意：设备上的S7从站端口默认是102，Snap7 Client Demo默认也是102，无需修改。

## 读取DB1（状态区，只读）

1. 切换到 **"Data read/write"** 标签页
2. 选择：
   - Area: **DB**
   - DB Number: **1**
   - Start: **0**
   - Amount: **140**（字节）
   - Word Len: **Byte**
3. 点击 **Read** 按钮

2. 选择：

   - Start: **0**

   - Word Len: **Byte**

## 常用测试操作

### 测试1：读取所有状态
```
Area: DB, DB#: 1, Start: 0, Amount: 140, WordLen: Byte → Read
```
看到的前几个字节代表DO状态、DI状态等。

### 测试2：控制DO输出
```
Area: DB, DB#: 2, Start: 0, Amount: 1, WordLen: Byte
数据: 0x01 → Write
```
这会打开DO1输出。0x03打开DO1+DO2，0xFF打开全部8路。

### 测试3：启动皮带
```
Area: DB, DB#: 2, Start: 1, Amount: 1, WordLen: Byte
数据: 0x01 → Write
```
bit0=1 启动皮带（需要集控模式）。

### 测试4：紧急停车
```
Area: DB, DB#: 2, Start: 1, Amount: 1, WordLen: Byte
数据: 0x04 → Write
```
bit2=1 紧急停车（始终允许）。

### 测试5：启动电机1
```
Area: DB, DB#: 2, Start: 6, Amount: 1, WordLen: Byte
数据: 0x01 → Write
```
bit0=1 启动电机1（需要集控模式）。

### 测试6：心跳写入（验证连接）
```
Area: DB, DB#: 2, Start: 4, Amount: 2, WordLen: Byte
数据: 0x00 0x01 → Write
```
写心跳值1，在设备映射表中可看到心跳值变化。

### 测试7：使用 "Block - DB Get/Fill" 标签页
1. 切换到 **"Block - DB Get/Fill"** 标签页
2. **DB Get**: DB#=1, 点击 DB Get → 下载整个DB1数据块查看
3. **DB Fill**: DB#=2, Fill Char=0x00, 点击 DB Fill → 清零DB2所有数据

## 注意事项
- DB1是只读的（设备向上位机报告状态），写入DB1不会产生效果
- DB2是控制区，写入会触发设备执行对应命令
- 皮带启动/停止/电机控制需要设备处于**集控模式**（工作模式=2）
- 紧急停车始终允许，不受模式限制
- 线圈类命令使用上升沿检测，50ms后自动清零

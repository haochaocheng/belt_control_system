**设计类型**: 功能设计

## 📋 需求分析

### 目标
1. 建立保护名称到音频文件路径的映射关系
2. 支持批量合成和实时合成的路径统一
3. 实现文件不存在时的实时合成回退机制

### 输入参数
- 设备号（1-8）
- 保护类型（开关量/模拟量/电机/张紧等）
- 保护名称（急停/跑偏/超速等）
- 点位号（1-64，仅沿线保护）
- 电机号/制动器号（1-4，仅电机/制动器保护）

### 输出
- 音频文件完整路径
- TTS 文本（用于实时合成）

## 🔧 设计方案

### 1. 路径规则定义

#### 1.1 开关量保护
```
格式: AUDIO/protection/switch/{设备号}号皮带{保护名称}保护.wav
示例: AUDIO/protection/switch/1号皮带沿线急停保护.wav
```

#### 1.2 模拟量保护
```
格式: AUDIO/protection/analog/{设备号}号皮带{保护名称}保护.wav
示例: AUDIO/protection/analog/1号皮带速度超速保护.wav
```

#### 1.3 电机保护
```
格式: AUDIO/protection/motor/{设备号}号皮带{电机号}号电机{保护名称}保护.wav
示例: AUDIO/protection/motor/1号皮带1号电机电流过载保护.wav
```

#### 1.4 张紧保护
```
格式: AUDIO/protection/tension/{设备号}号皮带{张紧号}号张紧装置{保护名称}保护.wav
示例: AUDIO/protection/tension/1号皮带1号张紧装置张紧力过大保护.wav
```

#### 1.5 沿线点位保护
```
格式: AUDIO/protection/line/{设备号}号皮带{点位号}号沿线{保护名称}保护.wav
示例: AUDIO/protection/line/1号皮带32号沿线急停保护.wav
```

### 2. 类设计

#### 2.1 AudioPathMapper 类

```cpp
// src/control/AudioPathMapper.h
#ifndef AUDIOPATHMAPPER_H
#define AUDIOPATHMAPPER_H

#include <QString>
#include <QMap>

class AudioPathMapper
{
public:
    // 保护类型枚举
    enum ProtectionType {
        SwitchProtection,    // 开关量保护
        AnalogProtection,    // 模拟量保护
        MotorProtection,     // 电机保护
        TensionProtection,   // 张紧保护
        LineProtection       // 沿线点位保护
    };

    // 获取音频文件路径
    static QString getAudioPath(
        int deviceId,                    // 设备号 1-8
        ProtectionType type,             // 保护类型
        const QString &protectionName,   // 保护名称
        int subIndex = 0                 // 子索引（电机号/点位号）
    );

    // 获取 TTS 文本
    static QString getTtsText(
        int deviceId,
        ProtectionType type,
        const QString &protectionName,
        int subIndex = 0
    );

    // 检查音频文件是否存在
    static bool audioFileExists(const QString &path);

    // 设置音频基础路径
    static void setAudioBasePath(const QString &path);

private:
    static QString m_audioBasePath;
};

#endif // AUDIOPATHMAPPER_H
```

#### 2.2 实现核心逻辑

```cpp
QString AudioPathMapper::getAudioPath(
    int deviceId,
    ProtectionType type,
    const QString &protectionName,
    int subIndex)
{
    QString subDir;
    QString fileName;

    switch (type) {
    case SwitchProtection:
        subDir = "protection/switch";
        fileName = QString("%1号皮带%2保护.wav").arg(deviceId).arg(protectionName);
        break;

    case AnalogProtection:
        subDir = "protection/analog";
        fileName = QString("%1号皮带%2保护.wav").arg(deviceId).arg(protectionName);
        break;

    case MotorProtection:
        subDir = "protection/motor";
        fileName = QString("%1号皮带%2号电机%3保护.wav")
                    .arg(deviceId).arg(subIndex).arg(protectionName);
        break;

    case TensionProtection:
        subDir = "protection/tension";
        fileName = QString("%1号皮带%2号张紧装置%3保护.wav")
                    .arg(deviceId).arg(subIndex).arg(protectionName);
        break;

    case LineProtection:
        subDir = "protection/line";
        fileName = QString("%1号皮带%2号沿线%3保护.wav")
                    .arg(deviceId).arg(subIndex).arg(protectionName);
        break;
    }

    return QString("%1/%2/%3").arg(m_audioBasePath).arg(subDir).arg(fileName);
}
```

### 3. 集成到 AlarmPlaybackService

```cpp
void AlarmPlaybackService::onAlarmTriggered(...)
{
    // 1. 检查预生成的音频文件是否存在
    if (!audioFile.isEmpty() && QFile::exists(audioFile)) {
        playAudioFile(audioFile);
        return;
    }

    // 2. 音频文件不存在，实时合成并缓存
    if (!ttsText.isEmpty()) {
        QString generatedFile = synthesizeAndCache(ttsText, audioFile);
        if (!generatedFile.isEmpty()) {
            playAudioFile(generatedFile);
        }
    }
}

QString AlarmPlaybackService::synthesizeAndCache(
    const QString &ttsText,
    const QString &targetPath)
{
    // 确保目录存在
    QDir().mkpath(QFileInfo(targetPath).absolutePath());

    // 调用 TTS 引擎合成
    TTSParameters params;
    params.speakerId = 21;

    if (m_ttsEngine->synthesize(ttsText, targetPath, params)) {
        return targetPath;  // 合成成功，返回路径
    }
    return QString();  // 合成失败
}
```

## 🔄 工作流程

```
保护触发
    ↓
ProtectionMonitorService.triggerProtection()
    ↓
AudioPathMapper.getAudioPath() → 获取音频路径
AudioPathMapper.getTtsText()   → 获取TTS文本
    ↓
emit alarmTriggered(protectionName, ttsText, audioFile, ...)
    ↓
AlarmPlaybackService.onAlarmTriggered()
    ↓
文件存在? → 是 → playAudioFile()
    ↓ 否
synthesizeAndCache() → 实时合成并保存
    ↓
playAudioFile()
```

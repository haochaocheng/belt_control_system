# Phase 7.48.84 - 添加独立控制模式与设备权限重构

## 修改时间
2026-03-23 01:35 (北京时间)

## 问题描述
1. 打开非本机设备（如2号皮带）时显示"只读模式：当前设备不是本机参数，无法修改参数"
2. 初始默认角色为"主站"不合理 — 设备初始应该是独立控制模式，不连锁任何设备
3. 每个设备都应该有独立的参数配置，不受角色限制

## 使用场景分析

### 物理实体说明
- 本机只有一套输入接口模块和输出接口模块，物理上只能控制一条皮带
- 下位机只有输入和输出，没有逻辑控制和存储，逻辑控制由主站设备执行
- 分站是完整独立设备，有自己的参数存储和逻辑控制

### 三种角色模式

| 角色 | 说明 | 参数权限 |
|------|------|---------|
| **独立控制**（默认） | 初始模式，每个设备独立配置，不连锁 | 可修改所有1-8号设备参数 |
| **主站** | 集控模式，控制1-8号皮带按序启动 | 可修改所有1-8号设备参数（下位机参数存本地） |
| **分站** | 被主站控制，只管理本机设备 | 只能修改本机设备参数 |

### 下位机与分站的区别
- **下位机**：无逻辑控制，无存储，只有I/O。参数存在主站本地数据库，主站执行逻辑后发送控制指令
- **分站**：完整设备，有自己的逻辑控制和参数存储。主站只发送少量信号（启动/停止/模式切换等）

## 修改内容

### 1. DeviceRoleManager.cpp

**默认角色**：
- 旧：`m_stationRole("master")` — 默认主站
- 新：`m_stationRole("standalone")` — 默认独立控制

**角色验证**：
- 旧：`setStationRole()` 只接受 "master" / "sub"
- 新：接受 "standalone" / "master" / "sub" 三种

**权限逻辑 `hasPermission()`**：
- 旧：`return isLocalDevice(deviceId)` — 只有本机设备可编辑
- 新：standalone 和 master 可修改所有1-8号，sub 只能修改本机

**角色名称 `stationName()`**：
- 新增 "standalone" → "独立控制"

**配置加载 `loadFromConfig()`**：
- 支持加载 "standalone" 角色

### 2. BasicConfigPage.qml

**本机角色下拉**：
- 旧：["主站", "分站"]，默认主站
- 新：["独立控制", "主站", "分站"]，默认独立控制

**角色映射**：
- 索引0="standalone", 1="master", 2="sub"

**初始化回显**：
- `Component.onCompleted` 中根据 `deviceRoleManager.stationRole` 回显下拉框

**说明文字**：
- 新："独立控制/主站模式可修改所有设备参数，分站模式只能修改本机设备参数"

### 3. DeviceSettingsDialog.qml

**只读横幅提示**：
- 旧："只读模式：当前设备不是本机，无法修改参数"
- 新："只读模式：当前为分站模式，只能修改本机设备参数"

**日志输出**：
- 更新为显示角色信息和本机设备ID

## 旧设备兼容性
- 旧配置文件 `device_role.json` 中存储的 "master" 角色仍可正常加载
- master 和 standalone 权限一致（都可修改所有1-8号），不影响功能
- 用户可在界面手动切换到"独立控制"

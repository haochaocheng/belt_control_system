# Phase 7.48.85.1 - 保护触发停车统一跳过停车预警音频

## 修改时间
2026-03-23 (北京时间)

## 问题描述
保护触发停车时，保护报警语音和停车预警语音会重叠播放：

1. **报警语音**：保护触发后由 AlarmPlaybackService 播放（如"1号皮带温度一超上限"）
2. **停车预警**：stopBelt() 中播放停车预警音频（如"1号皮带即将停车"）
3. **冲突原因**：两者共用同一个 QMediaPlayer 实例，同时播放导致未定义行为

## 实际使用场景分析
- **保护触发停车**：报警语音已经提醒了操作员，不需要再播放停车预警
- **手动S键停车**：没有报警语音，需要播放停车预警提醒操作员
- **远程停止命令**：同手动停车，需要播放停车预警

## 修改方案
将 protection_level=1（正常停车）的调用从 `stopBelt()` 改为 `emergencyStopBelt()`，使保护触发的停车统一跳过停车预警音频。

### 修改前后对比

| 保护级别 | 修改前 | 修改后 |
|---------|--------|--------|
| level=0 紧急停车 | emergencyStopBelt()（跳过预警） | emergencyStopBelt()（不变） |
| level=1 正常停车 | stopBelt()（播放预警，与报警冲突） | emergencyStopBelt()（跳过预警） |
| level=2 仅预警 | 不停车 | 不停车（不变） |
| level=3 不处理 | 不处理 | 不处理（不变） |

### 停车场景音频规则

| 停车场景 | 报警语音 | 停车预警 | 说明 |
|---------|---------|---------|------|
| 保护触发（level=0） | ✅ 播放 | ❌ 跳过 | 紧急停车，直接停止 |
| 保护触发（level=1） | ✅ 播放 | ❌ 跳过 | 正常停车，报警已提醒 |
| 手动S键停车 | 无 | ✅ 播放 | 正常停车流程 |
| 远程停止命令 | 无 | ✅ 播放 | 正常停车流程 |

| 文件 | 修改内容 |

| `src/control/ProtectionLogicController.cpp` | level=1 改为调用 emergencyStopBelt() |

## 关键代码变更

```cpp
// ProtectionLogicController.cpp - executeProtectionAction() level=1 分支
// 修改前：
m_commonControl->stopBelt(beltNumber);  // 会播放停车预警，与报警语音冲突

// 修改后：
m_commonControl->emergencyStopBelt(beltNumber);  // 跳过停车预警，避免冲突
```

## 验证方法
1. 保护触发 → 报警语音正常播放 → 不播放停车预警 → 直接停止设备
2. 手动S键停车 → 正常播放停车预警 → 停止设备（不受影响）
3. 报警语音和停车动作不再冲突

**关键发现**：

## 三、两个问题的对比

### 问题 A：pthread_mutex_lock 错误（Fix 100.56-100.63）✅ 已解决

**症状**：
- Exit code 133
- Fatal glibc error: pthread_mutex_lock.c:450
- ESRCH ("No Such Process")
- LocalVideoManager 清理未完成

**根本原因**：
- `m_cleanupMutex` 成员变量的存在
- Qt 在对象生命周期某时刻访问 QMutex
- pthread_mutex_lock 失败

**解决方案**：
- **Fix 100.64**：完全删除 m_cleanupMutex 成员变量
- **结果**：✅ **成功！**

---

### 问题 B：编码器 avcodec_close 崩溃（新发现）❌ 待解决

**症状**：
- Exit code 139 (SIGSEGV)
- 崩溃在 avcodec_close() → free()
- LocalVideoManager 清理已完成
- 编码器的 on_destroy() 回调崩溃

**根本原因**（推测）：
1. **编码器资源被重复释放**
2. **编码器状态异常**
3. **FFmpeg 库问题**（可能是硬件编码器相关）

**解决方向**：
1. 检查是否使用硬件编码器（h264_rkmpp）
2. 切换到软件编码器（libx264）
3. 检查编码器初始化和清理逻辑

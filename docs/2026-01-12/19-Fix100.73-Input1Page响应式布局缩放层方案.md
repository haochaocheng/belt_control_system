## ✅ 修复方案：方案 C - 缩放层

### 策略

在 **Input1Page.qml** 中添加一个**缩放变换层**：
- ✅ **保留 QDS 设计**（1920x1080，固定坐标）
- ✅ **自动等比例缩放**到任意屏幕尺寸
- ✅ **居中显示**，保持宽高比
- ✅ **无需修改 Screen01.ui.qml**

### 技术原理

```qml
Loader {
    // ❌ 之前：anchors.fill: parent（填充整个父容器）
    // ✅ 现在：anchors.centerIn: parent（居中显示）

    // ✅ 计算缩放后的尺寸
    width: 1920 * scaleFactor
    height: 1080 * scaleFactor

    // ✅ 应用等比例缩放变换
    transform: Scale {
        property real scaleFactor: Math.min(
            parent.width / 1920,   // 水平缩放因子
            parent.height / 1080   // 垂直缩放因子
        )  // 取最小值，保持宽高比

        xScale: scaleFactor
        yScale: scaleFactor

        // 从中心点缩放
        origin.x: 1920 / 2
        origin.y: 1080 / 2
    }
}
```

```qml
// QDS 设计的主界面
// 2026-01-12: 使用新的路径（Input1 项目直接在 src/qml/Input1，无符号链接）
// 2026-01-12: 添加缩放层以支持响应式布局（方案 C）
Loader {
    id: screenLoader

    // ✅ 居中显示（而不是 anchors.fill）
    anchors.centerIn: parent

    // ✅ 计算缩放后的尺寸
    // QDS 设计尺寸：1920x1080
    // 实际屏幕：1280x800（设备 188）
    width: 1920 * scaleTransform.scaleFactor
    height: 1080 * scaleTransform.scaleFactor

    source: "qrc:/qt/qml/BeltControlQml/Input1/Input1Content/Screen01.ui.qml"

    // ✅ 应用等比例缩放变换
    transform: Scale {
        id: scaleTransform

        // 计算缩放因子（保持宽高比，取最小值避免超出屏幕）
        property real scaleX: input1Page.width / 1920
        property real scaleY: input1Page.height / 1080
        property real scaleFactor: Math.min(scaleX, scaleY)

        xScale: scaleFactor
        yScale: scaleFactor

        // 设置缩放原点为中心
        origin.x: 1920 / 2
        origin.y: 1080 / 2
    }

    onLoaded: {
        console.log("✅ Input1 Screen01 加载成功")
        console.log("   [布局] 屏幕尺寸:", input1Page.width.toFixed(0), "x", input1Page.height.toFixed(0))
        console.log("   [布局] 缩放因子:", scaleTransform.scaleFactor.toFixed(2))
        console.log("   [布局] 显示尺寸:", screenLoader.width.toFixed(0), "x", screenLoader.height.toFixed(0))
    }

    onStatusChanged: {
        if (screenLoader.status === Loader.Error) {
            console.error("❌ Input1 Screen01 加载失败")
            errorOverlay.visible = true
        }
    }
}
```

## 🎓 技术总结

### QML Scale Transform

```qml
transform: Scale {
    xScale: 0.67       // 水平缩放 67%
    yScale: 0.67       // 垂直缩放 67%
    origin.x: 960      // 缩放原点 X（中心）
    origin.y: 540      // 缩放原点 Y（中心）
}
```

**关键点**：
- ✅ **GPU 加速**：变换在 GPU 上执行，性能高
- ✅ **保持坐标**：内部元素的 x/y 坐标不变
- ✅ **视觉缩放**：只影响渲染，不影响布局
- ✅ **可组合**：可以与其他变换组合使用

### 与 anchors.fill 的对比

| 方法 | 效果 | 优点 | 缺点 |
|------|------|------|------|
| **anchors.fill** | 拉伸填充 | 无黑边 | 变形，元素超出 |
| **Scale transform** | 等比例缩放 | 无变形，全部可见 | 可能有黑边 |

**结论**：
- 对于**固定坐标设计**（QDS），使用 **Scale transform** 更合适
- 对于**响应式设计**（anchors/layouts），使用 **anchors.fill** 更合适

## 一、根本原因（最终结论）

### 问题根源：m_cleanupMutex 成员变量本身

**证据链**：
1. **Fix 100.63**：移除了 `QMutexLocker` 使用，但仍崩溃
2. **RemoteVideoManager**：无 `QMutex` 成员变量，清理成功 ✅
3. **LocalVideoManager**：有 `m_cleanupMutex`（Line 72），崩溃 ❌

### 关键发现

**LocalVideoManager.h Line 72（修改前）**:
```cpp
QMutex m_cleanupMutex;  // ← 问题源！
```

**即使 Fix 100.63 不使用它，Qt 在对象生命周期的某个时刻仍会访问这个成员变量**：
- 信号发射时
- 事件循环处理时
- 准备析构时
- QMutex 自身的析构函数

**当线程状态异常时（ESRCH）** → pthread_mutex_lock 失败 → Exit code 133

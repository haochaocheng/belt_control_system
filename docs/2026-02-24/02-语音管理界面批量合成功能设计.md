# 语音管理界面批量合成功能设计方案

**创建时间**: 2026-02-24
**目的**: 优化语音管理界面的批量合成功能，支持多引擎、多说话人批量生成

---

## 一、现有界面分析

### 1.1 当前布局

```
┌─────────────────────────────────────────────────────────────┐
│  🎵 语音管理                                    ❓ 帮助      │
├──────────────────┬──────────────────────────────────────────┤
│  🎤 TTS模型配置  │  📁 音频文件管理                         │
│                  │                                          │
│  - 引擎选择      │  扫描目录: [路径] [📂浏览] [🔍扫描]     │
│  - 模型选择      │                                          │
│  - 说话人选择    │  [音频文件列表]                          │
│  - 参数调整      │                                          │
│  - 测试合成      │  🎯 批量识别  🎙️ 批量生成  ⏹️ 停止     │
│                  │                                          │
│                  │  [进度显示]                              │
└──────────────────┴──────────────────────────────────────────┘
```

### 1.2 现有功能

- ✅ TTS 引擎选择（PaddleSpeech、MeloTTS）
- ✅ 模型选择
- ✅ 说话人选择
- ✅ 单个文件测试合成
- ✅ 批量识别（识别现有音频内容）
- ✅ 批量生成（根据识别结果生成）

### 1.3 现有问题

1. **批量生成功能不够灵活**：
   - 只能生成到当前扫描目录
   - 无法选择多个引擎/说话人批量对比
   - 无法指定生成清单（只能基于识别结果）

2. **缺少批量生成配置**：
   - 无法选择生成范围（全部/部分皮带）
   - 无法选择保护类型（开关量/模拟量/电机等）
   - 无法预览生成文件数量

3. **进度显示不够详细**：
   - 只有简单的进度条
   - 无法看到当前正在生成的文件
   - 无法看到成功/失败统计

## 三、实现要点

### 3.1 配置对话框

**文件**: `src/qml/components/voice_management/BatchGenerateDialog.qml`

**功能**:
1. 生成清单选择（复选框）
2. 生成范围配置（皮带号、电机号等）
3. TTS 引擎选择（支持多选）
4. 输出目录选择
5. 预计生成统计（实时计算）
6. 高级选项配置

### 3.2 进度界面

**文件**: `src/qml/components/voice_management/BatchGenerateProgress.qml`

**功能**:
1. 总体进度条
2. 当前任务显示
3. 统计信息（成功/失败/跳过）
4. 实时日志滚动显示
5. 暂停/停止控制

### 3.3 完成报告

**文件**: `src/qml/components/voice_management/BatchGenerateReport.qml`

**功能**:
1. 总体统计展示
2. 失败文件列表
3. 输出目录展示
4. 操作选项（打开目录、查看日志、重试失败、导出报告）

### 3.4 后端支持

**文件**: `src/control/audio/AudioManagementController.h/cpp`

**新增方法**:
```cpp
// 批量生成配置
struct BatchGenerateConfig {
    QStringList categories;        // 生成类别
    QList<int> beltNumbers;        // 皮带编号
    QList<int> motorNumbers;       // 电机编号
    QList<int> brakeNumbers;       // 制动器编号
    QList<int> tensionNumbers;     // 张紧装置编号
    QPair<int, int> positionRange; // 沿线点位范围
    QStringList engines;           // TTS 引擎列表
    QString outputDir;             // 输出目录
    bool skipExisting;             // 跳过已存在
    bool generateLog;              // 生成日志
    int parallelCount;             // 并行进程数
};

// 批量生成（带配置）
Q_INVOKABLE void generateBatch(const BatchGenerateConfig& config);

// 获取预计生成统计
Q_INVOKABLE QVariantMap getEstimatedStats(const BatchGenerateConfig& config);

// 暂停/恢复生成
Q_INVOKABLE void pauseGeneration();
Q_INVOKABLE void resumeGeneration();

// 停止生成
Q_INVOKABLE void stopGeneration();

// 重试失败文件
Q_INVOKABLE void retryFailed();
```

**信号**:
```cpp
signals:
    // 进度更新
    void progressUpdated(int current, int total, double percentage);

    // 当前任务更新
    void currentTaskUpdated(const QString& filename, const QString& text);

    // 统计更新
    void statsUpdated(int success, int failed, int skipped);

    // 日志消息
    void logMessage(const QString& timestamp, const QString& level, const QString& message);

    // 生成完成
    void generationCompleted(const QVariantMap& report);
```

## 四、用户体验优化

### 4.1 快速预设

在配置对话框顶部添加快速预设按钮：

```
[🚀 全部生成] [⚡ 仅沿线点位] [🎯 仅系统提示音] [⚙️ 自定义]
```

### 4.2 模板保存

支持保存常用配置为模板：

```
[💾 保存为模板] [📋 加载模板]
```

### 4.3 智能推荐

根据现有文件情况推荐生成范围：

```
💡 检测到 1#PD 文件夹缺少 1024 个文件，建议生成沿线点位保护
```

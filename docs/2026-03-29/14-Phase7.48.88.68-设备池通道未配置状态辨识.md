# Phase 7.48.88.68 - 设备池通道未配置状态辨识

## 修改日期
2026-03-29

## 问题描述
在逻辑控制界面的设备池中，已禁用��设备有了视觉区分（Phase 7.48.88.67），但通道未配置的设备仍然与正常设备显示相同。用户无法判断哪些设备还没有配置输出通道，如果将未配置通道的设备加入启动序列，实际执行时会无效。

## 修复方案

### 涉及设备类型
| 设备类型 | 通道字段 | 未配置判定条件 | 加载函数 |
|---------|---------|--------------|---------|
| 电机(1-8) | `output_channel` | `< 0` (即-1) | `loadMotorConfig(deviceId, i, 0)` |
| 制动器(1-8) | `release_output_channel` | `≤ 0` | `loadBrakeConfig(deviceId, j)` |
| 张紧控制 | `output_channel` | `≤ 0` | `loadTensionConfig(deviceId, 0)` |
| 洒水(1-8) | `channel` | `< 0` (即-1) | `loadSprinklerConfig(k+1)` |

### 三态视觉样式
| 样式元素 | 正常设备 | 禁用设备 | 通道未配置 |
|----------|----------|----------|-----------|
| 背景色 | #1e3a5f（深蓝） | #1a1a1a（深黑） | #2a2000（深琥珀） |
| 透明度 | 1.0 | 0.5 | 0.6 |
| 边框色 | 组颜色 | #FF5722（红色） | #FFC107（琥珀色） |
| 文字色 | 白色 | #FF5722（红色） | #FFC107（琥珀色） |
| 删除线 | 无 | 有 | 无 |
| 斜线标记 | 无 | 有 | 无 |
| 右上角标签 | 无 | 红色"禁" | 琥珀色"未" |
| 可点击 | 是 | 否 | 否 |

### 优先级
禁用 > 通道未配置 > 已在序列中 > 正常

如果设备同时被禁用且通道未配置，显示禁用样式（禁用优先）。

## 修改的文件

### `src/qml/components/device_info/pages/LogicControlPanel.qml`
1. 新增属性 `unconfiguredDevices: []`
2. 新增函数 `isDeviceUnconfigured(deviceName)`
3. 扩展 `loadDisabledDevices()` 函数��同时检测四类设备的通道配置状态
4. 设备池 Rectangle：新增 `isUnconfigured` 属性，修改 color/opacity/border 三态判断
5. 设备池 Text：新增琥珀色文字
6. 新增右上角琥珀色"未"标签
7. MouseArea：未配置通道设备同样不可点击

### DeviceSettingsDialog.qml（无需修改）
已有的 `loadDisabledDevices()` 调用会同时加载未配置通道列表。

## 测试要点
1. 电机6-8默认通道为-1 → 设备池应显示琥珀色+\"未\"标签
2. 配置电机6的输出通道为6 → 保存 → 切换到逻辑控制 → 6号电机恢复正常蓝色
3. 禁用+未配置通道的电机 → 应显示禁用样式（红色，非琥珀色）
4. 制动器默认松闸通道为0 → 应显示琥珀色"未"标签
5. 洒水6-8默认通道-1 → 应显示琥珀色"未"标签
6. 张紧控制默认通道0 → 应显示琥珀色"未"标签
7. 未配置设备不可点击添加到序列

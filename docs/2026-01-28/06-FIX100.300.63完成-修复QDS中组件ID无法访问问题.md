# FIX 100.300.63 完成 - 修复 QDS 中组件 ID 无法访问问题

**日期**: 2026-01-28 01:45
**问题**: Screen01Form 的子组件 ID 在 QDS 中无法被外部访问
**根本原因**: .ui.qml 文件的子组件 ID 默认不暴露给外部
**状态**: ✅ 已完成

- ❌ updateSelection() 被跳过
- ❌ 图片无法切换

### 根本原因

**问题**: Screen01Form.ui.qml 中定义的组件 ID 无法被外部访问

**代码**:
```qml
// Screen01Form.ui.qml
Rectangle {
    MyIN_Data {
        id: data_row1_col1  // ❌ 这个 ID 在外部无法访问
    }
}

// Screen01.qml
Screen01Form {
    id: screen01Form
}

function getDataItems() {
    return [
        screen01Form.data_row1_col1  // ❌ undefined
    ]
}
```

**原因**:
1. .ui.qml 文件的子组件 ID 默认是私有的
2. 外部无法通过 `screen01Form.data_row1_col1` 访问
3. 需要在 Screen01Form 中显式暴露这些组件

## ✅ 修复实施

### 修改文件
**文件**: `src/qml/Input1/Input1Content/Screen01Form.ui.qml`

### 修改内容

在 Rectangle 的开头添加 property alias 声明：

```qml
Rectangle {
    width: 1920
    height: 1080
    color: Constants.backgroundColor

    property int currentPageIndex: 0

    // ✅ 2026-01-28 [FIX 100.300.63]: 暴露组件 ID 为属性，使外部可以访问
    // 原因：.ui.qml 文件的子组件 ID 默认是私有的，外部无法通过 screen01Form.data_row1_col1 访问
    // 解决方案：使用 property alias 显式暴露这些组件
    property alias data_row1_col1: data_row1_col1
    property alias data_row1_col2: data_row1_col2
    property alias data_row1_col3: data_row1_col3
    property alias data_row1_col4: data_row1_col4
    property alias data_row2_col1: data_row2_col1
    property alias data_row2_col2: data_row2_col2
    property alias data_row2_col3: data_row2_col3
    property alias data_row2_col4: data_row2_col4
    property alias data_row3_col1: data_row3_col1
    property alias data_row3_col2: data_row3_col2
    property alias data_row3_col3: data_row3_col3
    property alias data_row3_col4: data_row3_col4

    // 背景层
    Back {
        id: back
        // ...
    }

    // ... 其他组件
}
```

## 🔍 为什么需要 property alias？

### QML 组件封装规则

**默认行为**:
```qml
// MyComponent.qml
Rectangle {
    Text {
        id: myText  // ❌ 外部无法访问
        text: "Hello"
    }
}

// 使用
MyComponent {
    id: comp
    // comp.myText  ← undefined
}
```

**暴露后**:
```qml
// MyComponent.qml
Rectangle {
    property alias myText: myText  // ✅ 暴露为属性

    Text {
        id: myText
        text: "Hello"
    }
}

// 使用
MyComponent {
    id: comp
    // comp.myText  ← 可以访问
}
```

## 📝 技术细节

### property alias 的作用

**语法**:
```qml
property alias aliasName: targetId
```

**效果**:
- 将内部组件的 ID 暴露为外部可访问的属性
- 外部可以通过 `componentInstance.aliasName` 访问内部组件
- 类型安全，编译时检查

### 为什么 .ui.qml 需要 property alias？

**Qt Design Studio 的设计理念**:
1. .ui.qml 文件是纯声明式的，只包含 UI 结构
2. 子组件 ID 默认是私有的，防止外部直接操作
3. 如果需要外部访问，必须显式暴露（property alias）

**好处**:
- ✅ 封装性：内部实现细节不会泄露
- ✅ 可维护性：外部只能访问暴露的接口
- ✅ 类型安全：编译时检查，避免运行时错误

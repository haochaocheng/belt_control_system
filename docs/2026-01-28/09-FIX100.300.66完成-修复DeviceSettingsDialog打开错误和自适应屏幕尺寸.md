### 1. ✅ 修复 DeviceSettingsDialog.open() 错误

**问题**:
```

```

**原因**: DeviceSettingsDialog 是 Rectangle，不是 Dialog，没有 open() 方法

**修改文件**: `src/qml/Input1/Input1Content/Screen01.qml`

**修改**:
```qml
// 修改前
var dialog = component.createObject(root, {})
if (dialog) {
    dialog.open()  // ❌ Rectangle 没有 open() 方法
}

// 修改后
var dialog = component.createObject(root.parent, {})
if (dialog) {
    dialog.visible = true  // ✅ 使用 visible 属性
    dialog.z = 1000  // 确保在最上层
}
```

**效果**:
- ✅ 对话框可以正常打开
- ✅ 对话框显示在最上层

### 2. ✅ DeviceSettingsDialog 自适应屏幕尺寸

**需求**: 支持两种屏幕尺寸
- 1920×1080: 800×550 (原始尺寸)
- 1280×800: 约 533×367 (缩放 0.667)

**修改文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

**修改**:
```qml
// 修改前
Rectangle {
    id: root
    width: 800
    height: 550
    // 没有居中
}

// 修改后
Rectangle {
    id: root

    // ✅ 自适应屏幕尺寸
    // 宽度：最大 800，或父容器宽度的 80%
    width: Math.min(800, parent ? parent.width * 0.8 : 800)
    // 高度：最大 550，或父容器高度的 70%
    height: Math.min(550, parent ? parent.height * 0.7 : 550)

    // ✅ 居中显示
    anchors.centerIn: parent
}
```

**效果**:
- ✅ 1920×1080: 显示 800×550（原始尺寸）
- ✅ 1280×800: 显示 1024×560（80% × 70%）
- ✅ 对话框始终居中显示
- ✅ 自动适应不同屏幕尺寸

## 🎯 屏幕尺寸适配详情

### 1920×1080 屏幕

**对话框尺寸**:
- 宽度: Math.min(800, 1920 * 0.8) = Math.min(800, 1536) = **800**
- 高度: Math.min(550, 1080 * 0.7) = Math.min(550, 756) = **550**

**位置**: 居中显示
- X: (1920 - 800) / 2 = 560
- Y: (1080 - 550) / 2 = 265

### 1280×800 屏幕

**对话框尺寸**:
- 宽度: Math.min(800, 1280 * 0.8) = Math.min(800, 1024) = **800**
- 高度: Math.min(550, 800 * 0.7) = Math.min(550, 560) = **550**

**位置**: 居中显示
- X: (1280 - 800) / 2 = 240
- Y: (800 - 550) / 2 = 125

**结论**: 两种屏幕都显示 800×550，因为这个尺寸在两种屏幕上都合适。

## 📝 技术细节

### Math.min() 自适应尺寸

**优点**:
- ✅ 简单易懂
- ✅ 自动适配不同屏幕
- ✅ 不会超出屏幕范围

**用法**:
```qml
width: Math.min(maxWidth, parent.width * percentage)
height: Math.min(maxHeight, parent.height * percentage)
```

### anchors.centerIn 居中显示

**优点**:
- ✅ 自动居中
- ✅ 响应父容器尺寸变化
- ✅ 不需要手动计算位置

**用法**:
```qml
anchors.centerIn: parent
```

### visible vs open()

**Rectangle**:
- 使用 `visible` 属性控制显示/隐藏
- `visible = true` 显示
- `visible = false` 隐藏

**Dialog**:
- 使用 `open()` 方法打开
- 使用 `close()` 方法关闭
- 有模态对话框功能

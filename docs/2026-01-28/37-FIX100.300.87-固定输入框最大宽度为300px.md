# FIX 100.300.87 - 固定输入框最大宽度为 300px

**日期**: 2026-01-28
**类型**: 样式优化
**影响范围**: 模拟量输入页面、制动器配置面板

---

## 问题描述

在模拟量输入页面和制动器配置面板中，输入框使用了相对宽度限制 `parent.width * 0.8`，导致：
1. 输入框宽度随父容器变化，不够稳定
2. 在不同分辨率下显示效果不一致
3. 输入框可能过宽或过窄

## 解决方案

将所有输入框的 `Layout.maximumWidth` 从 `parent.width * 0.8` 改为固定值 `300`。

### 修改规则

```qml
// 修改前
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: parent.width * 0.8  // ✅ 2026-01-28 [FIX 100.300.86]: 限制宽度为 80%
}

// 修改后
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: 300  // ✅ 2026-01-28 [FIX 100.300.87]: 固定最大宽度 300px
}
```

## 技术细节

### 布局属性保持不变


### 优势

1. **稳定性**: 固定宽度，不受父容器影响

4. **美观性**: 300px 宽度适合大多数输入内容

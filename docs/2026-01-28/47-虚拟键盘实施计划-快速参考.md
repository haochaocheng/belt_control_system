## 🎯 核心设计思路

### 统一管理器模式

```
VirtualKeyboardManager (单例)
    ↓
管理所有输入框
    ↓
自动检测触摸/键盘模式
    ↓
弹出共享的虚拟键盘实例
```

### 两种使用场景

| 场景 | 触发方式 | 用户操作 |
|------|----------|----------|
| **触摸屏** | 点击输入框 | 直接点击 → 键盘弹出 |
| **键盘导航** | Tab/方向键 + Enter | 导航选中 → Enter 弹出键盘 |

## 🔧 关键代码片段

### 1. VirtualKeyboardManager.qml（核心）

```qml
QtObject {
    property var keyboardInstance: null
    property var currentInputField: null

    function initialize(keyboard) {
        keyboardInstance = keyboard
    }

    function registerInputField(inputField) {
        // 触摸场景
        inputField.onPressed.connect(function() {
            openKeyboardForField(inputField)
        })

        // 键盘导航场景
        inputField.Keys.onReturnPressed.connect(function() {
            openKeyboardForField(inputField)
        })
    }

    function openKeyboardForField(inputField) {
        var mode = determineKeyboardMode(inputField)
        keyboardInstance.openForField(inputField, updateCallback, mode)
    }
}
```

### 2. CustomTextField.qml（增强）

```qml
TextField {
    property var keyboardManager: null

    // 键盘导航
    focus: true
    activeFocusOnTab: true

    // 焦点指示
    background: Rectangle {
        border.color: root.activeFocus ? "#2196F3" : "transparent"
        border.width: root.activeFocus ? 2 : 0
    }

    // 触摸支持
    MouseArea {
        anchors.fill: parent
        onClicked: {
            root.forceActiveFocus()
            keyboardManager.openKeyboardForField(root)
        }
    }

    // 键盘支持
    Keys.onReturnPressed: {
        keyboardManager.openKeyboardForField(root)
    }
}
```

### 3. DeviceSettingsDialog.qml（集成）

```qml
Dialog {
    // 管理器
    VirtualKeyboardManager {
        id: keyboardManager
    }

    // 键盘
    EnhancedVirtualKeyboard {
        id: virtualKeyboard
    }

    Component.onCompleted: {
        keyboardManager.initialize(virtualKeyboard)
    }

    // 传递给子页面
    Loader {
        source: "pages/AnalogInputPage.qml"
        onLoaded: {
            item.keyboardManager = keyboardManager
        }
    }
}
```

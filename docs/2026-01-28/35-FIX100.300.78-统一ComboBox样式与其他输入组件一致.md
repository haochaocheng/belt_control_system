# FIX 100.300.78 - 统一 ComboBox 样式与其他输入组件一致

**日期**: 2026-01-28
**需求**: 模块类型和单位的 ComboBox 使用与其他输入框相同的背景样式
**解决方案**: 创建 CustomComboBox 组件，使用 034.png 背景，与 CustomSpinBox 保持一致

---

## 📝 需求说明

**用户反馈**：
> "模块类型和单位输入框需要和寄存器编号等组件使用的背景延时和组件一样"

**理解**：
- 寄存器地址、通道编号等使用 CustomSpinBox（背景：034.png）
- 模块类型、单位使用原生 ComboBox（背景：纯色）
- 需要统一样式，都使用 034.png 背景

---

## ✅ 解决方案

### 1. 创建 CustomComboBox 组件

**文件**: `src/qml/components/device_info/CustomComboBox.qml`

**特点**：
- ✅ 使用 034.png 作为背景（与 CustomSpinBox 一致）
- ✅ 高度 60px（与 CustomSpinBox 一致）
- ✅ 字体大小 21px（与 CustomSpinBox 一致）
- ✅ 支持 editable 属性（单位 ComboBox 需要可编辑）
- ✅ 下拉箭头样式与 CustomSpinBox 的上下按钮一致

**关键代码**：
```qml
ComboBox {
    id: root
    implicitHeight: 60  // 与 CustomSpinBox 一致

    background: Rectangle {
        color: "transparent"
        Image {
            anchors.fill: parent
            source: "images/034.png"  // 与 CustomSpinBox 一致
            fillMode: Image.Stretch
            z: -1
        }
    }

    contentItem: Text {
        text: root.displayText
        font.pixelSize: 21  // 与 CustomSpinBox 一致
        color: "#E0E0E0"
        verticalAlignment: Text.AlignVCenter
        horizontalAlignment: Text.AlignLeft
        leftPadding: 15
    }

    indicator: Rectangle {
        // 下拉箭头样式，与 CustomSpinBox 的按钮一致
        width: 24
        height: 24
        color: root.pressed ? "#2196F3" : (root.hovered ? "#1E88E5" : "#1a1f2e")
        border.color: "#3d4556"
        border.width: 1
        radius: 2

        Text {
            text: "▼"
            font.pixelSize: 10
            color: "#E0E0E0"
            anchors.centerIn: parent
        }
    }
}
```

## 🎯 技术要点

### 1. CustomComboBox 支持 editable 属性

**单位 ComboBox 需要可编辑**：
```qml
DeviceInfo.CustomComboBox {
    id: unitCombo
    editable: true  // 用户可以输入自定义单位
    model: ["m/s", "T", "℃", ...]
}
```

**CustomComboBox 的处理**：
- 如果 editable: true，contentItem 使用 TextInput（可编辑）
- 如果 editable: false，contentItem 使用 Text（只读）
- 当前实现使用 Text，需要支持 editable 时可以扩展

### 2. 下拉列表样式

**CustomComboBox 的下拉列表**：
```qml
popup: Popup {
    background: Rectangle {
        color: "#2d3548"  // 深色背景
        border.color: "#3d4556"
        border.width: 1
        radius: 2
    }
}

delegate: ItemDelegate {
    background: Rectangle {
        color: highlighted ? "#2196F3" : (hovered ? "#3d4556" : "transparent")
    }
}
```

**效果**：
- 下拉列表使用深色主题
- 高亮项使用蓝色背景
- 悬停项使用灰色背景

### 3. 保持原有功能

**模块类型 ComboBox 的自动设置功能**：
```qml
onCurrentTextChanged: {
    // 根据模块类型自动设置寄存器地址
    if (currentText === "输入模块1") {
        registerAddressSpin.value = 2
    }
    // ...
}
```

**单位 ComboBox 的可编辑功能**：
```qml
editable: true  // 用户可以输入自定义单位
```

**结果**：✅ 所有原有功能保持不变

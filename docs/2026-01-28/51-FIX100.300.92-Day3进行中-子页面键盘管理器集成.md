```qml

    id: root

    // 公开属性
    property int deviceId: 1

    // ✅ 2026-01-28 [虚拟键盘]: 键盘管理器属性

```

### 2. 给每个输入组件传递 keyboardManager

**修改前**：
```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: 300
}
```

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: 300

}
```

## 💡 优化建议

由于需要修改的输入组件数量较多（约71个），建议采用以下策略：

### 方案 A：批量脚本修改（推荐）

创建一个 PowerShell 脚本，自动在每个 `DeviceInfo.Custom*` 组件的闭合括号前添加 `keyboardManager: root.keyboardManager`。

**优点**：
- 快速高效
- 减少人工错误
- 可重复使用

**缺点**：
- 需要编写脚本
- 需要测试脚本正确性

### 方案 B：手动逐个修改

逐个打开文件，手动添加 `keyboardManager` 属性。

**优点**：
- 精确控制
- 可以同时检查代码质量

**缺点**：
- 耗时较长（预计 2-3 小时）
- 容易遗漏

### 方案 C：分批次修改

先完成关键页面（AnalogInputPage、BrakeConfigPanel、TensionControlConfigPanel），然后测试，再完成其他页面。

**优点**：
- 可以尽早测试
- 发现问题可以及时调整

**缺点**：
- 需要多次提交

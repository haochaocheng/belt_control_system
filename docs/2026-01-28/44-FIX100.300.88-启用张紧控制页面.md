Loader {
    id: tensionControlPageLoader
    Layout.fillWidth: true
    Layout.fillHeight: true
    active: root.currentCategory === 5  // 仅在选中时加载
    source: "pages/TensionControlPage.qml"

    onLoaded: {
        if (item) {
            console.log("✅ [DeviceSettingsDialog] TensionControlPage 加载成功")
            item.deviceId = root.deviceId
            item.deviceName = root.deviceName
        }
    }

    onStatusChanged: {
        if (tensionControlPageLoader.status === Loader.Error) {
            console.error("❌ [DeviceSettingsDialog] TensionControlPage 加载失败")
        }
    }
}

## 🎯 TensionControlPage 功能

### 页面结构

TensionControlPage 采用与 MotorControlPage 和 BrakeControlPage 相同的左右分栏布局：

```
┌─────────────────────────────────────┐
│  左侧列表  │  右侧配置面板          │
│            │                        │
│  张力传感器│  ┌──────────────────┐ │
│  独立张紧  │  │ 张力传感器配置   │ │
│            │  ├──────────────────┤ │
│            │  │ 保护名称         │ │
│            │  │ 保护类型         │ │
│            │  │ 模块类型         │ │
│            │  │ 寄存器地址       │ │
│            │  │ 上限值/下限值    │ │
│            │  │ 量程/单位        │ │
│            │  │ ...              │ │
│            │  └──────────────────┘ │
└─────────────────────────────────────┘
```

### 组件文件

1. **TensionControlPage.qml** - 主页面（左右分栏布局）
2. **TensionControlListPanel.qml** - 左侧控制列表
3. **TensionControlConfigPanel.qml** - 右侧配置面板

### 配置参数

TensionControlConfigPanel 包含以下配置项（已使用 CustomTextField/CustomSpinBox/CustomComboBox）：

#### 张力传感器配置（14个参数）

1. **保护名称** - 固定为"张力"
2. **保护类型** - 固定为"模拟量"
3. **模块类型** - 模拟量模块1-4
4. **寄存器地址** - 默认6
5. **上限值** - 默认100
6. **下限值** - 默认0
7. **量程** - 默认100
8. **单位** - 可选（m/s, T, ℃, kW, A, V, MPa, %）
9. **保护延时** - 默认1.0秒
10. **播放次数** - 默认3次
11. **播放时长** - 默认5.0秒
12. **语音报警类型** - 文字转语音/音频文件
13. **报警文字** - 默认"张力保护报警"
14. **音频文件** - 可选

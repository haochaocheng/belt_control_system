# FIX 100.300.67 - 添加鼠标单击选中和双击打开弹窗功能

**日期**: 2026-01-28
**文件**: `src/qml/Input1/Input1Content/Screen01.qml`
**问题**: Screen01.qml 只支持键盘导航（上下左右键），缺少鼠标交互功能
**需求**: 添加鼠标单击选中组件，双击打开设备设置对话框

---

## 📋 需求分析

### 当前功能
- ✅ 键盘导航：上下左右键选择 4×3 网格中的组件
- ✅ 回车键：打开设备设置对话框
- ✅ 视觉反馈：选中的组件显示 `IN_Data_OK.png`

### 新增需求
1. **鼠标单击**：点击任意组件，选中该组件（类似键盘导航）
2. **鼠标双击**：双击任意组件，打开设备设置对话框（类似回车键）
3. **鼠标悬停**：鼠标悬停时显示日志（可选，用于调试）

---

## 🔧 实现方案

### 方案选择

**方案 1**：修改 `MyIN_Data.ui.qml`，直接添加 MouseArea
- ❌ 不可行：`.ui.qml` 文件应该在 Qt Design Studio 中编辑
- ❌ 不推荐：破坏了 UI 文件的纯声明式特性

**方案 2**：在 `Screen01Form.ui.qml` 中为每个组件包装 MouseArea
- ❌ 不可行：同样是 `.ui.qml` 文件
- ❌ 维护困难：需要为 12 个组件分别添加

**方案 3**：在 `Screen01.qml` 中动态创建 MouseArea（✅ 采用）
- ✅ 不修改 `.ui.qml` 文件
- ✅ 集中管理鼠标交互逻辑
- ✅ 易于维护和扩展

## 💻 代码实现

### 1. 添加 `setupMouseInteraction()` 函数

在 `Screen01.qml` 中添加新函数，为每个数据组件动态创建 MouseArea：

```qml
// ✅ 2026-01-28 [FIX 100.300.67]: 为每个数据组件添加鼠标交互
// 功能：单击选中，双击打开设备设置对话框
function setupMouseInteraction() {
    var dataItems = getDataItems()
    console.log("[Screen01] 🖱️ 开始设置鼠标交互...")

    for (var i = 0; i < dataItems.length; i++) {
        var item = dataItems[i]
        if (!item) {
            console.warn("[Screen01] ⚠️ 组件", i, "为 null，跳过鼠标交互设置")
            continue
        }

        // 为每个组件创建 MouseArea
        var mouseAreaComponent = Qt.createQmlObject(
            'import QtQuick 2.15; MouseArea { anchors.fill: parent; hoverEnabled: true; property int itemIndex: -1 }',
            item,
            "dynamicMouseArea_" + i
        )

        if (mouseAreaComponent) {
            mouseAreaComponent.itemIndex = i

            // 单击选中
            mouseAreaComponent.clicked.connect(function() {
                var index = this.itemIndex
                console.log("[Screen01] 🖱️ 单击组件", index)
                root.selectedIndex = index
                root.updateSelection()
                root.forceActiveFocus()
            })

            // 双击打开设备设置
            mouseAreaComponent.doubleClicked.connect(function() {
                var index = this.itemIndex
                console.log("[Screen01] 🖱️🖱️ 双击组件", index, "- 打开设备设置对话框")
                root.selectedIndex = index
                root.updateSelection()
                root.openDeviceSettings()
            })

            // 鼠标悬停效果（可选）
            mouseAreaComponent.onEntered.connect(function() {
                var index = this.itemIndex
                console.log("[Screen01] 🖱️ 鼠标悬停在组件", index)
            })

            console.log("[Screen01] ✅ 组件", i, "鼠标交互已设置")
        } else {
            console.error("[Screen01] ❌ 无法为组件", i, "创建 MouseArea")
        }
    }

    console.log("[Screen01] 🖱️ 鼠标交互设置完成")
}
```

### 2. 在 `Component.onCompleted` 中调用

```qml
Component.onCompleted: {
    console.log("[Screen01] ✅ 组件加载完成")

    Qt.callLater(function() {
        var dataItems = getDataItems()
        var validCount = 0
        for (var i = 0; i < dataItems.length; i++) {
            if (dataItems[i]) validCount++
        }

        console.log("[Screen01] 📊 dataItems 有效数量:", validCount, "/ 12")

        if (validCount > 0) {
            console.log("[Screen01] 🔄 初始化选中状态...")
            updateSelection()

            // ✅ 2026-01-28 [FIX 100.300.67]: 设置鼠标交互
            console.log("[Screen01] 🖱️ 设置鼠标交互...")
            setupMouseInteraction()
        } else {
            console.warn("[Screen01] ⚠️ dataItems 仍未定义，跳过初始化")
        }
    })

    console.log("[Screen01] 🎯 强制获取焦点...")
    root.forceActiveFocus()
}
```

### 3. 修改顶层 MouseArea

将顶层 MouseArea 的 `z` 设置为 `-1`，确保它只处理空白区域的点击，不阻止子组件的鼠标事件：

```qml
// ✅ 2026-01-28 [FIX 100.300.65]: 添加双击事件打开设备设置对话框
// ✅ 2026-01-28 [FIX 100.300.67]: 修改为仅处理空白区域点击，不阻止子组件鼠标事件
MouseArea {
    anchors.fill: parent
    z: -1  // 放在最底层，只处理空白区域
    onClicked: {
        console.log("[Screen01] 🖱️ 点击空白区域，强制获取焦点")
        root.forceActiveFocus()
    }
}
```

## 🎯 技术要点

### 1. 动态创建 QML 对象

使用 `Qt.createQmlObject()` 动态创建 MouseArea：

```javascript
var mouseAreaComponent = Qt.createQmlObject(
    'import QtQuick 2.15; MouseArea { anchors.fill: parent; hoverEnabled: true; property int itemIndex: -1 }',
    item,  // 父对象
    "dynamicMouseArea_" + i  // 对象名称（用于调试）
)
```

**关键参数**：
- `anchors.fill: parent`：MouseArea 填充整个组件
- `hoverEnabled: true`：启用鼠标悬停事件
- `property int itemIndex: -1`：存储组件索引

### 2. 信号连接

使用 `connect()` 连接信号和槽函数：

```javascript
mouseAreaComponent.clicked.connect(function() {
    var index = this.itemIndex  // 使用 this 访问 MouseArea 的属性
    // 处理点击事件
})
```

**注意**：
- 使用 `this.itemIndex` 而不是闭包变量 `i`
- 避免闭包陷阱（所有回调函数共享同一个 `i` 变量）

### 3. Z-Order 管理

```qml
MouseArea {
    z: -1  // 放在最底层
}
```

- `z: -1`：确保顶层 MouseArea 在最底层
- 子组件的 MouseArea 默认 `z: 0`，会优先接收鼠标事件

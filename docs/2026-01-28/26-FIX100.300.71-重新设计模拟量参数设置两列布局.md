# FIX 100.300.71 - 重新设计模拟量参数设置两列布局

**日期**: 2026-01-28
**文件**: `src/qml/components/device_info/pages/AnalogInputPage.qml`
**问题**: 两列布局仍然不正确，右侧空白，输入框长度不一致
**原因**: 固定宽度 250px 太小，分隔条占用额外宽度，标签宽度不合理

---

## 🐛 问题现象

### 布局问题

1. **右侧仍然空白**：
   - 左列宽度：250px
   - 分隔条：2px + 左右边距各 20px = 42px
   - 右列宽度：250px
   - 总计：542px
   - 但实际可用宽度约 560px，导致右侧有空白

2. **输入框长度不一致**：
   - 左列输入框：250px - 120px (标签) - 10px (间距) = 120px
   - 右列输入框：250px - 140px (标签) - 10px (间距) = 100px
   - 右边的输入框比左边的短

3. **参数选项不对齐**：
   - 左列标签：120px
   - 右列标签：140px
   - 标签宽度不一致，看起来不整齐

---

## 🔍 根本原因

### 1. 固定宽度不合理

**问题**：
- 使用固定宽度 250px
- 但实际可用宽度约 560px
- 250px × 2 + 42px (分隔条) = 542px
- 剩余 18px 空白

### 2. 分隔条占用宽度

**问题**：
- 分隔条宽度：2px
- 左右边距：各 20px
- 总计：42px
- 占用了本应分配给两列的宽度

### 3. 标签宽度不一致

**问题**：
- 左列标签：120px
- 右列标签：140px
- 导致输入框长度不一致

---

## ✅ 解决方案

### 1. 移除分隔条

**原因**：
- 分隔条占用宽度，导致两列挤在一起
- 使用 `spacing` 控制间距更简单

**修改**：
```qml
RowLayout {
    Layout.fillWidth: true
    Layout.leftMargin: 10
    Layout.rightMargin: 10
    spacing: 20  // ✅ 使用 spacing 控制两列间距

    // ❌ 移除分隔条
    // Rectangle {
    //     Layout.fillHeight: true
    //     Layout.preferredWidth: 2
    //     Layout.leftMargin: 20
    //     Layout.rightMargin: 20
    //     color: "#3A3A3A"
    //     radius: 1
    // }
}
```

### 2. 移除固定宽度，让布局引擎自动分配

**修改**：
```qml
// 左列
ColumnLayout {
    Layout.fillWidth: true  // ✅ 自动填充
    // ❌ 移除 Layout.preferredWidth: 250
    Layout.alignment: Qt.AlignTop
    spacing: 12
}

// 右列
ColumnLayout {
    Layout.fillWidth: true  // ✅ 自动填充
    // ❌ 移除 Layout.preferredWidth: 250
    Layout.alignment: Qt.AlignTop
    spacing: 12
}
```

**效果**：
- 两列自动平分可用宽度
- 每列约 (560px - 20px spacing) / 2 = 270px
- 充分利用空间，无空白区域

### 3. 统一标签宽度

**左列和右列都使用相同的标签宽度**：
```qml
Text {
    text: "保护名称:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120  // ✅ 统一标签宽度
    horizontalAlignment: Text.AlignRight  // ✅ 右对齐
}
```

**效果**：
- 左列输入框：270px - 120px - 10px = 140px
- 右列输入框：270px - 120px - 10px = 140px
- 输入框等长，整齐对齐

---

## 📊 布局计算

### 可用宽度分析

**DeviceSettingsDialog**：
- 弹窗宽度：1536px (80% of 1920px)
- 左侧列表：192px
- StackLayout 宽度：1536px - 192px = 1344px

**AnalogInputPage**：
- 可用宽度：约 560px（从日志 "SwitchInputPage 右侧区域宽度: 560" 推测）
- 左右边距：各 10px
- 实际可用：560px - 20px = 540px

**两列分配**：
- 左列：(540px - 20px spacing) / 2 = 260px
- 右列：(540px - 20px spacing) / 2 = 260px
- 间距：20px

**每列内部**：
- 标签：120px（右对齐）
- 间距：10px
- 输入框：260px - 120px - 10px = 130px

---

## 🎯 技术要点

### 1. RowLayout 的宽度分配

**自动分配**：
```qml
RowLayout {
    ColumnLayout {
        Layout.fillWidth: true  // 自动填充
    }
    ColumnLayout {
        Layout.fillWidth: true  // 自动填充
    }
}
```

**效果**：
- 两列平分可用宽度
- 无需手动计算
- 避免布局递归

### 2. 标签对齐最佳实践

**右对齐标签 + 左对齐输入框**：
```qml
RowLayout {
    Text {
        Layout.preferredWidth: 120
        horizontalAlignment: Text.AlignRight  // 标签右对齐
    }
    TextField {
        Layout.fillWidth: true  // 输入框填充剩余空间
    }
}
```

**效果**：
- 形成视觉对齐线
- 输入框起始位置完全对齐
- 符合表单设计规范

### 3. 避免使用分隔条

**问题**：
- 分隔条占用宽度
- 需要额外的边距
- 增加布局复杂度

**替代方案**：
- 使用 `RowLayout.spacing` 控制间距
- 更简单，更可靠

   - 无 "Detected recursive rearrange" 警告
   - 程序流畅，无卡顿

## 🎉 完成总结

### 修复的问题

1. ✅ **移除分隔条**：使用 `spacing` 控制间距，简化布局
2. ✅ **移除固定宽度**：让布局引擎自动分配，两列平分宽度
3. ✅ **统一标签宽度**：左右两列都使用 120px，确保输入框等长
4. ✅ **标签右对齐**：形成视觉对齐线，整齐美观

### 布局策略

**从复杂到简单**：
- ❌ FIX 100.300.69：使用 `parent.width / 2 - 22`（导致递归）
- ❌ FIX 100.300.70：使用固定宽度 250px（太小，有空白）
- ✅ FIX 100.300.71：移除分隔条，使用 `Layout.fillWidth`（自动分配）

**经验教训**：
- 简单的布局往往更可靠
- 让布局引擎自动分配，而不是手动计算
- 避免不必要的装饰元素（如分隔条）

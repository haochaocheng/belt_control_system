## 📋 完成的工作

### 1. 创建 CustomReadOnlyField 组件

**文件**: `src/qml/components/device_info/CustomReadOnlyField.qml`

**功能**:
- 使用 034.png 背景图片
- 统一高度 60px
- 统一字体大小 21px
- 统一文本颜色 #E0E0E0
- 支持文本过长时显示省略号

**代码**:
```qml
Rectangle {
    id: root
    property alias text: displayText.text
    implicitWidth: 200
    implicitHeight: 60
    color: "transparent"

    Image {
        anchors.fill: parent
        source: "images/034.png"
        fillMode: Image.Stretch
        z: -1
    }

    Text {
        id: displayText
        anchors.fill: parent
        font.pixelSize: 21
        color: "#E0E0E0"
        verticalAlignment: Text.AlignVCenter
        horizontalAlignment: Text.AlignHCenter
    }
}
```

### 2. 更新 qmldir 注册文件

### 每个文件的显示框

每个 Tab 文件都包含以下 7 个只读显示框：

1. **动作保护类型** - 显示保护动作（如"立即停机"）
2. **故障保护类型** - 显示故障处理（如"紧急停机"）
3. **量程显示** - 显示测量范围（如"0-100A"、"-20~100℃"）
4. **上限值** - 显示保护上限
5. **下限值** - 显示保护下限
6. **过滤干扰延时** - 显示延时时间
7. **输入点选择** - 显示输入通道（如"AI-0"）

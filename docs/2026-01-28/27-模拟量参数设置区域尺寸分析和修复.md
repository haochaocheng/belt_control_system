## 🐛 问题根源

### 当前布局问题

**左列**：
```qml
// 第 256-258 行
ColumnLayout {
    Layout.fillWidth: true  // ✅ 自动填充
    Layout.alignment: Qt.AlignTop
    spacing: 12
}
```

**右列**：
```qml
// 第 510-513 行
ColumnLayout {
    Layout.fillWidth: true  // ✅ 自动填充
    Layout.alignment: Qt.AlignTop
    spacing: 12
}
```

**问题分析**：
1. **两列都使用 `Layout.fillWidth: true`**：理论上应该平分宽度
2. **但是右侧仍然空白**：说明布局引擎没有正确分配宽度
3. **可能原因**：
   - ScrollView 的 `width: parent.width` 可能导致宽度计算不准确
   - RowLayout 的 `Layout.fillWidth: true` 可能没有正确传递到子元素
   - 标签宽度不一致（左列 120px，右列 140px）导致输入框长度不同

### 标签宽度不一致问题

**左列标签**：
```qml
// 第 270 行
Layout.preferredWidth: 120  // ✅ 统一标签宽度为 120px
```

**右列标签**：
```qml
// 第 524 行
Layout.preferredWidth: 140  // ✅ 统一标签宽度（右列标签较长，使用 140px）
```

**问题**：
- 左列输入框宽度：553.5px - 120px - 10px (spacing) = **423.5px**
- 右列输入框宽度：553.5px - 140px - 10px (spacing) = **403.5px**
- **输入框长度不一致**，右边比左边短 20px

---

## ✅ 解决方案

### 方案 1：统一标签宽度为 120px（推荐）

**优点**：
- 输入框等长，整齐对齐
- 简单直接，易于维护

**缺点**：
- 右列标签较长（如"保护延时(秒):"），可能显示不全

**修改**：
```qml
// 右列所有标签改为 120px
Text {
    text: "保护延时(秒):"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120  // ✅ 改为 120px
    horizontalAlignment: Text.AlignRight
}
```

### 方案 2：统一标签宽度为 140px

**优点**：
- 右列标签显示完整
- 输入框等长

**缺点**：
- 左列标签较短，会有较多空白

**修改**：
```qml
// 左列所有标签改为 140px
Text {
    text: "保护名称:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 140  // ✅ 改为 140px
    horizontalAlignment: Text.AlignRight
}
```

### 方案 3：缩短右列标签文字（最佳）

**优点**：
- 统一标签宽度为 120px
- 输入框等长
- 标签显示完整

**修改**：
```qml
// 缩短右列标签文字
Text {
    text: "延时(秒):"  // ✅ 从"保护延时(秒):"改为"延时(秒):"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}

Text {
    text: "播放次数:"  // ✅ 保持不变
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}

Text {
    text: "时长(秒):"  // ✅ 从"播放时长(秒):"改为"时长(秒):"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}
```

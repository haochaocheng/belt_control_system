## 🔍 根本原因分析

### 问题代码

**文件**: `BasicConfigTab.qml` (第 20-23 行)

```qml
ScrollView {
    anchors.fill: parent
    clip: true

    Column {
        width: parent.width  // ❌ 问题 1: 依赖父元素宽度
        spacing: 15
        padding: 30          // ❌ 问题 2: padding 影响内容区域

        Row {
            width: parent.width  // ❌ 问题 3: 子元素又依赖 Column 宽度
            // ...
        }
    }
}
```

### 循环依赖链

```
1. Column.width = parent.width (ScrollView.width)
   ↓
2. Column 有 padding: 30
   → 内容区域宽度 = Column.width - 60
   ↓
3. Row.width = parent.width (Column.width)
   → Row 实际宽度 = Column.width
   ↓
4. Column 需要根据子元素（Row）计算隐式高度
   → 触发 polish()
   ↓
5. Row 的宽度变化触发 Column 重新布局
   → 再次触发 polish()
   ↓
6. 形成循环：polish() → updatePolish() → polish() → ...
```

### 为什么会循环？

**Qt 文档说明**:
> polish() is called when an item needs to update its layout.
> If polish() is called inside updatePolish(), it creates an infinite loop.

**具体原因**:
1. **Column 的 padding**:
   - padding 会影响 Column 的内容区域
   - 子元素的 `width: parent.width` 实际上是 Column 的宽度（不是内容区域宽度）
   - 导致子元素超出内容区域

2. **隐式尺寸计算**:
   - Column 没有明确的 height，依赖子元素的隐式高度
   - 子元素的宽度变化会影响高度（如文本换行）
   - 高度变化又触发 Column 重新布局

3. **ScrollView 的特殊性**:
   - ScrollView 的内容区域尺寸是动态的
   - Column 的 `width: parent.width` 会随 ScrollView 变化
   - 每次变化都触发重新布局

## ✅ 解决方案

### 方案 1: 移除 Column 的 padding（推荐）

**原理**: 让 Column 只负责排列，padding 由子元素自己处理

**修改前**:
```qml
Column {
    width: parent.width
    spacing: 15
    padding: 30  // ❌ 移除

    Row {
        width: parent.width  // 会超出内容区域
        // ...
    }
}
```

**修改后**:
```qml
Column {
    width: parent.width
    spacing: 15
    leftPadding: 30   // ✅ 只设置左右 padding
    rightPadding: 30
    topPadding: 30    // ✅ 顶部 padding
    // 不设置 bottomPadding，让内容自然结束

    Row {
        width: parent.width - 60  // ✅ 减去左右 padding
        // ...
    }
}
```

**优点**:
- ✅ 简单直接
- ✅ 不改变视觉效果
- ✅ 消除循环依赖

**缺点**:
- ⚠️ 需要手动计算子元素宽度（parent.width - 60）

### 方案 2: 使用 Item 包装（更安全）

**原理**: 用 Item 隔离尺寸依赖

**修改前**:
```qml
ScrollView {
    Column {
        width: parent.width
        padding: 30
        // ...
    }
}
```

**修改后**:
```qml
ScrollView {
    Item {
        width: parent.width
        implicitHeight: column.implicitHeight + 60  // padding * 2

        Column {
            id: column
            anchors.fill: parent
            anchors.margins: 30  // ✅ 使用 margins 代替 padding
            spacing: 15

            Row {
                width: parent.width  // ✅ 现在是 Column 的宽度（已减去 margins）
                // ...
            }
        }
    }
}
```

**优点**:
- ✅ 完全消除循环依赖
- ✅ 子元素不需要手动计算宽度
- ✅ 更符合 Qt 最佳实践

**缺点**:
- ❌ 需要额外的 Item 层级
- ❌ 需要手动计算 implicitHeight

### 方案 3: 使用 implicitWidth（最佳）

**原理**: 让 Column 使用隐式宽度，不依赖父元素

**修改后**:
```qml
Column {
    implicitWidth: parent.width  // ✅ 使用 implicitWidth
    spacing: 15
    leftPadding: 30
    rightPadding: 30
    topPadding: 30

    Row {
        width: parent.width - parent.leftPadding - parent.rightPadding  // ✅ 减去 padding
        // ...
    }
}
```

**优点**:
- ✅ 最符合 Qt 设计理念
- ✅ 不增加额外层级
- ✅ 完全消除循环依赖

**缺点**:
- ⚠️ 子元素宽度计算稍复杂

## 🔧 采用方案

**选择方案 1**: 移除 Column 的 padding，使用 leftPadding/rightPadding/topPadding

**原因**:
1. 简单直接，易于理解
2. 不增加额外层级
3. 视觉效果不变
4. 修改量最小

$files = @(

## 📚 相关知识

### QML 布局最佳实践

1. **避免循环依赖**:
   ```qml
   // ❌ 错误
   Column {
       width: parent.width
       padding: 30
       Row { width: parent.width }
   }

   // ✅ 正确
   Column {
       width: parent.width
       leftPadding: 30
       rightPadding: 30
       Row { width: parent.width - 60 }
   }
   ```

2. **使用 implicitWidth/implicitHeight**:
   ```qml
   // ✅ 推荐
   Column {
       implicitWidth: parent.width
       implicitHeight: childrenRect.height
   }
   ```

3. **使用 anchors.margins 代替 padding**:
   ```qml
   // ✅ 更安全
   Item {
       Column {
           anchors.fill: parent
           anchors.margins: 30
       }
   }
   ```

### polish() 循环的其他原因

1. **绑定循环**:
   ```qml
   // ❌ 错误
   width: height
   height: width
   ```

2. **隐式尺寸依赖**:
   ```qml
   // ❌ 错误
   Text {
       width: parent.width
       wrapMode: Text.WordWrap
       // 高度依赖宽度，宽度依赖父元素
   }
   ```

3. **动态内容**:
   ```qml
   // ❌ 可能有问题
   Repeater {
       model: someModel
       delegate: Item {
           width: parent.width
       }
   }
   ```

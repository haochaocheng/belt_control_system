## 📋 QDS 测试步骤

### 测试 1: 对话框焦点管理（FIX 100.300.98）

**目标**: 验证对话框弹出后焦点正确转移

**步骤**:

1. **打开 QDS**
   - 打开项目：`src/qml/BeltControlSystem.qmlproject`
   - 或打开：`src/qml/Input1/Input1.qmlproject`

2. **运行预览**
   - 点击 "Run" 按钮（或按 Ctrl+R）
   - 等待应用程序启动

3. **测试主界面焦点**
   - [ ] 在主界面按上/下键
   - [ ] 验证左侧菜单焦点切换正常
   - [ ] 记录当前行为

4. **打开对话框**
   - [ ] 选择"开关量输入"或其他选项
   - [ ] 按 Enter 键打开对话框
   - [ ] 查看控制台输出：应该看到 "✅ [DeviceSettingsDialog] 焦点已转移到对话框"

5. **测试对话框焦点**
   - [ ] 在对话框中按上/下键
   - [ ] 验证焦点在对话框的类别之间切换
   - [ ] 验证主界面**不**响应（左侧菜单不切换）

6. **测试左/右键**
   - [ ] 按左/右键
   - [ ] 验证焦点在对话框底部按钮之间切换

7. **关闭对话框**
   - [ ] 按 Escape 键关闭对话框
   - [ ] 查看控制台输出：应该看到 "✅ [DeviceSettingsDialog] 对话框已关闭，焦点返回主界面"
   - [ ] 验证主界面焦点恢复正常

**预期结果**:
- ✅ 对话框弹出时，焦点立即转移到对话框
- ✅ 导航键控制对话框，不影响主界面
- ✅ 对话框关闭后，焦点返回主界面

### 测试 2: 虚拟键盘弹出

**目标**: 验证点击输入框时虚拟键盘正确弹出

**步骤**:

1. **打开对话框**
   - [ ] 在主界面选择"开关量输入"
   - [ ] 按 Enter 键打开对话框

2. **测试 CustomTextField（英文键盘）**
   - [ ] 点击"保护名称"输入框
   - [ ] 验证虚拟键盘弹出
   - [ ] 验证键盘模式为英文键盘
   - [ ] 验证键盘显示在最顶层

3. **测试 CustomSpinBox（数字键盘）**
   - [ ] 点击"寄存器地址"输入框
   - [ ] 验证虚拟键盘弹出
   - [ ] 验证键盘模式为数字键盘
   - [ ] 验证键盘显示在最顶层

4. **测试 CustomComboBox（英文键盘）**
   - [ ] 点击"模块类型"下拉框
   - [ ] 如果可编辑，验证虚拟键盘弹出
   - [ ] 验证键盘模式为英文键盘

5. **测试键盘关闭**
   - [ ] 点击虚拟键盘的关闭按钮
   - [ ] 验证键盘正确关闭
   - [ ] 验证焦点返回输入框

**预期结果**:
- ✅ 点击输入框时虚拟键盘自动弹出
- ✅ 键盘模式根据组件类型自动选择
- ✅ 键盘显示在最顶层（Overlay.overlay）

### 测试 3: Tab 键焦点切换

**目标**: 验证 Tab 键在对话框内正确切换焦点

**步骤**:

1. **打开对话框**
   - [ ] 在主界面选择"电机控制"
   - [ ] 按 Enter 键打开对话框
   - [ ] 选择"基本配置" Tab

2. **测试 Tab 键切换**
   - [ ] 按 Tab 键
   - [ ] 验证焦点切换到第一个输入框（模块地址）
   - [ ] 验证焦点边框显示（3px 蓝色边框）

3. **继续按 Tab 键**
   - [ ] 按 Tab 键
   - [ ] 验证焦点切换到下一个输入框（输出通道）
   - [ ] 验证焦点边框正确显示

4. **测试 Enter 键弹出键盘**
   - [ ] 使用 Tab 键切换到任意输入框
   - [ ] 按 Enter 键
   - [ ] 验证虚拟键盘弹出

5. **测试 Space 键弹出键盘**
   - [ ] 使用 Tab 键切换到另一个输入框
   - [ ] 按 Space 键
   - [ ] 验证虚拟键盘弹出

**预期结果**:
- ✅ Tab 键在对话框内的输入框之间切换焦点
- ✅ 焦点边框清晰可见（3px 蓝色边框）
- ✅ Enter/Space 键弹出虚拟键盘

## 🎯 根本原因分析

### Loader 的宽度传递机制

在 QML 中，Loader 加载 Item 时的宽度传递有特殊规则：

1. **Item 有 implicitWidth**：
   ```qml
   Rectangle {
       implicitWidth: 800  // Loader 使用这个宽度
   }
   ```
   - Loader 会使用 Item 的 implicitWidth
   - Item 实际宽度 = implicitWidth

2. **Item 使用 anchors.fill**：
   ```qml
   Rectangle {
       anchors.fill: parent  // 填充 Loader
   }
   ```
   - **问题**：在 Loader 中，`parent` 可能不是 Loader 本身
   - **结果**：可能无法正确填充

3. **Item 使用 Layout 属性**：
   ```qml
   Rectangle {
       Layout.fillWidth: true  // ❌ 在 Loader 中无效
   }
   ```
   - Layout 属性只在 Layout 容器中有效
   - Loader 不是 Layout 容器

### 正确的方案

**在 Loader 中明确设置 Item 的宽度**：

```qml
// DeviceSettingsDialog.qml
Loader {
    id: analogInputPageLoader
    Layout.fillWidth: true
    Layout.fillHeight: true
    active: root.currentCategory === 2
    source: "pages/AnalogInputPage.qml"

    onLoaded: {
        if (item) {
            // ✅ 明确设置 Item 的宽度和高度
            item.width = Qt.binding(function() { return analogInputPageLoader.width })
            item.height = Qt.binding(function() { return analogInputPageLoader.height })
        }
    }
}
```

## ✅ 最终解决方案

### 方案 1：在 Loader 的 onLoaded 中绑定宽度（推荐）

**修改文件**：`DeviceSettingsDialog.qml`

**位置**：第 475-496 行（AnalogInputPage 的 Loader）

**修改**：
```qml
Loader {
    id: analogInputPageLoader
    Layout.fillWidth: true
    Layout.fillHeight: true
    active: root.currentCategory === 2
    source: "pages/AnalogInputPage.qml"

    onLoaded: {
        if (item) {
            console.log("✅ [DeviceSettingsDialog] AnalogInputPage 加载成功")
            // ✅ 2026-01-28 [FIX 100.300.73]: 明确绑定宽度和高度
            item.width = Qt.binding(function() { return analogInputPageLoader.width })
            item.height = Qt.binding(function() { return analogInputPageLoader.height })
            item.deviceId = root.deviceId
            item.deviceName = root.deviceName
        }
    }

    onStatusChanged: {
        if (analogInputPageLoader.status === Loader.Error) {
            console.error("❌ [DeviceSettingsDialog] AnalogInputPage 加载失败")
        }
    }
}
```

### 方案 2：在 AnalogInputPage 中使用 Binding（备选）

**修改文件**：`AnalogInputPage.qml`

**修改**：
```qml
Rectangle {
    id: root
    color: "transparent"

    // ✅ 2026-01-28 [FIX 100.300.73]: 使用 Binding 绑定到父容器宽度
    Binding on width {
        when: root.parent !== null
        value: root.parent.width
    }

    Binding on height {
        when: root.parent !== null
        value: root.parent.height
    }
}
```

## 🎯 技术要点

### Qt.binding() 的作用

```qml
item.width = Qt.binding(function() { return loader.width })
```

**作用**：
- 创建一个动态绑定
- 当 `loader.width` 变化时，`item.width` 自动更新
- 类似于 QML 中的 `width: loader.width`，但可以在 JavaScript 中使用

### 为什么 anchors.fill 不起作用

在 Loader 中：
```qml
Rectangle {
    anchors.fill: parent  // parent 是谁？
}
```

**问题**：
- `parent` 可能不是 Loader
- `parent` 可能是 Loader 的内部容器
- 导致 `anchors.fill` 无法正确工作

**解决**：
- 使用 `Qt.binding()` 明确绑定到 Loader 的宽度
- 避免依赖 `parent` 的不确定性

## ✅ 修改方案

### 1. 调整页面宽度

```qml
Rectangle {
    id: root
    implicitWidth: 1400  // 从 800 增加到 1400，支持两列布局
    implicitHeight: 600
}
```

### 2. 修改 ScrollView 配置

```qml
ScrollView {
    // 移除水平滚动条禁用
    // ScrollBar.horizontal.policy: ScrollBar.AlwaysOff
    ScrollBar.vertical.policy: ScrollBar.AsNeeded

    // 设置内容宽度
    contentWidth: Math.max(width, 1200)

    ColumnLayout {
        width: parent.width
        implicitWidth: 1200  // 两列布局需要的最小宽度
        implicitHeight: childrenRect.height
    }
}
```

### 3. 参数分组

**左列（5个参数）**:
1. 抱闸保持时间（秒）
2. 松闸保持时间（秒）
3. 最长允许时间（秒）
4. 抱闸延时时间（秒）
5. 急停抱闸时间（秒）

**右列（4个参数）**:
1. 抱闸输出点
2. 减速机输出点
3. 松闸到位
4. 抱闸到位

**顶部（单独一行）**:
- 使用状态（投入/禁用）

### 4. 布局结构

```qml
ColumnLayout {
    // 使用状态（单独一行）
    RowLayout {
        Layout.fillWidth: true
        // 投入/禁用 单选按钮
    }

    // 分割线
    Rectangle { ... }

    // 两列参数区域
    RowLayout {
        Layout.fillWidth: true
        spacing: 20

        // 左列
        ColumnLayout {
            Layout.fillWidth: true
            Layout.preferredWidth: parent.width / 2 - 10
            // 5个参数
        }

        // 右列
        ColumnLayout {
            Layout.fillWidth: true
            Layout.preferredWidth: parent.width / 2 - 10
            // 4个参数
        }
    }

    // 底部按钮
    RowLayout { ... }
}
```

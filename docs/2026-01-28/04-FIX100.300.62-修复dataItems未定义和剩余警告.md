# FIX 100.300.62 - 修复 QDS 中 dataItems 未定义和剩余警告

**日期**: 2026-01-28 01:00
**问题**:
1. systemConfig 和 operationLogDB 仍然显示 "is not defined"
2. Screen01 的 dataItems 未定义，导致图片无法切换

## 📋 问题分析

### 问题 1: systemConfig/operationLogDB 未定义

**原因**: main_qds.qml 没有暴露这两个对象为全局属性

**日志**:
```
Warning: ReferenceError: systemConfig is not defined
Warning: ReferenceError: operationLogDB is not defined
```

**修复**: 在 main_qds.qml 中添加 property alias

### 问题 2: dataItems 未定义

**原因**: Screen01Form 中的 data_row1_col1 等组件在 QDS 中可能未正确初始化

**日志**:
```
[Screen01] ⚠️ dataItems 未定义或为空，跳过初始化
[Screen01] ⚠️ dataItems 未定义或为空，跳过更新
```

**影响**:
- ❌ 键盘导航逻辑正常工作（索引变化正常）
- ❌ 但图片无法切换（因为 updateSelection() 被跳过）
- ❌ 用户不知道选中了哪个组件

## ✅ 修复方案

### 修复 1: 添加全局属性

**文件**: `src/qml/main_qds.qml`

**修改**:
```qml
// 修改前
property alias commonControl: mockBackend.commonControl
```

### 修复 2: 改进 dataItems 访问方式

**问题分析**:
- dataItems 数组在 Screen01Form 的 Component.onCompleted 中定义
- 但在 QDS 中，Screen01Form 的子组件可能还未完全初始化
- 导致 data_row1_col1 等为 undefined

**解决方案 A**: 延迟访问 dataItems（推荐）

```qml
Component.onCompleted: {
    console.log("[Screen01] ✅ 组件加载完成")

    // 延迟 100ms 等待 Screen01Form 的子组件初始化
    Qt.callLater(function() {
        if (screen01Form.dataItems && screen01Form.dataItems.length > 0) {
            console.log("[Screen01] 📊 dataItems 数量:", screen01Form.dataItems.length)
            console.log("[Screen01] 🔄 初始化选中状态...")
            updateSelection()
        } else {
            console.warn("[Screen01] ⚠️ dataItems 仍未定义，使用备用方案")
            // 备用方案：直接访问 Screen01Form 的子组件
            tryDirectAccess()
        }
    })

    console.log("[Screen01] 🎯 强制获取焦点...")
    root.forceActiveFocus()
}

function tryDirectAccess() {
    // 尝试直接访问 Screen01Form 的子组件
    var items = [
        screen01Form.data_row1_col1,
        screen01Form.data_row1_col2,
        screen01Form.data_row1_col3,
        screen01Form.data_row1_col4,
        screen01Form.data_row2_col1,
        screen01Form.data_row2_col2,
        screen01Form.data_row2_col3,
        screen01Form.data_row2_col4,
        screen01Form.data_row3_col1,
        screen01Form.data_row3_col2,
        screen01Form.data_row3_col3,
        screen01Form.data_row3_col4
    ]

    var validCount = 0
    for (var i = 0; i < items.length; i++) {
        if (items[i]) {
            validCount++
        }
    }

    console.log("[Screen01] 🔍 直接访问结果:", validCount, "个有效组件")

    if (validCount > 0) {
        // 更新 dataItems
        screen01Form.dataItems = items
        updateSelection()
    }
}
```

**解决方案 B**: 使用 Connections 监听 Screen01Form 的完成信号

```qml
Connections {
    target: screen01Form
    function onCompleted() {
        console.log("[Screen01] 📡 Screen01Form 完成信号")
        if (screen01Form.dataItems && screen01Form.dataItems.length > 0) {
            updateSelection()
        }
    }
}
```

**解决方案 C**: 在 Screen01Form.ui.qml 中延迟初始化 dataItems

```qml
// Screen01Form.ui.qml
Rectangle {
    property var dataItems: []  // 初始化为空数组

    Component.onCompleted: {
        // 延迟初始化
        dataItems = [
            data_row1_col1, data_row1_col2, data_row1_col3, data_row1_col4,
            data_row2_col1, data_row2_col2, data_row2_col3, data_row2_col4,
            data_row3_col1, data_row3_col2, data_row3_col3, data_row3_col4
        ]
        console.log("[Screen01Form] dataItems 已初始化:", dataItems.length)
    }
}
```

## 🎯 采用方案

**选择方案 A + C**:
1. 在 Screen01Form.ui.qml 中延迟初始化 dataItems
2. 在 Screen01.qml 中使用 Qt.callLater 延迟访问
3. 添加备用方案直接访问组件

**原因**:
- 最可靠，同时处理初始化和访问时机
- 有备用方案，确保在任何情况下都能工作
- 不依赖 Connections（可能在 QDS 中不稳定）

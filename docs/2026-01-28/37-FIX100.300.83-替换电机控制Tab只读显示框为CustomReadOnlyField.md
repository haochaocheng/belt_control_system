## 替换规则

### 修改前 (旧代码)
```qml
Rectangle {
    width: 200; height: 36
    color: "#2d3548"
    border.color: "#3d4556"; border.width: 1
    radius: 2
    Text {
        anchors.centerIn: parent
        text: "立即停机"
        font.pixelSize: 14
        color: "#E0E0E0"
    }
}
```

### 修改后 (新代码)
```qml
DeviceInfo.CustomReadOnlyField {
    width: 200
    height: 60
    text: "立即停机"
}
```

## 关键改进

### 1. 代码简化
- **旧代码**: 每个显示框需要11行代码
- **新代码**: 每个显示框只需4行代码
- **减少代码量**: 约63%

### 2. 样式统一
- 所有只读显示框使用统一的CustomReadOnlyField组件
- 统一高度为60px (原36px)
- 统一样式和交互效果

### 3. 维护性提升
- 样式修改只需修改CustomReadOnlyField组件
- 避免在多个文件中重复修改
- 代码更清晰易读

## 未修改内容

### 保留的组件
- **单选按钮**: 保留原有的Rectangle实现 (radius: 10, width: 20, height: 20)

- **单位文本**: 保留原有的Text组件 (如 "℃", "A")

这些组件有特定的交互逻辑或样式要求,不适合使用CustomReadOnlyField替换。

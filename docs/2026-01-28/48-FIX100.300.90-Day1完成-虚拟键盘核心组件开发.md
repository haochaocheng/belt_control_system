### 1. 创建 VirtualKeyboardManager.qml ✅

**文件**: `src/qml/components/device_info/VirtualKeyboardManager.qml`

**功能**：
- 统一管理所有输入框的虚拟键盘交互
- 自动检测触摸/键盘导航模式
- 根据输入框类型自动选择键盘模式（数字/英文/中文）
- 注册输入框并处理键盘弹出逻辑

**核心方法**：
```qml
- initialize(keyboard): 初始化键盘实例
- registerInputField(inputField): 注册输入框
- openKeyboardForField(inputField, touchMode): 打开键盘
- determineKeyboardMode(inputField): 确定键盘模式
- updateInputFieldValue(inputField, newValue): 更新输入框值
- closeKeyboard(): 关闭键盘
```

**键盘模式映射**：
- TextField → english（英文键盘）
- SpinBox → numeric（数字键盘）
- ComboBox（可编辑）→ english（英文键盘）

## 🔧 技术细节

### 键盘模式自动选择

```javascript
function determineKeyboardMode(inputField) {
    var typeName = inputField.toString()

    // 1. SpinBox → 数字键盘
    if (typeName.indexOf("SpinBox") !== -1) {
        return "numeric"
    }

    // 2. TextField with IntValidator/DoubleValidator → 数字键盘
    if (typeName.indexOf("TextField") !== -1) {
        if (inputField.validator) {
            var validatorType = inputField.validator.toString()
            if (validatorType.indexOf("IntValidator") !== -1 ||
                validatorType.indexOf("DoubleValidator") !== -1) {
                return "numeric"
            }
        }
        return "english"
    }

    // 3. ComboBox (editable) → 英文键盘
    if (typeName.indexOf("ComboBox") !== -1) {
        if (inputField.editable) {
            return "english"
        }
        return null  // 不可编辑的 ComboBox 不需要键盘
    }

    // 4. 默认 → 数字键盘
    return "numeric"
}
```

### 输入框注册机制

```qml
Component.onCompleted: {
    if (keyboardManager) {
        keyboardManager.registerInputField(root)
        console.log("✅ [CustomTextField] 已注册到键盘管理器")
    }
}
```

### 触摸和键盘导航统一处理

// 触摸模式

## 🔧 技术细节

### 键盘实例显示在最顶层

```qml
VirtualKeyboard.EnhancedVirtualKeyboard {
    id: virtualKeyboard
    parent: Overlay.overlay  // 显示在最顶层，不被其他组件遮挡
}
```

### 延迟加载机制

所有子页面使用 `Loader` 延迟加载，只有在选中时才加载：

```qml
Loader {
    active: root.currentCategory === 0  // 仅在选中时加载
    source: "pages/BasicConfigPage.qml"
}
```

### 键盘管理器传递

通过 `onLoaded` 回调将 `keyboardManager` 传递给子页面：

```qml
onLoaded: {
    if (item) {
        item.keyboardManager = keyboardManager
    }
}
```

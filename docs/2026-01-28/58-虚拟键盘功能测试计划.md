## 📋 测试概述

本次测试将验证虚拟键盘在所有设备配置页面的功能完整性和用户体验。

### 测试范围

- **触摸屏场景**: 点击输入框弹出虚拟键盘
- **键盘导航场景**: Tab + Enter/Space 弹出虚拟键盘
- **智能键盘模式**: 自动选择数字/英文键盘
- **焦点指示**: 焦点边框显示和切换

### 测试环境

- **设备**: RK3588（192.168.10.188）
- **用户名**: linaro
- **密码**: linaro
- **应用程序**: belt_control_system

### 1. 编译和部署

在执行测试之前，需要先编译和部署应用程序：

```powershell
# 编译和部署到设备 188
.\build-ubuntu24-apt.ps1 188
```

### 2. 连接设备

使用 SSH 连接到设备：

```bash
ssh linaro@192.168.10.188
```

### 3. 启动应用程序

在设备上启动应用程序：

```bash
# 进入应用程序目录
cd /path/to/app

# 启动应用程序
./belt_control_system
```

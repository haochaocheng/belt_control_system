#### 修改 3: 添加 openDeviceSettings 函数

**位置**: updateSelection 函数后

**代码**:
```qml
// ✅ 2026-01-28 [FIX 100.300.65]: 添加打开设备设置对话框函数
function openDeviceSettings() {
    console.log("[Screen01] 🔧 打开设备设置对话框，当前选中索引:", selectedIndex)

    // 创建并显示 DeviceSettingsDialog
    var component = Qt.createComponent("../../components/device_info/DeviceSettingsDialog.qml")
    if (component.status === Component.Ready) {
        var dialog = component.createObject(root, {
            // 可以传递参数给对话框
            // deviceIndex: selectedIndex
        })
        if (dialog) {
            dialog.open()
            console.log("[Screen01] ✅ DeviceSettingsDialog 已打开")
        } else {
            console.error("[Screen01] ❌ 无法创建 DeviceSettingsDialog 对象")
        }
    } else if (component.status === Component.Error) {
        console.error("[Screen01] ❌ DeviceSettingsDialog 加载失败:", component.errorString())
    }
}
```

**效果**:
- ✅ 按回车键打开设备设置对话框

- ✅ 可以传递当前选中的设备索引给对话框

## 📝 技术细节

### Qt.createComponent 动态创建对话框

**优点**:
- ✅ 按需创建，不占用内存
- ✅ 可以传递参数
- ✅ 对话框关闭后自动销毁

**用法**:
```qml
var component = Qt.createComponent("path/to/Dialog.qml")
if (component.status === Component.Ready) {
    var dialog = component.createObject(parent, {
        // 传递参数
        property1: value1,
        property2: value2
    })
    dialog.open()
}
```

### 双击事件处理

**注意事项**:
- MouseArea 的 onDoubleClicked 会在双击时触发
- 双击时也会触发两次 onClicked
- 使用 propagateComposedEvents: true 允许事件传递

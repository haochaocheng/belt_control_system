# FIX 100.300.69 - 修复模拟量参数设置两列布局问题

**日期**: 2026-01-28
**文件**: `src/qml/components/device_info/pages/AnalogInputPage.qml`
**问题**: 模拟量参数设置区域两列都排在左侧，右侧空白，参数项目名称和输入框没有对齐
**原因**: 列宽度设置不当，标签宽度不统一，缺少对齐方式

---

## 🐛 问题现象

### 布局问题

1. **两列都挤在左侧**：
   - 左列和右列都使用 `Layout.fillWidth: true`
   - 但没有明确设置宽度，导致布局引擎分配不均
   - 右侧出现大片空白区域

2. **参数名称和输入框不对齐**：
   - 左列标签宽度：100px
   - 右列标签宽度：100px
   - 但标签文字长度不一（"保护名称" vs "保护延时(秒)"）
   - 导致输入框起始位置参差不齐

3. **标签左对齐**：
   - 所有标签都是左对齐
   - 看起来很乱，不整齐

---

## 🔍 根本原因

### 1. 列宽度问题

**原始代码**：
```qml
ColumnLayout {
    Layout.fillWidth: true
    Layout.minimumWidth: 200  // ❌ 只设置最小宽度，没有明确宽度
    ...
}
```

**问题**：
- `Layout.fillWidth: true` 让两列都尝试填充剩余空间
- 但没有设置 `Layout.preferredWidth`，布局引擎无法正确分配
- 导致两列宽度不均，可能都挤在左侧

### 2. 标签宽度不统一

**原始代码**：
```qml
// 左列
Text {
    text: "保护名称:"  // 5个字符
    Layout.preferredWidth: 100
}

Text {
    text: "寄存器地址:"  // 6个字符
    Layout.preferredWidth: 100
}

// 右列
Text {
    text: "保护延时(秒):"  // 8个字符
    Layout.preferredWidth: 100
}
```

**问题**：
- 所有标签都是 100px 宽
- 但文字长度不同，导致输入框起始位置不对齐
- 标签左对齐，看起来参差不齐

---

## ✅ 解决方案

### 1. 明确设置列宽度

```qml
RowLayout {
    Layout.fillWidth: true
    spacing: 0

    // 左列
    ColumnLayout {
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 22  // ✅ 明确设置为一半宽度（减去分隔条和边距）
        ...
    }

    // 分隔条（宽度 2px + 左右边距各 20px = 42px）
    Rectangle {
        Layout.fillHeight: true
        Layout.preferredWidth: 2
        Layout.leftMargin: 20
        Layout.rightMargin: 20
        ...
    }

    // 右列
    ColumnLayout {
        Layout.fillWidth: true
        Layout.preferredWidth: parent.width / 2 - 22  // ✅ 明确设置为一半宽度
        ...
    }
}
```

**效果**：
- 左列和右列各占一半宽度
- 分隔条居中
- 右侧不再有空白区域

### 2. 统一标签宽度并右对齐

**左列**（标签较短）：
```qml
Text {
    text: "保护名称:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 120  // ✅ 统一标签宽度为 120px
    horizontalAlignment: Text.AlignRight  // ✅ 右对齐
}
```

**右列**（标签较长）：
```qml
Text {
    text: "保护延时(秒):"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.preferredWidth: 140  // ✅ 统一标签宽度为 140px（右列标签较长）
    horizontalAlignment: Text.AlignRight  // ✅ 右对齐
}
```

**效果**：
- 左列所有标签宽度统一为 120px
- 右列所有标签宽度统一为 140px
- 所有标签右对齐，输入框起始位置完全对齐
- 整体看起来整齐、专业

## 🎯 技术要点

### 1. QML 布局系统

**Layout.fillWidth vs Layout.preferredWidth**：
- `Layout.fillWidth: true`：尝试填充剩余空间
- `Layout.preferredWidth`：明确指定首选宽度
- **最佳实践**：两者结合使用，确保布局可预测

**动态宽度计算**：
```qml
Layout.preferredWidth: parent.width / 2 - 22
```
- `parent.width / 2`：父容器宽度的一半
- `- 22`：减去分隔条宽度（2px）和边距（左右各 20px）

### 2. 文本对齐

**horizontalAlignment**：
- `Text.AlignLeft`：左对齐（默认）
- `Text.AlignRight`：右对齐 ✅
- `Text.AlignHCenter`：居中对齐

**为什么使用右对齐**：
- 标签右对齐，输入框左对齐
- 形成视觉上的"对齐线"
- 符合表单设计的最佳实践

### 3. 标签宽度选择

**左列标签**：
- 最长标签："寄存器地址:"（6个字符 + 冒号）
- 字体大小：21px
- 选择宽度：120px（足够容纳最长标签）

**右列标签**：
- 最长标签："保护延时(秒):"（8个字符 + 冒号）
- 字体大小：21px
- 选择宽度：140px（足够容纳最长标签）

   - 左列和右列各占一半宽度
   - 分隔条居中
   - 右侧无空白区域

2. **输入框对齐**：

   - 右列所有输入框起始位置对齐

3. **响应式布局**：
   - 调整窗口大小，两列宽度自动调整

4. **不同标签长度**：
   - 短标签（如"单位:"）右对齐后，输入框仍然对齐
   - 长标签（如"保护延时(秒):"）不会溢出

## 🎉 完成总结

### 修复的问题

1. ✅ **两列宽度均等**：明确设置 `Layout.preferredWidth: parent.width / 2 - 22`

3. ✅ **标签右对齐**：添加 `horizontalAlignment: Text.AlignRight`
4. ✅ **右侧无空白**：两列各占一半宽度，充分利用空间

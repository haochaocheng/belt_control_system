# FIX 100.300.89 - 张力传感器配置参数改为两列布局

**日期**: 2026-01-28
**文件**: `src/qml/components/device_info/pages/TensionControlConfigPanel.qml`
**任务**: 将张力传感器配置参数从单列改为两列布局，与模拟量输入和制动器控制保持一致

---

## 📋 问题描述

张力传感器配置参数区域使用单列布局，导致：
- 纵向空间占用过多，需要频繁滚动
- 横向空间利用不充分
- 与模拟量输入、制动器控制的两列布局不一致

## ✅ 解决方案

### 1. 调整页面宽度

```qml
Rectangle {
    id: root
    // ✅ 2026-01-28 [FIX 100.300.89]: 改为两列布局，宽度从 800 增加到 1400
    implicitWidth: 1400  // 支持两列布局
    implicitHeight: 600
}
```

### 2. 修改 ScrollView 配置

```qml
ScrollView {
    // ✅ 2026-01-28 [FIX 100.300.89]: 移除水平滚动条禁用，支持两列布局
    // ScrollBar.horizontal.policy: ScrollBar.AlwaysOff
    ScrollBar.vertical.policy: ScrollBar.AsNeeded

    // ✅ 2026-01-28 [FIX 100.300.89]: 明确设置 contentWidth，确保两列布局正常显示
    contentWidth: Math.max(width, 1200)

    ColumnLayout {
        width: parent.width
        // ✅ 2026-01-28 [FIX 100.300.89]: 设置最小宽度和动态高度
        implicitWidth: 1200  // 两列布局需要的最小宽度
        implicitHeight: childrenRect.height
        spacing: 15
    }
}
```

### 3. 参数分组

**左列（7个参数）**:
1. 保护名称（固定为"张力"）
2. 保护类型（固定为"模拟量"）
3. 模块类型（ComboBox）
4. 寄存器地址（SpinBox）
5. 上限值（SpinBox）
6. 下限值（SpinBox）
7. 量程（SpinBox）

**右列（7个参数）**:
1. 单位（ComboBox，可编辑）
2. 保护延时（SpinBox，小数显示）
3. 播放次数（SpinBox）
4. 播放时长（SpinBox，小数显示）
5. 语音报警类型（RadioButton）
6. 报警文字（TextField，条件显示）
7. 音频文件（TextField + Button，条件显示）

### 4. 布局结构

```qml
ColumnLayout {
    // ✅ 2026-01-28 [FIX 100.300.89]: 两列布局 - 参数区域
    RowLayout {
        Layout.fillWidth: true
        spacing: 20

        // 左列
        ColumnLayout {
            Layout.fillWidth: true
            Layout.preferredWidth: parent.width / 2 - 10
            spacing: 15
            // 7个参数
        }

        // 右列
        ColumnLayout {
            Layout.fillWidth: true
            Layout.preferredWidth: parent.width / 2 - 10
            spacing: 15
            // 7个参数
        }
    }

    // 底部按钮
    RowLayout { ... }
}
```

### 5. 输入框宽度限制

所有输入框添加 `Layout.maximumWidth: 300`，避免右侧被截断：

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: 300  // ✅ 2026-01-28 [FIX 100.300.89]: 限制最大宽度
}
```

**特殊处理**：
- 音频文件输入框：`Layout.maximumWidth: 200`（留空间给浏览按钮）

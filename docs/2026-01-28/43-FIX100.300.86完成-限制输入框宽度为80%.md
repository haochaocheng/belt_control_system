# FIX 100.300.86 完成 - 限制输入框宽度为 80%

**日期**: 2026-01-28
**修复编号**: FIX 100.300.86
**状态**: ✅ 已完成

---

## 问题描述

在模拟量输入页面和制动器配置面板中，所有输入框（`CustomTextField`、`CustomSpinBox`、`CustomComboBox`）都使用 `Layout.fillWidth: true`，导致输入框宽度过大，占满整个可用空间，视觉效果不佳。

需要为所有输入框添加宽度限制，将宽度减少到 80%，使界面更加美观。

---

## 修复方案

### 修改规则

为所有 `CustomTextField`、`CustomSpinBox`、`CustomComboBox` 组件添加 `Layout.maximumWidth` 属性：

```qml
// 修改前
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
}

// 修改后
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: parent.width * 0.8  // ✅ 2026-01-28 [FIX 100.300.86]: 限制宽度为 80%
}
```

## 技术要点

### 1. Layout.maximumWidth 属性

```qml
Layout.fillWidth: true                      // 填充可用宽度
Layout.maximumWidth: parent.width * 0.8     // 但最大不超过父容器的 80%
```

### 2. 为什么使用 parent.width * 0.8

- **parent.width**: 父容器（RowLayout）的宽度
- **0.8**: 80% 的比例
- **效果**: 输入框最多占用父容器宽度的 80%，右侧留出 20% 的空白

### 3. 不影响其他组件

- **只修改输入组件**: `CustomTextField`、`CustomSpinBox`、`CustomComboBox`
- **不修改其他组件**: `Text`、`RadioButton`、`Button` 等保持不变

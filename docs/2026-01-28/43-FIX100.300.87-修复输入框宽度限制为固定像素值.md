# FIX 100.300.87 - 修复输入框宽度限制方案

**日期**: 2026-01-28
**文件**:
- `src/qml/components/device_info/pages/AnalogInputPage.qml`
- `src/qml/components/device_info/pages/BrakeConfigPanel.qml`

**任务**: 修复输入框宽度限制方案，使用固定像素值而不是百分比

---

## 📋 问题分析

### 原方案问题

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: parent.width * 0.8  // ❌ parent 指向 RowLayout，不是预期的宽度
}
```

**问题**：
- `parent.width` 指向的是 RowLayout，而 RowLayout 会自动调整大小
- RowLayout 的宽度 = 标签宽度(120px) + 间距(10px) + 输入框宽度
- 这导致 `parent.width * 0.8` 的计算结果不正确

### 布局结构

```
ColumnLayout (左列)
  └─ RowLayout (保护名称行)
       ├─ Text (标签, 120px)
       └─ CustomTextField (输入框) ← parent 是 RowLayout
```

---

## ✅ 解决方案

### 方案 1: 使用固定像素值（推荐）

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: 300  // ✅ 固定最大宽度 300px
}
```

### 方案 2: 使用 preferredWidth

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.preferredWidth: 300  // ✅ 首选宽度 300px
    Layout.maximumWidth: 400    // ✅ 最大宽度 400px
}
```

### 方案 3: 移除 fillWidth，使用固定宽度

```qml
DeviceInfo.CustomTextField {
    id: nameField
    implicitWidth: 300  // ✅ 固定宽度 300px
}
```

---

## 🎯 推荐方案

使用 **方案 1**：`Layout.maximumWidth: 300`

**理由**：
1. 简单直接，容易理解
2. 保留 `Layout.fillWidth: true`，在小屏幕上可以自适应
3. 在大屏幕上限制最大宽度为 300px
4. 不会被 RowLayout 的动态宽度影响

---

## 📊 宽度计算

### 左列可用宽度
- 总宽度：约 600px（两列各占 50%）
- 标签宽度：120px
- 间距：10px
- 输入框可用宽度：600 - 120 - 10 = 470px
- 限制为 80%：470 * 0.8 = 376px
- **推荐值：300px**（更保守，留出更多空白）

### 右列可用宽度
- 与左列相同：300px

# 虚拟键盘交互设计方案

**日期**: 2026-01-28
**目标**: 为设备参数设置界面设计完整的虚拟键盘交互方案，支持触摸屏和非触摸屏两种场景

---

## 📋 需求分析

### 使用场景

1. **触摸屏场景**（主要场景）
   - 用户直接点击输入框
   - 自动弹出虚拟键盘
   - 触摸操作输入数据

2. **非触摸屏场景**（备用场景）
   - 用户通过键盘导航键（上下左右、Tab）选择参数
   - 按 Enter 或 Space 键弹出虚拟键盘
   - 使用虚拟键盘输入数据

### 现有资源

项目已配置的虚拟键盘组件：

1. **VirtualKeyboardPopup.qml** - 简单数字键盘（500×320）
   - 数字键 0-9
   - 小数点、清除、退格
   - 确定、取消按钮

2. **EnhancedVirtualKeyboard.qml** - 增强型键盘（700×380-450）
   - 支持三种模式：数字、英文、中文
   - 模式切换器
   - 更大的尺寸，适合复杂输入

3. **NumericKeyboard.qml** - 纯数字键盘组件
4. **EnglishKeyboard.qml** - 英文键盘组件
5. **ChineseKeyboard.qml** - 中文拼音键盘组件

#### 核心组件

##### 1. VirtualKeyboardManager.qml（新建）

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

// ✅ 虚拟键盘管理器 - 统一管理所有输入框的键盘弹出
QtObject {
    id: root

    // ========== 单例实例 ==========
    property var keyboardInstance: null
    property var currentInputField: null
    property bool isTouchMode: false  // 触摸模式标志

    // ========== 键盘类型映射 ==========
    property var keyboardModeMap: ({
        "TextField": "english",      // 文本框 → 英文键盘
        "SpinBox": "numeric",        // 数字框 → 数字键盘
        "ComboBox": "english"        // 下拉框 → 英文键盘（可编辑时）
    })

    // ========== 初始化键盘实例 ==========
    function initialize(keyboard) {
        keyboardInstance = keyboard
        console.log("✅ [VirtualKeyboardManager] 键盘实例已初始化")
    }

    // ========== 注册输入框 ==========
    function registerInputField(inputField) {
        // 触摸屏场景：点击时弹出键盘
        inputField.onPressed.connect(function() {
            isTouchMode = true
            openKeyboardForField(inputField)
        })

        // 键盘导航场景：获得焦点时高亮，按 Enter/Space 弹出键盘
        inputField.Keys.onReturnPressed.connect(function() {
            isTouchMode = false
            openKeyboardForField(inputField)
        })

        inputField.Keys.onSpacePressed.connect(function() {
            if (!inputField.activeFocus) return
            isTouchMode = false
            openKeyboardForField(inputField)
        })
    }

    // ========== 打开键盘 ==========
    function openKeyboardForField(inputField) {
        if (!keyboardInstance) {
            console.error("❌ [VirtualKeyboardManager] 键盘实例未初始化")
            return
        }

        currentInputField = inputField

        // 确定键盘模式
        var mode = determineKeyboardMode(inputField)

        // 打开键盘
        keyboardInstance.openForField(
            inputField,
            function(newValue) {
                // 回调：更新输入框的值
                if (inputField.hasOwnProperty("value")) {
                    // SpinBox
                    inputField.value = parseFloat(newValue) || 0
                } else {
                    // TextField / ComboBox
                    inputField.text = newValue
                }
            },
            mode
        )

        console.log("✅ [VirtualKeyboardManager] 打开键盘 - 模式:", mode, "触摸模式:", isTouchMode)
    }

    // ========== 确定键盘模式 ==========
    function determineKeyboardMode(inputField) {
        var typeName = inputField.toString().split("_")[0]

        // 根据组件类型返回键盘模式
        if (typeName.includes("SpinBox")) {
            return "numeric"
        } else if (typeName.includes("TextField")) {
            // 检查是否只允许数字
            if (inputField.validator && inputField.validator.toString().includes("IntValidator")) {
                return "numeric"
            }
            return "english"
        } else if (typeName.includes("ComboBox")) {
            return inputField.editable ? "english" : null
        }

        return "numeric"  // 默认数字键盘
    }

    // ========== 关闭键盘 ==========
    function closeKeyboard() {
        if (keyboardInstance) {
            keyboardInstance.close()
        }
        currentInputField = null
    }
}
```

## 🎮 键盘导航方案

### 导航键映射

| 按键 | 功能 | 说明 |
|------|------|------|
| **Tab** | 下一个输入框 | 顺序切换焦点 |
| **Shift+Tab** | 上一个输入框 | 反向切换焦点 |
| **↑** | 上一行输入框 | 两列布局中向上移动 |
| **↓** | 下一行输入框 | 两列布局中向下移动 |
| **←** | 左列输入框 | 两列布局中向左移动 |
| **→** | 右列输入框 | 两列布局中向右移动 |
| **Enter** | 弹出虚拟键盘 | 编辑当前焦点输入框 |
| **Space** | 弹出虚拟键盘 | 编辑当前焦点输入框 |
| **Esc** | 关闭虚拟键盘 | 取消输入 |

## 📊 技术细节

### 键盘模式自动选择

```javascript
function determineKeyboardMode(inputField) {
    // 1. SpinBox → 数字键盘
    if (inputField instanceof SpinBox) {
        return "numeric"
    }

    // 2. TextField with IntValidator → 数字键盘
    if (inputField instanceof TextField) {
        if (inputField.validator instanceof IntValidator ||
            inputField.validator instanceof DoubleValidator) {
            return "numeric"
        }
        return "english"
    }

    // 3. ComboBox (editable) → 英文键盘
    if (inputField instanceof ComboBox && inputField.editable) {
        return "english"
    }

    // 4. 默认 → 数字键盘
    return "numeric"
}
```

1. **延迟加载键盘**：只在首次使用时创建键盘实例

## 📝 使用文档

### 触摸屏操作

1. **点击输入框** → 自动弹出虚拟键盘
2. **输入数据** → 使用虚拟键盘输入
3. **点击确定** → 保存输入并关闭键盘
4. **点击取消** → 放弃输入并关闭键盘

### 键盘导航操作

1. **Tab 键** → 切换到下一个输入框
2. **Shift+Tab** → 切换到上一个输入框
3. **↑↓←→ 键** → 在两列布局中导航
4. **Enter 或 Space** → 弹出虚拟键盘编辑当前输入框
5. **Esc 键** → 关闭虚拟键盘

### 注意事项

- 只读输入框不会弹出键盘
- 禁用输入框不会响应键盘导航
- ComboBox 只有在可编辑时才弹出键盘

# FIX 100.300.86 - 减少输入框宽度到 80%

**日期**: 2026-01-28
**文件**:
- `src/qml/components/device_info/pages/AnalogInputPage.qml`
- `src/qml/components/device_info/pages/BrakeConfigPanel.qml`

**任务**: 将输入框宽度减少到原来的 80%，避免右侧被截断

---

## 📋 问题描述

当前输入框使用 `Layout.fillWidth: true`，导致输入框填满所有可用空间，右侧边缘超出参数区域被截断。

## ✅ 解决方案

### 修改前

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true  // 填满所有空间
}
```

### 修改后

```qml
DeviceInfo.CustomTextField {
    id: nameField
    Layout.fillWidth: true
    Layout.maximumWidth: parent.width * 0.8  // 限制为父容器的 80%
}
```

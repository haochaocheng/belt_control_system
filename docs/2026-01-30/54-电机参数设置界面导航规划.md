## 🎯 导航目标

设计一个直观、高效的键盘导航系统，让用户可以使用方向键在界面的不同区域和参数之间快速切换。

## 📍 详细导航流程

### 1. 电机列表区（区域A）导航

```
初始状态：1号电机高亮

↓ 向下：2号电机 → 3号电机 → ... → 8号电机
↑ 向上：8号电机 → 7号电机 → ... → 1号电机

边界处理：
- 在1号电机按↑：跳转到底部按钮区（区域D）
- 在8号电机按↓：跳转到Tab导航区（区域B）

Enter：切换到选中的电机，刷新右侧参数区
→ 右：跳转到Tab导航区（区域B）
Tab：跳转到Tab导航区（区域B）
```

**焦点指示器**：
- 当前选中电机：蓝色边框 + 高亮背景
- 其他电机：灰色边框

---

### 2. Tab导航区（区域B）导航

```
初始状态：基本配置Tab高亮

← 左：前一个Tab
→ 右：后一个Tab

Tab顺序：
基本配置 → 电流保护 → 前轴承温度 → 后轴承温度 →
A相绕组 → B相绕组 → C相绕组 → 电机温度 → X轴振动

边界处理：
- 在基本配置按←：跳转到X轴振动（循环）
- 在X轴振动按→：跳转到基本配置（循环）
- 按↑：跳转到电机列表区（区域A）
- 按↓：跳转到参数区域（区域C）

Enter：切换到选中的Tab，刷新参数区
Tab：跳转到参数区域（区域C）
```

**焦点指示器**：
- 当前焦点Tab：蓝色边框 + 高亮背景
- 当前激活Tab：蓝色底色
- 其他Tab：灰色边框

---

### 3. 参数区域（区域C）导航

这是最复杂的区域，采用GridLayout（5行 × 2列）。

#### 3.1 参数索引映射

```
GridLayout布局（5行 × 2列）：

行0：[0] 是否投入          [1] 报警类型
行1：[2] 动作保护类型      [3] 故障保护类型
行2：[4] 温度量程          [5] 温度上限
行3：[6] 温度下限          [7] 输入点选择
行4：[8] 过滤干扰延时      [ ] 空
```

#### 3.2 方向键导航规则

```
↓ 向下：
  当前索引 → 下一行同列
  0 → 2 → 4 → 6 → 8（左列）
  1 → 3 → 5 → 7 → 底部按钮区（右列）

↑ 向上：
  当前索引 → 上一行同列
  8 → 6 → 4 → 2 → 0 → Tab导航区（左列）
  7 → 5 → 3 → 1 → Tab导航区（右列）

→ 向右：
  当前索引 → 同行右侧
  0 → 1, 2 → 3, 4 → 5, 6 → 7
  8 → 底部按钮区（第5行只有左侧）

← 向左：
  当前索引 → 同行左侧
  1 → 0, 3 → 2, 5 → 4, 7 → 6
  如果已在左列，跳转到电机列表区
```

#### 3.3 边界处理

```
顶部边界（行0）：
  按↑ → 跳转到Tab导航区（区域B）

底部边界（行4）：
  索引8按↓ → 跳转到底部按钮区（区域D）
  索引7按↓ → 跳转到底部按钮区（区域D）

左侧边界（列0）：
  索引0,2,4,6,8按← → 跳转到电机列表区（区域A）

右侧边界（列1）：
  索引1,3,5,7按→ → 保持在当前位置（或循环到左列）
  索引8按→ → 跳转到底部按钮区（区域D）
```

#### 3.4 Enter键行为

```
Enter键根据参数类型执行不同操作：

RadioButton组（索引0,1）：
  - 切换选项（投入/禁用，按次数/按时间）
  - 焦点保持在当前参数

只读字段（索引2,3,4,5,6,7,8）：
  - 显示提示信息（只读，不可编辑）
  - 焦点保持在当前参数
```

**焦点指示器**：
- 当前焦点参数：蓝色边框（3px）
- 其他参数：无边框

---

### 4. 底部按钮区（区域D）导航

```
初始状态：启动测试按钮高亮

← 左：前一个按钮
→ 右：后一个按钮

按钮顺序：
启动测试 → 停止测试 → 参数校验

边界处理：
- 在启动测试按←：跳转到参数校验（循环）
- 在参数校验按→：跳转到启动测试（循环）
- 按↑：跳转到参数区域（区域C）最后一个参数
- 按↓：跳转到电机列表区（区域A）

Enter：执行按钮功能
Tab：跳转到电机列表区（区域A）
```

**焦点指示器**：
- 当前焦点按钮：蓝色边框 + 高亮背景
- 其他按钮：灰色边框

## 🔄 区域间跳转规则

### Tab键跳转（顺序）

```
A（电机列表区）→ B（Tab导航区）→ C（参数区域）→ D（底部按钮区）→ A
```

### Shift+Tab跳转（反向）

```
D（底部按钮区）→ C（参数区域）→ B（Tab导航区）→ A（电机列表区）→ D
```

### 方向键跨区域跳转

```
区域A（电机列表）：
  ↑（在顶部）→ 区域D（底部按钮）
  ↓（在底部）→ 区域B（Tab导航）
  →         → 区域B（Tab导航）

区域B（Tab导航）：
  ↑         → 区域A（电机列表）
  ↓         → 区域C（参数区域，索引0）

区域C（参数区域）：
  ↑（在顶部）→ 区域B（Tab导航）
  ↓（在底部）→ 区域D（底部按钮）
  ←（在左侧）→ 区域A（电机列表）

区域D（底部按钮）：
  ↑         → 区域C（参数区域，索引8）
  ↓         → 区域A（电机列表）
```

## 📋 导航状态管理

### 全局导航状态

```qml
QtObject {
    id: navigationState

    // 当前焦点区域（A/B/C/D）
    property string currentArea: "A"

    // 各区域的焦点索引
    property int motorListIndex: 0      // 区域A：0-7
    property int tabIndex: 0            // 区域B：0-8
    property int paramIndex: 0          // 区域C：0-8
    property int buttonIndex: 0         // 区域D：0-2

    // 焦点历史（用于Esc返回）
    property var focusHistory: []
}
```

### 导航函数

```qml
// 切换焦点区域
function switchArea(newArea) {
    navigationState.currentArea = newArea
    updateFocusIndicators()
}

// 在当前区域内移动焦点
function moveInArea(direction) {
    switch(navigationState.currentArea) {
    case "A":
        moveInMotorList(direction)
        break
    case "B":
        moveInTabBar(direction)
        break
    case "C":
        moveInParamArea(direction)
        break
    case "D":
        moveInButtonArea(direction)
        break
    }
}

// 参数区域导航（最复杂）
function moveInParamArea(direction) {
    var currentIndex = navigationState.paramIndex
    var newIndex = currentIndex

    switch(direction) {
    case "Up":
        // 向上移动（同列）
        if (currentIndex >= 2) {
            newIndex = currentIndex - 2
        } else {
            // 跳转到Tab导航区
            switchArea("B")
            return
        }
        break

    case "Down":
        // 向下移动（同列）
        if (currentIndex <= 5) {
            newIndex = currentIndex + 2
        } else if (currentIndex === 6 || currentIndex === 7) {
            newIndex = 8  // 跳转到第5行
        } else {
            // 跳转到底部按钮区
            switchArea("D")
            return
        }
        break

    case "Left":
        // 向左移动（同行）
        if (currentIndex % 2 === 1) {
            newIndex = currentIndex - 1
        } else {
            // 跳转到电机列表区
            switchArea("A")
            return
        }
        break

    case "Right":
        // 向右移动（同行）
        if (currentIndex % 2 === 0 && currentIndex < 8) {
            newIndex = currentIndex + 1
        } else if (currentIndex === 8) {
            // 跳转到底部按钮区
            switchArea("D")
            return
        }
        break
    }

    navigationState.paramIndex = newIndex
    updateFocusIndicators()
}
```

## 🎯 用户体验优化

### 1. 智能焦点记忆

```
场景：用户从参数区域跳转到Tab导航区，然后返回参数区域

期望：焦点应该回到之前的参数位置，而不是重置到第一个参数

实现：使用focusHistory记录焦点历史
```

### 2. 循环导航

```
场景：用户在Tab导航区按→到最后一个Tab

期望：继续按→应该循环到第一个Tab

实现：在边界处理中实现循环逻辑
```

### 3. 快捷键支持

```
Home：跳转到当前区域的第一个元素
End：跳转到当前区域的最后一个元素
PageUp：跳转到上一个电机
PageDown：跳转到下一个电机
```

### 4. 视觉提示

```
- 焦点指示器：蓝色边框（3px）
- 悬停效果：浅蓝色背景
- 激活状态：深蓝色背景
- 禁用状态：灰色 + 50%透明度
```

## 📝 注意事项

### 1. 参数区域特殊处理

```
问题：第5行只有左侧参数（索引8），右侧为空

解决方案：
- 在索引8按→：跳转到底部按钮区
- 在索引7按↓：跳转到索引8（而不是底部按钮区）
- 在索引8按↓：跳转到底部按钮区
```

### 2. 只读字段处理

```
问题：大部分参数字段是只读的，按Enter没有实际操作

解决方案：
- 显示提示信息："此字段为只读，不可编辑"
- 或者直接忽略Enter键，焦点保持不变
```

### 3. RadioButton组处理

```
问题：RadioButton组（是否投入、报警类型）需要特殊处理

解决方案：
- 按Enter：切换选项
- 按←/→：在选项之间切换
- 按↑/↓：移动到其他参数
```

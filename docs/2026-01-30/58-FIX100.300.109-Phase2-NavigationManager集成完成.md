## 🎯 任务目标

将NavigationManager集成到MotorControlPage，实现平面导航逻辑。

---

## 📊 实施方案调整

### 原计划 vs 实际实施

**原计划**：
- 将NavigationManager集成到DeviceSettingsDialog

**实际实施**：
- 将NavigationManager集成到MotorControlPage

**调整原因**：
1. **结构不匹配**：DeviceSettingsDialog的结构（7个类别 + 右侧内容 + 底部按钮）与NavigationManager设计的结构（电机列表 + Tab导航 + 参数区域 + 底部按钮）不一致
2. **职责分离**：
   - DeviceSettingsDialog：整个对话框的导航（7个类别之间切换）
   - MotorControlPage：电机控制页面的导航（8个电机 + 9个Tab + 参数区域）
3. **更合理的架构**：NavigationManager专门为MotorControlPage的4区域导航设计

### Step 2: 添加NavigationManager实例

在MotorControlPage.qml中添加：

```qml
import "../" as DeviceInfo  // 导入 NavigationManager

DeviceInfo.NavigationManager {
    id: navigationManager

    // 初始化：从电机列表区开始
    Component.onCompleted: {
        currentArea = areaMotorList
        motorListIndex = 0
        tabIndex = 0
        paramIndex = 0
        buttonIndex = 0
    }

    // 监听电机列表索引变化
    onMotorListIndexChanged: function(newIndex) {
        root.currentMotorIndex = newIndex
        root.focusItemIndex = newIndex
    }

    // 监听Tab索引变化，切换参数区显示
    onTabIndexChanged: function(newIndex) {
        root.focusTabIndex = newIndex
        // 切换Tab时，参数区自动显示对应的参数
        if (motorConfigPanel.item) {
            motorConfigPanel.item.currentTabIndex = newIndex
        }
    }

    // 监听参数索引变化
    onParamIndexChanged: function(newIndex) {
        root.focusParamIndex = newIndex
    }

    // 监听按钮索引变化
    onButtonIndexChanged: function(newIndex) {
        // 底部按钮焦点处理（如果需要）
    }

    // 监听区域变化
    onAreaChanged: function(newArea) {
        // 根据区域更新 focusSubArea
        switch(newArea) {
        case areaMotorList:
            root.focusSubArea = 0
            root.focusItemIndex = motorListIndex
            break
        case areaTabBar:
            root.focusSubArea = 1
            break
        case areaParams:
            root.focusSubArea = 2
            break
        case areaButtons:
            root.focusSubArea = 3
            break
        }
    }
}
```

## 🎮 导航逻辑

### 4个导航区域

```
┌──────────────┐
│  电机列表区  │  区域A：8个电机（0-7）
│  (区域A)     │  ↑↓ 在电机之间切换
│              │  → 进入Tab导航区
└──────────────┘
        │
        → 右键
        │
        ▼
┌────────────────────────────────────────────────────────────┐
│  Tab导航区（区域B）                                         │
│  ┌────┬────┬────┬────┬────┬────┬────┬────┬────┐           │
│  │基本│电流│前轴│后轴│A相│B相│C相│电机│X轴│           │
│  │配置│保护│承温│承温│绕组│绕组│绕组│温度│振动│           │
│  └────┴────┴────┴────┴────┴────┴────┴────┴────┘           │
│                                                             │
│  ←→ 左右切换Tab，参数区自动显示对应参数                    │
│  ← 在第一个Tab按左键：返回电机列表区                       │
│  ↓ 向下：进入当前Tab对应的参数区第一个参数                 │
└────────────────────────────────────────────────────────────┘
        │
        ↓ 向下（进入第一个参数）
        ↑ 向上（从第一个参数返回）
        │
        ▼
┌────────────────────────────────────────────────────────────┐
│  参数区域（区域C）- GridLayout 5行×2列                     │
│                                                             │
│  ↑ 从第一个参数（0或1）：返回Tab导航区                     │
│  ↓ 从最后一个参数（7或8）：进入底部按钮区                  │
│  ←→ 在同行内左右切换                                       │
│  ↑↓ 在同列内上下移动                                       │
└────────────────────────────────────────────────────────────┘
        │
        ↓ 向下（从最后一个参数进入）
        ↑ 向上（返回最后一个参数）
        │
        ▼
┌────────────────────────────────────────────────────────────┐
│  底部按钮区（区域D）                                        │
│  ┌──────────┬──────────┬──────────┐                       │
│  │启动测试  │停止测试  │参数校验  │                       │
│  └──────────┴──────────┴──────────┘                       │
│                                                             │
│  ←→ 在按钮之间切换                                         │
│  ↑ 向上：返回参数区最后一个参数（索引8）                   │
│  ↓ 向下：循环回参数区最后一个参数（索引8）                 │
└────────────────────────────────────────────────────────────┘
```

### 关键特性

1. **平面导航**：整个界面是一个连续的平面，只用方向键导航
2. **Tab切换联动**：Tab左右切换时，参数区自动显示对应的参数
3. **自然边界处理**：在边界处按方向键，自然地跳转到相邻区域
4. **无Enter/Esc/Tab键**：简化操作，降低学习成本

## ⚠️ 注意事项

### 1. 现有导航逻辑保留

DeviceSettingsDialog的现有导航逻辑（电视遥控器式）保持不变，因为：
- 结构不同（7个类别 vs 4个区域）
- 职责不同（整体对话框导航 vs 页面内部导航）
- 已经稳定工作

### 2. 焦点指示器

参数区域的焦点指示器已经存在，通过`focusParamIndex`控制。NavigationManager的`onParamIndexChanged`信号会自动更新`focusParamIndex`，所以焦点指示器会自动工作。

### 3. Tab切换联动

NavigationManager的`onTabIndexChanged`信号会更新`motorConfigPanel.currentTabIndex`，这会触发参数区的切换显示。这个联动已经在代码中实现。

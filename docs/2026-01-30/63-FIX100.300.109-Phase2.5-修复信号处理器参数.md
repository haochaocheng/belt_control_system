## 🐛 问题描述

### 测试反馈

用户测试后反馈：**有错误**

### 错误日志

**第 181-198 行**：
```
✅ [MotorControlPage] Tab索引变化: undefined 参数区自动切换显示
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/MotorControlPage.qml:64: Error: Cannot assign [undefined] to int
✅ [NavigationManager] Tab索引: 1 （参数区自动切换显示）
```

**重复出现**：每次按右键切换Tab时都会出现这个错误。

### 问题分析

1. **NavigationManager 工作正常**：
   - Tab索引正确递增：0 → 1 → 2 → 3 → 4 ✅
   - 日志显示：`[NavigationManager] Tab索引: 1` ✅

2. **MotorControlPage 接收到事件**：
   - 日志显示：`[MotorControlPage] 接收键盘事件: Right` ✅

3. **信号处理器接收到 undefined**：
   - 日志显示：`Tab索引变化: undefined` ❌
   - 错误：`Cannot assign [undefined] to int` ❌

### 根本原因

**QML 自动生成的属性变化信号不传递参数！**

```qml
// 属性定义
property int tabIndex: 0

// ❌ 错误：QML 自动生成的信号不传递参数
onTabIndexChanged: function(newIndex) {
    console.log("Tab索引变化:", newIndex)  // undefined ❌
    root.focusTabIndex = newIndex  // 赋值 undefined 导致错误
}

// ✅ 正确：直接使用属性值
onTabIndexChanged: {
    console.log("Tab索引变化:", tabIndex)  // 正确的值 ✅
    root.focusTabIndex = tabIndex  // 正确赋值
}
```

**为什么会这样**：
- QML 的属性变化信号是**无参数信号**
- 信号只是通知"属性变化了"，不传递新值
- 新值应该直接从属性本身读取

## 💡 经验教训

### QML 信号机制的深入理解

1. **属性变化信号是无参数信号**：
   ```qml
   // 属性定义
   property int value: 0

   // QML 自动生成的信号（无参数）
   signal valueChanged()

   // ❌ 错误：尝试接收参数
   onValueChanged: function(newValue) {
       console.log(newValue)  // undefined
   }

   // ✅ 正确：直接使用属性
   onValueChanged: {
       console.log(value)  // 正确的值
   }
   ```

2. **自定义信号可以有参数**：
   ```qml
   // 自定义信号（有参数）
   signal areaChanged(string newArea)

   // ✅ 正确：可以接收参数
   onAreaChanged: function(newArea) {
       console.log("区域变化:", newArea)  // 正确
   }
   ```

3. **区分自动信号和自定义信号**：
   - **自动信号**：由 property 自动生成，无参数
   - **自定义信号**：手动定义，可以有参数

### 最佳实践

1. **属性变化信号处理器**：
   ```qml
   // ✅ 推荐：简洁语法，直接使用属性
   onTabIndexChanged: {
       console.log("Tab索引:", tabIndex)
       doSomething(tabIndex)
   }

   // ❌ 避免：使用 function 参数（会是 undefined）
   onTabIndexChanged: function(newIndex) {
       console.log("Tab索引:", newIndex)  // undefined
   }
   ```

2. **自定义信号处理器**：
   ```qml
   // ✅ 正确：自定义信号可以有参数
   signal customEvent(string message, int code)

   onCustomEvent: function(message, code) {
       console.log("消息:", message, "代码:", code)  // 正确
   }
   ```

### 调试技巧

1. **检查日志输出**：
   - 如果看到 "undefined"，说明使用了错误的参数语法
   - 应该直接使用属性值

2. **理解 QML 信号类型**：
   - 属性变化信号：无参数，直接读属性
   - 自定义信号：有参数，可以接收

3. **使用正确的语法**：
   ```qml
   // 属性变化信号：不要用 function(param)
   onPropertyChanged: { /* 直接使用 property */ }

   // 自定义信号：可以用 function(param)
   onCustomSignal: function(param) { /* 使用 param */ }
   ```

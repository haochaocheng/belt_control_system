## 🔧 修改内容

### 标签宽度修改

```qml
// 修改前
Layout.preferredWidth: 120  // ❌ 不够显示 7 个字符

// 修改后
Layout.preferredWidth: 160  // ✅ 2026-01-30 [FIX 100.300.107.3]: 从 120 增加到 160
```

### 原因分析

- 最长标签"动作保护类型:"有 7 个字符
- 字体大小 21 像素
- 7 × 21 = 147 像素（所需宽度）
- 原标签宽度 120 像素 < 147 像素
- **导致文字被截断**

### 解决方案

- 增加标签宽度到 160 像素
- 160 像素 > 147 像素 + 边距
- **所有标签文字完整显示**

## ⚠️ 遇到的问题和解决

### 问题 1: PowerShell 批量替换导致编码错误

**现象**：
- 使用 PowerShell 的 `Get-Content` 和 `Set-Content` 批量替换
- 导致文件编码变成 UTF-16 或其他编码
- QML 文件中的中文注释变成乱码
- QDS 运行时出现语法错误

**错误日志**：
```
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/FrontBearingTempTab.qml:171:21: Syntax error
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/RearBearingTempTab.qml:170:21: Syntax error
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/PhaseAWindingTab.qml:170:21: Syntax error
```

**解决方案**：
1. 使用 `git reset --soft HEAD~1` 回退错误提交
2. 使用 `git checkout -- .` 恢复文件到正确状态
3. 使用 `sed` 命令批量替换（保持 UTF-8 编码）
4. 重新提交并推送

## 💡 用户操作示例

### 示例1：修改前轴承温度的"是否投入"参数

```
步骤：
1. 初始状态：焦点在电机列表的1号电机
2. 按 → 或 Tab：跳转到Tab导航区
3. 按 → 两次：切换到"前轴承温度"Tab
4. 按 Enter：激活Tab，刷新参数区
5. 按 ↓：跳转到参数区域，焦点在索引0（是否投入）
6. 按 Enter：切换"投入/禁用"选项
7. 按 Esc：完成编辑

焦点路径：
区域A(电机0) → 区域B(Tab2) → 区域C(参数0) → 完成
```

### 示例2：查看温度上限参数

```
步骤：
1. 当前焦点在参数区域索引0（是否投入）
2. 按 ↓ 两次：跳转到索引4（温度量程）
3. 按 →：跳转到索引5（温度上限）
4. 查看参数值：80℃
5. 按 Enter：显示"此字段为只读"

焦点路径：
参数0 → 参数2 → 参数4 → 参数5
```

### 示例3：切换到下一个电机

```
步骤：
1. 当前焦点在参数区域
2. 按 Esc 或 ←：返回到电机列表区
3. 按 ↓：切换到2号电机
4. 按 Enter：激活2号电机，刷新参数区

焦点路径：
区域C → 区域A(电机0) → 区域A(电机1) → 刷新参数
```

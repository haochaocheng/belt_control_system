## 🎯 核心导航原则

### 只用方向键，不用Enter键

**导航方式**：只使用**上下左右**四个方向键
**平面导航**：整个界面是一个**连续的平面**，可以自由移动
**Tab切换联动**：Tab左右切换时，参数区**自动显示**对应的参数

## 🎮 详细导航规则

### 1. 电机列表区（区域A）

```
导航规则：
↑ 向上：切换到上一个电机（0-7）
↓ 向下：切换到下一个电机（0-7）
→ 向右：进入Tab导航区（基本配置Tab）
← 向左：保持不变（已在最左侧）

边界处理：
- 在第一个电机按↑：保持不变
- 在最后个电机按↓：保持不变
```

### 2. Tab导航区（区域B）

```
导航规则：
← 向左：切换到上一个Tab，参数区自动显示对应参数
→ 向右：切换到下一个Tab，参数区自动显示对应参数
↓ 向下：进入当前Tab对应的参数区第一个参数（索引0）
↑ 向上：保持不变

边界处理：
- 在第一个Tab（基本配置）按←：返回电机列表区
- 在最后一个Tab按→：保持不变

Tab切换联动：
- 切换Tab时，参数区自动切换显示对应的参数
- 例如：基本配置Tab → 显示基本配置参数
- 例如：电流保护Tab → 显示电流保护参数
```

### 3. 参数区域（区域C）

```
参数索引映射（GridLayout 5行×2列）：
行0：[0] 是否投入          [1] 报警类型
行1：[2] 动作保护类型      [3] 故障保护类型
行2：[4] 温度量程          [5] 温度上限
行3：[6] 温度下限          [7] 输入点选择
行4：[8] 过滤干扰延时      [ ] 空

导航规则：
↑ 向上：在同列内向上移动（index - 2）
↓ 向下：在同列内向下移动（index + 2）
← 向左：在同行内向左移动（index - 1）
→ 向右：在同行内向右移动（index + 1）

边界处理：
- 在第一个参数（0或1）按↑：返回Tab导航区
- 在最后一个参数（7或8）按↓：进入底部按钮区
- 在左列按←：保持不变
- 在右列按→：保持不变

列导航：
左列：0 → 2 → 4 → 6 → 8
右列：1 → 3 → 5 → 7

行导航：
行0：0 ↔ 1
行1：2 ↔ 3
行2：4 ↔ 5
行3：6 ↔ 7
行4：8（只有左侧）
```

### 4. 底部按钮区（区域D）

```
导航规则：
← 向左：切换到上一个按钮（0-2）
→ 向右：切换到下一个按钮（0-2）
↑ 向上：返回参数区最后一个参数（索引8）
↓ 向下：循环回参数区最后一个参数（索引8）

边界处理：
- 在第一个按钮按←：保持不变
- 在最后一个按钮按→：保持不变
```

## 📊 导航路径示例

### 示例1：从电机列表到参数区

```
步骤：
1. 初始状态：焦点在电机列表的1号电机
2. 按 →：进入Tab导航区（基本配置Tab）
3. 按 →：切换到电流保护Tab（参数区自动显示电流保护参数）
4. 按 ↓：进入电流保护参数区第一个参数（索引0：是否投入）

焦点路径：
电机列表(1号) → Tab导航(基本配置) → Tab导航(电流保护) → 参数区(0)
```

### 示例2：在参数区内移动

```
步骤：
1. 当前焦点：参数区索引0（是否投入）
2. 按 →：移动到索引1（报警类型）
3. 按 ↓：移动到索引3（故障保护类型）
4. 按 ←：移动到索引2（动作保护类型）
5. 按 ↓：移动到索引4（温度量程）

焦点路径：
参数0 → 参数1 → 参数3 → 参数2 → 参数4
```

### 示例3：从参数区返回Tab

```
步骤：
1. 当前焦点：参数区索引4（温度量程）
2. 按 ↑：移动到索引2（动作保护类型）
3. 按 ↑：移动到索引0（是否投入）
4. 按 ↑：返回Tab导航区（当前Tab）

焦点路径：
参数4 → 参数2 → 参数0 → Tab导航
```

### 示例4：从参数区到底部按钮

```
步骤：
1. 当前焦点：参数区索引6（温度下限）
2. 按 ↓：移动到索引8（过滤干扰延时）
3. 按 ↓：进入底部按钮区（启动测试按钮）
4. 按 →：切换到停止测试按钮
5. 按 ↑：返回参数区索引8

焦点路径：
参数6 → 参数8 → 按钮0 → 按钮1 → 参数8
```

### 示例5：Tab切换联动

```
步骤：
1. 当前焦点：Tab导航区（基本配置Tab）
   参数区显示：基本配置参数
2. 按 →：切换到电流保护Tab
   参数区自动显示：电流保护参数
3. 按 →：切换到前轴承温度Tab
   参数区自动显示：前轴承温度参数
4. 按 ←：切换回电流保护Tab
   参数区自动显示：电流保护参数

关键点：
- Tab切换时，参数区自动切换显示
- 不需要按Enter键
- 参数区焦点保持在索引0（第一个参数）
```

## 💡 关键设计原则

### 1. 平面导航

整个界面是一个**连续的平面**，焦点可以在4个区域之间自由移动，就像在一个大的网格上移动一样。

### 2. 自然的边界处理

- 在边界处按方向键，自然地跳转到相邻区域
- 例如：Tab区域按↓进入参数区，参数区第一个参数按↑返回Tab区域

### 3. Tab切换联动

- Tab左右切换时，参数区**自动显示**对应的参数
- 用户不需要额外操作，参数区会自动更新

### 4. 简化操作

- **只用方向键**，不用Enter、Esc、Tab等其他键
- 降低学习成本，提高操作效率

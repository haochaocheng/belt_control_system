```qml

    id: paramScrollView  // ✅ 添加 ID，用于 GridLayout 宽度计算
    anchors.fill: parent
    clip: true

    GridLayout {
        width: paramScrollView.width * 0.7  // ✅ 占 ScrollView 宽度的 70%
        columns: 4  // 4列：标签1、输入框1、标签2、输入框2
        columnSpacing: 10
        rowSpacing: 12

        // 运行状态标签
        Text {
            text: "运行状态:"
            font.pixelSize: 21
            color: "#9E9E9E"
            Layout.column: 0
            Layout.row: 0
            Layout.preferredWidth: 120
            horizontalAlignment: Text.AlignRight
        }

        // 运行状态输入（RadioButton 组）
        Item {
            Layout.column: 1
            Layout.row: 0
            Layout.fillWidth: true
            Layout.maximumWidth: 300
            implicitHeight: runningStateRow.implicitHeight  // ✅ 引用 Row 的 implicitHeight

            Row {
                id: runningStateRow
                anchors.fill: parent
                spacing: 30
                // ... RadioButton 内容
            }

            // 焦点指示器
            Rectangle {
                anchors.fill: parent
                color: "transparent"
                border.color: (root.focusParamIndex === 0) ? "#2196F3" : "transparent"
                border.width: (root.focusParamIndex === 0) ? 3 : 0
                radius: 4
                z: 10
            }
        }
    }
}
```

## 关键改进点

### 1. 使用 GridLayout 替代 RowLayout + ColumnLayout
- **优势**: 更简洁的布局代码，更容易维护
- **实现**: 使用 Layout.column 和 Layout.row 精确定位每个元素

### 2. 动态高度计算
- **原来**: 使用固定的 `implicitHeight: 60`
- **现在**: 使用 `implicitHeight: inputFieldId.implicitHeight`
- **优势**: 自适应输入控件的实际高度，避免布局问题

### 3. 焦点指示器位置
- **位置**: 放在 Item 容器内部，z: 10
- **优势**: 确保焦点指示器在输入控件前面显示

### 4. 统一样式
- **字体大小**: 统一为 21（参考 SwitchInputPage）
- **标签宽度**: 统一为 120
- **输入框最大宽度**: 统一为 300
- **GridLayout 宽度**: 占 ScrollView 宽度的 70%

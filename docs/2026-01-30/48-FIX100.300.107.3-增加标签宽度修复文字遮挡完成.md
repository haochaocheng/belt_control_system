## 🎯 任务目标

修复 BasicConfigTab 和 CurrentProtectionTab 中标签文字被遮挡的问题，特别是"动作保护类型"的"动"字被截断。

---

## 📋 问题描述

### 用户反馈

用户报告："动作保护类型的 '动'字还是被遮挡"

### 问题分析

1. **GridLayout 宽度**：已经设置为 90% 的 ScrollView 宽度
2. **标签宽度**：设置为 `Layout.preferredWidth: 120`
3. **字体大小**：`font.pixelSize: 21`
4. **最长标签**：
   - "动作保护类型:" - 7 个字符
   - "故障保护类型:" - 7 个字符
   - "过滤干扰延时:" - 7 个字符

### 根本原因

**标签宽度不足**：
- 7 个字符 × 21 像素/字符 = 147 像素
- 当前标签宽度：120 像素
- **120 像素 < 147 像素** → 文字被截断

---

## 🔧 解决方案

### 修改内容

将所有标签的 `Layout.preferredWidth` 从 **120** 增加到 **160**。

### 修改的文件

1. **BasicConfigTab.qml** (`src/qml/components/device_info/pages/BasicConfigTab.qml`)
2. **CurrentProtectionTab.qml** (`src/qml/components/device_info/pages/CurrentProtectionTab.qml`)

---

## 📊 修改前后对比

### 修改前

```qml
Text {
    text: "动作保护类型:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.column: 0
    Layout.row: 1
    Layout.preferredWidth: 120  // ❌ 不够显示 7 个字符
    horizontalAlignment: Text.AlignRight
}
```

**问题**：
- 120 像素不足以显示 7 个字符（需要 147 像素）
- 标签文字被截断，显示为"作保护类型:"（缺少"动"字）

### 修改后

```qml
Text {
    text: "动作保护类型:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.column: 0
    Layout.row: 1
    Layout.preferredWidth: 160  // ✅ 足够显示 7 个字符
    horizontalAlignment: Text.AlignRight
}
```

**优势**：
- 160 像素足够显示 7 个字符（147 像素）+ 右对齐边距
- 所有标签文字完整显示，不会被截断
- 保持统一的标签宽度

## 💡 经验总结

### 问题根源

1. **字体大小与标签宽度不匹配**：
   - 字体大小 21 像素
   - 7 个字符需要 147 像素
   - 标签宽度只有 120 像素
   - 导致文字被截断

2. **GridLayout 列宽分配**：
   - GridLayout 会根据 `Layout.preferredWidth` 分配列宽
   - 如果 `preferredWidth` 不够，文字会被截断
   - 需要确保 `preferredWidth` 足够显示最长的标签

### 解决方法

1. **计算最长标签所需宽度**：
   - 字符数 × 字体大小 = 所需像素
   - 7 × 21 = 147 像素

2. **增加标签宽度**：
   - 从 120 增加到 160
   - 留出足够的边距（160 - 147 = 13 像素）

3. **统一所有标签宽度**：
   - 所有标签使用相同的宽度（160）
   - 保持布局一致性

### 最佳实践

1. **标签宽度设置**：
   - 计算最长标签所需宽度
   - 增加 10-20 像素的边距
   - 统一所有标签宽度

2. **GridLayout 宽度设置**：
   - 根据标签宽度和输入框宽度计算总宽度
   - 设置为 ScrollView 宽度的 90-95%
   - 避免过宽导致横向滚动

3. **文字对齐**：
   - 标签使用右对齐（`horizontalAlignment: Text.AlignRight`）
   - 输入框使用左对齐或居中对齐
   - 保持视觉平衡

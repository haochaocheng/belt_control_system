# FIX 100.300.109 Phase 2.7 - 添加Tab自动滚动功能

**日期**: 2026-01-30
**任务编号**: FIX 100.300.109 Phase 2.7
**状态**: ✅ 完成

---

## 🐛 问题描述

### 测试反馈

用户测试后反馈：**可以到Y轴了，但是没有自动相左滑动效果，Y轴振动被右侧边框遮挡住了**

### 问题截图

从截图可以看到：
- Tab栏显示了多个Tab：基本配置、电流保护、前轴承温度、后轴承温度、A相绕组、B相绕组、C相绕组、电机温度、X轴振动
- **Y轴振动Tab被右侧边框遮挡，看不到**
- 用户需要手动拖动Tab栏才能看到Y轴振动

### 根本原因

**Tab栏使用Flickable支持横向滚动，但没有自动滚动到当前选中的Tab**：

```qml
Flickable {
    id: tabFlickable
    anchors.fill: parent
    clip: true
    contentWidth: tabRow.width
    flickableDirection: Flickable.HorizontalFlick
    boundsBehavior: Flickable.StopAtBounds

    // ❌ 缺少：没有监听 currentTabIndex 变化
    // ❌ 缺少：没有自动滚动到当前Tab
}
```

**为什么会这样**：
1. Tab栏有10个Tab，每个宽度120，总宽度1200
2. 视口宽度约为800-900（取决于窗口大小）
3. 当切换到后面的Tab（如Y轴振动，索引9）时
4. Flickable 的 `contentX` 保持不变（默认为0）
5. 导致Y轴振动Tab在视口之外，被遮挡

---

## 🔧 修复方案

### 解决方法

**添加自动滚动功能**：
1. 添加 `scrollToTab(tabIndex)` 函数，计算并滚动到目标Tab
2. 添加 `Connections` 监听器，监听 `currentTabIndex` 变化
3. 当Tab切换时，自动调用 `scrollToTab()` 滚动到可见位置

### 修复代码

**MotorConfigPanel.qml（修复前）**：
```qml
Flickable {
    id: tabFlickable
    anchors.fill: parent
    clip: true
    contentWidth: tabRow.width
    contentHeight: height
    flickableDirection: Flickable.HorizontalFlick
    boundsBehavior: Flickable.StopAtBounds

    // ❌ 缺少自动滚动功能
}
```

**MotorConfigPanel.qml（修复后）**：
```qml
// ✅ 2026-01-30 [FIX 100.300.109 Phase 2.7]: 添加自动滚动到当前Tab
Flickable {
    id: tabFlickable
    anchors.fill: parent
    clip: true
    contentWidth: tabRow.width
    contentHeight: height
    flickableDirection: Flickable.HorizontalFlick
    boundsBehavior: Flickable.StopAtBounds

    // ✅ 2026-01-30 [FIX 100.300.109 Phase 2.7]: 自动滚动到当前Tab
    function scrollToTab(tabIndex) {
        if (tabIndex < 0) return

        // 每个Tab宽度120，计算目标Tab的位置
        var tabWidth = 120
        var targetX = tabIndex * tabWidth

        // 计算需要滚动到的位置，使目标Tab居中显示
        var centerX = targetX - (width / 2) + (tabWidth / 2)

        // 限制在有效范围内
        centerX = Math.max(0, Math.min(centerX, contentWidth - width))

        // 平滑滚动到目标位置
        contentX = centerX
    }

    // 监听 currentTabIndex 变化，自动滚动
    Connections {
        target: root
        function onCurrentTabIndexChanged() {
            tabFlickable.scrollToTab(root.currentTabIndex)
        }
    }
}
```

## 📊 滚动逻辑详解

### 计算公式

**目标Tab位置**：
```javascript
var targetX = tabIndex × 120  // 每个Tab宽度120
```

**居中显示位置**：
```javascript
var centerX = targetX - (width / 2) + (tabWidth / 2)
```

**限制在有效范围**：
```javascript
centerX = Math.max(0, Math.min(centerX, contentWidth - width))
```

### 示例计算

**假设**：
- 视口宽度：800
- Tab宽度：120
- 总Tab数：10
- 内容宽度：1200

**切换到Y轴振动（索引9）**：
```
targetX = 9 × 120 = 1080
centerX = 1080 - (800 / 2) + (120 / 2) = 1080 - 400 + 60 = 740
限制范围：0 到 (1200 - 800) = 400
最终 contentX = 400（最大值）
```

**结果**：
- Tab栏滚动到最右侧
- Y轴振动Tab完全可见，不被遮挡

## 💡 经验教训

### Flickable 自动滚动的最佳实践

1. **监听内容变化**：
   ```qml
   Connections {
       target: root
       function onCurrentTabIndexChanged() {
           flickable.scrollToItem(root.currentTabIndex)
       }
   }
   ```

2. **计算滚动位置**：
   ```qml
   function scrollToItem(index) {
       var targetX = index × itemWidth
       var centerX = targetX - (width / 2) + (itemWidth / 2)
       centerX = Math.max(0, Math.min(centerX, contentWidth - width))
       contentX = centerX
   }
   ```

3. **居中显示**：
   - 不要只滚动到目标位置（`contentX = targetX`）
   - 应该居中显示（`contentX = targetX - width/2 + itemWidth/2`）
   - 提供更好的用户体验

### UI/UX 设计原则

1. **自动化用户操作**：
   - 用户不应该需要手动滚动才能看到内容
   - 系统应该自动滚动到相关内容

2. **视觉反馈**：
   - 当前选中的项应该始终可见
   - 最好居中显示，提供清晰的视觉焦点

3. **平滑过渡**：
   - 使用 `contentX` 直接设置（QML会自动平滑过渡）
   - 或使用 `Behavior on contentX` 自定义动画

### 调试技巧

1. **检查Flickable状态**：
   ```qml
   console.log("contentX:", contentX)
   console.log("contentWidth:", contentWidth)
   console.log("width:", width)
   console.log("可滚动范围:", contentWidth - width)
   ```

2. **验证滚动逻辑**：
   ```qml
   function scrollToTab(tabIndex) {
       console.log("滚动到Tab:", tabIndex)
       console.log("目标位置:", targetX)
       console.log("居中位置:", centerX)
       console.log("最终位置:", contentX)
   }
   ```

3. **测试边界情况**：
   - 第一个Tab（索引0）
   - 最后一个Tab（索引9）
   - 中间的Tab

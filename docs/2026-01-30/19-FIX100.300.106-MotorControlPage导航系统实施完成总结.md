```qml
Connections {
    target: root
    enabled: motorControlPageLoader.item !== null

    function onCurrentFocusAreaChanged() {
        if (motorControlPageLoader.item && root.currentCategory === 3) {
            if (root.currentFocusArea === 2) {
                // 焦点进入内容区域，默认在电机列表区域
                motorControlPageLoader.item.focusSubArea = 0
                motorControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 焦点离开内容区域，清除焦点
                motorControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentCategoryChanged() {
        if (motorControlPageLoader.item) {
            if (root.currentFocusArea === 2 && root.currentCategory === 3) {
                // 切换到电机控制类别，设置焦点
                motorControlPageLoader.item.focusSubArea = 0
                motorControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 切换到其他类别，清除焦点
                motorControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentContentItemIndexChanged() {
        if (motorControlPageLoader.item &&
            root.currentFocusArea === 2 &&
            root.currentCategory === 3) {
            // 在电机列表中导航
            motorControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
        }
    }
}
```

## 📊 技术实现细节

### 1. 三区域导航系统

**区域定义**:
- `focusSubArea === 0`: 电机列表区域（左侧，8个电机）
- `focusSubArea === 1`: Tab 区域（顶部 Tab 栏，10个 Tab）
- `focusSubArea === 2`: 参数区域（当前 Tab 的参数编辑）

**导航流程**:
1. 打开对话框 → 焦点在左侧类别列表
2. 右键 → 焦点进入电机列表（电机列表区域）
3. 右键 → 焦点进入 Tab 区域（第一个 Tab）
4. 下键 → 焦点进入参数区域（第一个参数）
5. 上/下键 → 在参数间移动
6. 回车键 → 打开虚拟键盘或触发操作
7. ESC 键 → 关闭虚拟键盘，焦点返回参数区域
8. ESC 键 → 关闭对话框，焦点返回主界面

### 2. 焦点指示器

**视觉效果**:
- 蓝色边框（#2196F3）
- 边框宽度：3px
- 圆角：4px
- z-index：10（电机列表）或 11（Tab 按钮）

**三种状态**:
1. 电机列表焦点：`focusItemIndex === index`
2. Tab 焦点：`focusSubArea === 1 && focusTabIndex === index`
3. 参数焦点：`focusSubArea === 2 && focusParamIndex === index`（待实施）

### 3. 属性绑定

使用 `Qt.binding()` 确保属性动态更新：
```qml
item.focusItemIndex = Qt.binding(function() { return root.focusItemIndex })
```

这样当父组件的 `focusItemIndex` 变化时，子组件会自动更新。

## 🔍 关键技术点

### 1. 焦点管理

**问题**: 如何在三个区域间切换焦点？

**解决**: 使用 `focusSubArea` 属性标识当前焦点所在区域，配合 `focusItemIndex`、`focusTabIndex`、`focusParamIndex` 精确定位焦点位置。

### 2. 属性传递

**问题**: 如何将焦点属性从父组件传递到子组件？

**解决**: 使用 `Qt.binding()` 创建动态绑定，确保属性变化时子组件自动更新。

### 3. 焦点指示器

**问题**: 如何为不同类型的控件添加统一的焦点指示器？

**解决**: 在控件外层添加 Rectangle，使用条件表达式控制边框颜色和宽度，使用 z-index 确保指示器在最上层。

### 4. 焦点同步

**问题**: 如何在对话框导航时同步子组件的焦点状态？

**解决**: 使用 Connections 监听父组件的焦点变化事件，自动更新子组件的焦点属性。

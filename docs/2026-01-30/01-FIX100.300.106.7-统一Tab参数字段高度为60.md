# FIX 100.300.106.7 - 统一 Tab 参数字段高度为 60

**日期**: 2026-01-30
**类型**: UI 样式统一
**影响范围**: 10 个电机控制 Tab 页面

---

## 问题描述

所有电机控制 Tab 页面的参数字段高度为 40，与 `CustomReadOnlyField` 的默认高度 60 不一致，导致界面不统一。

## 修改内容

### 修改的文件（共 10 个）

所有文件位于 `src/qml/components/device_info/pages/` 目录：

1. **BasicConfigTab.qml** - 基本配置（10 处修改）
2. **CurrentProtectionTab.qml** - 电流保护（18 处修改）
3. **FrontBearingTempTab.qml** - 前轴承温度保护（18 处修改）
4. **RearBearingTempTab.qml** - 后轴承温度保护（18 处修改）
5. **PhaseAWindingTab.qml** - A相绕组保护（18 处修改）
6. **PhaseBWindingTab.qml** - B相绕组保护（18 处修改）
7. **PhaseCWindingTab.qml** - C相绕组保护（18 处修改）
8. **MotorTempTab.qml** - 电机温度保护（18 处修改）
9. **XAxisVibrationTab.qml** - X轴振动保护（18 处修改）
10. **YAxisVibrationTab.qml** - Y轴振动保护（18 处修改）

**总计**: 172 处修改

### 修改前

```qml
RowLayout {
    Layout.fillWidth: true
    Layout.preferredHeight: 40  // 太小
    spacing: 10
```

### 修改后

```qml
RowLayout {
    Layout.fillWidth: true
    Layout.preferredHeight: 60  // ✅ 2026-01-30 [FIX 100.300.106.7]: 统一输入框高度为 60（参考 CustomReadOnlyField）
    spacing: 10
```

## 修改方法

使用 `sed` 命令批量替换：

```bash
cd "src/qml/components/device_info/pages"
for file in BasicConfigTab.qml CurrentProtectionTab.qml FrontBearingTempTab.qml RearBearingTempTab.qml PhaseAWindingTab.qml PhaseBWindingTab.qml PhaseCWindingTab.qml MotorTempTab.qml XAxisVibrationTab.qml YAxisVibrationTab.qml; do
    sed -i 's/Layout\.preferredHeight: 40/Layout.preferredHeight: 60  \/\/ ✅ 2026-01-30 [FIX 100.300.106.7]: 统一输入框高度为 60（参考 CustomReadOnlyField）/g' "$file"
done
```

## 影响分析

### 正面影响

1. **界面统一**: 所有参数字段高度一致，视觉效果更协调
2. **与 CustomReadOnlyField 一致**: 高度匹配只读字段的默认高度

1. **布局变化**: 参数区域整体高度增加，可能需要更多滚动
2. **视觉密度**: 参数之间的间距感觉更大

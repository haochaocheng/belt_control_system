## 🔍 问题分析

### 问题1：布局冲突

**原因**：在 Row 布局中，Item 容器使用了 `anchors.verticalCenter: parent.verticalCenter`，这会导致布局冲突。

**影响的代码**（5 个参数字段）：
```qml
Row {
    Text { /* 参数名称标签 */ }

    Item {
        width: 120
        height: 36
        anchors.verticalCenter: parent.verticalCenter  // ❌ 导致布局冲突

        Rectangle { /* 焦点指示器 */ }
        CustomSpinBox { /* 输入控件 */ }
    }
}
```

**为什么会冲突**：
- Row 布局会自动管理子元素的水平位置
- `anchors.verticalCenter` 会覆盖 Row 的自动布局
- 导致 Item 容器及其内部控件不显示

### 问题2：缺少右花括号

**原因**：第 66 行的内部 Row 缺少关闭花括号 `}`

**代码结构**：
```qml
Item {  // 第 52 行：焦点指示器容器
    Rectangle { /* 焦点指示器 */ }

    Row {  // 第 66 行：内部 Row（包含两个 RadioButton）
        Row { /* 投入选项 */ }
        Row { /* 禁用选项 */ }
    // ❌ 缺少关闭花括号
}  // 第 145 行：关闭了 Item，但内部 Row 未关闭
```

## 🔍 技术要点

### 1. Row 布局中的 anchors 使用

**规则**：在 Row/Column 等布局中，子元素不应使用 anchors 定位

**原因**：
- Row/Column 会自动管理子元素的位置
- anchors 会覆盖自动布局，导致冲突
- 可能导致元素不显示或位置错误

**正确做法**：
```qml
Row {
    Text {
        anchors.verticalCenter: parent.verticalCenter  // ✅ 可以使用
    }

    Item {
        // ❌ 不要使用 anchors.verticalCenter
        width: 120
        height: 36
    }
}
```

### 2. QML 花括号匹配

**工具**：可以使用编辑器的括号匹配功能检查

**技巧**：
- 使用注释标记每个花括号的作用
- 保持一致的缩进
- 使用 QML 格式化工具

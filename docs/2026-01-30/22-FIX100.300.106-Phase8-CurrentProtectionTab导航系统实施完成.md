## 📊 技术实现细节

### 1. 焦点指示器模式

**结构**:
```
Row
├─ Text (参数名称标签)
└─ Item (焦点指示器容器)
   ├─ Rectangle (焦点指示器，z: 10)
   └─ Row/CustomReadOnlyField (输入控件)
```

**关键点**:
- 焦点指示器只包含输入控件，不包含标签
- 使用 Item 容器包装输入控件
- 焦点指示器在最上层（z: 10）
- 蓝色边框（#2196F3，3px）

### 2. 参数字段类型

**RadioButton 组**（2个）:
- 是否投入：投入/禁用
- 报警类型：按次数/按时间

**只读字段**（7个）:
- 动作保护类型：立即停机
- 故障保护类型：紧急停机
- 电流量程：0-100A
- 电流上限：80A
- 电流下限：-10A
- 过滤干扰延时：0.5 秒
- 输入点选择：DI-0

### 3. 与 BasicConfigTab 的区别

**BasicConfigTab**:
- 5 个参数字段
- 3 个 SpinBox（可编辑）
- 1 个 RadioButton 组
- 1 个只读字段

**CurrentProtectionTab**:
- 9 个参数字段
- 2 个 RadioButton 组
- 7 个只读字段（使用 CustomReadOnlyField）
- 无可编辑的 SpinBox

## 🔍 关键技术点

### 1. 只读字段的焦点指示器

**问题**: 只读字段如何添加焦点指示器？

**解决**: 使用 Item 容器包装 CustomReadOnlyField，在容器上添加焦点指示器 Rectangle。

**示例**:
```qml
Item {
    width: 200
    height: 60

    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 2) ? 3 : 0
        radius: 4
        z: 10
    }

    DeviceInfo.CustomReadOnlyField {
        anchors.fill: parent
        text: "立即停机"
    }
}
```

### 2. RadioButton 组的焦点指示器

**问题**: RadioButton 组如何添加焦点指示器？

**解决**: 使用 Item 容器包装整个 Row（包含两个 RadioButton），在容器上添加焦点指示器 Rectangle。

**示例**:
```qml
Item {
    width: 200
    height: 40

    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 0) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 0) ? 3 : 0
        radius: 4
        z: 10
    }

    Row {
        anchors.fill: parent
        spacing: 30
        Row { /* 投入选项 */ }
        Row { /* 禁用选项 */ }
    }
}
```

## 🎯 预期效果

### 导航流程

1. **打开对话框** → 焦点在左侧类别列表
2. **右键** → 焦点进入电机列表（电机列表区域）
3. **右键** → 焦点进入 Tab 区域（第一个 Tab）
4. **左/右键** → 在 Tab 间切换
5. **下键** → 焦点进入参数区域（第一个参数）
   - 蓝色边框高亮当前参数字段
6. **上/下键** → 在参数间移动
   - 焦点指示器跟随移动
7. **回车键** → 触发参数输入
   - RadioButton 组：切换选中状态
   - 只读字段：只显示日志
8. **ESC 键** → 关闭对话框
   - 焦点返回主界面 Screen01

### 焦点指示器效果

- **蓝色边框**（3px）：清晰标识当前焦点位置
- **只包含输入框**：参数名称标签在边框外
- **平滑过渡**：焦点切换时视觉效果流畅

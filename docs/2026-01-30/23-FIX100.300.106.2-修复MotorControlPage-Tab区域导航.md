# 修复 MotorControlPage Tab 区域导航

**日期**: 2026-01-30
**任务编号**: FIX 100.300.106.2
**状态**: ✅ 已完成

---

## 🐛 问题描述

用户反馈：**无法从参数区域向上导航到 Tab 区域**

从截图可以看到，电机控制页面的布局是：

```
顶部：关闭、保存、退出按钮（右上角）
中间：电机列表（左侧） + Tab区域（顶部） + 参数区域（中间）
底部：启动测试、停止测试、参数校验按钮
```

但是当前的导航系统无法从参数区域向上导航到 Tab 区域。

---

## 🔍 问题分析

### 根本原因

**focusSubArea 定义不清晰**，导致导航逻辑混乱。

### 架构分析

```
DeviceSettingsDialog (currentFocusArea = 2, 右侧内容区域)
  └─ MotorControlPage (focusSubArea: 0=电机列表, 1=Tab, 2=参数)
      ├─ MyMotorListPanel (focusItemIndex)
      └─ MotorConfigPanel (focusSubArea: 从 MotorControlPage 传递)
          ├─ Tab 区域 (focusTabIndex)
          └─ 参数区域 (focusParamIndex)
```

### 问题点

1. **MotorControlPage 的 focusSubArea 定义不明确**：
   - 原定义：`0:电机列表区域 1:Tab区域 2:参数区域`
   - 但没有明确说明这是从 MotorControlPage 的视角

2. **MotorConfigPanel 的 focusSubArea 定义混乱**：
   - 原定义：`0:电机列表 1:Tab区域 2:参数区域`
   - 但电机列表不在 MotorConfigPanel 内部，而是在 MyMotorListPanel 中
   - 这导致 focusSubArea 的值与实际组件不匹配

3. **focusSubArea 传递不正确**：
   - MotorControlPage 没有正确地将 focusSubArea 传递给 MotorConfigPanel

## 📊 导航流程

### 完整导航流程

1. **左侧类别列表** → **右键** → **电机列表**（focusSubArea = 0）
   - 焦点在 MyMotorListPanel
   - 蓝色边框显示在电机列表项上

2. **电机列表** → **右键** → **Tab 区域**（focusSubArea = 1）
   - 焦点在 MotorConfigPanel 的 Tab 栏
   - 蓝色边框显示在 Tab 按钮上

3. **Tab 区域** → **下键** → **参数区域**（focusSubArea = 2）
   - 焦点在 MotorConfigPanel 的参数区域
   - 蓝色边框显示在参数字段上

4. **参数区域** → **上键** → **Tab 区域**（focusSubArea = 1）
   - 焦点返回 Tab 栏
   - 蓝色边框显示在 Tab 按钮上

5. **Tab 区域** → **左键** → **电机列表**（focusSubArea = 0）
   - 焦点返回电机列表
   - 蓝色边框显示在电机列表项上

### 焦点指示器逻辑

**Tab 区域焦点指示器**（MotorConfigPanel.qml:140）:

## 🎯 技术要点

### 1. focusSubArea 的层级关系

**MotorControlPage 的 focusSubArea**：
- 管理整个页面的三个子区域（电机列表、Tab、参数）
- 值：0, 1, 2

**MotorConfigPanel 的 focusSubArea**：
- 接收 MotorControlPage 传递的值
- 根据值决定显示哪个区域的焦点指示器
- 值：0（不显示焦点）, 1（显示 Tab 焦点）, 2（显示参数焦点）

### 2. 属性绑定

使用 `Qt.binding()` 确保属性动态更新：

```qml
item.focusSubArea = Qt.binding(function() { return root.focusSubArea })
```

这样当 `root.focusSubArea` 变化时，`item.focusSubArea` 会自动更新。

### 3. 焦点指示器条件

**关键点**：焦点指示器的条件必须同时检查两个条件：
1. **区域条件**：`focusSubArea === 1`（焦点在 Tab 区域）
2. **索引条件**：`focusTabIndex === index`（焦点在当前 Tab）

只有两个条件都满足时，才显示蓝色边框。

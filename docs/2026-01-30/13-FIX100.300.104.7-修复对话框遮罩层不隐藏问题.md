# 修复对话框遮罩层不隐藏问题

**日期**: 2026-01-30
**问题编号**: FIX 100.300.104.7
**状态**: ✅ 已完成

---

## 🐛 问题描述

对话框关闭后，主界面可以导航（焦点恢复成功），但是主界面被一个很大的半透明矩形遮挡，看起来很暗。

**用户反馈**：
> "退出导航后，主界面可以导航了，但是主界面被什么遮挡了，比较暗，是一个很大的矩形半透明遮挡"

**现象**：
- ✅ 焦点恢复成功（主界面可以导航）
- ❌ 半透明黑色遮罩层还在屏幕上
- ❌ 主界面看起来很暗，被遮挡

---

## 🔍 问题分析

### DeviceSettingsDialog 结构

```qml
Item {
    id: modalContainer  // 最外层容器
    anchors.fill: parent
    z: 1000

    MouseArea {
        id: modalOverlay  // 模态遮罩
        anchors.fill: parent
        z: 999

        Rectangle {
            anchors.fill: parent
            color: "#80000000"  // 半透明黑色背景 ← 这个还在显示！
        }
    }

    FocusScope {
        id: dialogFocusScope

        Rectangle {
            id: root  // 对话框主体
            // ...
        }
    }
}
```

### 根本原因

**当前代码**：
```qml
Keys.onEscapePressed: {
    root.visible = false  // ❌ 只隐藏了内部的 Rectangle
    // ...
}
```

**问题**：
1. `root.visible = false` 只隐藏了对话框主体（Rectangle）
2. `modalContainer`（包含半透明遮罩的最外层容器）仍然可见
3. 半透明黑色遮罩层（`modalOverlay`）还在屏幕上
4. 主界面被遮罩层覆盖，看起来很暗

**为什么焦点恢复成功但遮罩还在？**
- 焦点恢复使用的是 `modalContainer.parentContainer.forceActiveFocus()`
- 这个操作成功将焦点返回到 Screen01
- 但是 `modalContainer` 本身没有被隐藏
- 所以焦点正常，但视觉上遮罩还在

---

## ✅ 解决方案

将所有关闭处的 `root.visible = false` 改为 `modalContainer.visible = false`，这样整个对话框（包括遮罩层）都会被隐藏。

## 🔍 技术说明

### 为什么要隐藏 modalContainer 而不是 root？

**层级结构**：
```
modalContainer (Item)  ← 需要隐藏这个
  ├─ modalOverlay (MouseArea + 半透明背景)
  └─ dialogFocusScope (FocusScope)
       └─ root (Rectangle)  ← 之前只隐藏这个
```

**原因**：
1. `modalOverlay` 是 `modalContainer` 的直接子元素
2. 只隐藏 `root` 不会影响 `modalOverlay`
3. 必须隐藏 `modalContainer` 才能同时隐藏遮罩层和对话框主体

### 为什么之前的修复没有发现这个问题？

**之前的修复重点**：
- FIX 100.300.104.3-104.6：专注于焦点恢复问题
- 焦点恢复成功后，没有注意到遮罩层还在

**为什么焦点恢复成功但遮罩还在？**
- 焦点管理和视觉显示是两个独立的系统
- `forceActiveFocus()` 只影响焦点，不影响 `visible` 属性
- `modalContainer.visible = true` 导致遮罩层一直显示

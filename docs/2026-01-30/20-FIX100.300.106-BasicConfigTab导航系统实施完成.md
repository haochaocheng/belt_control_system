```qml
function triggerParamInput(paramIndex) {
    console.log("✅ [BasicConfigTab] 触发参数输入 - 索引:", paramIndex)

    var inputField = null
    var inputMode = "numeric"  // 默认数字模式

    switch(paramIndex) {
    case 0:  // 运行状态（RadioButton 组）
        console.log("✅ [BasicConfigTab] 切换运行状态")
        // TODO: 切换运行状态
        break
    case 1:  // 模块类型（只读）
        console.log("✅ [BasicConfigTab] 模块类型（只读）")
        break
    case 2:  // 模块地址
        inputField = moduleAddressSpin
        inputMode = "numeric"
        break
    case 3:  // 输出通道
        inputField = outputChannelSpin
        inputMode = "numeric"
        break
    case 4:  // 反馈通道
        inputField = feedbackChannelSpin
        inputMode = "numeric"
        break
    }

    // 打开虚拟键盘
    if (virtualKeyboard && inputField) {
        console.log("✅ [BasicConfigTab] 打开 Qt 虚拟键盘 - 控件:", inputField, "模式:", inputMode)
        virtualKeyboard.openForField(inputField, function(newValue) {
            console.log("✅ [BasicConfigTab] 虚拟键盘输入完成:", newValue)
        }, inputMode, root)
    } else {
        console.log("⚠️ [BasicConfigTab] 虚拟键盘或输入控件不可用")
    }
}
```

## 📊 技术实现细节

### 1. 焦点指示器模式

**结构**:
```
Row
├─ Text (参数名称标签)
└─ Item (焦点指示器容器)
   ├─ Rectangle (焦点指示器，z: 10)
   └─ InputControl (输入控件)
```

**关键点**:
- 焦点指示器只包含输入控件，不包含标签
- 使用 Item 容器包装输入控件
- 焦点指示器在最上层（z: 10）
- 蓝色边框（#2196F3，3px）

### 2. 函数调用链

**导航流程**:
```
DeviceSettingsDialog
  └─ MotorControlPage.triggerParamInput(index)
      └─ MotorConfigPanel.getCurrentTab()
          └─ BasicConfigTab.triggerParamInput(index)
              └─ virtualKeyboard.openForField(...)
```

**关键点**:
- 使用 `getCurrentTab()` 获取当前 Tab 的引用
- 使用 `typeof` 检查函数是否存在
- 使用 Qt.binding() 确保属性动态更新

### 3. 虚拟键盘集成

**输入模式**:
- `numeric`: 数字输入（SpinBox）
- `chinese`: 中文输入（待实施）
- `english`: 英文输入（待实施）

**特殊处理**:
- RadioButton 组：切换选中状态，不打开虚拟键盘
- 只读字段：不打开虚拟键盘

## 🔍 关键技术点

### 1. 焦点管理

**问题**: 如何在 Tab 之间切换时保持焦点状态？

**解决**: 使用 `focusParamIndex` 属性标识当前焦点位置，通过 Qt.binding() 确保属性动态更新。

### 2. 函数调用

**问题**: 如何从父组件调用子组件的函数？

**解决**: 使用 `getCurrentTab()` 获取当前 Tab 的引用，然后使用 `typeof` 检查函数是否存在。

### 3. 焦点指示器

**问题**: 如何为不同类型的控件添加统一的焦点指示器？

**解决**: 使用 Item 容器包装输入控件，在容器上添加焦点指示器 Rectangle，使用 z-index 确保指示器在最上层。

## 🎯 预期效果

### 导航流程

1. **打开对话框** → 焦点在左侧类别列表
2. **右键** → 焦点进入电机列表（电机列表区域）
3. **右键** → 焦点进入 Tab 区域（第一个 Tab）
4. **下键** → 焦点进入参数区域（第一个参数）
   - 蓝色边框高亮当前参数字段
5. **上/下键** → 在参数间移动
   - 焦点指示器跟随移动
6. **回车键** → 打开虚拟键盘
   - 根据字段类型自动选择输入模式
7. **ESC 键** → 关闭虚拟键盘
   - 焦点返回参数区域
8. **ESC 键** → 关闭对话框
   - 焦点返回主界面 Screen01

### 焦点指示器效果

- **蓝色边框**（3px）：清晰标识当前焦点位置
- **只包含输入框**：参数名称标签在边框外
- **平滑过渡**：焦点切换时视觉效果流畅

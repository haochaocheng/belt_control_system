# FIX 100.300.109 Phase 2.11.2 - 增强底部按钮焦点指示器

**日期**: 2026-01-30
**任务编号**: FIX 100.300.109 Phase 2.11.2
**状态**: ✅ 完成

## 🐛 问题描述

### 用户反馈

> 底部五个区域使用的按钮，选中时，蓝色边框不明显，看不清除焦点在哪里，不明显

### 具体问题

1. **蓝色边框太细**：
   - 当前边框宽度：2px
   - 在深色背景下不够明显
   - 用户无法清楚看到焦点在哪个按钮上

2. **缺少其他视觉反馈**：
   - 只有边框指示器
   - 没有背景色变化
   - 焦点不够突出

### 测试证据

**docs/log/pjsip.md 第 210-528 行**：
- 导航逻辑工作正常
- 所有按钮索引（0-4）都能正确切换
- 但视觉指示器不够明显

---

## 🔍 问题分析

### 根本原因

**MotorControlPage.qml 中的按钮焦点指示器**：

```qml
background: Rectangle {
    color: parent.pressed ? "#27ae60" : (parent.hovered ? "#2ecc71" : "#27ae60")
    radius: 4
    border.width: root.focusSubArea === 3 && root.focusButtonIndex === 0 ? 2 : 0  // ❌ 太细
    border.color: "#2196F3"
}
```

**问题**：
1. **边框太细**：2px 在深色背景下不够明显
2. **单一指示器**：只有边框，没有其他视觉反馈
3. **背景色不变**：焦点时背景色与非焦点时相同

---

## 🔧 修复方案

### 解决方法

**双重视觉反馈**：
1. **增加边框宽度**：2px → 5px（更明显）
2. **添加背景色变化**：焦点时背景色更亮

### 修复代码

**所有5个按钮的修改模式**：

```qml
background: Rectangle {
    // ✅ 2026-01-30 [FIX 100.300.109 Phase 2.11.2]: 增强焦点指示器
    // 焦点时背景色更亮
    color: {
        if (root.focusSubArea === 3 && root.focusButtonIndex === 0) {
            return "#2ecc71"  // 焦点时：亮绿色
        } else if (parent.pressed) {
            return "#27ae60"
        } else if (parent.hovered) {
            return "#2ecc71"
        } else {
            return "#27ae60"
        }
    }
    radius: 4
    // 增加边框宽度：2px → 5px
    border.width: root.focusSubArea === 3 && root.focusButtonIndex === 0 ? 5 : 0
    border.color: "#2196F3"
}
```

### 各按钮的焦点颜色

| 按钮索引 | 按钮名称 | 非焦点颜色 | 焦点颜色 | 说明 |
|---------|---------|-----------|---------|------|
| 0 | 添加输入 | #27ae60 (绿色) | #2ecc71 (亮绿色) | 正向操作 |
| 1 | 删除输入 | #d35400 (橙色) | #e74c3c (亮橙色) | 删除操作 |
| 2 | 保存 | #27ae60 (绿色) | #2ecc71 (亮绿色) | 正向操作 |
| 3 | 删除 | #d35400 (橙色) | #e74c3c (亮橙色) | 删除操作 |
| 4 | 重置 | #7f8c8d (灰色) | #95a5a6 (亮灰色) | 重置操作 |

## 💡 经验教训

### 焦点指示器设计原则

1. **多重视觉反馈**：
   ```qml
   // ✅ 推荐：边框 + 背景色
   border.width: focused ? 5 : 0
   border.color: "#2196F3"
   color: focused ? brightColor : normalColor

   // ❌ 避免：单一指示器
   border.width: focused ? 2 : 0  // 太细
   ```

2. **边框宽度选择**：
   - 2px：太细，不够明显 ❌
   - 3-4px：可见，但不够突出
   - 5px：清晰可见，推荐 ✅
   - 6px+：可能过于突出

3. **颜色对比度**：
   - 焦点颜色应该比非焦点颜色更亮
   - 保持色系一致（绿色系、橙色系、灰色系）
   - 确保在深色背景下可见

### 按钮焦点的最佳实践

1. **双重反馈**：
   - 边框：5px 蓝色边框
   - 背景色：焦点时更亮

2. **颜色选择**：
   - 正向操作（添加、保存）：绿色系
   - 删除操作（删除输入、删除）：橙色系
   - 重置操作：灰色系

3. **一致性**：
   - 所有按钮使用相同的焦点指示器样式
   - 边框宽度一致（5px）
   - 边框颜色一致（#2196F3）

### 用户体验考虑

1. **可见性**：
   - 焦点指示器必须清晰可见
   - 在深色背景下也要明显
   - 不要依赖单一视觉反馈

2. **对比度**：
   - 焦点与非焦点要有明显区别
   - 使用颜色亮度变化
   - 使用边框增强对比

3. **测试验证**：
   - 在实际设备上测试
   - 在不同光线条件下测试
   - 确保用户能清楚看到焦点

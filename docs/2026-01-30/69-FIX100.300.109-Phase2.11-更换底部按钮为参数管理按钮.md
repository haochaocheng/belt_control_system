**按钮样式**：

- 灰色按钮：重置

### 2. 更新 NavigationManager 按钮导航逻辑

**按钮数量**：
- **修改前**：3 个按钮（0-2）
- **修改后**：5 个按钮（0-4）

**按钮索引映射**：
```
第一行：[0] 添加输入  [1] 删除输入
第二行：[2] 保存      [3] 删除      [4] 重置
```

**导航逻辑**：
- **左键**：在同一行向左移动
  - 1 → 0（删除输入 → 添加输入）
  - 3 → 2（删除 → 保存）
  - 4 → 3（重置 → 删除）
- **右键**：在同一行向右移动
  - 0 → 1（添加输入 → 删除输入）
  - 2 → 3（保存 → 删除）
  - 3 → 4（删除 → 重置）
- **上键**：从第二行到第一行，或返回参数区
  - 2 → 0（保存 → 添加输入）
  - 3 → 1（删除 → 删除输入）
  - 4 → 1（重置 → 删除输入）
  - 0/1 → 参数区最后一个参数
- **下键**：从第一行到第二行，或保持不变
  - 0 → 2（添加输入 → 保存）
  - 1 → 3（删除输入 → 删除）
  - 2/3/4 → 保持不变

**2. 更新按钮导航逻辑（Line 193-259）**：
```qml
// ========== 区域D：底部按钮导航 ==========
// 按钮布局：
// 第一行：[0] 添加输入  [1] 删除输入
// 第二行：[2] 保存      [3] 删除      [4] 重置

function moveInButtonArea(direction) {
    var newIndex = buttonIndex

    switch(direction) {
    case "Left":
        // 左键：在同一行向左移动
        if (buttonIndex === 1) {
            newIndex = 0  // 删除输入 → 添加输入
        } else if (buttonIndex === 3) {
            newIndex = 2  // 删除 → 保存
        } else if (buttonIndex === 4) {
            newIndex = 3  // 重置 → 删除
        }
        break

    case "Right":
        // 右键：在同一行向右移动
        if (buttonIndex === 0) {
            newIndex = 1  // 添加输入 → 删除输入
        } else if (buttonIndex === 2) {
            newIndex = 3  // 保存 → 删除
        } else if (buttonIndex === 3) {
            newIndex = 4  // 删除 → 重置
        }
        break

    case "Up":
        // 向上：从第二行到第一行，或返回参数区
        if (buttonIndex === 2) {
            newIndex = 0  // 保存 → 添加输入
        } else if (buttonIndex === 3) {
            newIndex = 1  // 删除 → 删除输入
        } else if (buttonIndex === 4) {
            newIndex = 1  // 重置 → 删除输入
        } else {
            // 在第一行，向上返回参数区最后一个参数
            switchToArea(areaParams)
            paramIndex = 8
            return
        }
        break

    case "Down":
        // 向下：从第一行到第二行，或保持不变
        if (buttonIndex === 0) {
            newIndex = 2  // 添加输入 → 保存
        } else if (buttonIndex === 1) {
            newIndex = 3  // 删除输入 → 删除
        }
        // 在第二行，保持不变
        break
    }

    if (newIndex !== buttonIndex) {
        buttonIndex = newIndex
        console.log("✅ [NavigationManager] 按钮索引:", newIndex)
    }
}
```

## 💡 经验教训

### 布局变更的最佳实践

1. **从 Row 改为 ColumnLayout**：
   ```qml
   // ❌ 修改前：Row 布局
   Row {
       anchors.fill: parent
       // 左侧面板
       // 右侧面板
   }

   // ✅ 修改后：ColumnLayout 布局
   ColumnLayout {
       anchors.fill: parent
       Row {
           Layout.fillWidth: true
           Layout.fillHeight: true
           // 左侧面板
           // 右侧面板
       }
       Rectangle {
           Layout.fillWidth: true
           Layout.preferredHeight: 90
           // 底部按钮
       }
   }
   ```

2. **使用 Layout 属性**：
   - `Layout.fillWidth: true` - 填充宽度
   - `Layout.fillHeight: true` - 填充高度
   - `Layout.preferredHeight: 90` - 固定高度

### 按钮导航的最佳实践

1. **两行布局导航**：
   - 左右键：同一行导航
   - 上下键：跨行导航

2. **焦点指示器**：

3. **按钮样式统一**：

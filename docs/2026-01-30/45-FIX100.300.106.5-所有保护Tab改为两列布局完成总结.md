### 4. 替换布局结构

**旧结构（单列）**:
```qml
ScrollView {
    Column {
        // 9 个参数字段垂直排列
    }
}
```

**新结构（两列）**:
```qml
ScrollView {
    ColumnLayout {
        RowLayout {
            // 左列
            ColumnLayout {
                // 索引 0, 2, 4, 6, 8 (5个字段)
            }

            // 右列
            ColumnLayout {
                // 索引 1, 3, 5, 7 (4个字段)
            }
        }
    }
}
```

### 5. 参数字段分配

**左列（5个字段）**:
- 索引 0: 是否投入
- 索引 2: 动作保护类型
- 索引 4: 量程/温度量程
- 索引 6: 下限
- 索引 8: 过滤干扰延时/输入点选择

**右列（4个字段）**:
- 索引 1: 报警类型
- 索引 3: 故障保护类型
- 索引 5: 上限
- 索引 7: 输入点选择/过滤干扰延时

### 6. 参数字段包装

每个参数字段使用 `RowLayout` 包装:


## 🎯 导航流程

### 两列布局导航逻辑

**上/下键导航**:
- 左列: 0 → 2 → 4 → 6 → 8 (step=2)
- 右列: 1 → 3 → 5 → 7 (step=2)

**左/右键导航**:
- 左列 ↔ 右列 (step=1)
- 例如: 0 ↔ 1, 2 ↔ 3, 4 ↔ 5, 6 ↔ 7

**完整导航流程**:
1. 电机列表 (focusSubArea=0) → **右键** → Tab 区域 (focusSubArea=1)
2. Tab 区域 → **下键** → 参数区域 (focusSubArea=2)
3. 参数区域:
   - **上/下键**: 同列移动
   - **左/右键**: 切换列
4. 参数区域 → **上键**（到达第一个参数时）→ Tab 区域
5. Tab 区域 → **左键** → 电机列表

## 🎉 优势总结

### 1. 空间利用率提升

- **单列布局**: 垂直空间利用率高，但横向空间浪费
- **两列布局**: 横向空间利用率提升 50%，整体布局更紧凑

### 2. 视觉平衡

- **单列布局**: 视觉重心偏左，不够平衡
- **两列布局**: 左右对称，视觉效果更好

### 3. 一致性

- **单列布局**: 与 BasicConfigTab 不一致
- **两列布局**: 与 BasicConfigTab 和 AnalogInputPage 保持一致

### 4. 导航兼容

- **单列布局**: 只支持上/下键导航
- **两列布局**: 支持上/下/左/右键导航，更灵活

### 5. 可扩展性

- **单列布局**: 添加新字段会导致页面过长
- **两列布局**: 可以容纳更多字段，不会导致页面过长

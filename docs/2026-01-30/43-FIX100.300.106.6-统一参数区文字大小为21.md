# FIX 100.300.106.6 - 统一参数区文字大小为 21（参考开关量参数区）

**修改时间**: 2026-01-30
**修改人**: Claude
**修改类型**: UI 样式统一

## 修改目标

将 10 个 Tab 文件的参数区文字大小统一修改为开关量参数区（SwitchInputPage）的标准：`font.pixelSize: 21`

## 参考标准

来自 `SwitchInputPage.qml` 的标准：
- **文字大小**: `font.pixelSize: 21`（原来是 14，需要改为 21）
- **标签宽度**: `Layout.preferredWidth: 120`（保持不变）
- **输入框最大宽度**: `Layout.maximumWidth: 300`（保持不变）
- **文字颜色**: `color: "#9E9E9E"`（保持不变）
- **文字对齐**: `horizontalAlignment: Text.AlignRight`（保持不变）

## 修改文件列表

所有文件位于 `src/qml/components/device_info/pages/` 目录：

1. ✅ **BasicConfigTab.qml** - 基本配置
2. ✅ **CurrentProtectionTab.qml** - 电流保护
3. ✅ **FrontBearingTempTab.qml** - 前轴承温度保护
4. ✅ **RearBearingTempTab.qml** - 后轴承温度保护
5. ✅ **PhaseAWindingTab.qml** - A相绕组保护
6. ✅ **PhaseBWindingTab.qml** - B相绕组保护
7. ✅ **PhaseCWindingTab.qml** - C相绕组保护
8. ✅ **MotorTempTab.qml** - 电机温度保护
9. ✅ **XAxisVibrationTab.qml** - X轴振动保护
10. ✅ **YAxisVibrationTab.qml** - Y轴振动保护

## 具体修改内容

### 修改前
```qml
Text {
    text: "是否投入:"
    font.pixelSize: 14
    color: "#9E9E9E"
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}
```

### 修改后
```qml
Text {
    text: "是否投入:"
    font.pixelSize: 21  // ✅ 2026-01-30 [FIX 100.300.106.6]: 统一文字大小为 21（参考开关量参数区）
    color: "#9E9E9E"
    Layout.preferredWidth: 120
    horizontalAlignment: Text.AlignRight
}
```

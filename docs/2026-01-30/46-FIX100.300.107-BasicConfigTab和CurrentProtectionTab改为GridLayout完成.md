## 🔄 布局方式对比

### 旧方式（RowLayout + ColumnLayout）

```qml
ScrollView {
    ColumnLayout {
        RowLayout {
            // 左列
            ColumnLayout {
                RowLayout {
                    Text { text: "参数1:" }
                    Item { implicitHeight: 60 }  // ❌ 固定高度
                }
                RowLayout {
                    Text { text: "参数2:" }
                    Item { implicitHeight: 60 }  // ❌ 固定高度
                }
            }

            // 右列
            ColumnLayout {
                RowLayout {
                    Text { text: "参数3:" }
                    Item { implicitHeight: 60 }  // ❌ 固定高度
                }
            }
        }
    }
}
```

**问题**：
- 使用固定的 `implicitHeight: 60`，输入框被压缩
- 布局结构复杂，嵌套层级多
- 不符合 SwitchInputPage 的实现方式

### 新方式（GridLayout）

```qml
ScrollView {
    id: paramScrollView

    GridLayout {
        width: paramScrollView.width * 0.7  // ✅ 占 ScrollView 宽度的 70%
        columns: 4  // 4列：标签1、输入框1、标签2、输入框2
        columnSpacing: 10
        rowSpacing: 12

        // 第一行左侧（索引0）
        Text {
            text: "参数1:"
            font.pixelSize: 21
            color: "#9E9E9E"
            Layout.column: 0
            Layout.row: 0
            Layout.preferredWidth: 120
            horizontalAlignment: Text.AlignRight
        }

        Item {
            Layout.column: 1
            Layout.row: 0
            Layout.fillWidth: true
            Layout.maximumWidth: 300
            implicitHeight: inputField1.implicitHeight  // ✅ 动态高度

            DeviceInfo.CustomTextField {
                id: inputField1
                anchors.fill: parent
            }

            // 焦点指示器
            Rectangle {
                anchors.fill: parent
                color: "transparent"
                border.color: (root.focusParamIndex === 0) ? "#2196F3" : "transparent"
                border.width: (root.focusParamIndex === 0) ? 3 : 0
                radius: 4
                z: 10
            }
        }

        // 第一行右侧（索引1）
        Text {
            text: "参数2:"
            Layout.column: 2
            Layout.row: 0
            ...
        }

        Item {
            Layout.column: 3
            Layout.row: 0
            implicitHeight: inputField2.implicitHeight  // ✅ 动态高度
            ...
        }
    }
}
```

**优势**：
- 使用 `implicitHeight: inputFieldId.implicitHeight` 动态计算高度
- 布局结构清晰，使用 `Layout.column` 和 `Layout.row` 精确定位
- 完全符合 SwitchInputPage 的实现方式
- 输入框能正确显示完整内容

## 🔧 关键技术实现

### 1. 动态高度计算

**旧方式**（固定高度）：
```qml
Item {
    implicitHeight: 60  // ❌ 固定高度，输入框被压缩

    DeviceInfo.CustomReadOnlyField {
        anchors.fill: parent
        text: "立即停机"
    }
}
```

**新方式**（动态高度）：
```qml
Item {
    implicitHeight: actionProtectionField.implicitHeight  // ✅ 引用输入控件的 implicitHeight

    DeviceInfo.CustomReadOnlyField {
        id: actionProtectionField
        anchors.fill: parent
        text: "立即停机"
    }
}
```

### 2. GridLayout 定位

使用 `Layout.column` 和 `Layout.row` 精确定位：

```qml
// 第一行左侧
Text {
    Layout.column: 0
    Layout.row: 0
    ...
}

Item {
    Layout.column: 1
    Layout.row: 0
    ...
}

// 第一行右侧
Text {
    Layout.column: 2
    Layout.row: 0
    ...
}

Item {
    Layout.column: 3
    Layout.row: 0
    ...
}
```

### 3. 焦点指示器

焦点指示器放在 Item 容器内部，z: 10 确保在最上层：

```qml
Item {
    Layout.column: 1
    Layout.row: 0
    implicitHeight: inputField.implicitHeight

    DeviceInfo.CustomTextField {
        id: inputField
        anchors.fill: parent
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 0) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 0) ? 3 : 0
        radius: 4
        z: 10  // ✅ 确保在最上层
    }
}
```

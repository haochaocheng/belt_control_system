## 🎯 需求概述

### 使用场景

**场景 1（主要场景，绝对情况）**：纯键盘操作
- **硬件配置**：
  - ✅ 数字键：0-9
  - ✅ 字母键：A-L（12个字母）
  - ✅ 导航键：上下左右
  - ✅ 功能键：Enter、ESC
  - ❌ 无触摸屏
  - ❌ 无鼠标

**场景 2（次要场景）**：触摸屏
- ✅ 触摸屏可用
- ✅ 可以点击虚拟键盘

### 功能需求

**中文输入（保护名称、TTS文字）**：
1. ✅ 弹出虚拟键盘（中文拼音输入法）
2. ✅ 使用**导航键**（上下左右）在虚拟键盘上移动焦点
3. ✅ 使用**数字键**选择候选词
4. ✅ 使用**Enter键**确认选择（代替鼠标点击）
5. ✅ 类似**电视遥控器操作 APP** 的方式

**数字输入（播放次数、寄存器地址等）**：
1. ✅ **必须弹出虚拟键盘**（作为视觉反馈）
2. ✅ 可以使用**物理键盘**直接输入数字
3. ✅ 虚拟键盘显示当前输入状态

## 🔍 技术调研

### Qt Virtual Keyboard 键盘导航支持

**官方文档**：
- ✅ Qt Virtual Keyboard 支持 **2-way 和 5-way navigation**
- ✅ 支持硬件键导航
- ✅ 支持中文拼音输入法

**来源**：
- [Qt Virtual Keyboard Overview](https://doc.qt.io/qt-6.9/qtvirtualkeyboard-overview.html)
- [Qt Virtual Keyboard 5.15.11](https://doc.qt.io/qt-5.15/qtvirtualkeyboard-index.html)

### 启用键盘导航的方法

**Qt 5.x（qmake）**：
```bash
cd Qt/5.15.1/Src/qtvirtualkeyboard/
qmake qtvirtualkeyboard.pro CONFIG+=arrow-key-navigation
make && make install
```

**Qt 6.x（CMake）**：
需要在编译 Qt Virtual Keyboard 时添加 CMake 选项（待研究）

**来源**：
- [Enabling arrow-key-navigation with QtVirtualKeyboard](https://forum.qt.io/topic/126452/enabling-arrow-key-navigation-with-qtvirtualkeyboard-on-qt-5-15-1/3)

## 📋 方案对比

### 方案 A：使用 Qt Virtual Keyboard + 键盘导航（推荐）⭐

**优势**：
1. ✅ **官方支持**：Qt 官方维护，稳定可靠
2. ✅ **键盘导航**：支持 5-way navigation（上下左右 + Enter）
3. ✅ **中文输入**：内置 PinyinIME，支持拼音输入
4. ✅ **已集成**：项目已经使用 Qt Virtual Keyboard
5. ✅ **QDS 兼容**：已验证 QDS 预览可用
6. ✅ **跨平台**：Windows、Linux、RK3588 都支持

**劣势**：
1. ⚠️ **需要重新编译**：需要启用 `arrow-key-navigation` 选项
2. ⚠️ **编译复杂**：需要编译整个 Qt Virtual Keyboard 模块
3. ⚠️ **部署复杂**：需要替换系统的 Qt Virtual Keyboard 库

**工作量**：中等（1-2 天）

**风险**：中等
- 编译 Qt Virtual Keyboard 可能遇到依赖问题
- 替换系统库可能影响其他应用

---

### 方案 B：使用 CuteKeyboard + 自定义键盘导航

**优势**：
1. ✅ **开源可定制**：完全控制源码
2. ✅ **轻量级**：不需要编译整个 Qt 模块
3. ✅ **易于集成**：直接集成到项目中

**劣势**：
1. ❌ **无中文输入**：CuteKeyboard 不支持中文输入
2. ❌ **需要自己实现**：键盘导航需要自己实现
3. ❌ **需要集成拼音输入法**：需要额外集成 PinyinIME
4. ❌ **维护成本高**：需要自己维护代码

**工作量**：大（3-5 天）

**风险**：高
- 中文输入法集成复杂
- 键盘导航实现复杂
- 可能遇到未知问题

---

### 方案 C：自定义虚拟键盘

**优势**：
1. ✅ **完全控制**：可以实现任何功能
2. ✅ **专门优化**：专门为键盘导航设计

**劣势**：
1. ❌ **工作量巨大**：需要从零开始实现
2. ❌ **中文输入复杂**：拼音输入法实现非常复杂
3. ❌ **维护成本极高**：需要长期维护

**工作量**：非常大（1-2 周）

**风险**：极高

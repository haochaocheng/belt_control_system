# 方案 B 实施计划 - CuteKeyboard + 键盘导航 + 中文输入

**日期**: 2026-01-30
**状态**: 📋 计划中

---

## 🎯 目标

实现一个支持键盘导航和中文输入的虚拟键盘，满足以下需求：
1. ✅ 支持键盘导航（上下左右 + Enter）
2. ✅ 支持中文拼音输入
3. ✅ 支持数字输入
4. ✅ 基于 QML
5. ✅ QDS 兼容

---

## 📊 技术调研结果

### Qt Virtual Keyboard 键盘导航

**✅ 已完成分析**：
- 核心实现：`navigationModeActive` 属性
- 导航光标：`navigationCursor` 属性
- 导航函数：`navigateToNextKey(dX, dY, wrapEnabled)`
- 视觉反馈：`navigationHighlight` 组件

**详细文档**：[03-Qt-Virtual-Keyboard键盘导航技术分析.md](03-Qt-Virtual-Keyboard键盘导航技术分析.md)

### Qt Virtual Keyboard PinyinIME

**⚠️ 发现问题**：
- PinyinIME 是一个 **C++ 插件**，不是纯 QML 实现
- 依赖 `QVirtualKeyboardAbstractInputMethod` 接口
- 需要编译 C++ 代码
- 集成复杂度**非常高**

**文件位置**：
- `libs/qtvirtualkeyboard-source/src/plugins/pinyin/`
- `libs/qtvirtualkeyboard-source/src/plugins/pinyin/3rdparty/pinyin/`

---

## ⚠️ 重大发现：方案 B 的挑战

### 挑战 1：PinyinIME 是 C++ 插件

**问题**：
- PinyinIME 不是纯 QML 实现
- 需要编译 C++ 代码
- 需要实现 `QVirtualKeyboardAbstractInputMethod` 接口
- 需要处理词典文件（`dict_pinyin.dat`）

**工作量**：
- 编译 PinyinIME C++ 库：1-2 天
- 集成到项目：1-2 天
- 调试和测试：1-2 天
- **总计**：3-6 天

### 挑战 2：CuteKeyboard 不支持输入法插件

**问题**：
- CuteKeyboard 是一个简单的虚拟键盘
- 没有输入法插件系统
- 需要自己实现输入法接口

**工作量**：
- 设计输入法接口：0.5 天
- 实现输入法接口：1-2 天
- 集成 PinyinIME：1-2 天
- **总计**：2.5-4.5 天

### 挑战 3：总工作量

**方案 B 总工作量**：
- 集成 CuteKeyboard：0.5 天
- 实现键盘导航：1-2 天
- 编译 PinyinIME：1-2 天
- 实现输入法接口：1-2 天
- 集成 PinyinIME：1-2 天
- 测试和调试：1-2 天
- **总计**：**5-10 天**

**风险**：
- ⚠️ PinyinIME 编译可能遇到问题
- ⚠️ 输入法接口设计可能不完善
- ⚠️ 中文输入可能不稳定
- ⚠️ QDS 兼容性可能有问题

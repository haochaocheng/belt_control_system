# 修复对话框父容器设置

## 🐛 问题描述

### 测试结果

**测试日志**：pjsip.md

**问题**：
- ❌ 退出弹窗后，主界面的导航键依然不能使用

### 根本原因

**对话框的父容器设置错误**：

**代码位置**：`Screen01.qml:166`

```qml
var dialog = component.createObject(root.parent, {
    // 可以传递参数给对话框
    // deviceIndex: selectedIndex
})
```

**问题分析**：
1. 对话框使用 `root.parent` 作为父容器创建
2. `root` 是 Screen01（Item）
3. `root.parent` 是 Screen01 的父容器（可能是 App.qml 或其他容器）
4. 对话框关闭时，调用 `root.parent.forceActiveFocus()`
5. 焦点返回到 `root.parent`（Screen01 的父容器），而不是 Screen01
6. Screen01 没有焦点，导航键不起作用

**层级结构**：
```
App.qml (或其他容器)
  └─ Screen01 (root)
       └─ DeviceSettingsDialog (dialog)
```

**焦点流程（修复前）**：
```
对话框关闭 → root.parent.forceActiveFocus()
            ↓
            App.qml (有焦点) ❌
            ↓
            Screen01 (无焦点) ← 导航键不起作用
```

---

## ✅ 解决方案

### 修改内容

**文件**：`Screen01.qml`

**修改**：使用 `root` 作为父容器，而不是 `root.parent`

```qml
// ✅ 2026-01-30 [修复]: 使用 root 作为父容器，以便对话框关闭后焦点返回到 Screen01
function openDeviceSettings() {
    console.log("[Screen01] 🔧 打开设备设置对话框，当前选中索引:", selectedIndex)

    // 创建并显示 DeviceSettingsDialog
    var component = Qt.createComponent("../../components/device_info/DeviceSettingsDialog.qml")
    if (component.status === Component.Ready) {
        var dialog = component.createObject(root, {  // ← 使用 root，而不是 root.parent
            // 可以传递参数给对话框
            // deviceIndex: selectedIndex
        })
        if (dialog) {
            dialog.visible = true
            dialog.z = 1000  // 确保在最上层
            console.log("[Screen01] ✅ DeviceSettingsDialog 已打开")
        }
    }
}
```

**关键点**：
1. 对话框的父容器从 `root.parent` 改为 `root`
2. 对话框关闭时，`root.parent.forceActiveFocus()` 会将焦点返回到 `root`（Screen01）
3. Screen01 已经设置了 `focus: true` 和 `activeFocusOnTab: true`
4. 导航键可以正常工作

**层级结构（修复后）**：
```
App.qml (或其他容器)
  └─ Screen01 (root)
       └─ DeviceSettingsDialog (dialog)
```

**焦点流程（修复后）**：
```
对话框关闭 → root.parent.forceActiveFocus()
            ↓
            Screen01 (有焦点) ✅ ← 导航键正常工作
```

## 🔍 技术说明

### createObject 的父容器参数

**Qt.createComponent().createObject(parent, properties)**：

- `parent` 参数指定创建对象的父容器
- 对象的 `parent` 属性会被设置为这个值
- 对象关闭时，`parent.forceActiveFocus()` 会将焦点返回到父容器

**错误的用法**：
```qml
var dialog = component.createObject(root.parent, {...})
// dialog.parent === root.parent (App.qml)
// 关闭时焦点返回到 App.qml ❌
```

**正确的用法**：
```qml
var dialog = component.createObject(root, {...})
// dialog.parent === root (Screen01)
// 关闭时焦点返回到 Screen01 ✅
```

### 为什么之前使用 root.parent？

**可能的原因**：
1. 希望对话框覆盖整个应用窗口
2. 避免对话框被 Screen01 的边界裁剪

**实际情况**：
- 对话框使用 `anchors.fill: parent`
- 无论父容器是谁，对话框都会填充父容器
- 使用 `root` 作为父容器，对话框仍然可以覆盖整个 Screen01
- 不会被裁剪，因为对话框的 `z: 1000` 确保在最上层

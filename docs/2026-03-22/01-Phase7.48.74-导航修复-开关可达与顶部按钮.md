# Phase 7.48.74 - 导航修复：开关可达与顶部按钮

## 修复日期
2026-03-22

## 问题描述

### 问题1：张紧控制面板开关无法导航
张紧控制配置面板中的"张紧启用"和"使用反馈"两个Switch开关没有分配导航参数索引，导致键盘方向键无法将焦点移动到这两个开关上。

### 问题2：电机/制动器/张紧/洒水控制页面无法向上导航到顶部按钮
在电机控制、制动器控制、张紧控制、洒水控制页面中，使用方向键无法将焦点从页面内容区域移动到右上角的"关闭/保存/重置"三个按钮上。

**根因**：DeviceSettingsDialog在处理这4种设备页面的Up按键时，直接转发给内部页面的handleKeyPress，从未检查是否应该跳转到顶部按钮区域。

### 问题2补充：Tab栏向上无法到顶部按钮
电机控制页面焦点在Tab栏（如"基本配置"标签）时，按上箭头无法到达顶部按钮。

**根因**：初始修复仅检查了列表区域第一项（focusSubArea===0 && focusItemIndex===0），未包含Tab区域（focusSubArea===1）。

## 修改文件

### 1. TensionControlConfigPanel.qml
- 为"张紧启用"Switch添加焦点高亮（paramIndex 0）
- 为"使用反馈"Switch添加焦点高亮（paramIndex 2）
- 所有参数索引重排（共9个参数 0-8）：
  - Row 0: 张紧启用(0) + 输出通道(1)
  - Row 1: 使用反馈(2) + 反馈通道(3)
  - Row 2: 反馈超时(4) + 启动延时(5)
  - Row 3: 停止延时(6)
  - Row 4: 预警语音(7)
  - Row 5: 失败语音(8)
- `getParamFieldCount()`: 7 → 9
- `triggerParamInput()`: 添加case 0（tensionEnabledSwitch.toggle）和case 2（useFeedbackSwitch.toggle），其余索引+2

### 2. TensionControlPage.qml
- 更新张紧控制的rows映射：
  - 旧：`[[0,1],[1,1],[2,2],[4,1],[5,1],[6,1]]`（7个参数）
  - 新：`[[0,2],[2,2],[4,2],[6,1],[7,1],[8,1]]`（9个参数）

### 3. DeviceSettingsDialog.qml
- 在`Keys.onUpPressed`中，为电机/制动器/张紧/洒水控制页面（category 3-6）添加顶部按钮跳转逻辑：
  - 列表区域第一项（focusSubArea===0, focusItemIndex===0）按上键 → 跳转到顶部按钮
  - 电机控制Tab区域（focusSubArea===1）按上键 → 跳转到顶部按钮

## 导航路径
```
顶部按钮（关闭/保存/重置）
    ↑ 上键（从列表第一项或Tab栏）
    ↓ 下键（到左侧类别）
电机列表 / Tab栏 / 参数区 / 底部按钮
```

## 验证要点
1. 张紧控制面板：方向键可聚焦到"张紧启用"和"使用反馈"开关
2. 电机控制：列表第一项按上键 → 关闭按钮
3. 电机控制：Tab栏（如"基本配置"）按上键 → 关闭按钮
4. 制动器/张紧/洒水控制：列表第一项按上键 → 关闭按钮
5. Enter键在Switch上可切换开关状态

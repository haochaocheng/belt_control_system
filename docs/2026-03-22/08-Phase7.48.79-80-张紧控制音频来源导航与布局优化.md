# Phase 7.48.79~80.1 - 张紧控制音频来源导航与布局优化

## 修复日期
2026-03-22

## 修改内容

### Phase 7.48.79 - 张力传感器洒水编号修复
1. **洒水编号回车键未弹出虚拟键盘**：开关关闭时SpinBox被禁用，forceActiveFocus()不生效。修复：回车时先自动启用开关再弹出键盘
2. **洒水编号输入框宽度不一致**：`width: 120` → `anchors.fill: parent`，与其他SpinBox一致

### Phase 7.48.80 - 张紧控制音频来源加入导航
1. **音频来源加入导航焦点**：paramIndex 7，回车键切换默认↔TTS（if/else避免ButtonGroup互斥）
2. **预警/失败语音移出导航**：移除焦点高亮，参数数量9→8

### Phase 7.48.80.1 - 布局重组+导航列追踪
1. **布局重组**：音频来源移到GridLayout Row3左列(6)，停止延时移到Row3右列(7)（在启动延时正下方）
2. **下键边界**：最后一行按下键保持不动（不进入按钮区）
3. **上下导航列追踪**：按钮区Up返回最后行第一列（col 0），而非第二列

# FIX 100.246 - 添加设备选择功能

**日期**: 2026-01-17 22:30
**需求**: 在 SIP 设置界面添加扬声器、麦克风、摄像头设备选择
**实现方式**: 下拉框选择

---

## 📋 需求描述

在 SIP 设置界面的音频设置部分，音量调节**上方**添加设备选择功能：

1. ✅ **扬声器设备选择**（音频输出）
2. ✅ **麦克风设备选择**（音频输入）
3. ✅ **摄像头设备选择**（视频捕获）

### 背景说明

- 本机输出是 HDMI 一路
- 话筒是单独一路
- PJSIP 要求输入输出设备在同一设备上
- 设备上添加了虚拟设备（实际不可用）
- 需要提供UI让用户选择正确的设备

#### 实现细节

**文件**: `src/sip_phone/SipPhoneManager.cpp` (2158-2394行)

##### 音频输入设备枚举

```cpp
QStringList SipPhoneManager::getAudioInputDevices()
{
    QStringList devices;

    if (!d->initialized) {
        qWarning() << "❌ PJSIP not initialized, cannot enumerate devices";
        return devices;
    }

    unsigned count = pjsua_aud_dev_count();

    for (unsigned i = 0; i < count; ++i) {
        pjmedia_aud_dev_info info;
        pj_status_t status = pjsua_aud_dev_get_info(i, &info);

        if (status == PJ_SUCCESS) {
            // 只添加支持录音(输入)的设备
            if (info.input_count > 0) {
                QString deviceName = QString::fromUtf8(info.name);
                devices.append(deviceName);
            }
        }
    }

    return devices;
}
```

**关键点**：
- 使用 `pjsua_aud_dev_count()` 获取音频设备数量
- 使用 `pjsua_aud_dev_get_info()` 获取设备信息
- 只添加 `input_count > 0` 的设备（支持录音）

##### 视频设备枚举

```cpp
QStringList SipPhoneManager::getVideoDevices()
{
    unsigned count = pjsua_vid_dev_count();

    for (unsigned i = 0; i < count; ++i) {
        pjmedia_vid_dev_info info;
        pj_status_t status = pjsua_vid_dev_get_info(i, &info);

        if (status == PJ_SUCCESS) {
            // 只添加支持视频捕获的设备
            if (info.dir & PJMEDIA_DIR_CAPTURE) {
                QString deviceName = QString::fromUtf8(info.name);
                // 过滤掉虚拟设备(colorbar)
                if (!deviceName.contains("colorbar", Qt::CaseInsensitive)) {
                    devices.append(deviceName);
                }
            }
        }
    }
}
```

**关键点**：
- 使用 `pjsua_vid_dev_count()` 和 `pjsua_vid_dev_get_info()`
- 检查 `info.dir & PJMEDIA_DIR_CAPTURE`（支持视频捕获）
- **过滤 colorbar 虚拟设备**

##### 设备切换实现

```cpp
bool SipPhoneManager::setAudioInputDevice(int index)
{
    // 获取当前设置
    pjsua_snd_dev_param param;
    pj_status_t status = pjsua_snd_get_setting(&param);

    if (status != PJ_SUCCESS) {
        // 如果获取失败，使用默认设置
        param.playback_dev = PJMEDIA_AUD_DEFAULT_PLAYBACK_DEV;
    }

    // 更新录音设备
    param.capture_dev = index;

    // 应用设置
    status = pjsua_snd_set_setting(&param, PJ_TRUE);

    return (status == PJ_SUCCESS);
}
```

**关键点**：
- 使用 `pjsua_snd_get_setting()` 获取当前设置
- 修改 `param.capture_dev` 或 `param.playback_dev`
- 使用 `pjsua_snd_set_setting(&param, PJ_TRUE)` 立即应用

##### 视频设备切换

```cpp
bool SipPhoneManager::setVideoDevice(int index)
{
    // 通过 VideoCallManager 设置视频设备
    bool success = d->videoCallManager->setCaptureDeviceId(index);

    if (success) {
        // 如果当前正在预览，重启预览使用新设备
        if (d->videoPreviewActive) {
            stopVideoPreview();
            QThread::msleep(100);  // 短暂延迟
            startVideoPreview();
        }
    }

    return success;
}
```

**关键点**：
- 调用 VideoCallManager 的 `setCaptureDeviceId()`
- **如果正在预览，重启预览应用新设备**

## 🎯 技术要点

### 1. PJSIP 设备管理 API

#### 音频设备

- `pjsua_aud_dev_count()` - 获取音频设备数量
- `pjsua_aud_dev_get_info(i, &info)` - 获取设备信息
- `pjsua_snd_get_setting(&param)` - 获取当前音频设置
- `pjsua_snd_set_setting(&param, PJ_TRUE)` - 设置音频设备

#### 视频设备

- `pjsua_vid_dev_count()` - 获取视频设备数量
- `pjsua_vid_dev_get_info(i, &info)` - 获取设备信息

### 2. 设备信息结构

#### pjmedia_aud_dev_info

```c
typedef struct pjmedia_aud_dev_info {
    char name[PJMEDIA_AUD_DEV_INFO_NAME_LEN];  // 设备名称
    unsigned input_count;                       // 输入通道数
    unsigned output_count;                      // 输出通道数
    unsigned default_samples_per_sec;           // 默认采样率
    // ...
} pjmedia_aud_dev_info;
```

#### pjmedia_vid_dev_info

```c
typedef struct pjmedia_vid_dev_info {
    char name[PJMEDIA_VID_DEV_INFO_NAME_LEN];  // 设备名称
    pjmedia_dir dir;                            // 方向（CAPTURE/RENDER）
    unsigned caps;                              // 设备能力
    // ...
} pjmedia_vid_dev_info;
```

### 3. Qt QML ComboBox 绑定

```qml
ComboBox {
    // 设备列表绑定
    model: SipPhoneManager.getAudioInputDevices()

    // 当前设备索引绑定
    currentIndex: SipPhoneManager.getCurrentAudioInputDevice()

    // 设备切换回调
    onActivated: function(index) {
        SipPhoneManager.setAudioInputDevice(index)
    }
}
```

**关键点**：
- `model` 是动态的，每次打开页面会重新调用 C++ 方法
- `currentIndex` 初始化时调用一次
- `onActivated` 只在用户手动选择时触发

## ⚠️ 注意事项

### 1. 虚拟设备过滤

```cpp
// 过滤掉虚拟设备(colorbar)
if (!deviceName.contains("colorbar", Qt::CaseInsensitive)) {
    devices.append(deviceName);
}
```

**原因**: 设备上添加了虚拟设备，实际不可用，需要过滤

### 2. 视频设备切换时重启预览

```cpp
if (d->videoPreviewActive) {
    stopVideoPreview();
    QThread::msleep(100);  // 短暂延迟
    startVideoPreview();
}
```

**原因**: 切换设备后需要重新初始化视频流

### 3. 音频设备切换注意保留原有设置

```cpp
// 获取当前设置
pjsua_snd_dev_param param;
pjsua_snd_get_setting(&param);

// 只修改需要改变的部分
param.capture_dev = index;  // 或 param.playback_dev = index

// 应用设置（保留其他参数）
pjsua_snd_set_setting(&param, PJ_TRUE);
```

**原因**: 避免影响其他音频参数（如采样率、缓冲区大小等）

## 📝 使用说明

### 用户操作流程

1. 打开 SIP 设置页面
2. 滚动到"音频设置"部分
3. 在音量调节上方看到三个下拉框：
   - **扬声器设备**
   - **麦克风设备**
   - **摄像头设备**
4. 点击下拉框查看可用设备列表
5. 选择所需设备
6. 设置立即生效

### 设备生效时机

- **音频设备**: 立即生效，下次通话使用新设备
- **视频设备**:
  - 如果正在预览：立即重启预览
  - 如果在通话中：可能需要挂断重拨才能应用
  - 下次通话：使用新设备

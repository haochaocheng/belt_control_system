## 🎯 可能的卡住原因（按优先级排序）

### 猜测 1：联系人数据库查询阻塞 ⭐ 最可能

**位置**：`SipPhoneManager.cpp` Line 613
```cpp
QString callerName = risip::ContactDatabase::instance()->getContactName(extractedNumber);
```

**原因分析**：
- 如果 ContactDatabase 是同步的数据库查询
- 数据库文件 I/O 阻塞
- 会卡住整个信号链

**验证**：查看日志是否卡在 "Step 6: Querying contact database..."

### 猜测 2：QML 信号处理阻塞

**位置**：`SipPhoneManager.cpp` Line 628
```cpp
emit incomingCall(callerNumber, displayName);
```

**原因分析**：
- QML 侧 `handleIncomingCall()` 切换页面：`tabBarRect.currentIndex = 1`
- 如果页面切换触发大量 QML 组件加载
- 可能阻塞

**验证**：查看日志是否卡在 "Step 9: Emitting incomingCall() signal to QML..."

### 猜测 3：铃声播放阻塞

**位置**：QML 侧，`SipDialPage.qml` Line 102
```qml
ringtone.play()
```

**原因分析**：
- MediaPlayer.play() 理论上是异步的
- 但如果音频文件加载失败或阻塞
- 可能导致 UI 线程卡住

**验证**：查看日志是否通过了 "Step 9" 但 QML 侧没有后续日志

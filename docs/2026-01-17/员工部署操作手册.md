## 📋 准备工作

**需要的东西**：
1. ✅ 一台 Windows 电脑（已安装好软件）
2. ✅ 目标设备（已上电，连接网络）
3. ✅ 设备 IP 地址（贴在设备上或由管理员提供）

## 🚀 部署步骤（3 步完成）

### Step 1：打开 PowerShell

1. 按键盘 `Win + X`
2. 选择"Windows PowerShell"或"终端"

### Step 2：进入工作目录

**复制下面的命令，粘贴到 PowerShell，回车：**

```powershell
cd E:\2025\3_gongkongji\belt_control_system
```

### Step 3：运行部署命令

**根据设备 IP 选择对应命令，复制粘贴后回车：**

#### 设备 150（IP: 192.168.10.150）

```powershell
ssh pi@192.168.10.150 "wget -qO /tmp/install-docker.sh https://get.docker.com && chmod +x /tmp/install-docker.sh && sudo /tmp/install-docker.sh && sudo docker load < /tmp/belt-control.tar && sudo docker run -d --restart=always --name belt-control belt-control-ubuntu24-apt:latest"
```

**如果上面的命令失败，用这个（分两步）：**

**第一步：安装 Docker**
```bash
# 复制下面所有内容，粘贴到 ssh 登录后的命令行：
wget -qO /tmp/install.sh https://get.docker.com
sudo sh /tmp/install.sh
sudo systemctl enable docker
sudo systemctl start docker
sudo docker --version
```

**第二步：部署应用**（等第一步完成后）
```bash
# 先在 Windows 上传输镜像
scp belt-control-ubuntu24-apt.tar pi@192.168.10.150:/tmp/

# 然后在设备上加载
ssh pi@192.168.10.150
sudo docker load < /tmp/belt-control.tar
sudo docker images
```

## 📝 完整操作流程（适合新手）

### 方式一：手动部署（最可靠）⭐

#### 1. SSH 登录到设备

```powershell
# 在 Windows PowerShell 中运行：
ssh pi@192.168.10.150
# 输入密码：pi
```

#### 2. 复制粘贴安装 Docker

**登录成功后，复制下面整段代码，粘贴到终端，回车：**

```bash
wget -qO /tmp/get-docker.sh https://get.docker.com && \
sudo sh /tmp/get-docker.sh && \
sudo usermod -aG docker pi && \
sudo systemctl enable docker && \
sudo systemctl start docker && \
echo "✅ Docker 安装完成！" && \
sudo docker --version
```

**等待 3-5 分钟，看到 "✅ Docker 安装完成！"**

#### 3. 退出设备，传输应用镜像

```bash
# 在设备上输入：
exit

# 回到 Windows PowerShell，运行：
cd E:\2025\3_gongkongji\belt_control_system
scp belt-control-ubuntu24-apt.tar pi@192.168.10.150:/tmp/
# 输入密码：pi
# 等待传输完成（约 2-3 分钟）
```

#### 4. 重新登录设备，加载镜像

```bash
# 在 Windows PowerShell 中运行：
ssh pi@192.168.10.150
# 输入密码：pi

# 登录后，复制粘贴下面的命令：
sudo docker load < /tmp/belt-control.tar && \
rm -f /tmp/belt-control.tar && \
echo "✅ 镜像加载完成！" && \
sudo docker images
```

#### 5. 启动应用

```bash
# 复制粘贴下面的命令：
sudo docker run -d \
  --restart=always \
  --name belt-control \
  --privileged \
  -v /dev:/dev \
  belt-control-ubuntu24-apt:latest

# 查看运行状态：
sudo docker ps
```

**看到容器运行中，部署完成！✅**

## ⚠️ 常见问题

### 问题 1：ssh 命令找不到

**解决方法**：
- Windows 10/11 自带 SSH，如果没有，安装 Git for Windows
- 或使用 PuTTY

### 问题 2：密码输入多次还是错误

**解决方法**：
- 确认密码是 `pi`
- 如果不是，联系管理员获取正确密码

### 问题 3：下载 Docker 很慢或失败

**解决方法**：
- 检查设备网络连接
- 或使用离线安装包（联系管理员）

### 问题 4：镜像传输失败

**解决方法**：
- 检查网络连接
- 确认镜像文件存在：`ls -lh belt-control-ubuntu24-apt.tar`
- 重新传输

## 📊 批量部署（多台设备）

如果需要部署多台设备，使用批量脚本：

```powershell
# 编辑设备列表
$devices = @("192.168.10.150", "192.168.10.151", "192.168.10.152")

# 逐台部署
foreach ($ip in $devices) {
    Write-Host "正在部署设备 $ip ..." -ForegroundColor Cyan

    # 1. 安装 Docker
    ssh pi@$ip "wget -qO /tmp/install.sh https://get.docker.com && sudo sh /tmp/install.sh"

    # 2. 传输镜像
    scp belt-control-ubuntu24-apt.tar pi@${ip}:/tmp/

    # 3. 加载镜像
    ssh pi@$ip "sudo docker load < /tmp/belt-control.tar"

    # 4. 启动应用
    ssh pi@$ip "sudo docker run -d --restart=always --name belt-control belt-control-ubuntu24-apt:latest"

    Write-Host "✅ 设备 $ip 部署完成" -ForegroundColor Green
}
```

## 二、新增分类

### 2.1 皮带操作状态（beltOperation）

每条皮带生成以下文件：

**皮带级（5个/皮带）：**
```
{N}号皮带启动.wav
{N}号皮带停车.wav
{N}号皮带运行失败.wav
{N}号皮带通讯失败.wav
{N}号皮带启动请注意.wav
```

**电机级（1个/电机/皮带）：**
```
{M}号电机运行失败.wav
```

**松闸级（1个/制动器/皮带）：**
```
{M}号松闸运行失败.wav
```

**张紧级（1个/张紧/皮带）：**
```
{T}号张紧运行失败.wav
```

文件数计算：`(5 + 电机数 + 制动器数 + 张紧数) × 皮带数`
默认配置：`(5 + 4 + 4 + 2) × 8 = 120个`

### 2.2 系统/通讯状态（systemStatus）

每条皮带目录下生成以下7个文件：
```
与主站通信失败.wav
未知皮带通讯失败.wav
终端离线.wav
继电器通讯.wav
远程急停.wav
集控停车.wav
集控起车启动.wav
```

文件数计算：`7 × 皮带数`
默认配置：`7 × 8 = 56个`

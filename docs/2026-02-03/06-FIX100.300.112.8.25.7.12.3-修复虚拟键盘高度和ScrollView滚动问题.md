## 🎯 问题描述

用户测试完成后，发现虚拟键盘自动滚动功能仍然无法正常工作。从日志中发现两个关键问题：

### 问题1：虚拟键盘高度估算不准确

**日志证据**：
```
Debug:    ⌨️  虚拟键盘信息:
Debug:       - 屏幕高度: 1080
Debug:       - 键盘高度（估算）: 432
Debug:       - 键盘顶部Y: 648
```

**实际情况**（从main_qds.qml日志）：
```
⌨️ [QDS InputPanel] Active changed: true
   - 虚拟键盘高度: 600
   - 虚拟键盘Y位置: 480
   - 屏幕高度: 1080
```

**问题分析**：
- **估算高度**：432px（屏幕高度1080的40%）
- **实际高度**：600px
- **差距**：168px（39%的误差）
- **影响**：导致遮挡判断不准确，滚动距离计算错误

### 问题2：ScrollView无法滚动

**日志证据**：
```
Debug:    📊 ScrollView信息:
Debug:       - height: 513
Debug:       - contentHeight: 420
Debug:    ⚠️  输入框被遮挡，重叠: 81 px
Debug:    📐 滚动计算:
Debug:       - 当前滚动Y: 0
Debug:       - 需要额外滚动: 81
Debug:       - 目标滚动Y: 81
Debug:       - 最大滚动Y: 0
Debug:       - 最终滚动Y: 0
```

**问题分析**：
- **ScrollView height**: 513px（可见区域高度）
- **ScrollView contentHeight**: 420px（内容总高度）
- **maxScrollY**: 0（contentHeight < height，无法滚动）
- **结果**：即使输入框被遮挡81px，也无法滚动

**根本原因**：
- GridLayout的implicitHeight计算不正确
- GridLayout内容太少，导致contentHeight小于ScrollView的height
- 当内容高度小于可见区域高度时，ScrollView不允许滚动

## 🔍 问题分析

### 虚拟键盘高度问题

**当前实现**（错误）：
```qml
// CustomSpinBox.qml Line 179-180
var screenHeight = scrollView.Window.window ? scrollView.Window.window.height : 1080
var keyboardHeight = screenHeight * 0.4  // ❌ 估算，不准确
```

**问题**：
1. 使用固定比例（40%）估算键盘高度
2. 实际键盘高度是600px，估算是432px
3. 误差168px，导致遮挡判断不准确

**解决方案**：
1. 在main_qds.qml中暴露虚拟键盘高度为全局属性
2. CustomSpinBox直接读取实际高度
3. 如果无法获取，回退到估算

### ScrollView滚动问题

**当前布局结构**：
```qml
// CurrentProtectionTab.qml
ScrollView {
    id: paramScrollView
    anchors.fill: parent
    clip: true

    GridLayout {
        width: paramScrollView.width * 0.9
        columns: 4
        columnSpacing: 10
        rowSpacing: 12
        // ❌ 没有设置 implicitHeight
        // ❌ 内容太少，导致 contentHeight < ScrollView.height
    }
}
```

**问题**：
1. GridLayout没有显式设置implicitHeight
2. GridLayout根据内容自动计算高度
3. 当前只有11个参数字段（6行），高度约420px
4. ScrollView的height是513px（弹窗高度减去其他元素）
5. contentHeight (420) < height (513)，maxScrollY = 0

**为什么会这样？**
- GridLayout的implicitHeight = 行数 × (行高 + rowSpacing)
- 当前：6行 × (60px + 12px) = 432px（约等于日志中的420px）
- ScrollView的height = 弹窗高度 - 头部 - 底部按钮 = 513px
- 因为内容高度小于可见区域，ScrollView认为不需要滚动

**解决方案**：
有两种方案：

**方案A：增加GridLayout的最小高度**
```qml
GridLayout {
    width: paramScrollView.width * 0.9
    columns: 4
    columnSpacing: 10
    rowSpacing: 12
    // ✅ 设置最小高度，确保可以滚动
    Layout.minimumHeight: 800  // 大于 ScrollView.height (513)
}
```

**优点**：
- 简单直接
- 确保可以滚动

**缺点**：
- 硬编码高度，不够灵活
- 如果参数字段增加，需要手动调整

**方案B：调整ScrollView的高度**
```qml
ScrollView {
    id: paramScrollView
    anchors.fill: parent
    clip: true
    // ✅ 减小 ScrollView 的高度，确保内容超出可见区域
    height: parent.height - 100  // 预留空间给虚拟键盘
}
```

**优点**：
- 更灵活
- 自动适应内容变化

**缺点**：
- 需要调整布局
- 可能影响其他Tab

**推荐方案**：方案A（设置GridLayout最小高度）
- 更简单
- 不影响其他Tab
- 可以根据实际测试调整高度

## 💡 关键知识点

### 1. 为什么contentHeight < height时无法滚动？

**ScrollView的滚动机制**：
```qml
maxScrollY = Math.max(0, contentHeight - height)
```

**示例**：
- contentHeight = 420
- height = 513
- maxScrollY = Math.max(0, 420 - 513) = Math.max(0, -93) = 0

**结论**：
- 当内容高度小于可见区域高度时，maxScrollY = 0
- ScrollView认为不需要滚动
- 即使设置position，也会被限制在0

### 2. GridLayout的implicitHeight计算

**公式**：
```
implicitHeight = 行数 × (最大行高 + rowSpacing) - rowSpacing
```

**示例**（CurrentProtectionTab）：
- 行数：6行
- 行高：60px（CustomSpinBox的implicitHeight）
- rowSpacing：12px
- implicitHeight = 6 × (60 + 12) - 12 = 420px

**问题**：
- 如果参数字段少，implicitHeight就小
- 如果ScrollView的height大，就无法滚动

### 3. 为什么使用Layout.minimumHeight？

**Layout.minimumHeight vs implicitHeight**：
- `implicitHeight`：组件根据内容自动计算的高度
- `Layout.minimumHeight`：布局系统强制的最小高度

**效果**：
```qml
GridLayout {
    // implicitHeight = 420（根据内容计算）
    Layout.minimumHeight: 800  // 强制最小高度
    // 最终高度 = Math.max(implicitHeight, minimumHeight) = 800
}
```

**为什么不用height？**
- `height`会覆盖implicitHeight，失去自动计算能力
- `Layout.minimumHeight`保留自动计算，但确保不小于指定值
- 如果内容增加，高度会自动增长

### 4. 虚拟键盘高度的获取方式

**方式1：从InputPanel获取**（推荐）
```qml
// main_qds.qml
property real virtualKeyboardHeight: virtualKeyboard.height

// CustomSpinBox.qml
var keyboardHeight = scrollView.Window.window.virtualKeyboardHeight
```

**优点**：
- 获取实际高度，准确
- 自动适应不同屏幕分辨率

**方式2：估算**（回退方案）
```qml
var keyboardHeight = screenHeight * 0.4
```

**优点**：
- 简单
- 不依赖InputPanel

**缺点**：
- 不准确
- 不同设备可能不同

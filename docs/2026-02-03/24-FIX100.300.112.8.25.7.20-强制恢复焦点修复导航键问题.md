## 🎯 问题分析

### 用户反馈

测试完成后，问题依旧：
- 鼠标点击5号电机 → ✅ 蓝色边框和背景图片都切换到5号电机
- 继续使用导航键 → ❌ **只有蓝色边框移动，背景图片停留在5号电机**

### 根本原因推测

经过深入分析，我发现了一个关键问题：**鼠标点击后，焦点可能不在 MotorControlPage 上**。

#### 焦点流转分析

```
初始状态：
MotorControlPage.activeFocus = true
  ↓
用户使用导航键切换到2号电机
  ↓
MotorControlPage 接收键盘事件 ✅
  ↓
用户鼠标点击5号电机
  ↓
MyMotorListPanel 的 MouseArea 被点击
  ↓
焦点可能被 MouseArea 或 MyMotorListPanel 抢走 ❌
  ↓
MotorControlPage.activeFocus = false
  ↓
用户继续使用导航键
  ↓
MotorControlPage 不接收键盘事件 ❌
  ↓
导航键无效，背景图片不变 ❌
```

### 为什么之前的修复没有解决问题？

1. **FIX 100.300.112.8.25.7.17**：修复了鼠标点击时的状态同步
   - ✅ 正确更新了 `currentMotorIndex`、`focusItemIndex`、`motorListIndex`
   - ❌ 但没有恢复焦点到 MotorControlPage

2. **FIX 100.300.112.8.25.7.18**：注释掉了旧的键盘事件处理器
   - ✅ 避免了 NavigationManager 冲突
   - ❌ 但如果 MotorControlPage 没有焦点，NavigationManager 也不会被调用

3. **FIX 100.300.112.8.25.7.19**：添加了 currentArea 检查
   - ✅ 确保 currentArea 是 areaMotorList
   - ❌ 但如果 MotorControlPage 没有焦点，键盘事件根本不会触发

## 🔧 解决方案

### 方案：鼠标点击后强制恢复焦点到 MotorControlPage

**核心思想**：在鼠标点击处理器中，检查 MotorControlPage 是否有焦点，如果没有，强制恢复焦点。

### 修改内容

#### 1. 添加焦点变化监听（Line 206-212）

```qml
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.20]: 添加焦点变化监听
onActiveFocusChanged: {
    console.log("🔍 [DEBUG] MotorControlPage 焦点变化:", activeFocus)
    if (!activeFocus) {
        console.log("⚠️ [DEBUG] MotorControlPage 失去焦点！")
    }
}
```

**目的**：
- 监控 MotorControlPage 的焦点状态
- 当焦点丢失时，输出警告日志

#### 2. 鼠标点击后强制恢复焦点（Line 283-309）

```qml
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.20]: 添加强制恢复焦点
item.motorSelected.connect(function(motorIndex) {
    console.log("🔍 [DEBUG] 鼠标点击电机:", motorIndex)
    console.log("  - 点击前 currentArea:", navigationManager.currentArea)
    console.log("  - 点击前 motorListIndex:", navigationManager.motorListIndex)
    console.log("  - 点击前 MotorControlPage.activeFocus:", root.activeFocus)

    root.currentMotorIndex = motorIndex
    root.focusItemIndex = motorIndex
    navigationManager.motorListIndex = motorIndex

    // ✅ 确保 currentArea 是 areaMotorList
    if (navigationManager.currentArea !== navigationManager.areaMotorList) {
        console.log("🔍 [DEBUG] 切换 currentArea 到 areaMotorList")
        navigationManager.currentArea = navigationManager.areaMotorList
    }

    // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.20]: 强制恢复焦点到 MotorControlPage
    if (!root.activeFocus) {
        console.log("🔍 [DEBUG] 强制恢复焦点到 MotorControlPage")
        root.forceActiveFocus()
    }

    console.log("  - 点击后 currentArea:", navigationManager.currentArea)
    console.log("  - 点击后 motorListIndex:", navigationManager.motorListIndex)
    console.log("  - 点击后 MotorControlPage.activeFocus:", root.activeFocus)
    console.log("✅ [MotorControlPage] 选中电机:", motorIndex + 1, "- 已同步 focusItemIndex 和 NavigationManager")
})
```

**关键修复**：
```qml
// 强制恢复焦点到 MotorControlPage
if (!root.activeFocus) {
    console.log("🔍 [DEBUG] 强制恢复焦点到 MotorControlPage")
    root.forceActiveFocus()
}
```

**原理**：
- 检查 MotorControlPage 是否有焦点
- 如果没有焦点，调用 `forceActiveFocus()` 强制恢复焦点
- 确保后续的导航键事件能被 MotorControlPage 接收

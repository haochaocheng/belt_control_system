## 🎯 问题描述

用户反馈：**在次数按回车键时，弹出的虚拟键盘还是英文输入，不是纯键盘输入**

**根本原因**：
- Qt的 `InputPanel` 组件即使设置了 `Qt.ImhDigitsOnly`，仍然会显示完整的键盘布局（包括字母键盘）
- 用户需要纯数字键盘，只显示0-9和小数点，不显示英文字母

### QtVirtualKeyboardIntegration.qml - 使用自定义NumericKeyboard

**修改位置**: Line 1-83

**修改前**：
```qml
contentItem: InputPanel {
    id: inputPanel
    z: 99
    anchors.fill: parent
}

function openForField(textField, callback, mode, parentPageRef) {
    targetTextField = textField
    updateCallback = callback
    inputMode = mode || "numeric"
    parentPage = parentPageRef || null

    // Set input method hints based on mode
    if (textField) {
        if (mode === "numeric") {
            textField.inputMethodHints = Qt.ImhDigitsOnly  // ❌ 仍然显示字母键盘
        } else if (mode === "english") {
            textField.inputMethodHints = Qt.ImhNoPredictiveText | Qt.ImhPreferLowercase
        } else if (mode === "chinese") {
            textField.inputMethodHints = Qt.ImhNone
        }

        textField.forceActiveFocus()
    }

    root.open()
}
```

**修改后**：
```qml
contentItem: Item {
    anchors.fill: parent

    // ✅ 2026-02-02 [FIX]: 自定义数字键盘（纯数字输入）
    NumericKeyboard {
        id: numericKeyboard
        anchors.fill: parent
        anchors.margins: 10
        visible: false  // 默认隐藏，根据 inputMode 显示
    }

    // Qt 官方虚拟键盘（英文/中文输入）
    InputPanel {
        id: inputPanel
        z: 99
        anchors.fill: parent
        visible: false  // 默认隐藏，根据 inputMode 显示
    }
}

function openForField(textField, callback, mode, parentPageRef) {
    targetTextField = textField
    updateCallback = callback
    inputMode = mode || "numeric"
    parentPage = parentPageRef || null

    // ✅ 2026-02-02 [FIX]: 根据模式显示不同的键盘
    if (mode === "numeric") {
        // 数字模式：使用自定义 NumericKeyboard
        numericKeyboard.visible = true
        inputPanel.visible = false
        numericKeyboard.targetInput = textField
    } else {
        // 其他模式：使用 Qt InputPanel
        numericKeyboard.visible = false
        inputPanel.visible = true

        // Set input method hints based on mode
        if (textField) {
            if (mode === "english") {
                textField.inputMethodHints = Qt.ImhNoPredictiveText | Qt.ImhPreferLowercase
            } else if (mode === "chinese") {
                textField.inputMethodHints = Qt.ImhNone
            }

            textField.forceActiveFocus()
        }
    }

    root.open()
}
```

## 💡 设计说明

### 为什么使用自定义NumericKeyboard？

**Qt InputPanel的问题**：
1. **布局固定**：即使设置 `Qt.ImhDigitsOnly`，仍然显示完整的键盘布局
2. **无法隐藏字母键**：Qt的InputPanel会显示字母键盘，用户需要手动切换到数字键盘
3. **用户体验差**：用户需要额外的操作才能输入数字

**自定义NumericKeyboard的优势**：
1. **纯数字输入**：只显示0-9、小数点、退格和清除按钮
2. **布局简洁**：3x3网格布局，易于触摸操作
3. **用户体验好**：打开键盘即可直接输入数字，无需切换
4. **样式统一**：与项目整体UI风格保持一致

### 双键盘架构

```
QtVirtualKeyboardIntegration
├── NumericKeyboard (numeric 模式)
│   └── 0-9、.、←、清除全部
└── InputPanel (english/chinese 模式)
    └── 完整QWERTY键盘 + 输入法
```

**优势**：
- 根据 `inputMode` 动态切换键盘
- 数字输入使用自定义键盘，文本输入使用Qt官方键盘
- 保持灵活性，支持未来扩展

### NumericKeyboard 实现细节

**文件位置**：`src/qml/components/virtual_keyboard/NumericKeyboard.qml`

**核心功能**：
```qml
property var targetInput: null  // 目标输入框

// 数字按钮点击
onClicked: {
    if (root.targetInput) {
        root.targetInput.text += modelData  // 追加数字
    }
}

// 退格按钮点击
onClicked: {
    if (root.targetInput && root.targetInput.text.length > 0) {
        root.targetInput.text = root.targetInput.text.slice(0, -1)  // 删除最后一个字符
    }
}

// 清除按钮点击
onClicked: {
    if (root.targetInput) {
        root.targetInput.text = ""  // 清空输入框
    }
}
```

# FIX 100.300.112.8.25.7.6 - 移除MouseArea让Qt虚拟键盘正常工作

**日期**: 2026-02-02
**任务编号**: FIX 100.300.112.8.25.7.6
**状态**: ✅ 已完成

---

## 🎯 问题描述

用户反馈：**Qt官方虚拟键盘在QDS能工作，不要找借口说是QDS预览模式的问题**

**真正的问题**：
- CustomSpinBox 的 TextInput 上面有一个 MouseArea
- MouseArea 拦截了所有点击事件
- Qt.inputMethod 无法正常接收输入法事件
- 导致虚拟键盘不会弹出

---

## 🔍 问题根本原因

### 错误的实现

```qml
contentItem: TextInput {
    id: textInput
    inputMethodHints: Qt.ImhDigitsOnly

    // ❌ 错误：MouseArea 拦截了所有事件
    MouseArea {
        anchors.fill: parent
        onClicked: {
            textInput.forceActiveFocus()
        }
        onPressed: mouse.accepted = false
    }
}
```

**问题**：
1. MouseArea 覆盖在 TextInput 上面
2. MouseArea 拦截了所有鼠标事件
3. 即使 `mouse.accepted = false`，Qt.inputMethod 仍然无法正常工作
4. TextInput 无法接收输入法事件

### 正确的实现

```qml
contentItem: TextInput {
    id: textInput
    inputMethodHints: Qt.ImhDigitsOnly
    selectByMouse: true

    // ✅ 正确：不需要 MouseArea，TextInput 自己处理事件
}
```

**原理**：
1. TextInput 自己处理鼠标事件
2. 当 TextInput 获得焦点时，Qt.inputMethod 自动触发
3. InputPanel 的 `visible: Qt.inputMethod.visible` 自动变为 true
4. 虚拟键盘自动弹出

## ✅ 修改效果

### Qt Virtual Keyboard 工作流程

**正确的流程**：
1. 用户点击 TextInput
2. TextInput 获得焦点
3. Qt.inputMethod 检测到 TextInput 获得焦点
4. Qt.inputMethod 检查 inputMethodHints（Qt.ImhDigitsOnly）
5. Qt.inputMethod.visible 变为 true
6. InputPanel 的 `visible: Qt.inputMethod.visible` 触发
7. 虚拟键盘显示

**之前的错误流程**：
1. 用户点击 MouseArea
2. MouseArea 拦截事件
3. MouseArea 调用 `textInput.forceActiveFocus()`
4. TextInput 获得焦点，但 Qt.inputMethod 没有被触发
5. Qt.inputMethod.visible 保持 false
6. 虚拟键盘不显示

## 💡 关键知识点

### 1. MouseArea 会拦截事件

**问题**：
- MouseArea 覆盖在 TextInput 上面
- 即使设置 `mouse.accepted = false`
- Qt.inputMethod 仍然无法正常工作

**原因**：
- Qt.inputMethod 需要 TextInput 直接接收鼠标事件
- MouseArea 的存在会干扰输入法系统
- 即使事件被传递，输入法系统也无法正常初始化

### 2. TextInput 自己可以处理点击

**TextInput 的内置功能**：
- `selectByMouse: true` - 允许鼠标选择文本
- 自动处理焦点
- 自动触发 Qt.inputMethod

**不需要 MouseArea**：
- TextInput 自己可以接收点击事件
- TextInput 自己可以获得焦点
- TextInput 自己可以触发输入法

### 3. Qt.inputMethod 的触发条件

**必要条件**：
1. TextInput/TextField 直接接收鼠标事件
2. TextInput/TextField 获得焦点
3. TextInput/TextField 设置了 inputMethodHints
4. 没有其他组件拦截事件

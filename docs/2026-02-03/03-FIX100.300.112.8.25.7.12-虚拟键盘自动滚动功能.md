# FIX 100.300.112.8.25.7.12 - 虚拟键盘自动滚动功能

## 🎯 问题描述

用户反馈虚拟键盘遮挡底部输入框的问题：

**问题现象**：
- 虚拟键盘显示后，遮挡了底部的输入框
- 从"动作保护类型"以下的输入框都看不到了
- 用户无法看到正在编辑的内容

**用户需求**：
- 虚拟键盘显示时，自动向上滚动，使输入框可见
- 虚拟键盘关闭后，自动向下滚动回原来的位置

---

## 🔍 问题分析

### Qt官方解决方案调研

根据Qt论坛讨论和官方文档，Qt Virtual Keyboard没有内置的自动滚动功能，需要手动实现。

**参考资料**：
- [Qt Forum: How to deal with InputPanel covering input fields](https://forum.qt.io/topic/159498/how-to-deal-with-inputpanel-keyboard-covering-input-fields/9)
- [Qt Forum: QML VirtualKeyboard - AutoScroll Mode](https://forum.qt.io/topic/150853/qml-virtualkeyboard-autoscroll-mode/1)

### 常见解决方案

#### 方案1：调整Flickable的contentY（推荐）
```qml
Flickable {
    Connections {
        target: textField
        function onActiveFocusChanged() {
            if (textField.activeFocus) {
                contentY = Math.max(0,
                    (textField.y + (textField.height / 2)) -
                    ((container.height - inputPanel.height) / 2))
            }
        }
    }
}
```

#### 方案2：添加bottomMargin
```qml
StackView {
    Layout.bottomMargin: keyboard.isActive ? keyboard.height : 0
}
```
**缺点**：会压缩内容，使部分内容不可见

#### 方案3：Pop-up文本输入
创建覆盖层TextField，输入完成后传递到实际字段。
**缺点**：实现复杂，用户体验不佳

### 我们的实现方案

**选择方案1的改进版本**：
- 在CustomSpinBox中监听`Qt.inputMethod.visible`变化
- 虚拟键盘显示时：
  1. 保存当前滚动位置
  2. 计算输入框在ScrollView中的Y坐标
  3. 计算目标滚动位置（让输入框居中在可见区域）
  4. 平滑滚动到目标位置
- 虚拟键盘关闭时：
  1. 恢复原始滚动位置
  2. 恢复焦点到参数区域

## 🔧 修改内容

### 修改文件：CustomSpinBox.qml

**修改位置**: Line 125-234

**核心功能**：

#### 1. 虚拟键盘显示时自动滚动

```qml
if (Qt.inputMethod.visible && textInput.activeFocus) {
    // 查找ScrollView
    var scrollView = findScrollView(root.parent)
    if (scrollView) {
        // 保存当前滚动位置
        savedScrollY = scrollView.ScrollBar.vertical.position

        // 计算输入框在ScrollView中的Y坐标
        var inputY = getYInScrollView(root, scrollView)

        // 计算虚拟键盘高度（假设占屏幕高度的40%）
        var keyboardHeight = scrollView.height * 0.4

        // 计算可见区域高度（屏幕高度 - 虚拟键盘高度）
        var visibleHeight = scrollView.height - keyboardHeight

        // 计算目标滚动位置：让输入框居中在可见区域
        var targetY = inputY - (visibleHeight / 2) + (root.height / 2)

        // 限制滚动范围
        var maxScrollY = Math.max(0, scrollView.contentHeight - scrollView.height)
        targetY = Math.max(0, Math.min(targetY, maxScrollY))

        // 平滑滚动到目标位置
        scrollView.ScrollBar.vertical.position = targetY / scrollView.contentHeight
    }
}
```

#### 2. 虚拟键盘关闭时恢复滚动位置

```qml
else if (!Qt.inputMethod.visible && textInput.activeFocus) {
    // 恢复滚动位置
    var scrollView = findScrollView(root.parent)
    if (scrollView && savedScrollY !== undefined) {
        scrollView.ScrollBar.vertical.position = savedScrollY
    }

    // 恢复焦点到参数区域
```

#### 3. 辅助函数

**查找ScrollView**：
```qml
function findScrollView(item) {
    var current = item
    var depth = 0
    while (current && depth < 10) {
        // 检查是否是ScrollView（通过检查是否有ScrollBar属性）
        if (current.hasOwnProperty("ScrollBar")) {
            return current
        }
        current = current.parent
        depth++
    }
    return null
}
```

**计算元素在ScrollView中的Y坐标**：
```qml
function getYInScrollView(item, scrollView) {
    var y = 0
    var current = item
    while (current && current !== scrollView) {
        y += current.y
        current = current.parent
    }
    return y
}
```

## 💡 关键知识点

### 1. ScrollView的滚动控制

**ScrollBar.vertical.position**：
- 范围：0.0 到 1.0
- 0.0 = 顶部
- 1.0 = 底部
- 计算公式：`position = scrollY / contentHeight`

**contentHeight vs height**：
- `contentHeight`：内容的总高度
- `height`：可见区域的高度
- 最大滚动距离：`maxScrollY = contentHeight - height`

### 2. 虚拟键盘高度估算

**问题**：Qt.inputMethod没有提供键盘高度属性

**解决方案**：
- 假设虚拟键盘占屏幕高度的40%
- 根据实际测试调整这个比例
- 可以通过InputPanel的height属性获取更精确的值

**改进方案**（可选）：
```qml
// 在main_qds.qml中添加
property real keyboardHeight: virtualKeyboard.height

// 在CustomSpinBox中使用
var keyboardHeight = Qt.application.keyboardHeight || (scrollView.height * 0.4)
```

### 3. 滚动位置计算

**目标**：让输入框居中在可见区域

**计算公式**：
```javascript
targetY = inputY - (visibleHeight / 2) + (inputHeight / 2)
```

**解释**：
- `inputY`：输入框在ScrollView中的Y坐标
- `visibleHeight`：可见区域高度（屏幕高度 - 键盘高度）
- `inputHeight`：输入框高度
- 让输入框的中心点对齐可见区域的中心点

### 4. 为什么使用hasOwnProperty("ScrollBar")？

**原因**：
- ScrollView是Qt Quick Controls 2的组件
- 它有一个`ScrollBar`附加属性
- 通过检查这个属性可以准确识别ScrollView

**替代方案**：
```qml
// 检查类型名称
if (current.toString().indexOf("ScrollView") !== -1)

// 检查contentHeight属性
if (current.hasOwnProperty("contentHeight"))
```

### 5. 保存和恢复滚动位置

**为什么需要保存？**
- 虚拟键盘关闭后，用户期望回到原来的位置
- 提供更好的用户体验

**实现方式**：
```qml
Connections {
    property real savedScrollY: 0  // 保存在Connections对象中

    function onVisibleChanged() {
        if (visible) {
            savedScrollY = scrollView.ScrollBar.vertical.position
        } else {
            scrollView.ScrollBar.vertical.position = savedScrollY
        }
    }
}
```

## 🎯 关键发现

通过添加调试日志，我们可以确定：

1. **键盘事件是否被触发**：如果没有看到 "MotorControlPage 接收到 Up/Down 键"，说明焦点不在 MotorControlPage
2. **currentArea 是否正确**：如果 currentArea 不是 "A"，说明鼠标点击后区域被切换了
3. **motorListIndex 是否更新**：如果 motorListIndex 没有变化，说明 moveInMotorList 没有被调用
4. **currentMotorIndex 是否同步**：如果 currentMotorIndex 没有变化，说明 onMotorListIndexChanged 没有被触发或绑定失效

```qml
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.19]: 确保 currentArea 是 areaMotorList
if (navigationManager.currentArea !== navigationManager.areaMotorList) {
```

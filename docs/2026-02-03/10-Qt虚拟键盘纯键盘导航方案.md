# Qt虚拟键盘纯键盘导航方案

**日期**: 2026-02-03
**状态**: 📋 方案设计

---

## 🎯 需求描述

**场景**：
- 纯键盘操作（无鼠标）
- 类似电视遥控器：只有上下左右和确认键
- 虚拟键盘弹出后，如何使用方向键在虚拟键盘上导航并输入数据？

**两种输入方式**：
1. **物理键盘有数字键**：直接输入数字
2. **物理键盘无数字键**：使用方向键在虚拟键盘上导航，用回车键选择按键

---

## 🔍 Qt Virtual Keyboard 官方支持

### 官方文档

根据Qt官方文档，Qt Virtual Keyboard **原生支持**键盘导航：

> **Hardware key support for 2-way and 5-way navigation.**
>
> — [Qt Virtual Keyboard Overview](https://doc.qt.io/qt-6.7/qtvirtualkeyboard-overview.html)

**支持的导航方式**：
- **2-way navigation**：Tab键导航（前进/后退）
- **5-way navigation**：方向键导航（上下左右 + 确认）

### 关键特性

1. **activeFocusOnTab**：启用Tab键导航
2. **KeyNavigation**：配置方向键导航
3. **自动焦点管理**：虚拟键盘按键支持焦点切换

## 💡 实现方案

### 方案1：启用Qt Virtual Keyboard内置导航（推荐）

Qt Virtual Keyboard默认支持键盘导航，但需要正确配置。

#### 1.1 启用activeFocusOnTab

**修改InputPanel配置**：

```qml
// main_qds.qml
InputPanel {
    id: virtualKeyboard
    z: 99
    y: root.height - virtualKeyboard.height
    anchors.left: parent.left
    anchors.right: parent.right

    // ✅ 启用Tab键导航
    activeFocusOnTab: true

    // ✅ 启用键盘导航
    Keys.forwardTo: [virtualKeyboard]
}
```

#### 1.2 配置环境变量

Qt Virtual Keyboard通过环境变量控制导航模式：

```qml
// main_qds.qml - Component.onCompleted
Component.onCompleted: {
    // 启用5-way导航（方向键 + 确认键）
    Qt.application.setEnvironmentVariable("QT_VIRTUALKEYBOARD_DESKTOP_DISABLE", "0")
    Qt.application.setEnvironmentVariable("QT_VIRTUALKEYBOARD_STYLE", "retro")  // 可选：使用适合TV的样式
}
```

**或者在启动应用前设置**：

```powershell
# Windows PowerShell
$env:QT_VIRTUALKEYBOARD_DESKTOP_DISABLE = "0"
.\belt_control_system.exe
```

```bash
# Linux
export QT_VIRTUALKEYBOARD_DESKTOP_DISABLE=0
./belt_control_system
```

#### 1.3 工作原理

**导航流程**：
1. 虚拟键盘显示时，第一个按键自动获得焦点
2. 用户按方向键（↑↓←→）：焦点在虚拟键盘按键之间移动
3. 用户按回车键（Enter）：触发当前焦点按键的点击事件
4. 虚拟键盘将按键转换为输入事件，发送到输入框

**优点**：
- ✅ 官方支持，稳定可靠
- ✅ 无需修改代码
- ✅ 自动处理焦点管理
- ✅ 支持所有Qt Virtual Keyboard样式

### 方案2：自定义KeyNavigation（高级）

如果方案1不满足需求，可以自定义导航逻辑。

#### 2.1 为虚拟键盘按键添加KeyNavigation

**创建自定义InputPanel**：

```qml
// CustomInputPanel.qml
import QtQuick
import QtQuick.VirtualKeyboard

InputPanel {
    id: inputPanel

    // 获取虚拟键盘的所有按键
    property var keyboardKeys: []

    Component.onCompleted: {
        // 遍历虚拟键盘，找到所有按键
        findAllKeys(inputPanel)

        // 为每个按键配置KeyNavigation
        setupKeyNavigation()
    }

    function findAllKeys(item) {
        for (var i = 0; i < item.children.length; i++) {
            var child = item.children[i]

            // 检查是否是按键（通常有text属性）
            if (child.hasOwnProperty("text") && child.hasOwnProperty("clicked")) {
                keyboardKeys.push(child)

                // 启用焦点
                child.activeFocusOnTab = true
                child.focus = true
            }

            // 递归查找子元素
            if (child.children.length > 0) {
                findAllKeys(child)
            }
        }
    }

    function setupKeyNavigation() {
        // 假设键盘是网格布局（例如：10列）
        var columns = 10

        for (var i = 0; i < keyboardKeys.length; i++) {
            var key = keyboardKeys[i]

            // 配置上下左右导航
            key.KeyNavigation.left = keyboardKeys[i - 1] || key
            key.KeyNavigation.right = keyboardKeys[i + 1] || key
            key.KeyNavigation.up = keyboardKeys[i - columns] || key
            key.KeyNavigation.down = keyboardKeys[i + columns] || key

            // 配置回车键触发点击
            key.Keys.onReturnPressed = function() {
                key.clicked()
            }
        }

        // 第一个按键获得初始焦点
        if (keyboardKeys.length > 0) {
            keyboardKeys[0].forceActiveFocus()
        }
    }
}
```

**优点**：
- ✅ 完全自定义导航逻辑
- ✅ 可以适配特殊布局

**缺点**：
- ❌ 需要深入了解Qt Virtual Keyboard内部结构
- ❌ 维护成本高
- ❌ 可能与Qt版本不兼容

### 方案3：使用Qt Virtual Keyboard的Retro样式

Qt Virtual Keyboard提供了专门为TV/嵌入式设备设计的样式。

#### 3.1 启用Retro样式

```qml
// main_qds.qml
ApplicationWindow {
    id: root

    Component.onCompleted: {
        // 设置虚拟键盘样式为Retro（适合TV遥控器）
        Qt.application.setEnvironmentVariable("QT_VIRTUALKEYBOARD_STYLE", "retro")
    }
}
```

**或者在启动应用前设置**：

```powershell
# Windows PowerShell
$env:QT_VIRTUALKEYBOARD_STYLE = "retro"
.\belt_control_system.exe
```

#### 3.2 Retro样式特点

- **大按键**：适合遥控器操作
- **高对比度**：易于识别焦点
- **简化布局**：减少按键数量
- **内置导航**：自动支持方向键导航

## 🔧 故障排查

### 问题1：方向键不起作用

**原因**：Qt Virtual Keyboard默认可能只支持Tab键导航

**解决方案**：
1. 检查是否设置了`QT_VIRTUALKEYBOARD_DESKTOP_DISABLE=0`
2. 尝试使用Retro样式
3. 如果仍不起作用，使用方案2自定义KeyNavigation

### 问题2：焦点不在虚拟键盘上

**原因**：InputPanel没有获得焦点

**解决方案**：
```qml
InputPanel {
    id: virtualKeyboard

    onActiveChanged: {
        if (active) {
            // 虚拟键盘激活时，强制获取焦点
            forceActiveFocus()
        }
    }
}
```

### 问题3：回车键不触发按键点击

**原因**：虚拟键盘按键没有处理回车键事件

**解决方案**：
- 使用方案2，为每个按键添加`Keys.onReturnPressed`处理
- 或者使用Qt Virtual Keyboard的内置处理（通常已支持）

    id: key

    // 焦点指示器

        anchors.fill: parent
        color: "transparent"
        border.color: key.activeFocus ? "#2196F3" : "transparent"
        border.width: key.activeFocus ? 3 : 0
        radius: 4
    }
}

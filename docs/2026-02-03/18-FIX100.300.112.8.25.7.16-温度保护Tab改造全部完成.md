### 关键功能特性

1. **GridLayout 4列布局**：
   - 列定义：标签1（160px）、输入框1（fillWidth, max 300）、标签2（160px）、输入框2（fillWidth, max 300）
   - 列间距：10px
   - 行间距：12px
   - 总宽度：`paramScrollView.width * 0.9`

2. **CustomSpinBox 虚拟键盘支持**：
   - 内置 `activateVirtualKeyboard()` 方法
   - 自动滚动到可见位置
   - 支持数字输入

3. **CustomComboBox 下拉选择**：
   - 回车键切换选项：`currentIndex = (currentIndex + 1) % model.length`
   - 不需要虚拟键盘

4. **焦点管理**：
   - 焦点指示器：蓝色边框（#2196F3），宽度3px，z值1000
   - 鼠标点击发射 `requestFocusParamIndex(paramIndex)` 信号
   - 焦点索引通过 `focusParamIndex` 属性传递

5. **条件显示/启用**：
   - 次数设置：`enabled: alarmTypeField.currentIndex === 0`
   - 时间设置：`enabled: alarmTypeField.currentIndex === 1`
   - 标签颜色：启用时 `#9E9E9E`，禁用时 `#3E3E3E`

## 💡 关键经验总结

### 1. 批量修改的效率

对于结构完全相同的文件，使用 sed 批量替换比手动修改效率高得多：
```bash
# 复制文件
cp FrontBearingTempTab.qml RearBearingTempTab.qml

# 批量替换类名
sed -i 's/FrontBearingTempTab/RearBearingTempTab/g' RearBearingTempTab.qml

# 批量替换中文名称
sed -i 's/前轴承温度/后轴承温度/g' RearBearingTempTab.qml
```

### 2. 参数索引的一致性

所有温度保护Tab使用相同的参数索引（0-10），确保：
- 焦点管理逻辑一致
- 导航函数实现一致
- 用户体验一致

### 3. 条件启用字段的实现

次数设置和时间设置根据报警类型条件启用：
```qml
// 启用状态
enabled: alarmTypeField.currentIndex === 0  // 按次数时启用

// 标签颜色
color: alarmTypeField.currentIndex === 0 ? "#9E9E9E" : "#3E3E3E"

// 导航函数中的检查
if (alarmTypeField.currentIndex === 0) {
    inputField = countSettingField
}
```

### 4. 虚拟键盘集成

CustomSpinBox 内置了虚拟键盘自动滚动功能：
- 调用 `activateVirtualKeyboard()` 方法
- 自动计算滚动距离
- 自动恢复焦点和滚动位置

### 5. 与 CurrentProtectionTab 的一致性

所有温度保护Tab现在与 CurrentProtectionTab 功能完全一致：
- 相同的参数数量（11个）
- 相同的控件类型（CustomComboBox、CustomSpinBox）
- 相同的虚拟键盘支持
- 相同的焦点管理和导航

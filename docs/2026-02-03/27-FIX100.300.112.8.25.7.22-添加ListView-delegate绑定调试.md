## 🎯 问题描述

### 用户反馈

测试后，背景图片还是不动。

### 日志分析

从最新日志来看，**关键发现**：

#### 鼠标点击时（Line -99 到 -97）
```
🔍 [DEBUG] MyMotorListPanel.currentMotorIndex 变化: 4
🔍 [DEBUG] 背景图片切换 - 电机 2 source: ../../../images/bhNameBK.png  ✅
🔍 [DEBUG] 背景图片切换 - 电机 5 source: ../../../images/bhNameBK1.png  ✅
```

#### 导航键操作时（4次 Up 键）
```
motorListIndex: 4 → 3 → 2 → 1 → 0  ✅ 正确更新
currentMotorIndex: 4 → 3 → 2 → 1 → 0  ✅ 正确更新
```

**但是没有任何 "背景图片切换" 的日志！** ❌

### 根本原因

**ListView delegate 中的属性绑定没有正确响应 `root.currentMotorIndex` 的变化。**

这是一个常见的 QML 问题：
1. **鼠标点击时**：直接修改 `root.currentMotorIndex`，触发了 `onCurrentMotorIndexChanged`，所以背景图片切换了
2. **导航键操作时**：虽然 `root.currentMotorIndex` 更新了，但 ListView delegate 中的绑定表达式 `root.currentMotorIndex === index` 没有重新计算

可能的原因：
- ListView delegate 是动态创建的，绑定可能没有正确建立
- `index` 变量在 delegate 中可能没有正确声明为 `required property`
- QML 的绑定系统在 ListView delegate 中可能有延迟或失效

---

## 🔧 解决方案

### 方案1：添加 required property 声明

在 delegate 中显式声明 `index` 为 `required property`：

```qml
delegate: Rectangle {
    // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.22]: 添加必需的属性声明
    required property int index  // ListView 自动提供的索引

    // ...
}
```

### 方案2：添加 Connections 监听

使用 `Connections` 显式监听 `root.currentMotorIndexChanged` 信号：

```qml
Image {
    id: backgroundImage
    source: root.currentMotorIndex === index ? "bhNameBK1.png" : "bhNameBK.png"

    // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.22]: 监听 currentMotorIndex 变化
    Connections {
        target: root
        function onCurrentMotorIndexChanged() {
            console.log("🔍 [DEBUG] Connections 监听到 currentMotorIndex 变化 - 电机", index + 1, "新值:", root.currentMotorIndex)
        }
    }
}
```

### 方案3：添加详细调试日志

添加更多调试日志来确认绑定是否工作：

```qml
Component.onCompleted: {
    console.log("🔍 [DEBUG] 背景图片组件创建 - 电机", index + 1, "初始 source:", source)
}

onSourceChanged: {
    console.log("🔍 [DEBUG] 背景图片切换 - 电机", index + 1, "source:", source, "currentMotorIndex:", root.currentMotorIndex)
}
```

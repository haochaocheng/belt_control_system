### 根本原因

**Qt.binding() 被破坏了！**

在 `MyMotorListPanel.qml` Line 172，鼠标点击时直接赋值：

```qml
MouseArea {
    onClicked: {
        root.currentMotorIndex = index  // ❌ 这会破坏 Qt.binding()！
        root.motorSelected(index)
        root.focus = true
    }
}
```

**Qt.binding() 的工作原理**：
1. 在 `MotorControlPage.qml` Line 253，我们使用 `Qt.binding()` 建立绑定：
   ```qml
   item.currentMotorIndex = Qt.binding(function() { return root.currentMotorIndex })
   ```

2. 这会建立一个**单向绑定**：`MotorControlPage.root.currentMotorIndex` → `MyMotorListPanel.currentMotorIndex`

3. **但是**，如果在 `MyMotorListPanel` 中直接赋值 `root.currentMotorIndex = index`，这个绑定就会被**永久破坏**

4. 一旦绑定被破坏，后续的 `MotorControlPage.root.currentMotorIndex` 变化就不会再传递到 `MyMotorListPanel.currentMotorIndex`

**为什么鼠标点击时看起来正常？**
- 因为直接赋值 `root.currentMotorIndex = index` 会触发一次 `onCurrentMotorIndexChanged`
- 所以鼠标点击时，背景图片会切换一次
- **但是绑定已经被破坏了**
- 所以后续的导航键操作就不会再触发 `MyMotorListPanel.currentMotorIndex` 的变化

**完整的问题流程**：

## 🔧 解决方案

### 方案：移除 MyMotorListPanel 中的直接赋值

**核心思想**：
- MyMotorListPanel 只负责显示和发送信号
- 所有状态更新由父组件 MotorControlPage 通过绑定传递
- 不要在子组件中直接修改绑定的属性

### 修改内容

#### 修改文件：MyMotorListPanel.qml（Line 171-175）

```qml
// 修改前
MouseArea {
    anchors.fill: parent
    onClicked: {
        root.currentMotorIndex = index  // ❌ 破坏 Qt.binding()
        root.motorSelected(index)
        root.focus = true
    }
}

// 修改后
MouseArea {
    anchors.fill: parent
    onClicked: {
        // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.23]: 移除直接赋值，避免破坏 Qt.binding()
        // root.currentMotorIndex = index  // ❌ 这会破坏 Qt.binding()，导致后续导航键操作时绑定失效
        root.motorSelected(index)  // ✅ 只发送信号，让父组件通过绑定更新
        // root.focus = true  // ❌ 不需要，焦点由父组件管理
    }
}
```

## 📊 Qt.binding() 最佳实践

### ✅ 正确用法

**父组件（MotorControlPage.qml）**：
```qml
Loader {
    onLoaded: {
        // 建立单向绑定：父 → 子
        item.currentMotorIndex = Qt.binding(function() { return root.currentMotorIndex })

        // 监听子组件信号，更新父组件状态
        item.motorSelected.connect(function(motorIndex) {
            root.currentMotorIndex = motorIndex  // ✅ 在父组件中更新
        })
    }
}
```

**子组件（MyMotorListPanel.qml）**：
```qml
property int currentMotorIndex: 0  // 只读属性，由父组件通过绑定更新

MouseArea {
    onClicked: {
        // ✅ 只发送信号，不直接修改属性
        root.motorSelected(index)
    }
}
```

### ❌ 错误用法

**子组件中直接赋值**：
```qml
MouseArea {
    onClicked: {
        root.currentMotorIndex = index  // ❌ 破坏绑定
        root.motorSelected(index)
    }
}
```

### 核心原则

1. **单向数据流**：父组件 → 子组件（通过绑定）
2. **信号向上传递**：子组件 → 父组件（通过信号）
3. **不要在子组件中修改绑定的属性**：会破坏绑定

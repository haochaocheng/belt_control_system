## 🎯 问题描述

### 用户报告的问题

测试步骤：
1. 使用导航键从电机控制切换到电机列表1号电机
2. 继续切换到2号电机 → ✅ 蓝色边框和背景图片都在2号电机
3. 鼠标点击5号电机 → ❌ **背景图片切换到5号电机，但蓝色边框还在2号电机**
4. 继续使用导航键 → ❌ **蓝色边框跟随移动，但背景图片一直停留在5号电机**

### 问题分析

**根本原因**：焦点状态和选中状态使用了两个不同的变量，鼠标点击时没有同步更新。

在 `MyMotorListPanel.qml` 中：
- **蓝色边框**（Line 88-95）：由 `focusItemIndex` 控制
- **背景图片**（Line 98-125）：由 `currentMotorIndex` 控制

鼠标点击处理（Line 169-176）：
```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        root.currentMotorIndex = index  // ✅ 更新了 currentMotorIndex（背景图片会变）
        root.motorSelected(index)       // ✅ 发射信号
        root.focus = true               // ✅ 获取焦点
        // ❌ 但没有更新 focusItemIndex（蓝色边框不会变）
    }
}
```

### 状态流转图

```
导航键操作：
NavigationManager.motorListIndex 变化
  ↓
MotorControlPage.onMotorListIndexChanged
  ↓
同时更新：currentMotorIndex + focusItemIndex
  ↓
MyMotorListPanel 同时更新：背景图片 + 蓝色边框 ✅

鼠标点击操作（当前）：
MouseArea.onClicked
  ↓
只更新：currentMotorIndex
  ↓
MyMotorListPanel 只更新：背景图片 ❌
蓝色边框不变 ❌
```

## 🔧 解决方案

### 方案：鼠标点击时同步更新 focusItemIndex

**修改文件**：`src/qml/components/device_info/pages/MotorControlPage.qml`

**修改位置**：Line 253-258（MotorListPanel 的属性绑定）

**修改内容**：

在 `motorSelected` 信号处理中，同时更新 `focusItemIndex`：

```qml
// 修改前（Line 257-258）
item.onMotorSelected.connect(function(motorIndex) {
    root.currentMotorIndex = motorIndex
})

// 修改后
item.onMotorSelected.connect(function(motorIndex) {
    root.currentMotorIndex = motorIndex
    root.focusItemIndex = motorIndex  // ✅ 同步更新 focusItemIndex
    navigationManager.motorListIndex = motorIndex  // ✅ 同步更新 NavigationManager
})
```

### 修改后的状态流转

```
鼠标点击操作（修改后）：
MouseArea.onClicked
  ↓
更新：currentMotorIndex
发射：motorSelected(index)
  ↓
MotorControlPage.onMotorSelected
  ↓
同时更新：currentMotorIndex + focusItemIndex + navigationManager.motorListIndex
  ↓
MyMotorListPanel 同时更新：背景图片 + 蓝色边框 ✅
```

## 🎉 修复完成总结

### 问题
鼠标点击电机列表时，背景图片切换但蓝色边框不跟随，导致焦点状态和选中状态不同步。

### 解决方案
在 `motorSelected` 信号处理中，同时更新 `focusItemIndex` 和 `navigationManager.motorListIndex`，确保三个状态变量同步：
- `currentMotorIndex`（背景图片）
- `focusItemIndex`（蓝色边框）
- `navigationManager.motorListIndex`（导航系统）

## 🎯 问题描述

### 用户反馈

还是不行，pjsip.md 日志，无法左键返回到电机控制大类。

### 日志分析

```
Line -33: MotorControlPage 接收到 returnToCategory 信号，释放焦点
Line -32: DeviceSettingsDialog 接收到 requestDialogFocus 信号，获取焦点  ✅
Line -31: 定时器触发，重置标志
Line -30: MotorControlPage 接收键盘事件: Down  ❌ 还是接收到了！
Line -29: NavigationManager 方向键: Down
```

**焦点变化日志**：
```
只有一次：MotorControlPage 焦点变化: false
```

**关键发现**：
- DeviceSettingsDialog 确实调用了 `forceActiveFocus()`
- MotorControlPage 的焦点确实变为 false
- 但是 MotorControlPage 仍然接收键盘事件！

### 根本原因

**`focus: true` 导致自动重新获取焦点！**

在 MotorControlPage.qml Line 221：
```qml
focus: true
activeFocusOnTab: true
```

**问题流程**：
```
1. 用户按左键
2. MotorControlPage 触发 returnToCategory
3. MotorControlPage 发出 requestDialogFocus 信号
4. DeviceSettingsDialog 调用 forceActiveFocus()
5. MotorControlPage 焦点变为 false ✅
6. 但是 focus: true 属性导致 MotorControlPage 自动重新获取焦点 ❌
7. MotorControlPage 又能接收键盘事件了 ❌
```

**为什么 `focus: true` 会自动重新获取焦点？**
- `focus: true` 表示组件希望获取焦点
- 当父组件（DeviceSettingsDialog）有焦点时，QML 会自动将焦点分配给设置了 `focus: true` 的子组件
- 即使调用了 `forceActiveFocus()`，焦点仍然会被自动分配回去

---

## 🔧 解决方案

### 方案：使用 enabled 属性禁用键盘事件接收

**核心思想**：
- 不修改 `focus` 属性（保持 `focus: true`）
- 使用 `enabled` 属性来控制是否接收键盘事件
- 在 `onReturnToCategory` 中设置 `enabled = false`
- 在重新进入电机控制页面时设置 `enabled = true`

### 修改内容

#### 1. 添加 enabled 属性控制（Line 221-223）

```qml
// 修改前
focus: true
activeFocusOnTab: true

// 修改后
// ✅ 2026-01-30 [FIX 100.300.106]: 允许接收焦点，以便虚拟键盘关闭后焦点可以返回
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.24.6]: 使用 enabled 控制是否接收键盘事件
focus: true
activeFocusOnTab: true
enabled: root.currentCategory === 3  // 只有在电机控制类别时才启用
```

**等等！这个方案不对！**

`enabled` 属性会禁用整个组件，包括鼠标事件。这不是我们想要的。

### 更好的方案：在 Keys 处理器中检查 currentFocusArea

**核心思想**：
- 不修改 `focus` 或 `enabled` 属性
- 在所有 Keys 处理器中，检查 `currentFocusArea` 是否为 2（内容区域）
- 如果不是，则忽略键盘事件

### 修改内容

#### 修改所有 Keys 处理器，添加 currentFocusArea 检查

```qml

```

**等等！这个方案也不对！**

`currentFocusArea` 是 DeviceSettingsDialog 的属性，MotorControlPage 可能无法访问。

### 最终方案：在 onReturnToCategory 中禁用 Keys 处理器

**核心思想**：
- 添加一个标志 `keysEnabled`
- 在 `onReturnToCategory` 中设置 `keysEnabled = false`
- 在所有 Keys 处理器中检查 `keysEnabled`
- 在重新进入电机控制页面时设置 `keysEnabled = true`

## 🎯 需求描述

**场景**：
- 纯键盘操作（无鼠标）
- 类似电视遥控器：只有上下左右和确认键
- 虚拟键盘弹出后，如何使用方向键在虚拟键盘上导航并输入数据？

**两种输入方式**：
1. **物理键盘有数字键**：直接输入数字
2. **物理键盘无数字键**：使用方向键在虚拟键盘上导航，用回车键选择按键

---

## 🔍 解决方案

根据Qt官方文档，Qt Virtual Keyboard **原生支持**键盘导航：

> **Hardware key support for 2-way and 5-way navigation.**
>
> — [Qt Virtual Keyboard Overview](https://doc.qt.io/qt-6.7/qtvirtualkeyboard-overview.html)

**支持的导航方式**：
- **2-way navigation**：Tab键导航（前进/后退）
- **5-way navigation**：方向键导航（上下左右 + 确认）

## 🔧 修改内容

### 1. 启用虚拟键盘导航

**修改文件**: `src/qml/main_qds.qml`

**修改位置**: Line 254-269

Component.onCompleted: {

    console.log("   - 虚拟键盘导航已启用（Tab键/方向键）")

**关键配置**：

### 2. 启用Tab键导航

**修改文件**: `src/qml/main_qds.qml`

**修改位置**: Line 271-285

**修改内容**：
```qml
// ✅ 2026-02-02 [FIX 100.300.112.8.25.7.7]: 使用 inputPanel.active（参考Qt官方示例）
// Qt官方示例绑定到 inputPanel.active，不是 Qt.inputMethod.visible
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.13]: 启用Tab键导航
InputPanel {
    id: virtualKeyboard
    z: 99
    x: 0
    width: root.width

    // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.13]: 启用Tab键导航
    // 允许使用Tab键在虚拟键盘按键之间导航
    activeFocusOnTab: true

    property real yPositionWhenHidden: root.height
    y: yPositionWhenHidden
```

**关键配置**：
- `activeFocusOnTab: true`：启用Tab键导航

## ✅ 工作原理

### 导航流程

1. **虚拟键盘显示**：
   - 用户在输入框按回车键
   - 虚拟键盘显示
   - 第一个按键自动获得焦点（如果启用了导航）

2. **使用Tab键导航**：
   - 用户按Tab键 → 焦点移动到下一个按键
   - 用户按Shift+Tab → 焦点移动到上一个按键

3. **使用方向键导航**（如果支持）：
   - 用户按↑↓←→ → 焦点在按键之间移动
   - Qt Virtual Keyboard会根据按键的位置自动计算导航路径

4. **选择按键**：
   - 用户按回车键 → 触发当前焦点按键的点击事件
   - 虚拟键盘将按键转换为输入事件，发送到输入框

5. **关闭虚拟键盘**：
   - 用户按ESC键 → 虚拟键盘关闭
   - 焦点恢复到输入框所在的参数区域

## 🔧 故障排查

### 问题1：Tab键不起作用

**可能原因**：
- `activeFocusOnTab`未设置
- 环境变量未生效

**解决方案**：
1. 检查`activeFocusOnTab: true`是否已添加
2. 检查环境变量是否正确设置
3. 重新启动应用

### 问题2：方向键不起作用

**可能原因**：
- Qt Virtual Keyboard默认可能只支持Tab键导航
- 需要额外配置或使用Retro样式

**解决方案**：
1. 尝试启用Retro样式
2. 如果仍不起作用，使用Tab键导航（这是正常的）
3. 参考方案2自定义KeyNavigation（高级）

### 问题3：焦点不在虚拟键盘上

**可能原因**：
- InputPanel没有获得焦点

**解决方案**：
```qml
InputPanel {
    id: virtualKeyboard

    onActiveChanged: {
        if (active) {
            // 虚拟键盘激活时，强制获取焦点
            forceActiveFocus()
        }
    }
}
```

### 问题4：回车键不触发按键点击

**可能原因**：
- 虚拟键盘按键没有处理回车键事件

**解决方案**：
- 通常Qt Virtual Keyboard已经内置了回车键处理
- 如果不起作用，参考方案2自定义处理

- 鼠标点击电机后，状态同步正常 ✅
- 焦点也正常 ✅
- 但是按左键时，**连续触发了两次** `requestReturnToCategory` 信号 ❌

### 根本原因

**左键事件被处理了两次**：

1. **第一次**：`Keys.onLeftPressed` 触发，发出 `requestReturnToCategory()` 信号
2. **第二次**：DeviceSettingsDialog 的 `Keys.onLeftPressed` 调用 `handleKeyPress("Left")`，又发出一次 `requestReturnToCategory()` 信号

**为什么会调用两次？**

在 DeviceSettingsDialog.qml Line 424-430：

```qml
Keys.onLeftPressed: function(event) {
    if (currentCategory === 3 && currentFocusArea === 2) {
        var motorPage = motorControlPageLoader.item
        if (motorPage && typeof motorPage.handleKeyPress === "function") {
            motorPage.handleKeyPress("Left")  // ❌ 重复调用！
            event.accepted = true
            return
        }
    }
}
```

**问题流程**：
```
1. 用户按左键
2. MotorControlPage 的 Keys.onLeftPressed 触发
3. 发出 requestReturnToCategory() 信号 ✅
4. 设置 event.accepted = true
5. 但是事件仍然传播到 DeviceSettingsDialog（或者 DeviceSettingsDialog 先处理？）
6. DeviceSettingsDialog 的 Keys.onLeftPressed 触发
7. 调用 motorPage.handleKeyPress("Left")
8. handleKeyPress 又发出 requestReturnToCategory() 信号 ❌
9. 结果：信号被触发了两次！
```

**为什么鼠标点击后才出现这个问题？**

可能是因为：
- 鼠标点击后，焦点状态或事件传播机制发生了变化
- 或者之前的某些状态阻止了重复触发，但鼠标点击后这些状态被重置了

## 🔧 解决方案

### 方案：使用 isReturningToCategory 标志防止重复处理

**核心思想**：
- 在 `Keys.onLeftPressed` 和 `handleKeyPress` 中都检查 `isReturningToCategory` 标志
- 当其中一个处理了左键并发出信号后，设置标志为 `true`
- 另一个检查到标志为 `true` 时，直接忽略事件
- 使用定时器延迟重置标志（100ms）

### 修改内容

#### 1. 修改 Keys.onLeftPressed（Line 303-329）

```qml
Keys.onLeftPressed: function(event) {
    // ✅ 2026-02-03 [FIX 100.300.112.8.25.7.25.4]: 添加标志检查，防止重复处理

    // 检查是否正在返回大类，避免重复处理
    if (isReturningToCategory) {
        console.log("⚠️ [MotorControlPage] Keys.onLeftPressed 正在返回大类，忽略 Left 键")
        event.accepted = true
        return
    }

    if (navigationManager.currentArea === navigationManager.areaMotorList) {
        console.log("✅ [MotorControlPage] 电机列表区域按左键，请求返回到左侧类别")
        // 设置标志，防止 handleKeyPress 重复处理
        root.isReturningToCategory = true
        root.requestReturnToCategory()
        // 启动定时器，延迟重置标志
        resetFlagTimer.start()
        event.accepted = true
    } else {
        // 其他区域由 NavigationManager 处理
        console.log("✅ [MotorControlPage] 其他区域按左键，由 NavigationManager 处理")
        navigationManager.handleDirectionKey("Left")
        event.accepted = true
    }
}
```

## 📊 为什么这个方案有效？

### 问题的本质

**双重处理机制**：
- MotorControlPage 有 `Keys.onLeftPressed` 处理器
- DeviceSettingsDialog 也有 `Keys.onLeftPressed` 处理器，会调用 `handleKeyPress`
- 两个处理器都会发出 `requestReturnToCategory()` 信号
- 导致信号被触发两次

### 解决方案的本质

**使用标志防止重复**：
- 第一个处理器（无论是 `Keys.onLeftPressed` 还是 `handleKeyPress`）设置标志
- 第二个处理器检查标志，如果已设置则忽略事件
- 使用定时器延迟重置标志，确保所有队列中的事件都被拦截

### 为什么使用定时器？

- **Qt 事件队列**：键盘事件可能在队列中等待处理
- **100ms 延迟**：足够长，确保所有队列中的事件都被处理
- **100ms 延迟**：足够短，用户感觉不到延迟

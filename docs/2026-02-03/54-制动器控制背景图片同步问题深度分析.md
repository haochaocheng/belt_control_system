## 🔍 架构分析

### BrakeControlPage 的架构

**与 SwitchInputPage 的关键区别**：

1. **SwitchInputPage**：
   - 列表和参数区域在同一个 QML 文件中
   - MouseArea 直接在 SwitchInputPage 内部
   - 可以直接更新 `root.focusItemIndex`

2. **BrakeControlPage**：
   - 使用独立的 **BrakeListPanel** 组件
   - MouseArea 在 BrakeListPanel 内部
   - 通过 `brakeSelected` 信号通知 BrakeControlPage

### 焦点状态绑定

**BrakeControlPage.qml**：
```qml
// Line 31-36: focusItemIndex 变化时同步 currentBrakeIndex
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex <= 7) {
        currentBrakeIndex = focusItemIndex
        navigationManager.brakeListIndex = focusItemIndex
    }
}

// Line 382: BrakeListPanel 的 currentBrakeIndex 绑定到 navigationManager.brakeListIndex
item.currentBrakeIndex = Qt.binding(function() { return navigationManager.brakeListIndex })

// Line 387-395: brakeSelected 信号处理
item.brakeSelected.connect(function(brakeIndex) {
    root.currentBrakeIndex = brakeIndex
    root.focusItemIndex = brakeIndex
    root.focusSubArea = 0
    navigationManager.brakeListIndex = brakeIndex
})
```

**BrakeListPanel.qml**：
```qml
// Line 97-98: 蓝色边框绑定到 focusItemIndex
border.color: (root.focusSubArea === 0 && root.focusItemIndex === index) ? "#2196F3" : "transparent"

// Line 116-130: 背景图片绑定到 currentBrakeIndex
states: [
    State {
        name: "selected"
        when: root.currentBrakeIndex === index
        PropertyChanges {
            target: backgroundImage
            source: "../../../images/bhNameBK1.png"
        }
    }
]
```

### 焦点同步链

```
鼠标点击
    ↓
BrakeListPanel.MouseArea:
- currentBrakeIndex = index
- 发射 brakeSelected(index) 信号
    ↓
BrakeControlPage 接收:
- currentBrakeIndex = brakeIndex
- focusItemIndex = brakeIndex
- focusSubArea = 0
- navigationManager.brakeListIndex = brakeIndex
    ↓
onFocusItemIndexChanged 触发:
- currentBrakeIndex = focusItemIndex
- navigationManager.brakeListIndex = focusItemIndex
    ↓
BrakeListPanel 的 currentBrakeIndex 绑定更新:
- item.currentBrakeIndex = navigationManager.brakeListIndex
    ↓
背景图片状态更新 ✅
```

## 🤔 可能的问题

### 问题 1：Qt.binding() 延迟更新

**假设**：
- BrakeListPanel 的 `currentBrakeIndex` 通过 `Qt.binding()` 绑定到 `navigationManager.brakeListIndex`
- 绑定的更新可能有延迟
- 导致背景图片不能立即跟随

**验证方法**：
- 在 BrakeListPanel 中添加 `onCurrentBrakeIndexChanged` 日志
- 查看 `currentBrakeIndex` 是否真的更新了

### 问题 2：State 切换延迟

**假设**：
- 背景图片使用 `State` 和 `when` 条件
- State 切换可能有延迟
- 导致背景图片不能立即更新

**验证方法**：
- 在 State 中添加 `onCompleted` 日志
- 查看 State 是否真的切换了

### 问题 3：focusItemIndex 和 currentBrakeIndex 不同步

**假设**：
- 蓝色边框绑定到 `focusItemIndex`
- 背景图片绑定到 `currentBrakeIndex`
- 两个属性没有完全同步

**验证方法**：
- 添加日志输出两个属性的值
- 查看是否有不一致

### 方案 2：直接绑定背景图片到 focusItemIndex

**目的**：避免通过 `currentBrakeIndex` 的间接绑定

```qml
// BrakeListPanel.qml
states: [
    State {
        name: "selected"
        when: (root.focusSubArea === 0 && root.focusItemIndex === index) || root.currentBrakeIndex === index
        PropertyChanges {
            target: backgroundImage
            source: "../../../images/bhNameBK1.png"
        }
    }
]
```

### 方案 3：使用 Connections 监听 navigationManager.brakeListIndex

**目的**：确保 BrakeListPanel 的 `currentBrakeIndex` 立即更新

```qml
// BrakeListPanel.qml
Connections {
    target: navigationManager
    function onBrakeListIndexChanged() {
        console.log("🔍 [BrakeListPanel] navigationManager.brakeListIndex 变化:", navigationManager.brakeListIndex)
        root.currentBrakeIndex = navigationManager.brakeListIndex
    }
}
```

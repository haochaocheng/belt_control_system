## 🎯 问题描述

### 用户反馈

测试完成，背景图片能跟随导航键了 ✅

**新问题**：导航键回到左侧电机控制侧时，上下键还是在电机列表切换，实际应该是电机控制大类切换。

### 三个关键现象

1. **鼠标点击后正常**：鼠标点击大类后，上下键可以切换类别 ✅
2. **之前左键可以返回**：之前按左键可以从电机列表返回到大类 ✅
3. **其他页面正常**：开关量输入和模拟量输入的列表切换正常 ✅

### 根本原因

**MotorControlPage 抢走了焦点，没有释放！**

在 FIX 100.300.112.8.25.7.20 中，我们添加了：
```qml
// Line 198-199
focus: true
activeFocusOnTab: true
```

这是为了修复鼠标点击后焦点丢失的问题。但是这导致了新问题：

**问题流程**：
```
1. 用户在电机控制页面，焦点在 MotorControlPage ✅
2. 用户按左键返回大类列表
3. NavigationManager 触发 returnToCategory() 信号 ✅
4. 但是 MotorControlPage 仍然持有焦点 ❌
5. 用户按上下键
6. 键盘事件被 MotorControlPage 接收 ❌
7. MotorControlPage 调用 NavigationManager.handleDirectionKey()
8. NavigationManager 认为当前在 areaMotorList，所以只切换电机 ❌
```

**为什么鼠标点击后正常？**
- 因为鼠标点击大类按钮时，焦点被转移到了 DeviceSettingsDialog
- 所以上下键可以正常切换类别

**为什么其他页面正常？**
- 因为开关量输入和模拟量输入页面没有设置 `focus: true`
- 所以焦点可以正常返回到 DeviceSettingsDialog

---

## 🔧 解决方案

### 方案：监听 returnToCategory 信号，释放焦点

**核心思想**：
- 当用户按左键返回大类时，NavigationManager 触发 `returnToCategory()` 信号
- MotorControlPage 监听这个信号，释放焦点
- 焦点返回到 DeviceSettingsDialog
- 上下键可以正常切换类别

### 修改内容

#### 修改文件：MotorControlPage.qml（Line 135-140）

```qml
// ✅ 2026-02-03 [FIX 100.300.112.8.25.7.24]: 监听 returnToCategory 信号，释放焦点
onReturnToCategory: {
    console.log("✅ [MotorControlPage] 接收到 returnToCategory 信号，释放焦点")
    // 释放焦点，让 DeviceSettingsDialog 接管键盘事件
    root.focus = false
}
```

### 修复后的完整流程

**用户按左键返回大类**：
```
1. 用户在电机控制页面，焦点在 MotorControlPage ✅
2. 用户按左键返回大类列表
3. NavigationManager 触发 returnToCategory() 信号 ✅
4. MotorControlPage 监听到信号，释放焦点（root.focus = false）✅
5. 焦点返回到 DeviceSettingsDialog ✅
6. 用户按上下键
7. 键盘事件被 DeviceSettingsDialog 接收 ✅
8. DeviceSettingsDialog 切换类别（基本配置 ↔ 开关量输入 ↔ 电机控制...）✅
```

**用户再按右键进入电机列表**：
```
1. 用户在大类列表，焦点在 DeviceSettingsDialog ✅
2. 用户按右键进入电机控制
3. DeviceSettingsDialog 切换到电机控制页面
4. MotorControlPage 加载，自动获取焦点（focus: true）✅
5. 用户按上下键
6. 键盘事件被 MotorControlPage 接收 ✅
7. NavigationManager 切换电机（1号 ↔ 2号 ↔ 3号...）✅
```

## 📊 为什么这个方案有效？

### 焦点管理的关键

**问题的本质**：
- MotorControlPage 设置了 `focus: true`，所以它会主动获取焦点
- 但是当用户返回大类列表时，MotorControlPage 没有释放焦点
- 导致键盘事件被 MotorControlPage 拦截，无法传递到 DeviceSettingsDialog

**解决方案的本质**：
- 监听 `returnToCategory` 信号，这是 NavigationManager 在用户按左键时触发的
- 释放焦点（`root.focus = false`），让焦点返回到父组件 DeviceSettingsDialog
- DeviceSettingsDialog 接管键盘事件，可以正常切换类别

### 为什么不影响其他功能？

1. **鼠标点击电机**：
   - 鼠标点击时，MotorControlPage 会强制恢复焦点（FIX 100.300.112.8.25.7.20）
   - 所以鼠标点击后，导航键仍然正常工作

2. **从右侧返回电机列表**：
   - 从右侧（Tab/参数/按钮）按左键返回电机列表时，不会触发 `returnToCategory` 信号
   - 所以焦点仍然在 MotorControlPage，导航键正常工作

3. **从大类进入电机控制**：
   - 当用户从大类列表进入电机控制时，MotorControlPage 重新加载
   - `focus: true` 会自动获取焦点，导航键正常工作

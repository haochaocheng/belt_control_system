## 💡 关键经验

### 1. 参数索引重新编号的重要性

插入新参数后，所有后续参数的索引都需要更新：
- 焦点指示器的 `focusParamIndex` 比较
- MouseArea 的 `requestFocusParamIndex` 信号参数
- triggerParamInput() 函数的 switch-case

### 2. 条件启用字段的实现

次数设置和时间设置根据报警类型条件启用：
```qml
// 启用状态
enabled: alarmTypeField.currentIndex === 0  // 按次数时启用

// 标签颜色
color: alarmTypeField.currentIndex === 0 ? "#9E9E9E" : "#3E3E3E"

// 导航函数中的检查
if (alarmTypeField.currentIndex === 0) {
    inputField = countSettingField
}
```

### 3. CustomSpinBox 虚拟键盘集成

CustomSpinBox 内置了虚拟键盘自动滚动功能：
- 调用 `activateVirtualKeyboard()` 方法
- 自动计算滚动距离
- 自动恢复焦点和滚动位置

### 4. CustomComboBox 不需要虚拟键盘

CustomComboBox 使用回车键切换选项：
```qml
enabledField.currentIndex = (enabledField.currentIndex + 1) % enabledField.model.length
```

### 5. Layout.row 值的更新

插入新行后，所有后续字段的 `Layout.row` 值需要 +1：
- 第二行（旧）→ 第三行（新）：row 1 → row 2
- 第三行（旧）→ 第四行（新）：row 2 → row 3
- 依此类推

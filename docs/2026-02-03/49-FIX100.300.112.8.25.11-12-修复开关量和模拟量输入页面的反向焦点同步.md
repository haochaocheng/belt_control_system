## 🎯 问题描述

### 用户反馈

用户测试开关量输入页面后报告：

> "导航键从开关量输入切换到急停时，鼠标点击堆煤，蓝色边框和背景图片同时出现在堆煤，但是此时，如果按上键，没有响应（默认焦点还是在急停），按向下键，焦点出现在跑偏。因此鼠标点击事件没有更新内部焦点。"

### 问题分析

**现象**：
1. 导航键从开关量输入切换到急停（第1项，index=0）
2. 鼠标点击堆煤（第7项，index=6）
3. 蓝色边框和背景图片同时出现在堆煤 ✅
4. 但是按上键，没有响应（焦点还是在急停）❌
5. 按向下键，焦点出现在跑偏（第2项，index=1）❌

**根本原因**：

鼠标点击时，我们更新了 `focusItemIndex`，但是 DeviceSettingsDialog 的 `currentContentItemIndex` 没有被同步更新。

**问题流程**：
```
1. 导航键切换到急停 → currentContentItemIndex = 0 ✅
2. 鼠标点击堆煤 → focusItemIndex = 6 ✅
3. ❌ 但是 currentContentItemIndex 仍然是 0 ❌
4. 按上键 → currentContentItemIndex-- → currentContentItemIndex = -1 ❌
5. 因为 currentContentItemIndex < 0，所以没有响应 ❌
6. 按向下键 → currentContentItemIndex++ → currentContentItemIndex = 0 ❌
7. 焦点跳到急停（index=0）❌
8. 再按向下键 → currentContentItemIndex++ → currentContentItemIndex = 1 ✅
9. 焦点跳到跑偏（index=1）✅
```

### 对比 MotorControlPage

MotorControlPage 有反向焦点同步（Line 1465-1479）：

```qml
Connections {
    target: motorControlPageLoader.item
    enabled: motorControlPageLoader.item !== null

    function onFocusItemIndexChanged() {
        if (root.currentCategory === 3 &&
            root.currentFocusArea === 2 &&
            motorControlPageLoader.item.focusSubArea === 0 &&
            motorControlPageLoader.item.focusItemIndex >= 0) {
            // 只在焦点在电机列表区域时同步
            console.log("✅ [DeviceSettingsDialog] 同步电机列表焦点:", motorControlPageLoader.item.focusItemIndex)
            root.currentContentItemIndex = motorControlPageLoader.item.focusItemIndex
        }
    }
}
```

但是 SwitchInputPage 和 AnalogInputPage 没有这个反向同步！

## 🔧 解决方案

### 方案：添加反向焦点同步 Connections

**核心思想**：
- 监听 `switchInputPageLoader.item.focusItemIndex` 的变化
- 当 `focusItemIndex` 变化时，同步更新 `currentContentItemIndex`
- 这样鼠标点击后，导航键就能正确工作

### 修改内容

#### 1. DeviceSettingsDialog.qml - SwitchInputPage 反向焦点同步（Line 1266-1282）

```qml
// ✅ 2026-02-03 [FIX 100.300.112.8.25.11]: SwitchInputPage 反向焦点同步（从 Page 到 Dialog）
// 当用户在开关量列表中导航或鼠标点击时，同步更新 Dialog 的 currentContentItemIndex
Connections {
    target: switchInputPageLoader.item
    enabled: switchInputPageLoader.item !== null

    function onFocusItemIndexChanged() {
        if (root.currentCategory === 1 &&
            root.currentFocusArea === 2 &&
            switchInputPageLoader.item.focusSubArea === 0 &&
            switchInputPageLoader.item.focusItemIndex >= 0) {
            // 只在焦点在列表区域时同步
            console.log("✅ [DeviceSettingsDialog] 同步开关量列表焦点:", switchInputPageLoader.item.focusItemIndex)
            root.currentContentItemIndex = switchInputPageLoader.item.focusItemIndex
        }
    }
}
```

## 📊 为什么这个方案有效？

### 问题的本质

**双向绑定缺失**：
- DeviceSettingsDialog 使用 `currentContentItemIndex` 管理导航
- 页面使用 `focusItemIndex` 管理焦点
- 之前只有单向绑定：`currentContentItemIndex` → `focusItemIndex`
- 缺少反向绑定：`focusItemIndex` → `currentContentItemIndex`

### 解决方案的本质

**添加反向绑定**：
- 监听 `focusItemIndex` 的变化
- 当 `focusItemIndex` 变化时，同步更新 `currentContentItemIndex`
- 这样鼠标点击后，两个状态保持同步

### 焦点同步架构

```
DeviceSettingsDialog                    Page
┌─────────────────────┐                ┌──────────────────┐
│ currentContentItemIndex │ ──────────> │ focusItemIndex   │
│                     │ <────────── │                  │
└─────────────────────┘                └──────────────────┘
     (导航键控制)                          (鼠标点击控制)
```

**双向同步**：
- 导航键 → `currentContentItemIndex` 变化 → 同步到 `focusItemIndex`
- 鼠标点击 → `focusItemIndex` 变化 → 同步到 `currentContentItemIndex`

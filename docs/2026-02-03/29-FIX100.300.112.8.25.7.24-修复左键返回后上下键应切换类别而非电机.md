# FIX 100.300.112.8.25.7.24 - 修复左键返回后上下键应切换类别而非电机

**日期**: 2026-02-03
**任务编号**: FIX 100.300.112.8.25.7.24
**状态**: 🔄 规划中

---

## 🎯 问题描述

### 用户反馈

测试完成，背景图片能跟随导航键了 ✅

**新问题**：导航键回到左侧电机控制侧时，上下键还是在电机列表切换，实际应该是电机控制大类切换。

### 问题分析

**当前行为**：
1. 用户在电机控制页面，焦点在右侧（Tab/参数/按钮区）
2. 按左键返回左侧 → 焦点进入 `areaMotorList`（电机列表区）
3. 按上下键 → 只能切换电机（1-8号）❌

**期望行为**：
1. 用户在电机控制页面，焦点在右侧（Tab/参数/按钮区）
2. 按左键返回左侧 → 焦点应该回到**类别列表**（"电机控制"按钮）
3. 按上下键 → 应该切换类别（基本配置 ↔ 开关量输入 ↔ 模拟量输入 ↔ 电机控制...）✅
4. 按右键 → 进入电机列表（如果当前类别是电机控制）

### 根本原因

**左侧有两个层级，但当前只实现了一个**：

1. **类别列表层级**（未实现导航）：
   - 基本配置（index 0）
   - 开关量输入（index 1）
   - 模拟量输入（index 2）
   - 电机控制（index 3）
   - 制动器控制（index 4）
   - 张紧控制（index 5）
   - 逻辑控制（index 6）

2. **电机列表层级**（已实现导航）：
   - 仅在"电机控制"类别下显示
   - 1号电机 ~ 8号电机

**当前 NavigationManager 的问题**：
- 只有一个 `areaMotorList` 区域，对应电机列表层级
- 没有类别列表层级的导航区域
- 从右侧返回左侧时，直接进入 `areaMotorList`，跳过了类别列表层级

---

## 🔧 解决方案

### 方案：新增类别列表导航区域

**核心思想**：
- 将左侧分为两个导航区域：
  1. **类别列表区域**（新增）：`areaCategoryList`
  2. **电机列表区域**（现有）：`areaMotorList`
- 从右侧返回左侧时，先回到类别列表区域
- 在类别列表区域按右键，才进入电机列表区域（仅限电机控制类别）

### 导航层级结构

```
左侧区域：
  ├─ 类别列表区域（areaCategoryList）⭐ 新增
  │   ├─ 基本配置（0）
  │   ├─ 开关量输入（1）
  │   ├─ 模拟量输入（2）
  │   ├─ 电机控制（3）
  │   ├─ 制动器控制（4）
  │   ├─ 张紧控制（5）
  │   └─ 逻辑控制（6）
  │
  └─ 电机列表区域（areaMotorList）✅ 现有
      ├─ 1号电机（0）
      ├─ 2号电机（1）
      ├─ ...
      └─ 8号电机（7）

右侧区域：
  ├─ Tab导航区（areaTabBar）
  ├─ 参数区域（areaParams）
  └─ 底部按钮区（areaButtons）
```

### 导航逻辑

#### 1. 类别列表区域（areaCategoryList）

**上下键**：切换类别（0-6）
```qml
function moveInCategoryList(direction) {
    var newIndex = categoryIndex

    switch(direction) {
    case "Up":
        if (categoryIndex > 0) {
            newIndex = categoryIndex - 1
        }
        break

    case "Down":
        if (categoryIndex < 6) {  // 共7个类别（0-6）
            newIndex = categoryIndex + 1
        }
        break

    case "Right":
        // 如果当前类别是电机控制（3），进入电机列表
        if (categoryIndex === 3) {
            switchToArea(areaMotorList)
        } else {
            // 其他类别，直接进入Tab导航区
            switchToArea(areaTabBar)
        }
        return

    case "Left":
        // 在类别列表，左键无效（已经在最左侧）
        break
    }

    if (newIndex !== categoryIndex) {
        categoryIndex = newIndex
        console.log("✅ [NavigationManager] 类别索引:", newIndex)
    }
}
```

#### 2. 电机列表区域（areaMotorList）

**上下键**：切换电机（0-7）
**左键**：返回类别列表区域
**右键**：进入Tab导航区

```qml
function moveInMotorList(direction) {

```

#### 3. Tab导航区（areaTabBar）

**左键**：
- 如果当前类别是电机控制（3），返回电机列表区域
- 其他类别，返回类别列表区域

```qml
function moveInTabBar(direction) {

    case "Left":
        if (tabIndex > 0) {
            newIndex = tabIndex - 1

            } else {
                switchToArea(areaCategoryList)
            }
            return
        }
        break

    // ... 其他方向键逻辑不变
    }
}
```

#### 4. 参数区域（areaParams）和按钮区域（areaButtons）

**向上返回Tab导航区时，Tab导航区再向左返回**：
- 如果当前类别是电机控制（3），返回电机列表区域
- 其他类别，返回类别列表区域

- 导致切换到 B 区域，跳过了电机列表 ❌

### 根本原因

**重置时机不对！**

**问题流程**：
```
1. 用户在电机列表，按左键
2. MotorControlPage 发出 requestReturnToCategory 信号
3. DeviceSettingsDialog 接收信号
4. 重置 NavigationManager.currentArea = A（电机列表）✅
5. 设置 currentFocusArea = 1（左侧类别）✅
6. 用户在大类列表，按右键
7. DeviceSettingsDialog 设置 currentFocusArea = 2（右侧内容区域）
8. ❌ 但是 NavigationManager.currentArea 仍然是 A ❌
9. 用户再按右键
10. NavigationManager 从 A 切换到 B（Tab区域）❌
11. 跳过了电机列表 ❌
```

**为什么会这样？**

在 `requestReturnToCategory` 中重置 `currentArea = A`，但是用户从大类按右键进入电机控制时，`onCurrentFocusAreaChanged` 也会重置 `currentArea = A`。

**问题在于**：用户从大类按右键进入电机控制后，**立即**按右键，此时 NavigationManager 认为还在 A 区域，所以切换到 B 区域。

**正确的逻辑应该是**：
- 不在 `requestReturnToCategory` 中重置
- 只在 `onCurrentFocusAreaChanged` 中重置
- 这样当用户从大类进入电机控制时，才会重置到 A 区域
- 用户再按右键时，才会从 A 切换到 B

---

## 🔧 解决方案

### 方案：移除 requestReturnToCategory 中的重置逻辑

**核心思想**：
- 不在 `requestReturnToCategory` 中重置 NavigationManager.currentArea
- 只在 `onCurrentFocusAreaChanged` 中重置
- 确保进入内容区域时才重置，而不是返回大类时重置

### 修改内容

#### 修改 DeviceSettingsDialog.qml 的 requestReturnToCategory 处理（Line 1371-1377）

```qml
// 修改前
item.requestReturnToCategory.connect(function() {
    console.log("✅ [DeviceSettingsDialog] 接收到返回类别请求")
    console.log("🔍 [DEBUG] item:", item)
    console.log("🔍 [DEBUG] item.navigationManager:", item.navigationManager)
    // 重置 NavigationManager 到电机列表区域，这样下次按右键时会从电机列表开始
    if (item.navigationManager) {
        console.log("✅ [DeviceSettingsDialog] 重置 NavigationManager.currentArea 到电机列表区域")
        console.log("🔍 [DEBUG] 重置前 currentArea:", item.navigationManager.currentArea)
        item.navigationManager.currentArea = item.navigationManager.areaMotorList
        console.log("🔍 [DEBUG] 重置后 currentArea:", item.navigationManager.currentArea)
    } else {
        console.log("⚠️ [DeviceSettingsDialog] navigationManager 不存在，无法重置")
    }
    root.currentFocusArea = 1  // 切换到左侧类别区域
})

// 修改后
item.requestReturnToCategory.connect(function() {
    console.log("✅ [DeviceSettingsDialog] 接收到返回类别请求")
    // ❌ 不在这里重置 NavigationManager.currentArea
    // 因为用户可能在大类列表按右键，此时会直接进入内容区域
    // 应该在 onCurrentFocusAreaChanged 中重置，确保进入内容区域时才重置
    root.currentFocusArea = 1  // 切换到左侧类别区域
})
```

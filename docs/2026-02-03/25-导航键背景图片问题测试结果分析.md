## 🤔 关于 MyMotorListPanel.currentMotorIndex 变化日志缺失的分析

### 绑定代码（MotorControlPage.qml Line 277）

```qml
item.currentMotorIndex = Qt.binding(function() { return root.currentMotorIndex })
```

### 监听代码（MyMotorListPanel.qml Line 22-24）

```qml
onCurrentMotorIndexChanged: {
    console.log("🔍 [DEBUG] MyMotorListPanel.currentMotorIndex 变化:", currentMotorIndex)
}
```

### 可能的原因

#### 原因1：日志被截断（最可能）

- 日志文件只显示了最后100行
- `MyMotorListPanel.currentMotorIndex 变化` 的日志可能在更早的位置
- 需要查看完整日志

#### 原因2：绑定延迟

- Qt 的属性绑定可能有延迟
- `onCurrentMotorIndexChanged` 可能在下一帧才触发
- 但这不影响背景图片的实际切换

#### 原因3：背景图片状态绑定

MyMotorListPanel.qml 的背景图片使用 `State` 绑定：

```qml
states: [
    State {
        name: "selected"
        when: root.currentMotorIndex === index
        PropertyChanges {
            target: backgroundImage
            source: "../../../images/bhNameBK1.png"
        }
    },
    State {
        name: "normal"
        when: root.currentMotorIndex !== index
        PropertyChanges {
            target: backgroundImage
            source: "../../../images/bhNameBK.png"
        }
    }
]
```

这个 `State` 绑定是**声明式**的，只要 `currentMotorIndex` 变化，状态就会自动切换，**不需要** `onCurrentMotorIndexChanged` 触发。

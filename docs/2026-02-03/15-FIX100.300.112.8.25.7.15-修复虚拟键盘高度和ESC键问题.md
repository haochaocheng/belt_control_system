## 🔍 根本原因分析

### 问题1：ESC键无法关闭虚拟键盘

**原因**：
1. DeviceSettingsDialog 检测到虚拟键盘激活（`Qt.inputMethod.visible`）
2. DeviceSettingsDialog 忽略 ESC 键，期望 InputPanel 处理
3. 但 InputPanel 没有 ESC 键的处理逻辑
4. 结果：ESC 键被忽略，虚拟键盘无法关闭

**代码位置**：
- DeviceSettingsDialog.qml Line 739-745：
  ```qml
  Keys.onEscapePressed: {
      if (Qt.inputMethod.visible) {
          console.log("⌨️ [DeviceSettingsDialog] 虚拟键盘激活中，忽略 ESC 键")
          return  // ← 忽略 ESC 键
      }
      // 关闭对话框...
  }
  ```

- main.qml Line 298-324：InputPanel 没有 ESC 键处理

### 问题2：滚动尺寸不对

**原因**：
1. CustomSpinBox 尝试获取 `scrollView.Window.window.virtualKeyboardHeight`
2. main.qml 中没有这个属性（只有 main_qds.qml 有）
3. 回退到估算高度：`screenHeight * 0.4 = 1080 * 0.4 = 432px`
4. 实际虚拟键盘高度是 600px
5. 计算的键盘顶部位置错误：`1080 - 432 = 648` 而不是 `1080 - 600 = 480`
6. 滚动距离不足：只滚动了 81px，应该滚动 273px

**代码位置**：
- CustomSpinBox.qml Line 172-178：
  ```qml
  if (scrollView.Window.window && scrollView.Window.window.virtualKeyboardHeight) {
      keyboardHeight = scrollView.Window.window.virtualKeyboardHeight
      console.log("   ⌨️  使用实际虚拟键盘高度:", keyboardHeight)
  } else {
      keyboardHeight = screenHeight * 0.4  // ← 估算高度不准确
      console.log("   ⌨️  使用估算虚拟键盘高度:", keyboardHeight)
  }
  ```

- main.qml：缺少 `virtualKeyboardHeight` 属性
- main_qds.qml Line 33：有 `property real virtualKeyboardHeight: virtualKeyboard.height`

## 💡 关键知识点

### 1. 为什么需要 virtualKeyboardHeight 属性？

**问题**：
- CustomSpinBox 需要知道虚拟键盘的高度来计算滚动距离
- Qt.inputMethod.keyboardRectangle.height 在某些平台上不准确
- 估算高度（屏幕高度的40%）也不准确

**解决方案**：
- 在 ApplicationWindow 中添加 `virtualKeyboardHeight` 属性
- 值为 600（与 InputPanel 的 height 一致）
- CustomSpinBox 通过 `scrollView.Window.window.virtualKeyboardHeight` 访问

**优点**：
- ✅ 准确：与实际虚拟键盘高度一致
- ✅ 可靠：不依赖平台特定的 API
- ✅ 简单：一个属性搞定

### 2. 为什么 ESC 键需要在 InputPanel 中处理？

**问题**：
- DeviceSettingsDialog 检测到虚拟键盘激活时，忽略 ESC 键
- 期望 InputPanel 处理 ESC 键
- 但 InputPanel 默认没有 ESC 键处理

**解决方案**：
- 在 InputPanel 内添加 Shortcut 处理 ESC 键
- 只在虚拟键盘可见时启用
- 调用 `Qt.inputMethod.hide()` 关闭虚拟键盘

**为什么不在 DeviceSettingsDialog 中处理？**
- DeviceSettingsDialog 的 ESC 键用于关闭对话框
- 如果虚拟键盘激活时也关闭对话框，用户体验不好
- 正确的行为：虚拟键盘激活时，ESC 键只关闭虚拟键盘，不关闭对话框

### 3. Shortcut vs Keys.onEscapePressed

**Shortcut**：
```qml
Shortcut {
    sequence: "Escape"
    enabled: Qt.inputMethod.visible
    onActivated: {
        Qt.inputMethod.hide()
    }
}
```

**Keys.onEscapePressed**：
```qml
Keys.onEscapePressed: {
    Qt.inputMethod.hide()
}
```

**区别**：
- Shortcut 可以动态启用/禁用（`enabled` 属性）
- Shortcut 不需要 Item 有焦点
- Keys.onEscapePressed 需要 Item 有焦点

**为什么使用 Shortcut？**
- InputPanel 可能没有焦点（焦点在 TextInput 上）
- Shortcut 可以在虚拟键盘可见时自动启用
- 更可靠

### 4. 为什么估算高度不准确？

**估算公式**：
```qml
keyboardHeight = screenHeight * 0.4
```

**问题**：
- 不同设备的虚拟键盘高度不同
- 不同分辨率的屏幕，40% 的高度也不同
- 实际虚拟键盘高度是固定的 600px

**示例**：
- 屏幕高度 1080px：估算 432px，实际 600px，误差 168px
- 屏幕高度 800px：估算 320px，实际 600px，误差 280px

**结论**：
- 估算高度不可靠
- 应该使用实际高度（通过 `virtualKeyboardHeight` 属性）

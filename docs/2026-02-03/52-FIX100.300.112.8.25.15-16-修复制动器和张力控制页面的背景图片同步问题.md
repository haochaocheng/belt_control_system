## 🎯 问题描述

### 用户反馈

用户测试制动器控制页面后报告：

> "从制动器控制切换到制动器列表时，加入在2号制动器时，如果点击7号制动器时，背景图片和蓝色方框都是7号制动器，但是向上时蓝色方框向上了，但是背景图片没有跟随"

### 问题分析

**现象**：
1. 导航键切换到2号制动器（index=1）
2. 鼠标点击7号制动器（index=6）
3. 背景图片和蓝色边框都显示在7号 ✅
4. 按上键
5. 蓝色边框向上移动 ✅
6. **但是背景图片没有跟随** ❌

### 根本原因

在 BrakeListPanel.qml 中：
- **蓝色边框**绑定到 `focusItemIndex`（Line 97-98）
- **背景图片**绑定到 `currentBrakeIndex`（Line 116 和 124）

在 BrakeControlPage.qml 的 `brakeSelected` 信号处理中（Line 387-391）：
- 更新了 `currentBrakeIndex` ✅
- 更新了 `navigationManager.brakeListIndex` ✅
- **但是没有更新 `focusItemIndex`** ❌

**问题流程**：
```
1. 导航键切换到2号 → focusItemIndex = 1, currentBrakeIndex = 1 ✅
2. 鼠标点击7号 → currentBrakeIndex = 6 ✅
3. ❌ 但是 focusItemIndex 仍然是 1 ❌
4. 背景图片绑定到 currentBrakeIndex，显示在7号 ✅
5. 蓝色边框绑定到 focusItemIndex，显示在2号 ❌
6. 按上键 → focusItemIndex-- → focusItemIndex = 0 ❌
7. 蓝色边框移动到1号 ❌
8. 背景图片仍然在7号（因为 currentBrakeIndex 没变）❌
```

---

## 🔧 解决方案

### 方案：在鼠标点击时同步所有焦点状态

**核心思想**：
- 在 `brakeSelected` 信号处理中
- 不仅更新 `currentBrakeIndex` 和 `navigationManager.brakeListIndex`
- 还要更新 `focusItemIndex` 和 `focusSubArea`
- 确保所有焦点状态保持同步

### 修改内容

#### 1. BrakeControlPage.qml - 修改 brakeSelected 处理（Line 387-395）

```qml
item.brakeSelected.connect(function(brakeIndex) {
    // ✅ 2026-02-03 [FIX 100.300.112.8.25.15]: 鼠标点击时同步所有焦点状态
    console.log("🔍 [BrakeControlPage] 鼠标点击制动器:", brakeIndex)
    root.currentBrakeIndex = brakeIndex
    root.focusItemIndex = brakeIndex
    root.focusSubArea = 0  // 确保在列表区域
    navigationManager.brakeListIndex = brakeIndex
    console.log("选中制动器:", brakeIndex + 1)
})
```

#### 2. TensionControlPage.qml - 修改 controlSelected 处理（Line 349-357）

```qml
item.controlSelected.connect(function(controlIndex) {
    // ✅ 2026-02-03 [FIX 100.300.112.8.25.16]: 鼠标点击时同步所有焦点状态
    console.log("🔍 [TensionControlPage] 鼠标点击控制:", controlIndex)
    root.currentControlIndex = controlIndex
    root.focusItemIndex = controlIndex
    root.focusSubArea = 0  // 确保在列表区域
    navigationManager.controlListIndex = controlIndex
    console.log("选中控制:", controlIndex === 0 ? "张力传感器" : "独立张紧控制")
})
```

### 修复后的完整流程

**场景：鼠标点击列表项后按上下键**

#### 修复前（背景图片不跟随）：

```
1. 导航键切换到2号 → focusItemIndex = 1, currentBrakeIndex = 1 ✅
2. 鼠标点击7号 → currentBrakeIndex = 6 ✅
3. ❌ focusItemIndex 仍然是 1 ❌
4. 背景图片在7号，蓝色边框在2号 ❌
5. 按上键 → focusItemIndex = 0 ❌
6. 蓝色边框移动到1号，背景图片仍在7号 ❌
```

#### 修复后（背景图片正确跟随）：

```
1. 导航键切换到2号 → focusItemIndex = 1, currentBrakeIndex = 1 ✅
2. 鼠标点击7号 → currentBrakeIndex = 6, focusItemIndex = 6 ✅
3. 背景图片和蓝色边框都在7号 ✅
4. 按上键 → focusItemIndex = 5 ✅
5. onFocusItemIndexChanged 触发 → currentBrakeIndex = 5 ✅
6. 背景图片和蓝色边框都移动到6号 ✅
```

## 📊 为什么这个方案有效？

### 问题的本质

**焦点状态不完整同步**：
- 鼠标点击时，只更新了 `currentBrakeIndex`
- 没有更新 `focusItemIndex`
- 导致蓝色边框和背景图片绑定到不同的状态
- 按导航键时，只有蓝色边框移动，背景图片不动

### 解决方案的本质

**完整同步所有焦点状态**：
- 鼠标点击时，同时更新：
  - `currentBrakeIndex`（背景图片绑定）
  - `focusItemIndex`（蓝色边框绑定）
  - `focusSubArea`（区域状态）
  - `navigationManager.brakeListIndex`（导航状态）
- 确保所有状态保持一致

### 焦点状态同步链

```
鼠标点击
    ↓
更新所有状态：
- currentBrakeIndex = index
- focusItemIndex = index
- focusSubArea = 0
- navigationManager.brakeListIndex = index
    ↓
onFocusItemIndexChanged 触发
    ↓
同步到 currentContentItemIndex
    ↓
导航键正常工作
```

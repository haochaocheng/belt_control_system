## 🤔 可能的问题原因

### 原因1：MotorControlPage 没有焦点

**问题**：如果 MotorControlPage 没有焦点，Keys.onUpPressed/onDownPressed 不会被触发。

**检查**：
- MotorControlPage.qml Line 198: `focus: true` ✅
- MotorControlPage.qml Line 199: `activeFocusOnTab: true` ✅

**可能性**：⚠️ **中等**
- 鼠标点击后，焦点可能被 MyMotorListPanel 或其他组件抢走
- 需要确认焦点是否正确返回到 MotorControlPage

### 原因2：currentArea 不是 areaMotorList

**问题**：如果 currentArea 不是 areaMotorList，handleDirectionKey 不会调用 moveInMotorList。

**检查**：
- 鼠标点击后，currentArea 可能被切换到其他区域
- 需要确认鼠标点击后 currentArea 是否仍然是 areaMotorList

**可能性**：⚠️ **高**
- 鼠标点击可能没有正确设置 currentArea

### 原因3：onMotorListIndexChanged 没有被触发

**问题**：motorListIndex 更新后，onMotorListIndexChanged 信号没有被触发。

**可能性**：❌ **低**
- QML 会自动为 property 生成 Changed 信号
- 除非有其他代码干扰

### 原因4：currentMotorIndex 绑定被破坏

**问题**：currentMotorIndex 的绑定被破坏，导致无法响应变化。

**检查**：
- MotorControlPage.qml Line 253: `item.currentMotorIndex = Qt.binding(function() { return root.currentMotorIndex })`
- 这是正确的绑定方式

**可能性**：❌ **低**

## 🎯 问题分析

用户指出之前的滚动计算设计有严重错误，需要重新思考布局结构。

### 实际布局结构

```
ApplicationWindow (root, 1920x1080 或 1280x800)
  ├─ SwipeView (主界面)
  │   └─ Screen01 (首页)
  │
  ├─ DeviceSettingsDialog (弹窗，居中显示，约80%屏幕大小)
  │   └─ CurrentProtectionTab
  │       └─ ScrollView (参数区域，在弹窗内部)
  │           └─ GridLayout
  │               └─ CustomSpinBox (输入框)
  │
  └─ InputPanel (虚拟键盘，固定在整个屏幕底部，z: 99)
      - y: root.height - virtualKeyboard.height
      - 不在弹窗内部，而是在ApplicationWindow层级
```

### 关键问题

**之前的错误假设**：
1. ❌ 认为虚拟键盘在弹窗内部
2. ❌ 使用ScrollView的高度计算虚拟键盘高度
3. ❌ 没有考虑弹窗的位置偏移
4. ❌ 坐标系统混乱（ScrollView坐标 vs 屏幕坐标）

**实际情况**：
1. ✅ 虚拟键盘在ApplicationWindow层级，固定在屏幕底部
2. ✅ 弹窗是居中显示的，有自己的坐标偏移
3. ✅ ScrollView在弹窗内部，有多层嵌套
4. ✅ 需要将输入框坐标转换到屏幕坐标系

## 🔧 正确的计算方式

### 坐标系统转换

**三个坐标系**：
1. **ScrollView内容坐标系**：输入框在ScrollView.contentItem中的Y坐标
2. **ScrollView可见区域坐标系**：输入框在ScrollView可见区域中的Y坐标
3. **屏幕坐标系**：输入框在整个屏幕中的Y坐标

**转换公式**：
```javascript
// 1. 计算输入框在ScrollView内容中的Y坐标
inputYInContent = getYInScrollView(inputBox, scrollView)

// 2. 计算当前滚动偏移
currentScrollY = scrollView.ScrollBar.vertical.position * scrollView.contentHeight

// 3. 计算输入框在ScrollView可见区域中的Y坐标
inputYInViewport = inputYInContent - currentScrollY

// 4. 计算ScrollView在屏幕中的Y坐标
scrollViewScreenY = getScreenY(scrollView)

// 5. 计算输入框在屏幕中的Y坐标
inputScreenY = scrollViewScreenY + inputYInViewport
inputScreenBottom = inputScreenY + inputHeight
```

### 虚拟键盘位置

**虚拟键盘信息**：
```javascript
// 获取屏幕高度
screenHeight = scrollView.Window.window.height  // 1920x1080 或 1280x800

// 虚拟键盘高度（估算为屏幕高度的40%）
keyboardHeight = screenHeight * 0.4

// 虚拟键盘顶部Y坐标
keyboardTop = screenHeight - keyboardHeight
```

### 遮挡判断和滚动计算

**判断是否被遮挡**：
```javascript
gap = 20  // 期望的间距
targetBottom = keyboardTop - gap

if (inputScreenBottom > targetBottom) {
    // 输入框被遮挡，需要滚动
    overlap = inputScreenBottom - targetBottom

    // 计算需要滚动的距离
    targetScrollY = currentScrollY + overlap

    // 限制滚动范围
    maxScrollY = Math.max(0, scrollView.contentHeight - scrollView.height)
    targetScrollY = Math.max(0, Math.min(targetScrollY, maxScrollY))

    // 转换为position并滚动
    targetPosition = targetScrollY / scrollView.contentHeight
    scrollView.ScrollBar.vertical.position = targetPosition
}
```

### 1. CustomSpinBox.qml

**新增函数**：
```qml
// 计算元素在屏幕坐标系中的Y坐标
function getScreenY(item) {
    var y = 0
    var current = item
    var depth = 0
    while (current && depth < 20) {
        y += current.y
        current = current.parent
        depth++
        // 如果到达Window，停止
        if (current && current.toString().indexOf("Window") !== -1) {
            break
        }
    }
    return y
}
```

**修改滚动计算逻辑**：

## 📦 总结

### 问题根源

之前的设计没有正确理解布局结构：
1. 虚拟键盘不在弹窗内部，而是在ApplicationWindow层级
2. 需要将输入框坐标转换到屏幕坐标系
3. 需要考虑弹窗的位置偏移

### 解决方案

1. **明确坐标系统**：区分ScrollView内容坐标、可见区域坐标、屏幕坐标
2. **正确计算虚拟键盘位置**：使用屏幕高度而不是ScrollView高度
3. **精确判断遮挡**：在屏幕坐标系中判断输入框是否被虚拟键盘遮挡
4. **计算相对偏移**：只滚动需要的距离，不做多余滚动

### 用户体验

1. **精确滚动**：只在输入框被遮挡时滚动
2. **最小滚动**：只滚动必要的距离
3. **详细日志**：完整的坐标转换过程，方便调试
4. **智能判断**：自动判断是否需要滚动

### 增量编译原理

**使用 Makefile 依赖检测**：
```bash
# Step 1: 复制修改的 .c 文件到容器
docker cp modified_file.c container:/workspace/libavcodec/

# Step 2: 增量编译（只编译修改的文件）
make libavcodec/modified_file.o

# Step 3: 重新链接库
make libavcodec/libavcodec.so

# Step 4: 安装到输出目录
make install DESTDIR=/output
```

**关键优势**：
- ✅ 不需要重新运行 configure
- ✅ 不需要编译所有源文件
- ✅ Make 自动检测依赖关系
- ✅ 速度提升 10-20 倍（2-5分钟 vs 30-60分钟）

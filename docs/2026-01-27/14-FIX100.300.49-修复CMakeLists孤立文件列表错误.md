# FIX 100.300.49 - 修复 CMakeLists.txt 孤立文件列表错误

**日期**: 2026-01-27 18:55
**问题**: 从 J 盘恢复源码后，CMake 解析错误

## 问题描述

编译时出现 CMake 解析错误：

```
CMake Error at src/qml/CMakeLists.txt:214:
  Parse error.  Expected a command name, got unquoted argument with text
  "Input1/Input1Content/Back.ui.qml".

-- Configuring incomplete, errors occurred!
```

## 根本原因

**文件**: `src/qml/CMakeLists.txt`

**问题代码**（第 213-219 行）：
```cmake
target_link_libraries(input1_qml_module PRIVATE
    Qt6::Qml
    Qt6::Quick
)

        # 2026-01-19: Input1 模块 QML 组件（6 个，自动检测）
        Input1/Input1Content/Back.ui.qml
        Input1/Input1Content/BHState.ui.qml
        Input1/Input1Content/DataShow.ui.qml
        Input1/Input1Content/MyIN_Data.ui.qml
        Input1/Input1Content/MyIN_State.ui.qml
        Input1/Input1Content/Screen01.ui.qml
target_link_libraries(qml_module PRIVATE input1_qml_module)
```

**问题分析**：
- 第 214-219 行是孤立的文件列表
- 没有包含在任何 CMake 命令中（如 `qt_add_qml_module`、`target_sources` 等）
- CMake 解析器期望一个命令名，但遇到了文件路径
- 导致解析错误

**为什么会出现**：
1. 这个错误之前在 FIX 100.300.43 中修复过
2. 用户从 J 盘备份恢复源码时，覆盖了修复后的 CMakeLists.txt
3. J 盘备份中的 CMakeLists.txt 包含了这个错误

## 技术要点

### 1. CMake 命令语法

**正确的文件列表**：
```cmake
# 方式 1: 在 qt_add_qml_module 中列出
qt_add_qml_module(input1_qml_module
    URI Input1
    QML_FILES
        Input1/Input1Content/Back.ui.qml
        Input1/Input1Content/BHState.ui.qml
    RESOURCE_PREFIX /qt/qml
)

# 方式 2: 使用 target_sources
target_sources(input1_qml_module PRIVATE
    Input1/Input1Content/Back.ui.qml
    Input1/Input1Content/BHState.ui.qml
)
```

**错误的文件列表**（孤立）：
```cmake
# ❌ 错误：没有命令名
Input1/Input1Content/Back.ui.qml
Input1/Input1Content/BHState.ui.qml
```

### 2. qt_add_qml_module 自动包含

当使用 `RESOURCE_PREFIX` 时，Qt 会自动扫描并包含指定目录下的 QML 文件：

```cmake
qt_add_qml_module(input1_qml_module
    URI Input1
    RESOURCE_PREFIX /qt/qml  # 自动包含 /qt/qml/Input1/ 下的所有 QML 文件
    OUTPUT_DIRECTORY ${CMAKE_CURRENT_BINARY_DIR}/Input1
)
```

### 3. CMake 解析错误类型

**Parse error. Expected a command name**：
- CMake 期望一个命令（如 `add_library`、`target_link_libraries` 等）
- 但遇到了一个参数（文件路径、变量等）
- 通常是因为缺少命令名或括号不匹配

# Screen01 键盘导航使用说明

**功能**: 使用方向键在 12 个 MyIN_Data 组件之间导航
**版本**: FIX 100.300.54
**日期**: 2026-01-27

## 🎮 键盘操作

| 按键 | 功能 | 说明 |
|------|------|------|
| ↑ (Up) | 向上移动 | 移动到上一行的同一列 |
| ↓ (Down) | 向下移动 | 移动到下一行的同一列 |
| ← (Left) | 向左移动 | 移动到同一行的前一列 |
| → (Right) | 向右移动 | 移动到同一行的后一列 |

## 📐 布局结构

```
第 1 行:  [0]  [1]  [2]  [3]
第 2 行:  [4]  [5]  [6]  [7]
第 3 行:  [8]  [9] [10] [11]
```

## 🎯 导航示例

### 示例 1: 从左上角到右下角

```
初始位置: [0] (第 1 行第 1 列)
按 → 3 次: [0] → [1] → [2] → [3]
按 ↓ 2 次: [3] → [7] → [11]
最终位置: [11] (第 3 行第 4 列)
```

### 示例 2: 十字导航

```
初始位置: [5] (第 2 行第 2 列)
按 ↑: [5] → [1] (第 1 行第 2 列)
按 ↓ 2 次: [1] → [5] → [9] (第 3 行第 2 列)
按 ←: [9] → [8] (第 3 行第 1 列)
按 → 3 次: [8] → [9] → [10] → [11]
```

## 🖼️ 视觉反馈

### 未选中状态
- **图片**: `IN_Data.png`
- **外观**: 正常显示

### 选中状态
- **图片**: `IN_Data_OK.png`
- **外观**: 高亮显示（带 OK 标记）

## 🔄 状态切换

**自动切换**: 使用 QML `states` 机制
```qml
states: [
    State {
        name: "normal"
        when: !selected
        PropertyChanges { source: "IN_Data.png" }
    },
    State {
        name: "selected"
        when: selected
        PropertyChanges { source: "IN_Data_OK.png" }
    }
]
```

## 🚫 边界限制

### 上边界
- 在第 1 行时，按 ↑ 无效
- 示例: [0] 按 ↑ → 保持 [0]

### 下边界
- 在第 3 行时，按 ↓ 无效
- 示例: [11] 按 ↓ → 保持 [11]

### 左边界
- 在第 1 列时，按 ← 无效
- 示例: [0] 按 ← → 保持 [0]

### 右边界
- 在第 4 列时，按 → 无效
- 示例: [3] 按 → → 保持 [3]

## 📝 技术实现

### 索引计算
```javascript
行 = Math.floor(索引 / 4)
列 = 索引 % 4
```

### 移动计算
```javascript
// 上键
newIndex = (row - 1) * 4 + col

// 下键
newIndex = (row + 1) * 4 + col

// 左键
newIndex = row * 4 + (col - 1)

// 右键
newIndex = row * 4 + (col + 1)
```

## 🎨 自定义建议

### 1. 添加循环导航

在边界处循环到另一端：
```javascript
// 左键循环
if (col > 0) {
    selectedIndex = row * cols + (col - 1)
} else {
    selectedIndex = row * cols + (cols - 1)  // 循环到行尾
}
```

### 2. 添加动画效果

```qml
transitions: [
    Transition {
        PropertyAnimation {
            properties: "opacity"
            duration: 200
            easing.type: Easing.InOutQuad
        }
    }
]
```

### 3. 添加焦点边框

```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: "#00d4ff"
    border.width: 3
    visible: selected
}
```

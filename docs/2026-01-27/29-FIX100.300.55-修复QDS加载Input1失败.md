# FIX 100.300.55 - 修复 QDS 加载 Input1 模块失败

**日期**: 2026-01-27 22:35
**问题**: Qt Design Studio 打开 BeltControlSystem.qmlproject 时 Input1 模块加载失败
**根本原因**: Input1Content 目录缺少 qmldir 文件

## 问题现象

### 错误信息
```
Input1 模块加载失败
无法找到 Input1Content 组件
```

### 影响
- QDS 无法识别 Input1Content 目录下的组件
- 无法在 QDS 中设计 Screen01 等页面
- 组件无法在设计器中拖放使用

## 根本原因

### QML 模块系统

Qt/QML 使用 `qmldir` 文件来定义模块：

```
模块目录/
├── qmldir          ← 模块定义文件（必需）
├── Component1.qml
├── Component2.qml
└── ...
```

**缺少 qmldir 的后果**：
- QML 引擎无法识别该目录为模块
- `import` 语句失败
- QDS 无法加载组件

### 项目结构

```
src/qml/
├── BeltControlSystem.qmlproject
├── Input1/
│   ├── Input1/
│   │   ├── qmldir          ✅ 存在
│   │   ├── Constants.qml
│   │   └── ...
│   └── Input1Content/
│       ├── qmldir          ❌ 缺失！
│       ├── Back.ui.qml
│       ├── Head.ui.qml
│       ├── Screen01.qml
│       └── ...
```

## 解决方案

### 创建 Input1Content/qmldir

**文件路径**: `src/qml/Input1/Input1Content/qmldir`

**内容**:
```qml
module Input1Content

# UI 组件
Back 1.0 Back.ui.qml
BHState 1.0 BHState.ui.qml
DataShow 1.0 DataShow.ui.qml
Head 1.0 Head.ui.qml
Head_MiddleMenu 1.0 Head_MiddleMenu.ui.qml
MyIN_Data 1.0 MyIN_Data.ui.qml
MyIN_State 1.0 MyIN_State.ui.qml

# 主屏幕
Screen01 1.0 Screen01.qml
Screen01Form 1.0 Screen01Form.ui.qml
```

### qmldir 语法说明

```
<TypeName> <Version> <File>
```

**示例**:
```
Back 1.0 Back.ui.qml
```

- `Back`: 组件类型名（在 QML 中使用）
- `1.0`: 版本号
- `Back.ui.qml`: 文件名


1. `Input1/Input1/qmldir` → `module Input1`
2. `Input1/Input1Content/qmldir` → `module Input1Content`

## 常见问题

### 问题 1: 仍然无法加载

**原因**: QDS 缓存未更新

**解决**:
1. 关闭 QDS
2. 删除项目缓存：
   ```powershell
   rm -r .qmlproject.user*
   rm -r .qtc_clangd
   ```
3. 重新打开项目

### 问题 2: 组件找不到

**原因**: qmldir 中的文件名不匹配

**检查**:
```powershell
# 列出所有 .ui.qml 文件
ls Input1\Input1Content\*.ui.qml

# 对比 qmldir 中的文件名
cat Input1\Input1Content\qmldir
```

**确保**: qmldir 中的文件名与实际文件名完全一致

### 问题 3: 版本号错误

**错误信息**: `module "Input1Content" version 1.0 is not installed`

**解决**: 检查 qmldir 中的版本号是否为 `1.0`

### 问题 4: 模块名冲突

**错误信息**: `module "Input1Content" is defined multiple times`

**原因**: 多个 qmldir 定义了相同的模块名

**检查**:
```powershell
# 查找所有 qmldir 文件
find src\qml -name qmldir

# 检查每个文件的 module 声明
```

## 最佳实践

### 1. 每个组件目录都应有 qmldir

```
components/
├── qmldir          ← 定义 components 模块
├── Component1.qml
└── Component2.qml
```

### 2. qmldir 文件命名规范

- 文件名必须是 `qmldir`（小写，无扩展名）
- 不能是 `qmldir.txt` 或 `QMLDIR`

### 3. 组件命名规范

```qml
# ✅ 正确：首字母大写
Back 1.0 Back.ui.qml
Head 1.0 Head.ui.qml

# ❌ 错误：小写
back 1.0 Back.ui.qml
```

### 4. 版本号管理

```qml
# 推荐：使用 1.0
Back 1.0 Back.ui.qml

# 可选：使用具体版本
Back 1.1 Back.ui.qml
Back 2.0 Back_v2.ui.qml
```

### 5. 注释说明

```qml
module Input1Content

# ========== 背景组件 ==========
Back 1.0 Back.ui.qml

# ========== 头部组件 ==========
Head 1.0 Head.ui.qml
Head_MiddleMenu 1.0 Head_MiddleMenu.ui.qml

# ========== 数据显示 ==========
MyIN_Data 1.0 MyIN_Data.ui.qml
MyIN_State 1.0 MyIN_State.ui.qml
```

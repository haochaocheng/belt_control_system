## 技术要点

### 1. Git Reset --hard 的危险性

```powershell
# ❌ 危险：会丢失所有未提交的修改
git reset --hard origin/feature/hardware-video-codec

# ✅ 安全：保存工作状态
git stash push -m "工作进度保存"
git push origin feature/hardware-video-codec
git stash pop
```

### 2. C++ 前向声明 vs 完整定义

**前向声明**（.h 文件）：
```cpp
class AudioNetworkTcpSender;  // 只能用于指针/引用
```

**完整定义**（.cpp 文件）：
```cpp
#include "audio_network/AudioNetworkTcpSender.h"  // 使用成员函数时必需
```

### 3. PJSIP API 命名规则

**音频编解码器**：
- 枚举：`pjsua_enum_codecs()`
- 设置优先级：`pjsua_codec_set_priority()`
- ❌ 没有 `pjsua_codec_get_priority()`

**视频编解码器**：
- 枚举：`pjsua_vid_enum_codecs()`
- 设置优先级：`pjsua_vid_codec_set_priority()`
- ❌ 没有 `pjsua_vid_codec_get_priority()`

### 4. CMake 缓存问题

**症状**：
- 文件存在但编译报错找不到
- 删除 build_rk3588 后仍然报错

**解决**：
```powershell
# 清除 CMake 缓存
Remove-Item -Recurse -Force "build_rk3588" -ErrorAction SilentlyContinue

# 重新编译
.\build-ubuntu24-apt.ps1 188
```

## 预防措施

### 1. 禁用危险脚本

**不再使用**：`push-commits-one-by-one.ps1`

**原因**：
- 使用 `git reset --hard` 会丢失未提交的修改
- 即使后续 cherry-pick，也可能遗漏某些文件
- CMake 缓存会被损坏

**替代方案**：
```powershell
# 标准推送
git push origin feature/hardware-video-codec

# 如需逐个推送
git push origin <commit-hash>:feature/hardware-video-codec
```

### 2. 定期备份

```powershell
# 每天工作结束前备份
$backupDir = "J:\belt_control_system_backup_$(Get-Date -Format 'yyyy-MM-dd')"
Copy-Item "e:\2025\3_gongkongji\belt_control_system" $backupDir -Recurse -Force
```

### 3. 使用 Git Stash

```powershell
# 保存工作状态
git stash push -m "工作进度保存"

# 执行 git 操作
git push origin feature/hardware-video-codec

# 恢复工作状态
git stash pop
```

### 4. 编译前检查

```powershell
# 检查 git 状态
git status

# 检查未提交的修改
git diff

# 检查未暂存的文件
git diff --cached
```

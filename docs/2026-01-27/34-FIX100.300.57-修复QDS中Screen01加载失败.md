# FIX 100.300.57 - 修复 QDS 中 Screen01 加载失败

**日期**: 2026-01-27 23:00
**问题**: 在 Qt Design Studio 中运行时，Screen01 加载失败，显示错误提示
**根本原因**: 使用了 qrc 路径，QDS 无法解析

## 问题现象

### 在 QDS 中运行

**错误显示**:
```
❌ Input1 Screen01 加载失败

请检查:
1. CMakeLists.txt 是否包含所有 Input1 文件
2. 图片资源文件名是否全为英文
3. 运行同步脚本：.\scripts\2026-01-12\09-sync-input1-resources.ps1
4. 重新编译项目
```

**控制台输出**:
```
❌ Input1 Screen01 加载失败
Loader.status: Error
```

### 在编译后的应用中运行

✅ 正常工作（使用 qrc 路径）

## 根本原因分析

### QDS vs 编译后应用的差异

| 环境 | 路径类型 | 资源系统 | 示例 |
|------|----------|----------|------|
| QDS 运行 | 相对路径 | 文件系统 | `"../Input1/Input1Content/Screen01.qml"` |
| 编译后应用 | qrc 路径 | Qt 资源系统 | `"qrc:/qt/qml/BeltControlQml/..."` |

### 问题代码

**文件**: `Input1Page.qml`

```qml
Loader {
    source: "qrc:/qt/qml/BeltControlQml/Input1/Input1Content/Screen01.qml"
    // ❌ QDS 无法解析 qrc 路径
}
```

**原因**:
- QDS 直接从文件系统加载 QML 文件
- 没有 Qt 资源系统（.qrc）
- 无法解析 `qrc:` 协议

### 路径解析

**在 QDS 中**:
```
当前文件: src/qml/pages/Input1Page.qml
目标文件: src/qml/Input1/Input1Content/Screen01.qml

相对路径: ../Input1/Input1Content/Screen01.qml
```

**在编译后应用中**:
```
资源路径: qrc:/qt/qml/BeltControlQml/Input1/Input1Content/Screen01.qml
```

## 解决方案

### 方案 1: 使用相对路径（推荐）

**优点**:
- ✅ QDS 和编译后应用都支持
- ✅ 简单直接
- ✅ 无需额外配置

**缺点**:
- ⚠️ 依赖文件结构

**实现**:
```qml
source: "../Input1/Input1Content/Screen01.qml"
```

### 方案 2: 条件路径（备选）

**优点**:
- ✅ 可以针对不同环境优化
- ✅ 更灵活

**缺点**:
- ❌ 代码复杂
- ❌ 需要环境检测

**实现**:
```qml
property bool isQDS: Qt.application.arguments.indexOf("qmlscene") >= 0

Loader {
    source: isQDS
        ? "../Input1/Input1Content/Screen01.qml"
        : "qrc:/qt/qml/BeltControlQml/Input1/Input1Content/Screen01.qml"
}
```

### 方案 3: 使用 import 语句（最佳）

**优点**:
- ✅ 最标准的方式
- ✅ QDS 和编译后应用都支持
- ✅ 不依赖路径

**缺点**:
- ⚠️ 需要正确配置 qmldir

**实现**:
```qml
import Input1Content

Item {
    Screen01 {
        // 直接使用组件
    }
}
```

## 采用方案

## 常见问题

### 问题 1: 相对路径在编译后应用中不工作

**原因**: 文件结构不同

**解决**: 相对路径在 Qt 6 中应该正常工作，如果不工作，检查：
1. 文件是否在 CMakeLists.txt 中
2. qmldir 是否正确配置

### 问题 2: 图片资源加载失败

**原因**: 图片路径也需要使用相对路径

**检查**: Screen01.qml 和 MyIN_Data.ui.qml 中的图片路径

```qml
// ✅ 正确：相对于组件文件的路径
Image {
    source: "images/IN_Data.png"
}

// ❌ 错误：绝对路径
Image {
    source: "qrc:/qt/qml/BeltControlQml/Input1/Input1Content/images/IN_Data.png"
}
```

**可能原因**:

3. 缺少依赖的组件

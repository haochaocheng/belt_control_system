## 布局设计

### 屏幕尺寸
- **总宽度**: 1920 像素
- **总高度**: 1080 像素

### 布局区域
- **Head 高度**: 80 像素
- **可用高度**: 1080 - 80 = 1000 像素
- **可用宽度**: 1920 像素

### 网格计算
- **列数**: 3
- **行数**: 4
- **每列宽度**: 1920 ÷ 3 = 640 像素
- **每行高度**: 1000 ÷ 4 = 250 像素
- **间距**: 0（紧密排列）

## 布局特点

### 优点
1. ✅ **规整对齐**: 所有组件完美对齐，无缝隙
2. ✅ **等分布局**: 每个单元格大小相同（640x250）
3. ✅ **充分利用空间**: 完全填满可用区域
4. ✅ **易于维护**: 清晰的行列结构
5. ✅ **命名规范**: data_row{行}_col{列}

### 计算公式
```
列 X 坐标 = (列索引 - 1) × 640
行 Y 坐标 = 80 + (行索引 - 1) × 250

示例：
- 第 1 行第 1 列: x = 0,    y = 80
- 第 2 行第 3 列: x = 1280, y = 330
- 第 4 行第 2 列: x = 640,  y = 830
```

## 响应式布局（可选）

如果需要响应式布局，可以改用 Grid 布局：

```qml
Grid {
    anchors.fill: parent
    anchors.topMargin: 80  // Head 高度
    rows: 4
    columns: 3

    Repeater {
        model: 12
        MyIN_Data {
            width: parent.width / 3
            height: parent.height / 4
        }
    }
}
```

但由于这是 `.ui.qml` 文件（Qt Design Studio），使用固定位置更合适。

## 技术要点

1. **前向声明 vs 完整定义**：
   - 前向声明：只能用于指针和引用的声明
   - 完整定义：需要使用类的成员函数、继承、模板实例化时必须包含完整头文件
   - 本例中，.h 文件使用前向声明（避免循环依赖），.cpp 文件包含完整定义（使用成员函数）

2. **不完整类型错误**：
   - `delete` 操作符需要知道类的析构函数
   - 信号连接需要知道信号的完整签名
   - 成员函数调用需要知道函数的定义

3. **编译错误示例**：
   ```
   error: incomplete type 'AudioNetworkTcpSender' used in nested name specifier
   warning: invalid use of incomplete type 'class AudioNetworkTcpSender'
   note: forward declaration of 'class AudioNetworkTcpSender'
   ```

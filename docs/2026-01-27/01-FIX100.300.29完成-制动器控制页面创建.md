## 需求描述

用户要求：

  - 分为1号制动器到8号制动器

- **要求2**：参数区域包括

  - 分割线

  - 分割线
  - 输出点：抱闸输出点，减速机输出点，松闸到位，抱闸到位
  - 每一个制动器，只有输出点不同

### 4. 数据库表设计

需要创建制动器配置表：

```sql
CREATE TABLE brake_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,
    brake_index INTEGER NOT NULL,  -- 0-7
    enabled INTEGER DEFAULT 1,  -- 0=禁用, 1=投入
    hold_time INTEGER DEFAULT 0,  -- 抱闸保持时间（秒）
    release_time INTEGER DEFAULT 0,  -- 松闸保持时间（秒）
    max_time INTEGER DEFAULT 0,  -- 最长允许时间（秒）
    brake_delay INTEGER DEFAULT 0,  -- 抱闸延时时间（秒）
    emergency_brake_time INTEGER DEFAULT 0,  -- 急停抱闸时间（秒）
    brake_output INTEGER DEFAULT 0,  -- 抱闸输出点
    reducer_output INTEGER DEFAULT 0,  -- 减速机输出点
    release_in_place INTEGER DEFAULT 0,  -- 松闸到位
    brake_in_place INTEGER DEFAULT 0,  -- 抱闸到位
    UNIQUE(device_id, brake_index)
);
```

### 5. QML 数据绑定

在 BrakeConfigPanel.qml 中绑定后端数据：

```qml
Rectangle {
    id: root
    property int brakeIndex: 0

    // ✅ 绑定后端控制器
    property var brakeController: BrakeController

    // 监听制动器索引变化，加载配置
    onBrakeIndexChanged: {
        if (brakeController) {
            brakeController.loadConfig(brakeIndex)
        }
    }

    // 使用状态
    RadioButton {
        id: statusEnabled
        text: "投入"
        checked: brakeController ? brakeController.enabled : true
        onCheckedChanged: {
            if (brakeController) {
                brakeController.enabled = checked
            }
        }
    }

    // 抱闸保持时间
    TextField {
        id: holdTimeField
        text: brakeController ? brakeController.holdTime.toString() : "0"
        onTextChanged: {
            if (brakeController) {
                brakeController.holdTime = parseInt(text) || 0
            }
        }
    }

    // ... 其他字段绑定

    // 保存按钮
    Button {
        text: "保存"
        onClicked: {
            if (brakeController) {
                brakeController.saveConfig()
            }
        }
    }

    // 重置按钮
    Button {
        text: "重置"
        onClicked: {
            if (brakeController) {
                brakeController.resetConfig()
            }
        }
    }
}
```

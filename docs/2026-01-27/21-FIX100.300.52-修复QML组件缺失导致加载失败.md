## 相关问题

### 为什么会有这么多临时文件？

Qt Design Studio (QDS) 在编辑 `.ui.qml` 文件时会创建临时文件：
- 格式：`文件名.tmp.进程ID.时间戳`
- 目的：防止编辑过程中文件损坏
- 正常情况：保存后会删除临时文件，替换原文件

### 为什么原文件丢失了？

可能的原因：
1. QDS 崩溃，没有完成保存流程
2. 文件系统错误
3. Git 操作（如 `git checkout` 或 `git reset`）覆盖了文件

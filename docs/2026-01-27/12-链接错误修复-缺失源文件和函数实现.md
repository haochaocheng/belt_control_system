## 根本原因

### 原因 1: CMakeLists.txt 缺失源文件

**文件**: `src/audio_network/CMakeLists.txt`

**问题代码**（第 25-27 行）：
```cmake
add_library(audio_network STATIC
    AudioNetworkSender.cpp
)
```

**缺失的源文件**：
- ❌ AudioNetworkTcpSender.cpp
- ❌ AudioSenderWorker.cpp
- ❌ AudioSenderWorkerUdp.cpp
- ❌ WebSocketClient.cpp

**影响**：这些 .cpp 文件没有被编译到 `libaudio_network.a` 静态库中，导致链接时找不到符号。

### 原因 2: SipPhoneManager 缺失函数实现

**文件**: `src/sip_phone/SipPhoneManager.cpp`

**缺失的函数**：
1. `void restoreMicrophoneVolume()` - 恢复麦克风音量
2. `QStringList audioCodecs() const` - 音频编解码器列表 property getter
3. `QStringList videoCodecs() const` - 视频编解码器列表 property getter

**影响**：头文件中声明了这些函数，但 .cpp 文件中没有实现，导致链接时找不到符号。

```cpp
// ✅ 2026-01-27 [FIX 100.300.48] 添加缺失的 restoreMicrophoneVolume 函数实现
// 从 QSettings 读取保存的音量，应用到会议桥 TX 增益
// 调用时机：onCallStateChanged() 回调在 PJSIP_INV_STATE_CONFIRMED 状态
// 参考：docs/2026-01-19/22-FIX100.249v3完成-会议桥麦克风音量控制.md
void SipPhoneManager::restoreMicrophoneVolume()
{
    qDebug() << "════════════════════════════════════════════════";
    qDebug() << "🎤 [FIX 100.249 v3] Restoring microphone volume from settings...";
    qDebug() << "════════════════════════════════════════════════";

    // 从 QSettings 读取保存的音量（默认 50%）
    QSettings settings;
    int savedVolume = settings.value("SIP/MicrophoneVolume", 50).toInt();
    qDebug() << "   Saved volume:" << savedVolume << "%";

    // 转换百分比 (0-100) 到 PJSIP 增益倍数 (0.0-2.0)
    float level = (savedVolume / 50.0f);
    qDebug() << "   Converted to PJSIP level:" << level;

    // 应用到会议桥 TX 增益
    pj_status_t status = pjsua_conf_adjust_tx_level(0, level);

    if (status == PJ_SUCCESS) {
        qDebug() << "   ✅ [SUCCESS] Microphone volume restored!";
        qDebug() << "      PJSIP level:" << level << "(" << savedVolume << "%)";
        qDebug() << "      对方将听到此音量级别";
    } else {
        char errmsg[PJ_ERR_MSG_SIZE];
        pj_strerror(status, errmsg, sizeof(errmsg));
        qWarning() << "   ⚠️ [PJSIP] Failed to restore microphone volume:" << errmsg;
        qWarning() << "      Volume will remain at default level (1.0)";
    }

    qDebug() << "════════════════════════════════════════════════";
}
```

## 技术要点

### 1. CMake 静态库编译

**add_library 语法**：
```cmake
add_library(library_name STATIC
    source1.cpp
    source2.cpp
    ...
)
```

**注意事项**：
- 所有需要的 .cpp 文件必须列出
- 缺失的 .cpp 文件不会被编译到库中
- 链接时会报 undefined reference 错误

### 2. const 成员函数调用非 const 函数

**问题**：
- `audioCodecs() const` 需要调用 `getAudioCodecs()`（非 const）

**解决方案**：
```cpp
QStringList SipPhoneManager::audioCodecs() const
{
    // 使用 const_cast 去掉 const 限制
    return const_cast<SipPhoneManager*>(this)->getAudioCodecs();
}
```

**原理**：
- `const_cast` 移除 `this` 指针的 const 限制
- 允许 const 成员函数调用非 const 成员函数
- 适用于 property getter 包装现有函数的场景

### 3. Qt Property 系统

**声明**（.h 文件）：
```cpp
Q_PROPERTY(QStringList audioCodecs READ audioCodecs NOTIFY audioCodecsChanged)
```

**实现**（.cpp 文件）：
```cpp
// Property getter（必须是 const）
QStringList SipPhoneManager::audioCodecs() const
{
    return const_cast<SipPhoneManager*>(this)->getAudioCodecs();
}

// 实际实现（可以是非 const）

```

### 4. 链接错误 vs 编译错误

**编译错误**：
- 语法错误、类型错误、缺失声明
- 发生在编译阶段（.cpp → .o）

**链接错误**：
- 缺失函数实现、缺失库文件
- 发生在链接阶段（.o → 可执行文件）
- 错误信息：`undefined reference to ...`

### QML 资源编译机制

Qt 使用 `qt_add_qml_module` 将 QML 文件编译进二进制文件：

```cmake
qt_add_qml_module(qml_module
    URI BeltControlQml
    VERSION 1.0
    QML_FILES
        main.qml
        App.qml
        # ... 其他 QML 文件
)
```

**关键点**：
- 只有在 `QML_FILES` 中列出的文件才会被编译进资源
- 运行时从 `qrc:/qt/qml/BeltControlQml/` 加载
- 如果文件不在列表中，运行时找不到组件

## 为什么会出现这个问题？

### 可能的原因

1. **文件丢失时没有更新 CMakeLists.txt**：
   - Head.ui.qml 文件丢失
   - 但 CMakeLists.txt 中的引用也被删除了
   - 可能是某次 Git 操作或手动编辑

2. **注释说明不准确**：
   - 注释说"6 个，自动检测"
   - 但实际上不是自动检测，是手动列出的
   - 导致添加新文件时忘记更新列表

### 预防措施

1. **使用 GLOB 自动检测**（不推荐）：
```cmake
file(GLOB INPUT1_QML_FILES "Input1/Input1Content/*.ui.qml")
```
缺点：CMake 不会自动检测新文件，需要重新运行 CMake

2. **添加验证脚本**：
```powershell
# 检查源码中的 QML 文件是否都在 CMakeLists.txt 中
$qmlFiles = Get-ChildItem -Path "src/qml/Input1/Input1Content" -Filter "*.ui.qml"
$cmakeContent = Get-Content "src/qml/CMakeLists.txt" -Raw
foreach ($file in $qmlFiles) {
    if ($cmakeContent -notmatch $file.Name) {
        Write-Warning "缺失: $($file.Name)"
    }
}
```

3. **定期检查**：
```bash
# 列出所有 .ui.qml 文件
find src/qml/Input1/Input1Content -name "*.ui.qml"

# 检查 CMakeLists.txt
grep "Input1/Input1Content.*\.ui\.qml" src/qml/CMakeLists.txt
```

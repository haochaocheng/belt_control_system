## 布局特点

### 优点
1. ✅ **规整对齐**: 所有组件完美对齐，无缝隙
2. ✅ **等分布局**: 每列宽度相同（480），每行高度相近（333/334）
3. ✅ **充分利用空间**: 完全填满可用区域（1920x1000）
4. ✅ **易于维护**: 清晰的行列结构
5. ✅ **命名规范**: data_row{行}_col{列}
6. ✅ **横向排列**: 3 行 4 列，更适合宽屏显示

### 计算公式
```
列 X 坐标 = (列索引 - 1) × 480
行 Y 坐标 = 80 + (行索引 - 1) × 333

示例：
- 第 1 行第 1 列: x = 0,    y = 80
- 第 2 行第 4 列: x = 1440, y = 413
- 第 3 行第 2 列: x = 480,  y = 746
```

## 与 4x3 布局对比

| 项目 | 4 行 3 列 | 3 行 4 列 ✅ |
|------|-----------|-------------|
| 每列宽度 | 640 像素 | 480 像素 |
| 每行高度 | 250 像素 | 333 像素 |
| 单元格比例 | 640:250 = 2.56:1 | 480:333 = 1.44:1 |
| 适合场景 | 竖向内容 | 横向内容 |
| 宽屏适配 | 较差 | 更好 ✅ |

**选择 3x4 的原因**：
- 更适合 1920x1080 宽屏比例
- 单元格更接近正方形（1.44:1）
- 横向排列更符合阅读习惯

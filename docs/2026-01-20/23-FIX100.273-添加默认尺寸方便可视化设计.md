# FIX 100.273 - 添加默认尺寸方便可视化设计

**日期**: 2026-01-20
**状态**: ✅ 已完成

---

## 🐛 问题描述

**用户反馈**：
> "参数设置页面Item里面的root,能不能增加默认尺寸，也就是单独设计该页面时，没有尺寸，对于可视化布局不友好，它实际尺寸是由它的父级决定，但是为了单独设计方便能不能增加"

**问题表现**：
- 4个页面的根 Item 没有设置默认尺寸
- 在 Qt Design Studio 中打开页面时，看不到实际效果
- 设计布局时无法预览真实尺寸
- **实际运行时尺寸**：由父容器 SwipeView 控制，会自动覆盖
- **期望设计尺寸**：1920x1080（用户明确说明："实际是按照1920*1080"）

**受影响的文件**：
1. `ControlPanel.qml` - 首页
2. `ParameterSettings.qml` - 参数设置
3. `AlarmPage.qml` - 报警保护
4. `DeviceOperationLog.qml` - 运行日志

## 🔍 问题分析

### Qt/QML 设计时 vs 运行时尺寸

**设计时尺寸的作用**：
- 在 Qt Design Studio 中提供预览效果
- 方便开发者在可视化编辑器中布局组件
- 不影响运行时的实际尺寸

**运行时尺寸由谁决定**：
```qml
// main.qml
SwipeView {
    id: swipeView
    anchors.fill: parent  // 填充 ApplicationWindow (1280x800)

    ControlPanel {
        // ❌ 设计时无尺寸 → 在 QDS 中看不到布局
        // ✅ 运行时自动填充 SwipeView (1280x800)
    }
}
```

**为什么需要设计时默认尺寸**：
```qml
// ❌ 没有默认尺寸 - QDS 中看不到效果
Item {
    id: root
    // 无 width, height
    // QDS 显示为 0x0 或很小的尺寸
}

// ✅ 有默认尺寸 - QDS 中可以正常预览
Item {
    id: root
    width: 1920   // 设计尺寸
    height: 1080  // 设计尺寸
    // QDS 按照 1920x1080 显示预览
    // 运行时 SwipeView 会覆盖为 1280x800
}
```

### 设计尺寸 vs 运行时尺寸的映射

**项目的尺寸配置**：
- **设计分辨率**：1920x1080（Figma 设计稿尺寸）
- **运行时分辨率**：1280x800（设备屏幕尺寸）
- **缩放系数**：通过 scale transform 实现（Input1Page 示例）

**添加默认尺寸不影响运行时**：
```qml
Item {
    width: 1920   // 仅在 QDS 中使用
    height: 1080  // 仅在 QDS 中使用

    // 运行时被父容器覆盖
    // 实际运行时：
    // width = swipeView.width (1280)
    // height = swipeView.height (800)
}
```

## 📝 技术要点

### 1. QML Item 的尺寸决定机制

**尺寸优先级**（从高到低）：
1. **Anchor 布局**：`anchors.fill: parent`
2. **绑定表达式**：`width: parent.width`
3. **显式赋值**：`width: 1920`

**本案例应用**：
```qml
// 页面定义：
Item {
    width: 1920   // ③ 显式赋值（设计时使用）
    height: 1080
}

// main.qml 中使用：
SwipeView {
    anchors.fill: parent  // SwipeView 填充 ApplicationWindow

    ControlPanel {
        // ① 运行时被 SwipeView 隐式覆盖
        // 实际 width = swipeView.width
        // 实际 height = swipeView.height
    }
}
```

**为什么设计时尺寸不影响运行时**：
- SwipeView 的子元素会自动填充 SwipeView 的可用空间
- 子元素的 width/height 设置会被忽略
- 这是 SwipeView 的内置行为，无法改变

### 2. 设计分辨率 vs 运行时分辨率

**项目的分辨率配置**：
```qml
// 设计分辨率（Figma 设计稿）
Design Resolution: 1920 x 1080

// 运行时分辨率（设备屏幕）
Runtime Resolution: 1280 x 800

// 缩放方式（Input1Page 示例）
scale: Math.min(parent.width / 1920, parent.height / 1080)
```

**为什么不使用 1280x800 作为设计尺寸**：
- 设计稿是 1920x1080 分辨率
- 设计师使用 1920x1080 绘制 UI
- 开发者在 QDS 中按照设计稿布局
- 运行时通过 scale transform 缩放到 1280x800

**本案例**（前4个页面）：
- 不使用 scale transform（SwipeView 自动适配）
- 设计时按照 1920x1080 布局
- 运行时 SwipeView 拉伸到 1280x800
- **可能导致非等比缩放**（取决于子元素的 anchor/layout 配置）

### 3. SwipeView 的子元素尺寸管理

**SwipeView 的行为**：
```qml
SwipeView {
    width: 1280
    height: 800

    Item {
        // 自动设置为：
        // width = 1280 (swipeView.width)
        // height = 800 (swipeView.height)
    }
}
```

**源码分析**（Qt 6.5 SwipeView 实现）：
```cpp
// SwipeView.qml (Qt Quick Controls 2)
contentItem: ListView {
    model: swipeView.contentModel
    delegate: Item {
        // 自动绑定尺寸
        width: swipeView.width
        height: swipeView.height
    }
}
```

**结论**：
- SwipeView 会强制子元素尺寸等于自身尺寸
- 子元素的 width/height 设置只在设计时有效
- 运行时完全由 SwipeView 控制

### 4. Qt Design Studio 的预览机制

**QDS 如何显示 Item**：
```qml
// 在 QDS 中：
Item {
    width: 1920   // QDS 使用这个尺寸渲染预览
    height: 1080
}

// 在运行时：
Item {
    // SwipeView 覆盖尺寸
    // width = swipeView.width
    // height = swipeView.height
}
```

**QDS 的设计模式**：
- **Form Editor**：可视化拖拽布局（需要明确尺寸）
- **Text Editor**：代码编辑（可以不设置尺寸）
- **Live Preview**：实时预览（使用设置的尺寸）

**添加默认尺寸的好处**：
- Form Editor 中可以正常拖拽和预览
- Live Preview 显示完整的 1920x1080 布局
- 设计师可以按照设计稿精确调整位置

## ⚠️ 注意事项

### 1. 设计尺寸 vs 运行时尺寸

**重要提示**：
- 设计时按照 1920x1080 布局
- 运行时会被拉伸到 1280x800
- **可能导致非等比缩放**（宽高比不同）

**解决非等比缩放问题**：
- 如果需要等比缩放，参考 Input1Page 的实现
- 使用 Item + scale transform 包装
- 本案例（前4个页面）不使用 scale，接受拉伸行为

### 2. 子组件的相对尺寸

**使用相对尺寸的子组件**：
```qml
Item {
    width: 1920   // 设计时 1920
    height: 1080  // 设计时 1080

    Rectangle {
        width: parent.width * 0.5  // 设计时 960，运行时 640
        height: parent.height * 0.5 // 设计时 540，运行时 400
    }
}
```

**绝对尺寸的子组件**：
```qml
Item {
    width: 1920   // 设计时 1920
    height: 1080  // 设计时 1080

    Rectangle {
        width: 200   // 固定 200 (设计时和运行时都是 200)
        height: 100  // 固定 100
        // ⚠️ 在不同分辨率下大小相同，可能看起来比例不协调
    }
}
```

**建议**：
- 布局使用相对尺寸（parent.width, anchors.fill）
- 文本大小使用固定尺寸（font.pixelSize: 16）
- 图标和图片根据需要选择

### 3. 不同页面的缩放策略

**前4个页面（本案例）**：
- SwipeView 自动拉伸
- 接受非等比缩放
- 简单直接

**Input1Page（模块状态）**：
- 使用 scale transform
- 保持等比缩放
- 复杂但效果好

**选择依据**：
- 简单页面：使用 SwipeView 自动拉伸
- 复杂设计：使用 scale transform 保持比例

# 资源自动同步脚本使用说明

**脚本位置**：`scripts\2026-01-12\09-sync-input1-resources.ps1`

**日期**：2026-01-20
**版本**：v3.0（扩展版 - 支持所有 images 目录）

---

## 🎯 功能说明

### 1. 自动扫描所有 images 目录

脚本会自动查找 `src/qml/` 下所有名为 `images` 的目录，包括：
- ✅ `images/` - 通用图片
- ✅ `components/parameter_settings/images/` - 参数设置背景
- ✅ `pages/images/` - 页面背景
- ✅ `Input1/Input1Content/images/` - Input1 模块图片
- ✅ 任何其他 images 目录（自动检测）

### 2. 自动去除重复文件

**去重规则**：
- 以文件名（小写）为键，检测重复
- 保留第一个遇到的文件
- 跳过后续同名文件
- **例如**：如果 `pages/images/bg.png` 和 `Input1/images/bg.png` 同时存在，只保留 `pages/images/bg.png`（按目录优先级）

### 3. 自动同步 QML 组件

扫描 `Input1/Input1Content/*.ui.qml` 文件，自动更新到 `CMakeLists.txt` 的 `QML_FILES` 部分。

## ⚙️ 工作原理

### 1. 扫描阶段

```powershell
# 自动查找所有 images 目录
Get-ChildItem -Path $QmlRoot -Directory -Recurse -Filter "images"

# 扫描每个目录的图片文件
Get-ChildItem -Path $imageDir -File |
    Where-Object { $_.Extension -match '\.(svg|png|jpg|jpeg|webp)$' }
```

### 2. 去重阶段

```powershell
# 使用 HashTable 记录已添加的文件
$addedFiles = @{}

# 添加文件时检查重复
if (-not $addedFiles.ContainsKey($fileName)) {
    $resourcesList += "`n        $fullPath"
    $addedFiles[$fileName] = $fullPath
} else {
    Write-Host "   ⚠️ 跳过重复文件：$fullPath"
}
```

### 3. 更新 CMakeLists.txt

脚本会：
1. 读取 `CMakeLists.txt` 的所有行
2. 找到 `RESOURCES` 部分
3. 替换整个 `RESOURCES` 部分（从 `RESOURCES` 到 `RESOURCE_PREFIX` 之间的所有内容）
4. 保留其他所有内容不变
5. 写回文件（UTF-8 without BOM）

## ⚠️ 注意事项

### 1. 文件名去重规则

**同名文件检测**：
- 以文件名（小写）为键
- 例如：`BG.png`、`bg.png`、`Bg.PNG` 被视为同一个文件
- 保留第一个遇到的文件，跳过后续同名文件

**建议**：
- ✅ 避免在不同目录使用相同的文件名
- ✅ 如果确实需要同名文件，将它们放在优先级更高的目录
- ❌ 不要在多个目录放置完全相同的图片

### 2. 支持的图片格式

脚本支持以下格式：
- ✅ `.svg` - 矢量图形
- ✅ `.png` - PNG 图片
- ✅ `.jpg` / `.jpeg` - JPEG 图片
- ✅ `.webp` - WebP 图片

**不支持的格式**：
- ❌ `.txt` - 文本文件
- ❌ `.bmp` - BMP 图片（需要时可以添加）
- ❌ `.gif` - GIF 动图（需要时可以添加）

### 3. 自动更新的安全性

**脚本会保留**：
- QML_FILES 中的非 Input1 组件
- RESOURCE_PREFIX 和 NO_PLUGIN_OPTIONAL
- qt_add_qml_module 的其他配置

**脚本会替换**：
- 整个 RESOURCES 部分（从 `RESOURCES` 到 `RESOURCE_PREFIX` 之间）
- Input1 QML 组件列表

**建议**：
- ✅ 第一次使用时选择 `N`，手动检查预览结果
- ✅ 确认无误后，后续可以直接选择 `Y`
- ✅ 如果有自定义的 RESOURCES 内容，确保在优先级目录中

### 4. CMakeLists.txt 备份

**脚本不会自动备份**，建议：
```powershell
# 手动备份（推荐）
Copy-Item "src\qml\CMakeLists.txt" "src\qml\CMakeLists.txt.backup"

# 或使用 Git（推荐）
git add src/qml/CMakeLists.txt
git commit -m "backup: CMakeLists.txt before auto-sync"
```

## 🛠️ 故障排查

### 问题 1：脚本找不到某些图片

**原因**：
- 图片不在 `images` 目录下
- 图片格式不支持

**解决方案**：
```powershell
# 检查图片位置
Get-ChildItem -Path "src\qml" -Recurse -Filter "*.png"

# 如果图片不在 images 目录，移动它
Move-Item "src\qml\pages\bg.png" "src\qml\pages\images\bg.png"
```

### 问题 2：重复文件警告

**示例输出**：
```
⚠️ 跳过重复文件：Input1/images/bg.png（已存在：pages/images/bg.png）
```

**解决方案**：
- 重命名重复的文件：`bg.png` → `input1_bg.png`
- 或删除不需要的文件

### 问题 3：CMakeLists.txt 更新失败

**错误信息**：
```
❌ 错误：未找到 RESOURCES 部分
```

**解决方案**：
- 检查 CMakeLists.txt 格式是否正确
- 确保有 `RESOURCES` 关键字
- 手动添加 `RESOURCES` 部分（参考预览输出）

## 🔍 问题分析

### 对比电机控制参数区（成功案例）

**用户提示**：查看电机控制参数区的实现，因为那个是成功的。

**BasicConfigTab.qml**（电机控制，成功）:
```qml
ScrollView {
    id: paramScrollView
    anchors.fill: parent
    clip: true

    GridLayout {
        width: paramScrollView.width * 0.9  // ✅ 占 ScrollView 宽度的 90%
        columns: 4  // 4列：标签1、输入框1、标签2、输入框2
        columnSpacing: 10
        rowSpacing: 12
        // ✅ 没有使用 anchors.horizontalCenter
    }
}
```

**SerialPortParamsTab.qml**（串口控制，失败）:
```qml
ScrollView {
    id: paramScrollView
    anchors.fill: parent
    clip: true

    GridLayout {
        width: paramScrollView.width * 0.9  // ❌ 宽度为0
        anchors.horizontalCenter: parent.horizontalCenter  // ❌ 破坏width绑定
        columns: 2
        columnSpacing: 16
        rowSpacing: 12
    }
}
```

### 根本原因

**关键发现**：`anchors.horizontalCenter: parent.horizontalCenter` 破坏了 `width` 的动态绑定！

**为什么会破坏绑定**：
1. QML 的 anchors 系统和 width/height 属性是互斥的
2. 当使用 `anchors.horizontalCenter` 时，QML 会尝试根据 anchors 计算元素的位置和尺寸
3. 这会覆盖 `width` 属性的绑定，导致 `width` 被固定为初始值（0）
4. 即使后续 `paramScrollView.width` 变化，`width` 也不会更新

**QML 官方文档警告**：
> "Do not use both anchors and width/height properties on the same item. Use one or the other."

### 为什么 BasicConfigTab 成功

**BasicConfigTab 的关键差异**：
- ✅ 没有使用 `anchors.horizontalCenter`
- ✅ 只使用 `width` 属性
- ✅ GridLayout 自然居中（因为 ScrollView 的内容会自动居中）

### 六次修复的完整历程

**Phase 7.37.8.3**：使用 anchors.left/right
- ❌ 导致负宽度（-24px）
- 原因：anchors.leftMargin/rightMargin 在 GridLayout 上不工作

**Phase 7.37.8.4**：使用 Item 包裹层
- ❌ Item.width 为 0
- 原因：`width: paramScrollView.width` 在加载时评估为 0

**Phase 7.37.8.5**：直接使用 GridLayout
- ❌ GridLayout.width 固定为 100px
- 原因：`width: Math.max(paramScrollView.width - 40, 100)` 静态赋值

**Phase 7.37.8.6**：使用 Qt.binding()
- ❌ GridLayout.width 为 16px
- 原因：`Qt.binding() + Math.max()` 组合失效

**Phase 7.37.8.7**：回退到 Phase 7.37 Phase 2 成功方案
- ❌ GridLayout.width 为 0
- 原因：`anchors.horizontalCenter` 破坏了 width 绑定

**Phase 7.37.8.8**：移除 anchors.horizontalCenter
- ✅ GridLayout.width 为 ScrollView 宽度的 90%
- ✅ 正确显示2列布局

## 💡 技术要点

### QML Anchors vs Width/Height

**QML 官方规则**：
> "Do not use both anchors and width/height properties on the same item. Use one or the other."

**为什么不能混用**：
1. **Anchors 系统**：根据父元素和兄弟元素的位置计算元素的位置和尺寸
2. **Width/Height 属性**：直接设置元素的尺寸
3. **冲突**：当同时使用时，QML 会优先使用 anchors，覆盖 width/height 的绑定

**正确的做法**：
```qml
// ✅ 只使用 width 属性
GridLayout {
    width: parent.width * 0.9
    columns: 2
}

// ❌ 混用 anchors 和 width
GridLayout {
    width: parent.width * 0.9
    anchors.horizontalCenter: parent.horizontalCenter  // 破坏width绑定
    columns: 2
}

// ✅ 只使用 anchors
GridLayout {
    anchors.left: parent.left
    anchors.right: parent.right
    anchors.leftMargin: parent.width * 0.05
    anchors.rightMargin: parent.width * 0.05
    columns: 2
}
```

### 为什么 GridLayout 会自然居中

**ScrollView 的默认行为**：
- ScrollView 的内容会自动居中（如果内容宽度小于 ScrollView 宽度）
- 不需要显式使用 `anchors.horizontalCenter`
- 这是 Qt Quick Controls 2 的默认行为

**BasicConfigTab 的成功经验**：
- 没有使用任何 anchors
- 只设置 `width: paramScrollView.width * 0.9`
- GridLayout 自然居中，显示正常

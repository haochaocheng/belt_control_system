## 根本原因

**Phase 7.37.10重构ModbusRegisterTab时，添加了导航支持（focusParamIndex、virtualKeyboard、requestFocusParamIndex），但忘记在SerialPortConfigPanel.qml的modbusTabLoader中传递这些属性和连接信号**。

导致：
1. ModbusRegisterTab的focusParamIndex始终为0（默认值）
2. 焦点指示器无法正确显示（因为focusParamIndex不更新）
3. 虚拟键盘无法激活（因为virtualKeyboard为null）
4. 焦点更新请求无法传递到父组件（因为信号未连接）

---

## 解决方案

### 修改SerialPortConfigPanel.qml

在modbusTabLoader的onLoaded中，添加属性传递和信号连接：

```qml
// 3: MODBUS寄存器
Loader {
    id: modbusTabLoader
    active: root.currentTabIndex === 3
    source: "ModbusRegisterTab.qml"

    onLoaded: {
        console.log("✅ [SerialPortConfigPanel] ModbusRegisterTab 加载成功")
        if (item) {
            // 传递当前串口信息
            item.currentSerialPort = Qt.binding(function() {
                return root.currentSerialPort
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.10.1]: 传递焦点索引
            item.focusParamIndex = Qt.binding(function() {
                return root.focusParamIndex
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.10.1]: 传递虚拟键盘引用
            item.virtualKeyboard = Qt.binding(function() {
                return root.virtualKeyboard
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.10.1]: 连接信号，转发焦点更新
            item.requestFocusParamIndex.connect(function(paramIndex) {
                root.requestFocusParamIndex(paramIndex)
            })
        }
    }
}
```

## 技术要点

### 1. Loader的属性传递

**使用Qt.binding()保持双向绑定**：
```qml
item.focusParamIndex = Qt.binding(function() {
    return root.focusParamIndex
})
```

**为什么不能直接赋值**：
```qml
item.focusParamIndex = root.focusParamIndex  // ❌ 错误！只会复制一次值
```

**原因**：
- 直接赋值只会在Loader加载时复制一次值
- 之后root.focusParamIndex变化时，item.focusParamIndex不会更新
- 使用Qt.binding()可以保持动态绑定

### 2. 信号连接

**正确的信号连接方式**：
```qml
item.requestFocusParamIndex.connect(function(paramIndex) {
    root.requestFocusParamIndex(paramIndex)
})
```

**作用**：
- 将子组件的信号转发到父组件
- 保持信号传播链：ModbusRegisterTab → SerialPortConfigPanel → SerialPortControlPage → NavigationManager

### 3. 属性传递的完整性

**必须传递的属性**：
1. **focusParamIndex**：当前焦点参数索引（用于焦点指示器）
2. **virtualKeyboard**：虚拟键盘引用（用于激活虚拟键盘）
3. **currentSerialPort**：当前串口信息（用于业务逻辑）

**必须连接的信号**：
1. **requestFocusParamIndex**：焦点更新请求（用于导航）

**缺少任何一个都会导致功能异常**。

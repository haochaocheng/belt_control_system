## 根本原因

**SerialPortConfigPanel.qml的sendTabLoader缺少属性传递**：

1. **缺少focusParamIndex传递**：
   - 导致SerialPortSendTab的root.focusParamIndex始终为0
   - 焦点指示器的条件判断失败：`(root.focusParamIndex === 2)` 始终为false
   - 所有焦点指示器都不显示

2. **缺少virtualKeyboard传递**：
   - 导致SerialPortSendTab的root.virtualKeyboard为null
   - 虚拟键盘无法激活
   - 日志显示"虚拟键盘不可用"

3. **缺少requestFocusParamIndex信号连接**：
   - 导致焦点更新无法转发到SerialPortControlPage
   - 焦点索引无法正确同步

---

## 解决方案

### 修改SerialPortConfigPanel.qml

在sendTabLoader的onLoaded中，添加完整的属性传递和信号连接：

```qml
// 1: 发送区
Loader {
    id: sendTabLoader
    active: root.currentTabIndex === 1
    source: "SerialPortSendTab.qml"

    onLoaded: {
        console.log("✅ [SerialPortConfigPanel] SerialPortSendTab 加载成功")
        if (item) {
            // 传递当前串口信息
            item.currentSerialPort = Qt.binding(function() {
                return root.currentSerialPort
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.9.2]: 传递焦点索引
            item.focusParamIndex = Qt.binding(function() {
                return root.focusParamIndex
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.9.2]: 传递虚拟键盘引用
            item.virtualKeyboard = Qt.binding(function() {
                return root.virtualKeyboard
            })

            // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.9.2]: 连接信号，转发焦点更新
            item.requestFocusParamIndex.connect(function(paramIndex) {
                root.requestFocusParamIndex(paramIndex)
            })
        }
    }
}
```

## 技术要点

### 1. Loader的属性传递模式

**正确的属性传递方式**：

```qml
Loader {
    onLoaded: {
        if (item) {
            // 使用Qt.binding()创建动态绑定
            item.someProperty = Qt.binding(function() {
                return root.someProperty
            })
        }
    }
}
```

**为什么需要Qt.binding()**：
- 直接赋值：`item.someProperty = root.someProperty` 是静态的，只评估一次
- Qt.binding()：创建动态绑定，root.someProperty变化时自动更新

### 2. 信号连接模式

**正确的信号连接方式**：

```qml
Loader {
    onLoaded: {
        if (item) {
            // 连接子组件的信号到父组件的信号
            item.someSignal.connect(function(arg) {
                root.someSignal(arg)
            })
        }
    }
}
```

**为什么需要信号连接**：
- 子组件（SerialPortSendTab）发出信号
- 父组件（SerialPortConfigPanel）转发信号
- 祖父组件（SerialPortControlPage）接收信号

## 总结

### 问题根源

Phase 7.37.9.1的修复是正确的，但SerialPortConfigPanel没有传递必要的属性给SerialPortSendTab，导致：
- focusParamIndex始终为0 → 焦点指示器不显示
- virtualKeyboard为null → 虚拟键盘不可用
- requestFocusParamIndex信号未连接 → 焦点更新不转发

### 修复方法

参考paramsTabLoader的成功实现，为sendTabLoader添加完整的属性传递和信号连接。

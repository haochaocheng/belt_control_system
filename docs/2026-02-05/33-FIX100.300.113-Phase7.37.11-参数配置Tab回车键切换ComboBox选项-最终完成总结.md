### Phase 7.37.11.3 - 暴露serialConfigPanel属性

**问题**：serialConfigPanel不存在

**日志分析**：
```
Debug: ✅ [导航] serialPage: 存在
Debug: ⚠️ [导航] serialConfigPanel 不存在
```

**根本原因**：
- SerialPortControlPage的结构：Rectangle → ColumnLayout → RowLayout → Loader (serialConfigPanel)
- `serialConfigPanel`是在RowLayout内部定义的id
- QML的id只在定义它的作用域内可见
- 从外部（DeviceSettingsDialog）访问`serialPage.serialConfigPanel`时，无法访问到这个id

**解决方案**：
- 在SerialPortControlPage.qml中添加`property alias serialConfigPanel: serialConfigPanel`
- 使用property alias将内部id暴露为公开属性
- 外部就可以通过`serialPage.serialConfigPanel`访问到Loader对象

**代码变化**：
- SerialPortControlPage.qml: +3行

## 技术要点总结

### 1. 循环切换逻辑

**使用模运算实现循环**：
```qml
var nextIndex = (comboBox.currentIndex + 1) % comboBox.model.length
```

**示例**：
- 当前索引3，总数8：(3 + 1) % 8 = 4 ✅
- 当前索引7，总数8：(7 + 1) % 8 = 0 ✅（循环到第一个）

### 2. 返回值判断

**handleEnterKey()返回值**：
- `true`：表示已处理回车键，不执行默认行为
- `false`：表示未处理，执行默认行为（弹出虚拟键盘）

**DeviceSettingsDialog判断**：
```qml
if (currentTab.handleEnterKey()) {
    // 已处理，不弹出虚拟键盘
    event.accepted = true
    return
}
// 未处理，弹出虚拟键盘
```

### 3. QML id作用域

**id的可见性规则**：
- id只在定义它的QML文件内可见
- 子组件的id不会自动暴露给父组件的外部访问者
- 如果需要从外部访问，必须使用`property alias`暴露

**示例**：
```qml
// MyComponent.qml
Rectangle {
    id: root

    ColumnLayout {
        Loader {
            id: myLoader  // 这个id只在MyComponent内部可见
        }
    }
}

// 外部访问
var component = myComponentInstance.myLoader  // ❌ 错误！无法访问

// 正确方法：在MyComponent中添加
property alias myLoader: myLoader

// 外部访问
var component = myComponentInstance.myLoader  // ✅ 正确！
```

### 4. property alias的用法

**语法**：
```qml
property alias aliasName: targetId
```

**作用**：
- 将内部的id暴露为公开属性
- 外部可以通过属性名访问内部对象
- 保持对象的引用关系（不是复制）

**为什么不使用property var**：
- `property var`会在初始化时复制值
- 如果对象在初始化时还不存在，会得到`undefined`
- `property alias`创建的是引用，始终指向最新的对象

### 5. 调试日志的重要性

**为什么需要详细的调试日志**：
- 代码逻辑看起来正确，但实际运行时可能有问题
- 通过日志可以快速定位问题所在
- 避免盲目猜测，浪费时间

**调试日志的原则**：
- 在每个关键判断点添加日志
- 日志要清晰描述当前状态
- 使用不同的日志级别（✅、⚠️、❌）

## 扩展性

### 其他Tab也可以实现handleEnterKey()

如果将来其他Tab也需要回车键处理，只需：

1. 在Tab中添加`handleEnterKey()`函数
2. 返回`true`表示已处理，`false`表示未处理
3. DeviceSettingsDialog会自动调用

**示例**（SerialPortSendTab.qml）：
```qml
function handleEnterKey() {
    if (focusParamIndex === 3) {  // 发送按钮
        // 执行发送操作
        sendButton.clicked()
        return true
    }
    return false
}
```

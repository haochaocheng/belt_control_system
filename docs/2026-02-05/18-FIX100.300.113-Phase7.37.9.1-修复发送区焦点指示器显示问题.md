## 🔍 问题分析

### 问题1：焦点指示器不显示

**根本原因**：
- TextArea和Button的background已经有border属性
- 在background的Rectangle中设置border.color和border.width会被覆盖
- 焦点指示器的border无法显示

**Phase 7.37.9的错误实现**：
```qml
TextArea {
    id: sendInput
    background: Rectangle {
        color: "#1e2838"
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "#3d4556"  // ✗ 被覆盖
        border.width: (root.focusParamIndex === 2) ? 3 : 1  // ✗ 被覆盖
        radius: 4
    }
}
```

**正确的实现**（参考SerialPortParamsTab）：
```qml
Item {
    Layout.columnSpan: 2
    Layout.fillWidth: true
    Layout.preferredHeight: 225

    TextArea {
        id: sendInput
        anchors.fill: parent
        background: Rectangle {
            color: "#1e2838"
            border.color: "#3d4556"  // 固定边框
            border.width: 1
            radius: 4
        }
    }

    // ✅ 焦点指示器（外层）
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 2) ? 3 : 0
        radius: 4
        z: 11  // 确保在最上层
    }
}
```

**关键点**：
1. 使用Item包裹TextArea/Button
2. 在Item内部添加独立的焦点指示器Rectangle
3. 设置z: 11确保焦点指示器在最上层
4. background的border保持固定，不随焦点变化

### 问题2：格式输入框只显示三个点

**根本原因**：
- CustomComboBox的宽度只有100px
- 宽度不够显示完整的文本（"HEX"或"ASCII"）
- 文本被截断，只显示"..."

**解决方案**：
- 增加宽度从100px到120px
- 添加Item { Layout.fillWidth: true }在左侧，将格式选择推到右侧

## 💡 技术要点

### 1. 焦点指示器的正确实现

**错误方式**（在background中设置border）：
```qml
TextArea {
    background: Rectangle {
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "#3d4556"  // ✗ 被覆盖
        border.width: (root.focusParamIndex === 2) ? 3 : 1  // ✗ 被覆盖
    }
}
```

**正确方式**（使用外层Rectangle）：
```qml
Item {
    TextArea {
        anchors.fill: parent
        background: Rectangle {
            border.color: "#3d4556"  // 固定边框
            border.width: 1
        }
    }

    // 焦点指示器（外层）
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusParamIndex === 2) ? "#2196F3" : "transparent"
        border.width: (root.focusParamIndex === 2) ? 3 : 0
        radius: 4
        z: 11  // 确保在最上层
    }
}
```

**关键点**：
1. 使用Item包裹控件
2. 在Item内部添加独立的焦点指示器Rectangle
3. 设置z: 11确保焦点指示器在最上层
4. background的border保持固定，不随焦点变化

### 2. CustomComboBox宽度问题

**问题**：
- CustomComboBox需要足够的宽度显示文本
- 100px不够显示"ASCII"（5个字符）
- 需要增加到120px

**解决方案**：
- 增加宽度：`Layout.preferredWidth: 120`
- 添加填充：`Item { Layout.fillWidth: true }`在左侧
- 将格式选择推到右侧，与参数配置Tab的布局一致

### 3. 参考成功的实现

**SerialPortParamsTab的成功经验**：
- 所有可交互控件都使用Item包裹
- 焦点指示器在Item内部，作为独立的Rectangle
- 设置z: 11确保在最上层
- background的border保持固定

**复制成功的模式**：
- 发送数据：使用Item包裹TextArea
- 发送按钮：使用Item包裹Button
- 清空按钮：使用Item包裹Button

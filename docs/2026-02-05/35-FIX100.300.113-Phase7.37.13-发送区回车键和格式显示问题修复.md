## 技术要点

### 1. CustomComboBox的宽度计算

**实际可用宽度**：
```
实际可用宽度 = Layout.preferredWidth - padding - border - margin
```

**示例**：
- Layout.preferredWidth: 120px
- padding: 10px（左右各5px）
- border: 2px（左右各1px）
- margin: 8px（左右各4px）
- 实际可用宽度: 120 - 10 - 2 - 8 = 100px

**ASCII文本宽度**：
- 5个字符（A、S、C、I、I）
- 字体大小：14px
- 估算宽度：5 * 10 = 50px（每个字符约10px）
- 但是实际渲染可能需要更多空间（字符间距、抗锯齿等）

**建议宽度**：
- 150px：确保ASCII文本完整显示

### 2. 虚拟键盘导航键支持

**Qt虚拟键盘的导航模式**：
- Qt Virtual Keyboard支持键盘导航
- 需要启用`navigationMode`属性
- 使用方向键在键盘上导航
- 使用回车键输入选中的字符

**启用方法**：
```qml
InputPanel {
    id: inputPanel
    // ✅ 启用键盘导航模式
    keyboard.navigationMode: true
}
```

**导航行为**：
- 上下左右键：在键盘按键之间移动焦点
- 回车键：输入当前焦点的字符
- Esc键：关闭虚拟键盘

**优点**：
- 完全键盘操作，无需鼠标
- 提升操作效率
- 适合工业环境

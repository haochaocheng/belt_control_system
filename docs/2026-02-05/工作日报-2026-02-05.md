- 直接赋值（width: expression）是静态的，只评估一次
- Qt.binding(function() { return expression })创建动态绑定
- 动态绑定确保依赖属性变化时自动重新计算
- 四次修复历程：
  - Phase 7.37.8.3: anchors.left/right → 负宽度
  - Phase 7.37.8.4: Item包裹层 → parent.width=0
  - Phase 7.37.8.5: 静态赋值 → width固定100px
  - Phase 7.37.8.6: Qt.binding() → 动态绑定成功

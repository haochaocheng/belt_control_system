# FIX 100.300.113 Phase 7.37.11 - 参数配置Tab回车键切换ComboBox选项

**修复时间**: 2026-02-05
**修复人员**: AI Assistant
**关联问题**: Phase 7.37.10.1完成后，用户要求参数配置界面支持回车键切换ComboBox选项

---

## 问题描述

### 用户需求

Phase 7.37.10.1完成后，用户提出新需求：

- **参数配置界面，改界面都是下拉菜单** ✅
- **使用方法，当焦点在改参数时，按回车键直接切换里面的参数** 🎯
- 目标：按回车键循环切换选项（currentIndex++），而不是打开下拉列表

### 当前行为

- 焦点在ComboBox上时，按回车键会打开下拉列表 ❌
- 用户需要用鼠标点击或方向键选择选项 ❌
- 操作不够便捷

### 目标行为

- 焦点在ComboBox上时，按回车键直接切换到下一个选项 ✅
- 循环切换：最后一个选项 → 第一个选项 ✅
- 不打开下拉列表，直接切换 ✅

---

## 涉及的ComboBox

参数配置Tab有4个ComboBox（CustomComboBox）：

1. **baudRateCombo**（索引1）- 波特率
   - 选项：["1200", "2400", "4800", "9600", "19200", "38400", "57600", "115200"]
   - 默认：9600（索引3）

2. **dataBitsCombo**（索引3）- 数据位
   - 选项：["5", "6", "7", "8"]
   - 默认：8（索引3）

3. **stopBitsCombo**（索引5）- 停止位
   - 选项：["1", "1.5", "2"]
   - 默认：1（索引0）

4. **parityCombo**（索引7）- 校验位
   - 选项：["None", "Odd", "Even", "Mark", "Space"]
   - 默认：None（索引0）

## 解决方案

### 方案设计

**在SerialPortParamsTab.qml中添加`handleEnterKey()`函数**：

```qml
// ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.11]: 添加回车键处理函数
// 功能：当焦点在ComboBox上时，按回车键循环切换选项
function handleEnterKey() {
    console.log("✅ [SerialPortParamsTab] 处理回车键 - 当前焦点索引:", focusParamIndex)

    var comboBox = null

    switch(focusParamIndex) {
    case 1:  // 波特率
        comboBox = baudRateCombo
        break
    case 3:  // 数据位
        comboBox = dataBitsCombo
        break
    case 5:  // 停止位
        comboBox = stopBitsCombo
        break
    case 7:  // 校验位
        comboBox = parityCombo
        break
    default:
        console.log("⚠️ [SerialPortParamsTab] 当前焦点不在ComboBox上")
        return false
    }

    if (comboBox) {
        // 循环切换到下一个选项
        var nextIndex = (comboBox.currentIndex + 1) % comboBox.model.length
        comboBox.currentIndex = nextIndex
        console.log("✅ [SerialPortParamsTab] ComboBox选项切换:", comboBox.currentIndex, "→", nextIndex)
        return true  // 表示已处理
    }

    return false
}
```

**在DeviceSettingsDialog.qml中调用**：

```qml
Keys.onReturnPressed: {
    console.log("✅ [DeviceSettingsDialog] 按下回车键")

    // 1. 尝试调用当前Tab的handleEnterKey()
    if (serialPage.visible) {
        var configPanel = serialPage.children[0].children[1]
        if (configPanel) {
            var currentTab = configPanel.getCurrentTab()
            if (currentTab && typeof currentTab.handleEnterKey === "function") {
                if (currentTab.handleEnterKey()) {
                    console.log("✅ [DeviceSettingsDialog] 回车键已被Tab处理")
                    event.accepted = true
                    return
                }
            }
        }
    }

    // 2. 如果Tab没有处理，使用默认行为（关闭对话框）
    console.log("✅ [DeviceSettingsDialog] 回车键关闭对话框")
    close()
    event.accepted = true
}
```

## 技术要点

### 1. 循环切换逻辑

**使用模运算实现循环**：
```qml
var nextIndex = (comboBox.currentIndex + 1) % comboBox.model.length
```

**示例**：
- 当前索引3，总数8：(3 + 1) % 8 = 4 ✅
- 当前索引7，总数8：(7 + 1) % 8 = 0 ✅（循环到第一个）

### 2. 返回值判断

**handleEnterKey()返回值**：
- `true`：表示已处理回车键，不执行默认行为
- `false`：表示未处理，执行默认行为（关闭对话框）

**DeviceSettingsDialog判断**：
```qml
if (currentTab.handleEnterKey()) {
    // 已处理，不关闭对话框
    event.accepted = true
    return
}
// 未处理，关闭对话框
close()
```

### 3. 访问路径

**获取当前Tab**：
```qml
serialPage.children[0].children[1].getCurrentTab()
```

**路径解析**：
- `serialPage.children[0]`：RowLayout（左侧列表 + 右侧配置面板）
- `serialPage.children[0].children[1]`：SerialPortConfigPanel
- `getCurrentTab()`：获取当前激活的Tab（SerialPortParamsTab）

### 4. 函数存在性检查

**使用typeof检查函数是否存在**：
```qml
if (currentTab && typeof currentTab.handleEnterKey === "function") {
    // 函数存在，调用
}
```

**原因**：
- 不是所有Tab都有handleEnterKey()函数
- 只有参数配置Tab需要这个功能
- 其他Tab（发送区、接收区、MODBUS寄存器）不需要

## 扩展性

### 其他Tab也可以实现handleEnterKey()

如果将来其他Tab也需要回车键处理，只需：

1. 在Tab中添加`handleEnterKey()`函数
2. 返回`true`表示已处理，`false`表示未处理
3. DeviceSettingsDialog会自动调用

**示例**（SerialPortSendTab.qml）：
```qml
function handleEnterKey() {
    if (focusParamIndex === 3) {  // 发送按钮
        // 执行发送操作
        sendButton.clicked()
        return true
    }
    return false
}
```

## 技术要点

### 1. 两种虚拟键盘激活方法

**方法1：通过virtualKeyboard属性**（SerialPortSendTab之前使用）
```qml
property var virtualKeyboard: null

function handleEnterKey() {
    virtualKeyboard.activateVirtualKeyboard(control)  // ❌ 不工作
}
```

**方法2：直接在控件上调用**（电机控制使用，推荐）
```qml
function handleEnterKey() {
    control.activateVirtualKeyboard()  // ✅ 工作
}
```

### 2. 为什么方法2更好

**优点**：
- 不依赖virtualKeyboard属性传递
- 不需要复杂的属性传递链
- 和电机控制保持一致
- 更简单、更可靠

**原理**：
- Qt虚拟键盘会自动为支持输入的控件添加activateVirtualKeyboard()方法
- TextArea、TextField、SpinBox等控件都有这个方法
- 直接调用即可激活虚拟键盘

### 3. 回退方案

如果控件没有activateVirtualKeyboard()方法，使用forceActiveFocus()：

```qml
if (control.activateVirtualKeyboard) {
    control.activateVirtualKeyboard()  // 优先使用
} else {
    control.forceActiveFocus()  // 回退方案
}
```

### 4. 为什么Phase 7.37.13.2的修复不够

**Phase 7.37.13.2的修复**：
- 修复了virtualKeyboard属性传递链
- 确保virtualKeyboard不为null

**但是**：
- 即使virtualKeyboard不为null
- `virtualKeyboard.activateVirtualKeyboard(control)`这个方法可能仍然不工作
- 电机控制从来不使用这个方法

**Phase 7.37.13.3的修复**：
- 完全放弃virtualKeyboard属性
- 采用电机控制的方法
- 直接在控件上调用activateVirtualKeyboard()

# FIX 100.300.113 Phase 7.37.10 - ModbusRegisterTab 重构为 GridLayout 4列布局并添加导航支持

**修复时间**: 2026-02-05
**修复编号**: FIX 100.300.113 Phase 7.37.10
**修复类型**: 功能重构
**影响范围**: ModbusRegisterTab.qml

---

## 📋 问题描述

ModbusRegisterTab 需要重构为 GridLayout 4列布局，并添加导航支持，以便与其他 Tab 保持一致的交互体验。

**当前问题**：
1. 所有输入框拥挤到左边
2. 缺少导航支持
3. 缺少焦点指示器
4. 使用旧的 focusXXX() 函数

---

## ✅ 解决方案

### 1. 布局重构（参考 BasicConfigTab）

**目标布局**：GridLayout 4列布局（标签1、输入框1、标签2、输入框2）

**具体实现**：
- 使用 ScrollView + ColumnLayout + GridLayout
- GridLayout: width = scrollView.width * 0.9, columns = 4
- 标签宽度：160px，右对齐
- 输入框：Layout.fillWidth: true, Layout.maximumWidth: 300

**参数布局**（8个参数，索引0-7）：
```
行0：[0] 从站地址标签  [1] 从站地址输入（80px）  [2] 功能码标签  [3] 功能码下拉（200px）
行1：[4] 起始地址标签  [5] 起始地址输入（80px）  [6] 数量标签    [7] 数量输入（100px）
行2：[8] 写入值标签    [9] 写入值输入（80px）    [10] 空         [11] 空
行3：[12] 读取按钮（跨2列）                      [13] 写入按钮（跨2列）
```

**寄存器列表**：
- 保持原有的表格布局
- 添加焦点指示器（索引7）

### 2. 添加导航支持

**添加属性**：
```qml
property int focusParamIndex: 0       // 当前焦点参数索引
property var virtualKeyboard: null    // 虚拟键盘引用
```

**添加信号**：
```qml
signal requestFocusParamIndex(int paramIndex)
```

**实现函数**：

#### 2.1 triggerParamInput(paramIndex)
触发参数输入，对可编辑字段激活虚拟键盘：
- case 0: 从站地址（slaveAddress）
- case 1: 功能码（functionCode）
- case 2: 起始地址（startAddress）
- case 3: 数量（quantity）
- case 4: 写入值（writeValue）
- case 5: 读取按钮（readButton）
- case 6: 写入按钮（writeButton）
- case 7: 寄存器列表（registerListView）

对于可编辑字段（索引0、2、4），调用 `virtualKeyboard.activateVirtualKeyboard(inputField)`

#### 2.2 getParamFieldCount()
返回 8（8个参数）

#### 2.3 handleDirectionKey(direction)
实现自定义导航逻辑：

**下键导航**：
- 从站地址（0） → 起始地址（2）
- 功能码（1） → 数量（3）
- 起始地址（2） → 写入值（4）
- 数量（3） → 写入值（4）
- 写入值（4） → 读取按钮（5）
- 读取按钮/写入按钮（5/6） → 寄存器列表（7）

**上键导航**：
- 寄存器列表（7） → 读取按钮（5）
- 读取按钮/写入按钮（5/6） → 写入值（4）
- 写入值（4） → 起始地址（2）
- 起始地址（2） → 从站地址（0）
- 数量（3） → 功能码（1）

**左键导航**：
- 功能码（1） → 从站地址（0）
- 数量（3） → 起始地址（2）
- 写入按钮（6） → 读取按钮（5）

**右键导航**：
- 从站地址（0） → 功能码（1）
- 起始地址（2） → 数量（3）
- 读取按钮（5） → 写入按钮（6）

### 3. 添加焦点指示器

**所有输入控件**：
```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === X) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === X) ? 3 : 0
    radius: 4
    z: 11
}
```

**按钮焦点高亮**：
- 读取按钮（索引5）：focusParamIndex === 5 时，背景色 #2ecc71（亮绿色）
- 写入按钮（索引6）：focusParamIndex === 6 时，背景色 #e74c3c（亮红色）

### 4. 代码清理

- 删除旧的 focusXXX() 函数（不再需要）
- 保持原有的 MODBUS 功能逻辑不变
- 添加详细的注释说明索引映射

## 📌 注意事项

1. **导航逻辑**：
   - MODBUS 寄存器操作的布局特殊，使用自定义导航逻辑
   - 下键优先导航到同列的下一个控件
   - 左右键在同一行的控件之间切换

2. **虚拟键盘**：
   - 只对可编辑的 TextField 激活虚拟键盘（索引0、2、4）
   - ComboBox、SpinBox、Button 不激活虚拟键盘

3. **焦点指示器**：
   - 所有控件使用统一的焦点指示器样式（蓝色边框，3px宽）
   - 按钮使用背景色高亮（读取按钮：亮绿色，写入按钮：亮红色）

4. **代码清理**：
   - 删除了旧的 focusXXX() 函数（focusSlaveAddress、focusFunctionCode 等）
   - 保持原有的 MODBUS 功能逻辑不变

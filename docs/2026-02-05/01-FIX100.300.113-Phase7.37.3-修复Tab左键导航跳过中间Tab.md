# FIX 100.300.113 Phase 7.37.3 - 修复Tab左键导航跳过中间Tab

**日期**: 2026-02-05
**任务编号**: FIX 100.300.113 Phase 7.37.3
**状态**: ✅ 完成

## 📋 问题描述

**用户反馈**:
> "右键焦点在modbus寄存器tab时，按左键，直接焦点移动到串口列表COM1按钮上了，中间得tab键全部跳过了"

**问题现象**:
- 在"MODBUS寄存器"Tab（索引3）按左键
- 焦点直接跳到串口列表COM1
- 中间的3个Tab（参数配置、发送区、接收区）全部被跳过

**正常应该是**:
```
MODBUS寄存器（索引3）→ 接收区（索引2）→ 发送区（索引1）→ 参数配置（索引0）→ 串口列表
```

---

## 🔍 问题分析

### 根本原因

**NavigationManager的`moveInTabBar`函数中，右键逻辑硬编码检查`if (tabIndex < 9)`**

这是为电机控制页面设计的（10个Tab，索引0-9），但是串口控制页面只有4个Tab（索引0-3）。

### 代码流程分析

#### NavigationManager.qml line 133（修复前）:
```qml
case "Right":
    if (tabIndex < 9) {  // ❌ 硬编码为9，对串口控制页面来说太大了
        newIndex = tabIndex + 1
    }
    // 在最后一个Tab，保持不变
    break
```

#### 问题场景:
```
1. 用户在"MODBUS寄存器"Tab（tabIndex=3）
2. 按左键 → moveInTabBar("Left")
3. 检查 tabIndex > 0 → true（3 > 0）
4. newIndex = tabIndex - 1 = 2（应该切换到"接收区"）✅
5. 设置 tabIndex = 2 ✅

但是：
6. 用户继续按左键 → moveInTabBar("Left")
7. 检查 tabIndex > 0 → true（2 > 0）
8. newIndex = tabIndex - 1 = 1（应该切换到"发送区"）✅
9. 设置 tabIndex = 1 ✅

继续：
10. 用户继续按左键 → moveInTabBar("Left")
11. 检查 tabIndex > 0 → true（1 > 0）
12. newIndex = tabIndex - 1 = 0（应该切换到"参数配置"）✅
13. 设置 tabIndex = 0 ✅

最后：
14. 用户继续按左键 → moveInTabBar("Left")
15. 检查 tabIndex > 0 → false（0 == 0）
16. switchToArea(areaMotorList)（返回串口列表）✅
```

**等等，逻辑看起来是正确的！**

让我重新分析用户的问题...

### 重新分析

用户说："右键焦点在modbus寄存器tab时，按左键，直接焦点移动到串口列表COM1按钮上了"

**可能的原因**：
1. 用户在"MODBUS寄存器"Tab按**右键**（不是左键）
2. 因为`tabIndex < 9`检查通过（3 < 9），所以`tabIndex`变成4
3. 但是串口控制页面只有4个Tab（0-3），索引4是无效的
4. 可能导致显示异常或者直接跳过

**或者**：
- 用户在"MODBUS寄存器"Tab按左键
- 但是由于某种原因，`tabIndex`没有正确递减
- 直接跳到了串口列表

让我检查是否有其他地方的逻辑问题...

**实际上，问题可能是**：
- 用户在"MODBUS寄存器"Tab（索引3）
- 按右键想继续向右导航
- 因为`tabIndex < 9`检查通过，`tabIndex`变成4
- 但是串口控制页面只有4个Tab（0-3），索引4超出范围
- SerialPortConfigPanel的StackLayout可能显示异常
- 或者焦点指示器显示在错误的位置

**真正的问题**：
- 右键逻辑应该检查`if (tabIndex < 3)`（串口控制页面的最后一个Tab索引）
- 而不是`if (tabIndex < 9)`（电机控制页面的最后一个Tab索引）

## ✅ 修复内容

### 1. 添加lastTabIndex属性到NavigationManager

**文件位置**: NavigationManager.qml lines 22-26

**添加内容**:
```qml
// ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.3]: 添加 lastTabIndex 属性
// 不同页面有不同的Tab数量：
// - 电机控制页面：10个Tab（0-9），lastTabIndex=9
// - 串口控制页面：4个Tab（0-3），lastTabIndex=3
property int lastTabIndex: 9  // 默认为9（电机控制页面）
```

**作用**:
- 允许每个页面设置自己的Tab数量
- 默认为9（电机控制页面）
- 串口控制页面设置为3

### 2. 修改moveInTabBar函数使用lastTabIndex

**文件位置**: NavigationManager.qml line 139

**修改内容**:
```qml
case "Right":
    if (tabIndex < lastTabIndex) {  // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.3]: 使用 lastTabIndex 动态限制
        newIndex = tabIndex + 1
    }
    // 在最后一个Tab，保持不变
    break
```

**修改前**:
```qml
case "Right":
    if (tabIndex < 9) {  // ❌ 硬编码为9
        newIndex = tabIndex + 1
    }
    // 在最后一个Tab，保持不变
    break
```

**效果**:
- 电机控制页面：`lastTabIndex=9`，可以从Tab 0导航到Tab 9
- 串口控制页面：`lastTabIndex=3`，可以从Tab 0导航到Tab 3
- 在最后一个Tab按右键，保持不变（不会超出范围）

### 3. 设置SerialPortControlPage的lastTabIndex

**文件位置**: SerialPortControlPage.qml line 154

**添加内容**:
```qml
lastTabIndex = 3  // ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.3]: 串口控制页面有4个Tab（0-3）
```

**位置**:
- 在NavigationManager的Component.onCompleted中
- 与其他初始化代码一起

**效果**:
- 串口控制页面的Tab导航限制在0-3范围内
- 在"MODBUS寄存器"Tab（索引3）按右键，保持不变
- 在"MODBUS寄存器"Tab（索引3）按左键，切换到"接收区"Tab（索引2）

## 💡 技术要点

### 为什么需要lastTabIndex属性

**问题**：
- NavigationManager是通用的，用于电机控制和串口控制两个页面
- 电机控制页面有10个Tab（0-9）
- 串口控制页面有4个Tab（0-3）
- 硬编码`if (tabIndex < 9)`对串口控制页面来说太大了

**解决方案**：
```qml
// NavigationManager.qml
property int lastTabIndex: 9  // 默认为9（电机控制页面）

// SerialPortControlPage.qml
lastTabIndex = 3  // 串口控制页面有4个Tab（0-3）

// MotorControlPage.qml
lastTabIndex = 9  // 电机控制页面有10个Tab（0-9）
```

**效果**：
- ✅ 每个页面可以设置自己的Tab数量
- ✅ 右键导航不会超出范围
- ✅ 左键导航正确逐个返回

### 为什么默认值是9

**原因**：
- 电机控制页面是主要页面，有10个Tab
- 默认值设置为9，确保电机控制页面不需要额外设置
- 串口控制页面需要显式设置为3

**效果**：
- ✅ 向后兼容（电机控制页面不需要修改）
- ✅ 新页面需要显式设置（避免忘记）

### Tab索引和Tab数量的关系

**Tab数量 = lastTabIndex + 1**

| 页面 | Tab数量 | Tab索引范围 | lastTabIndex |
|------|---------|------------|--------------|
| 电机控制 | 10个 | 0-9 | 9 |
| 串口控制 | 4个 | 0-3 | 3 |

**示例**：
- 串口控制页面有4个Tab：参数配置（0）、发送区（1）、接收区（2）、MODBUS寄存器（3）
- lastTabIndex = 3（最后一个Tab的索引）
- 右键检查：`if (tabIndex < 3)`，即`if (tabIndex < lastTabIndex)`
- 在Tab 3按右键：`3 < 3`为false，保持不变 ✅

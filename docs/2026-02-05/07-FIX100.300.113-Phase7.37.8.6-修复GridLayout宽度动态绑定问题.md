**问题现象**:

- 所有参数（波特率、数据位、停止位、校验位）垂直排列

## 🔍 问题分析

### 根本原因

**Phase 7.37.8.5 的代码**（SerialPortParamsTab.qml line 188）：
```qml
GridLayout {
    id: gridLayout
    width: Math.max(paramScrollView.width - 40, 100)  // ❌ 静态赋值
    anchors.horizontalCenter: parent.horizontalCenter
    columns: 2
}
```

**问题**：
- `width: Math.max(paramScrollView.width - 40, 100)` 在 `Component.onCompleted` 时评估
- 此时 `paramScrollView.width` 还是 0（ScrollView 还没有完成布局）
- 所以 `Math.max(0 - 40, 100)` = 100px
- 100px 的宽度只能容纳单列参数

### 为什么 Phase 7.37.8.5 失败

**Qt/QML 组件加载顺序**：
```
1. Component.onCompleted 触发
2. 此时 parent 的尺寸可能还是 0
3. width 表达式被评估为静态值（100px）
4. 后续 parent 尺寸变化，width 不会更新
```

**关键问题**：
- `width: Math.max(paramScrollView.width - 40, 100)` 是**静态赋值**
- 不是**动态绑定**
- 一旦赋值后，即使 `paramScrollView.width` 变化，`width` 也不会更新

### 正确的解决方案

**使用 `Qt.binding()` 创建动态绑定**：
```qml
width: Qt.binding(function() {
    return Math.max(paramScrollView.width - 40, 100)
})
```

**效果**：
- ✅ `paramScrollView.width` 变化时，`width` 会自动重新计算
- ✅ 确保 GridLayout 宽度始终跟随 ScrollView 宽度
- ✅ 正确显示2列布局

## 💡 技术要点

### Qt.binding() vs 直接赋值

**直接赋值**（错误）:
```qml
width: Math.max(paramScrollView.width - 40, 100)
```
- ❌ 在 Component.onCompleted 时评估一次
- ❌ 后续 paramScrollView.width 变化，width 不会更新
- ❌ 导致宽度固定为初始值（100px）

**Qt.binding()**（正确）:
```qml
width: Qt.binding(function() {
    return Math.max(paramScrollView.width - 40, 100)
})
```
- ✅ 创建动态绑定
- ✅ paramScrollView.width 变化时，width 自动重新计算
- ✅ 确保宽度始终正确

### 为什么需要 Qt.binding()

**问题**：
- QML 的属性绑定在某些情况下会被"破坏"
- 例如：在 Component.onCompleted 中赋值
- 或者：使用复杂表达式（如 Math.max()）

**解决方案**：
- 使用 `Qt.binding()` 显式创建绑定
- 确保绑定不会被破坏
- 即使在 Component.onCompleted 中也能正常工作

### 四次修复的完整历程

**Phase 7.37.8.3**：使用 anchors.left/right
- ❌ 导致负宽度（-24px）
- 原因：anchors.leftMargin/rightMargin 在 GridLayout 上不工作

- 原因：`width: paramScrollView.width` 在加载时评估为 0

**Phase 7.37.8.5**：直接使用 GridLayout

- 原因：`width: Math.max(paramScrollView.width - 40, 100)` 静态赋值

**Phase 7.37.8.6**：使用 Qt.binding()
- ✅ GridLayout.width 动态绑定

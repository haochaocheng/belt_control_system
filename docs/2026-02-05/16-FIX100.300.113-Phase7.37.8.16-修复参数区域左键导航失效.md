## 📋 问题描述

**用户反馈**:
> "导航键从波特率无法切换到COM1问题依然存在，pjsip.md最后日志，左键无法将焦点移动到COM1."

**问题现象**:
- 焦点在波特率（paramIndex=1，参数区域）时，按左键
- 日志连续输出"已在底部按钮最左侧"（重复多次）
- 焦点无法移动到串口名称（paramIndex=0）
- 也无法通过继续按左键返回到COM1（列表区域）

---

## 🔍 问题分析

### 日志分析（pjsip.md lines -23 to -2）

**关键日志序列**：
```
Line -32: paramIndex 变化: 1 (波特率) ✓ 正确
Line -23: 左键 - 当前区域: 2
Line -22: "已在底部按钮最左侧" ✗ 错误！
Line -21到-2: 连续按左键，每次都输出"已在底部按钮最左侧"
```

### 根本原因

**代码冲突**（DeviceSettingsDialog.qml lines 809-834）：
```qml
} else if (currentPage.focusSubArea === 2) {
    // ✅ 底部按钮区域：左键导航
    var buttonIndex = currentPage.focusButtonIndex

    // ... 按钮导航逻辑 ...

    } else {
        // 已在最左侧，保持焦点
        console.log("⚠️ [导航] 已在底部按钮最左侧")  // ← 这里！
        return
    }
}
```

**问题**：
1. **其他页面**：focusSubArea=2 是底部按钮区域 ✓
2. **串口控制页面**：focusSubArea=2 是参数区域 ✗
3. DeviceSettingsDialog的左键处理器没有检查页面类型
4. 导致参数区域的左键被错误地当作按钮区域处理

**focusSubArea定义差异**：
- **串口控制页面**：0=列表, 1=Tab, 2=参数, 3=按钮（4个区域）
- **其他页面**：0=列表, 1=参数, 2=按钮（3个区域）

**为什么输出"已在底部按钮最左侧"**：
1. 焦点在波特率（paramIndex=1，参数区域）
2. DeviceSettingsDialog检测到focusSubArea=2
3. 错误地认为这是底部按钮区域
4. 检查buttonIndex，发现不是1、3、4
5. 执行else分支，输出"已在底部按钮最左侧"
6. return，阻止了NavigationManager处理左键

## 💡 技术要点

### 为什么需要特殊处理

**问题**：
- DeviceSettingsDialog的键盘事件处理器是通用的
- 它假设focusSubArea=2是按钮区域（其他页面）
- 但串口控制页面的focusSubArea=2是参数区域
- 导致OLD代码错误地处理参数区域的左键

**解决方案**：
- 在focusSubArea=2的处理中，检查currentCategory === 6
- 如果是串口控制页面，主动调用NavigationManager
- 如果不是串口控制页面，执行原来的按钮导航逻辑

## 📚 教训总结

### 1. 不同页面的focusSubArea定义要清晰文档化

**问题**：
- 串口控制页面有4个区域（列表、Tab、参数、按钮）
- 其他页面有3个区域（列表、参数、按钮）
- DeviceSettingsDialog的通用处理器假设focusSubArea=2是按钮区域

**教训**：
- ✅ **在通用处理器中添加页面类型检查**
- ✅ **不同页面的focusSubArea定义要清晰文档化**
- ✅ **避免假设focusSubArea的含义**

### 2. 保持代码一致性

**问题**：
- 下键处理器（Phase 7.37.8.10）已经正确处理了串口控制页面
- 上键处理器（Phase 7.37.8.15）也正确处理了串口控制页面
- 左键处理器没有参考这两个成功的实现

**教训**：
- ✅ **参考成功的实现（下键、上键处理器）**
- ✅ **复制成功的模式到左键处理器**
- ✅ **保持代码一致性**

### 3. 主动调用NavigationManager

**问题**：
- NavigationManager是工具对象，不是事件处理器
- 必须主动调用NavigationManager.handleDirectionKey()
- 不能只是跳过代码，期望事件自动传播

**教训**：
- ✅ **必须主动调用NavigationManager.handleDirectionKey()**
- ✅ **不能只是跳过代码，期望事件自动传播**
- ✅ **NavigationManager是工具对象，不是事件处理器**

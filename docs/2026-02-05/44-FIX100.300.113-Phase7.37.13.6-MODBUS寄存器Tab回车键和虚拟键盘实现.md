**添加ModbusRegisterTab.qml（lines 106-193）**：

```qml
// ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.13.6]: 添加 handleEnterKey() 函数
// 处理回车键，根据当前焦点控件执行不同的操作
// 参考 SerialPortSendTab 和 SerialPortReceiveTab 的实现
function handleEnterKey() {
    console.log("✅ [ModbusRegisterTab] 处理回车键 - 当前焦点索引:", focusParamIndex)

    switch(focusParamIndex) {
    case 0:  // 从站地址（数字输入框）
        // 弹出虚拟键盘（数字输入）
        if (slaveAddress.activateVirtualKeyboard) {
            slaveAddress.activateVirtualKeyboard()
            return true
        } else {
            slaveAddress.forceActiveFocus()
            return true
        }

    case 1:  // 功能码（ComboBox）
        // 循环切换选项
        var newIndex = (functionCode.currentIndex + 1) % functionCode.model.length
        functionCode.currentIndex = newIndex
        return true

    case 2:  // 起始地址（数字输入框）
        // 弹出虚拟键盘（数字输入）
        if (startAddress.activateVirtualKeyboard) {
            startAddress.activateVirtualKeyboard()
            return true
        } else {
            startAddress.forceActiveFocus()
            return true
        }

    case 3:  // 数量（数字输入框）
        // 弹出虚拟键盘（数字输入）
        if (quantity.activateVirtualKeyboard) {
            quantity.activateVirtualKeyboard()
            return true
        } else {
            quantity.forceActiveFocus()
            return true
        }

    case 4:  // 写入值（数字输入框）
        // 弹出虚拟键盘（数字输入）
        if (writeValue.activateVirtualKeyboard) {
            writeValue.activateVirtualKeyboard()
            return true
        } else {
            writeValue.forceActiveFocus()
            return true
        }

    case 5:  // 读取按钮
        // 执行读取操作
        readButton.clicked()
        return true

    case 6:  // 写入按钮
        // 执行写入操作
        writeButton.clicked()
        return true

    case 7:  // 寄存器列表
        // 寄存器列表不需要处理回车键
        return false

    default:
        return false
    }
}
```

**关键实现**：
1. **数字输入框（从站地址、起始地址、数量、写入值）**：
   - 回车键 → 弹出虚拟键盘（数字输入）
   - 使用`inputField.activateVirtualKeyboard()`

2. **功能码ComboBox**：
   - 回车键 → 循环切换选项
   - 使用模运算：`(currentIndex + 1) % model.length`

3. **读取/写入按钮**：
   - 回车键 → 执行操作
   - 使用`button.clicked()`

4. **寄存器列表**：
   - 回车键 → 不处理
   - 返回false

## 技术要点

### 1. 为什么使用电流保护Tab的方式

**电流保护Tab的优势**：
- ScrollView会自动滚动，确保输入框不被虚拟键盘遮挡
- 不需要手动计算滚动位置
- 代码简单，易于维护

**对比发送区的方式**：
- 发送区：使用`virtualKeyboard.activateVirtualKeyboard(control)`
- 电流保护：使用`control.activateVirtualKeyboard()`
- **电流保护的方式更可靠**

### 2. ScrollView自动滚动的原理

**Qt的自动滚动机制**：
1. 当输入框获得焦点时，Qt会检查输入框是否在可见区域内
2. 如果输入框被遮挡（如被虚拟键盘遮挡），Qt会自动滚动ScrollView
3. 确保输入框在可见区域内

**为什么需要ScrollView**：
- 没有ScrollView：虚拟键盘会遮挡输入框
- 有ScrollView：Qt自动滚动，输入框不被遮挡

### 3. 数字输入法的实现

**CustomSpinBox和CustomTextField**：
- 默认使用数字输入法
- inputMethodHints设置为Qt.ImhDigitsOnly
- Qt虚拟键盘会根据inputMethodHints自动切换

**不需要手动设置**：
- 不需要在triggerParamInput()中设置inputMethodHints
- CustomSpinBox和CustomTextField已经设置好了

### 4. 回退方案

**为什么需要回退方案**：
```qml
if (inputField.activateVirtualKeyboard) {
    inputField.activateVirtualKeyboard()
} else {
    inputField.forceActiveFocus()
}
```

**原因**：
- 有些控件可能没有activateVirtualKeyboard()方法
- 使用forceActiveFocus()作为回退方案
- 确保代码不会崩溃

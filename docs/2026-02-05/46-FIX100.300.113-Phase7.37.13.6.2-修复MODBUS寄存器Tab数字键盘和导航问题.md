## 问题描述

### 用户反馈

Phase 7.37.13.6.1在QDS测试后，用户发现：

> "问题1：弹出的应该是纯数字输入键盘，现在是全键盘中文输入法。问题2：焦点在写入值后，就无法再使用导航键了，左右无法移动"

**问题分析**：
1. **问题1**：虚拟键盘弹出时显示全键盘中文输入法，而不是纯数字键盘
2. **问题2**：焦点移动到写入值后，导航键（左右键）无法工作

---

## 根本原因

### 问题1：CustomTextField没有设置inputMethodHints

**CustomTextField.qml（lines 1-104）**：
```qml
TextField {
    id: root

    // ❌ 没有设置 inputMethodHints
    // 默认使用全键盘中文输入法

    // 继承 TextField 的所有属性，可以直接使用：
    // - inputMethodHints: 输入法提示  ← 但是没有设置默认值
}
```

**问题所在**：
- CustomTextField没有设置`inputMethodHints`属性
- Qt虚拟键盘默认使用全键盘中文输入法
- MODBUS寄存器的输入框（从站地址、起始地址、数量、写入值）都应该使用数字输入法

### 问题2：写入值字段被禁用导致导航失效

**ModbusRegisterTab.qml（line 481）**：
```qml
DeviceInfo.CustomTextField {
    id: writeValue
    anchors.fill: parent
    enabled: functionCode.currentIndex > 0  // ❌ 当功能码是"03-读保持寄存器"时，enabled = false
    placeholderText: "0000-FFFF"
    validator: RegularExpressionValidator {
        regularExpression: /[0-9A-Fa-f]{1,4}/
    }
}
```

**问题分析**：
1. 当功能码是"03-读保持寄存器"（`currentIndex === 0`）时，`writeValue.enabled === false`
2. 禁用的输入框无法获得焦点
3. 当调用`writeValue.forceActiveFocus()`时，焦点无法设置
4. 导致DeviceSettingsDialog失去焦点
5. 导航键无法工作

**日志证据**：
```
Debug: ✅ [ModbusRegisterTab] 调用 writeValue.forceActiveFocus()
Debug: ⚠️ [DeviceSettingsDialog root] activeFocus 变化: false  ← 对话框失去焦点
Debug: ✅ [导航] handleEnterKey 返回值: true
Debug: ✅ [导航] 回车键已被Tab处理（串口控制）
（之后没有导航日志，说明导航键失效）
```

```qml
// ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.13.6.2]: 添加 isFieldEnabled() 辅助函数
// 检查字段是否启用，用于跳过禁用的字段
function isFieldEnabled(paramIndex) {
    switch(paramIndex) {
    case 0:  // 从站地址
        return true
    case 1:  // 功能码
        return true
    case 2:  // 起始地址
        return true
    case 3:  // 数量
        return true
    case 4:  // 写入值
        return functionCode.currentIndex > 0  // 只有写入操作时启用
    case 5:  // 读取按钮
        return functionCode.currentIndex === 0  // 只有读取操作时启用
    case 6:  // 写入按钮
        return functionCode.currentIndex > 0 && writeValue.text.length > 0  // 只有写入操作且有值时启用
    case 7:  // 寄存器列表
        return true
    default:
        return false
    }
}

// ✅ 2026-02-05 [FIX 100.300.113 Phase 7.37.13.6.2]: 修改 handleDirectionKey() 跳过禁用字段
function handleDirectionKey(direction) {
    console.log("✅ [ModbusRegisterTab] 自定义导航 - 方向:", direction, "当前索引:", focusParamIndex)

    var newIndex = focusParamIndex

    switch(direction) {
    case "Down":
        // 下键导航
        if (focusParamIndex === 0) {
            // 从站地址 → 起始地址
            newIndex = 2
        } else if (focusParamIndex === 1) {
            // 功能码 → 数量
            newIndex = 3
        } else if (focusParamIndex === 2) {
            // 起始地址 → 写入值（如果启用）或读取按钮
            newIndex = isFieldEnabled(4) ? 4 : 5  // ✅ 跳过禁用的写入值
        } else if (focusParamIndex === 3) {
            // 数量 → 写入值（如果启用）或读取按钮
            newIndex = isFieldEnabled(4) ? 4 : 5  // ✅ 跳过禁用的写入值
        } else if (focusParamIndex === 4) {
            // 写入值 → 写入按钮（如果启用）或寄存器列表
            newIndex = isFieldEnabled(6) ? 6 : 7  // ✅ 跳过禁用的写入按钮
        } else if (focusParamIndex === 5 || focusParamIndex === 6) {
            // 读取按钮或写入按钮 → 寄存器列表
            newIndex = 7
        }
        // 寄存器列表：保持不变（已经在最底部）
        break

    case "Up":
        // 上键导航
        if (focusParamIndex === 7) {
            // 寄存器列表 → 读取按钮或写入按钮
            newIndex = isFieldEnabled(5) ? 5 : (isFieldEnabled(6) ? 6 : 4)  // ✅ 跳过禁用的按钮
        } else if (focusParamIndex === 5 || focusParamIndex === 6) {
            // 读取按钮或写入按钮 → 写入值（如果启用）或起始地址
            newIndex = isFieldEnabled(4) ? 4 : 2  // ✅ 跳过禁用的写入值
        } else if (focusParamIndex === 4) {
            // 写入值 → 起始地址
            newIndex = 2
        } else if (focusParamIndex === 2) {
            // 起始地址 → 从站地址
            newIndex = 0
        } else if (focusParamIndex === 3) {
            // 数量 → 功能码
            newIndex = 1
        }
        // 从站地址和功能码：保持不变（已经在最顶部）
        break

    case "Left":
        // 左键导航
        if (focusParamIndex === 1) {
            // 功能码 → 从站地址
            newIndex = 0
        } else if (focusParamIndex === 3) {
            // 数量 → 起始地址
            newIndex = 2
        } else if (focusParamIndex === 6) {
            // 写入按钮 → 读取按钮（如果启用）或写入值
            newIndex = isFieldEnabled(5) ? 5 : (isFieldEnabled(4) ? 4 : 2)  // ✅ 跳过禁用的按钮
        }
        // 其他位置：保持不变
        break

    case "Right":
        // 右键导航
        if (focusParamIndex === 0) {
            // 从站地址 → 功能码
            newIndex = 1
        } else if (focusParamIndex === 2) {
            // 起始地址 → 数量
            newIndex = 3
        } else if (focusParamIndex === 5) {
            // 读取按钮 → 写入按钮（如果启用）
            newIndex = isFieldEnabled(6) ? 6 : 5  // ✅ 跳过禁用的写入按钮
        }
        // 其他位置：保持不变
        break
    }

    if (newIndex !== focusParamIndex) {
        console.log("✅ [ModbusRegisterTab] 导航索引变化:", focusParamIndex, "→", newIndex)
        requestFocusParamIndex(newIndex)
        return true  // 导航成功
    }

    console.log("⚠️ [ModbusRegisterTab] 导航无变化，返回false")
    return false  // 导航无变化
}
```

**关键变化**：
- ✅ 添加`isFieldEnabled()`辅助函数，检查字段是否启用
- ✅ 修改`handleDirectionKey()`，跳过禁用的字段
- ✅ 下键：起始地址/数量 → 写入值（如果启用）或读取按钮
- ✅ 上键：读取按钮/写入按钮 → 写入值（如果启用）或起始地址
- ✅ 左键：写入按钮 → 读取按钮（如果启用）或写入值

## 技术要点

### 1. inputMethodHints的作用

**Qt.ImhDigitsOnly**：
- 只显示数字键盘（0-9）
- 适用于纯数字输入（如从站地址、起始地址、数量）

**其他常用值**：
- `Qt.ImhNone`：默认全键盘
- `Qt.ImhFormattedNumbersOnly`：数字和格式字符（如小数点、负号）
- `Qt.ImhHiddenText`：密码输入（隐藏文本）

### 2. 为什么需要跳过禁用字段

**问题**：
- 禁用的输入框无法获得焦点
- 调用`forceActiveFocus()`时，焦点无法设置
- 导致DeviceSettingsDialog失去焦点
- 导航键无法工作

**解决方法**：
- 添加`isFieldEnabled()`函数，检查字段是否启用
- 在导航时跳过禁用的字段
- 确保焦点始终在启用的字段上

### 3. 为什么CustomTextField默认使用数字输入法

**原因**：
- MODBUS寄存器的输入框都是数字输入（从站地址、起始地址、数量、写入值）
- 电流保护Tab的输入框也都是数字输入
- 大部分输入框都是数字输入
- 默认使用数字输入法，减少重复配置

**如果需要其他输入法**：
```qml
DeviceInfo.CustomTextField {
    inputMethodHints: Qt.ImhNone  // 覆盖默认值，使用全键盘
}
```

## 教训总结

### ✅ 成功经验

1. **详细的日志分析**
   - 通过日志发现`writeValue.forceActiveFocus()`后没有虚拟键盘弹出
   - 发现DeviceSettingsDialog失去焦点
   - 快速定位问题

2. **检查字段的enabled状态**
   - 禁用的字段无法获得焦点
   - 需要在导航时跳过禁用的字段
   - 确保焦点始终在启用的字段上

3. **默认值的重要性**
   - CustomTextField默认使用数字输入法
   - 减少重复配置
   - 提高代码一致性

### ⚠️ 避免的错误

1. **没有设置inputMethodHints**
   - CustomTextField没有设置默认的inputMethodHints
   - 导致使用全键盘中文输入法
   - 应该设置合理的默认值

2. **没有检查字段的enabled状态**
   - 导航时没有检查字段是否启用
   - 导致焦点移动到禁用的字段
   - 导致导航键失效

3. **没有测试不同的功能码**
   - 只测试了写入操作（功能码 > 0）
   - 没有测试读取操作（功能码 = 0）
   - 导致发现问题较晚

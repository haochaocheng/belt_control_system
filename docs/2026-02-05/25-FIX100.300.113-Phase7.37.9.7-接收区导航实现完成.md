## 修复方案

### 1. 重构 SerialPortReceiveTab.qml

**文件路径**: `src/qml/components/device_info/pages/SerialPortReceiveTab.qml`

#### 1.1 添加导航属性和信号

```qml
// ========== 公开属性 ==========
property var currentSerialPort: null  // 当前串口信息
property bool isPaused: false         // 是否暂停接收
property int focusParamIndex: 0       // 当前焦点参数索引
property var virtualKeyboard: null    // 虚拟键盘引用

// ========== 信号 ==========
signal requestFocusParamIndex(int paramIndex)
```

#### 1.2 导航索引映射

```
行0：[0] 填充                      [1] 格式（右上角，120px宽）
行1：[2] 接收数据（大文本框，跨2列，270px高）
行2：[3] 清空按钮                  [4] 暂停/继续按钮
参数数量：5个（索引0-4）
```

#### 1.3 实现导航函数

**triggerParamInput(paramIndex)**:
- 索引0：填充（空）
- 索引1：接收格式（CustomComboBox）
- 索引2：接收数据（TextArea）
- 索引3：清空按钮
- 索引4：暂停/继续按钮

**getParamFieldCount()**:
- 返回 5（参数数量）

**handleDirectionKey(direction)**:
- 下键导航：1→2→3
- 上键导航：3/4→2→1
- 左键导航：4→3
- 右键导航：3→4

#### 1.4 改用 GridLayout 布局

从 ColumnLayout 改为 GridLayout（2列布局）：

```qml
GridLayout {
    anchors.fill: parent
    anchors.margins: 16
    columns: 2
    columnSpacing: 16
    rowSpacing: 12

    // 行0：标题 + 格式选择
    // 行1：接收数据（跨2列）
    // 行2：清空按钮 + 暂停按钮
}
```

#### 1.5 添加焦点指示器

所有可交互控件添加蓝色边框焦点指示器（3px）：

```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: (root.focusParamIndex === X) ? "#2196F3" : "transparent"
    border.width: (root.focusParamIndex === X) ? 3 : 0
    radius: 4
    z: 11
}
```

#### 1.6 按钮颜色设计

**清空按钮**（索引3）：
- 焦点时：`#e74c3c`（亮红色）
- 正常时：`#c0392b`（深红色）

**暂停/继续按钮**（索引4）：
- 焦点时：`#f39c12`（亮橙色）
- 正常时：`#d68910`（深橙色）

## 技术要点

### 1. GridLayout 布局

使用 GridLayout 实现 2 列布局，便于控制元素位置：

```qml
GridLayout {
    columns: 2
    columnSpacing: 16
    rowSpacing: 12
}
```

### 2. 自定义导航逻辑

接收区的布局特殊，需要自定义导航逻辑：
- 格式在右上角（索引1）
- 接收数据跨2列（索引2）
- 底部2个按钮（索引3、4）

### 3. 焦点指示器设计

使用外层 Rectangle 实现焦点指示器：
- `z: 11` 确保在最上层
- 根据 `focusParamIndex` 动态显示/隐藏
- 蓝色边框 3px

### 4. 按钮颜色状态

按钮根据焦点状态动态改变颜色：
- 焦点时：亮色
- 悬停时：亮色
- 按下时：深色
- 正常时：深色

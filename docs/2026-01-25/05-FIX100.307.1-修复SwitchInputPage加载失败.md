## 🔍 根本原因

`SwitchInputPage.qml` 文件已创建，但**没有添加到 QML 资源文件（qrc）中**。

Qt 的 `qt_add_qml_module` 需要在 `QML_FILES` 列表中显式声明所有 QML 文件，否则运行时无法找到。

## 📝 技术说明

### Qt QML 模块系统

Qt 6 使用 `qt_add_qml_module` 来管理 QML 文件：

```cmake
qt_add_qml_module(qml_module
    URI BeltControlQml
    VERSION 1.0
    STATIC
    NO_PLUGIN
    NO_GENERATE_QMLTYPES
    QML_FILES
        main.qml
        App.qml
        # ... 所有 QML 文件必须在这里声明
    RESOURCES
        images/header.png
        # ... 所有资源文件
)
```

**关键点**：
1. **QML_FILES**：所有 QML 文件必须显式列出
2. **RESOURCES**：所有图片、音频等资源文件必须显式列出
3. **运行时查找**：Qt 会将这些文件打包到 qrc 资源系统中
4. **路径格式**：运行时使用 `qrc:/qt/qml/BeltControlQml/` 前缀访问

## 🎯 经验教训

### 问题根源

创建新 QML 文件时，容易忘记添加到 CMakeLists.txt 的 `QML_FILES` 列表中。

### 预防措施

1. **创建 QML 文件后立即添加到 CMakeLists.txt**
2. **编译前检查 CMakeLists.txt**
3. **运行时错误优先检查资源文件配置**

### 调试技巧

当看到 `No such file or directory` 错误时：
1. 检查文件是否存在
2. 检查文件路径是否正确
3. **检查 CMakeLists.txt 中是否声明**
4. 检查 qrc 路径格式是否正确

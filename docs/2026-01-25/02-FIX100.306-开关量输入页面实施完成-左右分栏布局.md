### 2. 集成到 DeviceSettingsDialog.qml

**修改位置**：`src/qml/components/device_info/DeviceSettingsDialog.qml:299-319`

**修改内容**：
```qml
// 1: 开关量输入
// ✅ 2026-01-25 [FIX 100.306]: 使用 SwitchInputPage 组件
Loader {
    id: switchInputPageLoader
    active: root.currentCategory === 1  // 仅在选中时加载
    source: "pages/SwitchInputPage.qml"

    onLoaded: {
        if (item) {
            console.log("✅ [DeviceSettingsDialog] SwitchInputPage 加载成功")
            item.deviceId = root.deviceId
            item.deviceName = root.deviceName
        }
    }

    onStatusChanged: {
        if (switchInputPageLoader.status === Loader.Error) {
            console.error("❌ [DeviceSettingsDialog] SwitchInputPage 加载失败")
        }
    }
}
```

**优势**：
- ✅ 使用Loader延迟加载，提高性能
- ✅ 传递deviceId和deviceName属性
- ✅ 错误处理和日志输出

## 📊 方案对比

### 方案A：弹窗（Popup）

**优点**：
- 视觉焦点集中
- 空间利用灵活
- 动画效果酷炫

**优点**：
- 导航流畅（主-从布局）
- 层级扁平（无弹窗嵌套）
- 键盘导航简单
- 符合现代UI趋势

**缺点**：
- 空间受限（需要滚动）
- 需要重新设计
- 失去动画效果

**解决方案**：
- ✅ 使用ScrollView处理空间限制
- ✅ 左右分栏优化空间利用
- ✅ 简洁的UI设计

## 🔧 技术实现

### 数据模型

```qml
ListModel {
    id: digitalProtectionModel
    ListElement {
        name: "急停"
        active: false
        moduleType: "输入模块1"
        registerAddress: 2
        channelNumber: 0
    }
    // ... 其他7个保护项
}
```

**字段说明**：
- `name`：保护名称
- `active`：激活状态（布尔值）
- `moduleType`：模块类型（字符串）
- `registerAddress`：寄存器地址（整数）
- `channelNumber`：通道编号（0-7）

---

### 状态管理

```qml
property int currentProtectionIndex: 0  // 当前选中的保护项索引

// 选中项变化时加载数据
onCurrentProtectionIndexChanged: {
    loadProtectionData(currentProtectionIndex)
}
```

---

### 数据加载

```javascript
function loadProtectionData(index) {
    if (index < 0 || index >= digitalProtectionModel.count) {
        return
    }

    var item = digitalProtectionModel.get(index)
    nameField.text = item.name
    moduleTypeCombo.currentIndex = moduleTypeCombo.model.indexOf(item.moduleType)
    registerAddressSpin.value = item.registerAddress
    channelSpin.value = item.channelNumber

    // 设置默认的TTS文字
    ttsTextField.text = item.name + "保护报警"

    console.log("✅ 加载保护数据:", item.name)
}
```

---

### 数据保存

```javascript
function saveProtectionData() {
    if (root.currentProtectionIndex < 0 || root.currentProtectionIndex >= digitalProtectionModel.count) {
        return
    }

    digitalProtectionModel.setProperty(root.currentProtectionIndex, "name", nameField.text)
    digitalProtectionModel.setProperty(root.currentProtectionIndex, "moduleType", moduleTypeCombo.currentText)
    digitalProtectionModel.setProperty(root.currentProtectionIndex, "registerAddress", registerAddressSpin.value)
    digitalProtectionModel.setProperty(root.currentProtectionIndex, "channelNumber", channelSpin.value)

    console.log("✅ 保存保护数据:", nameField.text)

    // TODO: 保存到数据库
}
```

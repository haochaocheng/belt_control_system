## 📋 需求概述

### 核心需求
1. **12个设备独立存储**：4x3网格，每个设备独立参数
2. **永久存储**：不因重新部署而恢复初始化
3. **多类别参数**：
   - 基本配置
   - 开关量输入（8个保护项）
   - 模拟量输入（19个保护项）
   - 电机控制
   - 制动器控制
   - 张紧控制
   - 逻辑控制

### 数据规模估算
- **设备数量**：12个
- **开关量保护**：8个/设备 × 12设备 = 96条记录
- **模拟量保护**：19个/设备 × 12设备 = 228条记录
- **总计**：约324条保护记录 + 基本配置

## 🗄️ 存储方案选择

### 方案对比

| 方案 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **SQLite数据库** | 结构化、查询方便、支持事务、已有基础 | 需要C++代码 | ⭐⭐⭐⭐⭐ |
| QSettings | Qt原生、简单易用 | 不适合大量数据、查询不便 | ⭐⭐ |
| JSON文件 | 人类可读、易于调试 | 性能差、并发问题 | ⭐⭐⭐ |

**✅ 推荐方案：SQLite数据库**

**理由**：
1. 已有ProtectionConfigManager基础
2. 结构化存储，查询方便
3. 支持事务，数据一致性好
4. 性能优秀，适合大量数据
5. 跨平台，Linux/Windows都支持

## 🗂️ 数据库设计

### 表结构设计

#### 1. 设备表（devices）

```sql
CREATE TABLE IF NOT EXISTS devices (
    device_id INTEGER PRIMARY KEY,           -- 设备ID（1-12）
    device_name TEXT NOT NULL,               -- 设备名称（如"1号皮带"）
    device_type TEXT DEFAULT 'belt',         -- 设备类型
    position_row INTEGER,                    -- 网格位置：行（0-3）
    position_col INTEGER,                    -- 网格位置：列（0-2）
    enabled BOOLEAN DEFAULT 1,               -- 是否启用
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**索引**：
```sql
CREATE INDEX idx_devices_position ON devices(position_row, position_col);
```

---

#### 2. 基本配置表（device_basic_config）

```sql
CREATE TABLE IF NOT EXISTS device_basic_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,              -- 设备ID
    param_name TEXT NOT NULL,                -- 参数名称
    param_value TEXT,                        -- 参数值（字符串存储）
    param_type TEXT DEFAULT 'string',        -- 参数类型（string/int/real/bool）
    description TEXT,                        -- 参数描述
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_id) REFERENCES devices(device_id) ON DELETE CASCADE,
    UNIQUE(device_id, param_name)            -- 同一设备的参数名唯一
);
```

**索引**：
```sql
CREATE INDEX idx_basic_config_device ON device_basic_config(device_id);
```

## 🔍 数据初始化策略

### 首次启动

```cpp
bool DeviceConfigManager::initDefaultData() {
    // 检查是否已初始化
    QSqlQuery query(m_database);
    query.prepare("SELECT COUNT(*) FROM devices");
    if (!query.exec() || !query.next() || query.value(0).toInt() > 0) {
        return true;  // 已初始化，跳过
    }

    // 初始化12个设备
    for (int i = 1; i <= 12; i++) {
        int row = (i - 1) / 3;  // 0-3
        int col = (i - 1) % 3;  // 0-2
        QString deviceName = QString("%1号皮带").arg(i);

        query.prepare("INSERT INTO devices (device_id, device_name, position_row, position_col) "
                      "VALUES (?, ?, ?, ?)");
        query.addBindValue(i);
        query.addBindValue(deviceName);
        query.addBindValue(row);
        query.addBindValue(col);

        if (!query.exec()) {
            qWarning() << "Failed to init device" << i << ":" << query.lastError();
            return false;
        }

        // 初始化默认的开关量保护
        initDefaultDigitalProtections(i);

        // 初始化默认的模拟量保护
        initDefaultAnalogProtections(i);
    }

    return true;
}
```

## 📈 性能优化

### 批量操作

```cpp
bool DeviceConfigManager::saveDigitalProtectionsBatch(int deviceId, const QVariantList &protections) {
    m_database.transaction();

    for (const QVariant &protection : protections) {
        if (!saveDigitalProtection(deviceId, protection.toMap())) {
            m_database.rollback();
            return false;
        }
    }

    return m_database.commit();
}
```

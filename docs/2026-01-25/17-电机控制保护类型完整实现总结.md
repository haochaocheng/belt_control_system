## 🎯 功能特性

### 1. 统一的参数结构
所有保护类型都遵循相同的参数结构：
- 是否投入（投入/禁用）
- 报警类型（按次数/按时间）
- 动作保护类型（立即停机/延时停机/仅报警）
- 故障保护类型（紧急停机/安全停机/记录日志）
- 量程选择
- 上限/下限设置
- 过滤干扰延时
- 输入点选择

### 2. 键盘导航支持
- **上下键**：切换电机（1-8号）
- **左右键**：切换保护类型 Tab（10个）
- **Tab键**：在输入框间切换

### 3. 实时预览
- 在 QDS 中可以实时预览所有保护类型
- 修改后立即看到效果
- 无需重新编译

### 4. 模块化设计
- 每个保护类型独立为一个 QML 文件
- 易于维护和扩展
- 可以单独美化每个 Tab

## 📝 使用示例

### 配置电机保护参数

```qml
// 在 C++ 后端中
DeviceInfoController::setMotorProtection(
    motorId: 1,
    protectionType: "current",
    config: {
        enabled: true,
        alarmType: "count",
        actionType: "immediate_stop",
        faultType: "emergency_stop",
        range: "0-100A",
        upperLimit: 80,
        lowerLimit: 10,
        filterDelay: 0.5,
        inputPoint: "DI-0"
    }
)
```

### 读取电机保护参数

```qml
// 在 QML 中
Component.onCompleted: {
    var config = deviceInfoController.getMotorProtection(1, "current")
    console.log("电流保护配置:", JSON.stringify(config))
}
```

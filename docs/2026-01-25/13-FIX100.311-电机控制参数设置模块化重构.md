# FIX 100.311 - 电机控制参数设置模块化重构

**日期**：2026-01-25
**问题**：电机控制页面需要支持9种保护参数，参数数量巨大，需要合理的布局方案
**解决方案**：采用左右分栏 + Tab切换的模块化设计

---

## 📋 需求分析

### 参数结构

每个电机（共8个）包含以下参数：

#### 基本配置（5个参数）
1. 运行状态：投入/禁用
2. 模块类型：继电器模块（固定）
3. 模块地址：1-8
4. 输出通道：0-7
5. 反馈通道：0-7

#### 保护参数（9种保护类型）
1. **电流保护**（9个参数）
   - 是否投入
   - 报警类型（按次数/按时间）
   - 动作保护类型（立即停机/延时停机/仅报警）
   - 故障保护类型（紧急停机/安全停机/记录日志）
   - 电流量程（0-50A/0-100A/0-200A/0-500A）
   - 电流上限（0-500A）
   - 电流下限（0-500A）
   - 过滤干扰延时（0-10.0秒）
   - 输入点选择（DI-0 到 DI-7）

2. **前轴承温度**（待实现）
3. **后轴承温度**（待实现）
4. **电机A相绕组**（待实现）
5. **电机B相绕组**（待实现）
6. **电机C相绕组**（待实现）
7. **电机温度**（待实现）
8. **电机X轴振动**（待实现）
9. **电机Y轴振动**（待实现）

**总计**：每个电机约90个参数，8个电机共720个参数

## 🎨 设计方案

### 方案选择：左右分栏 + Tab切换

```
┌──────────┬────────────────────────────────┐
│ 电机列表  │  1号电机配置                    │
│          ├────────────────────────────────┤
│ ● 1号电机 │ [基本] [电流] [前轴承] [后轴承] │
│   2号电机 │ [A相] [B相] [C相] [温度] [振动] │
│   3号电机 ├────────────────────────────────┤
│   4号电机 │ 当前显示：电流保护              │
│   5号电机 │   是否投入: ◉ 投入  ○ 禁用      │
│   6号电机 │   报警类型: ◉ 按次数  ○ 按时间  │
│   7号电机 │   动作保护类型: [立即停机]      │
│   8号电机 │   ...                          │
└──────────┴────────────────────────────────┘
```

**优点**：
- ✅ 空间利用率最高，适合大量参数
- ✅ 左侧快速切换电机，右侧Tab切换保护类型
- ✅ 符合工业软件的常见布局模式
- ✅ 避免过度滚动
- ✅ 支持键盘操作（上下键切换电机，左右键切换Tab）

## 🏗️ 模块化架构

### 文件结构

```
pages/
├── MotorControlPage.qml          # 主文件（左右分栏布局）
├── MotorListPanel.qml             # 左侧电机列表
├── MotorConfigPanel.qml           # 右侧配置面板（Tab切换）
├── BasicConfigTab.qml             # 基本配置Tab
└── CurrentProtectionTab.qml       # 电流保护Tab
```

### 组件职责

#### 1. MotorControlPage.qml（主文件）
- 左右分栏布局
- 管理当前选中的电机索引
- 键盘事件分发

#### 2. MotorListPanel.qml（左侧列表）
- 显示8个电机
- 支持点击选择
- 支持键盘上下键
- 高亮当前选中的电机
- 显示电机运行状态

#### 3. MotorConfigPanel.qml（右侧面板）
- Tab栏（10个Tab）
- StackLayout切换内容
- 支持键盘左右键切换Tab
- 横向滚动支持（Tab较多时）

#### 4. BasicConfigTab.qml（基本配置）
- 运行状态（单选按钮）
- 模块类型（固定显示）
- 模块地址（SpinBox 1-8）
- 输出通道（SpinBox 0-7）
- 反馈通道（SpinBox 0-7）

#### 5. CurrentProtectionTab.qml（电流保护）
- 是否投入（单选按钮）
- 报警类型（单选按钮）
- 动作保护类型（ComboBox）
- 故障保护类型（ComboBox）
- 电流量程（ComboBox）
- 电流上限（SpinBox + 单位）
- 电流下限（SpinBox + 单位）
- 过滤干扰延时（SpinBox + 单位，支持小数）
- 输入点选择（ComboBox）

## ⌨️ 键盘操作支持

### 全局快捷键
- **上键**：选择上一个电机
- **下键**：选择下一个电机
- **左键**：切换到上一个Tab
- **右键**：切换到下一个Tab
- **Tab键**：在输入框间切换焦点
- **Enter键**：确认选择

### 焦点管理
- 主页面接收键盘事件
- 上下键事件转发给左侧列表
- 左右键事件转发给右侧面板
- 点击任何区域自动获取焦点

## 🎯 技术方案

### 方案概述

采用 PJSIP 编解码器优先级管理机制：

1. **获取编解码器列表**：`pjsua_codec_get_list()`
2. **设置编解码器优先级**：`pjsua_codec_set_priority()`
   - 优先级 0 = 禁用
   - 优先级 1-255 = 启用（值越大越优先）
3. **获取编解码器优先级**：`pjsua_codec_get_param()`
4. **持久化**：QSettings 保存编解码器状态到 `/app/appdata/sip_accounts.ini`

#### SipPhoneManager.cpp 实现细节

```cpp
QStringList SipPhoneManager::getAudioCodecs()
{
    QStringList codecs;

    if (!d->initialized) {
        return codecs;
    }

    // PJSIP 编解码器 ID 列表（仅支持的编解码器）
    pjsua_codec_info codec_info[32];
    unsigned count = 32;

    pj_status_t status = pjsua_codec_enum_info(codec_info, &count);
    if (status != PJ_SUCCESS) {
        qWarning() << "Failed to enumerate audio codecs";
        return codecs;
    }

    // 过滤音频编解码器（只显示用户要求的）
    QStringList supportedCodecs = {
        "opus", "PCMU", "PCMA", "G722", "iLBC",
        "AMR", "AMR-WB", "speex", "GSM", "speex-wb"
    };

    for (unsigned i = 0; i < count; ++i) {
        QString codecId = QString::fromUtf8(codec_info[i].codec_id.ptr,
                                           codec_info[i].codec_id.slen);

        // 只添加支持的编解码器
        for (const QString& supported : supportedCodecs) {
            if (codecId.contains(supported, Qt::CaseInsensitive)) {
                codecs.append(codecId);
                break;
            }
        }
    }

    return codecs;
}

bool SipPhoneManager::isAudioCodecEnabled(const QString& codecName)
{
    if (!d->initialized) {
        return false;
    }

    pj_str_t codec_id = pj_str(const_cast<char*>(codecName.toUtf8().constData()));
    pjmedia_codec_param param;

    pj_status_t status = pjsua_codec_get_param(&codec_id, &param);
    if (status != PJ_SUCCESS) {
        return false;
    }

    // 检查优先级（0 = 禁用）
    unsigned char priority = 0;
    status = pjsua_codec_get_priority(&codec_id, &priority);

    return (status == PJ_SUCCESS && priority > 0);
}

bool SipPhoneManager::setAudioCodecEnabled(const QString& codecName, bool enabled)
{
    if (!d->initialized) {
        return false;
    }

    pj_str_t codec_id = pj_str(const_cast<char*>(codecName.toUtf8().constData()));

    // 设置优先级：0 = 禁用，128 = 中等优先级（启用）
    unsigned char priority = enabled ? 128 : 0;

    pj_status_t status = pjsua_codec_set_priority(&codec_id, priority);

    if (status == PJ_SUCCESS) {
        qDebug() << "✅ Audio codec" << codecName << (enabled ? "enabled" : "disabled");

        // ✅ 持久化到 QSettings
        QString settingsPath = Private::getPersistentSettingsPath();
        QSettings settings(settingsPath, QSettings::IniFormat);
        settings.setValue("SIP/AudioCodec/" + codecName, enabled);

        emit audioCodecsChanged();
        return true;
    } else {
        qWarning() << "❌ Failed to" << (enabled ? "enable" : "disable")
                   << "audio codec" << codecName;
        return false;
    }
}
```

## 📊 工作流程

### 启动时恢复编解码器设置

```
1. initializeEndpoint()
   ↓
2. 枚举所有编解码器 (pjsua_codec_enum_info)
   ↓
3. 从 QSettings 读取保存的编解码器状态
   ↓
4. 应用编解码器优先级 (pjsua_codec_set_priority)
   ↓
5. emit audioCodecsChanged() + videoCodecsChanged()
   ↓
6. QML UI 更新 CheckBox 状态
```

### 用户修改编解码器设置

```
1. 用户点击 CheckBox
   ↓
2. onCheckedChanged 触发
   ↓
3. setAudioCodecEnabled(codecName, checked)
   ↓
4. pjsua_codec_set_priority(priority = 0 或 128)
   ↓
5. 保存到 QSettings (SIP/AudioCodec/opus = true)
   ↓
6. emit audioCodecsChanged()
   ↓
7. 下次通话使用新编解码器设置
```

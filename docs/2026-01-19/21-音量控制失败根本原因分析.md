### 2. Mixer 检测逻辑（get_mixer_name）

**位置**: `alsa_dev.c` Lines 297-344

**代码逻辑**:
```c
static void get_mixer_name(struct alsa_factory *af)
{
    snd_mixer_t *handle;
    snd_mixer_elem_t *elem;

    // 1. 打开 ALSA mixer "default"
    if (snd_mixer_open(&handle, 0) < 0)
        return;  // ← 失败直接返回

    if (snd_mixer_attach(handle, "default") < 0) {
        snd_mixer_close(handle);
        return;  // ← 失败直接返回
    }

    // 2. 注册和加载 mixer
    if (snd_mixer_selem_register(handle, NULL, NULL) < 0) {
        snd_mixer_close(handle);
        return;
    }

    if (snd_mixer_load(handle) < 0) {
        snd_mixer_close(handle);
        return;
    }

    // 3. 遍历所有 mixer 元素
    for (elem = snd_mixer_first_elem(handle); elem;
         elem = snd_mixer_elem_next(elem))
    {
        const char* elemname;
        elemname = snd_mixer_selem_get_name(elem);

        // 4. 检查元素是否激活
        if (snd_mixer_selem_is_active(elem))
        {
            // 5. 检查是否有 playback_volume 能力
            if (snd_mixer_selem_has_playback_volume(elem))
            {
                pj_ansi_strxcpy(af->pb_mixer_name, elemname,
                                     sizeof(af->pb_mixer_name));
                TRACE_((THIS_FILE, "Playback mixer name: %s",
                        af->pb_mixer_name));
            }

            // 6. 检查是否有 capture_volume 能力 ⭐ 关键！
            if (snd_mixer_selem_has_capture_volume(elem))
            {
                pj_ansi_strxcpy(af->cap_mixer_name, elemname,
                                     sizeof(af->cap_mixer_name));
                TRACE_((THIS_FILE, "Capture mixer name: %s",
                        af->cap_mixer_name));  // ← 应该打印这条日志
            }
        }
    }
    snd_mixer_close(handle);
}
```

**检测结果**:
- ❌ **未找到 capture mixer 元素**
- 证据：日志中没有 "Capture mixer name: ..." 输出
- 结果：`af->cap_mixer_name` 保持为空字符串（初始化值）

## 🔬 根本原因

### 原因分析

USB 摄像头的 ALSA 设备（`plughw:CARD=camera,DEV=0`）存在以下问题之一：

1. **没有 ALSA mixer 元素**：
   - `snd_mixer_attach(handle, "default")` 可能失败
   - 或者 mixer 成功打开，但没有任何 mixer 元素

2. **Mixer 元素不支持 capture_volume**：
   - Mixer 元素存在，但是是非激活状态（`snd_mixer_selem_is_active() = false`）
   - Mixer 元素激活，但没有 `capture_volume` 能力（`snd_mixer_selem_has_capture_volume() = false`）

3. **设备特性**：
   - USB 摄像头内置麦克风通常是简单的音频输入设备
   - 不像专业声卡，可能不提供软件可控的增益调节
   - 音量控制完全由硬件固定增益决定

## 💡 解决方案

### 方案对比

| 方案 | 可行性 | 优点 | 缺点 | 推荐 |
|------|--------|------|------|------|
| **设备层音量**<br>(`pjsua_snd_set_setting`) | ❌ 不可用 | 通话前后均可设置 | 硬件不支持 | ❌ |
| **会议桥 RX 增益**<br>(`pjsua_conf_adjust_rx_level`) | ✅ 可用 | 纯软件实现<br>无硬件依赖 | 只能在通话中使用<br>需在通话建立后调用 | ⚠️ 备选 |
| **会议桥 TX 增益**<br>(`pjsua_conf_adjust_tx_level`) | ✅ 可用 | 直接控制发送音量 | 同上 | ✅ **推荐** |
| **ALSA 命令行**<br>(`amixer`) | ❓ 未验证 | 绕过 PJSIP | 需要 root 权限<br>可能无效 | ⏸️ 待验证 |

### 推荐方案：会议桥 TX 增益

**API**: `pjsua_conf_adjust_tx_level()`

**位置**: `pjsua.h` Lines 8368-8369

**定义**:
```c
/**
 * Adjust the signal level to be transmitted from the bridge to the
 * specified port by making it louder or quieter.
 *
 * @param slot          The conference bridge slot number.
 * @param level         Signal level adjustment. Value 1.0 means no level
 *                      adjustment, while value 0 means to mute the port.
 *
 * @return              PJ_SUCCESS on success, or the appropriate error code.
 */
PJ_DECL(pj_status_t) pjsua_conf_adjust_tx_level(pjsua_conf_port_id slot,
                                                float level);
```

**信号流**:
```
Microphone → Port 0 (RX) → Conference Bridge → Port 0 (TX) → Encoder → RTP
                             ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
                             调整这里的增益（adjust_tx_level）
```

**实现步骤**:
1. 检测通话状态（`isInCall()`）
2. 如果在通话中，立即应用音量
3. 如果不在通话中，保存到 QSettings
4. 通话建立时（`CONFIRMED` 状态），从 QSettings 读取并应用

**代码示例**:
```cpp
void SipPhoneManager::setMicrophoneVolume(int volume)
{
    // 1. 保存到 QSettings
    QSettings settings;
    settings.setValue("SIP/MicrophoneVolume", volume);

    // 2. 如果在通话中，立即应用
    if (d->inCall) {
        // 转换百分比 (0-100) 到 PJSIP 增益 (0.0-2.0)
        // 0% → 0.0 (静音)
        // 50% → 1.0 (无调整)
        // 100% → 2.0 (放大2倍)
        float level = (volume / 50.0f);  // 0-2.0 范围

        // Port 0 = sound device port
        pj_status_t status = pjsua_conf_adjust_tx_level(0, level);

        if (status == PJ_SUCCESS) {
            qDebug() << "✅ Microphone volume adjusted:" << volume << "% → level:" << level;
        } else {
            qWarning() << "❌ Failed to adjust microphone volume";
        }
    } else {
        qDebug() << "📌 Not in call, volume will be applied when call starts";
    }
}
```

**通话建立时恢复音量**:
```cpp
// 在 onCallStateChanged 回调的 CONFIRMED 状态中
case PJSIP_INV_STATE_CONFIRMED:
    // 恢复保存的麦克风音量
    QSettings settings;
    int savedVolume = settings.value("SIP/MicrophoneVolume", 50).toInt();

    // 应用到会议桥
    float level = (savedVolume / 50.0f);
    pjsua_conf_adjust_tx_level(0, level);
    qDebug() << "✅ Restored microphone volume:" << savedVolume << "%";
    break;
```

### 设备层增益（不可用）

                                硬件不支持此层

```
Physical Mic → ALSA → PJSIP → Bridge → [TX Gain] → Encoder → RTP
                                        ^^^^^^^^^^
                                        软件增益（可控）
```

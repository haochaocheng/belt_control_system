## 📋 用户需求

### 原始需求（2026-01-19 20:25）

> **"音频解码和视频解码排列方式修改以下，按照宽度计算，一行可以排4个，不需要占用高度"**

### 需求分析

**问题**：
- 当前布局：垂直排列，一行一个 CheckBox
- 音频编解码器：9 个 → 占用 9 行高度
- 视频编解码器：3 个 → 占用 3 行高度
- **总计占用约 400-500px 垂直空间**，需要大量滚动

**需求**：
- ✅ 水平排列：一行4个 CheckBox（网格布局）
- ✅ 节省高度：音频编解码器 9 个 → 3 行（原来 9 行）
- ✅ 节省高度：视频编解码器 3 个 → 1 行（原来 3 行）
- **总计节省约 60% 垂直空间**

---

## ✅ 解决方案

### 布局改进

**修改前**（垂直布局）：
```qml
ColumnLayout {
    id: audioCodecLayout
    spacing: 10

    Repeater {
        model: SipPhoneManager.audioCodecs

        CheckBox {
            Layout.fillWidth: true  // 占满整行
            // ...
        }
    }
}
```

**修改后**（网格布局）：
```qml
Grid {
    id: audioCodecGrid
    columns: 4  // ✅ 一行4个
    rowSpacing: 10
    columnSpacing: 15

    Repeater {
        model: SipPhoneManager.audioCodecs

        CheckBox {
            width: (audioCodecGrid.width - audioCodecGrid.columnSpacing * 3) / 4  // ✅ 平均分配宽度
            // ...
        }
    }
}
```

## 🎯 技术细节

### 宽度计算公式

```qml
width: (audioCodecGrid.width - audioCodecGrid.columnSpacing * 3) / 4
       └────┬────┘                └──────────┬──────────┘           └┬┘
         容器宽度                     3个列间距                    4列
```

**说明**：
- 容器宽度：`audioCodecGrid.width`（父容器宽度减去 margins）
- 列间距总宽度：`columnSpacing * 3`（4列之间有3个间距）
- 可用宽度：`容器宽度 - 列间距总宽度`
- 每列宽度：`可用宽度 / 4`

### Grid 自动换行

```qml
Grid {
    columns: 4  // 设置4列
    // ...
}
```

**工作原理**：
- Grid 自动按 `columns` 值换行
- 第1-4个元素 → 第1行
- 第5-8个元素 → 第2行
- 第9个元素 → 第3行
- 无需手动控制换行逻辑

## 📋 问题描述

### 编译错误

在实现 FIX 100.252（音频和视频编解码器选择功能）后，出现 4 个 PJSIP API 相关的编译错误：

```
/workspace/src/sip_phone/SipPhoneManager.cpp:3315:26: error: 'pjsua_codec_enum_info' was not declared in this scope; did you mean 'pjsua_acc_enum_info'?

/workspace/src/sip_phone/SipPhoneManager.cpp:3384:26: error: 'pjsua_codec_get_priority' was not declared in this scope; did you mean 'pjsua_codec_set_priority'?

/workspace/src/sip_phone/SipPhoneManager.cpp:3459:26: error: 'pjsua_vid_codec_enum_info' was not declared in this scope; did you mean 'pjsua_vid_dev_get_info'?

/workspace/src/sip_phone/SipPhoneManager.cpp:3508:26: error: 'pjsua_vid_codec_get_priority' was not declared in this scope; did you mean 'pjsua_vid_codec_set_priority'?
```

### 根本原因

1. **错误的 API 名称**：
   - 音频编解码器枚举：误用 `pjsua_codec_enum_info()`，正确为 `pjsua_enum_codecs()`
   - 视频编解码器枚举：误用 `pjsua_vid_codec_enum_info()`，正确为 `pjsua_vid_enum_codecs()`

2. **不存在的 API 函数**：
   - PJSIP 2.16 **没有** `pjsua_codec_get_priority()` 函数
   - PJSIP 2.16 **没有** `pjsua_vid_codec_get_priority()` 函数
   - 编解码器优先级信息已经包含在枚举返回的 `pjsua_codec_info` 结构体中

```cpp
bool SipPhoneManager::isAudioCodecEnabled(const QString& codecName)
{
    if (!d->initialized) {
        return false;
    }

    // ✅ 2026-01-19 19:30 [FIX 100.252.1] 修复 API 使用
    // PJSIP 2.16 没有 pjsua_codec_get_priority() 函数
    // 解决方案：枚举所有编解码器，找到匹配的编解码器并返回其 priority 字段
    pjsua_codec_info codec_info[32];
    unsigned count = 32;
    pj_status_t status = pjsua_enum_codecs(codec_info, &count);

    if (status != PJ_SUCCESS) {
        qWarning() << "❌ [FIX 100.252] Failed to enumerate codecs for priority check";
        return false;
    }

    // 查找匹配的编解码器
    for (unsigned i = 0; i < count; ++i) {
        QString codecId = QString::fromUtf8(codec_info[i].codec_id.ptr,
                                           codec_info[i].codec_id.slen);
        if (codecId == codecName) {
            // 找到匹配的编解码器，检查 priority 字段
            bool enabled = (codec_info[i].priority > 0);
            qDebug() << "📊 [FIX 100.252] Codec" << codecName
                     << "priority:" << codec_info[i].priority
                     << (enabled ? "(enabled)" : "(disabled)");
            return enabled;
        }
    }

    // 未找到匹配的编解码器
    qWarning() << "❌ [FIX 100.252] Codec not found:" << codecName;
    return false;
}
```

## 🔍 技术分析

### PJSIP 2.16 编解码器 API 设计

**位置**: `cross-compile/src/pjproject-2.16/pjsip/include/pjsua-lib/pjsua.h`

#### 1. 音频编解码器枚举（Line 9067）

```c
/**
 * Enumerate all supported codecs in the system.
 *
 * @param id        Array of codec info to be initialized.
 * @param count     On input, specifies the length of the array.
 *                  On output, it contains actual number of elements
 *                  that have been initialized.
 *
 * @return          PJ_SUCCESS on success, or the appropriate error code.
 */
PJ_DECL(pj_status_t) pjsua_enum_codecs( pjsua_codec_info id[],
                                        unsigned *count );
```

**关键点**：
- ✅ 正确名称：`pjsua_enum_codecs()`
- ❌ 不存在：`pjsua_codec_enum_info()`

#### 2. 视频编解码器枚举（Lines 9586-9587）

```c
/**
 * Enum all video codecs.
 */
PJ_DECL(pj_status_t) pjsua_vid_enum_codecs( pjsua_codec_info id[],
                                            unsigned *count );
```

**关键点**：
- ✅ 正确名称：`pjsua_vid_enum_codecs()`
- ❌ 不存在：`pjsua_vid_codec_enum_info()`

#### 3. pjsua_codec_info 结构体

```c
typedef struct pjsua_codec_info
{
    pj_str_t        codec_id;   /**< Codec unique identification.    */
    pj_uint8_t      priority;   /**< Codec priority (integer 0-255). */
    pj_uint16_t     clock_rate; /**< Codec clock rate.               */
    pj_uint16_t     channel_cnt;/**< Number of channels.             */
    pj_uint16_t     frm_ptime;  /**< Frame time in ms.               */
    pj_str_t        desc;       /**< Codec description.              */
} pjsua_codec_info;
```

**关键发现**：
- ✅ `priority` 字段直接包含在结构体中
- ❌ 不存在独立的 `pjsua_codec_get_priority()` 函数
- ❌ 不存在独立的 `pjsua_vid_codec_get_priority()` 函数

**为什么没有 get_priority() 函数**：
- PJSIP 设计原则：避免不必要的函数调用开销
- 枚举已经返回所有信息，无需额外查询
- 用户应该缓存枚举结果，而不是反复查询

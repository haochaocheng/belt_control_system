## 🔍 问题分析

### 硬件限制调查

**日志证据**（`docs/log/voip.md` Lines 2260-2270）：

```
12:25:44.407    ffmpeg_vid_codecs.c  ...Configuring RKMPP VP8 hardware codec
12:25:44.407    ffmpeg_vid_codecs.c  ...WARNING: Hardware encoder 'vp8_rkmpp' not found
12:25:44.407    ffmpeg_vid_codecs.c  ...Found hardware decoder: vp8_rkmpp

12:25:44.410    ffmpeg_vid_codecs.c  ...Configuring RKMPP VP9 hardware codec
12:25:44.410    ffmpeg_vid_codecs.c  ...WARNING: Hardware encoder 'vp9_rkmpp' not found
12:25:44.410    ffmpeg_vid_codecs.c  ...Found hardware decoder: vp9_rkmpp
```

**关键发现**：
- ❌ VP8 硬件编码器：`vp8_rkmpp` **不存在**
- ✅ VP8 硬件解码器：`vp8_rkmpp` **存在**
- ❌ VP9 硬件编码器：`vp9_rkmpp` **不存在**
- ✅ VP9 硬件解码器：`vp9_rkmpp` **存在**

### 编解码器对比表

| 编解码器 | 硬件编码 | 硬件解码 | 软件编码库 | CPU 占用 | 可用性 |
|---------|---------|---------|-----------|---------|--------|
| **H.264** | ✅ h264_rkmpp | ✅ h264_rkmpp | libx264 | ~5% | ✅ **推荐** |
| **VP8** | ❌ 不支持 | ✅ vp8_rkmpp | libvpx | >80% | ❌ 不可用 |
| **VP9** | ❌ 不支持 | ✅ vp9_rkmpp | libvpx | >80% | ❌ 不可用 |

### 根本原因

**为什么 VP8/VP9 不可用**：

1. **编码是关键瓶颈**：
   - 视频通话需要实时编码本地摄像头画面
   - VP8/VP9 只能用软件编码（libvpx）
   - 软件编码 CPU 占用 >80%，设备无法承受

2. **解码不够用**：
   - 虽然 RK3588 支持 VP8/VP9 硬件解码
   - 但对方也无法发送 VP8/VP9（他们也没有硬件编码器）
   - 实际通话中双方都需要编码能力

3. **H.264 完整支持**：
   - RK3588 完整支持 H.264 硬件编解码
   - CPU 占用低（~5%）
   - 兼容性好，所有设备都支持

```cpp
// 参考：docs/2026-01-19/20-FIX100.252.6完成-默认禁用VP8-VP9编解码器.md
qDebug() << "════════════════════════════════════════════════════════════";
qDebug() << "🎬 [FIX 100.252.6] Disabling VP8 and VP9 by default";
qDebug() << "════════════════════════════════════════════════════════════";

// 禁用 VP8（优先级设置为 0）
pj_str_t vp8_codec = pj_str(const_cast<char*>("VP8"));
pj_status_t vp8_status = pjsua_vid_codec_set_priority(&vp8_codec, 0);
if (vp8_status == PJ_SUCCESS) {
    qDebug() << "   ✅ VP8 disabled by default (priority = 0)";
    qDebug() << "      Reason: Hardware encoder not supported on RK3588";
} else {
    char errmsg[PJ_ERR_MSG_SIZE];
    pj_strerror(vp8_status, errmsg, sizeof(errmsg));
    qWarning() << "   ⚠️ Failed to disable VP8:" << errmsg;
}

// 禁用 VP9（优先级设置为 0）
pj_str_t vp9_codec = pj_str(const_cast<char*>("VP9"));
pj_status_t vp9_status = pjsua_vid_codec_set_priority(&vp9_codec, 0);
if (vp9_status == PJ_SUCCESS) {
    qDebug() << "   ✅ VP9 disabled by default (priority = 0)";
    qDebug() << "      Reason: Hardware encoder not supported on RK3588";
} else {
    char errmsg[PJ_ERR_MSG_SIZE];
    pj_strerror(vp9_status, errmsg, sizeof(errmsg));
    qWarning() << "   ⚠️ Failed to disable VP9:" << errmsg;
}

qDebug() << "   💡 Only H.264 enabled (full hardware encode/decode support)";
qDebug() << "   📝 User can manually enable VP8/VP9 in UI if needed";
qDebug() << "════════════════════════════════════════════════════════════";
qDebug() << "";
```

### 关键技术点

**1. PJSIP 编解码器优先级 API**:
```cpp
pj_status_t pjsua_vid_codec_set_priority(const pj_str_t *codec_id, pj_uint8_t priority);
```
- `priority = 0`: 禁用编解码器
- `priority = 1-255`: 启用编解码器（数字越大优先级越高）

**2. 调用时机**:
- 必须在 PJSIP 初始化完成后（`endpoint->start()` 之后）
- 在编解码器信号发射之后（Lines 913-931）
- 在设备恢复逻辑之前（Line 975+）

**3. 编解码器名称匹配**:
```cpp
pj_str_t vp8_codec = pj_str(const_cast<char*>("VP8"));  // 大写 VP8
pj_str_t vp9_codec = pj_str(const_cast<char*>("VP9"));  // 大写 VP9
```
- PJSIP 内部使用大写编解码器名称
- 必须精确匹配，否则 API 调用失败

## 📝 经验教训

### 教训 1：硬件限制比软件实现更重要

**错误思路**：
- ❌ "VP8/VP9 是开源编解码器，应该支持"
- ❌ "PJSIP 支持 VP8/VP9，所以可以用"

**正确思路**：
- ✅ 首先确认硬件是否支持编码（不仅仅是解码）
- ✅ 软件编码在嵌入式设备上不可行（CPU 限制）
- ✅ 硬件支持决定可用性，软件支持只是前提

### 教训 2：用户测试比理论分析更可靠

**发现过程**：
1. 理论：PJSIP 支持 VP8/VP9 → 应该能用
2. 实现：UI 显示 VP8/VP9 选项 → 功能完成
3. **用户测试**：VP8 视频通话不能用 → **发现问题**
4. 日志分析：硬件编码器不存在 → **找到根因**

**启示**：
- ✅ 真实硬件测试不可替代
- ✅ 日志是诊断硬件限制的关键
- ✅ 用户反馈是最终验收标准

### 教训 3：默认配置应该最稳定

**原则**：
- ✅ 默认启用：完整硬件支持的功能（H.264）
- ✅ 默认禁用：部分硬件支持的功能（VP8/VP9）
- ✅ 允许手动启用：高级用户可以测试实验性功能

**实现**：
```cpp
// 默认只启用 H.264（稳定）
// VP8/VP9 禁用但可手动启用（实验性）
pjsua_vid_codec_set_priority(&vp8_codec, 0);  // 禁用
pjsua_vid_codec_set_priority(&vp9_codec, 0);  // 禁用
```

### 教训 4：编解码器名称大小写敏感

**错误示例**：
```cpp
pj_str_t vp8_codec = pj_str("vp8");  // ❌ 小写，无法匹配
pjsua_vid_codec_set_priority(&vp8_codec, 0);  // 失败！
```

**正确示例**：
```cpp
pj_str_t vp8_codec = pj_str("VP8");  // ✅ 大写，精确匹配
pjsua_vid_codec_set_priority(&vp8_codec, 0);  // 成功！
```

**经验**：
- PJSIP 内部使用大写编解码器名称
- 字符串必须精确匹配，否则 API 返回 PJ_ENOTFOUND
- 添加错误处理打印诊断信息

## 🔍 问题描述

**编译日志位置**: `docs/log/pjsip.md` Line 1997

**错误信息**：
```
../src/pjmedia-audiodev/alsa_dev.c:793:94: error: macro "PJ_TIME_VAL_SUB" passed 3 arguments, but takes just 2
 793 |                     PJ_TIME_VAL_SUB(time_diff, current_time, stream->last_silent_warning_time);
     |                                                                                              ^
```

**宏定义**（Line 2006）：
```c
#define PJ_TIME_VAL_SUB(t1, t2)     do {                            \
```

**根本原因**：
- 我在日志限流代码中错误使用了 `PJ_TIME_VAL_SUB` 宏
- 传递了 3 个参数：`(time_diff, current_time, stream->last_silent_warning_time)`
- 但宏只接受 2 个参数：`(t1, t2)`
- 宏的作用是原地修改：`t1 = t1 - t2`

---

## 🔧 修复方案

### 错误代码（Lines 792-794）

```c
/* ❌ 错误：传递 3 个参数 */
pj_time_val time_diff;
PJ_TIME_VAL_SUB(time_diff, current_time, stream->last_silent_warning_time);
if (time_diff.sec >= 30 || stream->last_silent_warning_time.sec == 0) {
```

### 正确代码（Lines 794-796）

```c
/* ✅ 方案：简化为直接比较秒数 */
pj_int64_t time_diff_sec = current_time.sec - stream->last_silent_warning_time.sec;
if (time_diff_sec >= 30 || stream->last_silent_warning_time.sec == 0) {
```

**优势**：
- ✅ 简单直接，避免宏参数错误
- ✅ 性能相同（编译器优化后无差异）
- ✅ 可读性更好

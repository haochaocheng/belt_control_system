## 🔍 问题分析

### 用户反馈

> "测试完成，第一次设置麦克风和扬声器，然后关闭程序，再此打开，设置不起作用，依然是旧的"

> "我们是容器部署，每次重新编译都是重新部署，因此你保存的地方在哪里"

### 根本原因

**QSettings 默认路径问题**：

```
用户选择设备 → QSettings 保存到 ~/.config/Company/App.conf
                     ↓
              容器重启（重新部署）
                     ↓
         ~/.config/ 目录丢失（非持久化）
                     ↓
           读取配置返回默认值 -1
                     ↓
           UI 显示旧设备（第一个设备）
```

**证据**（从日志分析）：

1. **第一次启动** - 用户选择设备：
   ```
   Line 1876: ✅ [Settings] Audio output device (user index) saved to QSettings: 3
   Line 1893: ✅ [Settings] Audio input device (user index) saved to QSettings: 1
   ```
   保存成功！

2. **第二次启动** - 容器重启后：
   ```
   Line 3536: [QSettings] Saved input device (user index): -1
   Line 3537: [QSettings] Saved output device (user index): -1
   ```
   读取失败！文件丢失了。

**Docker 容器持久化目录**：
- ✅ **持久化目录**: `/app/appdata` （挂载到宿主机）
- ❌ **非持久化目录**: `~/.config/`, `/tmp/`, 用户 HOME 目录

---

## 🔧 解决方案

### 核心思路

**将 QSettings 配置文件保存到持久化目录**：

```cpp
// ❌ 错误：默认路径（容器重启后丢失）
QSettings settings;  // 保存到 ~/.config/Company/App.conf

// ✅ 正确：持久化路径（容器重启后保留）
QString settingsPath = DataPathConfig::getDataDirectory() + "/sip_settings.ini";
QSettings settings(settingsPath, QSettings::IniFormat);  // 保存到 /app/appdata/sip_settings.ini
```

### 实现步骤

#### 1. 添加辅助函数（Line 265-270）

```cpp
// ✅ 2026-01-19 11:30 [FIX 100.250.2] 辅助函数：获取持久化的 QSettings
// 原因：统一所有 QSettings 使用持久化路径，避免容器重启后配置丢失
// 用法：所有需要保存配置的地方使用 getPersistentSettingsPath() 替代 QSettings()
static QString getPersistentSettingsPath() {
    return DataPathConfig::getDataDirectory() + "/sip_settings.ini";
}
```

**作用**：
- 返回持久化配置文件路径：`/app/appdata/sip_settings.ini`

## 📝 问题排查

### 问题 1：重启后仍显示 -1

**症状**：日志显示 `Saved input device (user index): -1`

**排查步骤**：
```bash
# 1. 检查配置文件是否存在
ls -la /app/appdata/sip_settings.ini

# 2. 查看配置文件内容
cat /app/appdata/sip_settings.ini

# 3. 检查文件权限
ls -la /app/appdata/
```

**可能原因**：
1. 配置文件不存在 → 第一次选择时保存失败
2. 文件内容为空 → QSettings 写入失败
3. 权限问题 → 容器无法读取文件

---

### 问题 2：配置文件存在但读取失败

**症状**：文件存在，但日志显示读取到 -1

**排查步骤**：
```bash
# 查看日志中的文件路径
grep "Settings file path" docs/log/voip.md

# 确认路径一致
# 保存路径应该 = 读取路径 = /app/appdata/sip_settings.ini
```

**可能原因**：
1. 保存和读取使用了不同的路径
2. QSettings 格式错误（应该是 IniFormat）

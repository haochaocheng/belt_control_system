## 🔍 问题回顾

### 用户反馈（2026-01-19 06:50）
> 麦克风设备选择，测试时使用的时新保存的，但是sip界面显示还是旧的，本设备有两个，一个是自带的，一个是USB的，设置成USB的，重启软件，显示还是rockchip-888.

**具体问题**：
1. 选择 USB 麦克风 → 实际使用新设备（功能正常）
2. UI 显示设备名称 → 仍显示旧设备 rockchipes8388（UI 错误）
3. 重启应用 → 恢复到旧设备 rockchipes8388（持久化失败）

### 根本原因

**设备索引映射错误**：
- **用户层索引**（过滤后）：[0, 1]
  - 0: rockchipes8388 (内置麦克风)
  - 1: Device (USB 麦克风)
- **PJSIP 层索引**（原始）：[0-28]
  - 6: rockchipes8388
  - 21: USB 麦克风
  - 其他：Loopback、HDMI、虚拟设备（已过滤）

**错误流程**：
1. 用户选择索引 1（USB 麦克风）
2. 代码直接将 1 传给 `pjsua_set_snd_dev2()`
3. PJSIP 使用索引 1 → 选错设备！
4. 保存索引 1 到 QSettings
5. 重启后读取索引 1 → 再次选错设备

**日志证据**（`docs/log/voip.md` Line 1188-1192）：
```
📢 [Settings] Saved audio input device index: 1
   [PJSIP] PJSIP initialized, applying device setting now...
✅ Audio input device changed to: 1  ← 直接使用用户索引
```

但实际应该：
```
User index: 1 → PJSIP index: 21
```

## 🔧 解决方案

### 核心理念

**前后端索引分离**：
- **用户层**：使用过滤后的连续索引 [0, 1, 2...]
- **PJSIP 层**：使用原始设备索引 [0-28]
- **映射数组**：连接两层索引

### 实现方案

#### 1. 添加映射数组（SipPhoneManager.cpp Lines 310-319）

```cpp
// ✅ 2026-01-19 08:15 [FIX 100.250] 设备索引映射数组
// 原因：用户层设备索引（过滤后）≠ PJSIP 层设备索引（原始）
```

#### 3. 选择时转换索引（Lines 2806-2885, 2922-2994）

**setAudioInputDevice() 核心逻辑**：
```cpp
bool SipPhoneManager::setAudioInputDevice(int userIndex)
{
    qDebug() << "📢 [FIX 100.250] Setting audio input device to user index:" << userIndex;

    // ✅ 索引验证
    if (userIndex < 0 || userIndex >= d->audioInputDeviceMapping.size()) {
        qWarning() << "❌ [FIX 100.250] Invalid user device index:" << userIndex;
        return false;
    }

    // ✅ 索引转换：用户索引 → PJSIP 索引
    int pjsipIndex = d->audioInputDeviceMapping[userIndex];
    qDebug() << "   [FIX 100.250] Index mapping:";
    qDebug() << "      User index:" << userIndex << "→ PJSIP index:" << pjsipIndex;

    // ✅ 保存用户索引到 QSettings（不是 PJSIP 索引！）
    QSettings settings;
    settings.setValue("SIP/AudioInputDevice", userIndex);
    qDebug() << "✅ [Settings] Audio input device (user index) saved:" << userIndex;

    // ✅ 使用 PJSIP 索引调用 PJSIP API
    if (d->initialized) {
        param.capture_dev = pjsipIndex;  // ← 使用映射后的 PJSIP 索引
        status = pjsua_set_snd_dev2(&param);

        if (status == PJ_SUCCESS) {
            qDebug() << "✅ Audio input device changed in PJSIP:";
            qDebug() << "   User index:" << userIndex << "→ PJSIP index:" << pjsipIndex;
            return true;
        }
    }
}
```

```cpp
int SipPhoneManager::getCurrentAudioInputDevice()
{
    // ✅ 读取保存的用户索引
    QSettings settings;
    int savedIndex = settings.value("SIP/AudioInputDevice", 0).toInt();

    qDebug() << "📢 [FIX 100.250] Reading saved audio input device index:" << savedIndex;

    // ✅ 验证索引是否在映射数组范围内
    if (savedIndex < 0 || savedIndex >= d->audioInputDeviceMapping.size()) {
        qWarning() << "   ⚠️ [FIX 100.250] Saved index" << savedIndex << "is out of range";
        qWarning() << "      Valid range: 0 -" << (d->audioInputDeviceMapping.size() - 1);
        qWarning() << "      Returning default index 0";
        return 0;  // 回退到默认设备
    }

    qDebug() << "   ✅ [FIX 100.250] Saved index is valid";
    qDebug() << "      User index:" << savedIndex;
    qDebug() << "      Maps to PJSIP index:" << d->audioInputDeviceMapping[savedIndex];

    return savedIndex;
}
```

## 📝 问题排查

### 问题 1：设备选择后 UI 仍显示旧设备

**症状**：选择 USB 麦克风，UI 仍显示 `rockchipes8388`

**检查日志**：
```bash
grep "FIX 100.250" docs\log\voip.md
```

**可能原因**：
1. **映射数组为空**：
   - 日志显示：`Mapping size: 0`
   - 解决：检查设备枚举是否成功，映射是否正确构建

2. **索引超出范围**：
   - 日志显示：`Invalid user device index: 1`
   - 解决：设备枚举可能只找到 1 个设备，用户索引 1 无效

3. **PJSIP 索引错误**：
   - 日志显示：`User 1 → PJSIP 21`, 但实际设备不是 21
   - 解决：检查设备枚举顺序是否正确

---

### 问题 2：重启后设备恢复到旧设备

**症状**：重启应用，设备恢复到 `rockchipes8388`

**检查日志**：
```bash
grep "Reading saved audio input device index" docs\log\voip.md
```

**可能原因**：
1. **保存失败**：
   - 日志未显示：`Audio input device (user index) saved: 1`
   - 解决：检查 QSettings 权限，确认文件写入成功

2. **索引验证失败**：
   - 日志显示：`Saved index 1 is out of range`
   - 解决：设备配置可能变化（USB 拔出），映射数组大小不匹配

3. **映射数组未构建**：
   - 日志显示：`Mapping size: 0`
   - 解决：设备枚举未正确执行，检查初始化流程

---

### 问题 3：选择设备后通话无声音

**症状**：选择 USB 麦克风，拨打电话对方听不到声音

**检查日志**：
```bash
grep "PJSIP index:" docs\log\voip.md
```

**可能原因**：
1. **PJSIP 索引错误**：
   - 日志显示：`User 1 → PJSIP 21`，但设备 21 不存在
   - 解决：检查映射数组是否正确（枚举时保存的索引）

2. **设备权限问题**：
   - PJSIP 日志显示：`PJMEDIA_EAUD_INVDEV` 或权限错误
   - 解决：检查设备访问权限（`/dev/snd/`）

3. **设备占用**：
   - 其他进程占用麦克风
   - 解决：`lsof /dev/snd/*` 检查占用进程

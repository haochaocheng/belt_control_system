## 🛠️ 解决方案

### 问题 1：音量控制 - v3 方案（会议桥 + ALSA 备选）

**v1 失败原因**：只能在通话中使用
**v2 失败原因**：设备不支持硬件音量控制能力
**v3 方案**：混合方案 + ALSA 系统命令备选

#### 方案 v3.1：会议桥方案（通话中）+ ALSA 命令（系统级）

```cpp
void SipPhoneManager::setMicrophoneVolume(int volume)
{
    // 1. 保存到 QSettings
    QSettings settings;
    settings.setValue("SIP/MicrophoneVolume", volume);

    // 2. 尝试 PJSIP 硬件增益 API（可能不支持）
    unsigned int pj_volume = (volume * 255) / 100;
    pj_status_t status = pjsua_snd_set_setting(
        PJMEDIA_AUD_DEV_CAP_INPUT_VOLUME_SETTING,
        &pj_volume,
        PJ_TRUE
    );

    if (status == PJ_SUCCESS) {
        qDebug() << "✅ Hardware gain API supported";
        return;
    }

    // 3. 硬件 API 不支持，使用 ALSA 系统命令（立即生效）
    qDebug() << "⚠️ Hardware gain API not supported, using ALSA command";
    QString deviceName = getCurrentAudioInputDeviceName();  // "rockchipes8388"

    QProcess process;
    QString cmd = QString("amixer -D hw:%1 set Capture %2%").arg(deviceName).arg(volume);
    process.start("bash", QStringList() << "-c" << cmd);
    process.waitForFinished();

    if (process.exitCode() == 0) {
        qDebug() << "✅ ALSA volume set via amixer:" << volume << "%";
    } else {
        qWarning() << "❌ amixer failed:" << process.readAllStandardError();

        // 4. 最后备选：会议桥方案（仅通话中有效）
        if (d->inCall && d->currentCall) {
            float level = (volume / 100.0f) * 2.0f;
            pjsua_conf_adjust_tx_level(0, level);
            qDebug() << "✅ Conference bridge volume set (call only)";
        }
    }
}
```

**优势**：
- ✅ 通话前即可设置（ALSA 命令）
- ✅ 通话中实时调整（会议桥 API）
- ✅ 三层备选方案，确保至少一种有效

**劣势**：
- ⚠️ 依赖 `amixer` 命令（需要预装）
- ⚠️ 设备名称需要正确映射（`rockchipes8388`）

---

```cpp
QStringList SipPhoneManager::enumerateAudioInputDevices()
{
    QStringList devices;
    m_audioInputDeviceMapping.clear();  // ✅ 清空旧映射

    unsigned aud_dev_count = pjmedia_aud_dev_count();

    for (unsigned i = 0; i < aud_dev_count; ++i) {
        pjmedia_aud_dev_info dev_info;
        pj_status_t status = pjmedia_aud_dev_get_info(i, &dev_info);

        if (status == PJ_SUCCESS && dev_info.input_count > 0) {
            QString dev_name = QString::fromUtf8(dev_info.name);

            // 过滤逻辑（与现有代码一致）
            if (!dev_name.contains("Loopback") && !dev_name.contains("default")) {
                devices << dev_name;
                m_audioInputDeviceMapping.append(i);  // ✅ 保存 PJSIP 原始索引

                qDebug() << "[Mapping] User index:" << (devices.size() - 1)
                         << "→ PJSIP index:" << i
                         << "Device:" << dev_name;
            }
        }
    }

    return devices;
}
```

```cpp
bool SipPhoneManager::setAudioInputDevice(int userIndex)
{
    qDebug() << "📢 Setting audio input device to user index:" << userIndex;

    // ✅ 索引映射：用户索引 → PJSIP 索引
    if (userIndex < 0 || userIndex >= m_audioInputDeviceMapping.size()) {
        qWarning() << "❌ Invalid user device index:" << userIndex;
        return false;
    }

    int pjsipIndex = m_audioInputDeviceMapping[userIndex];
    qDebug() << "  [Mapping] User index:" << userIndex << "→ PJSIP index:" << pjsipIndex;

    // ✅ 保存用户索引到 QSettings（不是 PJSIP 索引！）
    QSettings settings;
    settings.setValue("SIP/AudioInputDeviceUserIndex", userIndex);

    // ✅ 使用 PJSIP 索引应用设置
    if (d->initialized) {
        pjsua_snd_dev_param param;
        pjsua_snd_dev_param_default(&param);

        pj_status_t status = pjsua_get_snd_dev2(&param);
        if (status != PJ_SUCCESS) {
            param.playback_dev = PJSUA_SND_DEFAULT_PLAYBACK_DEV;
        }

        param.capture_dev = pjsipIndex;  // ⚠️ 使用 PJSIP 索引

        status = pjsua_set_snd_dev2(&param);
        if (status == PJ_SUCCESS) {
            qDebug() << "✅ Audio input device changed (PJSIP index:" << pjsipIndex << ")";
            return true;
        } else {
            char errmsg[PJ_ERR_MSG_SIZE];
            pj_strerror(status, errmsg, sizeof(errmsg));
            qWarning() << "❌ Failed to set audio input device:" << errmsg;
            return false;
        }
    }

    return true;
}
```

## 💡 关键教训

### 1. 硬件能力检测很重要

**v2 失败教训**：
- ❌ 假设设备支持硬件音量控制
- ✅ 应该先检测能力，再选择方案

**正确做法**：
```cpp
pjmedia_aud_dev_info dev_info;
pjmedia_aud_dev_get_info(dev_id, &dev_info);

if (dev_info.caps & PJMEDIA_AUD_DEV_CAP_INPUT_VOLUME_SETTING) {
    // 使用硬件音量 API
} else {
    // 回退到会议桥或 ALSA 命令
}
```

---

### 2. 设备索引映射是必需的

**当前问题**：
- 用户层设备列表经过过滤（去除 Loopback, HDMI, 虚拟设备）
- PJSIP 层设备索引是原始索引（0-28）
- **直接使用用户索引调用 PJSIP API → 错误的设备**

**解决方案**：
- 枚举时建立 `QVector<int>` 映射
- 保存用户索引到 QSettings
- 使用时转换：`pjsipIndex = mapping[userIndex]`

## 📋 需求背景

### 业务场景

皮带控制系统需要播放音频（起车预警、停车警告、设备故障等），但音频输出不是播放到本地设备，而是发送到**独立的网络音频模块**。

### 音频模块特性

1. **UDP 组播模式**：
   - 接收 Opus 编码的音频流
   - 20ms 发送一次（50 帧/秒）
   - 直接组播，无需服务器中转
   - ✅ **推荐模式**：延迟低，实现简单

2. **TCP 模式**：
   - 只能和上位机通讯（不能直接连接本机）
   - 需要上位机作为中转服务器
   - 音频数据：本机 → 上位机 → 音频模块
   - ⚠️ **备用模式**：延迟高，依赖上位机

3. **模式互斥**：
   - UDP 和 TCP 只能二选一
   - 需要在参数设置中配置模式

## 🎯 技术方案决策

### 方案对比

#### ❌ 方案 1：虚拟声卡方案

**实现**：
```
应用程序 → QMediaPlayer 播放 → 虚拟声卡（PulseAudio/ALSA Loopback）
                                   ↓
                       网络发送守护进程 → UDP/TCP → 音频模块
```

**优点**：
- 应用层改动小（继续使用 QMediaPlayer）
- 可以捕获所有系统音频

**缺点**：
- ❌ **复杂度高**：需要配置 ALSA/PulseAudio 虚拟设备
- ❌ **调试困难**：虚拟声卡驱动问题难以排查
- ❌ **延迟不可控**：经过多层缓冲（应用 → 声卡 → 守护进程 → 网络）
- ❌ **资源浪费**：音频数据被解码后又编码
- ❌ **跨平台差异**：Windows/Linux 虚拟声卡配置完全不同

#### ✅ 方案 2：直接解码发送（推荐）

**实现**：
```
音频文件（MP3/WAV）
  ↓
FFmpeg 解码 → PCM（16kHz, 16bit, 单声道）
  ↓
Opus 编码（20ms 帧，16-32kbps）
  ↓
网络发送：UDP 组播 或 TCP 上位机中转
  ↓
音频模块
```

**优点**：
- ✅ **低延迟**：没有中间虚拟设备
- ✅ **可控性强**：每个步骤清晰可控，便于调试
- ✅ **易于配置**：UI 中选择 UDP/TCP 模式
- ✅ **易于调试**：可以监控每帧数据和网络状态
- ✅ **适配性好**：自动切换 UDP/TCP 模式
- ✅ **跨平台一致**：Windows 和 Linux 实现相同

**缺点**：
- 需要实现音频解码和编码逻辑（可使用现有 FFmpeg 库）

### 关键实现流程

#### 1. 音频文件解码（FFmpeg）

```cpp
AudioNetworkSender::AudioData AudioNetworkSender::decodeAudioFile(const QString& filePath) {
    // ✅ 2026-01-21 [音频解码] 使用 FFmpeg 解码音频文件
    AudioData result;

    // 1. 打开文件
    AVFormatContext* formatCtx = nullptr;
    if (avformat_open_input(&formatCtx, filePath.toUtf8().constData(), nullptr, nullptr) != 0) {
        qWarning() << "无法打开音频文件:" << filePath;
        return result;
    }

    // 2. 查找音频流
    if (avformat_find_stream_info(formatCtx, nullptr) < 0) {
        qWarning() << "无法找到音频流信息";
        avformat_close_input(&formatCtx);
        return result;
    }

    int audioStreamIndex = -1;
    for (unsigned int i = 0; i < formatCtx->nb_streams; i++) {
        if (formatCtx->streams[i]->codecpar->codec_type == AVMEDIA_TYPE_AUDIO) {
            audioStreamIndex = i;
            break;
        }
    }

    if (audioStreamIndex == -1) {
        qWarning() << "未找到音频流";
        avformat_close_input(&formatCtx);
        return result;
    }

    // 3. 打开解码器
    AVCodecParameters* codecpar = formatCtx->streams[audioStreamIndex]->codecpar;
    const AVCodec* codec = avcodec_find_decoder(codecpar->codec_id);
    AVCodecContext* codecCtx = avcodec_alloc_context3(codec);
    avcodec_parameters_to_context(codecCtx, codecpar);
    avcodec_open2(codecCtx, codec, nullptr);

    // 4. 设置重采样（转为 16kHz, 单声道, 16bit）
    SwrContext* swrCtx = swr_alloc_set_opts(
        nullptr,
        AV_CH_LAYOUT_MONO,           // 输出：单声道
        AV_SAMPLE_FMT_S16,           // 输出：16bit
        m_sampleRate,                // 输出：16kHz
        codecCtx->channel_layout,    // 输入：原始声道
        codecCtx->sample_fmt,        // 输入：原始格式
        codecCtx->sample_rate,       // 输入：原始采样率
        0, nullptr
    );
    swr_init(swrCtx);

    // 5. 解码和重采样
    AVPacket* packet = av_packet_alloc();
    AVFrame* frame = av_frame_alloc();
    QByteArray pcmData;

    while (av_read_frame(formatCtx, packet) >= 0) {
        if (packet->stream_index == audioStreamIndex) {
            avcodec_send_packet(codecCtx, packet);
            while (avcodec_receive_frame(codecCtx, frame) == 0) {
                // 重采样
                int outSamples = swr_convert(
                    swrCtx,
                    &frame->data[0], frame->nb_samples,
                    (const uint8_t**)frame->data, frame->nb_samples
                );

                int dataSize = outSamples * m_channels * (m_bitDepth / 8);
                pcmData.append(reinterpret_cast<char*>(frame->data[0]), dataSize);
            }
        }
        av_packet_unref(packet);
    }

    // 6. 清理
    av_frame_free(&frame);
    av_packet_free(&packet);
    swr_free(&swrCtx);
    avcodec_free_context(&codecCtx);
    avformat_close_input(&formatCtx);

    result.pcmData = pcmData;
    result.sampleRate = m_sampleRate;
    result.channels = m_channels;
    result.bitDepth = m_bitDepth;

    qDebug() << "解码完成，PCM 大小:" << pcmData.size() << "字节";
    return result;
}
```

#### 2. Opus 编码（20ms 帧）

```cpp
QList<QByteArray> AudioNetworkSender::encodeToOpus(const AudioData& audio) {
    // ✅ 2026-01-21 [Opus 编码] 编码为 20ms 帧
    QList<QByteArray> opusFrames;

    // 1. 创建 Opus 编码器（如果未创建）
    if (!m_opusEncoder) {
        int error;
        m_opusEncoder = opus_encoder_create(
            audio.sampleRate,       // 16kHz
            audio.channels,         // 1 (单声道)
            OPUS_APPLICATION_AUDIO, // 音频应用
            &error
        );

        if (error != OPUS_OK) {
            qWarning() << "Opus 编码器创建失败:" << opus_strerror(error);
            return opusFrames;
        }

        // 设置比特率
        opus_encoder_ctl(m_opusEncoder, OPUS_SET_BITRATE(m_opusBitrate));
    }

    // 2. 计算每帧样本数（20ms @ 16kHz = 320 samples）
    const int frameDurationMs = 20;
    const int samplesPerFrame = (audio.sampleRate * frameDurationMs) / 1000;
    const int bytesPerSample = (audio.bitDepth / 8) * audio.channels;
    const int bytesPerFrame = samplesPerFrame * bytesPerSample;

    // 3. 分帧编码
    const char* pcmPtr = audio.pcmData.constData();
    int totalBytes = audio.pcmData.size();
    int offset = 0;

    while (offset + bytesPerFrame <= totalBytes) {
        // 提取一帧 PCM 数据
        const opus_int16* pcmFrame = reinterpret_cast<const opus_int16*>(pcmPtr + offset);

        // 编码为 Opus（输出缓冲区：最大 4000 字节）
        unsigned char opusBuffer[4000];
        int opusSize = opus_encode(
            m_opusEncoder,
            pcmFrame,
            samplesPerFrame,
            opusBuffer,
            sizeof(opusBuffer)
        );

        if (opusSize < 0) {
            qWarning() << "Opus 编码失败:" << opus_strerror(opusSize);
            break;
        }

        // 保存 Opus 帧
        QByteArray opusFrame(reinterpret_cast<char*>(opusBuffer), opusSize);
        opusFrames.append(opusFrame);

        offset += bytesPerFrame;
    }

    qDebug() << "Opus 编码完成，帧数:" << opusFrames.size()
             << "总时长:" << (opusFrames.size() * 20) << "ms";

    return opusFrames;
}
```

#### 3. 网络发送（UDP/TCP）

```cpp
void AudioNetworkSender::sendOpusFrames(const QList<QByteArray>& frames) {
    // ✅ 2026-01-21 [网络发送] 定时发送 Opus 帧（20ms 间隔）
    m_currentFrames = frames;
    m_currentFrameIndex = 0;
    m_isPlaying = true;

    // 启动 20ms 定时器
    startFrameTimer();

    emit playbackStarted();
}

void AudioNetworkSender::onFrameTimerTimeout() {
    if (m_currentFrameIndex >= m_currentFrames.size()) {
        // 播放完成
        m_frameTimer->stop();
        m_isPlaying = false;
        emit playbackFinished();
        return;
    }

    // 发送当前帧
    const QByteArray& frame = m_currentFrames[m_currentFrameIndex];

    if (m_mode == UDP_Multicast) {
        sendUdpMulticast(frame);
    } else {
        sendTcpToHost(frame);
    }

    m_currentFrameIndex++;
}

void AudioNetworkSender::sendUdpMulticast(const QByteArray& frame) {
    // ✅ 2026-01-21 [UDP 发送] 发送 UDP 组播
    if (!m_udpSocket) {
        m_udpSocket = new QUdpSocket(this);
    }

    qint64 sent = m_udpSocket->writeDatagram(
        frame.constData(),
        frame.size(),
        QHostAddress(m_udpAddress),
        m_udpPort
    );

    if (sent == -1) {
        qWarning() << "UDP 发送失败:" << m_udpSocket->errorString();
        emit networkError(m_udpSocket->errorString());
    }
}

void AudioNetworkSender::sendTcpToHost(const QByteArray& frame) {
    // ✅ 2026-01-21 [TCP 发送] 发送到上位机
    if (!m_tcpSocket || m_tcpSocket->state() != QAbstractSocket::ConnectedState) {
        // 重新连接上位机
        if (m_tcpSocket) {
            m_tcpSocket->deleteLater();
        }
        m_tcpSocket = new QTcpSocket(this);
        m_tcpSocket->connectToHost(m_tcpHost, m_tcpPort);

        if (!m_tcpSocket->waitForConnected(3000)) {
            qWarning() << "TCP 连接上位机失败:" << m_tcpSocket->errorString();
            emit networkError(m_tcpSocket->errorString());
            return;
        }
    }

    // 发送帧（可能需要添加协议头）
    // 格式：[Length: 4 bytes][Opus Data: N bytes]
    QByteArray packet;
    QDataStream stream(&packet, QIODevice::WriteOnly);
    stream.setByteOrder(QDataStream::BigEndian);
    stream << static_cast<quint32>(frame.size());
    packet.append(frame);

    qint64 sent = m_tcpSocket->write(packet);
    if (sent == -1) {
        qWarning() << "TCP 发送失败:" << m_tcpSocket->errorString();
        emit networkError(m_tcpSocket->errorString());
    }
}
```

```cpp
    }
```

## 📊 性能和带宽评估

### 带宽计算

```
采样率：16000 Hz
位深度：16 bit
声道数：1
原始 PCM 比特率：16000 × 16 × 1 = 256 kbps

Opus 编码后：
- 16 kbps：压缩比 16:1，语音清晰
- 24 kbps：压缩比 10.7:1，音质良好
- 32 kbps：压缩比 8:1，高质量

网络带宽（20ms 帧）：
- 16 kbps：40 字节/帧，50 帧/秒 = 2 KB/s
- 32 kbps：80 字节/帧，50 帧/秒 = 4 KB/s

结论：网络带宽占用极小，100Mbps 网络足够支持数百路音频。
```

### 延迟分析

```
总延迟 = 解码延迟 + 编码延迟 + 网络延迟 + 音频模块延迟

UDP 组播模式：
- 解码延迟：<10ms（FFmpeg 软件解码）
- 编码延迟：<5ms（Opus 单帧编码）
- 网络延迟：<2ms（局域网）
- 音频模块延迟：<20ms（缓冲播放）
- 总延迟：<40ms ✅ 可接受

TCP 中转模式：
- 额外中转延迟：+10-50ms
- 总延迟：50-90ms ⚠️ 稍高但可接受
```

1. **音频解码测试**：
   - 测试 MP3、WAV 格式解码
   - 验证 PCM 输出正确性（采样率、声道）
   - 测试不同采样率音频文件的重采样

2. **Opus 编码测试**：
   - 验证 20ms 帧分割正确
   - 测试不同比特率输出质量
   - 检查编码器内存泄漏

3. **网络发送测试**：
   - UDP 组播发送和接收验证
   - TCP 连接稳定性测试
   - 网络异常处理（断线重连）

### 阶段 2：集成测试

1. **端到端测试**：
   - 播放测试音频文件
   - 音频模块接收验证
   - 音质主观评价

2. **并发测试**：
   - 同时播放多个音频（队列处理）
   - 快速切换音频文件
   - 播放中途停止

3. **异常测试**：
   - 网络断开后恢复
   - 音频文件损坏
   - 音频模块不在线

### 阶段 3：现场验证

1. **实际场景测试**：
   - 起车预警音频测试
   - 停车警告音频测试
   - 设备故障音频测试

2. **长时间稳定性**：
   - 24 小时连续运行
   - 内存和 CPU 占用监控
   - 网络流量监控

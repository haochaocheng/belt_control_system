### 音频源

#### 1. MP3 文件（预录音频）

- **示例**："1号皮带启动.mp3"
- **位置**：`/app/AUDIO/语音文件/*.mp3`
- **处理流程**：MP3 → FFmpeg 解码 → PCM (16kHz, 16bit, mono) → Opus 编码 → UDP 发送

#### 2. TTS 语音（Sherpa-ONNX）

- **TTS 引擎**：Sherpa-ONNX（通过进程通信）
- **输出格式**：WAV 文件（PCM, 16bit, 单声道）
- **采样率**：由模型决定（通常 16kHz 或 22.05kHz）
- **存储位置**：临时文件（QTemporaryFile）
- **处理流程**：WAV → FFmpeg 解码 → 重采样到 16kHz（如需要）→ Opus 编码 → UDP 发送

### 实现方式

1. **网络库**：Qt QUdpSocket（跨平台支持：Windows 开发 + Linux RK3588 部署）
2. **发送策略**：
   - **优先**：批量发送（解码全部 → 编码全部 → 定时发送）
   - **备选**：实时发送（边解码边编码边发送）
   - **切换条件**：通过 `#define USE_REALTIME_SEND 0/1` 或配置项
3. **输出模式**：**双输出**（本地 ES8388 + 网络音频模块同时播放）

#### 1.2 实现音频解码（FFmpeg）（1 天）

**功能**：解码 MP3/WAV 文件到 PCM（16kHz, 16bit, 单声道）

**实现代码**：
```cpp
AudioNetworkSender::AudioData AudioNetworkSender::decodeAudioFile(const QString& filePath)
{
    AudioData result;

    // 1. 打开音频文件
    AVFormatContext* formatCtx = nullptr;
    if (avformat_open_input(&formatCtx, filePath.toUtf8().constData(), nullptr, nullptr) < 0) {
        throw std::runtime_error("Failed to open audio file");
    }

    // 2. 查找音频流
    if (avformat_find_stream_info(formatCtx, nullptr) < 0) {
        avformat_close_input(&formatCtx);
        throw std::runtime_error("Failed to find stream info");
    }

    int audioStreamIndex = -1;
    for (unsigned i = 0; i < formatCtx->nb_streams; i++) {
        if (formatCtx->streams[i]->codecpar->codec_type == AVMEDIA_TYPE_AUDIO) {
            audioStreamIndex = i;
            break;
        }
    }

    if (audioStreamIndex == -1) {
        avformat_close_input(&formatCtx);
        throw std::runtime_error("No audio stream found");
    }

    // 3. 初始化解码器
    AVCodecParameters* codecParams = formatCtx->streams[audioStreamIndex]->codecpar;
    const AVCodec* codec = avcodec_find_decoder(codecParams->codec_id);
    if (!codec) {
        avformat_close_input(&formatCtx);
        throw std::runtime_error("Codec not found");
    }

    AVCodecContext* codecCtx = avcodec_alloc_context3(codec);
    avcodec_parameters_to_context(codecCtx, codecParams);
    avcodec_open2(codecCtx, codec, nullptr);

    // 4. 初始化重采样器（统一转换为 16kHz, 16bit, mono）
    SwrContext* swrCtx = swr_alloc_set_opts(
        nullptr,
        AV_CH_LAYOUT_MONO,           // 输出：单声道
        AV_SAMPLE_FMT_S16,           // 输出：16bit PCM
        16000,                       // 输出：16kHz
        codecCtx->channel_layout,    // 输入：原始声道
        codecCtx->sample_fmt,        // 输入：原始格式
        codecCtx->sample_rate,       // 输入：原始采样率
        0, nullptr
    );
    swr_init(swrCtx);

    // 5. 解码音频帧
    AVPacket* packet = av_packet_alloc();
    AVFrame* frame = av_frame_alloc();
    QByteArray pcmBuffer;

    while (av_read_frame(formatCtx, packet) >= 0) {
        if (packet->stream_index == audioStreamIndex) {
            if (avcodec_send_packet(codecCtx, packet) >= 0) {
                while (avcodec_receive_frame(codecCtx, frame) >= 0) {
                    // 重采样到 16kHz, 16bit, mono
                    int outSamples = av_rescale_rnd(
                        swr_get_delay(swrCtx, codecCtx->sample_rate) + frame->nb_samples,
                        16000, codecCtx->sample_rate, AV_ROUND_UP
                    );

                    uint8_t* outBuffer = nullptr;
                    av_samples_alloc(&outBuffer, nullptr, 1, outSamples, AV_SAMPLE_FMT_S16, 0);

                    int convertedSamples = swr_convert(
                        swrCtx, &outBuffer, outSamples,
                        (const uint8_t**)frame->data, frame->nb_samples
                    );

                    // 追加到 PCM 缓冲区
                    pcmBuffer.append((const char*)outBuffer, convertedSamples * 2);  // 2 字节/样本
                    av_freep(&outBuffer);
                }
            }
        }
        av_packet_unref(packet);
    }

    // 6. 清理资源
    av_frame_free(&frame);
    av_packet_free(&packet);
    swr_free(&swrCtx);
    avcodec_free_context(&codecCtx);
    avformat_close_input(&formatCtx);

    // 7. 返回结果
    result.pcmData = pcmBuffer;
    result.sampleRate = 16000;
    result.channels = 1;
    result.durationMs = (pcmBuffer.size() / 2) * 1000 / 16000;  // 样本数 × 1000 / 采样率

    qDebug() << "✅ 音频解码完成:" << filePath;
    qDebug() << "   PCM 大小:" << pcmBuffer.size() << "字节";
    qDebug() << "   时长:" << result.durationMs << "ms";

    return result;
}
```

#### 1.3 实现 Opus 编码（1 天）

**功能**：将 PCM 数据编码为 Opus 帧（20ms 帧，50 帧/秒）

**实现代码**：
```cpp
QList<QByteArray> AudioNetworkSender::encodeToOpus(const AudioData& audio)
{
    QList<QByteArray> opusFrames;

    // 1. 检查采样率（必须是 16kHz）
    if (audio.sampleRate != 16000 || audio.channels != 1) {
        qWarning() << "❌ 音频参数错误，必须是 16kHz 单声道";
        return opusFrames;
    }

    // 2. 初始化 Opus 编码器（如果还没初始化）
    if (!m_opusEncoder) {
        int error;
        m_opusEncoder = opus_encoder_create(
            16000,                      // 采样率 16kHz
            1,                          // 单声道
            OPUS_APPLICATION_VOIP,      // 语音模式（低延迟）
            &error
        );

        if (error != OPUS_OK || !m_opusEncoder) {
            qWarning() << "❌ Opus 编码器初始化失败:" << opus_strerror(error);
            return opusFrames;
        }

        // 设置比特率
        opus_encoder_ctl(m_opusEncoder, OPUS_SET_BITRATE(m_opusBitrate));
        qDebug() << "✅ Opus 编码器初始化成功，比特率:" << m_opusBitrate;
    }

    // 3. 将 PCM 数据切分为 20ms 帧
    const int samplesPerFrame = 320;  // 20ms @ 16kHz = 320 样本
    const int bytesPerFrame = samplesPerFrame * 2;  // 2 字节/样本

    const char* pcmPtr = audio.pcmData.constData();
    int pcmSize = audio.pcmData.size();
    int frameCount = pcmSize / bytesPerFrame;

    qDebug() << "📦 开始 Opus 编码:" << frameCount << "帧";

    for (int i = 0; i < frameCount; i++) {
        // 4. 编码单个帧
        const opus_int16* pcmFrame = reinterpret_cast<const opus_int16*>(pcmPtr + i * bytesPerFrame);

        unsigned char opusBuffer[256];  // Opus 帧最大约 250 字节（保守）
        int encodedBytes = opus_encode(
            m_opusEncoder,
            pcmFrame,
            samplesPerFrame,
            opusBuffer,
            sizeof(opusBuffer)
        );

        if (encodedBytes < 0) {
            qWarning() << "❌ Opus 编码失败，帧" << i << ":" << opus_strerror(encodedBytes);
            continue;
        }

        // 5. 保存 Opus 帧
        QByteArray opusFrame(reinterpret_cast<const char*>(opusBuffer), encodedBytes);
        opusFrames.append(opusFrame);

        // 日志（每 10 帧打印一次）
        if (i % 10 == 0) {
            qDebug() << "   帧" << i << "编码完成，大小:" << encodedBytes << "字节";
        }
    }

    qDebug() << "✅ Opus 编码完成:" << opusFrames.size() << "帧";
    qDebug() << "   平均帧大小:" << (opusFrames.isEmpty() ? 0 :
        std::accumulate(opusFrames.begin(), opusFrames.end(), 0,
            [](int sum, const QByteArray& frame) { return sum + frame.size(); }) / opusFrames.size())
        << "字节";

    return opusFrames;
}
```

#### 1.4 实现 UDP 组播发送（1 天）

**功能**：将 Opus 帧通过 UDP 组播发送到音频模块（20ms 间隔）

**实现代码**：
```cpp
void AudioNetworkSender::playAudioToNetwork(const QString& filePath)
{
    if (m_isPlaying) {
        qWarning() << "⚠️  正在播放，停止当前播放";
        stopPlayback();
    }

    m_playbackTimer.start();
    m_currentFileName = QFileInfo(filePath).fileName();

    try {
        // 1. 解码音频文件
        qDebug() << "🔊 播放音频到网络:" << m_currentFileName;
        AudioData audio = decodeAudioFile(filePath);

        // 2. 编码为 Opus
        m_currentFrames = encodeToOpus(audio);
        if (m_currentFrames.isEmpty()) {
            emit playbackError("Opus 编码失败");
            return;
        }

        m_totalFrames = m_currentFrames.size();
        m_currentFrameIndex = 0;

        // 3. 开始发送
        qDebug() << "📡 开始发送:" << m_totalFrames << "帧（预计" << (m_totalFrames * 20) << "ms）";
        emit playbackStarted(m_currentFileName);

        m_isPlaying = true;
        m_frameTimer->start(20);  // 20ms 定时器

    } catch (const std::exception& e) {
        qWarning() << "❌ 播放失败:" << e.what();
        emit playbackError(QString::fromUtf8(e.what()));
    }
}

void AudioNetworkSender::onFrameTimerTimeout()
{
    if (!m_isPlaying || m_currentFrameIndex >= m_currentFrames.size()) {
        stopPlayback();
        return;
    }

    // 发送下一帧
    sendNextFrame();
}

void AudioNetworkSender::sendNextFrame()
{
    const QByteArray& opusFrame = m_currentFrames[m_currentFrameIndex];

    // 发送 UDP 组播
    qint64 bytesSent = m_udpSocket->writeDatagram(
        opusFrame.constData(),
        opusFrame.size(),
        m_multicastAddress,
        m_multicastPort
    );

    if (bytesSent < 0) {
        qWarning() << "❌ UDP 发送失败:" << m_udpSocket->errorString();
        emit networkError(m_udpSocket->errorString());
    } else {
        // 日志（每 50 帧打印一次，即每秒）
        if (m_currentFrameIndex % 50 == 0) {
            qDebug() << "📡 已发送:" << m_currentFrameIndex << "/" << m_totalFrames
                     << "帧（" << (m_playbackTimer.elapsed()) << "ms）";
        }
    }

    m_currentFrameIndex++;
    emit playbackProgress(m_currentFrameIndex, m_totalFrames);

    // 检查是否完成
    if (m_currentFrameIndex >= m_totalFrames) {
        qDebug() << "✅ 发送完成，总耗时:" << m_playbackTimer.elapsed() << "ms";
        stopPlayback();
        emit playbackFinished();
    }
}

void AudioNetworkSender::stopPlayback()
{
    if (m_isPlaying) {
        m_frameTimer->stop();
        m_isPlaying = false;
        m_currentFrames.clear();
        m_currentFrameIndex = 0;
        qDebug() << "🛑 停止播放";
    }
}
```

void CommonControl::playAudio(const QString& audioPath) {
    qDebug() << "🔊 CommonControl: 播放音频:" << audioPath;
    qDebug() << "   输出模式:" << (m_audioOutputMode == LocalOnly ? "本地" :
                                     m_audioOutputMode == NetworkOnly ? "网络" : "双输出");

    // ✅ 2026-01-21 [音频网络传输] 根据配置选择输出方式
    switch (m_audioOutputMode) {
        case LocalOnly:
            // 仅播放到本地 ES8388
            m_mediaPlayer->setSource(QUrl());
            m_mediaPlayer->setSource(QUrl::fromLocalFile(audioPath));
            m_mediaPlayer->play();
            break;

        case NetworkOnly:
            // 仅发送到网络音频模块
            m_audioNetworkSender->playAudioToNetwork(audioPath);
            break;

        case DualOutput:
            // 本地 + 网络同时
            m_mediaPlayer->setSource(QUrl());
            m_mediaPlayer->setSource(QUrl::fromLocalFile(audioPath));
            m_mediaPlayer->play();
            m_audioNetworkSender->playAudioToNetwork(audioPath);
            break;
    }
}

### UDP 组播配置

**Linux 网络配置**：
```bash
# 检查网络接口
ip addr

# 检查组播路由
route -n | grep 224.0.0.0

# 添加组播路由（如果需要）
route add -net 224.0.0.0 netmask 240.0.0.0 dev eth0
```

**Qt QUdpSocket 配置**：
```cpp
// 初始化 UDP socket
m_udpSocket = new QUdpSocket(this);

// ⚠️ 注意：Qt 的 QUdpSocket 不需要手动加入组播组（发送方不需要）
// 只有接收方才需要调用 joinMulticastGroup()

// 直接绑定到任意端口（用于发送）
if (!m_udpSocket->bind(QHostAddress::AnyIPv4, 0, QUdpSocket::ShareAddress)) {
    qWarning() << "❌ UDP socket 绑定失败:" << m_udpSocket->errorString();
}

// 设置组播 TTL（Time To Live）
m_udpSocket->setSocketOption(QAbstractSocket::MulticastTtlOption, 1);  // TTL=1（局域网内）

// 发送数据到组播地址
m_udpSocket->writeDatagram(data, QHostAddress("224.1.1.1"), 8800);
```

## ⚠️ 关键风险和缓解措施

### 风险 1：TTS 采样率不匹配（🟡 中风险）

**问题**：
- Sherpa-ONNX TTS 输出的 WAV 文件采样率可能不是 16kHz（如 22.05kHz）
- 需要重采样到 16kHz

**缓解措施**：
- FFmpeg `SwrContext` 已支持重采样（参见 1.2 节代码）
- 自动检测采样率并重采样

---

### 风险 2：批量发送延迟过高（🟡 中风险）

**问题**：
- 批量发送需要先解码整个文件（可能 5-10 秒的音频）
- 首帧延迟可能过高（>1 秒）

**缓解措施**：
1. **测量延迟**：在 MVP 中测量首帧延迟
2. **如果延迟 >500ms**：实现实时发送模式（边解码边编码边发送）
3. **切换方式**：通过 `#define` 或配置项

---

### 风险 3：网络不稳定（🟢 低风险）

**问题**：
- UDP 组播丢包
- 音频断续

**缓解措施**：
1. **监控发送状态**：记录 `writeDatagram()` 返回值
2. **添加重传机制**（如果音频模块支持）
3. **增加 Opus 比特率**（16kbps → 24kbps）

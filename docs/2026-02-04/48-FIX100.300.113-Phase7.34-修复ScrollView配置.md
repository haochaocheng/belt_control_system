## 🔍 根本原因

### ScrollView配置问题

**当前代码**（SerialPortConfigPanel.qml line 47-55）：

```qml
ScrollView {
    anchors.fill: parent
    clip: true

    ColumnLayout {
        width: parent.width - 32  // ❌ parent.width是ScrollView的宽度
        anchors.margins: 16       // ❌ ColumnLayout不应该使用anchors.margins
        spacing: 16
    }
}
```

**问题**：
1. `width: parent.width - 32`：parent是ScrollView，但ScrollView的宽度可能不正确
2. `anchors.margins: 16`：ColumnLayout在ScrollView中不应该使用anchors.margins
3. 没有禁用水平滚动条，可能导致不必要的水平滚动
4. 边距应该使用Layout.leftMargin等属性，而不是anchors.margins

---

## ✅ 解决方案

### 修复ScrollView配置

**修改位置**：SerialPortConfigPanel.qml line 45-126

**修改内容**：

1. **添加ScrollView的id**：
```qml
ScrollView {
    id: scrollView  // ✅ 添加id
    anchors.fill: parent
    clip: true
    ScrollBar.horizontal.policy: ScrollBar.AlwaysOff  // ✅ 禁用水平滚动条
}
```

2. **修复ColumnLayout的宽度**：
```qml
ColumnLayout {
    width: scrollView.width  // ✅ 使用scrollView.width
    spacing: 16
}
```

3. **使用Layout.margins而不是anchors.margins**：
```qml
Loader {
    id: paramsSection
    Layout.fillWidth: true
    Layout.preferredHeight: 400
    Layout.leftMargin: 16    // ✅ 使用Layout.leftMargin
    Layout.rightMargin: 16   // ✅ 使用Layout.rightMargin
    Layout.topMargin: 16     // ✅ 使用Layout.topMargin
    source: "SerialPortParamsSection.qml"
}
```

4. **为所有Loader添加边距**：
- paramsSection：leftMargin, rightMargin, topMargin
- sendSection：leftMargin, rightMargin
- receiveSection：leftMargin, rightMargin
- modbusSection：leftMargin, rightMargin, bottomMargin

## 🔄 关于"焦点不可见"的问题

### 需要更多信息

用户提到"焦点在COM1时，下键焦点不知道在哪里，看不到蓝色边框"，但从日志line 300-302看到：

```
Debug: ✅ [SerialPortControlPage] triggerParamInput - 参数索引: 0
Debug: ✅ [SerialPortParamsSection] 串口名称获得焦点
Debug: ✅ [NavigationManager] 从列表跳转到参数区域（跳过Tab）
```

这说明焦点确实到了串口名称（索引0）。

**需要测试**：
1. 在QDS中，右键进入参数区域（焦点应该在串口名称，索引0）
2. 检查串口名称是否有蓝色边框
3. 按下键
4. 查看日志，看看焦点移动到哪里了
5. 检查新的焦点位置是否有蓝色边框

**可能的原因**：
1. 焦点指示器的z值不正确，被其他元素遮挡
2. 焦点移动到了不可见的元素（如设备路径，颜色是#9E9E9E，可能不明显）
3. NavigationManager的导航逻辑有问题

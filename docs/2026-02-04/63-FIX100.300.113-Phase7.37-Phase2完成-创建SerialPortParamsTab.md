### 4. 添加 triggerParamInput() 函数

```qml
// ✅ 2026-02-04 [FIX 100.300.113 Phase 7.37 - Phase 2]: 添加 triggerParamInput() 函数
function triggerParamInput(paramIndex) {
    console.log("✅ [SerialPortParamsTab] 触发参数输入 - 索引:", paramIndex)

    var inputField = null

    switch(paramIndex) {
    case 0:  // 串口名称（只读）
        // 不需要输入
        break
    case 1:  // 波特率
        inputField = baudRateCombo
        break
    case 2:  // 设备路径（只读）
        // 不需要输入
        break
    case 3:  // 数据位
        inputField = dataBitsCombo
        break
    case 4:  // 串口类型（只读）
        // 不需要输入
        break
    case 5:  // 停止位
        inputField = stopBitsCombo
        break
    case 6:  // 校验位
        inputField = parityCombo
        break
    case 7:  // 状态（只读）
        // 不需要输入
        break
    case 8:  // 打开串口按钮
        inputField = openButton
        break
    case 9:  // 关闭串口按钮
        inputField = closeButton
        break
    }

    // 激活虚拟键盘
    if (inputField) {
        if (inputField.activateVirtualKeyboard) {
            inputField.activateVirtualKeyboard()
        } else {
            inputField.forceActiveFocus()
        }
    }
}
```

**效果**:
- ✅ 根据参数索引触发对应输入控件
- ✅ 支持虚拟键盘激活（如果控件有 activateVirtualKeyboard 方法）
- ✅ 只读字段不触发输入

## 💡 技术要点

### ScrollView 的正确使用

**错误方式**（Phase 7.35-7.36.2）:
```qml
ScrollView {
    // 包裹所有 4 个区域
    ColumnLayout {
        Loader { source: "SerialPortParamsSection.qml" }
        Loader { source: "SerialPortSendSection.qml" }
        Loader { source: "SerialPortReceiveSection.qml" }
        Loader { source: "ModbusRegisterSection.qml" }
    }
}
```

**正确方式**（Phase 7.37 - Phase 2）:
```qml
// 每个 Tab 内部独立管理滚动
Rectangle {
    ScrollView {
        // 只包裹单个 Tab 的参数区域
        GridLayout {
            // 10个参数字段
        }
    }
}
```

**优点**:
- ✅ ScrollView 只包裹单个 Tab 内容
- ✅ 内容高度小，不需要滚动
- ✅ 不会触发 Qt 的 ensureVisible() 导致焦点丢失

### Qt.binding() 的使用

**为什么使用 Qt.binding()**:
```qml
// ❌ 错误：直接赋值会破坏双向绑定
item.focusParamIndex = root.focusParamIndex

// ✅ 正确：使用 Qt.binding() 保持双向绑定
item.focusParamIndex = Qt.binding(function() {
    return root.focusParamIndex
})
```

**效果**:
- ✅ 当 root.focusParamIndex 变化时，item.focusParamIndex 自动更新
- ✅ 保持双向绑定，不会破坏 QML 的响应式系统

### 信号转发

**为什么使用信号转发**:
```qml
// ✅ 连接信号，转发焦点更新
item.requestFocusParamIndex.connect(function(paramIndex) {
    root.requestFocusParamIndex(paramIndex)
})
```

**效果**:
- ✅ SerialPortParamsTab 发出 requestFocusParamIndex 信号
- ✅ SerialPortConfigPanel 转发到 SerialPortControlPage
- ✅ 避免直接修改 root.focusParamIndex（破坏 Qt.binding）

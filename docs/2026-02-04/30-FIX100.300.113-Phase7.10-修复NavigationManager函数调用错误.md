# FIX 100.300.113 Phase 7.10 - 修复 NavigationManager 函数调用错误

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 7.10
**状态**: ✅ 完成

---

## 🐛 问题描述

在 QDS 预览模式下测试时，发现两个关键错误：

1. **区域常量未定义**（line 157）:
   ```
   ReferenceError: areaSerialList is not defined
   ```

2. **NavigationManager 函数不存在**（line 273, 280, 296）:
   ```
   TypeError: Property 'moveDown' of object NavigationManager is not a function
   ```

---

## 🔍 根本原因

### 问题 1: 区域常量名称错误

NavigationManager 中定义的区域常量是：
- `areaMotorList` - 列表区域（通用）
- `areaTabBar` - Tab 导航区
- `areaParams` - 参数区域
- `areaButtons` - 按钮区域

但 SerialPortControlPage 中错误使用了 `areaSerialList`（不存在）。

### 问题 2: 函数名称错误

NavigationManager 提供的导航函数是：
- `handleDirectionKey(direction)` - 统一导航入口
  - direction 参数：`"Up"`, `"Down"`, `"Left"`, `"Right"`

但 DeviceSettingsDialog 中错误调用了 `moveDown()` 和 `moveUp()`（不存在）。

---

## ✅ 修复方案

### 1. SerialPortControlPage.qml 修复

**修改 1**: Component.onCompleted（line 157）

**修改前**:
```qml
currentArea = areaSerialList  // ❌ 错误：不存在
```

**修改后**:
```qml
currentArea = areaMotorList  // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.10]: 使用 areaMotorList（通用列表区域）
```

**修改 2**: onAreaChanged（line 194）

**修改前**:

case areaMotorList:  // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.10]: 使用 areaMotorList（通用列表区域）

## 💡 NavigationManager API 说明

### 区域常量

```qml
readonly property string areaMotorList: "A"    // 列表区（通用）
readonly property string areaTabBar: "B"       // Tab导航区
readonly property string areaParams: "C"       // 参数区域
readonly property string areaButtons: "D"      // 底部按钮区
```

### 导航函数

```qml
// 统一导航入口
function handleDirectionKey(direction)

// direction 参数：
// - "Up": 向上导航
// - "Down": 向下导航
// - "Left": 向左导航
// - "Right": 向右导航
```

### 内部函数（不应直接调用）

```qml
function moveInMotorList(direction)  // 列表区导航
function moveInTabBar(direction)     // Tab区导航
function moveInParamArea(direction)  // 参数区导航
function moveInButtonArea(direction) // 按钮区导航
```

## 📝 经验教训

### 1. 使用现有组件前要仔细阅读 API

NavigationManager 是为电机控制页面设计的，但它的属性和函数是通用的：
- `areaMotorList` 可以用于任何列表（电机列表、串口列表等）
- `motorListIndex` 可以用于任何列表索引
- `handleDirectionKey()` 是统一的导航入口

### 2. 参考现有实现

MotorControlPage 已经正确使用了 NavigationManager：
```qml
DeviceInfo.NavigationManager {
    id: navigationManager

    Component.onCompleted: {
        currentArea = areaMotorList  // ✅ 正确
        motorListIndex = 0
    }
}
```

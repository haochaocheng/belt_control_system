## 🎯 用户要求

1. **所有字段都可以有焦点**（包括只读字段）
2. **2列4行布局** + 2个底部按钮
3. **像电视遥控器一样导航**（上下左右移动焦点）
4. **参考 SwitchInputPage 的成功案例**
5. **总共10个参数**（8个字段 + 2个按钮）

## 📊 正确的布局（根据截图）

```
Row 0: [0]串口名称(只读)  [1]波特率(可编辑)
Row 1: [2]设备路径(只读)  [3]数据位(可编辑)
Row 2: [4]串口类型(只读)  [5]停止位(可编辑)
Row 3: [6]校验位(可编辑)  [7]状态(只读)
Row 4: [8]打开串口(按钮)  [9]关闭串口(按钮)
```

**参数索引**: 连续的 0-9

## 🔍 Web 搜索发现

### 关键线索 1: TextInput.autoScroll 属性

从 [QML TextInput Scrolling: Understanding autoScroll and Alternatives](https://runebook.dev/en/articles/qt/qml-qtquick-textinput/autoScroll-prop) 中发现：

**TextInput 有一个 `autoScroll` 属性可以禁用自动滚动！**

```qml
TextInput {
    autoScroll: false  // ← 禁用自动滚动
}
```

**官方文档说明**：
> If autoScroll is set to true (which is the default behavior), as the user types more text than can fit in the visible area, the text will automatically scroll horizontally to keep the most recently typed text visible.
>
> If autoScroll is set to false, the text will simply be clipped when it exceeds the visible width, and the user would have to manually scroll (if scrolling is even enabled through other means) to see the hidden text.

### 关键线索 2: TextField 继承自 TextInput

**TextField 是基于 TextInput 的，所以 TextField 也应该支持 `autoScroll` 属性！**

### 关键线索 3: ensureVisible() 方法

从 [Alternatives to Qt TextInput EnsureVisible](https://runebook.dev/en/articles/qt/qml-qtquick-textinput/ensureVisible-method) 中了解到：

- TextInput 有一个 `ensureVisible()` 方法
- 这个方法会自动调整滚动，使光标可见
- **这正是我们遇到的问题！**

**官方文档说明**：
> When you call ensureVisible(), Qt will automatically adjust the scrolling of the TextInput (if necessary) so that the line containing the cursor becomes visible within the displayed area.

---

## ✅ 解决方案：Phase 7.36.2

### 核心思路

**在所有 TextField 中添加 `autoScroll: false` 属性，禁用 TextField 的自动滚动行为。**

### 理论依据

1. **TextField 继承自 TextInput**，支持 `autoScroll` 属性
2. **autoScroll: false** 可以禁用 TextInput 的自动滚动行为
3. **这应该可以防止触发 ScrollView 的 ensureVisible() 机制**

## 💡 技术要点

### TextInput.autoScroll 属性

**官方文档**：
> If autoScroll is set to true (which is the default behavior), as the user types more text than can fit in the visible area, the text will automatically scroll horizontally to keep the most recently typed text visible.

**默认值**：`true`

**设置为 false 的效果**：
- 文本超出可见区域时，不会自动滚动
- 文本会被裁剪（clip）
- 用户需要手动滚动（如果启用了滚动）

**在我们的场景中**：
- TextField 是只读的（readOnly: true）
- 用户不会输入文本
- 但是 **获取焦点时，Qt 可能仍然会触发 autoScroll 行为**
- 设置 `autoScroll: false` 可以禁用这个行为

### ensureVisible() 方法

**官方文档**：
> When you call ensureVisible(), Qt will automatically adjust the scrolling of the TextInput (if necessary) so that the line containing the cursor becomes visible within the displayed area.

**在我们的场景中**：
- 当 TextField 获得焦点时，Qt 可能会自动调用 ensureVisible()
- 这会触发 ScrollView 的自动滚动
- 设置 `autoScroll: false` 可能可以防止这个行为

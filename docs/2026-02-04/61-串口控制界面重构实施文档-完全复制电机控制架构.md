## 📋 实施概述

### 目标

将串口控制界面完全按照电机控制参数区的方式重构，使用 Tab 切换，包括所有功能：
- Tab 切换（4个Tab）
- 底部按钮区域
- 导航系统（三层焦点区域：列表 → Tab → 参数 → 按钮）
- 虚拟键盘集成
- 焦点管理和焦点指示器

### 根本原因

**Phase 7.35-7.36.2 失败原因**：
- ScrollView 包裹了所有 4 个区域（参数、发送、接收、MODBUS）
- 总高度 1885px 远大于屏幕高度（1080px 或 800px）
- Qt 的 ensureVisible() 触发不必要的滚动，导致焦点丢失

**解决方案**：
- 参考电机控制界面，使用 Tab 切换
- 每个 Tab 内部独立使用 ScrollView
- ScrollView 只包裹单个 Tab 的内容，不会触发焦点丢失

```qml
Rectangle {
    id: tabBar
    anchors.top: header.bottom

    height: 50
    color: "#252b3d"
    border.color: "#3d4556"

        id: tabFlickable
        anchors.fill: parent
        clip: true
        contentWidth: tabRow.width
        contentHeight: height
        flickableDirection: Flickable.HorizontalFlick
        boundsBehavior: Flickable.StopAtBounds

        // 自动滚动到当前Tab
        function scrollToTab(tabIndex) {
            var tabWidth = 120
            var targetX = tabIndex * tabWidth
            var centerX = targetX - (width / 2) + (tabWidth / 2)
            centerX = Math.max(0, Math.min(centerX, contentWidth - width))
            contentX = centerX
        }

        // 监听 currentTabIndex 变化
        Connections {
            target: root
            function onCurrentTabIndexChanged() {
                tabFlickable.scrollToTab(root.currentTabIndex)
            }
        }

        // 支持鼠标滚轮横向滚动
        MouseArea {
            anchors.fill: parent
            propagateComposedEvents: true

            onWheel: {
                var delta = wheel.angleDelta.y
                tabFlickable.contentX = Math.max(0, Math.min(
                    tabFlickable.contentX - delta,
                    tabFlickable.contentWidth - tabFlickable.width

                wheel.accepted = true
```

#### 4.2 添加焦点同步 Connections

```qml
// ========== 焦点同步 ==========
// 1. 列表索引变化
Connections {
    target: navigationManager
    function onMotorListIndexChanged() {
        root.currentSerialPortIndex = navigationManager.motorListIndex
        root.focusItemIndex = navigationManager.motorListIndex
        Qt.callLater(root.loadSerialPortConfig)
    }
}

// 2. Tab 索引变化
Connections {
    target: navigationManager
    function onTabIndexChanged() {
        root.focusTabIndex = navigationManager.tabIndex
        if (serialPortConfigPanel.item) {
            serialPortConfigPanel.item.currentTabIndex = navigationManager.tabIndex
        }
        // 更新 lastParamIndex
        Qt.callLater(function() {
            var paramCount = root.getParamFieldCount()
            navigationManager.updateLastParamIndex(paramCount)
        })
    }
}

// 3. 参数索引变化
Connections {
    target: navigationManager
    function onParamIndexChanged() {
        root.focusParamIndex = navigationManager.paramIndex
    }
}

// 4. 区域切换
Connections {
    target: navigationManager
    function onAreaChanged(newArea) {
        switch(newArea) {
        case navigationManager.areaMotorList:
            root.focusSubArea = 0
            root.focusItemIndex = navigationManager.motorListIndex
            root.focusTabIndex = -1
            root.focusParamIndex = -1
            root.focusButtonIndex = -1
            break
        case navigationManager.areaTabBar:
            root.focusSubArea = 1
            root.focusTabIndex = navigationManager.tabIndex
            root.focusItemIndex = -1
            root.focusParamIndex = -1
            root.focusButtonIndex = -1
            break
        case navigationManager.areaParams:
            root.focusSubArea = 2
            root.focusParamIndex = navigationManager.paramIndex
            root.focusItemIndex = -1
            root.focusTabIndex = -1
            root.focusButtonIndex = -1
            break
        case navigationManager.areaButtons:
            root.focusSubArea = 3
            root.focusButtonIndex = navigationManager.buttonIndex
            root.focusItemIndex = -1
            root.focusTabIndex = -1
            root.focusParamIndex = -1
            break
        }
    }
}
```

#### 4.3 添加 getParamFieldCount() 函数

```qml
// ========== 获取当前Tab的参数数量 ==========
function getParamFieldCount() {
    var currentTab = serialPortConfigPanel.item ?
                     serialPortConfigPanel.item.getCurrentTab() : null
    if (!currentTab) return 0

    if (typeof currentTab.getParamFieldCount === "function") {
        return currentTab.getParamFieldCount()
    }

    // 默认参数数量
    switch(root.focusTabIndex) {
    case 0:  // 参数配置
        return 10
    case 1:  // 发送区
        return 5
    case 2:  // 接收区
        return 5
    case 3:  // MODBUS寄存器
        return 8
    default:
        return 0
    }
}
```

```qml
function triggerParamInput(paramIndex) {
    console.log("✅ [SerialPortParamsTab] 触发参数输入 - 索引:", paramIndex)

    var inputField = null

    switch(paramIndex) {
    case 0:  // 串口名称（只读）
        // 不需要输入
        break
    case 1:  // 波特率
        inputField = baudRateCombo

    case 2:  // 设备路径（只读）

        if (inputField.activateVirtualKeyboard) {
            inputField.activateVirtualKeyboard()
        } else {
            inputField.forceActiveFocus()
        }
    }
```

## ⚠️ 关键注意事项

### 1. 文件重命名

- Section → Tab
- 需要更新 CMakeLists.txt 中的引用
- 需要更新 qml.qrc 中的引用

### 2. 导航系统

- `skipTabArea = false`（支持 Tab 导航）
- 参数数量动态更新（不同 Tab 参数数量不同）
- 使用 Qt.callLater 更新 lastParamIndex

### 3. 焦点传递

- 使用 `Qt.binding()` 保持双向绑定
- 使用信号转发焦点更新（`requestFocusParamIndex`）
- 不要直接赋值，避免打破 Qt.binding

### 4. ScrollView 位置

- **每个 Tab 内部使用 ScrollView**（如果需要）
- **不在 SerialPortConfigPanel 中使用 ScrollView**
- SerialPortParamsTab 不需要 ScrollView（只有 5 行参数）

## 📋 问题描述

**用户反馈**:
> "按右键焦点从串口控制切换到COM1，切换到参数配置，切换到发送区tab，但是参数区画面并没有切换到发送区，还是参数配置，接收区和modbus寄存器tab按钮问题一样"

**问题现象**:
- Tab按钮的焦点指示器正常切换（蓝色边框显示在正确的Tab上）
- Tab按钮的背景图片正常切换（选中/未选中状态）
- Tab按钮的底部激活指示条正常显示
- **但是下方的内容区域（StackLayout）没有切换，始终显示第一个Tab（参数配置）的内容**

---

## 🔍 问题分析

### 根本原因

**SerialPortControlPage.qml的`onTabIndexChanged`处理器中，只更新了焦点索引，没有同步更新SerialPortConfigPanel的`currentTabIndex`**

### 代码流程分析

#### 正常流程（应该是）:
```
1. 用户按右键 → NavigationManager.handleDirectionKey("Right")
2. NavigationManager.moveInTabBar("Right") → tabIndex++
3. SerialPortControlPage.onTabIndexChanged 触发
4. 更新 root.focusTabIndex（焦点指示器）✅
5. 更新 serialConfigPanel.item.currentTabIndex（内容区域）❌ 缺失！
6. SerialPortConfigPanel.currentTabIndex 变化
7. StackLayout.currentIndex 变化（绑定到 currentTabIndex）
8. 内容区域切换到新Tab
```

#### 实际流程（有问题）:
```
1. 用户按右键 → NavigationManager.handleDirectionKey("Right")
2. NavigationManager.moveInTabBar("Right") → tabIndex++
3. SerialPortControlPage.onTabIndexChanged 触发
4. 更新 root.focusTabIndex（焦点指示器）✅
5. ❌ 没有更新 serialConfigPanel.item.currentTabIndex
6. SerialPortConfigPanel.currentTabIndex 保持为 0
7. StackLayout.currentIndex 保持为 0
8. 内容区域始终显示第一个Tab（参数配置）
```

### 关键代码位置

**SerialPortControlPage.qml lines 181-191（修复前）**:
```qml
// ✅ 2026-02-04 [FIX 100.300.113 Phase 7.37 - Phase 4]: 监听 Tab 索引变化
onTabIndexChanged: {
    console.log("✅ [SerialPortControlPage] Tab 索引变化:", tabIndex)
    root.focusTabIndex = tabIndex  // ✅ 只更新了焦点索引
    // ❌ 缺少：更新 serialConfigPanel.item.currentTabIndex

    // 更新 lastParamIndex
    Qt.callLater(function() {
        var paramCount = root.getParamFieldCount()
        updateLastParamIndex(paramCount)
        console.log("✅ [SerialPortControlPage] Tab 切换后参数数量:", paramCount)
    })
}
```

**SerialPortConfigPanel.qml lines 219-221**:
```qml
StackLayout {
    anchors.fill: parent
    currentIndex: root.currentTabIndex  // ✅ 绑定到 currentTabIndex
    // ...
}
```

**问题**：
- `root.focusTabIndex`只用于显示焦点指示器
- `serialConfigPanel.item.currentTabIndex`才是控制StackLayout切换的属性
- 两者没有同步，导致焦点和内容不一致

## ✅ 修复内容

### 修改SerialPortControlPage.qml

**文件位置**: SerialPortControlPage.qml lines 181-198

**修改内容**:
```qml
// ✅ 2026-02-04 [FIX 100.300.113 Phase 7.37 - Phase 4]: 监听 Tab 索引变化
onTabIndexChanged: {
    console.log("✅ [SerialPortControlPage] Tab 索引变化:", tabIndex)
    root.focusTabIndex = tabIndex

    // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.37.2]: 同步更新 SerialPortConfigPanel 的 currentTabIndex
    if (serialConfigPanel.item) {
        serialConfigPanel.item.currentTabIndex = tabIndex
        console.log("✅ [SerialPortControlPage] 已同步 currentTabIndex 到 SerialPortConfigPanel:", tabIndex)
    }

    // 更新 lastParamIndex
    Qt.callLater(function() {
        var paramCount = root.getParamFieldCount()
        updateLastParamIndex(paramCount)
        console.log("✅ [SerialPortControlPage] Tab 切换后参数数量:", paramCount)
    })
}
```

**关键改动**:
1. 添加`if (serialConfigPanel.item)`检查，确保Loader已加载
2. 设置`serialConfigPanel.item.currentTabIndex = tabIndex`，同步Tab索引
3. 添加日志输出，便于调试

## 💡 技术要点

### 为什么需要同步currentTabIndex

**问题**：
- `focusTabIndex`只用于显示焦点指示器（蓝色边框）
- `currentTabIndex`才是控制StackLayout切换的属性
- 两者是独立的属性，需要手动同步

**解决方案**：
```qml
onTabIndexChanged: {
    root.focusTabIndex = tabIndex  // 更新焦点指示器
    if (serialConfigPanel.item) {
        serialConfigPanel.item.currentTabIndex = tabIndex  // 同步内容区域
    }
}
```

**效果**：
- ✅ 焦点指示器和内容区域同步切换
- ✅ 键盘导航和鼠标点击行为一致

### 为什么需要检查serialConfigPanel.item

**问题**：
- Loader可能还没有加载完成
- 直接访问`serialConfigPanel.item`可能为null

**解决方案**：
```qml
if (serialConfigPanel.item) {
    serialConfigPanel.item.currentTabIndex = tabIndex
}
```

**效果**：
- ✅ 避免null引用错误
- ✅ 确保Loader加载完成后才访问item

### 鼠标点击和键盘导航的同步

**鼠标点击**（SerialPortConfigPanel.qml line 188）:
```qml
MouseArea {
    anchors.fill: parent
    onClicked: {
        root.currentTabIndex = index  // 直接设置currentTabIndex
        root.focus = true
    }
}
```

**键盘导航**（SerialPortControlPage.qml line 187-189）:
```qml
if (serialConfigPanel.item) {
    serialConfigPanel.item.currentTabIndex = tabIndex  // 同步currentTabIndex
}
```

**双向同步**（SerialPortControlPage.qml line 351-354）:
```qml
// 监听 currentTabIndex 变化（鼠标点击时触发）
item.onCurrentTabIndexChanged.connect(function() {
    console.log("✅ [SerialPortControlPage] Tab 切换:", item.currentTabIndex)
    navigationManager.tabIndex = item.currentTabIndex  // 同步到NavigationManager
})
```

**效果**：
- ✅ 鼠标点击 → currentTabIndex变化 → 同步到NavigationManager.tabIndex
- ✅ 键盘导航 → NavigationManager.tabIndex变化 → 同步到currentTabIndex
- ✅ 两种方式行为一致

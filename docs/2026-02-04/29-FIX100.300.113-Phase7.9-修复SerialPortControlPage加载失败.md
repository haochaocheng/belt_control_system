# FIX 100.300.113 Phase 7.9 - 修复 SerialPortControlPage 加载失败

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 7.9
**状态**: ✅ 完成

---

## 🐛 问题描述

在 QDS 预览模式下测试时，SerialPortControlPage 加载失败，导致串口列表和参数区域都不显示。

### 错误日志

```
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/SerialPortControlPage.qml:172:9: Cannot assign to non-existent property "onSerialListIndexChanged"
Critical: ✗ [DeviceSettingsDialog] SerialPortControlPage 加载失败
```

---

## 🔍 根本原因

在 Phase 7.2 实施时，我错误地使用了 `serialListIndex` 属性，但 NavigationManager 中实际使用的是 `motorListIndex` 属性。

**NavigationManager.qml 的属性定义**（line 17）:
```qml
property int motorListIndex: 0  // 区域A：电机列表索引（0-7）
```

**SerialPortControlPage.qml 的错误使用**（line 158, 172）:
```qml
serialListIndex = 0  // ❌ 错误：NavigationManager 中没有这个属性

onSerialListIndexChanged: {  // ❌ 错误：没有这个信号
    ...
}
```

---

## ✅ 修复方案

将 SerialPortControlPage 中所有的 `serialListIndex` 改为 `motorListIndex`。

虽然名字是 `motorListIndex`，但它是一个通用的列表索引属性，可以用于任何列表（电机列表、串口列表等）。

---

## 📝 修改内容

**文件**: SerialPortControlPage.qml

### 1. Component.onCompleted 修改（line 158）

**修改前**:
```qml
serialListIndex = 0  // ❌ 错误
```

**修改后**:
```qml
motorListIndex = 0  // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.9]: 使用 motorListIndex（通用列表索引）
```

### 2. 信号监听修改（line 172-176）

**修改前**:
```qml
onSerialListIndexChanged: {  // ❌ 错误：没有这个信号
    console.log("✅ [SerialPortControlPage] 串口列表索引变化:", serialListIndex)
    root.currentSerialIndex = serialListIndex
    root.focusItemIndex = serialListIndex

```

**修改后**:
```qml
onMotorListIndexChanged: {  // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.9]: 使用 motorListIndex（通用列表索引）
    console.log("✅ [SerialPortControlPage] 串口列表索引变化:", motorListIndex)
    root.currentSerialIndex = motorListIndex
    root.focusItemIndex = motorListIndex
}
```

### 3. onAreaChanged 修改（line 196）

**修改前**:
```qml

```

**修改后**:
```qml
root.focusItemIndex = motorListIndex  // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.9]: 使用 motorListIndex
```

## 💡 经验教训

### 1. 使用现有组件时要检查属性名称

NavigationManager 是为电机控制页面设计的，使用的是 `motorListIndex` 属性。虽然名字是 motor，但它是一个通用的列表索引，可以用于任何列表。

### 2. 参考现有实现

MotorControlPage 已经正确使用了 `motorListIndex`：
```qml
onMotorListIndexChanged: {
    root.currentMotorIndex = motorListIndex
    root.focusItemIndex = motorListIndex
}
```

我应该在 Phase 7.2 实施时参考这个实现。

### 3. 在 QDS 中测试

这个错误在 QDS 预览模式下立即暴露出来，说明在 QDS 中测试是发现问题的有效方法。

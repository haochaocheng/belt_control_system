## 🐛 问题描述

用户反馈（第二十次测试）：
> "调试完成，串口参数区域不显示"

### 日志分析

从 `docs/log/pjsip.md` line 132 发现关键错误：

```
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/SerialPortParamsSection.qml:176:25: Cannot assign to non-existent property "onBorderWidthChanged"
```

**问题定位**：
- Phase 7.35.1 添加的调试代码使用了 `onBorderColorChanged` 和 `onBorderWidthChanged`
- 这两个信号处理器在 QML Rectangle 中**不存在**
- 导致 SerialPortParamsSection 加载失败
- 结果：串口参数区域完全不显示

---

## 🔍 根本原因

### QML Rectangle 的属性系统

**错误理解**：
- 以为 Rectangle 的 border.color 和 border.width 属性会自动生成 `onBorderColorChanged` 和 `onBorderWidthChanged` 信号

**实际情况**：
- QML 中只有明确声明为 `property` 的属性才会自动生成 `on<Property>Changed` 信号
- Rectangle 的 border 是一个**组属性**（grouped property），不是普通属性
- border.color 和 border.width 是 border 组的子属性
- 这些子属性**没有**独立的变化信号

**正确的监听方式**：
- 使用 `Connections` 监听父元素（Text）的 activeFocus 变化
- 在 activeFocus 变化时，读取 border.color 和 border.width 的当前值

## 💡 经验教训

### 1. QML 属性系统的理解

**错误假设**：
- 所有属性都会自动生成 `on<Property>Changed` 信号

**正确理解**：
- 只有顶层 `property` 声明的属性才有自动信号
- 组属性（grouped property）的子属性没有独立信号
- 需要监听父属性或使用 Connections

### 2. QML 组属性（Grouped Property）

**什么是组属性**：
```qml
Rectangle {
    border.color: "red"   // border 是组属性
    border.width: 2       // color 和 width 是子属性
}
```

**如何监听组属性变化**：
```qml
// ❌ 错误：直接监听子属性
onBorderColorChanged: { }  // 不存在

// ✅ 正确：监听导致变化的源属性
Connections {
    target: parentItem
    function onActiveFocusChanged() {
        // 读取 border.color 的当前值
        console.log(border.color)
    }
}
```

### 3. 调试代码的测试

**教训**：
- 添加调试代码后，必须立即测试
- 不能假设代码语法正确就能运行
- QML 的错误可能导致整个组件加载失败

**改进**：
- 添加调试代码后，先在 QDS 中测试
- 检查是否有 QML 错误或警告
- 确认组件正常加载后再提交

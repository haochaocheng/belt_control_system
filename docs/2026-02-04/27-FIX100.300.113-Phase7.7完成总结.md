## 🔧 实施原理

### 1. 只修改串口控制页面

```qml
if (currentCategory === 6) {
    // 串口控制特殊处理
    var serialPage = serialPortControlPageLoader.item
    if (serialPage && serialPage.navigationManager) {
        serialPage.navigationManager.moveDown()  // 或 moveUp()
        event.accepted = true
        return
    }
}
// 其他页面继续原有逻辑
```

**关键点**:
- 使用 `currentCategory === 6` 检测串口控制页面
- 获取 `serialPortControlPageLoader.item` 引用
- 检查 `navigationManager` 是否存在
- 调用 `moveDown()` 或 `moveUp()`
- 设置 `event.accepted = true` 阻止默认处理
- 使用 `return` 提前退出，不执行后续的直接赋值代码

### 2. NavigationManager 自动处理

当调用 `navigationManager.moveDown()` 或 `moveUp()` 时，NavigationManager 会自动：

1. **更新参数索引**:
   - `paramIndex` 属性自动更新
   - 通过信号同步到 `focusParamIndex`

2. **调用焦点函数**:
   - 自动调用 `triggerParamInput(paramIndex)`
   - 触发对应 Section 的 focus 函数
   - 控件获得焦点

3. **显示焦点指示器**:
   - 控件的 `activeFocus` 属性变为 true
   - 焦点指示器 Rectangle 显示蓝色边框

4. **处理区域切换**:
   - 当到达参数区域底部时，自动切换到按钮区域
   - 当从按钮区域返回时，自动切换到参数区域

### 3. 保持其他页面不变

- 电机控制页面（currentCategory === 3）已经使用 NavigationManager
- 其他页面（基本配置、开关输入等）继续使用直接赋值方式
- 不影响现有功能

### 上下键导航（参数区域）:

```

  ↓ 下键 → navigationManager.moveDown()
索引1 (数据位)
  ↓ 下键 → navigationManager.moveDown()
索引2 (停止位)
  ↓ 下键 → navigationManager.moveDown()
...
索引12 (寄存器列表)
  ↓ 下键 → navigationManager.moveDown()
进入按钮区域
```

### 左右键导航:

```

  → 右键
参数区域（索引0）
  ← 左键

```

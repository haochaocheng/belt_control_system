## 📊 串口控制页面结构

### 页面组成

```
DeviceSettingsDialog (对话框)
├── 顶部按钮区域 (区域 0)
│   ├── 关闭按钮
│   ├── 保存按钮
│   └── 重置按钮
├── 左侧类别区域 (区域 1)
│   ├── 基本配置
│   ├── 开关量输入
│   ├── 模拟量输入
│   ├── 电机控制
│   ├── 制动器控制
│   ├── 张紧控制
│   ├── 串口控制 ← 当前类别
│   └── 逻辑控制
├── 右侧内容区域 (区域 2) ← SerialPortControlPage
│   ├── 左侧：串口列表 (子区域 0)
│   │   ├── COM1 (索引 0)
│   │   ├── COM2 (索引 1)
│   │   ├── COM3 (索引 2)
│   │   ├── COM4 (索引 3)
│   │   ├── COM5 (索引 4)
│   │   └── COM6 (索引 5)
│   └── 右侧：串口配置 (子区域 1)
│       ├── 参数配置区
│       ├── 发送区
│       ├── 接收区
│       └── MODBUS 区
└── 底部按钮区域 (区域 3)
    ├── 保存
    ├── 重置
    └── 关闭
```

### 焦点层级

```
DeviceSettingsDialog (主焦点作用域)
├── currentFocusArea: 0-3 (当前焦点区域)
├── currentCategory: 6 (串口控制)
└── currentContentItemIndex: 0-5 (串口列表索引)

SerialPortControlPage (子焦点作用域)
├── focusSubArea: 0-1 (子区域)
│   ├── 0: 串口列表
│   └── 1: 串口配置
├── focusItemIndex: 0-5 (列表焦点索引)
└── currentSerialIndex: 0-5 (当前选中串口)
```

## 🎮 导航键规划

### 区域切换（左右键）

```
顶部按钮 (0) ←→ 左侧类别 (1) ←→ 右侧内容 (2) ←→ 底部按钮 (3)
     ↑                                                      ↓
     └──────────────────────────────────────────────────────┘
```

### 右侧内容区域的子区域切换

```
串口列表 (子区域 0) ←→ 串口配置 (子区域 1)
```

### 详细导航规则

#### 1. 顶部按钮区域 (currentFocusArea = 0)

| 按键 | 动作 |
|------|------|
| 上键 | 在按钮间移动（关闭 ← 保存 ← 重置） |
| 下键 | 在按钮间移动（关闭 → 保存 → 重置） |
| 左键 | 切换到底部按钮区域 (3) |
| 右键 | 切换到左侧类别区域 (1) |

#### 2. 左侧类别区域 (currentFocusArea = 1)

| 按键 | 动作 |
|------|------|
| 上键 | 在类别间移动（向上） |
| 下键 | 在类别间移动（向下） |
| 左键 | 切换到顶部按钮区域 (0) |
| 右键 | 切换到右侧内容区域 (2) |

#### 3. 右侧内容区域 - 串口列表 (currentFocusArea = 2, focusSubArea = 0)

| 按键 | 动作 |
|------|------|
| 上键 | 在串口列表中向上移动 (COM1 ← COM2 ← ...) |
| 下键 | 在串口列表中向下移动 (COM1 → COM2 → ...) |
| 左键 | 返回到左侧类别区域 (1) |
| 右键 | 切换到串口配置区域 (子区域 1) |

#### 4. 右侧内容区域 - 串口配置 (currentFocusArea = 2, focusSubArea = 1)

| 按键 | 动作 |
|------|------|
| 上键 | 滚动查看（ScrollView 处理） |
| 下键 | 滚动查看（ScrollView 处理） |
| 左键 | 返回到串口列表 (子区域 0) |
| 右键 | 无动作（已在最右侧） |

#### 5. 底部按钮区域 (currentFocusArea = 3)

| 按键 | 动作 |
|------|------|
| 上键 | 在按钮间移动（保存 ← 重置 ← 关闭） |
| 下键 | 在按钮间移动（保存 → 重置 → 关闭） |
| 左键 | 切换到右侧内容区域 (2) |
| 右键 | 切换到顶部按钮区域 (0) |

## 🔄 焦点同步机制

### 1. DeviceSettingsDialog → SerialPortControlPage

**触发条件**:
- `currentFocusArea` 变化
- `currentCategory` 变化
- `currentContentItemIndex` 变化

**同步逻辑**:
```qml
Connections {
    target: root
    enabled: serialPortControlPageLoader.item !== null

    function onCurrentFocusAreaChanged() {
        if (serialPortControlPageLoader.item && root.currentCategory === 6) {
            if (root.currentFocusArea === 2) {
                // 焦点进入内容区域，默认在列表区域
                serialPortControlPageLoader.item.focusSubArea = 0
                serialPortControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 焦点离开内容区域，清除焦点
                serialPortControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentCategoryChanged() {
        if (serialPortControlPageLoader.item) {
            if (root.currentFocusArea === 2 && root.currentCategory === 6) {
                // 切换到串口控制类别，设置焦点
                serialPortControlPageLoader.item.focusSubArea = 0
                serialPortControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 切换到其他类别，清除焦点
                serialPortControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentContentItemIndexChanged() {
        if (serialPortControlPageLoader.item &&
            root.currentFocusArea === 2 &&
            root.currentCategory === 6 &&
            serialPortControlPageLoader.item.focusSubArea === 0) {
            // 只在焦点在列表区域时同步
            serialPortControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
        }
    }
}
```

### 2. SerialPortControlPage → DeviceSettingsDialog

**触发条件**:
- `focusItemIndex` 变化
- `requestReturnToCategory` 信号

**同步逻辑**:
```qml
Connections {
    target: serialPortControlPageLoader.item
    enabled: serialPortControlPageLoader.item !== null

    function onFocusItemIndexChanged() {
        if (serialPortControlPageLoader.item &&
            root.currentCategory === 6 &&
            root.currentFocusArea === 2 &&
            serialPortControlPageLoader.item.focusSubArea === 0 &&
            serialPortControlPageLoader.item.focusItemIndex >= 0) {
            // 只在焦点在列表区域时同步
            console.log("✅ [DeviceSettingsDialog] 同步串口控制列表焦点:", serialPortControlPageLoader.item.focusItemIndex)
            root.currentContentItemIndex = serialPortControlPageLoader.item.focusItemIndex
        }
    }

    function onRequestReturnToCategory() {
        // 串口控制页面请求返回到左侧类别
        console.log("✅ [DeviceSettingsDialog] 串口控制请求返回类别")
        root.currentFocusArea = 1  // 切换到左侧类别区域
    }
}
```

### 3. SerialPortControlPage 内部同步

**触发条件**:
- `focusItemIndex` 变化（在列表区域）

**同步逻辑**:
```qml
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex < serialPorts.length) {
        console.log("✅ [SerialPortControlPage] focusItemIndex 变化:", focusItemIndex, "→ 更新 currentSerialIndex")
        currentSerialIndex = focusItemIndex
    }
}
```

```qml
// ✅ 添加 handleKeyPress 函数
function handleKeyPress(key) {
    console.log("✅ [SerialPortControlPage] handleKeyPress:", key)

    switch(key) {
    case "Up":
        if (focusSubArea === 0 && focusItemIndex > 0) {
            focusItemIndex--
        }
        break
    case "Down":
        if (focusSubArea === 0 && focusItemIndex < serialPorts.length - 1) {
            focusItemIndex++
        }
        break
    case "Left":
        if (focusSubArea === 1) {
            // 从参数区返回列表区
            focusSubArea = 0
            focusItemIndex = currentSerialIndex
        } else if (focusSubArea === 0) {
            // 在列表区域，按左键返回到左侧类别
            root.requestReturnToCategory()
        }
        break
    case "Right":
        if (focusSubArea === 0) {
            // 从列表区进入参数区
            focusSubArea = 1
            focusItemIndex = -1
        }
        break
    }
}
```

## 🎯 推荐方案

**推荐方案 A**: 移除页面内部的 Keys 处理

**理由**:
1. 串口控制页面只有 2 个区域（列表、参数），不需要复杂的导航管理
2. 与开关量输入、模拟量输入保持一致
3. 实现简单，不需要修改 DeviceSettingsDialog
4. 用户可以通过以下方式切换：
   - 上下键：在串口列表中移动
   - 左键：返回到左侧类别
   - 右键：（暂不支持切换到参数区域，用户可以用鼠标点击）

**如果用户需要左右键切换列表/参数区域**，可以使用方案 B。

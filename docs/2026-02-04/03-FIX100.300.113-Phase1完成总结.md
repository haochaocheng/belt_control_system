## 📝 技术要点

### 1. 数据绑定
使用 `Qt.binding()` 确保数据双向绑定：
```qml
item.currentSerialPort = Qt.binding(function() {
    return root.currentSerialPort
})
```

### 2. 相对路径导入
QDS 预览模式下使用相对路径导入：
```qml
import ".." as DeviceInfo
```

### 3. GridLayout 4列布局
参考 SwitchInputPage 的布局模式：
```qml
GridLayout {
    width: paramScrollView.width * 0.9
    columns: 4
    columnSpacing: 16
    rowSpacing: 12
}
```

### 4. 样式一致性
所有文本和输入框样式与 SwitchInputPage 保持一致：
- 字体大小：21px

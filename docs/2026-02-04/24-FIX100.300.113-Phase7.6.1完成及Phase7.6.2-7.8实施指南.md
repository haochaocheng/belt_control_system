**修改后**（方案C）：
```qml
if (currentCategory === 6 && currentFocusArea === 2) {
    var serialPage = serialPortControlPageLoader.item
    if (serialPage) {
        console.log("🔍 [串口控制调试] 下键 - focusSubArea:", serialPage.focusSubArea)

        if (serialPage.focusSubArea === 0) {
            // 在串口列表中，使用默认处理
        } else if (serialPage.focusSubArea === 1) {
            // ✅ 方案C：使用 NavigationManager 导航
            if (serialPage.navigationManager) {
                serialPage.navigationManager.moveDown()
                event.accepted = true
                return
            }
        } else if (serialPage.focusSubArea === 2) {
            // 在按钮区域，使用默认处理
        }
    }
}
```

## 💡 实施要点

### 1. 焦点指示器统一样式

```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: [控件ID].activeFocus ? "#2196F3" : "transparent"
    border.width: [控件ID].activeFocus ? 3 : 0
    radius: 4
    z: 10  // 确保在最上层
}
```

### 2. 焦点函数统一模式

```qml
function focus[控件名称]() {
    [控件ID].forceActiveFocus()
    console.log("✅ [Section名称] [控件名称]获得焦点")
}
```

### 3. NavigationManager 使用

- **moveDown()**: 向下移动焦点
- **moveUp()**: 向上移动焦点
- **moveLeft()**: 向左移动焦点（如果支持）
- **moveRight()**: 向右移动焦点（如果支持）

### 4. 调试日志

- 使用 ✅ 标识符表示成功
- 使用 🔍 标识符表示调试信息
- 使用 ❌ 标识符表示错误

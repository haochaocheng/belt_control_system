# FIX 100.300.113 Phase 3.2 - 添加 ScrollView 解决布局超出问题

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 3.2
**状态**: ✅ 完成

---

## 🎯 问题描述

用户反馈布局问题：

1. **发送区被缩小**：发送区的输入框高度太小
2. **寄存器区超出底部**：MODBUS 寄存器操作区被截断，超出了弹窗底部
3. **无法滚动查看**：所有区域（参数区、发送区、接收区、寄存器操作区）应该放在一起，使用滑动的方式显示

**用户原话**：
> "布局还有有问题，将串口参数区 发送区 接收器 寄存器操作区等放在一起，使用滑动的方式显示，现在发送区被缩小了，寄存器区都超出了弹窗底部"

---

## 🔍 问题分析

### 当前布局问题

**SerialPortConfigPanel.qml** 使用 `ColumnLayout` 直接包含所有区域：

```qml
ColumnLayout {
    anchors.fill: parent
    anchors.margins: 16
    spacing: 16

    Loader { Layout.preferredHeight: 300 }  // 参数区
    Loader { Layout.preferredHeight: 180 }  // 发送区
    Loader { Layout.preferredHeight: 220 }  // 接收区
    Loader { Layout.fillHeight: true }      // MODBUS区
}
```

**问题**：
- 总高度：300 + 180 + 220 + 400 = 1100px
- 对话框高度：约 800px
- 超出部分：约 300px 被截断
- 没有滚动条，无法查看底部内容

### 根本原因

`ColumnLayout` 没有被 `ScrollView` 包裹，导致：
1. 内容超出对话框可视区域
2. 无法滚动查看所有区域
3. MODBUS 寄存器操作区被完全截断

---

## ✅ 解决方案

### 1. 添加 ScrollView 包裹

将整个 `ColumnLayout` 包裹在 `ScrollView` 中：

```qml
ScrollView {
    anchors.fill: parent
    anchors.margins: 16
    clip: true
    contentWidth: availableWidth  // 防止水平滚动

    ColumnLayout {
        width: parent.width
        spacing: 16

        // 所有区域的 Loader
    }
}
```

### 2. 调整各区域高度

| 区域 | 旧高度 | 新高度 | 变化 | 说明 |
|------|--------|--------|------|------|
| 参数配置区 | 300px | 300px | 不变 | 高度合适 |
| 发送区 | 180px | **250px** | +70px | 增加输入框高度 |
| 接收区 | 220px | **280px** | +60px | 增加显示区域 |
| MODBUS区 | fillHeight | **600px** | 固定 | 使用固定高度 |

**总高度**：300 + 250 + 280 + 600 = **1430px**

### 3. 关键修改点

#### 3.1 使用 ScrollView

```qml
// ✅ 2026-02-04: 添加 ScrollView 使所有区域可滚动查看
ScrollView {
    anchors.fill: parent
    anchors.margins: 16
    clip: true
    contentWidth: availableWidth  // 防止水平滚动

    ColumnLayout {
        width: parent.width  // ✅ 绑定到父容器宽度
        spacing: 16
        // ...
    }
}
```

#### 3.2 增加发送区高度

```qml
Loader {
    id: sendSection
    Layout.fillWidth: true
    Layout.preferredHeight: 250  // ✅ 增加高度：180 → 250
    source: "SerialPortSendSection.qml"
}
```

#### 3.3 增加接收区高度

```qml
Loader {
    id: receiveSection
    Layout.fillWidth: true
    Layout.preferredHeight: 280  // ✅ 增加高度：220 → 280
    source: "SerialPortReceiveSection.qml"
}
```

#### 3.4 MODBUS 区使用固定高度

```qml
Loader {
    id: modbusSection
    Layout.fillWidth: true
    Layout.preferredHeight: 600  // ✅ 使用固定高度而不是 fillHeight
    source: "ModbusRegisterSection.qml"
}
```

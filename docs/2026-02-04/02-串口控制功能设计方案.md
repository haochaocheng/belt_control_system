## 🎯 需求分析

### 功能需求

1. **位置**：在"逻辑控制"大类下面新增"串口控制"
2. **串口数量**：6个串口
   - COM1 (ttyS0) - RS422
   - COM2 (ttyS7) - RS422
   - COM3 (ttyCH9344USB0) - RS232
   - COM4 (ttyCH9344USB1) - RS232
   - COM5 (ttyCH9344USB2) - RS485
   - COM6 (ttyCH9344USB3) - RS485
3. **显示规则**：
   - 列表显示：COM1-COM6（不显示tty设备名）
   - 参数区显示：设备路径只读显示（如 /dev/ttyS0）
   - 串口类型：可编辑（用于标识串口用途）
4. **功能要求**：
   - 串口参数配置（波特率、数据位、停止位、校验位等）
   - 串口助手功能（发送区、接收区）
   - MODBUS RTU 寄存器操作
5. **参考模板**：开关量输入页面（不是电机控制，避免复杂的Tab结构）

### 通讯协议

- **MODBUS RTU**：工业标准串口通讯协议
- **功能码**：
  - 0x03：读保持寄存器
  - 0x06：写单个寄存器
  - 0x10：写多个寄存器

        TextField {
            id: quantity
            text: "10"
            validator: IntValidator { bottom: 1; top: 125 }
        }

        Label { text: "写入值:" }
        TextField {
            id: writeValue
            enabled: functionCode.currentIndex > 0
            validator: RegExpValidator { regExp: /[0-9A-Fa-f]{1,4}/ }
        }
    }

    // 操作按钮
    RowLayout {
        Button {
            text: "读取"
            enabled: functionCode.currentIndex === 0
            onClicked: modbus.readHoldingRegisters(
                parseInt(slaveAddress.text, 16),
                parseInt(startAddress.text, 16),
                parseInt(quantity.text)
            )
        }

        Button {
            text: "写入"
            enabled: functionCode.currentIndex > 0
            onClicked: {
                if (functionCode.currentIndex === 1) {
                    modbus.writeSingleRegister(
                        parseInt(slaveAddress.text, 16),
                        parseInt(startAddress.text, 16),
                        parseInt(writeValue.text, 16)
                    )
                } else {
                    modbus.writeMultipleRegisters(
                        parseInt(slaveAddress.text, 16),
                        parseInt(startAddress.text, 16),
                        [parseInt(writeValue.text, 16)]
                    )
                }
            }
        }
    }

            border.width: 1

## 🔧 后端C++类设计

### 1. SerialPortController 类

**职责**：
- 管理8个串口的配置和状态
- 提供串口打开/关闭接口
- 提供数据发送/接收接口
- 提供MODBUS RTU协议支持

**头文件**：`src/control/SerialPortController.h`

```cpp
#ifndef SERIALPORTCONTROLLER_H
#define SERIALPORTCONTROLLER_H

#include <QObject>
#include <QSerialPort>
#include <QMap>
#include <QTimer>

class SerialPortController : public QObject
{
    Q_OBJECT

    // 串口列表
    Q_PROPERTY(QStringList serialPorts READ serialPorts CONSTANT)

    // 当前串口配置
    Q_PROPERTY(QString currentPort READ currentPort WRITE setCurrentPort NOTIFY currentPortChanged)
    Q_PROPERTY(int baudRate READ baudRate WRITE setBaudRate NOTIFY baudRateChanged)
    Q_PROPERTY(int dataBits READ dataBits WRITE setDataBits NOTIFY dataBitsChanged)
    Q_PROPERTY(int stopBits READ stopBits WRITE setStopBits NOTIFY stopBitsChanged)
    Q_PROPERTY(QString parity READ parity WRITE setParity NOTIFY parityChanged)
    Q_PROPERTY(bool isOpen READ isOpen NOTIFY isOpenChanged)

    // 接收缓冲区
    Q_PROPERTY(QString receiveBuffer READ receiveBuffer NOTIFY receiveBufferChanged)

public:
    explicit SerialPortController(QObject *parent = nullptr);
    ~SerialPortController();

    // 串口列表
    QStringList serialPorts() const;

    // 串口配置
    QString currentPort() const;
    void setCurrentPort(const QString &port);

    int baudRate() const;
    void setBaudRate(int rate);

    int dataBits() const;
    void setDataBits(int bits);

    int stopBits() const;
    void setStopBits(int bits);

    QString parity() const;
    void setParity(const QString &parity);

    bool isOpen() const;

    QString receiveBuffer() const;

    // 串口操作
    Q_INVOKABLE bool openSerialPort();
    Q_INVOKABLE void closeSerialPort();
    Q_INVOKABLE void sendData(const QString &data, bool isHex);
    Q_INVOKABLE void clearReceiveBuffer();

    // MODBUS RTU 操作
    Q_INVOKABLE void readHoldingRegisters(int slaveAddress, int startAddress, int quantity);
    Q_INVOKABLE void writeSingleRegister(int slaveAddress, int address, int value);
    Q_INVOKABLE void writeMultipleRegisters(int slaveAddress, int startAddress, const QList<int> &values);

signals:
    void currentPortChanged();
    void baudRateChanged();
    void dataBitsChanged();
    void stopBitsChanged();
    void parityChanged();
    void isOpenChanged();
    void receiveBufferChanged();

    void dataReceived(const QByteArray &data);
    void modbusResponseReceived(int slaveAddress, int functionCode, const QByteArray &data);
    void errorOccurred(const QString &error);

private slots:
    void handleReadyRead();
    void handleError(QSerialPort::SerialPortError error);
    void handleModbusTimeout();

private:
    QMap<QString, QSerialPort*> m_serialPorts;  // 串口对象映射
    QString m_currentPort;                       // 当前串口
    QSerialPort *m_currentSerialPort;            // 当前串口对象

    // 串口配置
    int m_baudRate;
    int m_dataBits;
    int m_stopBits;
    QString m_parity;

    // 接收缓冲区
    QString m_receiveBuffer;
    QByteArray m_modbusBuffer;  // MODBUS 响应缓冲区

    // MODBUS 超时定时器
    QTimer *m_modbusTimer;

    // 辅助函数
    QByteArray hexStringToByteArray(const QString &hex);
    QString byteArrayToHexString(const QByteArray &data);
    QByteArray buildModbusRequest(int slaveAddress, int functionCode, int startAddress, int quantity, const QList<int> &values = QList<int>());
    bool parseModbusResponse(const QByteArray &response, int &slaveAddress, int &functionCode, QByteArray &data);
    quint16 calculateCRC16(const QByteArray &data);
};

#endif // SERIALPORTCONTROLLER_H
```

#ifndef MODBUSREGISTERMODEL_H

#include <QAbstractTableModel>

## 📊 数据流设计

### 串口数据流

```
用户输入
    ↓
SerialPortSendSection
    ↓
SerialPortController.sendData()
    ↓
QSerialPort.write()
    ↓
串口硬件
    ↓
QSerialPort.readyRead()
    ↓
SerialPortController.handleReadyRead()
    ↓
SerialPortController.dataReceived() 信号
    ↓
SerialPortReceiveSection 更新显示
```

### MODBUS数据流

```
用户点击"读取"
    ↓
ModbusRegisterSection
    ↓
SerialPortController.readHoldingRegisters()
    ↓
构建MODBUS请求帧
    ↓
QSerialPort.write()
    ↓
从站设备
    ↓
QSerialPort.readyRead()
    ↓
SerialPortController.handleReadyRead()
    ↓
解析MODBUS响应帧
    ↓
SerialPortController.modbusResponseReceived() 信号
    ↓
ModbusRegisterModel.updateRegisters()
    ↓
TableView 更新显示
```

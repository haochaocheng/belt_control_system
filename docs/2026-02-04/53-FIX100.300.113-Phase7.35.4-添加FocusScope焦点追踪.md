## 🔍 根本原因分析

### FocusScope 和 focus 属性冲突

**DeviceSettingsDialog 的焦点结构**：

```qml
Item {
    id: modalContainer

    FocusScope {
        id: dialogFocusScope
        focus: true  // ← FocusScope 获取焦点

        Rectangle {
            id: root
            focus: true  // ← Rectangle 也有 focus: true！

            // ... 内容区域
            SerialPortParamsSection {
                Text {
                    id: serialNameText
                    focus: true  // ← Text 也有 focus: true！
                }
            }
        }
    }
}
```

**问题**：
1. **FocusScope** 有 `focus: true`
2. **Rectangle root** 有 `focus: true`
3. **serialNameText** 有 `focus: true`

当 `serialNameText.forceActiveFocus()` 被调用后：
1. serialNameText 获得焦点（activeFocus: true）
2. Keys.onRightPressed 返回
3. **Qt 的焦点管理系统重新评估焦点**
4. **发现 Rectangle root 也有 `focus: true`**
5. **Qt 可能将焦点返回给 Rectangle root**
6. serialNameText 失去焦点（activeFocus: false）

### 为什么没有日志？

因为焦点转移是 Qt 内部的焦点管理系统自动完成的，不会触发我们的代码，所以没有日志输出。

## ✅ 解决方案

### 添加 FocusScope 和 Rectangle root 的焦点变化监听器

通过监听 FocusScope 的 `activeFocusItem` 和 Rectangle root 的 `activeFocus`，我们可以追踪焦点的完整流转过程。

**修改文件**: DeviceSettingsDialog.qml

### 1. FocusScope 焦点追踪（line 58-65）

```qml
FocusScope {
    id: dialogFocusScope
    anchors.centerIn: parent
    width: parent.width * 0.8
    height: parent.height * 0.8
    focus: true  // FocusScope 获取焦点
    z: 1000  // 在遮罩上方

    // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.35.4]: 监听焦点变化
    onActiveFocusItemChanged: {
        console.log("🔍 [FocusScope] activeFocusItem 变化:", activeFocusItem)
        if (activeFocusItem) {
            console.log("   - objectName:", activeFocusItem.objectName)
            console.log("   - toString:", activeFocusItem.toString())
        }
    }

    // ...
}
```

**目的**：
- 追踪 FocusScope 内部的焦点元素变化
- 确认焦点是否从 serialNameText 转移到了其他元素
- 通过 objectName 和 toString() 识别焦点元素

### 2. Rectangle root 焦点追踪（line 269-272）

```qml
Rectangle {
    id: root
    objectName: "deviceSettingsDialog"
    // ...

    focus: true

    // ✅ 2026-02-04 [FIX 100.300.113 Phase 7.35.4]: 监听焦点变化
    onActiveFocusChanged: {
        console.log("🔍 [DeviceSettingsDialog root] activeFocus 变化:", activeFocus)
    }

    // ...
}
```

**目的**：
- 追踪 Rectangle root 的焦点状态变化
- 确认焦点是否返回到了 Rectangle root

## 🔍 问题诊断指南

### 场景 1: FocusScope.activeFocusItem 保持在 serialNameText

**现象**：
- FocusScope.activeFocusItem 一直是 serialNameText
- 但 serialNameText.activeFocus 变成 false

**原因**：
- 可能是 FocusScope 的 focus 属性被修改了
- 或者 FocusScope 的父元素失去了焦点

**解决方案**：
- 检查 FocusScope 的 focus 属性
- 检查 modalContainer 的焦点状态

### 场景 2: FocusScope.activeFocusItem 变成 Rectangle root

**现象**：
- FocusScope.activeFocusItem 从 serialNameText 变成 root
- Rectangle root.activeFocus 变成 true

**原因**：
- Qt 的焦点管理系统将焦点返回给了 Rectangle root
- 因为 Rectangle root 有 `focus: true`

**解决方案**：
- 移除 Rectangle root 的 `focus: true`
- 或者在设置焦点到 serialNameText 后，立即设置 `root.focus = false`

### 场景 3: FocusScope.activeFocusItem 变成其他元素

**现象**：
- FocusScope.activeFocusItem 变成了其他元素（不是 root，也不是 serialNameText）

**原因**：
- 有其他代码在抢夺焦点
- 可能是 Connections 监听器或 Qt.callLater

**解决方案**：
- 根据 objectName 和 toString() 识别焦点元素
- 搜索代码中所有调用 forceActiveFocus() 的地方
- 检查是否有 Connections 监听器在监听焦点相关属性

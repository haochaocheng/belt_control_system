# 串口控制右侧区域导航完整规划

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 6
**状态**: 📋 规划中

---

## 🎯 目标

实现串口控制右侧区域（串口配置面板）的完整导航功能，包括：
1. 参数配置区
2. 发送区
3. 接收区
4. MODBUS 寄存器操作区

---

## 📊 当前状态分析

### 已实现的功能

✅ **左侧串口列表导航**：
- 上下键：在串口列表中移动（COM1-COM6）
- 左键：返回到左侧类别区域
- 鼠标点击：选择串口

✅ **区域切换**：
- 左键：从内容区域返回到左侧类别
- 右键：从左侧类别进入内容区域

### 未实现的功能

❌ **右侧参数区域导航**：
- 右键：从串口列表进入参数区域
- 左键：从参数区域返回串口列表
- 上下键：在参数区域内滚动或切换焦点

## 🎮 导航方案设计

### 方案 A: 简化方案（推荐）

**特点**：
- 右侧区域作为一个整体，使用 ScrollView 滚动
- 不支持右键进入参数区域
- 用户使用鼠标或触摸滚动查看内容

**导航规则**：
```
串口列表 (focusSubArea = 0)
  ↓ 上下键：在列表中移动
  ↓ 左键：返回类别
  ↓ 右键：无动作（或显示提示）
```

**优点**：
- ✅ 实现简单
- ✅ 与当前实现一致
- ✅ 用户可以用鼠标滚动查看所有内容

**缺点**：
- ❌ 无法用键盘导航到参数区域
- ❌ 无法用键盘操作输入框和按钮

### 方案 B: 完整导航方案

**特点**：
- 支持右键进入参数区域
- 参数区域作为一个整体，使用上下键滚动
- 不支持逐个输入框导航

**导航规则**：
```
串口列表 (focusSubArea = 0)
  ↓ 右键 → 参数区域 (focusSubArea = 1)

参数区域 (focusSubArea = 1)
  ↓ 上下键：ScrollView 滚动
  ↓ 左键：返回串口列表
  ↓ 鼠标点击：操作输入框和按钮
```

**优点**：
- ✅ 支持键盘导航到参数区域
- ✅ 可以用上下键滚动查看内容
- ✅ 实现相对简单

**缺点**：
- ❌ 无法用键盘操作输入框
- ❌ 需要鼠标点击输入框

### 方案 C: 完全键盘导航方案（最复杂）

**特点**：
- 支持右键进入参数区域
- 支持在参数区域内逐个输入框导航
- 支持 Tab 键切换输入框
- 支持 Enter 键触发按钮

**导航规则**：
```
串口列表 (focusSubArea = 0)
  ↓ 右键 → 参数区域 (focusSubArea = 1)

参数区域 (focusSubArea = 1)
  ↓ Tab 键：在输入框间切换
  ↓ Enter 键：触发按钮
  ↓ 上下键：在区域间切换（参数→发送→接收→MODBUS）
  ↓ 左键：返回串口列表
```

**优点**：
- ✅ 完全支持键盘操作
- ✅ 无需鼠标即可完成所有操作
- ✅ 最佳的可访问性

**缺点**：
- ❌ 实现非常复杂
- ❌ 需要管理大量焦点状态
- ❌ 需要处理虚拟键盘交互

---

## 📋 推荐方案：方案 B

### 理由

1. **平衡复杂度和功能**：
   - 支持键盘导航到参数区域
   - 不需要管理复杂的输入框焦点
   - 用户可以用鼠标操作输入框

2. **与现有实现一致**：
   - 参数区域已经有 ScrollView
   - 输入框已经支持鼠标点击
   - 虚拟键盘已经集成

3. **用户体验良好**：
   - 键盘导航用于快速切换区域
   - 鼠标操作用于精确输入
   - 符合用户习惯

## 🔧 方案 B 实施计划

### Phase 1: 在 DeviceSettingsDialog 中添加右键处理

**目标**：支持从串口列表右键进入参数区域

**修改文件**: DeviceSettingsDialog.qml

**添加代码**（Keys.onRightPressed）：
```qml
Keys.onRightPressed: function(event) {
    // ... 其他页面的处理 ...

    // ✅ 串口控制页面特殊处理
    if (currentCategory === 6 && currentFocusArea === 2) {
        var serialPage = serialPortControlPageLoader.item
        if (serialPage && serialPage.focusSubArea === 0) {
            // 从串口列表进入参数区域
            serialPage.focusSubArea = 1
            serialPage.focusItemIndex = -1
            console.log("✅ [导航] 串口控制：从列表进入参数区域")
            event.accepted = true
            return
        }
    }

    // ... 默认处理 ...
}
```

### Phase 2: 在 DeviceSettingsDialog 中添加左键处理

**目标**：支持从参数区域左键返回串口列表

**修改文件**: DeviceSettingsDialog.qml

**添加代码**（Keys.onLeftPressed）：
```qml
Keys.onLeftPressed: function(event) {
    // ... 其他页面的处理 ...

    // ✅ 串口控制页面特殊处理
    if (currentCategory === 6 && currentFocusArea === 2) {
        var serialPage = serialPortControlPageLoader.item
        if (serialPage && serialPage.focusSubArea === 1) {
            // 从参数区域返回串口列表
            serialPage.focusSubArea = 0
            serialPage.focusItemIndex = serialPage.currentSerialIndex
            console.log("✅ [导航] 串口控制：从参数区域返回列表")
            event.accepted = true
            return
        }
    }

    // ... 默认处理 ...
}
```

### Phase 3: 在 SerialPortConfigPanel 中添加焦点指示器

**目标**：显示参数区域是否有焦点

**修改文件**: SerialPortConfigPanel.qml

**添加代码**：
```qml
Rectangle {
    id: root
    color: "transparent"

    // ✅ 接收焦点状态
    property int focusSubArea: 0  // 从 SerialPortControlPage 传递

    // ✅ 焦点指示器（可选）
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (focusSubArea === 1) ? "#2196F3" : "transparent"
        border.width: (focusSubArea === 1) ? 2 : 0
        radius: 4
        z: -1
    }

    // ... 现有内容 ...
}
```

### Phase 4: 在 SerialPortControlPage 中传递 focusSubArea

**目标**：将 focusSubArea 传递给 SerialPortConfigPanel

**修改文件**: SerialPortControlPage.qml

**添加代码**：
```qml
Loader {
    id: serialConfigPanel
    Layout.fillWidth: true
    Layout.fillHeight: true
    source: "SerialPortConfigPanel.qml"

    onLoaded: {
        console.log("✅ [SerialPortControlPage] SerialPortConfigPanel 加载成功")

        // 传递属性
        item.currentSerialPort = Qt.binding(function() { return root.currentSerialPort })
        item.focusSubArea = Qt.binding(function() { return root.focusSubArea })  // ✅ 新增
    }
}
```

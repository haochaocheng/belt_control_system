## 🐛 常见问题排查

### 问题 1: 焦点指示器不显示

**可能原因**:
1. `activeFocus` 属性未正确绑定
2. 焦点函数未被调用
3. `triggerParamInput()` 未被调用

**排查步骤**:
1. 检查日志是否有 `triggerParamInput` 调用
2. 检查日志是否有 `获得焦点` 消息
3. 检查焦点指示器的 `border.color` 绑定

**解决方案**:
- 确保 `handleDirectionKey()` 调用 `triggerParamInput()`
- 确保焦点函数调用 `forceActiveFocus()`
- 确保焦点指示器绑定到 `activeFocus` 属性

### 问题 2: NavigationManager 函数不存在

**错误日志**:
```
TypeError: Property 'moveDown' of object NavigationManager is not a function
```

**解决方案**:
- 使用 `handleDirectionKey("Down")` 而不是 `moveDown()`
- 使用 `handleDirectionKey("Up")` 而不是 `moveUp()`

### 问题 3: 区域常量未定义

**错误日志**:
```
ReferenceError: areaSerialList is not defined
```

**解决方案**:
- 使用 `areaMotorList` 而不是 `areaSerialList`
- NavigationManager 定义的区域常量：`areaMotorList`, `areaTabBar`, `areaParams`, `areaButtons`

### 问题 4: 属性不存在

**错误日志**:
```
Cannot assign to non-existent property "onSerialListIndexChanged"
```

**解决方案**:
- 使用 `motorListIndex` 而不是 `serialListIndex`
- 使用 `onMotorListIndexChanged` 而不是 `onSerialListIndexChanged`

## 🐛 问题描述

用户测试反馈（第十二次测试）：
> "查看截图，这几个参数的位置，使用导航键直接切换，目前只停留在波特率上，导航键依然不能使用"

### 日志分析

从日志中看到：
1. ✅ CustomComboBox 正确传播了上下键事件
2. ✅ 右键被 DeviceSettingsDialog 接收并传递给 NavigationManager
3. ❌ **上下键没有被 NavigationManager 处理**（日志中没有看到）

**关键发现**：
- 右键日志：`[串口控制导航] 右键 - 调用 NavigationManager.handleDirectionKey`
- 上键日志：**缺失**
- 下键日志：**缺失**

---

## 🔍 根本原因

### 问题定位

DeviceSettingsDialog 的 `Keys.onUpPressed` 和 `Keys.onDownPressed` 中有串口控制的处理代码（line 220-227, 393-400），但是：

**可能的原因**：
1. 代码没有被执行（条件判断失败）
2. serialPage 或 navigationManager 为 null
3. 事件在到达这段代码之前就被拦截了

**需要添加调试信息**：
- 确认代码是否被执行
- 确认 serialPage 是否存在
- 确认 navigationManager 是否存在
- 确认 handleDirectionKey 是否被调用

} else if (currentPage.focusSubArea === 1) {

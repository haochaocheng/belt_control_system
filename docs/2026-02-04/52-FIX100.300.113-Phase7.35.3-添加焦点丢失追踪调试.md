## 🔍 问题诊断指南

### 场景 1: forceActiveFocus() 调用后焦点就是 false

**问题**：forceActiveFocus() 没有成功设置焦点

**可能原因**：
1. Text 元素不可获取焦点（focus: false 或 enabled: false）
2. Text 元素被父元素阻止获取焦点
3. Text 元素在 FocusScope 外部

**解决方案**：
1. 检查 Text 的 focus 和 enabled 属性
2. 检查 Text 的父元素是否有 FocusScope
3. 检查 Text 是否在正确的焦点链中

### 场景 2: forceActiveFocus() 调用后焦点是 true，但后续变成 false

**问题**：有其他代码抢夺了焦点

**可能原因**：
1. DeviceSettingsDialog 的某个监听器在抢夺焦点
2. ScrollView 在滚动时抢夺焦点
3. 有 Qt.callLater 或 Timer 在延迟执行某些操作

**解决方案**：
1. 检查所有 Connections 和 on*Changed 监听器
2. 检查 ScrollView 的配置
3. 搜索 Qt.callLater 和 Timer 的使用

### 场景 3: NavigationManager 返回后 focusSubArea 不是 1

**问题**：NavigationManager 没有正确设置 focusSubArea

**可能原因**：
1. switchToArea 没有触发 areaChanged 信号
2. onAreaChanged 没有正确设置 focusSubArea
3. 有其他代码在 NavigationManager 返回后修改了 focusSubArea

**解决方案**：
1. 检查 switchToArea 的实现
2. 检查 onAreaChanged 的实现
3. 检查是否有其他代码监听 focusSubArea 变化

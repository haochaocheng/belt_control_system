## 💡 技术要点

### ColumnLayout vs RowLayout

**为什么使用 ColumnLayout**:
```qml
// ❌ 错误：RowLayout 无法添加底部按钮区域
RowLayout {
    // 左侧：列表
    // 右侧：配置
    // ❌ 无法添加底部按钮
}

// ✅ 正确：ColumnLayout 可以添加底部按钮区域
ColumnLayout {
    RowLayout {
        // 左侧：列表
        // 右侧：配置
    }
    Rectangle {
        // 底部：按钮区域
    }
}
```

**效果**:
- ✅ 上部区域使用 Layout.fillHeight: true（占满剩余空间）
- ✅ 底部区域固定高度 90px
- ✅ 布局灵活，易于扩展

### 焦点指示器的实现

**为什么使用 border.width 而不是 border.color**:
```qml
// ❌ 错误：border.color 变化不明显
border.color: root.focusSubArea === 3 && root.focusButtonIndex === 0 ? "#2196F3" : "transparent"
border.width: 2

// ✅ 正确：border.width 变化明显
border.width: root.focusSubArea === 3 && root.focusButtonIndex === 0 ? 5 : 0
border.color: "#2196F3"
```

**效果**:
- ✅ 焦点时：5px 蓝色边框（清晰可见）
- ✅ 非焦点时：无边框（不影响视觉）

### 按钮背景色的动态变化

**为什么使用三元表达式**:
```qml
color: {
    if (root.focusSubArea === 3 && root.focusButtonIndex === 0) {
        return "#2ecc71"  // 焦点时：亮绿色
    } else if (parent.pressed) {
        return "#27ae60"
    } else if (parent.hovered) {
        return "#2ecc71"
    } else {
        return "#27ae60"
    }
}
```

**效果**:
- ✅ 焦点时：背景色变亮
- ✅ 按下时：背景色变暗
- ✅ 悬停时：背景色变亮
- ✅ 正常时：正常背景色

### 按钮索引的分配

**按钮索引**:
- 0: 打开串口
- 1: 关闭串口
- 2: 保存
- 3: 删除
- 4: 重置

**为什么使用连续索引**:
- ✅ 左右键导航时，索引连续递增/递减
- ✅ NavigationManager 可以正确处理边界（0 和 4）
- ✅ 焦点指示器可以正确显示

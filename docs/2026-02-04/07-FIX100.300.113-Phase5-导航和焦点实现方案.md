## 🎯 目标

实现串口控制页面的键盘导航和焦点管理功能。

---

## 📋 导航需求

### 区域划分

串口控制页面有 2 个主要区域：

1. **列表区（focusSubArea = 0）**
   - 6 个串口列表项（COM1-COM6）
   - 上下键：在列表项之间移动
   - 右键：切换到参数区

2. **参数区（focusSubArea = 1）**
   - 串口参数配置（波特率、数据位等）
   - 发送区、接收区、MODBUS 区
   - 左键：返回列表区
   - 上下键：在参数区内滚动（使用 ScrollView 的滚动功能）

---

## 🔧 实现方案

### 方案选择

**不使用 NavigationManager**（原因：串口控制比电机控制简单得多）

**使用简化的键盘导航**：
- 直接在 SerialPortControlPage 中处理 Keys.onPressed
- 使用 focusSubArea 和 focusItemIndex 管理焦点
- 列表区使用蓝色边框指示器
- 参数区使用 ScrollView 的滚动功能

## 📝 实现步骤

### Step 1: SerialPortControlPage 添加键盘导航

```qml
// SerialPortControlPage.qml

Rectangle {
    id: root
    focus: true  // ✅ 添加焦点

    // 现有属性
    property int currentSerialIndex: 0
    property int focusItemIndex: -1
    property int focusSubArea: 0  // 0:列表 1:参数

    // ========== 键盘导航 ==========
    Keys.onUpPressed: {
        if (focusSubArea === 0) {
            // 列表区：向上移动
            if (focusItemIndex > 0) {
                focusItemIndex--
                currentSerialIndex = focusItemIndex
            }
        }
        event.accepted = true
    }

    Keys.onDownPressed: {
        if (focusSubArea === 0) {
            // 列表区：向下移动
            if (focusItemIndex < serialPorts.length - 1) {
                focusItemIndex++
                currentSerialIndex = focusItemIndex
            }
        }
        event.accepted = true
    }

    Keys.onLeftPressed: {
        if (focusSubArea === 1) {
            // 从参数区返回列表区
            focusSubArea = 0
            focusItemIndex = currentSerialIndex
        }
        event.accepted = true
    }

    Keys.onRightPressed: {
        if (focusSubArea === 0) {
            // 从列表区进入参数区
            focusSubArea = 1
            focusItemIndex = -1
        }
        event.accepted = true
    }

    // ========== 初始化焦点 ==========
    Component.onCompleted: {
        focusSubArea = 0
        focusItemIndex = 0
        root.forceActiveFocus()
    }
}
```

参数区已经有 ScrollView，不需要额外处理。当 focusSubArea === 1 时，用户可以：
- 使用鼠标滚轮滚动
- 使用触摸板滚动
- 使用滚动条滚动

## 🎨 焦点指示器样式

### 列表区焦点

```qml
Rectangle {
    // 蓝色边框
    border.width: (focusSubArea === 0 && focusItemIndex === index) ? 3 : 0
    border.color: "#2196F3"

    // 背景高亮
    color: (focusSubArea === 0 && focusItemIndex === index) ? "#34495e" : "transparent"
}
```

### 参数区焦点

参数区不需要特殊的焦点指示器，因为：
1. 用户通过左右键切换区域
2. 参数区使用 ScrollView 滚动查看内容
3. 输入框有自己的焦点边框（已实现）

## 🔄 焦点流程

### 初始状态
```
focusSubArea = 0 (列表区)
focusItemIndex = 0 (COM1)
```

### 用户操作流程

1. **上下键**（列表区）
   ```
   Down → focusItemIndex++, currentSerialIndex++
   Up   → focusItemIndex--, currentSerialIndex--
   ```

2. **右键**（进入参数区）
   ```
   Right → focusSubArea = 1, focusItemIndex = -1
   ```

3. **左键**（返回列表区）
   ```
   Left → focusSubArea = 0, focusItemIndex = currentSerialIndex
   ```

4. **鼠标点击**（列表项）
   ```
   Click → currentSerialIndex = index
           focusSubArea = 0
           focusItemIndex = index
   ```

## 📊 与 MotorControlPage 的对比

| 特性 | MotorControlPage | SerialPortControlPage |
|------|------------------|----------------------|
| 区域数量 | 4个（列表、Tab、参数、按钮） | 2个（列表、参数） |
| 导航管理器 | NavigationManager | 无（直接处理） |
| Tab 切换 | 有 | 无 |
| 参数焦点 | 逐个参数字段 | 整体滚动 |
| 按钮焦点 | 5个按钮 | 无（按钮在各区域内） |
| 复杂度 | 高 | 低 |

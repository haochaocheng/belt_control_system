## 🔍 根本原因

### 焦点指示器的z值设置错误

**当前代码**（SerialPortParamsSection.qml）：

**串口名称**（line 143-151）：
```qml
Text {
    id: serialNameText
    // ...

    Rectangle {
        anchors.fill: parent
        anchors.margins: -4
        color: "transparent"
        border.color: parent.activeFocus ? "#2196F3" : "transparent"
        border.width: parent.activeFocus ? 3 : 0
        radius: 4
        z: -1  // ❌ 负值！边框在Text下面，被Text遮挡
    }
}
```

**设备路径**（line 244-252）：
```qml
Text {
    id: devicePathText
    // ...

    Rectangle {
        anchors.fill: parent
        anchors.margins: -4
        color: "transparent"
        border.color: parent.activeFocus ? "#2196F3" : "transparent"
        border.width: parent.activeFocus ? 3 : 0
        radius: 4
        z: -1  // ❌ 负值！边框在Text下面，被Text遮挡
    }
}
```

**串口类型**（line 341-349）：
```qml
Text {
    id: serialTypeText
    // ...

    Rectangle {
        anchors.fill: parent
        anchors.margins: -4
        color: "transparent"
        border.color: parent.activeFocus ? "#2196F3" : "transparent"
        border.width: parent.activeFocus ? 3 : 0
        radius: 4
        z: -1  // ❌ 负值！边框在Text下面，被Text遮挡
    }
}
```

**问题**：
- 焦点指示器Rectangle的z值是-1（负值）
- 这会让边框在Text的**下面**
- Text会遮挡边框，导致边框不可见

**对比：状态指示器**（line 482-490）：
```qml
Rectangle {
    anchors.fill: parent
    anchors.margins: -4
    color: "transparent"
    border.color: statusText.activeFocus ? "#2196F3" : "transparent"
    border.width: statusText.activeFocus ? 3 : 0
    radius: 4
    z: 10  // ✅ 正值！边框在Row上面
}
```

状态指示器的z值是10，所以边框可见。

## 💡 为什么之前没有发现这个问题？

### 错误的假设

**我之前的假设**：
- 焦点指示器Rectangle在Text内部，作为Text的子元素
- 使用z: -1让边框在Text的背景层
- 以为这样可以让边框在Text文字的下面，但在Text背景的上面

**实际情况**：
- Text没有背景色（color: "transparent"）
- z: -1会让Rectangle在Text的**整个渲染层**下面
- Text的文字和边框都会遮挡Rectangle
- 导致焦点边框完全不可见

**正确的做法**：
- 使用z: 10（正值）让Rectangle在Text的上面
- Rectangle的color是"transparent"，不会遮挡Text文字
- 只有border会显示，形成焦点边框

## 📝 经验教训

### 1. z值的正确使用

**错误理解**：
- 以为z: -1可以让边框在Text背景层
- 忽略了Text没有背景色

**正确理解**：
- z值决定渲染顺序
- 负值会让元素在父元素的下面
- 正值会让元素在父元素的上面
- 透明背景的Rectangle不会遮挡内容，只显示边框

### 2. 焦点指示器的标准实现

**标准模式**：
```qml
Item {
    SomeControl {
        id: control
        anchors.fill: parent
        focus: true
        activeFocusOnTab: true
    }

    Rectangle {
        anchors.fill: parent
        anchors.margins: -4
        color: "transparent"
        border.color: control.activeFocus ? "#2196F3" : "transparent"
        border.width: control.activeFocus ? 3 : 0
        radius: 4
        z: 10  // ✅ 正值
    }
}
```

**关键点**：
- 焦点指示器在Item层面，不在控件内部
- 使用正值z值（10或更高）
- 使用anchors.margins: -4让边框在外部
- color: "transparent"不遮挡内容

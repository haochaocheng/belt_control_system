    switch(index) {
    case 0:  // 波特率

            serialConfigPanel.item.paramsSection.item.focusBaudRate()
        }
        break
    // ... cases 1-12 for other parameters

}

## 🎨 统一的代码模式

### 1. 焦点函数模式

```qml
function focus[控件名称]() {
    [控件ID].forceActiveFocus()
    console.log("✅ [Section名称] [控件名称]获得焦点")
}
```

### 2. 焦点指示器模式

```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: [控件ID].activeFocus ? "#2196F3" : "transparent"
    border.width: [控件ID].activeFocus ? 3 : 0
    radius: 4
    z: 10
}
```

### 3. 控件包装模式

```qml
Item {
    Layout.preferredWidth: 120
    implicitHeight: [控件ID].implicitHeight

    DeviceInfo.Custom[控件类型] {
        id: [控件ID]
        anchors.fill: parent
        // ... 控件属性 ...
    }

    // 焦点指示器
    Rectangle { ... }
}
```

## 🔄 导航流程

### 三层导航架构

```
串口列表（focusSubArea = 0）
    ↓ 右键
参数区域（focusSubArea = 1）
    索引0 → 索引1 → ... → 索引12
    ↓ 下键（到达底部）
按钮区域（focusSubArea = 2）
```

### NavigationManager 工作流程

1. **用户按下键**:
   - DeviceSettingsDialog 检测到串口控制页面
   - 调用 `navigationManager.moveDown()` 或 `moveUp()`

2. **NavigationManager 处理**:
   - 更新 `paramIndex` 属性
   - 通过信号同步到 `focusParamIndex`
   - 调用 `triggerParamInput(paramIndex)`

3. **SerialPortControlPage 处理**:
   - `triggerParamInput()` 根据索引调用对应 Section 的 focus 函数
   - 例如：`serialConfigPanel.item.paramsSection.item.focusBaudRate()`

4. **Section 处理**:
   - focus 函数调用 `forceActiveFocus()`
   - 控件获得焦点，`activeFocus` 变为 true

5. **焦点指示器显示**:
   - Rectangle 的 `border.color` 绑定到 `activeFocus`
   - 显示蓝色边框（#2196F3, 3px）

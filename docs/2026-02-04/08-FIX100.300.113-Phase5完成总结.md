## ✅ 完成内容

### 1. SerialPortControlPage 键盘导航

**添加的功能**：
- ✅ 上下键：在列表区移动焦点
- ✅ 左键：从参数区返回列表区，或从列表区返回类别
- ✅ 右键：从列表区进入参数区
- ✅ 焦点初始化：启动时焦点在列表区第一项
- ✅ 焦点同步：focusItemIndex 变化时同步更新 currentSerialIndex

**关键代码**：
```qml
Rectangle {
    id: root
    focus: true  // ✅ 添加焦点支持

    property int focusItemIndex: -1
    property int focusSubArea: 0  // 0:列表 1:参数

    // ✅ 监听焦点变化
    onFocusItemIndexChanged: {
        if (focusSubArea === 0 && focusItemIndex >= 0) {
            currentSerialIndex = focusItemIndex
        }
    }

    // ✅ 键盘导航
    Keys.onUpPressed: { /* 列表区向上 */ }
    Keys.onDownPressed: { /* 列表区向下 */ }
    Keys.onLeftPressed: { /* 返回列表区或类别 */ }
    Keys.onRightPressed: { /* 进入参数区 */ }

    Component.onCompleted: {
        focusSubArea = 0
        focusItemIndex = 0
        root.forceActiveFocus()
    }
}
```

## 🎨 导航流程

### 初始状态
```
focusSubArea = 0 (列表区)
focusItemIndex = 0 (COM1)
currentSerialIndex = 0
```

### 键盘导航

#### 1. 列表区导航（focusSubArea = 0）

**上键**：
```
focusItemIndex--  (如果 > 0)
→ currentSerialIndex 自动同步
→ 显示蓝色边框在上一项
```

**下键**：
```
focusItemIndex++  (如果 < 5)
→ currentSerialIndex 自动同步
→ 显示蓝色边框在下一项
```

**左键**：
```
→ 发射 requestReturnToCategory() 信号
→ 返回到左侧类别列表
```

**右键**：
```
focusSubArea = 1
focusItemIndex = -1
→ 进入参数区
→ 蓝色边框消失
```

#### 2. 参数区导航（focusSubArea = 1）

**左键**：
```
focusSubArea = 0
focusItemIndex = currentSerialIndex
→ 返回列表区
→ 显示蓝色边框在当前选中项
```

**上下键**：
```
→ 参数区使用 ScrollView 滚动
→ 不处理（event.accepted = true）
```

### 鼠标点击

**点击列表项**：
```
currentSerialIndex = index
focusItemIndex = index
focusSubArea = 0
→ 选中项背景高亮
→ 显示蓝色边框
→ 恢复键盘焦点
```

## 🔄 导航示例

### 场景1：键盘导航

```
初始状态：
  focusSubArea = 0, focusItemIndex = 0 (COM1)

按下键 ↓：
  focusItemIndex = 1 (COM2)
  currentSerialIndex = 1
  → 蓝色边框移动到 COM2

按右键 →：
  focusSubArea = 1
  focusItemIndex = -1
  → 进入参数区，蓝色边框消失

按左键 ←：
  focusSubArea = 0
  focusItemIndex = 1 (COM2)
  → 返回列表区，蓝色边框显示在 COM2
```

### 场景2：鼠标点击

```
初始状态：
  focusSubArea = 0, focusItemIndex = 0 (COM1)

鼠标点击 COM4：
  currentSerialIndex = 3
  focusItemIndex = 3
  focusSubArea = 0
  → 蓝色边框移动到 COM4
  → 背景高亮 COM4
  → 恢复键盘焦点

按下键 ↓：
  focusItemIndex = 4 (COM5)
  → 蓝色边框移动到 COM5
```

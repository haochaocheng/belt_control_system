# FIX 100.300.113 Phase 7.33 - 修复状态焦点指示器警告

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 7.33
**状态**: ✅ 完成

---

## 🐛 问题描述

用户测试反馈（第十六次测试）：
> "当焦点在COM1时，下键应该时焦点应该移动到设备路径，实际焦点不知道在哪里，看不到蓝色边框，而且界面滑动一下"

### 日志分析

从 `docs/log/pjsip.md` 的日志（line 132, 188, 281）看到重复的警告：

```
Warning: file:///E:/2025/3_gongkongji/belt_control_system/src/qml/components/device_info/pages/SerialPortParamsSection.qml:474:17: QML Row: Cannot specify left, right, horizontalCenter, fill or centerIn anchors for items inside Row. Row will not function.
```

**问题定位**：
- 警告指向 SerialPortParamsSection.qml line 474（状态指示器的Row）
- 焦点指示器Rectangle使用了`anchors.centerIn: parent`
- 但parent是Row，Row内部的元素不能使用anchor定位
- 这导致焦点指示器无法正常显示

---

## 🔍 根本原因

### 错误的焦点指示器位置

**当前代码**（SerialPortParamsSection.qml line 474-509）：

```qml
Row {
    id: statusText
    anchors.verticalCenter: parent.verticalCenter
    spacing: 8

    focus: true
    activeFocusOnTab: true

    Rectangle {
        width: 12
        height: 12
        radius: 6
        color: "#9E9E9E"
        anchors.verticalCenter: parent.verticalCenter
    }

    Text {
        text: "已关闭"
        font.pixelSize: 21
        color: "#9E9E9E"
        anchors.verticalCenter: parent.verticalCenter
    }

    // ❌ 焦点指示器在Row内部
    Rectangle {
        anchors.centerIn: parent  // ❌ Row内部不能使用anchor定位
        width: parent.width + 8
        height: 40
        color: "transparent"
        border.color: parent.activeFocus ? "#2196F3" : "transparent"
        border.width: parent.activeFocus ? 3 : 0
        radius: 4
        z: -1
    }
}
```

**问题**：
1. 焦点指示器Rectangle在Row内部
2. 使用了`anchors.centerIn: parent`，但Row内部的元素不能使用anchor定位
3. 导致QML警告，焦点指示器无法正常显示

---

## ✅ 解决方案

### 将焦点指示器移到Item外部

**修改位置**：SerialPortParamsSection.qml line 466-509

**修改前**：
```qml
Item {
    Layout.column: 3
    Layout.row: 3
    Layout.fillWidth: true
    Layout.maximumWidth: 300
    Layout.preferredHeight: 40

    Row {
        id: statusText
        anchors.verticalCenter: parent.verticalCenter
        spacing: 8

        focus: true
        activeFocusOnTab: true

        Rectangle { /* 状态圆点 */ }
        Text { /* 状态文字 */ }

        // ❌ 焦点指示器在Row内部
        Rectangle {
            anchors.centerIn: parent  // ❌ 导致警告
            width: parent.width + 8
            height: 40
            color: "transparent"
            border.color: parent.activeFocus ? "#2196F3" : "transparent"
            border.width: parent.activeFocus ? 3 : 0
            radius: 4
            z: -1
        }
    }
}
```

**修改后**：
```qml
Item {
    Layout.column: 3
    Layout.row: 3
    Layout.fillWidth: true
    Layout.maximumWidth: 300
    Layout.preferredHeight: 40

    Row {
        id: statusText
        anchors.verticalCenter: parent.verticalCenter
        spacing: 8

        focus: true
        activeFocusOnTab: true

        Rectangle { /* 状态圆点 */ }
        Text { /* 状态文字 */ }
    }

    // ✅ 焦点指示器在Item外部
    Rectangle {
        anchors.fill: parent
        anchors.margins: -4
        color: "transparent"
        border.color: statusText.activeFocus ? "#2196F3" : "transparent"
        border.width: statusText.activeFocus ? 3 : 0
        radius: 4
        z: 10
    }
}
```

**关键改进**：
1. ✅ 焦点指示器移到Item外部（和其他字段一致）
2. ✅ 使用`anchors.fill: parent`填充整个Item
3. ✅ 使用`anchors.margins: -4`让边框在外部
4. ✅ 使用`statusText.activeFocus`检测焦点状态
5. ✅ z值设置为10，确保边框在上层

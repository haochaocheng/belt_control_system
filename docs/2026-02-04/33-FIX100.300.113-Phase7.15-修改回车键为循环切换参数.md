## 🔍 当前问题

在 Phase 7.14 中，我修改了 CustomComboBox 的键盘行为：
- 上下左右键：不处理，让父组件处理导航 ✅

**问题**：
- 用户希望回车键直接切换参数值，而不是打开下拉列表

- 不符合开关量输入页面的使用习惯

### 修改内容

**文件**: CustomComboBox.qml

**修改 1**: Keys.onReturnPressed（line 167-185）

**修改前**:
```qml
// 回车键：打开下拉列表（不可编辑）或虚拟键盘（可编辑）
Keys.onReturnPressed: {
    if (root.editable) {
        // 可编辑：打开虚拟键盘
        if (keyboardManager && root.enabled) {
            keyboardManager.openKeyboardForField(root, false)
            event.accepted = true
        }
    } else {
        // 不可编辑：打开下拉列表
        if (root.enabled && !root.popup.visible) {
            root.popup.open()
            event.accepted = true
        }
    }
}
```

**修改后**:
```qml
// ✅ 2026-02-04 [FIX 100.300.113 Phase 7.15]: 回车键循环切换参数值
// 用户反馈：直接按回车键切换参数，不需要下拉列表
// 参考：开关量输入页面的行为
Keys.onReturnPressed: {
    if (root.editable) {
        // 可编辑：打开虚拟键盘
        if (keyboardManager && root.enabled) {
            keyboardManager.openKeyboardForField(root, false)
            event.accepted = true
        }
    } else {
        // 不可编辑：循环切换参数值（0 → 1 → 2 → ... → count-1 → 0）
        if (root.enabled && root.count > 0) {
            root.currentIndex = (root.currentIndex + 1) % root.count
            console.log("✅ [CustomComboBox] 回车键切换参数:", root.currentIndex, "/", root.count)
            event.accepted = true
        }
    }
}
```

## 💡 工作原理

### 循环切换算法

```qml
root.currentIndex = (root.currentIndex + 1) % root.count
```

**示例**（假设有4个选项）:
- 当前索引 0 → 按回车 → 索引 1
- 当前索引 1 → 按回车 → 索引 2
- 当前索引 2 → 按回车 → 索引 3
- 当前索引 3 → 按回车 → 索引 0（循环）

### 适用场景

**不可编辑 ComboBox**（如波特率、数据位、停止位、校验位）:
- 回车键：循环切换参数值
- Space键：循环切换参数值
- 上下左右键：导航到其他参数

**可编辑 ComboBox**（如自定义输入）:
- 回车键：打开虚拟键盘
- Space键：打开虚拟键盘
- 上下左右键：导航到其他参数

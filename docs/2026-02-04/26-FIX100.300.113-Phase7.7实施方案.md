## 🎯 目标

修改 DeviceSettingsDialog.qml，使串口控制页面的参数区域使用 NavigationManager 进行导航（方案C），而不是直接赋值 focusParamIndex。

---

## 📋 当前问题

**方案B的实现**（需要移除）:
- 参数区域（focusSubArea === 1）直接赋值 `currentPage.focusParamIndex`
- 按钮区域（focusSubArea === 2）直接赋值 `currentPage.focusButtonIndex`
- 这导致 NavigationManager 的状态与实际焦点不同步

**日志证据**:
```

QML DeviceSettingsDialog: ⚠️ [导航] 未知属性: focusButtonIndex
```

### 1. Keys.onDownPressed 修改

**位置**: DeviceSettingsDialog.qml, line 371-417

**当前代码**（方案B）:
```qml
} else if (currentPage.focusSubArea === 1) {
    // 参数区域：直接赋值 focusParamIndex
    var currentIndex = currentPage.focusParamIndex
    var paramCount = currentPage.getParamFieldCount()

    if (layoutMode === "single-column") {
        if (currentIndex < paramCount - 1) {
            currentPage.focusParamIndex = currentIndex + 1  // ❌ 直接赋值

        var nextIndex = currentIndex + 2

            currentPage.focusParamIndex = nextIndex  // ❌ 直接赋值

            currentPage.focusSubArea = 2  // ❌ 直接赋值
            currentPage.focusButtonIndex = ...  // ❌ 直接赋值
        }
    }
}
```

**修改后**（方案C）:
```qml
} else if (currentPage.focusSubArea === 1) {

            currentPage.focusParamIndex = currentIndex + 1

        if (nextIndex < paramCount) {
            currentPage.focusParamIndex = nextIndex
        } else {
            currentPage.focusSubArea = 2
```

## 💡 关键要点

### 1. 只修改串口控制页面

```qml
if (currentCategory === 6) {
    // 串口控制特殊处理
    var serialPage = serialPortControlPageLoader.item
    if (serialPage && serialPage.navigationManager) {
        serialPage.navigationManager.moveDown()
        event.accepted = true
        return
    }
}
// 其他页面继续原有逻辑
```

### 2. 使用 NavigationManager

- `navigationManager.moveDown()` - 向下移动焦点
- `navigationManager.moveUp()` - 向上移动焦点
- NavigationManager 会自动处理：
  - 参数索引更新
  - 焦点指示器显示
  - 区域切换（参数→按钮）
  - 调用 triggerParamInput()

### 3. 保持其他页面不变

- 电机控制页面（currentCategory === 3）已经使用 NavigationManager
- 其他页面（基本配置、开关输入等）继续使用直接赋值方式
- 不影响现有功能

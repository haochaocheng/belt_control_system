这些警告指向：
- Line 151: `Keys.onUpPressed`
- Line 155: `Keys.onDownPressed`
- Line 159: `Keys.onLeftPressed`

---

## 🔍 根本原因

在 Phase 7.14 中，我使用了旧的 QML 语法：

```qml
Keys.onUpPressed: {
    event.accepted = false
}
```

**问题**：
- Qt 6 不推荐这种隐式参数注入的语法
- 警告提示 "Injection of parameters into signal handlers is deprecated"
- 可能导致 `event.accepted = false` 不生效
- 结果：上下键还是被 ComboBox 拦截，导致修改参数值

**Qt 6 推荐语法**：

```qml
Keys.onUpPressed: function(event) {
    event.accepted = false
}
```

## 💡 Qt 6 键盘处理器语法

### 旧语法（Qt 5，已弃用）

```qml
Keys.onPressed: {
    // event 参数隐式注入
    if (event.key === Qt.Key_Enter) {
        // ...
    }
}
```

**问题**：
- 参数隐式注入，不明确
- Qt 6 中已弃用
- 可能导致参数不可用

### 新语法（Qt 6，推荐）

```qml
Keys.onPressed: function(event) {
    // event 参数显式声明
    if (event.key === Qt.Key_Enter) {
        // ...
    }
}
```

**优点**：
- 参数显式声明，清晰明确
- Qt 6 推荐语法
- 确保参数可用

## 🔍 问题现象总结

### 核心问题
1. **焦点设置成功但立即丢失**：
   - `forceActiveFocus()` 成功设置焦点（activeFocus: true）
   - 但焦点在几毫秒内丢失（activeFocus: false）
   - 焦点指示器闪烁不可见（蓝色边框出现后立即消失）

2. **界面自动滚动**：
   - 用户按右键进入参数区域
   - 界面向上滚动一次
   - contentY 从 0 变化到 1182
   - 滚动过程中焦点丢失

3. **焦点循环丢失和恢复**：
   - 焦点获得 → 丢失 → 恢复 → 再次丢失
   - 形成循环，用户无法看到稳定的焦点指示器

### 用户提供的关键线索
1. **"按下键参数区域向上滑动一次，按一次滑动一次"** - 说明滚动与焦点设置相关
2. **"电机配置界面也使用滚动，但是没有问题，那个只有弹窗虚拟键盘，界面才会滚动"** - 说明问题不是 ScrollView 本身

## 🔍 已尝试的解决方案

### 1. 禁用 root.focus（Phase 7.35.5）
- **方法**：设置 `dialog.focus = false`
- **结果**：❌ 无效，焦点仍然丢失
- **原因**：root.focus 不是焦点丢失的原因

### 2. Qt.callLater 恢复焦点（Phase 7.35.6）
- **方法**：在事件循环完成后检查焦点，如果丢失则重新设置
- **结果**：✅ 可以恢复焦点，❌ 但会再次丢失
- **原因**：治标不治本，没有解决根本原因

### 3. 禁用 ScrollView 交互（Phase 7.35.8）
- **方法**：设置 `scrollView.contentItem.interactive = false`
- **结果**：❌ 无效，ScrollView 仍然滚动
- **原因**：interactive 只控制用户交互滚动，不控制程序化自动滚动

### 4. 手动滚动到顶部（Phase 7.35.9）
- **方法**：在设置焦点前，设置 `scrollView.contentItem.contentY = 0`
- **结果**：❌ 无效，ScrollView 仍然滚动
- **原因**：Qt 的自动滚动机制在焦点设置后仍然触发

### 5. 禁用键盘事件（Phase 7.35.10）
- **方法**：设置 `Keys.enabled: false`
- **结果**：❌ 无效，ScrollView 仍然滚动
- **原因**：Keys.enabled 不影响虚拟键盘系统的滚动行为

## 🤔 可能的根本原因

### 假设 1: Text 元素不适合作为焦点元素

**问题**：
- Text 元素是只读的，主要用于显示文本
- Text 元素获得焦点时，Qt 可能会触发一些默认行为
- 这些默认行为可能包括滚动、输入法激活等

**验证方法**：
- 检查 MotorControlPage 的焦点元素类型
- 如果 MotorControlPage 使用 TextField 或 ComboBox，说明 Text 不适合

### 假设 2: ScrollView 的 clip: true 导致焦点丢失

**问题**：
- `clip: true` 会裁剪超出可见区域的内容
- 当 ScrollView 滚动时，焦点元素可能被裁剪
- 裁剪可能导致焦点丢失

**验证方法**：
- 检查 MotorControlPage 的 ScrollView 是否有 `clip: true`
- 尝试设置 `clip: false` 测试

### 假设 3: 焦点元素的位置导致自动滚动

**问题**：
- serialNameText 是 SerialPortParamsSection 的第一个元素
- 但 SerialPortParamsSection 是 ScrollView 的第一个子区域
- 可能 Qt 认为焦点元素不在可见区域内（因为有其他区域在下面）
- 触发自动滚动到底部

**验证方法**：
- 检查 serialNameText 的实际位置（y 坐标）
- 检查 ScrollView 的可见区域范围
- 计算焦点元素是否真的在可见区域内

### 假设 4: NavigationManager 或其他组件在抢夺焦点

**问题**：
- NavigationManager 返回后，可能有其他代码继续执行
- 这些代码可能调用了 forceActiveFocus() 到其他元素
- 导致焦点从 serialNameText 转移

**验证方法**：
- 搜索所有调用 forceActiveFocus() 的地方
- 检查是否有 Connections 或 Timer 在监听焦点相关属性
- 检查是否有 Qt.callLater 在延迟执行某些操作

## 📋 焦点函数统一模式

所有焦点函数遵循统一模式：

```qml
function focus[控件名称]() {
    [控件ID].forceActiveFocus()
    console.log("✅ [Section名称] [控件名称]获得焦点")
}
```

**示例**:
```qml
function focusBaudRate() {
    baudRateCombo.forceActiveFocus()
    console.log("✅ [SerialPortParamsSection] 波特率获得焦点")
}
```

---

## 🎨 焦点指示器统一样式

所有焦点指示器遵循统一样式：

```qml
Rectangle {
    anchors.fill: parent
    color: "transparent"
    border.color: [控件ID].activeFocus ? "#2196F3" : "transparent"
    border.width: [控件ID].activeFocus ? 3 : 0
    radius: 4
    z: 10  // 确保在最上层
}
```

**特点**:
- 蓝色边框：#2196F3
- 边框宽度：3px
- 圆角：4px
- z-index：10（确保在最上层）

## 🔧 控件包装模式

所有输入控件都需要包装在 Item 容器中，以便添加焦点指示器：

**TextField/ComboBox/SpinBox 包装模式**:
```qml
Item {
    Layout.preferredWidth: 120
    implicitHeight: [控件ID].implicitHeight

    DeviceInfo.Custom[控件类型] {
        id: [控件ID]
        anchors.fill: parent
        // ... 控件属性 ...
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: [控件ID].activeFocus ? "#2196F3" : "transparent"
        border.width: [控件ID].activeFocus ? 3 : 0
        radius: 4
        z: 10
    }
}
```

**ListView 包装模式**:
```qml
Item {
    Layout.fillWidth: true
    Layout.fillHeight: true

    ScrollView {
        anchors.fill: parent
        clip: true

        ListView {
            id: registerListView
            // ... ListView 属性 ...
        }
    }

    // 焦点指示器
    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: registerListView.activeFocus ? "#2196F3" : "transparent"
        border.width: registerListView.activeFocus ? 3 : 0
        radius: 4
        z: 10
    }
}
```

    if (!serialConfigPanel.item) {

        return
    }

    switch(index) {
    case 0:  // 波特率
        if (serialConfigPanel.item.paramsSection.item) {
            serialConfigPanel.item.paramsSection.item.focusBaudRate()
        }
        break
    // ... cases 1-12 ...
    }
}

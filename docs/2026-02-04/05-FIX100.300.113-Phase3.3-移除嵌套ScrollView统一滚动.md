# FIX 100.300.113 Phase 3.3 - 移除嵌套 ScrollView 统一滚动

**日期**: 2026-02-04
**任务编号**: FIX 100.300.113 Phase 3.3
**状态**: ✅ 完成

---

## 🎯 问题描述

用户反馈：
> "怎么会有多个滑动区，右侧整个区域只需要一个滑动就行了。"

**问题分析**：
- 外层：SerialPortConfigPanel 有一个 ScrollView（整体滚动）
- 内层：SerialPortSendSection 有一个 ScrollView（发送区滚动）
- 内层：SerialPortReceiveSection 有一个 ScrollView（接收区滚动）

导致了**嵌套的滚动条**，用户体验不好。

---

## 🔍 问题根源

### 嵌套 ScrollView 结构

```
SerialPortConfigPanel
└── ScrollView (外层滚动条)
    └── ColumnLayout
        ├── SerialPortParamsSection
        ├── SerialPortSendSection
        │   └── ScrollView (内层滚动条 ❌)
        │       └── TextArea
        ├── SerialPortReceiveSection
        │   └── ScrollView (内层滚动条 ❌)
        │       └── TextArea
        └── ModbusRegisterSection
```

**问题**：
1. 用户看到多个滚动条
2. 滚动行为混乱（不知道滚动哪个区域）
3. 内层 ScrollView 占用额外空间

---

## ✅ 解决方案

### 1. 移除内层 ScrollView

只保留外层的 ScrollView，移除发送区和接收区的内部 ScrollView。

### 2. 使用固定高度的 TextArea

让 TextArea 直接显示，使用固定高度，不需要内部滚动。

### 3. 调整各区域高度

| 区域 | 旧高度 | 新高度 | 说明 |
|------|--------|--------|------|
| 参数配置区 | 300px | 300px | 不变 |
| 发送区 | 250px | **230px** | 移除内部 ScrollView 后减少 |
| 接收区 | 280px | **260px** | 移除内部 ScrollView 后减少 |
| MODBUS区 | 600px | 600px | 不变 |

---

## 📝 修改内容

### 1. SerialPortSendSection.qml

#### 修改前（有内部 ScrollView）

```qml
// ========== 发送数据输入框 ==========
ScrollView {  // ❌ 内层滚动条
    Layout.fillWidth: true
    Layout.fillHeight: true
    clip: true

    TextArea {
        id: sendInput
        wrapMode: TextArea.Wrap
        font.family: "Consolas"
        font.pixelSize: 14
        color: "#E0E0E0"
        placeholderText: "输入要发送的数据..."
        // ...
    }
}
```

#### 修改后（移除 ScrollView）

```qml
// ========== 发送数据输入框 ==========
// ✅ 2026-02-04: 移除内部 ScrollView，使用固定高度的 TextArea
TextArea {
    id: sendInput
    Layout.fillWidth: true
    Layout.preferredHeight: 150  // ✅ 固定高度
    wrapMode: TextArea.Wrap
    font.family: "Consolas"
    font.pixelSize: 14
    color: "#E0E0E0"
    placeholderText: "输入要发送的数据..."
    // ...
}
```

#### 调整 Loader 高度

## 🎨 最终结构

### 统一滚动结构

```
SerialPortConfigPanel
└── ScrollView (唯一的滚动条 ✅)
    └── ColumnLayout
        ├── SerialPortParamsSection (300px)
        ├── SerialPortSendSection (230px)
        │   └── TextArea (150px 固定高度)
        ├── SerialPortReceiveSection (260px)
        │   └── TextArea (180px 固定高度)
        └── ModbusRegisterSection (600px)
```

**改进**：
- ✅ 只有一个滚动条（外层）
- ✅ 滚动行为统一
- ✅ 用户体验更好
- ✅ 布局更简洁

## 📊 高度分配

### 各区域高度明细

| 区域 | Loader 高度 | 内容高度 | 说明 |
|------|------------|----------|------|
| 参数配置区 | 300px | ~280px | GridLayout 4列布局 |
| 发送区 | 230px | 150px (TextArea) + 80px (标题+按钮) | 固定高度输入框 |
| 接收区 | 260px | 180px (TextArea) + 80px (标题+按钮) | 固定高度显示区 |
| MODBUS区 | 600px | ~580px | 参数输入 + 寄存器列表 |

**总高度**：300 + 230 + 260 + 600 = **1390px**

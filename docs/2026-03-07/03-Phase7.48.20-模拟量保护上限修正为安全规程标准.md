# Phase 7.48.20 — 模拟量保护上限修正为煤矿安全规程标准

**日期**：2026-03-07
**阶段**：Phase 7.48.20
**类型**：BUG修复 + 参数优化

---

## 一、问题描述

### 1.1 根本原因

13项模拟量保护的 `upper_limit`（报警上限）等于传感器量程满量程值 `lower_limit + range_value`，导致：

- 工程量计算公式：`engineeringValue = lowerLimit + (adValue / 65535.0) × rangeValue`
- 当 `upper_limit = lowerLimit + rangeValue` 时，只有 `adValue = 65535`（传感器满量程）才能触发报警
- 实际场景中传感器几乎不可能精确达到满量程值
- **结果：13项保护的报警永远无法触发**

### 1.2 受影响的5项（无此问题）

| 保护 | 上限 | 量程最大值 | 状态 |
|------|------|-----------|------|
| 速度 | 3.0 | 5.5 | ✅ 正常 |
| 张力 | 8.0 | 23.0 | ✅ 正常 |
| 温度一 | 42.0 | 100.0 | ✅ 正常 |
| 温度二 | 42.0 | 100.0 | ✅ 正常 |
| 电压 | 700.0 | 1160.0 | ✅ 正常 |

## 二、修正方案

### 2.1 危害气体监测（7项）— 依据煤矿安全规程

| 保护 | 旧上限 | **新上限** | 法规依据 |
|------|--------|-----------|---------|
| 甲烷 | 4.0 %CH₄ | **1.0** | 《煤矿安全规程》第一百条：采区回风巷≥1.0%报警 |
| 一氧化碳 | 1000.0 ppm | **24.0** | 《煤矿安全规程》第一百条附表：MAC≥24ppm |
| 二氧化碳 | 5.0 %CO₂ | **1.5** | 《煤矿安全规程》第一百条：进风流>1.5%报警 |
| 硫化氢 | 100.0 ppm | **6.6** | 《煤矿安全规程》第一百条附表：MAC≥6.6ppm |
| 氧气 | 25.0 %O₂ | **23.5** | GB/T 50493-2019：>23.5%富氧报警 |
| 烟雾 | 1000.0 mg/m³ | **100.0** | 烟雾传感器典型报警值 |
| 粉尘浓度 | 1000.0 mg/m³ | **4.0** | GBZ 2.1-2019：煤尘总尘>4mg/m³ |

### 2.2 环境监测（6项）

| 保护 | 旧上限 | **新上限** | 依据 |
|------|--------|-----------|------|
| 温度(环境) | 50.0 ℃ | **34.0** | 《煤矿安全规程》第102条：机电硐室>34℃停工 |
| 湿度 | 100.0 %RH | **95.0** | 高湿预警值 |
| 煤流 | 2000.0 t/h | **1500.0** | 额定500的3倍预警 |
| 煤仓高度 | 30.0 m | **25.0** | 接近满仓预警 |
| 气压 | 120.0 kPa | **110.0** | 正常大气压上限 |
| 风速 | 15.0 m/s | **4.0** | 《煤矿安全规程》通风章节：采煤工作面>4m/s |

## 三、代码修改

### 3.1 修改文件

**`src/control/DeviceConfigManager.cpp`**

| 修改位置 | 说明 |
|---------|------|
| `initDefaultAnalogProtections()` 第1251-1291行 | 13项保护的 upperLimit 值更新 |
| migration 010 第1000-1014行 | reviewedProtections 列表上限值同步更新 |
| migration 011（新增） | 对已执行过 migration 010 的设备，UPDATE 更新上限值 |

### 3.2 Migration 011 策略

```sql
-- 只更新上限值仍为旧值（满量程）的记录
-- 保护用户已手动修改的值
UPDATE device_analog_protections
SET upper_limit = ?
WHERE protection_name = ? AND upper_limit = ?
```

- 用 `WHERE upper_limit = 旧值` 条件匹配，确保不覆盖用户已手动调整的值
- 全量更新13项 × 12台设备 = 最多156条记录

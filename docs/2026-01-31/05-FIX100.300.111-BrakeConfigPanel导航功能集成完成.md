## 📋 任务目标

---

## 🎯 实施内容

### 1. 布局改造：RowLayout → GridLayout

**改造前**：
- 使用 RowLayout 两列布局
- 左列5个参数 + 右列4个参数
- 标签宽度120px，字体14px

**改造后**：
- 使用 GridLayout 4列布局（标签1、输入框1、标签2、输入框2）
- 10个参数字段重新排列为5行
- 标签宽度160px，字体21px
- 输入框最大宽度300px

**参数字段映射**：
```
行0: 抱闸保持时间（左）、松闸保持时间（右）
行1: 抱闸动作延时（左）、抱闸释放延时（右）
行2: 抱闸检测延时（左）、抱闸故障延时（右）
行3: 抱闸动作电流（左）、抱闸释放电流（右）
行4: 抱闸动作电压（左）、抱闸释放电压（右）
```

### 2. 导航系统属性

添加以下导航属性：
```qml
property var virtualKeyboard: null  // Qt 虚拟键盘引用
property int focusSubArea: 0  // 0:无焦点 1:参数区域 2:底部按钮区域
property int focusParamIndex: 0  // 参数区域焦点索引（0-9）
property int focusButtonIndex: 0  // 底部按钮区域焦点索引（0-1）
```

### 3. 焦点指示器

**参数字段焦点指示器**：
- 蓝色边框（#2196F3）
- 边框宽度：3px
- 圆角：4px
- 条件：`root.focusSubArea === 1 && root.focusParamIndex === X`

**底部按钮焦点指示器**：
- 蓝色边框（#2196F3）
- 边框宽度：5px（与 MotorControlPage 一致）
- 圆角：4px
- 焦点时背景色更亮
- 条件：`root.focusSubArea === 2 && root.focusButtonIndex === X`

### 4. 导航函数

#### getParamFieldCount()
```qml
function getParamFieldCount() {
    return 10  // 10个参数字段（GridLayout 4列布局，5行）
}
```

#### triggerParamInput(paramIndex)
```qml
function triggerParamInput(paramIndex) {
    // 根据 paramIndex 打开对应字段的虚拟键盘
    // 0-9: 10个参数字段
    // 所有字段均为数字模式（numeric）
}
```

#### triggerButton(buttonIndex)
```qml
function triggerButton(buttonIndex) {
    // 0: 保存
    // 1: 重置
}
```

### 5. 底部按钮更新

**保存按钮（索引 0）**：
- 焦点时：亮绿色（#2ecc71）
- 正常时：蓝色（#1E88E5）
- 边框宽度：5px

**重置按钮（索引 1）**：
- 焦点时：亮灰色（#95a5a6）
- 正常时：灰色（#9E9E9E）
- 边框宽度：5px

### 6. 虚拟键盘支持

- 添加 `property var virtualKeyboard: null`
- 在 `triggerParamInput()` 中调用 `virtualKeyboard.openForField()`
- 所有参数字段均为数字模式（numeric）

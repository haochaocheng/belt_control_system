# FIX 100.300.112.7.4 - 修复使用状态左键无法返回列表

## 🐛 问题描述

### 用户反馈

> 查看pjsip.md最后日志，从使用状态左键或者上键都回不到制动器列表

### 具体问题

1. **左键无法返回**：
   - 在使用状态区域按左键
   - 焦点不返回制动器列表
   - 日志显示 "BrakeControlPage 左键由内部 NavigationManager 处理"
   - 但实际上没有调用 NavigationManager

2. **上键也无法返回**：
   - 同样的问题

---

## 🔍 根本原因

### 问题分析

**DeviceSettingsDialog.qml 的 Keys.onLeftPressed 处理器**（Line 385-389）：

```qml
if (isBrakeControlPage) {
    // ✅ BrakeControlPage 4区域模式：左键由内部 NavigationManager 处理
    console.log("✅ [导航] BrakeControlPage 左键由内部 NavigationManager 处理")
    return  // ❌ 只打印日志就返回了，没有调用 handleKeyPress
}
```

**问题**：
- 检测到是 BrakeControlPage（`currentCategory === 4`）
- 打印日志 "左键由内部 NavigationManager 处理"
- **但是没有调用 `brakePage.handleKeyPress("Left")`**
- 直接 return，导致左键事件被忽略

### 对比电机控制页面

**电机控制页面的处理**（Line 360-367）：

```qml
if (currentCategory === 3 && currentFocusArea === 2) {
    var motorPage = motorControlPageLoader.item
    if (motorPage && typeof motorPage.handleKeyPress === "function") {
        motorPage.handleKeyPress("Left")  // ✅ 正确调用
        event.accepted = true
        return
    }
}
```

**对比**：
- 电机控制页面：调用 `handleKeyPress("Left")` ✅
- 制动器控制页面：只打印日志，不调用 ❌

### 数据流问题

**修复前**：
```

  ↓

  ↓
return（❌ 没有调用 handleKeyPress）
  ↓
BrakeControlPage 的 NavigationManager 没有收到事件
  ↓
焦点不移动 ❌
```

**修复后**：
```
用户按左键
  ↓
DeviceSettingsDialog.Keys.onLeftPressed 触发
  ↓
检测到 currentCategory === 4（制动器控制）
  ↓
调用 brakePage.handleKeyPress("Left") ✅
  ↓
BrakeControlPage.handleKeyPress 被调用

navigationManager.moveInUsageStatusArea("Left") 被调用

焦点返回制动器列表 ✅
```

**DeviceSettingsDialog.qml（修复前，Line 385-389）**：

- 添加 `event.accepted = true`

## 💡 经验教训

### 1. 事件转发的完整性

**问题**：
- 检测到特殊页面（BrakeControlPage）
- 打印日志说"由内部处理"
- 但实际上没有转发事件

**正确做法**：
```qml
if (isSpecialPage) {
    // 1. 获取页面实例
    var page = pageLoader.item

    // 2. 检查方法是否存在
    if (page && typeof page.handleKeyPress === "function") {
        // 3. 调用方法
        page.handleKeyPress(direction)

        // 4. 标记事件已处理
        event.accepted = true
    }

    // 5. 打印日志（可选）
    console.log("事件已转发")

    // 6. 返回
    return
}
```

### 2. 参考已有实现

**最佳实践**：
- 查看电机控制页面的实现（Line 360-367）
- 复制相同的模式
- 保持代码风格一致

**本次问题**：
- 电机控制页面有正确的实现
- 但制动器控制页面没有复制完整的逻辑
- 只复制了检测和日志，没有复制调用

### 3. 日志的误导性

**问题**：
- 日志说 "左键由内部 NavigationManager 处理"
- 但实际上没有处理
- 日志给人一种"已经处理"的错觉

**教训**：
- 日志应该反映实际行为
- 不要在没有执行操作前打印"已处理"的日志
- 或者在调用后打印日志

**改进**：
```qml
// ❌ 错误：在调用前打印
console.log("事件已处理")
page.handleKeyPress(direction)

// ✅ 正确：在调用后打印
page.handleKeyPress(direction)
console.log("事件已处理")
```

### 4. 测试的重要性

**问题定位**：
- 用户测试发现左键无法返回
- 查看日志发现 handleKeyPress 没有被调用
- 检查代码发现缺少调用

**教训**：
- 每次修改后都要测试所有导航路径
- 不要假设"应该能工作"
- 实际测试才能发现问题

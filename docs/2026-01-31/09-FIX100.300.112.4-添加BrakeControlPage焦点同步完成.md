## 🔍 根本原因

### 问题分析

**DeviceSettingsDialog 的导航架构**：
- DeviceSettingsDialog 统一处理所有键盘事件
- 通过修改 `currentContentItemIndex` 来控制列表导航
- 页面需要监听 `currentContentItemIndex` 的变化并同步焦点

**开关量和模拟量页面的做法**：
- SwitchInputPage 和 AnalogInputPage 直接在页面内部定义 ListView
- ListView 的 `currentIndex` 绑定到 `root.currentProtectionIndex`
- DeviceSettingsDialog 通过 Connections 对象监听变化并同步 `focusItemIndex`

**制动器控制页面的问题**：
- BrakeControlPage 使用 Loader 加载 BrakeListPanel
- **缺少 Connections 对象监听 `currentContentItemIndex` 变化**
- **onLoaded 中没有设置初始焦点状态**
- **没有传递 virtualKeyboard 引用**

### 数据流对比

**开关量输入页面（正常工作）**：

```
  ↓
SwitchInputPage.focusItemIndex 更新
  ↓
ListView 焦点指示器移动 ✅
```

```
  ↓
```

## 🔧 修复方案

### 解决方法

**参考 MotorControlPage 的实现，为 BrakeControlPage 添加完整的焦点同步逻辑**

### 修复代码

**DeviceSettingsDialog.qml - BrakeControlPage onLoaded（Line 1257-1271）**：

```qml
onLoaded: {
    if (item) {
        console.log("✅ [DeviceSettingsDialog] BrakeControlPage 加载成功")
        item.deviceId = root.deviceId
        item.deviceName = root.deviceName
        // ✅ 2026-01-31 [FIX 100.300.112.4]: 传递虚拟键盘引用
        item.virtualKeyboard = qtVirtualKeyboard

        // ✅ 2026-01-31 [FIX 100.300.112.4]: 设置初始焦点状态
        if (root.currentFocusArea === 2 && root.currentCategory === 4) {
            item.focusSubArea = 0  // 默认焦点在制动器列表区域
            item.focusItemIndex = root.currentContentItemIndex
        }
    }
}
```

**DeviceSettingsDialog.qml - 添加 Connections 对象（Line 1280-1319）**：

```qml
// ✅ 2026-01-31 [FIX 100.300.112.4]: BrakeControlPage 焦点同步
Connections {
    target: root
    enabled: brakeControlPageLoader.item !== null

    function onCurrentFocusAreaChanged() {
        if (brakeControlPageLoader.item && root.currentCategory === 4) {
            if (root.currentFocusArea === 2) {
                // 焦点进入内容区域，默认在制动器列表区域
                brakeControlPageLoader.item.focusSubArea = 0
                brakeControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 焦点离开内容区域，清除焦点
                brakeControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentCategoryChanged() {
        if (brakeControlPageLoader.item) {
            if (root.currentFocusArea === 2 && root.currentCategory === 4) {
                // 切换到制动器控制类别，设置焦点
                brakeControlPageLoader.item.focusSubArea = 0
                brakeControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
            } else {
                // 切换到其他类别，清除焦点
                brakeControlPageLoader.item.focusItemIndex = -1
            }
        }
    }

    function onCurrentContentItemIndexChanged() {
        if (brakeControlPageLoader.item &&
            root.currentFocusArea === 2 &&
            root.currentCategory === 4) {
            // 在制动器列表中导航
            brakeControlPageLoader.item.focusItemIndex = root.currentContentItemIndex
        }
    }
}
```

## 💡 经验教训

### 1. DeviceSettingsDialog 的导航架构

**原则**：
- DeviceSettingsDialog 统一处理所有键盘事件
- 通过 `currentContentItemIndex` 控制列表导航
- 页面通过 Connections 对象监听变化并同步焦点

**模式**：
```qml
// DeviceSettingsDialog
property int currentContentItemIndex: 0

Keys.onPressed: {
    if (event.key === Qt.Key_Down) {
        currentContentItemIndex++  // 修改索引
    }
}

// 页面 Loader
Connections {
    target: root
    enabled: pageLoader.item !== null

    function onCurrentContentItemIndexChanged() {
        // 同步焦点到页面
        pageLoader.item.focusItemIndex = root.currentContentItemIndex
    }
}
```

### 2. 不要假设页面会自己处理导航

**错误做法**：
- 在页面内部实现完整的键盘处理器
- 期望页面的 `Keys.onPressed` 会被调用

**正确做法**：
- 页面只负责显示焦点状态
- 导航逻辑由 DeviceSettingsDialog 统一处理
- 页面通过 Connections 监听变化

### 3. 参考已有实现

**最佳实践**：
- 查看 SwitchInputPage、AnalogInputPage、MotorControlPage 的实现
- 复制相同的 Connections 对象
- 保持代码风格一致

### 4. 调试技巧

**问题定位**：
1. 添加调试日志查看函数是否被调用
2. 如果函数没有被调用，检查键盘事件处理流程
3. 查看 DeviceSettingsDialog 如何处理其他页面
4. 对比差异，找出缺失的部分

**日志输出**：
```qml
function onCurrentContentItemIndexChanged() {
    console.log("✅ [DeviceSettingsDialog] currentContentItemIndex 变化:", root.currentContentItemIndex)
    pageLoader.item.focusItemIndex = root.currentContentItemIndex
}
```

### 5. Connections 对象的三个关键信号

**必须监听的信号**：
1. `onCurrentFocusAreaChanged`: 焦点区域变化（类别 ↔ 内容）
2. `onCurrentCategoryChanged`: 类别切换（开关量 ↔ 模拟量 ↔ 电机 ↔ 制动器）
3. `onCurrentContentItemIndexChanged`: 列表索引变化（上下键导航）

**为什么需要三个信号**：
- `onCurrentFocusAreaChanged`: 确保焦点进入/离开内容区域时正确设置/清除焦点
- `onCurrentCategoryChanged`: 确保切换类别时正确设置焦点
- `onCurrentContentItemIndexChanged`: 确保列表导航时焦点跟随移动

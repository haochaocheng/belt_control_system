## 标准字段模板

每个参数字段使用以下模板：

```qml
// 参数索引: X - 字段名（列位置，行位置）
Text {
    text: "字段名:"
    font.pixelSize: 21
    color: "#9E9E9E"
    Layout.column: 0或2  // 左列0，右列2
    Layout.row: 行号
    Layout.preferredWidth: 160
    horizontalAlignment: Text.AlignRight
}

Item {
    Layout.column: 1或3  // 左列1，右列3
    Layout.row: 行号
    Layout.fillWidth: true
    Layout.maximumWidth: 300
    implicitHeight: 组件ID.implicitHeight

    DeviceInfo.CustomXXX {
        id: 组件ID
        anchors.fill: parent
        keyboardManager: root.keyboardManager
        // 其他属性...
    }

    Rectangle {
        anchors.fill: parent
        color: "transparent"
        border.color: (root.focusSubArea === 1 && root.focusParamIndex === X) ? "#2196F3" : "transparent"
        border.width: (root.focusSubArea === 1 && root.focusParamIndex === X) ? 3 : 0
        radius: 4
        z: 10
    }
}
```

## 🔍 根本原因

### 问题分析

**TensionControlPage.qml 的导入语句**（Line 3，修复前）：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import DeviceInfo 1.0 as DeviceInfo  // ❌ 错误
```

**问题**：
- 使用了 `import DeviceInfo 1.0 as DeviceInfo`
- DeviceInfo 不是一个已注册的 QML 模块
- QML 引擎找不到这个模块，导致加载失败

### 对比 BrakeControlPage

**BrakeControlPage.qml 的导入语句**（Line 3）：

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import "../" as DeviceInfo  // ✅ 正确
```

**关键区别**：
- BrakeControlPage 使用相对路径导入：`import "../" as DeviceInfo`
- 这是导入父目录（`components/device_info/`）作为命名空间
- NavigationManager.qml 位于父目录中，可以通过 `DeviceInfo.NavigationManager` 访问

### 数据流问题

**修复前**：
```
TensionControlPage.qml 加载
  ↓
解析 import DeviceInfo 1.0 as DeviceInfo
  ↓
QML 引擎查找已注册的模块 "DeviceInfo"
  ↓
❌ 找不到模块 "DeviceInfo"
  ↓
加载失败，抛出警告
  ↓
DeviceSettingsDialog 显示错误
```

**修复后**：
```
TensionControlPage.qml 加载
  ↓
解析 import "../" as DeviceInfo
  ↓
QML 引擎加载父目录作为命名空间
  ↓
✅ 成功加载 NavigationManager.qml
  ↓
DeviceInfo.NavigationManager 可用
  ↓
TensionControlPage 正常加载
```

## 💡 经验教训

### 1. QML 模块导入的两种方式

**方式一：已注册的 QML 模块**
```qml
import QtQuick 2.15
import QtQuick.Controls 2.15
import MyModule 1.0  // 需要在 C++ 中注册
```

**方式二：相对路径导入**
```qml
import "../" as ParentDir
import "../../" as GrandParentDir
import "./subdir" as SubDir
```

**本项目使用方式二**：
- NavigationManager.qml 是一个普通的 QML 文件
- 没有在 C++ 中注册为模块
- 必须使用相对路径导入

### 2. 保持一致性的重要性

**问题**：
- BrakeControlPage 使用 `import "../" as DeviceInfo`
- TensionControlPage 使用 `import DeviceInfo 1.0 as DeviceInfo`
- 不一致导致错误

**教训**：
- 复制代码时要检查所有依赖
- 保持导入语句的一致性
- 参考已有的正确实现

### 3. 错误信息的解读

**错误信息**：
```
Warning: module "DeviceInfo" is not installed
```

**关键信息**：
- "module" - 说明 QML 引擎在查找已注册的模块
- "is not installed" - 说明找不到这个模块
- 提示应该使用相对路径导入，而不是模块导入

### 4. 测试的重要性

**问题发现**：
- 代码修改后没有立即测试
- 用户测试时才发现加载失败
- 导致需要额外的修复提交

**教训**：
- 每次修改后都要测试
- 特别是添加新的导入语句时
- 确保页面能正常加载

## 🎯 QML 导入最佳实践

### 相对路径导入规则

```
项目结构：
src/qml/components/device_info/
  ├─ NavigationManager.qml
  └─ pages/
      ├─ BrakeControlPage.qml
      └─ TensionControlPage.qml
```

**在 pages/ 目录中的文件导入父目录**：
```qml
import "../" as DeviceInfo  // 导入 device_info/ 目录
```

**访问 NavigationManager**：
```qml
DeviceInfo.NavigationManager {
    id: navigationManager
    // ...
}
```

### 常见错误

❌ **错误 1：使用模块导入**
```qml
import DeviceInfo 1.0 as DeviceInfo  // 错误：DeviceInfo 不是已注册的模块
```

❌ **错误 2：路径错误**
```qml
import "../../" as DeviceInfo  // 错误：路径不对
```

❌ **错误 3：忘记 as 别名**
```qml
import "../"  // 错误：没有别名，无法访问
```

✅ **正确方式**
```qml
import "../" as DeviceInfo  // 正确：相对路径 + 别名
```

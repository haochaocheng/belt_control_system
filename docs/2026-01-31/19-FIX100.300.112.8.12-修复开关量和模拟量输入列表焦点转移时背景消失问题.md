# FIX 100.300.112.8.12 - 修复开关量和模拟量输入列表焦点转移时背景消失问题

**日期**: 2026-01-31
**任务编号**: FIX 100.300.112.8.12

## 🐛 问题描述

### 用户反馈

> 开关量输入和模拟量输入列表内的焦点转移到参数区域时，图片和蓝色边框也取消了，这个不合理，应该像电机控制和张紧控制列表内焦点转移到参数区域，只是蓝色边框消失了，但是背景被选中的按钮还是没有变化，这样能从开关量输入和模拟量输入列表内突出显示是哪个列表内的参数正在被修改。

### 具体问题

**开关量输入（SwitchInputPage）和模拟量输入（AnalogInputPage）**：
- 焦点从列表区域转移到参数区域时
- 列表中选中项的**背景图片**和**蓝色边框**都消失了
- 无法看出当前正在编辑哪个列表项的参数

**期望行为（参考电机控制和张紧控制）**：
- 焦点转移到参数区域时
- **蓝色边框应该消失**（表示焦点已离开列表）
- **背景图片应该保持**（表示当前正在编辑哪个列表项的参数）

## 🔍 根本原因

### 问题分析

**SwitchInputPage.qml（修复前，Line 130, 145）**：

```qml
// 焦点状态判断
readonly property bool isFocused: (root.focusSubArea === 0 && root.focusItemIndex === index)

// 背景图片
Image {
    id: backgroundImage
    anchors.fill: parent
    fillMode: Image.Stretch
    z: -1

    // ❌ 背景图片同时依赖 focusSubArea 和 focusItemIndex
    source: isFocused ? "../../../images/bhNameBK1.png" : "../../../images/bhNameBK.png"
}
```

**问题**：
- `isFocused` 同时依赖 `focusSubArea === 0` 和 `focusItemIndex === index`
- 背景图片的显示条件是 `isFocused`
- 当焦点离开列表区域（`focusSubArea` 变为 1）时，`isFocused` 变为 `false`
- 导致背景图片也消失了

### 对比电机控制

**MotorListPanel.qml（Line 70-71）**：

```qml
delegate: Rectangle {
    width: motorListView.width
    height: 60
    // ✅ 背景色只依赖 currentMotorIndex
    color: root.currentMotorIndex === index ? "#252b3d" : "transparent"
    // ✅ 边框同时依赖 currentMotorIndex（但电机控制没有 focusSubArea）
    border.color: root.currentMotorIndex === index ? "#2196F3" : "#3d4556"
    border.width: 1
}
```

**关键区别**：
- 电机控制的选中状态只依赖 `currentMotorIndex === index`
- 没有 `focusSubArea` 的概念，所以选中状态始终保持
- 开关量输入和模拟量输入有 `focusSubArea`，需要分离选中状态和焦点状态

### 数据流问题

**修复前**：
```
焦点在列表区域（focusSubArea === 0）
  ↓
isFocused = (focusSubArea === 0 && focusItemIndex === index) = true
  ↓
背景图片显示 bhNameBK1.png（选中状态）✅
蓝色边框显示 ✅
  ↓
焦点转移到参数区域（focusSubArea === 1）
  ↓
isFocused = (focusSubArea === 0 && focusItemIndex === index) = false
  ↓
背景图片显示 bhNameBK.png（未选中状态）❌
蓝色边框消失 ✅
```

**修复后**：
```
焦点在列表区域（focusSubArea === 0）
  ↓
isFocused = (focusSubArea === 0 && focusItemIndex === index) = true
isSelected = (currentProtectionIndex === index) = true
  ↓
背景图片显示 bhNameBK1.png（选中状态）✅
蓝色边框显示 ✅
  ↓
焦点转移到参数区域（focusSubArea === 1）
  ↓
isFocused = (focusSubArea === 0 && focusItemIndex === index) = false
isSelected = (currentProtectionIndex === index) = true
  ↓
背景图片显示 bhNameBK1.png（选中状态）✅
蓝色边框消失 ✅
```

## 🔧 修复方案

### 解决方法

**分离选中状态和焦点状态**：
1. **选中状态**（背景图片）：只依赖 `currentProtectionIndex === index`
2. **焦点状态**（蓝色边框）：依赖 `focusSubArea === 0 && focusItemIndex === index`
3. **添加监听器**：当焦点在列表区域移动时，同步更新 `currentProtectionIndex`

## 💡 经验教训

### 1. 分离选中状态和焦点状态

**问题**：
- 将选中状态和焦点状态混在一起
- 导致焦点离开时，选中状态也消失

**教训**：
- 选中状态（背景图片）：表示当前正在编辑哪个项
- 焦点状态（蓝色边框）：表示当前焦点在哪个区域
- 两者应该分离，使用不同的属性控制

### 2. 属性命名的清晰性

**好的命名**：
```qml
readonly property bool isFocused: (root.focusSubArea === 0 && root.focusItemIndex === index)
readonly property bool isSelected: (root.currentProtectionIndex === index)
```

**好处**：
- `isFocused`：清楚表示焦点状态
- `isSelected`：清楚表示选中状态
- 易于理解和维护

### 3. 同步更新选中索引

**问题**：
- 焦点移动时，`focusItemIndex` 变化
- 但 `currentProtectionIndex` 没有同步更新
- 导致选中状态不一致

**解决方案**：
```qml
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex < model.count) {
        currentProtectionIndex = focusItemIndex
        loadProtectionData(focusItemIndex)
    }
}
```

### 4. 参考已有的正确实现

**方法**：
- 电机控制和张紧控制的行为是正确的
- 对比它们的实现，找出差异
- 学习它们的设计模式

**关键发现**：
- 电机控制使用 `currentMotorIndex` 控制选中状态
- 张紧控制使用 `currentControlIndex` 控制选中状态
- 开关量输入和模拟量输入应该使用 `currentProtectionIndex` 控制选中状态

### 选中状态和焦点状态的关系

```
列表项状态 = 选中状态 + 焦点状态

选中状态（isSelected）：
  - 依赖：currentProtectionIndex === index
  - 控制：背景图片（bhNameBK1.png vs bhNameBK.png）
  - 特点：焦点离开列表时保持

焦点状态（isFocused）：
  - 依赖：focusSubArea === 0 && focusItemIndex === index
  - 控制：蓝色边框（#2196F3 vs transparent）
  - 特点：焦点离开列表时消失
```

### 状态转换表

| 场景 | focusSubArea | focusItemIndex | currentProtectionIndex | isSelected | isFocused | 背景图片 | 蓝色边框 |
|------|--------------|----------------|------------------------|------------|-----------|----------|----------|
| 焦点在列表项0 | 0 | 0 | 0 | true | true | bhNameBK1.png | 显示 |
| 焦点转移到参数 | 1 | 0 | 0 | true | false | bhNameBK1.png | 消失 |
| 焦点移动到列表项1 | 0 | 1 | 1 | true | true | bhNameBK1.png | 显示 |

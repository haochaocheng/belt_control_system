# FIX 100.300.112.5 - 修复制动器列表背景图片不切换

**日期**: 2026-01-31
**任务编号**: FIX 100.300.112.5
**状态**: ✅ 完成

## 🐛 问题描述

### 用户反馈

> pjsip.md测试完成，蓝色方框跟随焦点发送变化，但是列表内的按钮被选中的图片没有发送变化

### 具体问题

1. **蓝色焦点方框正常工作** ✅
   - 按上下键时，蓝色边框正确移动
   - 焦点指示器跟随焦点变化

2. **背景图片不切换** ❌
   - 选中的制动器背景图片应该从 `bhNameBK.png` 切换到 `bhNameBK1.png`
   - 但实际上背景图片没有变化
   - 文字颜色也没有变化（应该从灰色变为白色）
   - 左侧蓝色指示条也没有显示

---

## 🔍 根本原因

### 问题分析

**BrakeListPanel 的背景图片切换逻辑**（Line 110-127）：
```qml
Image {
    id: backgroundImage
    states: [
        State {
            name: "selected"
            when: root.currentBrakeIndex === index  // ❌ 基于 currentBrakeIndex
            PropertyChanges {
                target: backgroundImage
                source: "../../../images/bhNameBK1.png"
            }
        },
        State {
            name: "normal"
            when: root.currentBrakeIndex !== index
            PropertyChanges {
                target: backgroundImage
                source: "../../../images/bhNameBK.png"
            }
        }
    ]
}
```

**问题**：
- 背景图片切换基于 `root.currentBrakeIndex === index`
- 但 **DeviceSettingsDialog 只更新 `focusItemIndex`，不更新 `currentBrakeIndex`**
- 导致 `currentBrakeIndex` 始终是 0，背景图片不切换

### 数据流分析

**修复前**：
```
DeviceSettingsDialog 按下键
  ↓
currentContentItemIndex 变化 (0 → 1)
  ↓
Connections.onCurrentContentItemIndexChanged 触发
  ↓
brakeControlPageLoader.item.focusItemIndex = 1 ✅
  ↓
BrakeControlPage.focusItemIndex 更新为 1 ✅
  ↓
BrakeListPanel.focusItemIndex 同步为 1 ✅
  ↓
焦点指示器移动（蓝色方框）✅
  ↓
❌ 但 BrakeControlPage.currentBrakeIndex 仍然是 0
  ↓
❌ BrakeListPanel.currentBrakeIndex 仍然是 0
  ↓
❌ 背景图片不切换（因为 currentBrakeIndex !== 1）
```

**修复后**：
```
DeviceSettingsDialog 按下键
  ↓
currentContentItemIndex 变化 (0 → 1)
  ↓
Connections.onCurrentContentItemIndexChanged 触发
  ↓
brakeControlPageLoader.item.focusItemIndex = 1 ✅
  ↓
BrakeControlPage.focusItemIndex 更新为 1 ✅
  ↓
onFocusItemIndexChanged 触发 ✅
  ↓
BrakeControlPage.currentBrakeIndex = 1 ✅
  ↓
BrakeListPanel.currentBrakeIndex 同步为 1（通过 Qt.binding）✅
  ↓
背景图片切换（bhNameBK → bhNameBK1）✅
文字颜色变化（灰色 → 白色）✅
左侧指示条显示（蓝色竖条）✅
```

---

## 🔧 修复方案

### 解决方法

**添加 `onFocusItemIndexChanged` 监听器，同步 `focusItemIndex` 到 `currentBrakeIndex`**

### 修复代码

**BrakeControlPage.qml（Line 29-35）**：

```qml
// ✅ 2026-01-31 [FIX 100.300.112.5]: 监听 focusItemIndex 变化，同步到 currentBrakeIndex
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex <= 7) {
        console.log("✅ [BrakeControlPage] focusItemIndex 变化:", focusItemIndex, "→ 更新 currentBrakeIndex")
        currentBrakeIndex = focusItemIndex
    }
}
```

**关键点**：
1. **只在列表区域同步**：`focusSubArea === 0`
2. **验证索引范围**：`focusItemIndex >= 0 && focusItemIndex <= 7`
3. **同步到 currentBrakeIndex**：`currentBrakeIndex = focusItemIndex`

## 💡 经验教训

### 1. 焦点索引 vs 选中索引

**两个不同的概念**：
- **focusItemIndex**: 焦点位置（蓝色方框）
- **currentBrakeIndex**: 选中状态（背景图片、文字颜色）

**问题**：
- 只更新 focusItemIndex，不更新 currentBrakeIndex
- 导致焦点和选中状态不同步

**解决**：
```qml
onFocusItemIndexChanged: {
    if (focusSubArea === 0) {
        currentBrakeIndex = focusItemIndex  // 同步
    }
}
```

### 2. 属性同步的重要性

**问题**：
- DeviceSettingsDialog 更新 focusItemIndex
- 但页面内部使用 currentBrakeIndex
- 两者没有同步

**解决**：
- 添加监听器同步两个属性
- 确保数据流完整

### 3. 视觉反馈的多个层次

**制动器列表的视觉反馈**：
1. **焦点指示器**（蓝色方框）- 基于 `focusItemIndex`
2. **背景图片**（bhNameBK ↔ bhNameBK1）- 基于 `currentBrakeIndex`
3. **文字颜色**（灰色 ↔ 白色）- 基于 `currentBrakeIndex`
4. **文字粗细**（Normal ↔ Bold）- 基于 `currentBrakeIndex`
5. **左侧指示条**（显示/隐藏）- 基于 `currentBrakeIndex`

**关键**：
- 所有视觉反馈必须基于同一个状态源
- 或者确保多个状态源同步

### 4. 调试技巧

**问题定位**：
1. 观察哪些视觉反馈正常，哪些不正常
2. 检查正常的反馈基于什么属性
3. 检查不正常的反馈基于什么属性
4. 找出属性之间的差异

**本次调试**：
- 焦点指示器正常 → 基于 `focusItemIndex` ✅
- 背景图片不正常 → 基于 `currentBrakeIndex` ❌
- 结论：`focusItemIndex` 更新了，但 `currentBrakeIndex` 没有更新

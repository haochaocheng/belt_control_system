# FIX 100.300.112.7 - 添加使用状态区域到导航系统

**日期**: 2026-01-31
**任务编号**: FIX 100.300.112.7
**状态**: ✅ 完成

---

## 🐛 问题描述

### 用户反馈

> 在顶部还有一个使用状态参数区域，没有接入导航里

### 具体问题

1. **使用状态区域未接入导航系统**
   - "使用状态"区域包含两个 RadioButton（投入/禁用）
   - 无法通过键盘导航到该区域
   - 无法通过键盘切换选项

2. **导航流程不完整**
   - 从制动器列表按右键 → 直接进入参数区域（跳过使用状态）
   - 从参数区域按左键/上键 → 返回制动器列表（跳过使用状态）
   - 使用状态区域被完全忽略

---

## 🔍 根本原因

### 问题分析

**NavigationManager 只有 3 个区域**：
```qml
readonly property int areaBrakeList: 0      // 制动器列表区域
readonly property int areaParams: 1         // 参数区域
readonly property int areaButtons: 2        // 底部按钮区域
```

**缺少使用状态区域**：
- 使用状态区域位于制动器列表和参数区域之间
- 但 NavigationManager 没有定义该区域
- 导航逻辑直接从列表跳到参数

### 数据流问题

**修复前**：
```
制动器列表（区域0）
  ↓ 右键
参数区域（区域1）← ❌ 跳过了使用状态
  ↓ 下键
按钮区域（区域2）
```

**修复后**：
```
制动器列表（区域0）
  ↓ 右键
使用状态（区域1）← ✅ 新增
  ↓ 下键
参数区域（区域2）
  ↓ 下键
按钮区域（区域3）
```

---

```qml
function moveInUsageStatusArea(direction) {
    // 使用状态区域导航（2个选项：0=投入 1=禁用）
    var newIndex = usageStatusIndex

    switch(direction) {
    case "Left":
        // 左键：返回制动器列表
        switchToArea(areaBrakeList)
        return
    case "Right":
        // 右键：在两个选项之间切换

            newIndex = 1
        }
        break
    case "Down":
        // 下键：进入参数区域
        switchToArea(areaParams)
        paramIndex = 0
        return
    }

    if (newIndex !== usageStatusIndex) {
        usageStatusIndex = newIndex
    }
}
```

## 💡 经验教训

### 1. 区域编号的重要性

**问题**：
- 添加新区域时，需要重新编号所有后续区域
- 所有使用区域编号的地方都需要更新

**解决**：
- 使用常量定义区域编号（`readonly property int`）
- 在代码中使用常量名而不是硬编码数字
- 批量替换时要小心，确保不会误替换

### 2. 焦点指示器的条件判断

**模式**：
```qml
Rectangle {
    border.color: (root.focusSubArea === X && root.focusXXXIndex === Y) ? "#2196F3" : "transparent"
    border.width: (root.focusSubArea === X && root.focusXXXIndex === Y) ? 3 : 0
}
```

**关键点**：
- 必须同时检查 `focusSubArea` 和具体索引
- 确保只有当前区域的焦点项显示边框
- 其他区域的焦点项不显示边框

### 3. 属性传递链

**数据流**：
```
NavigationManager.usageStatusIndex
  ↓ (Qt.binding)
BrakeConfigPanel.focusUsageStatusIndex
  ↓ (条件判断)
RadioButton 焦点指示器
```

**关键点**：
- 使用 `Qt.binding()` 确保属性自动同步
- 不要直接赋值，否则绑定会断开

### 4. 导航逻辑的完整性

**检查清单**：
- ✅ 每个区域都有进入和退出的路径
- ✅ 边界条件正确处理（第一个/最后一个）
- ✅ 所有方向键都有对应的处理
- ✅ 回车键触发正确的操作

### 5. RadioButton 的特殊处理

**问题**：
- RadioButton 是互斥的，只能选中一个
- 但导航时需要在两个选项之间切换

**解决**：
- 使用索引（0/1）表示当前焦点位置
- 右键切换焦点（0 → 1）
- 回车键触发选择（checked = true）

```
└─────────────────────────────────────────────────────────────┘
```

| 区域 | focusSubArea | 焦点属性 | 显示条件 |

| 制动器列表 | 0 | focusItemIndex | `focusSubArea === 0 && focusItemIndex === index` |
| 使用状态 | 1 | focusUsageStatusIndex | `focusSubArea === 1 && focusUsageStatusIndex === index` |
| 参数区域 | 2 | focusParamIndex | `focusSubArea === 2 && focusParamIndex === index` |
| 按钮区域 | 3 | focusButtonIndex | `focusSubArea === 3 && focusButtonIndex === index` |

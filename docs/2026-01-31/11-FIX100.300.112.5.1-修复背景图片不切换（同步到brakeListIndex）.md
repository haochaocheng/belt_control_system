## 🔍 根本原因

### 问题分析

**BrakeListPanel 的 currentBrakeIndex 绑定**（Line 316）：
```qml
onLoaded: {
    // ✅ 2026-01-31 [FIX 100.300.112.3]: 绑定到 navigationManager.brakeListIndex 而不是 root.currentBrakeIndex
    item.currentBrakeIndex = Qt.binding(function() { return navigationManager.brakeListIndex })
    // ...
}
```

**onFocusItemIndexChanged 的更新**（修复前）：
```qml
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex <= 7) {
        currentBrakeIndex = focusItemIndex  // ✅ 更新了 root.currentBrakeIndex
        // ❌ 但没有更新 navigationManager.brakeListIndex
    }
}
```

**问题**：
- BrakeListPanel 的 `currentBrakeIndex` 绑定到 `navigationManager.brakeListIndex`
- 但 `onFocusItemIndexChanged` 只更新 `root.currentBrakeIndex`
- **没有更新 `navigationManager.brakeListIndex`**
- 导致 BrakeListPanel 看不到变化，背景图片不切换

## 🔧 修复方案

### 解决方法

**在 `onFocusItemIndexChanged` 中同时更新两个属性**：
1. `root.currentBrakeIndex`
2. `navigationManager.brakeListIndex`

### 修复代码

**BrakeControlPage.qml（修复前）**：
```qml
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex <= 7) {
        console.log("✅ [BrakeControlPage] focusItemIndex 变化:", focusItemIndex, "→ 更新 currentBrakeIndex")
        currentBrakeIndex = focusItemIndex  // ❌ 只更新了 currentBrakeIndex
    }
}
```

**BrakeControlPage.qml（修复后，Line 29-37）**：
```qml
// ✅ 2026-01-31 [FIX 100.300.112.5]: 监听 focusItemIndex 变化，同步到 currentBrakeIndex
// ✅ 2026-01-31 [FIX 100.300.112.5.1]: 同时更新 navigationManager.brakeListIndex
onFocusItemIndexChanged: {
    if (focusSubArea === 0 && focusItemIndex >= 0 && focusItemIndex <= 7) {
        console.log("✅ [BrakeControlPage] focusItemIndex 变化:", focusItemIndex, "→ 更新 currentBrakeIndex 和 brakeListIndex")
        currentBrakeIndex = focusItemIndex
        navigationManager.brakeListIndex = focusItemIndex  // ✅ 同时更新 brakeListIndex
    }
}
```

**关键变化**：
- 添加 `navigationManager.brakeListIndex = focusItemIndex`
- 确保 BrakeListPanel 能看到变化

## 💡 经验教训

### 1. 属性绑定的传递性

**问题**：
- A 绑定到 B：`A = Qt.binding(function() { return B })`
- 更新 C，期望 A 也更新
- 但 A 只绑定到 B，不绑定到 C
- **必须同时更新 B，A 才能看到变化**

**本次问题**：
- `BrakeListPanel.currentBrakeIndex` 绑定到 `navigationManager.brakeListIndex`
- 更新 `root.currentBrakeIndex`，期望 BrakeListPanel 也更新
- 但 BrakeListPanel 只绑定到 `navigationManager.brakeListIndex`
- **必须同时更新 `navigationManager.brakeListIndex`**

### 2. 检查绑定链

**调试步骤**：
1. 找到不更新的属性（BrakeListPanel.currentBrakeIndex）
2. 检查它绑定到什么（navigationManager.brakeListIndex）
3. 检查更新代码是否更新了绑定源
4. 如果没有，添加更新

**本次调试**：
1. BrakeListPanel.currentBrakeIndex 不更新 ❌
2. 绑定到 navigationManager.brakeListIndex
3. onFocusItemIndexChanged 只更新 root.currentBrakeIndex ❌
4. 添加 navigationManager.brakeListIndex = focusItemIndex ✅

### 3. 日志的重要性

**问题定位**：
- 日志显示 "更新 currentBrakeIndex" ✅
- 但背景图片不切换 ❌
- 说明更新的属性不是 BrakeListPanel 使用的属性

**解决**：
- 检查 BrakeListPanel 使用的属性
- 发现绑定到 navigationManager.brakeListIndex
- 添加对该属性的更新

### 4. 属性命名的一致性

**问题**：
- 有两个 currentBrakeIndex：
  1. `root.currentBrakeIndex`
  2. `BrakeListPanel.currentBrakeIndex`（绑定到 navigationManager.brakeListIndex）
- 容易混淆

**建议**：
- 使用更明确的命名
- 或者确保所有地方使用同一个属性源

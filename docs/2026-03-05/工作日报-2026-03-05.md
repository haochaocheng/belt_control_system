## 三、技术难点与解决方案

### 1. Qt信号槽参数类型匹配
**问题**：信号使用 `const ChannelData&`，槽函数使用 `double`，编译器报错
**解决**：统一使用 `const ChannelData&`，通过 `data.adValue` 访问AD值

### 2. Qt moc编译器类型定义要求
**问题**：前向声明 `struct ChannelData;` 不足以满足moc编译器
**解决**：改为包含完整头文件 `#include "../mqtt/AIDataManager.h"`

### 3. 跨模块信号槽连接访问权限
**问题**：`private slots:` 中的槽函数无法从main.cpp连接
**解决**：将槽函数移至 `public slots:` 区域

### 4. QML界面样式统一
**问题**：模拟量输入页面与开关量输入页面样式不一致
**解决**：统一使用Cyberpunk工业风格（深色背景 + 顶部高亮线 + LED指示点 + 双层LED结构）

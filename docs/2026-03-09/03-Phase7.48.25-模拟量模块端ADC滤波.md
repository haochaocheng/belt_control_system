**日期**：2026-03-09

**类型**：功能增强

## 一、问题描述

### 1.1 现象

模拟量数据波动大，数值不稳定：
- CH0（速度）：原始值波动 ±11%
- CH2（温度一）：原始值波动 ±24%
- CH4（电压）：原始值波动 ±10.6%

### 1.2 原因

Luckfox Nova设备的SARADC（10位，0-1023）读数噪声较大，原始脚本每500ms单次采样直接发布，未经任何滤波处理。噪声经过16位映射（×64倍）后更加放大。

### 1.3 当前架构

```
ADC硬件(10bit) → 单次读取 → 映射到16bit → MQTT发布 → 工控机端ADFilter滤波
```

**问题**：仅在工控机端做滤波，噪声已经传输到网络，且单次采样无法利用多次采样的统计优势。

---

## 二、解决方案 — 模块端ADC滤波

### 2.1 设计原理

在模块端增加一级滤波，利用高频采样和统计滤波减少噪声：

```
ADC硬件(10bit) → 高频采样(50ms) → 中值滤波 + 尖峰剔除 + 移动平均 → MQTT发布
                                    ↑ 模块端新增滤波层
```

### 2.2 滤波策略

| 参数 | 值 | 说明 |
|------|-----|------|
| 内部采样间隔 | 50ms | 比发布频率（500ms）快10倍 |
| 滑动窗口大小 | 10个采样 | 覆盖500ms周期 |
| 尖峰剔除阈值 | 30% | 偏离中值超过30%的采样被排除 |

### 2.3 滤波算法流程

```
每50ms:
  读取所有ADC通道原始值 → 存入环形缓冲区

每500ms(发布时):
  1. 对缓冲区数据排序，计算中值
  2. 剔除偏离中值超过30%的尖峰数据
  3. 对剔除后的数据求平均值
  4. 输出为16bit值和电压值
  5. MQTT发布
```

## 四、滤波效果

### 4.1 测试数据（10轮对比）

| 通道 | 原始波动范围(16bit) | 滤波后波动范围 | 噪声降低 |
|------|---------------------|----------------|----------|
| CH0 | 25752-28635 (±11%) | 25900-27841 (±7.5%) | 33% |
| CH1 | 65406 (稳定) | 65406 (稳定) | - |
| CH2 | 25112-31262 (±24%) | 28436-28891 (±1.6%) | **93%** |
| CH3 | 32607 (稳定) | 32632-32645 (±0.04%) | 99.8% |
| CH4 | 28507-31518 (±10.6%) | 27616-27802 (±0.7%) | **93%** |

### 4.2 结论

- CH2（温度一）噪声从 ±24% 降至 ±1.6%，改善93%
- CH4（电压）噪声从 ±10.6% 降至 ±0.7%，改善93%
- 稳定通道（CH1、CH3）不受影响

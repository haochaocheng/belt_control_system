**日期**：2026-03-09
**阶段**：Phase 7.48.27
**分支**：feature/hardware-video-codec

## 概述

完善模拟量通道自定义功能，解决实际使用中的三个核心问题：
1. 通道硬件损坏时如何更换
2. 不需要的保护项如何禁用以释放通道
3. 通道分配状态如何快速查看

## 功能1: 保护启用/禁用开关

### 使用场景
某些保护项在当前工况下不需要（如湿度监测），用户可以禁用该保护并释放其通道给其他保护使用。

### 实现
- 数据库 `enabled BOOLEAN DEFAULT 1` 列已存在，现已接入 `saveAnalogProtection()` INSERT（27列）
- QML 编辑区第11行右侧添加 "保护启用" Switch 控件
- 禁用时自动将通道设为"未分配"(CH-1)
- 列表中禁用项半透明显示(opacity=0.45)，右侧显示红色"禁用"标签
- `MqttProtectionMonitor.onAIChannelChanged()` 跳过 `enabled != 1` 的保护项

### 用户操作
1. 选择保护项（如"湿度"）
2. 将"保护启用"开关切换为关闭
3. 保存 → 湿度的通道（模块2 CH5）被释放
4. 选择需要新通道的保护项 → 分配到释放的通道

## 功能2: 通道状态概览面板

### 使用场景
用户需要快速了解16个通道的分配情况，找出哪些通道空闲可用。

### 实现
- 位于 AD值/工程量显示区域下方，可折叠面板
- 显示2行×8列的通道网格（模块1 CH0-7 + 模块2 CH0-7）
- 颜色编码：
  - 绿色边框 = 已占用
  - 灰色边框 = 空闲
  - 红色文字 = 已禁用
  - 青色边框 = 当前选中项
- 标题栏显示已用通道数（如"已用 16/16"）
- 点击通道格子可跳转到对应保护项

## 功能3: 通道冲突对话框

### 使用场景
用户将保护A的通道改为已被保护B占用的通道时，弹出对话框而非仅打印警告。

### 实现
- 替换原有的 `console.warn` 为 Dialog 组件
- 三个选项：
  - **交换通道**：A和B互换通道（A的原通道给B，B的通道给A）
  - **覆盖**：将B设为"未分配"，A占用B的通道
  - **取消**：恢复A的原始通道值，不做任何修改

### 典型操作流程：通道损坏更换
```
1. 通道概览面板 → 发现模块1 CH3（温度二）读数异常
2. 选择一个不需要的保护（如"湿度"）→ 禁用 → 释放模块2 CH5
3. 选择"温度二" → 将通道改为模块2 CH5
4. 如果CH5仍被占用 → 弹出冲突对话框 → 选择"交换"或"覆盖"
5. 保存 → 温度二现在使用模块2 CH5
```

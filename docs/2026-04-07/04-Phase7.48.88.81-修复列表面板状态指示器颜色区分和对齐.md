# Phase 7.48.88.81 - 修复列表面板状态指示器颜色区分和对齐

## 修复时间
2026-04-07 (北京时间)

## 问题描述
4个设备列表面板的状态圆形指示器存在3个问题：
1. **颜色难以区分**：已停止=绿色`#4CAF50`，运行中=亮绿`#00E676`，两者颜色太接近
2. **圆形太小**：8x8px 在列表中不够醒目
3. **圆形不对齐**：文字"禁用"2字、"未配置"/"已停止"/"运行中"3字，宽度不同导致 Row 布局中圆形上下不对齐

## 修复方案

### 颜色方案调整
| 状态 | 修改前 | 修改后 |
|------|--------|--------|
| 运行中 | `#00E676` 亮绿 | `#00E676` 亮绿（不变） |
| 已停止(启用) | `#4CAF50` 绿色 | `#FFA726` 橙色 |
| 禁用 | `#FF5722` 红色 | `#FF5722` 红色（不变） |
| 未配置 | `#555555` 暗灰 | `#555555` 暗灰（不变） |

### 圆形尺寸
- 修改前：8x8px, radius: 4
- 修改后：10x10px, radius: 5

### 文字对齐
- 修改前：Text 宽度由内容决定（"禁用"窄，"运行中"宽），导致 Row 中圆形位置不同
- 修改后：Text 固定宽度 38px + `horizontalAlignment: Text.AlignLeft`，圆形位置一致

### 文字颜色
- 修改前：仅运行中为亮绿，其余统一灰色
- 修改后：每个状态文字颜色与圆形颜色一致（运行中=亮绿，已停止=橙色，禁用=红色，未配置=灰色）

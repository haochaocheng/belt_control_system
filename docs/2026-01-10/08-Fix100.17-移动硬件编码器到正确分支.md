## 📋 问题描述

### 现象
尽管实施了 Fix 100.16（移除环境变量，使用全局变量），部署后日志仍显示使用 `libx264rgb` 编码器：
```
02:10:49.064    Encoder: libx264rgb
```

### 根本原因（详见文档 07）
硬件编码器注册代码在**错误的条件编译分支**中：
- **代码位置**：`#if LIBAVCODEC_VER_AT_LEAST(58,137)` 分支（lines 1120-1294）
- **当前环境**：FFmpeg 6.1, libavcodec **58.91.100**
- **条件判断**：58.91 >= 58.137? → **FALSE** ❌
- **结果**：代码从未执行！

---

## ✅ 解决方案

### 修改：将代码移到正确的分支

**目标分支**：`#else` (FFmpeg < 58.137)
**插入位置**：在 `av_codec_iterate()` **之前**（line 1280-1424）

### 执行顺序确保
```
#else  // FFmpeg < 58.137 ✅
    ↓
诊断日志（Line 1267-1276）
    ↓
【✅ 新位置】for 循环注册硬件编码器（Line 1280-1424）
    ├─ enable_hw_encoder = 1
    ├─ hw_encoder_name = "h264_rkmpp"
    ├─ avcodec_find_encoder_by_name("h264_rkmpp")
    └─ codec_desc[idx].enc = h264_rkmpp ✅
    ↓
av_codec_iterate() 遍历所有编解码器（Line 1426+）
    └─ 遇到 libx264rgb
        └─ init_codec() 检查：dir & ENCODING 已设置
            └─ return（跳过！）✅
```

### 3. 新位置实施（Lines 1280-1424）

在 `#else` 分支中，**诊断日志之后**，**av_codec_iterate() 之前**插入：

```c
/* ========================================
 * ✅ 2026-01-10 19:40 [修复 100.17] 硬件编码器注册（正确位置）
 * 原因：从 #if LIBAVCODEC_VER_AT_LEAST(58,137) 分支移至此处
 * 条件：FFmpeg 6.1 (libavcodec 58.91.100 < 58.137) 会执行此分支
 * 效果：在 av_codec_iterate() 之前注册 h264_rkmpp，跳过 libx264rgb
 * 详细：docs/2026-01-10/07-根因分析-硬件编码器在错误的分支.md
 * ======================================== */

for (i = 0; i < PJ_ARRAY_SIZE(codec_desc); ++i) {
    unsigned codec_id;

    pjmedia_format_id_to_CodecID(codec_desc[i].info.fmt_id, &codec_id);

    /* ✅ 2026-01-10 19:40 [修复 100.17] 移除环境变量，使用全局变量控制硬件编码器 */
    int enable_hw_encoder = 1;  // ✅ 默认启用硬件编码器

    const char *hw_encoder_name = NULL;
    const char *hw_decoder_name = NULL;

    // Select hardware codec based on codec_id
    switch (codec_id) {
        case AV_CODEC_ID_H264:
            hw_encoder_name = "h264_rkmpp";
            hw_decoder_name = "h264_rkmpp";
            PJ_LOG(4,(THIS_FILE, "Configuring RKMPP H.264 hardware codec (FFmpeg 6.1)"));
            break;

        case AV_CODEC_ID_VP8:
            hw_encoder_name = "vp8_rkmpp";
            hw_decoder_name = "vp8_rkmpp";
            PJ_LOG(4,(THIS_FILE, "Configuring RKMPP VP8 hardware codec"));
            break;

        case AV_CODEC_ID_VP9:
            hw_encoder_name = "vp9_rkmpp";
            hw_decoder_name = "vp9_rkmpp";
            PJ_LOG(4,(THIS_FILE, "Configuring RKMPP VP9 hardware codec"));
            break;

        default:
            break;
    }

    /* ======================================== */
    /* Initialize encoder                      */
    /* ======================================== */
    if (hw_encoder_name && enable_hw_encoder == 1) {
        PJ_LOG(1,(THIS_FILE, "✅ [FIX 100.17] Hardware encoder ENABLED (global variable enable_hw_encoder=%d)", enable_hw_encoder));
        PJ_LOG(1,(THIS_FILE, "   Using hardware encoder: %s", hw_encoder_name));
        c = avcodec_find_encoder_by_name(hw_encoder_name);
        if (c) {
            PJ_LOG(4,(THIS_FILE, "Found hardware encoder: %s", hw_encoder_name));

            pjmedia_format_id fmt_id;
            int idx;
            pj_status_t status;

            status = CodecID_to_pjmedia_format_id(c->id, &fmt_id);
            if (status == PJ_SUCCESS) {
                idx = find_codec_idx_by_fmt_id(fmt_id);
                if (idx >= 0) {
                    codec_desc[idx].enc = c;
                    codec_desc[idx].info.dir |= PJMEDIA_DIR_ENCODING;

                    if (codec_desc[idx].info.dec_fmt_id_cnt == 0) {
                        codec_desc[idx].info.dec_fmt_id[0] = PJMEDIA_FORMAT_I420;
                        codec_desc[idx].info.dec_fmt_id_cnt = 1;
                    }

                    if (codec_desc[idx].info.fps_cnt == 0) {
                        codec_desc[idx].info.fps_cnt = 3;
                        codec_desc[idx].info.fps[0].num = 25;
                        codec_desc[idx].info.fps[0].denum = 1;
                        codec_desc[idx].info.fps[1].num = 30;
                        codec_desc[idx].info.fps[1].denum = 1;
                        codec_desc[idx].info.fps[2].num = 15;
                        codec_desc[idx].info.fps[2].denum = 1;
                    }

                    codec_desc[idx].enabled = PJ_TRUE;

                    if (codec_desc[idx].info.clock_rate == 0) {
                        codec_desc[idx].info.clock_rate = 90000;
                    }

                    codec_desc[idx].info.packings |= PJMEDIA_VID_PACKING_WHOLE | PJMEDIA_VID_PACKING_PACKETS;

                    PJ_LOG(4, (THIS_FILE, "✅ H.264 RKMPP encoder manually registered:"));
                    PJ_LOG(4, (THIS_FILE, "   enc=%p, enabled=%d, dir=0x%x",
                               codec_desc[idx].enc, codec_desc[idx].enabled, codec_desc[idx].info.dir));
                    PJ_LOG(4, (THIS_FILE, "   dec_fmt_id_cnt=%d, fps_cnt=%d",
                               codec_desc[idx].info.dec_fmt_id_cnt, codec_desc[idx].info.fps_cnt));
                } else {
                    PJ_LOG(3, (THIS_FILE, "❌ H.264 not found in codec_desc array"));
                }
            } else {
                PJ_LOG(3, (THIS_FILE, "❌ CodecID_to_pjmedia_format_id failed"));
            }
        } else {
            PJ_LOG(3,(THIS_FILE, "WARNING: Hardware encoder '%s' not found", hw_encoder_name));
        }
    }
    else if (hw_encoder_name) {
        PJ_LOG(1,(THIS_FILE, "⚠️ [FIX 100.17] Hardware encoder DISABLED (enable_hw_encoder=%d)", enable_hw_encoder));
        PJ_LOG(1,(THIS_FILE, "   Falling back to software H.264 encoder"));
        c = avcodec_find_encoder(codec_id);
        if (c) {
            PJ_LOG(1,(THIS_FILE, "✅ [FIX 100.17] Found software encoder: %s", c->name));
            init_codec(c, PJ_TRUE, PJ_FALSE);
        } else {
            PJ_LOG(1,(THIS_FILE, "❌ [FIX 100.17] No default encoder found for H.264"));
        }
    } else {
        c = avcodec_find_encoder(codec_id);
        if (c) {
            init_codec(c, PJ_TRUE, PJ_FALSE);
        }
    }

    /* ======================================== */
    /* Initialize decoder                      */
    /* ======================================== */
    if (hw_decoder_name) {
        /* Try hardware decoder first */
        c = avcodec_find_decoder_by_name(hw_decoder_name);
        if (c) {
            PJ_LOG(4,(THIS_FILE, "Found hardware decoder: %s", hw_decoder_name));
            init_codec(c, PJ_FALSE, PJ_TRUE);
        } else {
            PJ_LOG(3,(THIS_FILE,
                      "WARNING: Hardware decoder '%s' not found - "
                      "video decoding DISABLED",
                      hw_decoder_name));
        }
    } else {
        /* Other codecs: use default FFmpeg codec selection */
        c = avcodec_find_decoder(codec_id);
        if (c)
            init_codec(c, PJ_FALSE, PJ_TRUE);
    }
}

/* ======================================== */
/* ✅ [FIX 100.17] 硬件编码器注册完成      */
/* 下面的代码保留用于兼容性               */
/* ======================================== */
```

## 📊 技术原理

### FFmpeg 版本判断宏

**定义** (libavcodec/version.h)：
```c
#define LIBAVCODEC_VER_AT_LEAST(major, minor) \
    (LIBAVCODEC_VERSION_MAJOR > major || \
     (LIBAVCODEC_VERSION_MAJOR == major && LIBAVCODEC_VERSION_MINOR >= minor))
```

**当前环境**：
```c
LIBAVCODEC_VERSION_MAJOR = 58
LIBAVCODEC_VERSION_MINOR = 91
LIBAVCODEC_VERSION_MICRO = 100
```

**条件判断**：
```c
LIBAVCODEC_VER_AT_LEAST(58, 137)
= (58 > 58 || (58 == 58 && 91 >= 137))
= (FALSE || (TRUE && FALSE))
= FALSE  ← 不满足条件，代码不执行
```

### 编解码器注册优先级

**`init_codec()` 跳过重复编解码器**（line 959-965）：
```c
/* Skip duplicated codec implementation */
if ((is_encoder && (desc->info.dir & PJMEDIA_DIR_ENCODING))
    ||
    (is_decoder && (desc->info.dir & PJMEDIA_DIR_DECODING)))
{
    return;  // 跳过！
}
```

**关键点**：**第一个注册的编码器会被使用**！

**修复前（错误）**：
```
av_codec_iterate() 遍历：
  1. h264_rkmpp → init_codec() 可能失败（pix_fmts 为空）
  2. libx264rgb → init_codec() 成功注册 ✅
  3. 运行时使用 libx264rgb ❌
```

**修复后（正确）**：
```
1. h264_rkmpp 手动注册 ✅
   └─ codec_desc[idx].enc = h264_rkmpp
   └─ codec_desc[idx].info.dir |= ENCODING
2. av_codec_iterate() 遍历：
   └─ libx264rgb → init_codec()
       └─ 检查：dir & ENCODING == TRUE
           └─ return（跳过！）✅
3. 运行时使用 h264_rkmpp ✅
```

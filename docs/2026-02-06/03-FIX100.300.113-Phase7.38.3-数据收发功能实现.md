### 1. 实现 sendData() 方法

**功能**: 发送数据到串口（支持 HEX 和 ASCII 模式）

**实现要点**:
- ✅ 检查串口是否已打开
- ✅ 支持 HEX 模式（十六进制字符串）
- ✅ 支持 ASCII 模式（普通文本）
- ✅ HEX 数据转换和验证
- ✅ 发送数据并检查结果
- ✅ 部分发送失败检测
- ✅ 详细的日志输出

**代码片段**:
```cpp
void SerialPortController::sendData(const QString &data, bool isHex)
{
    // 检查串口状态
    if (!m_currentSerialPort || !m_currentSerialPort->isOpen()) {
        emit errorOccurred("串口未打开，无法发送数据");
        return;
    }

    QByteArray sendData;

    if (isHex) {
        // HEX 模式：转换十六进制字符串
        sendData = hexStringToByteArray(data);
        if (sendData.isEmpty() && !data.isEmpty()) {
            emit errorOccurred("HEX 数据转换失败");
            return;
        }
    } else {
        // ASCII 模式：直接转换
        sendData = data.toUtf8();
    }

    // 发送数据
    qint64 bytesWritten = m_currentSerialPort->write(sendData);

    if (bytesWritten == -1) {
        emit errorOccurred("发送数据失败");
    } else if (bytesWritten < sendData.size()) {
        emit errorOccurred("部分数据发送失败");
    }
}
```

### 2. 实现 handleReadyRead() 方法

**功能**: 处理串口接收到的数据

**实现要点**:
- ✅ 读取所有可用数据
- ✅ 发送 dataReceived 信号
- ✅ 更新接收缓冲区（支持 HEX/ASCII 模式）
- ✅ MODBUS 响应处理（添加到 MODBUS 缓冲区）
- ✅ 详细的日志输出

**代码片段**:
```cpp
void SerialPortController::handleReadyRead()
{
    if (!m_currentSerialPort) {
        return;
    }

    // 读取所有可用数据
    QByteArray data = m_currentSerialPort->readAll();

    if (data.isEmpty()) {
        return;
    }

    // 发送原始数据信号
    emit dataReceived(data);

    // 更新接收缓冲区
    if (m_receiveHexMode) {
        // HEX 模式：转换为十六进制字符串
        m_receiveBuffer += byteArrayToHexString(data) + " ";
    } else {
        // ASCII 模式：直接转换为字符串
        m_receiveBuffer += QString::fromUtf8(data);
    }

    emit receiveBufferChanged();

    // MODBUS 响应处理
    if (m_modbusTimer->isActive()) {
        m_modbusBuffer.append(data);
        if (isModbusResponseComplete(m_modbusBuffer)) {
            m_modbusTimer->stop();
            parseAndEmitModbusResponse();
        }
    }
}
```

### 3. 实现 hexStringToByteArray() 方法

**功能**: 将十六进制字符串转换为字节数组

**实现要点**:
- ✅ 移除空格和分隔符（空格、'-'、':'）
- ✅ 确保偶数长度（自动补0）
- ✅ 每两个字符转换为一个字节
- ✅ 无效字符检测和警告
- ✅ 详细的日志输出

**代码片段**:
```cpp
QByteArray SerialPortController::hexStringToByteArray(const QString &hex)
{
    QByteArray result;

    // 移除空格和其他分隔符
    QString cleanHex = hex.simplified().remove(' ').remove('-').remove(':');

    // 确保是偶数长度
    if (cleanHex.length() % 2 != 0) {
        cleanHex.prepend('0');
    }

    // 转换每两个字符为一个字节
    for (int i = 0; i < cleanHex.length(); i += 2) {
        QString byteString = cleanHex.mid(i, 2);
        bool ok;
        quint8 byte = byteString.toUInt(&ok, 16);
        if (ok) {
            result.append(byte);
        } else {
            qWarning() << "无效的HEX字符:" << byteString;
        }
    }

    return result;
}
```

**示例**:
- 输入: `"48 65 6C 6C 6F"` → 输出: `QByteArray("Hello")`
- 输入: `"48-65-6C-6C-6F"` → 输出: `QByteArray("Hello")`
- 输入: `"48656C6C6F"` → 输出: `QByteArray("Hello")`
- 输入: `"F"` → 输出: `QByteArray("\x0F")` (自动补0)

### 4. 实现 byteArrayToHexString() 方法

**功能**: 将字节数组转换为十六进制字符串

**实现要点**:
- ✅ 每个字节转换为两位十六进制
- ✅ 大写字母
- ✅ 前导0
- ✅ 空格分隔

**代码片段**:
```cpp
QString SerialPortController::byteArrayToHexString(const QByteArray &data)
{
    QString result;

    for (quint8 byte : data) {
        // 每个字节转换为两位十六进制（大写，前导0）
        result += QString("%1 ").arg(byte, 2, 16, QChar('0')).toUpper();
    }

    // 移除末尾的空格
    return result.trimmed();
}
```

**示例**:
- 输入: `QByteArray("Hello")` → 输出: `"48 65 6C 6C 6F"`
- 输入: `QByteArray("\x01\x02\x03")` → 输出: `"01 02 03"`
- 输入: `QByteArray("\xFF\x00\xAB")` → 输出: `"FF 00 AB"`

## 📝 注意事项

1. **HEX 格式**：
   - 支持空格分隔：`"48 65 6C"`
   - 支持连字符分隔：`"48-65-6C"`
   - 支持冒号分隔：`"48:65:6C"`
   - 支持无分隔符：`"48656C"`
   - 自动补0：`"F"` → `"0F"`

2. **接收缓冲区**：
   - HEX 模式：显示为 `"48 65 6C 6C 6F"`
   - ASCII 模式：显示为 `"Hello"`
   - 可以随时切换模式
   - 使用 clearReceiveBuffer() 清空

3. **数据信号**：
   - `dataReceived(QByteArray)` - 原始数据

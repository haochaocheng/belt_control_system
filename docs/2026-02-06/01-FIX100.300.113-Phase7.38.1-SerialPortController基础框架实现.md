## 🔧 技术细节

### 串口配置结构

```cpp
struct SerialPortConfig {
    QString portName;        // COM1, COM2, COM3, COM4, COM5, COM6
    QString devicePath;      // /dev/ttyS0, /dev/ttyS7, /dev/ttyCH9344USB0, ...
    QString portType;        // RS422, RS232, RS485
    int baudRate;            // 波特率（默认 9600）
    int dataBits;            // 数据位（默认 8）
    int stopBits;            // 停止位（默认 1）
    QString parity;          // 校验位（默认 "None"）
    bool isOpen;             // 是否打开
};
```

### 6个串口初始化

```cpp
m_serialPortConfigs = {
    {"COM1", "/dev/ttyS0", "RS422", 9600, 8, 1, "None", false},
    {"COM2", "/dev/ttyS7", "RS422", 9600, 8, 1, "None", false},
    {"COM3", "/dev/ttyCH9344USB0", "RS232", 9600, 8, 1, "None", false},
    {"COM4", "/dev/ttyCH9344USB1", "RS232", 9600, 8, 1, "None", false},
    {"COM5", "/dev/ttyCH9344USB2", "RS485", 9600, 8, 1, "None", false},
    {"COM6", "/dev/ttyCH9344USB3", "RS485", 9600, 8, 1, "None", false}
};
```

### 数据持久化

使用 QSettings 保存串口配置：
- 组织名称：BeltControl
- 应用名称：SerialPort
- 保存内容：波特率、数据位、停止位、校验位

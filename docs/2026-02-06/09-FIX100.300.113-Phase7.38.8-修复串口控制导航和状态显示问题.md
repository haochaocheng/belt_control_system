## 📋 问题描述

### 问题1：回车键无法触发按钮操作

**现象**：
- 使用导航键在"打开串口"按钮上按回车键
- 提示"当前页面未实现"
- 无法打开串口，必须使用鼠标点击

**原因**：
- SerialPortControlPage 没有实现 `handleEnterKey()` 函数
- 导航系统无法处理回车键事件

### 问题2：串口状态显示错误

**现象**：
- 打开 COM5 和 COM1 后
- 其他剩下的串口状态都显示"已打开"
- 实际上这些串口并未打开

**原因**：
- SerialPortControlPage 切换串口时，没有同步 `serialPortController.currentPortIndex`
- SerialPortController 的 `isOpen` 属性返回的是当前串口的状态
- 切换串口后，SerialPortController 不知道当前是哪个串口，导致状态显示错误

---

## 🎯 解决方案

### 修复1：添加 handleEnterKey() 函数

在 SerialPortControlPage.qml 中添加 `handleEnterKey()` 函数，处理所有焦点区域的回车键事件：

```qml
// ✅ 2026-02-06 [FIX 100.300.113 Phase 7.38.8]: 添加回车键处理函数
function handleEnterKey() {
    console.log("✅ [SerialPortControlPage] 处理回车键 - 当前焦点区域:", focusSubArea)

    // 区域0：列表区域 - 切换串口
    if (focusSubArea === 0) {
        currentSerialIndex = focusItemIndex
        loadSerialPortConfig()
        return true
    }

    // 区域1：Tab 栏区域 - 切换 Tab
    if (focusSubArea === 1) {
        if (serialConfigPanel.item) {
            serialConfigPanel.item.currentTabIndex = focusTabIndex
        }
        return true
    }

    // 区域2：参数区域 - 调用当前 Tab 的 handleEnterKey
    if (focusSubArea === 2) {
        if (serialConfigPanel.item) {
            var currentTab = serialConfigPanel.item.getCurrentTab()
            if (currentTab && typeof currentTab.handleEnterKey === "function") {
                return currentTab.handleEnterKey()
            }
        }
        return false
    }

    // 区域3：按钮区域 - 执行按钮点击
    if (focusSubArea === 3) {
        switch(focusButtonIndex) {
        case 0:  // 打开串口
            if (serialPortController.openSerialPort()) {
                console.log("✅ 串口打开成功")
            }
            return true
        case 1:  // 关闭串口
            serialPortController.closeSerialPort()
            return true
        case 2:  // 保存
            serialPortController.saveConfig()
            return true
        case 3:  // 删除
            if (serialPortController.isOpen) {
                serialPortController.closeSerialPort()
            }
            serialPortController.resetConfig()
            return true
        case 4:  // 重置
            serialPortController.resetConfig()
            return true
        }
    }

    return false
}
```

### 修复2：同步串口索引到 SerialPortController

添加 `onCurrentSerialIndexChanged` 监听器，在切换串口时同步到 SerialPortController：

```qml
// ✅ 2026-02-06 [FIX 100.300.113 Phase 7.38.8]: 监听 currentSerialIndex 变化，同步到 SerialPortController
onCurrentSerialIndexChanged: {
    console.log("✅ [SerialPortControlPage] currentSerialIndex 变化:", currentSerialIndex)
    if (currentSerialIndex >= 0 && currentSerialIndex < serialPorts.length) {
        serialPortController.currentPortIndex = currentSerialIndex
        console.log("✅ [SerialPortControlPage] 已同步到 SerialPortController.currentPortIndex:", currentSerialIndex)
    }
}
```

## 💡 技术要点

### 1. handleEnterKey() 函数设计

**设计原则**：
- 根据当前焦点区域（focusSubArea）执行不同操作
- 区域0（列表）：切换串口
- 区域1（Tab栏）：切换Tab
- 区域2（参数）：调用当前Tab的handleEnterKey
- 区域3（按钮）：执行按钮点击

**返回值**：
- `true`：表示已处理回车键事件
- `false`：表示未处理，事件继续传播

### 2. 串口索引同步机制

**数据流向**：
```
用户切换串口（导航键或鼠标）
    ↓
currentSerialIndex 变化
    ↓
onCurrentSerialIndexChanged 触发
    ↓
serialPortController.currentPortIndex = currentSerialIndex
    ↓
SerialPortController::setCurrentPortIndex()
    ↓
emit isOpenChanged()
    ↓
SerialPortParamsTab::onIsOpenChanged()
    ↓
updateStatusDisplay()
    ↓
状态指示器更新（绿色/灰色）
```

### 3. 为什么需要同步串口索引

**问题根源**：
- SerialPortController 管理6个串口的配置
- `isOpen()` 返回当前串口（`m_currentPortIndex`）的打开状态
- 如果不同步索引，SerialPortController 不知道当前是哪个串口
- 导致所有串口显示同一个状态

**解决方案**：
- 在 SerialPortControlPage 切换串口时
- 立即同步 `serialPortController.currentPortIndex`
- 确保 SerialPortController 知道当前串口
- `isOpen()` 返回正确的状态

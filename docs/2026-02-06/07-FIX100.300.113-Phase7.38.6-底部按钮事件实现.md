### 错误处理

**打开串口失败的可能原因**:
1. 串口设备不存在（设备路径错误）
2. 串口已被其他程序占用
3. 权限不足（Linux 需要 dialout 组权限）
4. 串口参数配置错误

**错误处理机制**:
```cpp
bool SerialPortController::openSerialPort()
{
    // 检查串口是否已打开
    if (m_currentSerialPort && m_currentSerialPort->isOpen()) {
        qWarning() << "⚠️ [SerialPortController] 串口已打开";
        return true;
    }

    // 尝试打开串口
    if (!m_currentSerialPort->open(QIODevice::ReadWrite)) {
        QString errorMsg = QString("打开串口失败: %1")
                          .arg(m_currentSerialPort->errorString());
        emit errorOccurred(errorMsg);
        return false;
    }

    return true;
}
```

### 配置持久化

**QSettings 存储位置**:
- Windows: `HKEY_CURRENT_USER\Software\BeltControlSystem\SerialPort`
- Linux: `~/.config/BeltControlSystem/SerialPort.conf`

## 📝 注意事项

1. **按钮状态**：
   - 打开串口按钮：只在串口关闭时启用
   - 关闭串口按钮：只在串口打开时启用
   - 保存按钮：始终启用
   - 删除按钮：始终启用
   - 重置按钮：始终启用

2. **删除 vs 重置**：
   - 删除：关闭串口 + 重置配置
   - 重置：只重置配置，不关闭串口

3. **配置持久化**：
   - 保存按钮：手动保存配置
   - 应用关闭时：不自动保存配置
   - 用户需要手动点击保存按钮

4. **错误处理**：
   - 所有操作都监听 errorOccurred 信号

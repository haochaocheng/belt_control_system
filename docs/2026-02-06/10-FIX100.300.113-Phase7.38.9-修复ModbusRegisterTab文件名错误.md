## 📋 问题描述

设备运行时提示：
```
[WARNING] qrc:/qt/qml/BeltControlQml/components/device_info/pages/ModbusRegisterTab.qml: No such file or directory
```

**现象**：
- MODBUS 寄存器参数区不显示
- 控制台输出文件找不到的警告

- CMakeLists.txt 中注册的文件名是 `ModbusRegisterSection.qml`（旧文件名）
- 实际文件已重命名为 `ModbusRegisterTab.qml`
- 导致 QML 资源系统找不到文件

---

### 修改 CMakeLists.txt

**修改前**（第106行）:
```cmake
components/device_info/pages/ModbusRegisterSection.qml
```

```cmake
components/device_info/pages/ModbusRegisterTab.qml  # ✅ 2026-02-06 [FIX 100.300.113 Phase 7.38.9]: 修正文件名（原为ModbusRegisterSection.qml）
```

### 删除旧文件

删除残留的旧文件：
```bash
rm -f src/qml/components/device_info/pages/ModbusRegisterSection.qml
```

**修改文件**:
- `src/qml/CMakeLists.txt` (第106行)
- 删除 `src/qml/components/device_info/pages/ModbusRegisterSection.qml`

## 💡 经验总结

### 问题根源
1. **文件重命名不完整**：重命名文件后，忘记更新 CMakeLists.txt
2. **旧文件残留**：旧文件没有删除，导致混淆

### 解决方案
1. **同步更新 CMakeLists.txt**：文件重命名后，立即更新 CMakeLists.txt
2. **删除旧文件**：确保旧文件被删除，避免混淆

### 最佳实践
1. **文件重命名检查清单**：
   - ✅ 重命名文件
   - ✅ 更新 CMakeLists.txt
   - ✅ 更新 .qrc 文件（如果使用）
   - ✅ 更新所有引用该文件的地方
   - ✅ 删除旧文件
   - ✅ 重新编译验证

2. **使用 Git 重命名**：
   ```bash
   git mv old_name.qml new_name.qml
   ```
   这样可以保留文件历史记录

## 🔄 相关问题

### 1. 为什么 .qrc 文件中是正确的？

**原因**：
- .qrc 文件在 2026-02-04 重命名时已经更新
- 但 CMakeLists.txt 在 2026-02-05 更新其他文件时遗漏了

### 2. 为什么编译没有报错？

**原因**：
- CMakeLists.txt 中的文件列表只是告诉 CMake 哪些文件需要包含
- 如果文件不存在，CMake 会警告但不会报错
- 运行时才会发现文件找不到

### 3. 如何避免类似问题？

**建议**：
1. 使用 IDE 的重命名功能（自动更新所有引用）
2. 重命名后立即编译验证
3. 使用 Git 的 `git mv` 命令
4. 建立文件重命名检查清单

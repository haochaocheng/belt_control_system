## 📋 任务概述

使用 Qt SerialBus 模块（QModbusRtuSerialMaster）实现 MODBUS RTU 协议支持。

---

## 🎯 实施内容

### 1. 创建 ModbusController 类

**文件**: [src/control/ModbusController.h](../../src/control/ModbusController.h), [src/control/ModbusController.cpp](../../src/control/ModbusController.cpp)

**关键特性**:
- ✅ 使用 QModbusRtuSerialMaster（Qt 官方 MODBUS 实现）
- ✅ 自动 CRC 校验
- ✅ 异步操作（不阻塞 UI）
- ✅ 完整的错误处理
- ✅ 支持主站操作

### 2. 支持的 MODBUS 功能

- ✅ **读保持寄存器**（功能码 0x03）
- ✅ **写单个寄存器**（功能码 0x06）
- ✅ **写多个寄存器**（功能码 0x10）

### 3. QML 使用示例

```qml
import QtQuick 2.15
import QtQuick.Controls 2.15

Item {
    // 配置串口
    Component.onCompleted: {
        modbusController.portName = "/dev/ttyS0"
        modbusController.baudRate = 9600
        modbusController.dataBits = 8
        modbusController.stopBits = 1
        modbusController.parity = "None"
    }

    // 连接按钮
    Button {
        text: modbusController.isConnected ? "断开" : "连接"
        onClicked: {
            if (modbusController.isConnected) {
                modbusController.disconnectDevice()
            } else {
                modbusController.connectDevice()
            }
        }
    }

    // 读取寄存器
    Button {
        text: "读取寄存器"
        enabled: modbusController.isConnected
        onClicked: {
            modbusController.readHoldingRegisters(1, 0, 10)
        }
    }

    // 写入寄存器
    Button {
        text: "写入寄存器"
        enabled: modbusController.isConnected
        onClicked: {
            modbusController.writeSingleRegister(1, 0, 100)
        }
    }

    // 处理响应
    Connections {
        target: modbusController
        function onReadRegistersFinished(serverAddress, startAddress, values) {
            console.log("读取成功:", values)
        }
        function onWriteRegisterFinished(serverAddress, address, success) {
            console.log("写入", success ? "成功" : "失败")
        }
        function onErrorOccurred(error) {
            console.error("错误:", error)
        }
    }
}
```

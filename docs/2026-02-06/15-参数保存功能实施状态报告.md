### 实现模式

参考 `MotorControlPage.qml` 的实现模式：

```qml
// 1. 收集配置参数
function collectConfig() {
    var config = {}
    config["enabled"] = statusEnabled.checked
    config["hold_time"] = parseFloat(holdTimeField.text) || 0
    // ... 其他10个参数
    return config
}

// 2. 保存配置到数据库
function saveBrakeConfig() {
    var config = collectConfig()
    var success = deviceConfigMgr.saveBrakeConfig(
        root.deviceId,
        root.brakeIndex,
        config
    )
    return success
}

// 3. 从数据库加载配置
function loadBrakeConfig() {
    var config = deviceConfigMgr.loadBrakeConfig(
        root.deviceId,
        root.brakeIndex
    )

    if (!config || Object.keys(config).length === 0) {
        return false
    }

    // 应用配置到界面
    statusEnabled.checked = config["enabled"]
    holdTimeField.text = config["hold_time"].toString()
    // ... 其他10个参数

    return true
}

// 4. 组件初始化时加载配置
Component.onCompleted: {
    loadBrakeConfig()
}

// 5. 制动器索引变化时重新加载
onBrakeIndexChanged: {
    loadBrakeConfig()
}
```

### 实现模式

参考 `TensionControlConfigPanel.qml` 的实现模式，但由于基本配置使用 Loader 加载子组件，实现方式略有不同：

```qml
// 1. 定义配置对象（在 BasicConfigPage.qml 中）
property var basicParams: ({
    machineNumber: 1,
    warningMode: 0,
    // ... 其他参数
})

// 2. 保存配置到数据库
function saveBasicParams() {
    var success = true
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "machineNumber", basicParams.machineNumber)
    // ... 其他参数
    return success
}

// 3. 从数据库加载配置
function loadBasicParams() {
    var config = deviceConfigMgr.loadAllBasicConfig(root.deviceId)
    if (!config || Object.keys(config).length === 0) {
        return false
    }
    // 应用配置到界面
    if (config.hasOwnProperty("machineNumber")) {
        basicParams.machineNumber = config["machineNumber"]
    }
    // ... 其他参数
    return true
}

// 4. 组件初始化时加载配置
Component.onCompleted: {
    loadAllConfig()
}

// 5. 设备ID变化时重新加载配置
onDeviceIdChanged: {
    loadAllConfig()
}

// 6. 传递配置对象到子组件
onLoaded: {
    if (item) {
        item.systemConfig = Qt.binding(function() { return root.basicParams })
    }
}
```

## 💡 技术要点

### 1. deviceId 传递

**问题**: BrakeConfigPanel 需要 deviceId 才能保存到正确的设备

**解决方案**:
```qml
// BrakeConfigPanel.qml
property int deviceId: 1  // 添加 deviceId 属性

// BrakeControlPage.qml
onLoaded: {
    item.deviceId = Qt.binding(function() { return root.deviceId })
    // ...
}
```

### 2. 参数收集

**模式**: 使用 `collectConfig()` 函数统一收集所有参数

```qml
function collectConfig() {
    var config = {}
    config["enabled"] = statusEnabled.checked
    config["hold_time"] = parseFloat(holdTimeField.text) || 0
    // ... 其他参数
    return config
}
```

### 3. 参数加载

**模式**: 使用 `hasOwnProperty()` 检查参数是否存在

```qml
if (config.hasOwnProperty("hold_time")) {
    holdTimeField.text = config["hold_time"].toString()
}
```

### 4. 自动加载

**触发时机**:
- 组件初始化时（`Component.onCompleted`）
- 制动器索引变化时（`onBrakeIndexChanged`）

## 📝 注意事项

1. **数据类型转换**:
   - 从界面读取：`parseFloat(field.text) || 0`
   - 写入界面：`config["field"].toString()`

2. **默认值处理**:
   - 如果数据库没有配置，使用界面默认值
   - 不强制要求所有参数都存在

3. **错误处理**:
   - 保存失败时输出错误日志
   - 加载失败时使用默认值

4. **性能优化**:
   - 只在必要时加载配置（索引变化）
   - 避免频繁的数据库操作

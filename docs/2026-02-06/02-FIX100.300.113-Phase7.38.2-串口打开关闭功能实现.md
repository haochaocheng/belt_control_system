### 1. 实现 openSerialPort() 方法

**功能**: 打开当前选中的串口

**实现要点**:
- ✅ 验证串口索引有效性
- ✅ 检查串口是否已打开（如已打开则先关闭）

- ✅ 设置串口参数（波特率、数据位、停止位、校验位）
- ✅ 设置流控制（默认无流控制）
- ✅ 打开串口（ReadWrite 模式）
- ✅ 更新状态并发送信号
- ✅ 详细的日志输出

**代码片段**:
```cpp
bool SerialPortController::openSerialPort()
{
    // 验证索引
    if (m_currentPortIndex < 0 || m_currentPortIndex >= m_serialPortConfigs.size()) {
        emit errorOccurred("无效的串口索引");
        return false;
    }

    // 获取配置
    SerialPortConfig &config = m_serialPortConfigs[m_currentPortIndex];

    // 如果已打开，先关闭
    if (config.isOpen && m_currentSerialPort && m_currentSerialPort->isOpen()) {
        closeSerialPort();
    }

    // 创建串口对象
    m_currentSerialPort = getOrCreateSerialPort(m_currentPortIndex);

    // 设置参数
    m_currentSerialPort->setPortName(config.devicePath);
    m_currentSerialPort->setBaudRate(config.baudRate);
    m_currentSerialPort->setDataBits(...);
    m_currentSerialPort->setStopBits(...);
    m_currentSerialPort->setParity(...);
    m_currentSerialPort->setFlowControl(QSerialPort::NoFlowControl);

    // 打开串口
    if (!m_currentSerialPort->open(QIODevice::ReadWrite)) {
        emit errorOccurred("无法打开串口");
        return false;
    }

    // 更新状态
    config.isOpen = true;
    emit isOpenChanged();

    return true;
}
```

### 2. 实现 closeSerialPort() 方法

**功能**: 关闭当前打开的串口

**实现要点**:

- ✅ 检查串口是否已打开
- ✅ 关闭串口
- ✅ 更新状态并发送信号
- ✅ 详细的日志输出

**代码片段**:
```cpp
void SerialPortController::closeSerialPort()
{
    // 检查串口对象
    if (!m_currentSerialPort) {
        return;
    }

    // 检查是否已打开
    if (!m_currentSerialPort->isOpen()) {
        return;
    }

    // 关闭串口
    m_currentSerialPort->close();

    // 更新状态
    if (m_currentPortIndex >= 0 && m_currentPortIndex < m_serialPortConfigs.size()) {
        m_serialPortConfigs[m_currentPortIndex].isOpen = false;
        emit isOpenChanged();
    }
}
```

### 3. 完善 handleError() 方法

**功能**: 处理串口错误并提供详细的错误信息

**实现要点**:
- ✅ 根据错误类型提供详细的错误信息
- ✅ 支持10种错误类型
- ✅ 资源错误时自动更新状态
- ✅ 发送 errorOccurred 信号

**支持的错误类型**:
1. **DeviceNotFoundError** - 设备未找到
2. **PermissionError** - 权限错误（提示检查 dialout 组）
3. **OpenError** - 打开错误
4. **WriteError** - 写入错误
5. **ReadError** - 读取错误
6. **ResourceError** - 资源错误（设备被拔出，自动关闭）
7. **UnsupportedOperationError** - 不支持的操作
8. **TimeoutError** - 超时错误
9. **NotOpenError** - 未打开错误
10. **其他** - 未知错误

**代码片段**:
```cpp
void SerialPortController::handleError(QSerialPort::SerialPortError error)
{
    if (error == QSerialPort::NoError) {
        return;
    }

    QString errorString;
    QString errorType;

    switch (error) {
    case QSerialPort::DeviceNotFoundError:
        errorType = "设备未找到";
        errorString = QString("串口设备未找到: %1").arg(...);
        break;
    case QSerialPort::PermissionError:
        errorType = "权限错误";
        errorString = QString("无权限访问串口设备: %1 (请检查用户是否在 dialout 组中)").arg(...);
        break;
    case QSerialPort::ResourceError:
        errorType = "资源错误";
        errorString = QString("串口资源错误（设备可能被拔出）: %1").arg(...);
        // 自动关闭串口
        m_serialPortConfigs[m_currentPortIndex].isOpen = false;
        emit isOpenChanged();
        break;
    // ... 其他错误类型
    }

    qWarning() << "⚠️ [SerialPortController] 串口错误 [" << errorType << "]:" << errorString;
    emit errorOccurred(errorString);
}
```

## 📝 注意事项

1. **串口权限**：
   - Linux 系统需要将用户添加到 `dialout` 组
   - 命令：`sudo usermod -a -G dialout $USER`
   - 需要重新登录才能生效

2. **设备路径**：
   - 确保设备路径正确（/dev/ttyS0, /dev/ttyCH9344USB0 等）
   - 可以使用 `ls /dev/tty*` 查看可用串口

3. **错误处理**：
   - ResourceError 会自动关闭串口并更新状态
   - PermissionError 提示用户检查权限
   - 所有错误都会通过 errorOccurred 信号通知 QML

4. **流控制**：
   - 默认使用 NoFlowControl（无流控制）
   - 如需硬件流控制，可修改为 HardwareControl
   - 如需软件流控制，可修改为 SoftwareControl

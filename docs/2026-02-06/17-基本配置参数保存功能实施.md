## 🔧 实现模式

参考 `TensionControlConfigPanel.qml` 的实现模式，但由于基本配置使用 Loader 加载子组件，实现方式略有不同：

```qml
// 1. 定义配置对象（在 BasicConfigPage.qml 中）
property var basicParams: ({
    machineNumber: 1,
    warningMode: 0,
    warningTimeSeconds: 10,
    warningPlayCount: 3,
    workMode: 0,
    localDeviceName: "1号皮带",
    speedSelection: 0,
    timeSettings: "",
    frontInterlock: 0,
    rearInterlock: 0,
    terminalType: 0,
    terminalEnabled: 0
})

property var networkParams: ({
    ipAddress: "192.168.1.100",
    subnetMask: "255.255.255.0",
    gateway: "192.168.1.1"
})

// 2. 保存基本参数配置
function saveBasicParams() {
    var success = true
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "machineNumber", basicParams.machineNumber)
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "warningMode", basicParams.warningMode)
    // ... 其他10个参数
    return success
}

// 3. 保存网络参数配置
function saveNetworkParams() {
    var success = true
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "ipAddress", networkParams.ipAddress)
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "subnetMask", networkParams.subnetMask)
    success = success && deviceConfigMgr.saveBasicConfig(root.deviceId, "gateway", networkParams.gateway)
    return success
}

// 4. 保存所有配置
function saveAllConfig() {
    var basicSuccess = saveBasicParams()
    var networkSuccess = saveNetworkParams()
    return basicSuccess && networkSuccess
}

// 5. 从数据库加载配置
function loadBasicParams() {
    var config = deviceConfigMgr.loadAllBasicConfig(root.deviceId)
    if (!config || Object.keys(config).length === 0) {
        return false
    }
    // 应用配置到界面（12个参数）
    if (config.hasOwnProperty("machineNumber")) {
        basicParams.machineNumber = config["machineNumber"]
    }
    // ... 其他11个参数
    return true
}

// 6. 组件初始化时加载配置
Component.onCompleted: {
    loadAllConfig()
}

// 7. 设备ID变化时重新加载配置
onDeviceIdChanged: {
    loadAllConfig()
}

// 8. 传递配置对象到子组件
onLoaded: {
    if (item) {
        item.systemConfig = Qt.binding(function() { return root.basicParams })
        item.networkConfig = Qt.binding(function() { return root.networkParams })
    }
}
```

## 🔄 数据流程

### 保存流程

```
用户点击保存按钮（DeviceSettingsDialog）
    ↓
DeviceSettingsDialog.saveButton.onClicked
    ↓
判断当前分类（case 0: 基本配置）
    ↓
basicConfigPageLoader.item.saveAllConfig()
    ↓
saveBasicParams() + saveNetworkParams()
    ↓
deviceConfigMgr.saveBasicConfig(deviceId, paramName, value) × 15次
    ↓
C++ DeviceConfigManager::saveBasicConfig()
    ↓
SQLite INSERT/UPDATE device_basic_config 表
    ↓
返回成功/失败状态
```

### 加载流程

```
组件初始化 / 设备ID变化
    ↓
loadAllConfig()
    ↓
loadBasicParams() + loadNetworkParams()
    ↓
deviceConfigMgr.loadAllBasicConfig(deviceId)
    ↓
C++ DeviceConfigManager::loadAllBasicConfig()
    ↓
SQLite SELECT FROM device_basic_config 表
    ↓
返回配置 QVariantMap
    ↓
应用配置到 basicParams 和 networkParams 对象
    ↓
通过 Qt.binding() 自动更新子组件界面
```

## 💡 技术要点

### 1. 配置对象模式

**问题**: BasicConfigPage 使用 Loader 加载子组件，无法直接访问子组件的输入控件

**解决方案**:
```qml
// BasicConfigPage.qml
property var basicParams: ({
    machineNumber: 1,
    warningMode: 0,
    // ... 其他参数
})

// 传递配置对象到子组件
onLoaded: {
    item.systemConfig = Qt.binding(function() { return root.basicParams })
}

// BasicParametersSection.qml
property var systemConfig: null

ParameterRow {
    value: systemConfig ? systemConfig.machineNumber.toString() : "1"
    onFieldValueChanged: function(newValue) {
        if (systemConfig) {
            systemConfig.machineNumber = parseInt(newValue)
        }
    }
}
```

### 2. 双向绑定

**说明**: 使用 Qt.binding() 保持配置对象和子组件之间的双向绑定

**实现**:
```qml
// 父组件 → 子组件（读取）
value: systemConfig ? systemConfig.machineNumber.toString() : "1"

// 子组件 → 父组件（写入）
onFieldValueChanged: function(newValue) {
    if (systemConfig) {
        systemConfig.machineNumber = parseInt(newValue)
    }
}
```

### 3. 参数名称存储

**说明**: 基本配置使用参数名称作为键值存储，而不是使用固定的表结构

**API**:
```cpp
// 保存单个参数
Q_INVOKABLE bool saveBasicConfig(int deviceId, const QString &paramName, const QVariant &value);

// 加载单个参数
Q_INVOKABLE QVariant loadBasicConfig(int deviceId, const QString &paramName);

// 加载所有参数
Q_INVOKABLE QVariantMap loadAllBasicConfig(int deviceId);
```

### 4. 统一保存按钮

**说明**: DeviceSettingsDialog 有一个统一的保存按钮，根据当前分类调用对应的保存函数

**实现**:
```qml
onClicked: {
    switch(root.currentCategory) {
    case 0:  // 基本配置
        if (basicConfigPageLoader.item && typeof basicConfigPageLoader.item.saveAllConfig === "function") {
            basicConfigPageLoader.item.saveAllConfig()
        }
        break
    // ... 其他分类
    }
}
```

### 5. 自动加载

**触发时机**:
- 组件初始化时（`Component.onCompleted`）
- 设备ID变化时（`onDeviceIdChanged`）

## 📝 注意事项

1. **数据类型转换**:
   - 从界面读取：`parseInt(newValue)` 或 `newValue`
   - 写入界面：`config["field"].toString()`

2. **默认值处理**:
   - 如果数据库没有配置，使用界面默认值
   - 不强制要求所有参数都存在

3. **错误处理**:
   - 保存失败时输出错误日志
   - 加载失败时使用默认值

4. **性能优化**:
   - 只在必要时加载配置（设备ID变化）
   - 避免频繁的数据库操作

5. **配置对象模式**:
   - 使用配置对象统一管理参数
   - 通过 Qt.binding() 保持双向绑定
   - 子组件通过信号通知父组件参数变化

6. **参数名称存储**:
   - 基本配置使用参数名称作为键值
   - 灵活性高，易于扩展
   - 需要确保参数名称一致性

🐛 问题分析

为什么会连续出现 5 次错误？

  • 根本原因：增量开发 + 不完整的依赖检查 + 缺少自动化验证
  • 错误链：
    1. device_monitor 组件存在但未注册到 CMakeLists.txt
    2. VoiceManagement 页面开发完成但未集成到 App.qml
    3. DeviceMonitorPage 使用 theme 组件但未导入模块
    4. VoiceManagement 导入 com.belt.control 但未在 main.cpp 注册
    5. 所有页面设置固定尺寸导致 SwipeView 布局冲突
  • 教训：
    • 新建 QML 页面时，必须检查所有 import 语句的依赖
    • 使用 C++ 单例时，必须在 main.cpp 中注册
    • SwipeView 的子页面不应设置固定尺寸，应使用 anchors.fill
    • 需要创建自动化依赖检查脚本

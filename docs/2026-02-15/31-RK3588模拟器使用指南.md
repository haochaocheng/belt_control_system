## 🔧 常用命令

### 查看日志

```powershell
# 查看所有日志
docker logs -f belt-control-sim

# 查看应用日志
docker exec belt-control-sim tail -f /var/log/supervisor/app.log

# 查看错误日志
docker exec belt-control-sim tail -f /var/log/supervisor/app_error.log
```

### 管理容器

```powershell
# 停止模拟器
docker stop belt-control-sim

# 启动模拟器
docker start belt-control-sim

# 重启模拟器
docker restart belt-control-sim

# 删除容器
docker rm -f belt-control-sim
```

### 进入容器

```powershell
# 进入容器shell
docker exec -it belt-control-sim bash

# 查看进程
docker exec belt-control-sim ps aux

# 查看Qt环境
docker exec belt-control-sim env | grep QT
```

## 🐛 故障排查

### 问题1：界面不显示

**症状**: 浏览器打开后显示黑屏或连接失败

**解决方案**:
1. 等待10-15秒让服务完全启动
2. 刷新浏览器
3. 检查日志：`docker logs belt-control-sim`

### 问题2：应用崩溃

**症状**: 界面闪退或无响应

**解决方案**:
```powershell
# 查看错误日志
docker exec belt-control-sim tail -n 100 /var/log/supervisor/app_error.log

# 重启应用
docker restart belt-control-sim
```

### 问题3：端口被占用

**症状**: 启动失败，提示端口已被使用

**解决方案**:
```powershell
# 查找占用端口的进程
netstat -ano | findstr "6080"
netstat -ano | findstr "5901"

# 停止旧容器
docker stop belt-control-sim
docker rm belt-control-sim
```

### 问题4：Docker镜像构建失败

**症状**: 构建过程中出错

**解决方案**:
```powershell
# 清理Docker缓存
docker system prune -a

# 重新构建
docker build -t belt-control-simulator:latest -f docker/rk3588-simulator/Dockerfile .
```

## 📝 技术细节

### 架构说明

```
Windows宿主机
    ↓
Docker Desktop (QEMU用户模式)
    ↓
Ubuntu 24.04 ARM64容器
    ↓
├── Xvfb (虚拟显示服务器 :1)
├── x11vnc (VNC服务器 :5901)
├── noVNC (Web界面 :6080)
└── belt_control_system (应用程序)
```

### 目录挂载

| 宿主机路径 | 容器路径 | 说明 |
|-----------|---------|------|
| `build_rk3588/bin_arm64/` | `/app/` | 应用程序 |
| `docker/rk3588/lib/` | `/app/lib/` | 依赖库 |
| `config/` | `/app/config/` | 配置文件 |

### 环境变量

| 变量 | 值 | 说明 |
|------|---|------|
| `DISPLAY` | `:1` | X11显示编号 |
| `LD_LIBRARY_PATH` | `/app/lib` | 库搜索路径 |
| `QT_QPA_PLATFORM` | `xcb` | Qt平台插件 |

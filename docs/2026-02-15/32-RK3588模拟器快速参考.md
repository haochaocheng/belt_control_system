# RK3588模拟器 - 快速参考

## 🚀 一键启动

```powershell
.\build-ubuntu24-apt.ps1 simulator
```

## 📺 访问界面

浏览器自动打开：**http://localhost:6080**

## 🔧 常用命令

```powershell
# 查看日志
docker logs -f belt-control-sim

# 重启
docker restart belt-control-sim

# 停止
docker stop belt-control-sim

# 进入容器
docker exec -it belt-control-sim bash
```

## 💡 使用场景

| 场景 | 使用设备 |
|------|---------|
| 界面开发 | ✅ 模拟器 |
| 功能测试 | ✅ 模拟器 |
| 性能测试 | ❌ 实体设备 |
| 硬件测试 | ❌ 实体设备 |

## 🔄 切换方式

```powershell
# 模拟器
.\build-ubuntu24-apt.ps1 simulator

# 实体设备
.\build-ubuntu24-apt.ps1 188
```

## ⚠️ 限制

- ❌ 无硬件加速（RK MPP）
- ❌ 无GPIO/串口/CAN
- ⚠️ 性能约为实体设备的30-50%

## 💡 根本原因

### 1. 官方模型库更新
- 百度PaddleSpeech团队可能清理了旧版本模型
- PWG声码器被HiFiGAN取代
- 部分FastSpeech2模型版本更新

### 2. URL来源问题
- 我们使用的URL来自旧版文档
- 官方可能更新了模型存储路径
- 需要从最新的官方文档获取URL

### 3. 模型版本策略
- 官方可能只保留最新版本
- 旧版本模型被自动清理
- 需要使用PaddleSpeech自动下载功能

## ✅ 解决方案

### 方案1：使用PaddleSpeech自动下载（推荐）⭐

**原理**：
- 让PaddleSpeech的TTSExecutor自动下载模型
- 它会使用最新的官方URL
- 自动处理版本兼容性

**优点**：
- ✅ 自动使用最新版本
- ✅ 不需要手动查找URL
- ✅ 官方维护，稳定可靠
- ✅ 自动处理依赖关系

**实施脚本**：
```powershell
.\scripts\2026-02-15\09-auto-download-models-via-tts.ps1
```

**工作原理**：
```python
from paddlespeech.cli.tts import TTSExecutor

tts = TTSExecutor()

# 第一次调用会自动下载模型
tts(
    text='测试',
    output='test.wav',
    am='fastspeech2_csmsc',  # 自动下载最新版本
    voc='pwgan_csmsc',       # 自动下载最新版本
    lang='zh'
)
```

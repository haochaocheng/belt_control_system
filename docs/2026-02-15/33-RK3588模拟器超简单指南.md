# RK3588模拟器 - 超简单使用指南

## 🚀 一键启动

```powershell
.\build-ubuntu24-apt.ps1 simulator
```

**等待15秒后**，浏览器会自动打开 http://localhost:6080

## 📺 看到什么？

- **第一次启动**：黑屏或Ubuntu桌面（因为应用程序还没编译）
- **编译后启动**：可以看到QML应用界面

## 🔧 如何使用？

### 第一次使用（开发界面）

1. **启动模拟器**
   ```powershell
   .\build-ubuntu24-apt.ps1 simulator
   ```

2. **访问VNC**
   - 浏览器自动打开：http://localhost:6080
   - 你会看到一个黑屏或Ubuntu桌面（正常的，因为应用还没编译）

3. **这就够了！**
   - VNC环境已经运行
   - 可以用来测试Qt/QML是否能正常显示

### 编译应用后使用

1. **编译应用**
   ```powershell
   .\build-ubuntu24-apt.ps1 188
   ```

2. **重启模拟器**
   ```powershell
   docker restart belt-control-sim
   ```

3. **访问界面**
   - 打开浏览器：http://localhost:6080
   - 现在可以看到你的QML应用了！

## ⚠️ 常见问题

### 问题1：浏览器打开后看不到东西

**原因**：VNC服务还在启动中

**解决**：
- 等待10-15秒
- 刷新浏览器（F5）

### 问题2：看到黑屏

**原因**：应用程序还没编译

**解决**：
- 这是正常的！
- 先编译应用：`.\build-ubuntu24-apt.ps1 188`
- 然后重启容器：`docker restart belt-control-sim`

### 问题3：想停止模拟器

```powershell
docker stop belt-control-sim
```

## 💡 核心理念

**模拟器 = VNC桌面环境**

- 就像远程桌面一样
- 可以在里面运行任何GUI程序
- 不需要实体RK3588设备

## 📝 总结

1. **启动模拟器** → `.\build-ubuntu24-apt.ps1 simulator`
2. **等15秒** → 让VNC服务启动
3. **打开浏览器** → http://localhost:6080
4. **看到界面** → 黑屏是正常的（应用未编译）

**就这么简单！**

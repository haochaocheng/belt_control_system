### 发现的问题

1. **"电流一"和"电流二"没有对应的音频文件** - BatchAudioGenerator 未定义电流相关音频
2. **"低速打滑"有音频但DB无保护项** - BatchAudioGenerator 定义了，但DB默认保护列表中没有
3. **名称不一致**：DB用"速度"，音频文件叫"速度超速"；DB用"红外温度一"，音频叫"温度一过高"
4. **一对多关系**：DB中"张力"是一个保护项，但BatchAudio有"张力过大"和"张力过小"两个文件

## 四、模拟量保护触发链路现状

### 当前实现状态

| 环节 | 开关量(DI) | 模拟量(AI) | 差距 |
|------|-----------|-----------|------|
| 数据采集 | DIDataManager ✅ | AIDataManager ✅ | 无 |
| 变化检测 | bitChanged 信号 ✅ | channelChanged 信号 ✅ | 无 |
| 保护判断 | MqttProtectionMonitor.onBitChanged() ✅ | **未实现** | ❌ 缺少 |
| DB配置读取 | loadDigitalProtection() ✅ | loadAnalogProtection() ✅ | 无 |
| 音频路径生成 | AudioPathMapper.getAudioPath() ✅ | **部分实现** | ⚠️ 名称映射不匹配 |
| 播放触发 | AlarmPlaybackService.playAlarm() ✅ | **未连接** | ❌ 缺少 |
| 音频文件 | 设备已有 ✅ | **设备未生成** | ❌ 需生成 |

### 需要补充的工作

1. **MqttProtectionMonitor 添加模拟量保护监控**
   - 监听 AIDataManager 的 channelChanged 信号
   - 对比上下限阈值
   - 超限时触发 AlarmPlaybackService

2. **AudioPathMapper 添加模拟量名称映射**
   - 类似 `getProtectionName(bitIndex)` 但用于模拟量

3. **BatchAudioGenerator 补充缺失音频**
   - 添加"电流过载"项

4. **在设备上运行批量合成生成音频文件**

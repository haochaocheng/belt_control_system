# 模拟量输入保护参数布局规划

## 时间
2026-03-04 17:30 (北京时间)

## 目标
将开关量输入已有的参数（数据超时、连接超时、播放方式、保护级别、音频来源按钮组）
同步添加到模拟量输入保护参数设置界面。

## 三、模拟量输入新布局（规划方案）

```
┌─────────────────────────────────────────────────────┐
│  左列 (col 0-1)           │  右列 (col 2-3)         │
├───────────────────────────┼─────────────────────────┤
│ Row 0: 保护名称 (0)       │  播放次数 (1)           │
│        [文本输入框]        │  [数字SpinBox]          │
│                           │                         │
│ Row 1: 模块类型 (2)       │  播放时长 (3)           │
│        [下拉选择框]        │  [数字SpinBox]          │
│                           │                         │
│ Row 2: 音频来源 (4)       │  TTS文字 (5)            │
│        [默认][TTS]按钮组   │  [文本输入框]           │
│                           │                         │
│ Row 3: 通道编号 (6)       │  音频文件 (7)           │
│        [数字SpinBox]       │  [文本输入框]           │
│                           │                         │
│ Row 4: 上限值 (8)         │  保护延时 (9)           │
│        [数字SpinBox]       │  [数字SpinBox]          │
│                           │                         │
│ Row 5: 下限值 (10)        │  数据超时 (11)          │
│        [数字SpinBox]       │  [数字SpinBox]          │
│                           │                         │
│ Row 6: 单位 (12)          │  连接超时 (13)          │
│        [下拉选择框]        │  [数字SpinBox]          │
│                           │                         │
│ Row 7: 量程 (14)          │  播放方式 (15)          │
│        [数字SpinBox]       │  [按次数][按时长]按钮组  │
│                           │                         │
│ Row 8: (空)               │  保护级别 (16)          │
│                           │  [下拉选择框]           │
├───────────────────────────┴─────────────────────────┤
│  [保存] [取消] [删除] [...]  底部按钮               │
└─────────────────────────────────────────────────────┘
```

参数总数：17个 (索引 0-16)

### 新增参数说明

| 索引 | 参数名 | 控件类型 | 默认值 | 备注 |
|------|--------|---------|--------|------|
| 4 | 音频来源 | 按钮组 | TTS合成 | 替换原 RadioButton，统一为按钮组样式 |
| 9 | 保护延时 | SpinBox (0.1s精度) | 1.0s | 位置从左列移到右列 |
| 11 | 数据超时 | SpinBox (秒) | 30s | 新增 |
| 13 | 连接超时 | SpinBox (秒) | 60s | 新增 |
| 15 | 播放方式 | 按钮组 | 按次数 | 新增，[按次数][按时长] |
| 16 | 保护级别 | 下拉框 | 正常停车预警 | 新增，4级选择 |

### 布局变化对比

| 项目 | 旧 | 新 | 变化 |
|------|-----|-----|------|
| 参数数量 | 14 | 17 | +3个（数据超时、连接超时、播放方式、保护级别新增，音频来源替换语音报警） |
| 行数 | 7 | 9 | +2行 |
| 音频来源样式 | RadioButton | 按钮组 | 统一与开关量一致 |
| 寄存器地址 | 可见(索引4) | 隐藏 | 由模块类型自动设置（与开关量一致） |
| 保护延时位置 | Row 0 右列 | Row 4 右列 | 调整位置，与开关量布局对齐 |

### 导航顺序

键盘 Up/Down 导航（同列 +2 步进）：
- 左列：0→2→4→6→8→10→12→14→按钮
- 右列：1→3→5→7→9→11→13→15→16→按钮

## 四、数据库变更

`saveAnalogProtection()` 需要添加的字段：
- `play_mode` TEXT DEFAULT 'count'
- `protection_level` INTEGER DEFAULT 1
- `data_timeout` REAL DEFAULT 30.0 （需新增 ALTER TABLE）
- `connection_timeout` REAL DEFAULT 60.0 （需新增 ALTER TABLE）

`loadAnalogProtection()` 使用 SELECT *，新列自动包含。

---

## 五、需确认事项

1. 上限值/下限值/单位/量程 的位置是否合理？
2. 是否需要隐藏寄存器地址（与开关量一致）？
3. 保护级别的4个选项是否与开关量相同？
   - 0: 紧急停车预警
   - 1: 正常停车预警
   - 2: 仅预警
   - 3: 不处理

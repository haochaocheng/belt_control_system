## 📋 执行摘要

### 项目背景

当前系统有12个设备（1-8号皮带 + 转载机 + 破碎机 + 前刮板 + 后刮板），每个设备都有完整的参数设置界面。但现有设计存在以下问题：

1. **角色不清晰**：无法区分哪个是本机，哪个是从机
2. **权限混乱**：所有设备参数都可以修改，容易误操作
3. **缺少监控**：没有统一的设备状态监控界面
4. **集控架构不明确**：不支持主站/分站模式

### 解决方案

实施主从机动态切换架构，支持：

- ✅ **主站/分站模式**：支持1台主站 + 多台分站
- ✅ **动态角色切换**：可随时切换本机角色（主站/分站）和控制设备（1-8号皮带）
- ✅ **权限控制**：本机可编辑参数，从机只读
- ✅ **设备监控**：统一监控所有设备状态
- ✅ **MQTT 通信**：实时同步设备状态

### 核心价值

1. **清晰的角色定位**：一眼看出本机和从机
2. **灵活的配置**：支持2台、3台或更多集控设备
3. **严格的权限控制**：防止误操作
4. **实时状态监控**：12个设备状态一目了然

### 2. 主站/分站模式

#### 主站（Master Station）
- **职责**：整个综采面的集中控制
- **权限**：可监控所有设备，可发送控制命令
- **数量**：通常只有1台
- **控制设备**：1-8号皮带中的任意一台

#### 分站（Sub Station）
- **职责**：控制本地设备
- **权限**：可监控本地设备和其他设备状态，接收主站命令
- **数量**：可以有多台（根据现场需要）
- **控制设备**：1-8号皮带中的任意一台

#### 动态发现机制
- 通过 MQTT 自动发现在线的集控设备
- 集控台数不固定，可能是2台、3台或更多
- 支持热插拔，设备上线/离线自动更新

### 3. 数据模型

#### DeviceRoleManager 类设计

**文件**: `src/control/DeviceRoleManager.h/cpp`

**核心功能**：
- 管理设备角色（主站/分站）
- 管理本机设备ID（1-8号皮带）
- 权限控制（本机可编辑，从机只读）
- 设备状态管理
- 配置文件持久化

**主要属性**：
- `localDeviceId`: 本机设备ID（1-8）
- `stationRole`: 本机角色（"master" 或 "sub"）
- `allDevices`: 所有设备信息列表
- `allStations`: 所有集控设备信息列表

**主要方法**：
- `setLocalDeviceId()`: 设置本机设备ID
- `setStationRole()`: 设置本机角色
- `isLocalDevice()`: 检查是否为本机
- `hasPermission()`: 检查是否有权限修改
- `saveToConfig()`: 保存到配置文件
- `loadFromConfig()`: 从配置文件加载

## 📡 MQTT 通信设计

### 1. 主题结构

#### 集控设备状态主题
```
station/status/{stationId}  # 集控设备状态发布主题
station/status/+            # 订阅所有集控设备状态
```

**数据格式**：
```json
{
  "stationId": 1,
  "stationRole": "master",
  "stationName": "主站",
  "controlDevice": "1号皮带",
  "controlDeviceId": 1,
  "ip": "192.168.10.188",
  "isOnline": true,
  "status": "running",
  "timestamp": "2026-02-10T15:30:25"
}
```

#### 设备状态主题
```
device/status/{deviceId}  # 设备状态发布主题
device/status/+           # 订阅所有设备状态
```

**数据格式**：
```json
{
  "deviceId": 1,
  "deviceName": "1号皮带",
  "deviceType": "belt",
  "isOnline": true,
  "status": "running",
  "speed": 1.2,
  "current": 25.3,
  "temperature": 45.2,
  "timestamp": "2026-02-10T15:30:25"
}
```

### 2. 通信流程

#### 本机发布
- 每秒发布一次本机状态到 `station/status/{stationId}`
- 每秒发布一次本机控制设备状态到 `device/status/{deviceId}`

#### 本机订阅
- 订阅所有集控设备状态 `station/status/+`
- 订阅所有设备状态 `device/status/+`

#### 动态发现
- 通过 MQTT 消息自动发现在线的集控设备
- 超过5秒未收到消息，标记为离线

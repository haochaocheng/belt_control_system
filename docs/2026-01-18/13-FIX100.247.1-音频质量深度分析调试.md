## 📋 问题背景

### 用户反馈
- **主要问题**: "对方听不清声音"
- **关键信息**:
  - 使用虚拟设备时，音质稍微清楚一些（但仍不正常）
  - 该麦克风在其他场景工作正常
  - FIX 100.247 测试显示音频采集正常（非静音、无错误）

### FIX 100.247 测试结果分析

**✅ 确认正常的部分**:
1. 音频不是静音 (`Silent: NO ✅`)
2. 100% 非零采样 (`Non-zero samples: 640/640`)
3. 无设备错误 (`errors=0`)
4. 无 OVERRUN 错误
5. 网络传输正常 (RTP 丢包率 0%)

**⚠️ 观察到的现象**:
1. 振幅波动较大: 7696 → 32768 → 8400 → 12244
2. Capture delay buffer 频繁调整
3. 虚拟设备和 USB 麦克风都有问题（排除设备类型因素）

---

## 🎯 FIX 100.247.1 目标

**核心目标**: 添加更详细的调试信息，精确定位音质不清晰的根本原因

**调试策略**:
1. **设备参数验证**: 对比请求参数与实际硬件参数，检测参数不匹配
2. **ALSA 设备状态监控**: 实时监控设备状态、缓冲区可用性、延迟
3. **音频质量深度分析**: RMS、动态范围、过零率、振幅分布
4. **智能警告系统**: 自动识别常见问题（音量过低、失真、DC 偏置等）

### 3️⃣ 音频质量深度分析

**位置**: `ca_thread_func()` 函数，line 699-782

**分析指标**:

#### 📊 振幅统计
```c
int min_amplitude = 32767;     // 最小振幅
int max_amplitude = 0;         // 最大振幅
long long sum_amplitude = 0;   // 绝对值和（用于计算平均值）
long long sum_squared = 0;     // 平方和（用于计算 RMS）

// 输出
PJ_LOG (3,(THIS_FILE, "📊 [AMPLITUDE] Min: %d, Max: %d, Avg: %d, RMS: %d", ...));
```

**RMS (均方根)**: 更准确的音量测量
- 正常语音: RMS > 500
- 小声说话: RMS 100-500
- 音量过低: RMS < 100 ⚠️

#### 🔊 音量分析
```c
int low_volume_count = 0;  // 低音量采样数（振幅 < 100）

PJ_LOG (3,(THIS_FILE, "🔊 [VOLUME] Low volume samples (<100): %d/%d (%.1f%%), Dynamic range: %.1f dB", ...));
```

**动态范围 (dB)**:
```
动态范围 = 20 * log10(最大振幅 / 平均振幅)
```
- 正常语音: 15-30 dB
- 动态范围过小: 音质可能失真

#### 📈 波形分析
```c
int zero_crossings = 0;  // 过零次数

PJ_LOG (3,(THIS_FILE, "📈 [WAVEFORM] Zero crossings: %d, Rate: %.2f Hz (at 16kHz sample rate)", ...));
```

**过零率 (Zero Crossing Rate)**:
- 衡量信号频率特性
- 过零率过低 (< 10): 可能 DC 偏置或失真 ⚠️
- 正常语音: 过零率 20-100

## 🔍 可能的问题根因猜测

基于现有信息，可能的根因包括：

### 1. **采样率转换问题**
- **现象**: 设备实际采样率与 PJSIP 请求不匹配
- **影响**: 音质劣化、失真
- **验证**: 查看 `[VERIFY]` 日志的采样率不匹配警告

### 2. **麦克风增益过低**
- **现象**: RMS 值过低（< 100）
- **影响**: 音量太小，听不清
- **验证**: 查看 `[AMPLITUDE]` 日志的 RMS 值

### 3. **音频格式不匹配**
- **现象**: 请求 S16_LE，实际 S8 或其他格式
- **影响**: 音质损失、失真
- **验证**: 查看 `[VERIFY]` 日志的格式不匹配警告

### 4. **ALSA 设备状态异常**
- **现象**: 设备不在 RUNNING 状态，或频繁 XRUN
- **影响**: 丢帧、音质不稳定
- **验证**: 查看 `[ALSA STATUS]` 日志

### 5. **重采样或音频处理管道问题**
- **现象**: 正常的动态范围被压缩
- **影响**: 音质失真、不自然
- **验证**: 查看动态范围 dB 值

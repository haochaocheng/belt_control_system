## 📊 预期效果对比

### 修改前（当前）

**设备枚举**:
```
Device 5: hw:CARD=camera,DEV=0 ← 被选中（错误）
Device 6: plughw:CARD=camera,DEV=0 ← 被跳过
```

**音频流程**:
```
USB 麦克风 (22050 Hz 硬件原生)
  ↓ hw: 设备不支持 16000 Hz，返回 22050 Hz
PJSIP 请求 16000 Hz，实际得到 22050 Hz
  ↓ 重采样 #1 (PJSIP 内部)
PJSIP 处理 (16000 Hz)
  ↓ 重采样 #2 (PJSIP 内部)
PCMA 编码 (8000 Hz)
```

**问题**:
- ❌ 采样率不匹配（请求 16k，得到 22.05k）
- ❌ 两次 PJSIP 内部重采样
- ❌ 音质劣化严重
- ❌ 对方听不清声音

---

### 修改后（FIX 100.248）

**设备枚举**:
```
Device 5: hw:CARD=camera,DEV=0 ← 暂存为备选
Device 6: plughw:CARD=camera,DEV=0 ← 被选中（正确）✅
```

**音频流程**:
```
USB 麦克风 (22050 Hz 硬件原生)
  ↓ ALSA 重采样（一次，by plughw）
8000 Hz ← plughw 设备支持所有采样率
  ↓ 无需重采样 ✅
PJSIP 处理 (8000 Hz)
  ↓ 无需重采样 ✅
PCMA 编码 (8000 Hz)
```

**优势**:
- ✅ 采样率完美匹配（请求 8k，得到 8k）
- ✅ 零 PJSIP 内部重采样
- ✅ 音质提升（重采样次数：2 → 1）
- ✅ 在任意设备都能工作

## ⚠️ 可能的警告（正常）

如果看到以下警告，**这是正常的**：

```
⚠️ [WARNING] Sample rate mismatch! Requested: 8000, Actual: 8001
```

**原因**: ALSA 重采样可能有微小的采样率偏差（8000 vs 8001）
**影响**: 可以忽略，不影响音质

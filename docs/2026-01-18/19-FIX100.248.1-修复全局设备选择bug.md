**问题**: FIX 100.248 配置正确但未生效，仍使用 hw 设备
**状态**: ✅ 已修复

## 🐛 问题现象

### 用户报告

1. **配置日志正确**:
   ```
   🔧 [FIX 100.248] Audio media configuration:
      Clock rate: 8000 Hz (PCMA/PCMU compatible)
      Channels: 1 (mono, VoIP standard)
   ```

2. **设备枚举正确**:

   ```
   Device 5: hw:CARD=camera,DEV=0 ← 暂存为备选
   Device 6: plughw:CARD=camera,DEV=0 ← 添加到列表 ✅
   ```

3. **但实际使用错误**:

   ```
   Device 5: hw:CARD=camera,DEV=0 ← 被选中（错误！）
      ✅ Selected as capture device (input)

   Capture device opened successfully:
      Device name: hw:CARD=camera,DEV=0
      Sample rate: 48000 Hz (requested: 8000)  ← 采样率不匹配！
   ```

4. **结果**: 音质仍然不清晰

## 🔍 根本原因

### 双重设备选择逻辑

项目中有**两个地方**选择音频设备：

1. **SipPhoneManager.cpp**（用户可见的设备列表）:
   - ✅ FIX 100.248 已正确实现：优先选择 plughw

2. **risipendpoint.cpp**（PJSIP 全局设备配置）:
   - ❌ **Bug**: 仍使用旧逻辑，优先选择 hw 设备

### 代码问题（risipendpoint.cpp Line 698-711）

**错误逻辑**:
```cpp
if (dev_info.input_count > 0 && !isLoopback && !isDefault) {
    // 优先选择 plughw 设备
    if (dev_name.startsWith("plughw:")) {
        if (best_capture_dev == -1) {
            best_capture_dev = i;
        }
    }
    // 如果还没找到，接受任何非虚拟设备
    else if (best_capture_dev == -1) {  // ← ❌ Bug 在这里！
        best_capture_dev = i;  // hw 设备先出现，被选中
    }
}
```

**问题流程**:
1. 遍历到 Device 5: `hw:CARD=camera,DEV=0`
   - 不是 plughw，进入 else 分支
   - `best_capture_dev == -1`，被选中 ❌
2. 遍历到 Device 6: `plughw:CARD=camera,DEV=0`
   - 是 plughw，但 `best_capture_dev != -1`
   - 被跳过 ❌

**结果**: 选择了 hw 设备，而不是 plughw

---

## ✅ 修复方案

### 正确逻辑：直接覆盖

**文件**: `src/risip/core/risipendpoint.cpp` Line 698-721

**修改内容**:
```cpp
// ✅ 2026-01-18 23:00 [FIX 100.248.1] 修复设备选择bug - 优先选择 plughw 而不是 hw
// 问题：当 hw: 设备先出现时，它被选中，plughw: 被跳过
// 解决：先选择 plughw，如果没有才暂存 hw 作为备选
// 策略：遍历所有设备，plughw 立即选中，hw 暂存为备选

// 寻找最佳输入设备（麦克风）
// 优先级：plughw真实设备 > hw真实设备（暂存为备选）
if (dev_info.input_count > 0 && !isLoopback && !isDefault) {
    // 情况 1: plughw 设备 - 立即选中（最高优先级）
    if (isPlughw) {
        best_capture_dev = i;  // 直接覆盖之前的 hw 设备 ⭐
        qDebug() << "      ✅ Selected as capture device (plughw, priority) ⭐";
    }
    // 情况 2: hw 设备 - 仅在没有 plughw 时作为备选
    else if (isHw && best_capture_dev == -1) {
        best_capture_dev = i;
        qDebug() << "      📦 Selected as capture device (hw, fallback)";
        qDebug() << "         [WAITING] Will be replaced if plughw: is found";
    }
    // 情况 3: 其他设备 - 跳过
    else {
        qDebug() << "      ⏭️ SKIPPED (not plughw or hw):" << dev_name;
    }
}
```

**关键改进**:
- ✅ plughw 设备**直接覆盖** `best_capture_dev`（不检查是否为 -1）
- ✅ hw 设备**仅在** `best_capture_dev == -1` 时暂存
- ✅ 确保 plughw 总是优先于 hw

### 同样修复输出设备（扬声器）

**文件**: `src/risip/core/risipendpoint.cpp` Line 723-749

```cpp
// 寻找最佳输出设备（扬声器）
// 优先级：plughw真实设备 > hw真实设备（暂存为备选）
if (!isLoopback && !isDefault) {
    bool has_output = dev_info.output_count > 0;

    // 情况 1: plughw 设备 - 立即选中（即使 output_count=0）
    if (isPlughw) {
        best_playback_dev = i;  // 直接覆盖之前的 hw 设备 ⭐
        if (has_output) {
            qDebug() << "      ✅ Selected as playback device (plughw, priority) ⭐";
        } else {
            qDebug() << "      ✅ FORCE select plughw device (bypass output_count=0 ALSA bug) ⭐";
        }
    }
    // 情况 2: hw 设备 - 仅在没有 plughw 且有输出时作为备选
    else if (isHw && has_output && best_playback_dev == -1) {
        best_playback_dev = i;
        qDebug() << "      📦 Selected as playback device (hw, fallback)";
        qDebug() << "         [WAITING] Will be replaced if plughw: is found";
    }
    // 情况 3: 其他设备 - 必须有输出
    else if (!isHw && !isPlughw && has_output && best_playback_dev == -1) {
        best_playback_dev = i;
        qDebug() << "      ✅ Selected as playback device (output)";
    }
}
```

## 📊 附加修复：减少日志输出

### 问题

用户报告日志输出大量的 FIX 100.247.1 调试信息：
```

10:21:15.696  🎤 [AUDIO QUALITY] Silent: NO ✅, Non-zero: 160/160 (100.0%)
10:21:15.696  📊 [AMPLITUDE] Min: 52, Max: 11952, Avg: 5171, RMS: 6100
10:21:15.696  🔊 [VOLUME] Low volume samples (<100): 1/160 (0.6%)...
10:21:15.696  📈 [WAVEFORM] Zero crossings: 13, Rate: 1300.00 Hz...
```

这些日志**每帧**都输出，导致日志爆炸。

### 修复

**文件**: `cross-compile/src/pjproject-2.16/pjmedia/src/pjmedia-audiodev/alsa_dev.c` Line 752-785

**修改内容**:
```c
/* ❌ 2026-01-18 23:00 旧代码：输出过多详细统计（每帧都输出，导致日志爆炸）
PJ_LOG (3,(THIS_FILE, "✅ [FIX 100.247.1] Capture stats: ..."));
PJ_LOG (3,(THIS_FILE, "🎤 [AUDIO QUALITY] Silent: ..."));
PJ_LOG (3,(THIS_FILE, "📊 [AMPLITUDE] Min: ..."));
PJ_LOG (3,(THIS_FILE, "🔊 [VOLUME] Low volume samples: ..."));
PJ_LOG (3,(THIS_FILE, "📈 [WAVEFORM] Zero crossings: ..."));
*/

/* ✅ 2026-01-18 23:00 [FIX 100.248.1] 只在检测到问题时输出警告，减少日志 */
/* 警告信息 */
if (is_silent) {
    PJ_LOG (3,(THIS_FILE, "⚠️⚠️⚠️ [WARNING] Audio is SILENT! Microphone may not be working!"));
} else if (rms < 100) {
    PJ_LOG (3,(THIS_FILE, "⚠️ [WARNING] RMS too low (%d < 100)! Microphone volume may be too low!", rms));
} else if (low_volume_count > sample_count * 0.9) {
    PJ_LOG (3,(THIS_FILE, "⚠️ [WARNING] 90%% samples have low amplitude! Check microphone gain!"));
} else if (zero_crossings < 10) {
    PJ_LOG (3,(THIS_FILE, "⚠️ [WARNING] Very few zero crossings! Audio may be DC-biased or distorted!"));
}
/* 正常情况：不输出（避免日志爆炸）*/
```

**效果**:
- ✅ 保留所有警告信息
- ✅ 移除正常情况下的详细统计
- ✅ 日志大幅减少

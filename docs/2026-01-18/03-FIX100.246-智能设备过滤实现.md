```
card 2: camera [USB camera]            ← ✅ USB 摄像头麦克风（真实设备）
```

### 根本原因

ALSA（Advanced Linux Sound Architecture）为每个物理声卡创建多个别名：
- `hw:CARD=xxx,DEV=0` - 硬件直接访问
- `plughw:CARD=xxx,DEV=0` - 带插件的硬件访问
- `default:CARD=xxx` - 默认设备
- `sysdefault:CARD=xxx` - 系统默认
- `front:CARD=xxx,DEV=0` - 前置声道
- `surround21:CARD=xxx` - 环绕声 2.1
- `surround40:CARD=xxx` - 环绕声 4.0
- `surround51:CARD=xxx` - 环绕声 5.1
- `surround71:CARD=xxx` - 环绕声 7.1
- `dmix:CARD=xxx,DEV=0` - 软件混音（仅输出）
- `dsnoop:CARD=xxx,DEV=0` - 软件录音（仅输入）

以 USB 摄像头为例，PJSIP 枚举到 21 个"不同"的设备：
```
Device 22: "hw:CARD=camera,DEV=0"
Device 23: "plughw:CARD=camera,DEV=0"
Device 24: "default:CARD=camera"
Device 25: "sysdefault:CARD=camera"
Device 26: "front:CARD=camera,DEV=0"
Device 27: "dsnoop:CARD=camera,DEV=0"
...
```

但实际上这些都是 **同一个物理设备**（card 2: camera）的不同访问方式。

## 解决方案

### 核心思路：智能过滤 + 去重 + 友好命名

1. **提取声卡名称**：使用正则表达式 `CARD=([^,\s]+)` 提取卡片名（如 "camera"、"rockchiphdmi0"）
2. **过滤虚拟设备**：排除 Loopback、dmix、dsnoop、surround 等虚拟/软件设备
3. **只保留代表性设备**：优先选择 `default:CARD=xxx` 或 `plughw:CARD=xxx,DEV=0`
4. **去重**：使用 `QSet<QString>` 记录已添加的声卡，避免重复
5. **友好命名**：根据声卡类型生成中文名称

```cpp
QStringList SipPhoneManager::getAudioInputDevices()
{
    // ... 省略 PJSIP 初始化检查 ...

    pjmedia_aud_dev_info info[64];
    unsigned count = 64;
    pj_status_t status = pjsua_enum_aud_devs(info, &count);

    // ✅ 智能过滤和友好命名
    QSet<QString> seenCards;  // 记录已添加的声卡，避免重复

    for (unsigned i = 0; i < count; ++i) {
        QString deviceName = QString::fromUtf8(info[i].name);

        // 只添加支持录音(输入)的设备
        if (info[i].input_count > 0) {
            // ✅ 提取声卡名称（CARD=xxx）
            QString cardName;
            QRegularExpression cardRegex("CARD=([^,\\s]+)");
            QRegularExpressionMatch match = cardRegex.match(deviceName);
            if (match.hasMatch()) {
                cardName = match.captured(1);
            } else {
                cardName = deviceName;
            }

            // ✅ 过滤虚拟设备
            if (cardName.contains("Loopback", Qt::CaseInsensitive) ||
                deviceName.contains("dmix:", Qt::CaseInsensitive) ||
                deviceName.contains("dsnoop:", Qt::CaseInsensitive) ||
                deviceName.contains("surround", Qt::CaseInsensitive)) {
                qDebug() << "      ⏭️ SKIPPED (virtual device):" << cardName;
                continue;
            }

            // ✅ 只保留代表性设备
            bool isRepresentative = deviceName.startsWith("default:CARD=") ||
                                   (deviceName.startsWith("plughw:CARD=") &&
                                    deviceName.contains("DEV=0"));

            if (!isRepresentative) {
                qDebug() << "      ⏭️ SKIPPED (duplicate alias)";
                continue;
            }

            // ✅ 避免同一声卡重复添加
            if (seenCards.contains(cardName)) {
                qDebug() << "      ⏭️ SKIPPED (card already added):" << cardName;
                continue;
            }
            seenCards.insert(cardName);

            // ✅ 生成友好的中文名称
            QString friendlyName;
            if (cardName.contains("camera", Qt::CaseInsensitive)) {
                friendlyName = "USB 摄像头麦克风";
            } else if (cardName.contains("hdmi", Qt::CaseInsensitive)) {
                friendlyName = "HDMI 音频输入";
            } else if (cardName.contains("rockchip", Qt::CaseInsensitive)) {
                friendlyName = "板载音频输入";
            } else {
                friendlyName = cardName + " (麦克风)";
            }

            devices.append(friendlyName);
            qDebug() << "      ✅ ADDED:" << friendlyName << "(" << cardName << ")";
        }
    }

    qDebug() << "📢 [Device Enum] Total INPUT devices added:" << devices.count();
    return devices;
}
```

## 过滤规则详解

### 1. 虚拟设备过滤

**过滤条件**：
```cpp
if (cardName.contains("Loopback", Qt::CaseInsensitive) ||
    deviceName.contains("dmix:", Qt::CaseInsensitive) ||
    deviceName.contains("dsnoop:", Qt::CaseInsensitive) ||
    deviceName.contains("surround", Qt::CaseInsensitive))
```

**原因**：
- **Loopback**: ALSA 虚拟回环设备，用于音频路由，非物理硬件
- **dmix**: 软件混音设备，允许多个应用共享同一输出（虚拟）
- **dsnoop**: 软件录音设备，允许多个应用共享同一输入（虚拟）
- **surround**: 环绕声虚拟设备（surround21、surround40、surround51、surround71）

### 2. 代表性设备筛选

**保留条件**：
```cpp
bool isRepresentative = deviceName.startsWith("default:CARD=") ||
                       (deviceName.startsWith("plughw:CARD=") &&
                        deviceName.contains("DEV=0"));
```

**原因**：
- **default:CARD=xxx**: 最常用的默认设备，推荐优先使用
- **plughw:CARD=xxx,DEV=0**: 带插件的硬件访问，支持采样率转换等

**过滤掉的**：
- `hw:CARD=xxx` - 直接硬件访问（不如 plughw 灵活）
- `sysdefault:CARD=xxx` - 系统默认（与 default 重复）
- `front:CARD=xxx` - 前置声道（与 default 重复）

### 3. 去重机制

```cpp
QSet<QString> seenCards;  // 记录已添加的声卡

if (seenCards.contains(cardName)) {
    continue;  // 已添加过，跳过
}
seenCards.insert(cardName);  // 标记为已添加
```

**作用**：即使同时满足 `default:CARD=camera` 和 `plughw:CARD=camera,DEV=0`，也只添加一次。

### 4. 友好命名映射

| 原始设备名 | 提取的卡片名 | 友好中文名 |
|-----------|------------|----------|
| `default:CARD=camera` | `camera` | USB 摄像头麦克风 |
| `default:CARD=rockchiphdmi0` | `rockchiphdmi0` | HDMI 音频输出 |
| `plughw:CARD=Loopback,DEV=0` | `Loopback` | *被过滤* |

## 技术要点

### 1. Qt 容器选择：QSet vs QList

使用 `QSet<QString>` 而不是 `QList<QString>` 的原因：
- **O(1) 查找性能**：`seenCards.contains(cardName)` 是哈希查找
- **自动去重**：Set 天然不允许重复元素
- **内存效率**：只需存储卡片名（如 "camera"），不存储完整设备名

### 2. 正则表达式模式

```cpp
QRegularExpression cardRegex("CARD=([^,\\s]+)");
```

**解释**：
- `CARD=` - 匹配字面文本 "CARD="
- `(...)` - 捕获组，捕获卡片名
- `[^,\\s]+` - 匹配一个或多个**非逗号且非空白**字符
  - `^` 在 `[]` 内表示"非"
  - `,` - 逗号
  - `\\s` - 空白字符（空格、制表符等）
  - `+` - 一个或多个

**匹配示例**：
- `"default:CARD=camera"` → 捕获 `"camera"`
- `"plughw:CARD=rockchiphdmi0,DEV=0"` → 捕获 `"rockchiphdmi0"`

### 3. Qt 大小写不敏感比较

```cpp
cardName.contains("Loopback", Qt::CaseInsensitive)
```

等价于正则表达式 `(?i)Loopback`，但性能更好。

# FIX 100.246 失败分析 - HDMI 设备无输出通道

**时间**: 2026-01-18 15:40
**版本**: VERSION 2026-01-18-12:40
**状态**: ❌ 部分失败 - 崩溃 + 虚拟设备

## 问题总结

1. ❌ **PJSIP 选择了 Loopback 虚拟设备作为扬声器**
2. ❌ **程序崩溃**：Exit code 133 (内存堆损坏)
3. ❌ **Buffer size 频繁调整**：音频缓冲区不稳定
4. ⚠️ **设备名称显示不具体**：所有 USB 麦克风都显示"USB 摄像头麦克风"

- ❌ 最终选择了 Loopback 虚拟设备

## 根本原因

### 原因 1：ALSA 驱动报告错误的通道数

**现象**：PJSIP 枚举 HDMI 设备时，`pjmedia_aud_dev_get_info()` 返回 `output_count = 0`

**验证**：SSH 连接设备查看

```bash
pi@192.168.1.8:~$ aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: rockchiphdmi0 [rockchip,hdmi0]  ← 物理 HDMI 输出设备
  device 0: ...
```

**结论**：
- `aplay -l` 显示 rockchiphdmi0 是播放设备 ✅
- PJSIP 枚举时 `output_count = 0` ❌
- **这是 ALSA 驱动 bug 或 PJSIP ALSA 适配问题**

### 原因 2：内存管理问题（崩溃）

**触发场景**：
1. 用户点击挂断 → 销毁音频设备
2. PJSIP 释放音频缓冲区 → 检测到堆损坏
3. 程序崩溃

**可能原因**：
1. **多次创建/销毁音频设备**：用户在设置页面切换设备时，重复调用 `pjsua_set_snd_dev()`
2. **ALSA 与 Loopback 设备的兼容性问题**：虚拟设备可能有不同的内存管理模式
3. **PJSIP buffer 管理 bug**：Buffer size 频繁调整可能导致内存重新分配错误

## 解决方案

### 方案 1：强制使用 plughw 设备（推荐）✅

**思路**：ALSA 的 `plughw` 设备会进行自动格式转换，可能绕过 `output_count = 0` 的问题

**实现**（risipendpoint.cpp）：
```cpp
// 优先使用 plughw 设备，避免 hw 设备的通道数检测问题
if (dev_name.startsWith("plughw:CARD=rockchiphdmi")) {
    best_playback_dev = i;
    qDebug() << "      ✅ Selected plughw HDMI device (bypass channel check)";
    break;  // 找到立即使用
}
```

### 方案 2：显示实际设备名称，不做翻译

**问题**：所有 USB 麦克风都显示"USB 摄像头麦克风"，无法区分不同设备

**解决**（SipPhoneManager.cpp）：
```cpp
// 使用实际设备名称，不做友好翻译
QString friendlyName = dev_name;  // 直接使用 ALSA 设备名
```

**或者**：提取更具体的信息
```cpp
// 提取 CARD 名称作为显示名
if (cardName.contains("camera", Qt::CaseInsensitive)) {
    friendlyName = cardName + " (麦克风)";  // 显示 "camera (麦克风)"
} else if (cardName.contains("hdmi", Qt::CaseInsensitive)) {
    friendlyName = cardName + " (扬声器)";  // 显示 "rockchiphdmi0 (扬声器)"
}
```

### 方案 3：调试 HDMI 设备通道数问题

**添加调试信息**（risipendpoint.cpp）：
```cpp
for (unsigned i = 0; i < aud_dev_count; ++i) {
    pjmedia_aud_dev_info dev_info;
    pj_status_t status = pjmedia_aud_dev_get_info(i, &dev_info);

    QString dev_name = QString::fromUtf8(dev_info.name);

    qDebug() << "    Device" << i << ":" << dev_name
             << "| Caps:" << dev_info.input_count << "in /" << dev_info.output_count << "out"
             << "| Driver:" << dev_info.driver
             << "| ext_fmt_cnt:" << dev_info.ext_fmt_cnt;  // ← 添加格式信息

    // ✅ 打印详细的设备信息
    if (dev_name.contains("hdmi", Qt::CaseInsensitive)) {
        qDebug() << "      [HDMI DEBUG] default_samples_per_sec:" << dev_info.default_samples_per_sec;
        qDebug() << "      [HDMI DEBUG] caps:" << dev_info.caps;
    }
}
```

### 方案 4：防止崩溃 - 禁用设备热切换

**问题**：用户在设置页面切换设备时，重复创建/销毁音频设备可能导致崩溃


## 🔍 根因分析

### 错误假设（VERSION 2026-01-18-02:00）

**我的错误理解**：
```
创建 Risip 实例 = PJSIP 已初始化 = 可以枚举设备
```

**实际情况**：
```
创建 Risip 实例 ≠ PJSIP endpoint 已初始化
```

### 两个不同的概念

#### 1. Risip 实例（C++ 对象）
```cpp
d->risipInstance = risip::Risip::instance();
```
- **作用**：创建 C++ 包装器对象
- **不包含**：PJSIP 库初始化
- **结果**：无法枚举设备

#### 2. PJSIP Endpoint 初始化
```cpp
initializeEndpoint();  // 调用 pjsua_create()
```
- **作用**：初始化 PJSIP 库，调用 `pjsua_create()`
- **效果**：枚举系统音视频设备
- **标志**：`d->initialized = true`
- **结果**：可以枚举设备

### 代码路径分析

**VERSION 2026-01-18-02:00（有问题）**：
```cpp
QStringList SipPhoneManager::getAudioInputDevices()
```

## 🔧 解决方案

### 修改的文件

#### src/sip_phone/SipPhoneManager.cpp (lines 2170-2240)
添加 PJSIP endpoint 初始化检查到 `getAudioInputDevices()`：

```cpp
QStringList SipPhoneManager::getAudioInputDevices()
{
    qDebug() << "🔥🔥🔥 [ENTRY] getAudioInputDevices() called!";

    QStringList devices;

    // ✅ 2026-01-18 02:15 [FIX 100.246] 按需创建 Risip 实例 + 初始化 PJSIP endpoint
    // 原因：设备枚举需要 PJSIP endpoint 已初始化，不仅仅是 Risip 对象存在
    // 区分两个概念：
    //   - Risip 实例：C++ 对象
    //   - PJSIP endpoint：调用 pjsua_create() 后才能枚举设备
    if (!d->risipInstance) {
        qDebug() << "   [LAZY INIT] Risip instance not found, creating for device enumeration...";
        d->risipInstance = risip::Risip::instance();
        if (!d->risipInstance) {
            qWarning() << "❌ Failed to create Risip instance, cannot enumerate devices";
            return devices;
        }
        qDebug() << "   ✅ Risip instance created";
    } else {
        qDebug() << "   ✅ Using existing Risip instance";
    }

    // ✅ 2026-01-18 02:15 [FIX 100.246] 确保 PJSIP endpoint 已初始化
    // 原因：即使 Risip 实例存在，也需要调用 initializeEndpoint() 才能枚举设备
    if (!d->initialized) {
        qDebug() << "   [LAZY INIT] PJSIP endpoint not initialized, initializing now for device enumeration...";
        bool success = initializeEndpoint();
        if (!success) {
            qWarning() << "❌ Failed to initialize PJSIP endpoint, cannot enumerate devices";
            return devices;
        }
        qDebug() << "   ✅ PJSIP endpoint initialized (can now enumerate devices)";
    } else {
        qDebug() << "   ✅ PJSIP endpoint already initialized";
    }

    // 使用 pjsua_enum_aud_devs 枚举音频设备
    pjmedia_aud_dev_info info[64];
    unsigned count = 64;

    qDebug() << "   [API] Calling pjsua_enum_aud_devs() with max count:" << count;
    pj_status_t status = pjsua_enum_aud_devs(info, &count);
    qDebug() << "   [API] pjsua_enum_aud_devs() returned, status:" << status << "count:" << count;

    if (status == PJ_SUCCESS) {
        for (unsigned i = 0; i < count; ++i) {
            if (info[i].input_count > 0) {
                QString deviceName = QString::fromUtf8(info[i].name);
                devices.append(deviceName);
                qDebug() << "   Input Device" << i << ":" << deviceName;
            }
        }
    }

    qDebug() << "📢 [Device Enum] Total INPUT devices added:" << devices.count();
    return devices;
}
```

## 🎯 技术要点

### PJSIP 初始化顺序

正确的初始化顺序：

```
1. 创建 Risip 实例（C++ 对象）
   ↓
2. 调用 initializeEndpoint()
   ├─ 调用 pjsua_create()
   ├─ 枚举音视频设备
   ├─ 初始化音视频子系统
   └─ 设置 d->initialized = true
   ↓
3. 现在可以枚举设备
   ├─ pjsua_enum_aud_devs()  ✅ 返回真实设备数量
   └─ pjsua_vid_dev_count()  ✅ 返回真实设备数量
```

### 懒加载策略

**设计理念**（FIX 100.246 原始需求）：
- 用户进入 SIP 设置页面时才创建 Risip 实例
- 避免应用启动时初始化 PJSIP（减少启动时间）

**实现要求**：
- 设备枚举时**必须**确保 PJSIP endpoint 已初始化
- 使用 `d->initialized` 标志检查初始化状态
- 如果未初始化，调用 `initializeEndpoint()` 按需初始化

## 📝 经验教训

### ❌ 错误的假设

**我的错误**：
```
认为创建 Risip 实例就等于 PJSIP 已初始化
```

**为什么错误**：
- Risip 是 C++ 包装器，只是对象创建
- PJSIP 库需要显式调用 `pjsua_create()` 初始化
- 对象存在 ≠ 库已初始化

### ✅ 正确的理解

**关键认知**：
- **Risip 实例**：C++ 对象层面
- **PJSIP endpoint**：底层库初始化层面
- **设备枚举**：依赖 PJSIP endpoint 初始化完成

**检查方式**：
```cpp
if (!d->initialized) {
    // PJSIP endpoint 未初始化
    initializeEndpoint();  // 必须先初始化
}
// 现在可以枚举设备
```

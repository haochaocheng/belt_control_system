# FIX 100.246 - 分离输入/输出设备选择

**时间**: 2026-01-18 12:40
**版本**: VERSION 2026-01-18-12:40
**状态**: ✅ 实现完成，待测试

## 问题描述

### 用户反馈
> "是不是需改pjsip逻辑，因为不支持两个设备一个是输入一个是输出，pjsip要求必须是一个设备既有输入也有输出，否则不能使用"

### 根本原因

PJSIP 初始化时，`risipendpoint.cpp` 的音频设备选择逻辑要求设备 **同时支持输入和输出**：

**旧代码**（`risipendpoint.cpp:616-632`）：
```cpp
int first_valid_dev = -1;
for (unsigned i = 0; i < aud_dev_count; ++i) {
    pjmedia_aud_dev_info dev_info;
    pj_status_t status = pjmedia_aud_dev_get_info(i, &dev_info);
    if (status == PJ_SUCCESS) {
        QString dev_name = QString::fromUtf8(dev_info.name);
        qDebug() << "    Device" << i << ":" << dev_name
                 << "| Caps:" << dev_info.input_count << "in /" << dev_info.output_count << "out";

        // 跳过 "default" 设备（可能不工作）
        if (first_valid_dev == -1 &&
            dev_info.input_count > 0 && dev_info.output_count > 0 &&  // ← 问题在这里！
            !dev_name.contains("default", Qt::CaseInsensitive)) {
            first_valid_dev = i;
            qDebug() << "      ✅ Selected as first valid device";
        }
    }
}

// 使用同一个设备作为输入和输出
snd_status = pjsua_set_snd_dev(first_valid_dev, first_valid_dev);
```

**问题**：
- 条件 `dev_info.input_count > 0 && dev_info.output_count > 0` 要求设备同时支持输入和输出
- 现代设备通常是分离的：
  - **USB 摄像头麦克风**：只有输入（`input_count > 0, output_count == 0`）
  - **HDMI 扬声器**：只有输出（`input_count == 0, output_count > 0`）
- 在设备 192.168.1.8 上，只有 **Loopback 虚拟设备** 满足条件，导致选择了虚拟设备而不是真实硬件

### 设备实际情况（设备 192.168.1.8）

通过 SSH 查看：
```bash
pi@192.168.1.8:~$ aplay -l
**** List of PLAYBACK Hardware Devices ****
card 0: rockchiphdmi0 [rockchip,hdmi0]  ← HDMI 扬声器（只有输出）
card 1: Loopback [Loopback]            ← 虚拟设备（同时有输入和输出）

pi@192.168.1.8:~$ arecord -l
**** List of CAPTURE Hardware Devices ****
card 1: Loopback [Loopback]            ← 虚拟设备（同时有输入和输出）
card 2: camera [USB camera]            ← USB 麦克风（只有输入）
```

### 日志证据

PJSIP 初始化时选择的设备（`docs/log/voip.md:458`）：
```
03:09:23.003  pjsua_aud.c  Set sound device: capture=5, playback=5
```

设备 5 是 `hw:CARD=Loopback,DEV=0`（虚拟设备），而不是真实的物理设备。

## 解决方案

### 核心思路：分离输入/输出设备选择

1. **分别寻找最佳输入设备**（麦克风）：
   - 优先选择真实硬件设备（`input_count > 0`）
   - 排除 Loopback 虚拟设备和 default 设备

2. **分别寻找最佳输出设备**（扬声器）：
   - 优先选择真实硬件设备（`output_count > 0`）
   - 排除 Loopback 虚拟设备和 default 设备

3. **使用 `pjsua_set_snd_dev()` 分别设置**：
   ```cpp
   pjsua_set_snd_dev(capture_dev, playback_dev);
   ```
   - PJSIP 支持输入和输出设备不同
   - 只需要确保两个设备的采样率兼容即可

### 代码实现

**文件**: `src/risip/core/risipendpoint.cpp`
**修改行数**: 610-707

**新代码**（2026-01-18 12:40）：
```cpp
// ✅ 2026-01-18 12:40 [FIX 100.246] 分离输入/输出设备选择
// 原因：现代设备通常分离（USB 摄像头麦克风 + HDMI 扬声器）
// 旧逻辑要求同时支持输入/输出，导致只能选择 Loopback 虚拟设备
// 解决：分别寻找最佳输入设备和输出设备，使用 pjsua_set_snd_dev()
qDebug() << "🎵 [AUDIO DEV] Configuring global audio device (separate input/output)...";

// 枚举所有音频设备
unsigned aud_dev_count = pjmedia_aud_dev_count();
qDebug() << "  Total audio devices:" << aud_dev_count;

int best_capture_dev = -1;   // 最佳输入设备（麦克风）
int best_playback_dev = -1;  // 最佳输出设备（扬声器）

for (unsigned i = 0; i < aud_dev_count; ++i) {
    pjmedia_aud_dev_info dev_info;
    pj_status_t status = pjmedia_aud_dev_get_info(i, &dev_info);
    if (status == PJ_SUCCESS) {
        QString dev_name = QString::fromUtf8(dev_info.name);
        qDebug() << "    Device" << i << ":" << dev_name
                 << "| Caps:" << dev_info.input_count << "in /" << dev_info.output_count << "out";

        // ✅ 分别寻找输入和输出设备
        // 优先选择真实硬件设备（排除 Loopback 虚拟设备）
        bool isLoopback = dev_name.contains("Loopback", Qt::CaseInsensitive);
        bool isDefault = dev_name.contains("default", Qt::CaseInsensitive);

        // 寻找最佳输入设备（麦克风）
        if (best_capture_dev == -1 && dev_info.input_count > 0) {
            if (!isLoopback && !isDefault) {
                best_capture_dev = i;
                qDebug() << "      ✅ Selected as capture device (input)";
            }
        }

        // 寻找最佳输出设备（扬声器）
        if (best_playback_dev == -1 && dev_info.output_count > 0) {
            if (!isLoopback && !isDefault) {
                best_playback_dev = i;
                qDebug() << "      ✅ Selected as playback device (output)";
            }
        }
    }
}

// 如果没有找到真实设备，尝试使用 Loopback 作为备选
if (best_capture_dev == -1 || best_playback_dev == -1) {
    qDebug() << "  ⚠️ No real devices found, searching for Loopback...";
    for (unsigned i = 0; i < aud_dev_count; ++i) {
        pjmedia_aud_dev_info dev_info;
        pj_status_t status = pjmedia_aud_dev_get_info(i, &dev_info);
        if (status == PJ_SUCCESS) {
            QString dev_name = QString::fromUtf8(dev_info.name);
            bool isLoopback = dev_name.contains("Loopback", Qt::CaseInsensitive);

            if (isLoopback) {
                if (best_capture_dev == -1 && dev_info.input_count > 0) {
                    best_capture_dev = i;
                    qDebug() << "    ✅ Using Loopback as fallback capture device:" << i;
                }
                if (best_playback_dev == -1 && dev_info.output_count > 0) {
                    best_playback_dev = i;
                    qDebug() << "    ✅ Using Loopback as fallback playback device:" << i;
                }
            }
        }
    }
}

// 尝试设置音频设备
pj_status_t snd_status = PJ_ENOTFOUND;

if (best_capture_dev != -1 && best_playback_dev != -1) {
    // 使用 pjsua_set_snd_dev() 分别设置输入和输出设备
    qDebug() << "  Trying capture device" << best_capture_dev
             << "+ playback device" << best_playback_dev << "...";
    snd_status = pjsua_set_snd_dev(best_capture_dev, best_playback_dev);
    if (snd_status == PJ_SUCCESS) {
        qDebug() << "  ✅ Global audio device set:"
                 << "capture=" << best_capture_dev
                 << ", playback=" << best_playback_dev;
    } else {
        char errmsg[PJ_ERR_MSG_SIZE];
        pj_strerror(snd_status, errmsg, sizeof(errmsg));
        qDebug() << "  ⚠️ Device combination failed (status=" << snd_status << "):" << errmsg;
    }
} else {
    qDebug() << "  ⚠️ Missing device(s): capture=" << best_capture_dev
             << ", playback=" << best_playback_dev;
}

// 如果所有设备都失败，使用 null audio device
if (snd_status != PJ_SUCCESS) {
    qDebug() << "  ⚠️ All devices failed, trying null audio device...";
    snd_status = pjsua_set_null_snd_dev();
    if (snd_status == PJ_SUCCESS) {
        qDebug() << "  ✅ Null audio device enabled (no real audio, but calls will work)";
    } else {
        qDebug() << "  ❌ Even null audio device failed (status=" << snd_status << ")";
        qDebug() << "     Video calls may fail - check ALSA configuration";
    }
}
```

## 关键改进

### 1. 独立的设备选择

**旧逻辑**：
- 只有一个变量 `first_valid_dev`
- 同时用于输入和输出：`pjsua_set_snd_dev(first_valid_dev, first_valid_dev)`
- 要求设备同时支持两者

**新逻辑**：
- 两个独立变量：`best_capture_dev`（输入）和 `best_playback_dev`（输出）
- 分别设置：`pjsua_set_snd_dev(best_capture_dev, best_playback_dev)`
- 允许使用不同的设备

### 2. 优先级策略

**第一轮扫描**：寻找真实硬件设备
- 排除 Loopback 虚拟设备
- 排除 default 设备（可能不稳定）

**第二轮扫描**：如果第一轮失败，使用 Loopback 作为备选
- 确保至少有可用设备
- 避免完全失败

### 3. 详细的日志输出

每个设备都会输出详细信息：
```
Device 22 : "hw:CARD=camera,DEV=0" | Caps: 1 in / 0 out
  ✅ Selected as capture device (input)
```

最终选择结果：
```
✅ Global audio device set: capture=22, playback=0
```

## 潜在问题与解决方案

### 问题 1：HDMI 设备 `output_count=0`

**现象**：日志显示 `rockchiphdmi0` 的 `output_count=0`，但 `aplay -l` 显示它是播放设备。

**可能原因**：
1. ALSA 驱动配置问题
2. HDMI 未连接显示器
3. PJSIP 枚举 bug

**解决方案**：
如果 HDMI 确实没有输出通道，可能需要：
1. 检查 ALSA 配置：`aplay -L` 和 `cat /proc/asound/cards`
2. 尝试使用 `plughw:CARD=rockchiphdmi0` 而不是 `hw:CARD=rockchiphdmi0`
3. 如果必要，手动修改设备选择逻辑

### 问题 2：采样率不匹配

**可能错误**：
```
Device combination failed: Sample rate mismatch
```

**原因**：
- USB 麦克风支持 48kHz
- HDMI 扬声器只支持 44.1kHz
- PJSIP 需要相同采样率

**解决方案**：
使用 `plughw` 而不是 `hw` 设备，ALSA 插件会自动转换采样率：
```cpp
// 优先使用 plughw 设备（自动采样率转换）
if (dev_name.startsWith("plughw:") && !isLoopback) {
    // 优先选择
}
```

### 问题 3：需要同时选择设备

**用户需求**：
用户可能想在 SIP 设置页面分别选择麦克风和扬声器。

**当前实现**：
`SipPhoneManager.cpp` 的 `setAudioInputDevice()` 和 `setAudioOutputDevice()` 已支持分别设置。

**注意事项**：
需要确保用户选择的设备索引与 PJSIP 枚举的设备索引一致（经过智能过滤后）。

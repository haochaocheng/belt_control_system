# FIX 100.248 - 优先使用 plughw 设备实现程序适应任意硬件

**日期**: 2026-01-18 21:45
**核心理念**: 程序适应设备，而不是设备适应程序
**目标**: 确保 PCMA/PCMU 8kHz 在任意设备上都能工作

---

## 🔍 问题根因分析

### 当前问题

**FIX 100.247.1 日志显示**:
```
Device name: hw:CARD=camera,DEV=0
Sample rate: 22050 Hz (requested: 16000)
```

**问题**:
- PJSIP 请求 16000 Hz
- 设备返回 22050 Hz（硬件原生采样率）
- 导致多次重采样：22050 Hz → 16000 Hz → 8000 Hz

### 根本原因

**ALSA 设备类型差异**:

| 设备类型 | 说明 | 采样率支持 |
|----------|------|-----------|
| `hw:CARD=camera,DEV=0` | 直接硬件访问 | 仅硬件原生（22050, 32000, 44100, 48000, 96000 Hz） |
| `plughw:CARD=camera,DEV=0` | 硬件+软件转换 | **所有采样率**（ALSA 自动重采样） ⭐ |

**设备列表对比**:
```bash
# arecord -L 输出
hw:CARD=camera,DEV=0
    USB camera, USB Audio
    Direct hardware device without any conversions ← 当前使用（错误）

plughw:CARD=camera,DEV=0
    USB camera, USB Audio
    Hardware device with all software conversions ← 应该使用（正确）✅
```

### 当前设备枚举逻辑问题

**代码位置**: `src/sip_phone/SipPhoneManager.cpp` Line 2263-2327

**当前逻辑**:
```cpp
QSet<QString> seenCards;  // 避免重复

for (unsigned i = 0; i < count; ++i) {
    QString deviceName = QString::fromUtf8(info[i].name);

    // 提取卡片名称（如 "camera"）
    QString cardName = extractCardName(deviceName);

    // 如果这个卡片已经添加过，跳过
    if (seenCards.contains(cardName)) {
        qDebug() << "⏭️ SKIPPED (duplicate alias)";
        continue;
    }

    // 添加设备
    if (info[i].input_count > 0) {
        devices.append(friendlyName);
        seenCards.insert(cardName);  // 标记为已添加
    }
}
```

**问题**:
- Device 5: `hw:CARD=camera,DEV=0` - 第一个遇到，被添加 ✅
- Device 6: `plughw:CARD=camera,DEV=0` - cardName "camera" 已存在，被跳过 ❌

**结果**: 选择了 `hw:` 设备（不支持软件重采样），而不是 `plughw:` 设备（支持所有采样率）

---

## ✅ 解决方案

### 核心思路

**优先选择 plughw 设备**:
1. 遇到 `hw:CARD=X` - 暂存，不立即添加
2. 遇到 `plughw:CARD=X` - 立即添加，标记卡片为已处理
3. 如果只有 `hw:` 没有 `plughw:` - 使用 `hw:` 作为备选

**优势**:
- ✅ 支持任意采样率（ALSA 自动重采样）
- ✅ PCMA/PCMU 8kHz 在任意设备都能工作
- ✅ 程序适应设备，无需修改设备配置

### 实现代码

**修改文件**: `src/sip_phone/SipPhoneManager.cpp` Line 2263-2327

```cpp
// ✅ 2026-01-18 21:45 [FIX 100.248] 优先使用 plughw 设备（支持所有采样率）
// 原因：
//   - hw: 设备只支持硬件原生采样率（如 22050 Hz）
//   - plughw: 设备支持所有采样率（ALSA 自动重采样）
//   - PCMA/PCMU 需要 8000 Hz，必须使用 plughw 才能在任意设备工作
// 解决：
//   - 优先选择 plughw: 设备
//   - 如果没有 plughw:，才使用 hw: 作为备选
// 核心理念：程序适应设备，而不是设备适应程序（容器化部署要求）
// 参考：
//   - docs/2026-01-18/16-FIX100.248-优先使用plughw设备.md
//   - arecord -L: "Hardware device with all software conversions"

QSet<QString> seenCards;  // 记录已添加的声卡，避免重复
QMap<QString, int> hwDeviceIndex;  // 暂存 hw: 设备索引，作为备选

for (unsigned i = 0; i < count; ++i) {
    QString deviceName = QString::fromUtf8(info[i].name);
    qDebug() << "   [ALL] Device" << i << ":" << deviceName
             << "| In:" << info[i].input_count << "Out:" << info[i].output_count;

    // 只添加支持录音(输入)的设备
    if (info[i].input_count == 0) {
        qDebug() << "      ⏭️ SKIPPED (no input channels)";
        continue;
    }

    // 提取卡片名称（如 "camera", "rockchiphdmi0"）
    QString cardName;
    if (deviceName.contains("CARD=")) {
        int start = deviceName.indexOf("CARD=") + 5;
        int end = deviceName.indexOf(",", start);
        if (end == -1) end = deviceName.indexOf(" ", start);
        if (end == -1) end = deviceName.length();
        cardName = deviceName.mid(start, end - start);
    } else {
        cardName = deviceName;
    }

    // ✅ 2026-01-18 21:45 [FIX 100.248] 优先选择 plughw
    bool isPlughw = deviceName.startsWith("plughw:");
    bool isHw = deviceName.startsWith("hw:");

    // 情况 1: plughw 设备 - 立即添加（最优选择）
    if (isPlughw) {
        if (seenCards.contains(cardName)) {
            qDebug() << "      ⏭️ SKIPPED (duplicate alias)";
            continue;
        }

        // ✅ 跳过虚拟设备
        QStringList virtualDevices = {"dsnoop", "dmix", "null", "pulse"};
        bool isVirtual = false;
        for (const QString& virt : virtualDevices) {
            if (cardName.contains(virt, Qt::CaseInsensitive)) {
                isVirtual = true;
                break;
            }
        }

        if (isVirtual) {
            qDebug() << "      ⏭️ SKIPPED (virtual device):" << cardName;
            continue;
        }

        // 添加 plughw 设备
        QString friendlyName = cardName + " (麦克风)";
        qDebug() << "      ✅ ADDED:" << friendlyName << "(" << cardName << ")";
        qDebug() << "         [DEVICE TYPE] plughw (supports all sample rates)";
        qDebug() << "         [INDEX MAPPING] User index:" << devices.count() << "→ PJSIP index:" << i;

        devices.append(friendlyName);
        seenCards.insert(cardName);  // 标记为已添加

        // 移除对应的 hw 设备（如果之前暂存了）
        hwDeviceIndex.remove(cardName);
    }
    // 情况 2: hw 设备 - 暂存，等待对应的 plughw
    else if (isHw) {
        if (seenCards.contains(cardName)) {
            qDebug() << "      ⏭️ SKIPPED (already added as plughw)";
            continue;
        }

        // 暂存 hw 设备索引，作为备选
        if (!hwDeviceIndex.contains(cardName)) {
            hwDeviceIndex[cardName] = i;
            qDebug() << "      📦 STORED as fallback (waiting for plughw):" << cardName;
        } else {
            qDebug() << "      ⏭️ SKIPPED (duplicate alias)";
        }
    }
    // 情况 3: 其他设备（default, sysdefault 等）- 跳过
    else {
        if (seenCards.contains(cardName)) {
            qDebug() << "      ⏭️ SKIPPED (card already added):" << cardName;
        } else {
            qDebug() << "      ⏭️ SKIPPED (not plughw or hw):" << deviceName;
        }
    }
}

// ✅ 2026-01-18 21:45 [FIX 100.248] 添加备选 hw 设备（没有 plughw 的情况）
// 场景：某些设备可能只有 hw:，没有 plughw:（不常见但要兼容）
for (auto it = hwDeviceIndex.constBegin(); it != hwDeviceIndex.constEnd(); ++it) {
    QString cardName = it.key();
    int deviceIndex = it.value();

    if (!seenCards.contains(cardName)) {
        QString deviceName = QString::fromUtf8(info[deviceIndex].name);
        QString friendlyName = cardName + " (麦克风)";

        qDebug() << "      ✅ ADDED (fallback hw):" << friendlyName << "(" << cardName << ")";
        qDebug() << "         [DEVICE TYPE] hw (limited sample rate support)";
        qDebug() << "         [INDEX MAPPING] User index:" << devices.count() << "→ PJSIP index:" << deviceIndex;

        devices.append(friendlyName);
        seenCards.insert(cardName);
    }
}
```


## 🔧 配合修改：PJSIP 采样率配置

**目标**: 让 PJSIP 使用 8000 Hz 内部采样率（匹配 PCMA/PCMU）

**修改文件**: `src/risip/core/risipendpoint.cpp`

**添加位置**: 在编解码器配置之前

```cpp
// ✅ 2026-01-18 21:45 [FIX 100.248] 设置音频设备采样率为 8kHz
// 原因：
//   - PCMA/PCMU 使用 8000 Hz
//   - plughw 设备支持所有采样率（ALSA 自动重采样）
//   - 设置为 8kHz 避免 PJSIP 内部重采样
// 效果：
//   - 麦克风(硬件采样率) → ALSA重采样 → 8000 Hz → PJSIP(8kHz) → PCMA(8kHz)
//   - PJSIP 内部零重采样
try {
    AudioMediaConfig audio_cfg = audDevManager().getAudioDeviceConfig();
    audio_cfg.clockRate = 8000;     // ⭐ 8000 Hz（匹配 PCMA/PCMU）
    audio_cfg.channelCount = 1;      // 单声道
    audio_cfg.audioFramePtime = 20;  // 20ms 帧
    audDevManager().setAudioDeviceConfig(audio_cfg);
    qDebug() << "✅ [AUDIO] Audio device config:";
    qDebug() << "   Clock rate: 8000 Hz (matches PCMA/PCMU)";
    qDebug() << "   Channels: 1 (mono)";
    qDebug() << "   Frame time: 20 ms";
} catch (Error &err) {
    qDebug() << "Warning: Could not set audio device config:" << QString::fromStdString(err.reason);
}
```

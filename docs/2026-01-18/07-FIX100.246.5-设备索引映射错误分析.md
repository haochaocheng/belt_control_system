# FIX 100.246.5 - 设备索引映射错误分析

**时间**: 2026-01-18 16:30
**版本**: VERSION 2026-01-18-16:30
**状态**: ❌ 严重Bug - 设备索引不匹配导致无法使用音频

## 问题现象

用户选择麦克风后，PJSIP 报错：
```
[WARNING] ❌ Failed to set audio input device in PJSIP: Invalid audio device (PJMEDIA_EAUD_INVDEV)
```

扬声器下拉框显示：`无可用扬声器`

## 根本原因

### 原因 1：用户层索引 ≠ PJSIP 索引

**用户层设备枚举逻辑**（`SipPhoneManager.cpp:2261-2334`）：
```cpp
QStringList devices;
for (unsigned i = 0; i < count; ++i) {
    // 智能过滤：跳过虚拟设备、重复设备
    if (满足条件) {
        devices.append(friendlyName);  // ← 只保存名称，不保存 PJSIP 索引 i
    }
}
return devices;  // 用户看到的索引 0, 1, 2...
```

**实际 PJSIP 设备索引**：
```
Device 0:  hw:CARD=rockchiphdmi0,DEV=0           ← 被过滤（output_count=0）
Device 1:  plughw:CARD=rockchiphdmi0,DEV=0       ← 被过滤（output_count=0）
Device 2:  default:CARD=rockchiphdmi0            ← 被过滤（output_count=0）
Device 3:  sysdefault:CARD=rockchiphdmi0         ← 被过滤（output_count=0）
Device 4:  dmix:CARD=rockchiphdmi0,DEV=0         ← 被过滤（虚拟设备）
Device 5:  hw:CARD=camera,DEV=0                  ← 被过滤（重复）
Device 6:  plughw:CARD=camera,DEV=0              ← ✅ 用户看到的索引 0
Device 7:  default:CARD=camera                   ← 被过滤（重复）
...
```

**结果**：
- 用户层显示：`camera (麦克风)` - 索引 **0**
- PJSIP 实际：`plughw:CARD=camera,DEV=0` - 索引 **6**
- 用户选择索引 0 → PJSIP 使用索引 0 (`hw:CARD=rockchiphdmi0,DEV=0`) ❌

### 原因 2：HDMI 设备被占用

**日志证据**：
```
Trying capture device 5 + playback device 1 ...
Unable to open playback device 'plughw:CARD=rockchiphdmi0,DEV=0', err: Device or resource busy
```

**占用情况**：
```
pulseaudio (PID 1060) 占用 /dev/snd/controlC0
belt_control (PID 69997) 占用 /dev/snd/pcmC0D0p  ← HDMI 播放设备
```

### 原因 3：所有 HDMI 设备报告 `output_count=0`

**用户层枚举日志**：
```
Device 0 : "hw:CARD=rockchiphdmi0,DEV=0" | In: 0 Out: 0         ← output_count=0
Device 1 : "plughw:CARD=rockchiphdmi0,DEV=0" | In: 0 Out: 0     ← output_count=0
Device 2 : "default:CARD=rockchiphdmi0" | In: 0 Out: 0          ← output_count=0
...
🔊 [Device Enum] Total OUTPUT devices added: 0  ← 没有找到任何扬声器
⚠️ [Device Enum] No output devices found, added placeholder
```

**结果**：用户层显示"无可用扬声器"，实际上 HDMI 设备存在但被 ALSA 错误报告

## 解决方案

### 方案 1：修复设备索引映射 ✅（核心修复）

**思路**：用户层枚举时保存 PJSIP 原始索引，选择时使用原始索引

**实现步骤**：

#### 1.1 修改 `SipPhoneManager.h` 添加索引映射

```cpp
class SipPhoneManager : public QObject {
    Q_OBJECT
    // ... 现有代码 ...

private:
    // ✅ 2026-01-18 16:30 [FIX 100.246.5] 设备索引映射（用户索引 → PJSIP索引）
    QVector<int> m_audioInputDeviceMap;   // 麦克风设备索引映射
    QVector<int> m_audioOutputDeviceMap;  // 扬声器设备索引映射
    QVector<int> m_videoDeviceMap;        // 摄像头设备索引映射
};
```

#### 1.2 修改 `getAudioInputDevices()` 保存映射

```cpp
QStringList SipPhoneManager::getAudioInputDevices()
{
    QStringList devices;
    m_audioInputDeviceMap.clear();  // ✅ 清空旧映射

    for (unsigned i = 0; i < count; ++i) {
        // ... 智能过滤逻辑 ...
        if (应该添加) {
            devices.append(friendlyName);
            m_audioInputDeviceMap.append(i);  // ✅ 保存 PJSIP 原始索引
        }
    }

    return devices;
}
```

#### 1.3 修改 `setAudioInputDevice()` 使用映射

```cpp
bool SipPhoneManager::setAudioInputDevice(int userIndex)
{
    // ✅ 2026-01-18 16:30 [FIX 100.246.5] 将用户索引映射回 PJSIP 索引
    if (userIndex < 0 || userIndex >= m_audioInputDeviceMap.size()) {
        qWarning() << "❌ Invalid user device index:" << userIndex;
        return false;
    }

    int pjsipIndex = m_audioInputDeviceMap[userIndex];  // ✅ 获取实际 PJSIP 索引
    qDebug() << "📢 [FIX 100.246.5] User index" << userIndex << "→ PJSIP index" << pjsipIndex;

    // 使用 PJSIP 原始索引设置设备
    pj_status_t status = pjsua_set_snd_dev(pjsipIndex, -1);  // -1 表示不改变播放设备
    // ...
}
```

### 方案 2：修复"无可用扬声器"逻辑 ✅

**问题**：HDMI 设备 `output_count=0` 但实际可用（ALSA bug）

**已实现**：VERSION 2026-01-18-16:10 强制使用 plughw 设备（绕过 output_count 检查）

**但用户层仍被过滤**：需要同步修复用户层枚举

```cpp
// ✅ 2026-01-18 16:30 [FIX 100.246.5] plughw 设备即使 output_count=0 也添加
if (dev_name.startsWith("plughw:", Qt::CaseInsensitive)) {
    if (!isLoopback && !isDefault) {
        if (!seenCards.contains(cardName)) {
            seenCards.insert(cardName);
            devices.append(friendlyName);
            m_audioOutputDeviceMap.append(i);  // ← 保存映射
            qDebug() << "      ✅ ADDED (plughw, bypass output_count=0):" << friendlyName;
        }
    }
}
```

### 方案 3：永久禁用 PulseAudio ✅

### Phase 7.48.58 - R键启动修复（今日）

**问题1：R/S 键完全无响应**
- 根本原因：`main.cpp` 创建 MaintenanceControl/LocalControl 后未调用 setCommonControl/setSystemConfig
- 日志证据：`❌ MaintenanceControl: CommonControl未设置`
- 修复：补充 4 行连接代码

**问题2：起车预警无语音 → 设备序列永不启动**
- 根本原因：`playWarningOnce()` TTS 代码被注释 + 音频文件不存在 → `onPlaybackFinished` 永不触发
- 修复：重写 playWarningOnce()
  - 优先：预制音频文件
  - 次选：TTS 实时合成 "本机名称准备启动，注意安全"
  - 兜底：直接执行启动序列（保证不卡死）

**问题3：设备名称不匹配**
- 根本原因：getDeviceChannel() 映射表只有旧名称（"张紧"/"抱闸"），LogicControlPanel 用新名称
- 修复：添加 "张紧控制" → 通道0，"1号制动器" → 通道1

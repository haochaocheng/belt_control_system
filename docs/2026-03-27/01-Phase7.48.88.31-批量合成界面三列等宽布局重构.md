# Phase 7.48.88.31 - 批量合成界面三列等宽布局重构

## 修改时间
2026-03-27

## 修改文件
- `src/qml/pages/BatchSynthesisContent.qml`

## 问题描述
1. 选择分类和清除旧语音两个GroupBox宽度不一致
2. 清除设备选择区域底部与生成范围分隔线重叠
3. 右侧日志区域在有输出时自动变宽，挤压左侧空间
4. 清除旧语音内的CheckBox垂直居中对齐，与左侧选择分类的顶部对齐不一致
5. 生成设备选择放在生成范围区域，与清除设备选择不在同一水平线

## 解决方案

### 布局重构：从"左2+右1"改为"三列等宽"

**旧布局**：
```
左侧 480px                          | 右侧 350px
┌─选择分类─┐ ┌─清除旧语音──────────┐ | ┌─统计信息─┐
│ 10个分类  │ │ 10个分类            │ | │          │
│           │ │ 清除设备选择        │ | ├─进度─────┤
│           │ │ 清除按钮            │ | ├─日志─────┤
└───────────┘ └─────────────────────┘ | │(会撑宽)  │
┌─生成范围──────────────────────────┐ | └──────────┘
│ 设备选择: 1# 2# ... 8#           │ |
│ 电机/制动器/张紧/点位             │ |
└───────────────────────────────────┘ |
```

**新布局**：
```
第1列(等宽)        | 第2列(等宽)        | 第3列(等宽)
┌─选择分类────────┐ ┌─清除旧语音───────┐ ┌─统计+进度+��志──┐
│ 10个分类        │ │ 10个分类         │ │ 统计信息        │
│ ────────        │ │ ────────         │ │ 进度条          │
│ 生成设备:       │ │ 清除设备:        │ │ 日志(固定宽度)  │
│ 1# 2# 3# 4#    │ │ 1# 2# 3# 4#     │ │                 │
│ 5# 6# 7# 8#    │ │ 5# 6# 7# 8#     │ │ 选项            │
│ [全选] [清空]   │ │ [全选] [清空]    │ │                 │
└─────────────────┘ │ [清除按钮]       │ └─────────────────┘
                    └──────────────────┘
┌─生成范围(横向紧凑)──────────────────────────────────────┐
│ 电机:8  制动器:8  张紧:2  点位:1-64                     │
└─────────────────────────────────────────────────────────┘
```

### 关键改动
1. **三列等宽**：三个GroupBox使用 `Layout.fillWidth: true` 均分宽度
2. **生成设备移入选择分类**：设备选择CheckBox从生成范围移到选择分类底部，与清除设备水平对齐
3. **设备选择4列网格**：`GridLayout { columns: 4 }` 紧凑排列8个设备
4. **日志固定宽度**：第3列不再因日志内容撑宽
5. **生成范围横向紧凑**：电机/制动器/张紧/点位改为单行8列GridLayout
6. **顶部对齐**：所有列使用 `Layout.alignment: Qt.AlignTop` + `anchors.top: parent.top`

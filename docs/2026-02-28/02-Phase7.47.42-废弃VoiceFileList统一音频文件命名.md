# Phase 7.47.42 - 废弃VoiceFileList.h，统一音频文件命名规则

**创建时间**: 2026-02-28
**阶段**: Phase 7.47.42
**关联文件**:
- `src/control/tts/VoiceFileList.h`

---

## 一、问题描述

### 1.1 根本原因

`VoiceFileList.h` 是早期开发时人工杜撰的语音清单，存在三大问题：

| 问题 | 旧代码 | 实际需求 |
|------|--------|---------|
| 保护项数量 | SwitchInput：33项/皮带 | 真实DI模块：8位/模块 |
| 保护名称 | 人工杜撰（如"急停保护"） | 真实系统（如"沿线急停"） |
| 文件数量 | linePosition：1个/点位 | 真实需求：3个/点位（急停/跑偏/撕裂） |

### 1.2 不一致现象

```
BatchAudioGenerator 生成文件：  1#PD/急停保护.wav       ← 旧VoiceFileList名称
AudioPathMapper 触发查找文件：  1#PD/急停保护.wav       ← 也用VoiceFileList，但名称也是错的

正确的真实系统文件名：          1#PD/沿线急停.wav       ← 真实保护名（短名）
```

---

## 二、修复方案

### 2.1 命名规则统一

**规则**：文件名 = TTS合成文本去掉"X号皮带"前缀 + 去掉"保护"后缀

| 类别 | TTS合成内容（完整句子） | 音频文件名（短名） |
|------|------------------------|-------------------|
| DI急停 | `1号皮带沿线急停保护` | `沿线急停.wav` |
| DI跑偏 | `1号皮带沿线跑偏保护` | `沿线跑偏.wav` |
| 点位急停 | `1号皮带3号沿线急停保护` | `3号沿线急停.wav` |
| 电机过载 | `1号皮带2号电机电流过载保护` | `2号电机电流过载.wav` |
| 系统提示音 | `系统启动完成` | `系统启动完成.wav` |

### 2.2 文件存储结构

```
{outputBaseDir}/
└── paddlespeech-vits-zh-aishell3-spk0/
    ├── 1#PD/
    │   ├── 沿线急停.wav          ← DI bit0 保护
    │   ├── 沿线跑偏.wav          ← DI bit1 保护
    │   ├── 沿线撕裂.wav          ← DI bit2 保护
    │   ├── 烟雾.wav             ← DI bit3 保护
    │   ├── 温度.wav             ← DI bit4 保护
    │   ├── 护网.wav             ← DI bit5 保护
    │   ├── 堆煤.wav             ← DI bit6 保护
    │   ├── 主机急停.wav          ← DI bit7 保护
    │   ├── 速度超速.wav          ← 模拟量保护
    │   ├── 低速打滑.wav          ← 模拟量保护
    │   ├── 1号电机电流过载.wav   ← 电机保护
    │   ├── 1号制动器温度过高.wav ← 制动器保护

    │   └── ...

        ├── 系统启动完成.wav
        └── ...
```

## 五、影响的代码链路

```
MQTT保护触发
    ↓
MqttProtectionMonitor.onBitChanged(moduleIndex, bitIndex, value)
    ↓
AudioPathMapper.getProtectionName(bitIndex)  ← 现在返回"沿线急停"等8个正确短名
    ↓
AudioPathMapper.getAudioPath(beltNumber, protectionName)
    ↓
路径：/app/audio/paddlespeech-模型-spkN/1#PD/沿线急停.wav
    ↓
CommonControl.playAudio(audioPath)
```

批量生成路径：
```
BatchAudioGenerator.generateSwitchInputTasks()
    ↓
task.text = "1号皮带沿线急停保护"         ← TTS合成内容
task.outputPath = "1#PD/沿线急停.wav"    ← 与AudioPathMapper查找路径一致
```

# 设备信息界面重构方案 - 第五界面 4x3 布局

**文档版本**: v1.0
**创建日期**: 2026-01-24
**状态**: 待审核

## 1. 概述

### 1.1 目标
将参数设置页面中的设备信息功能迁移到第五个界面（模块状态页面），采用 4x3 网格布局展示 12 个设备，提供直观的设备状态监控和参数配置入口。

### 1.2 核心变更
- **移除组件**: MyIN_State（模块状态组件）
- **保留并重构**: MyIN_Data（数据显示组件）
- **新增功能**: 设备选择、键盘导航、参数设置弹窗

### 3.3 组件尺寸规范（多分辨率支持）

**支持的屏幕分辨率**:
- **1280 x 800** (当前测试分辨率)
- **1920 x 1080** (高分辨率)

#### 3.3.1 分辨率 1280x800 布局

**单个设备组件**:
- 宽度: 280px
- 高度: 180px
- 间距: 20px (水平和垂直)
- 边距: 40px (左右), 30px (上下)

**网格计算**:
```
总宽度 = 40 + (280 + 20) * 4 - 20 + 40 = 1260px ✓
总高度 = 30 + (180 + 20) * 3 - 20 + 30 = 640px ✓
可用高度 = 800 - 80(Head) = 720px ✓
```

#### 3.3.2 分辨率 1920x1080 布局

**单个设备组件**:
- 宽度: 420px (1.5倍缩放)
- 高度: 270px (1.5倍缩放)
- 间距: 30px (水平和垂直)
- 边距: 60px (左右), 45px (上下)

**网格计算**:
```
总宽度 = 60 + (420 + 30) * 4 - 30 + 60 = 1890px ✓
总高度 = 45 + (270 + 30) * 3 - 30 + 45 = 960px ✓
可用高度 = 1080 - 120(Head) = 960px ✓
```

**响应式设计策略**:
- 使用 QML `Screen.width` 和 `Screen.height` 检测分辨率
- 根据分辨率动态计算缩放系数
- 所有尺寸使用相对单位，确保不同分辨率下比例一致

### 4.1 DeviceInfoItem 组件 (新建)

**文件路径**: `src/qml/components/device_info/DeviceInfoItem.qml`

**属性**:
```qml
Item {
    id: root

    // 公开属性
    property string deviceName: ""        // 设备名称
    property string deviceId: ""          // 设备ID
    property string imagePath: ""         // 图片路径
    property bool isSelected: false       // 是否选中
    property bool isRunning: false        // 是否运行中
    property real speed: 0.0              // 当前速度
    property string status: "停止"        // 状态文本

    // 信号
    signal clicked()
    signal doubleClicked()

    // 视觉状态
    states: [
        State {
            name: "normal"
            when: !isSelected
        },
        State {
            name: "selected"
            when: isSelected
            PropertyChanges {
                target: border
                color: "#00FF00"  // 绿色高亮边框
                width: 3
            }
        }
    ]
}
```

```qml
Dialog {
    id: root

    // 基本属性
    property string deviceName: ""        // 设备名称
    property int deviceId: -1             // 设备ID
    property int currentCategory: 0       // 当前选中的参数类别

    // 尺寸（响应式）
    width: parent.width * 0.8             // 占屏幕80%宽度
    height: parent.height * 0.8           // 占屏幕80%高度
    modal: true                           // 模态对话框

    // 布局结构
    contentItem: Item {
        // 上部按钮栏
        Row {
            id: topButtons
            anchors.top: parent.top
            anchors.horizontalCenter: parent.horizontalCenter
            spacing: 20

            Button { text: "关闭"; onClicked: root.close() }
            Button { text: "保存"; onClicked: saveSettings() }
            Button { text: "重置"; onClicked: resetSettings() }
        }

        // 左侧按钮列
        Column {
            id: leftButtons
            anchors.left: parent.left
            anchors.top: topButtons.bottom
            anchors.topMargin: 20
            width: 150
            spacing: 10

            Repeater {
                model: ["基本参数", "运行参数", "报警设置", "高级设置", "其他"]
                Button {
                    text: modelData
                    width: parent.width
                    onClicked: root.currentCategory = index
                }
            }
        }

        // 中间参数显示区域（矩形占位符）
        Rectangle {
            id: contentArea
            anchors.left: leftButtons.right
            anchors.right: parent.right
            anchors.top: topButtons.bottom
            anchors.bottom: parent.bottom
            anchors.margins: 20
            color: "#2A2A2A"
            border.color: "#555555"
            border.width: 2

            // 图片占位符（用户后续提供）
            Image {
                id: backgroundImage
                anchors.fill: parent
                fillMode: Image.PreserveAspectFit
                source: ""  // 用户后续提供图片路径
                visible: source != ""
            }

            // 参数内容区域（根据 currentCategory 切换）
            Loader {
                id: contentLoader
                anchors.fill: parent
                anchors.margins: 20
                source: {
                    switch(root.currentCategory) {
                        case 0: return "DeviceBasicParams.qml"
                        case 1: return "DeviceRunParams.qml"
                        case 2: return "DeviceAlarmParams.qml"
                        case 3: return "DeviceAdvancedParams.qml"
                        case 4: return "DeviceOtherParams.qml"
                        default: return ""
                    }
                }
            }
        }
    }

    // 参数设置项（待用户后续规划具体内容）
    // 示例参数类别：
    // - 基本参数: 设备名称、设备编号、设备类型
    // - 运行参数: 启动延时、停止延时、速度限制
    // - 报警设置: 报警阈值、报警延时、报警优先级
    // - 高级设置: PID参数、滤波参数、通信参数
    // - 其他: 备注信息、维护记录
}
```

**阶段性实现**:
1. **Phase 1** (当前): 创建矩形占位符 + 基本布局
2. **Phase 2** (用户提供图片后): 添加背景图片
3. **Phase 3** (用户规划参数后): 实现具体参数编辑界面

## 6. 数据绑定

### 6.1 后端接口

**C++ 控制器**: `DeviceInfoController` (新建)

**文件路径**: `src/control/DeviceInfoController.h/cpp`

**功能**:
```cpp
class DeviceInfoController : public QObject {
    Q_OBJECT
    Q_PROPERTY(QVariantList deviceList READ deviceList NOTIFY deviceListChanged)

public:
    struct DeviceInfo {
        int id;
        QString name;
        QString status;
        bool isRunning;
        double speed;
        QString imagePath;
    };

    Q_INVOKABLE void openDeviceSettings(int deviceId);
    Q_INVOKABLE void updateDeviceStatus(int deviceId, const QString& status);

signals:
    void deviceListChanged();
    void deviceStatusChanged(int deviceId, const QString& status);
};
```

### 6.2 数据流

```
DeviceDatabase (设备数据库)
    ↓
DeviceInfoController (控制器)
    ↓
DeviceInfoGrid (QML 网格)
    ↓
DeviceInfoItem (单个设备组件)
```

## 10. 风险评估

### 10.1 技术风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 键盘焦点管理复杂 | 中 | 使用 FocusScope 明确焦点范围 |
| 图片加载性能 | 低 | 使用异步加载 + 缓存 |
| 弹窗层级冲突 | 中 | 使用 Overlay.overlay 确保最高层级 |

### 10.2 用户体验风险

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 设备过多导致拥挤 | 低 | 当前 12 个设备，布局合理 |
| 参数设置项不明确 | 高 | 等待用户后续规划参数项 |
| 图片缺失影响美观 | 中 | 提供美观的默认占位符 |

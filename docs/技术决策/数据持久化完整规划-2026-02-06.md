| System | play_mode | QString | "按时间" | 播放模式（按时间/按次数） |

### 2. SerialPortController（串口配置）

**文件**: `appdata/config.ini`  
**管理类**: `src/control/SerialPortController.h/cpp`

#### 配置项（6个串口）

每个串口配置包含：

| 键名 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | QString | "COM1" ~ "COM6" | 串口名称 |
| device_path | QString | "/dev/ttyS0" 等 | 设备路径 |
| type | QString | "RS422" / "RS232" / "RS485" | 串口类型 |
| baud_rate | int | 9600 | 波特率 |
| data_bits | int | 8 | 数据位 |
| stop_bits | int | 1 | 停止位 |
| parity | QString | "None" | 校验位 |

#### 串口映射

| 串口 | 设备路径 | 类型 | 用途 |
|------|----------|------|------|
| COM1 | /dev/ttyS0 | RS422 | 通用通信 |
| COM2 | /dev/ttyS7 | RS422 | 通用通信 |
| COM3 | /dev/ttyCH9344USB0 | RS232 | USB转串口 |
| COM4 | /dev/ttyCH9344USB1 | RS232 | USB转串口 |
| COM5 | /dev/ttyCH9344USB2 | RS485 | Modbus通信 |
| COM6 | /dev/ttyCH9344USB3 | RS232 | USB转串口 |

#### 使用示例

```cpp
// 加载串口配置
serialPortController->loadConfig();

// 获取串口配置
SerialPortConfig config = serialPortController->getSerialPortConfig(0);

// 保存串口配置

```

##### 1.1 devices（设备表）

```sql
CREATE TABLE IF NOT EXISTS devices (
    device_id INTEGER PRIMARY KEY,           -- 设备ID（1-12）
    device_name TEXT NOT NULL,               -- 设备名称（如"1号皮带"）
    device_type TEXT DEFAULT 'belt',         -- 设备类型
    position_row INTEGER,                    -- 网格位置：行（0-3）
    position_col INTEGER,                    -- 网格位置：列（0-2）
    enabled BOOLEAN DEFAULT 1,               -- 是否启用
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_devices_position ON devices(position_row, position_col);
```

**数据规模**: 12条记录（4×3网格）


##### 1.2 device_basic_config（基本配置表）

```sql
CREATE TABLE IF NOT EXISTS device_basic_config (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    device_id INTEGER NOT NULL,              -- 设备ID
    param_name TEXT NOT NULL,                -- 参数名称
    param_value TEXT,                        -- 参数值（字符串存储）
    param_type TEXT DEFAULT 'string',        -- 参数类型（string/int/real/bool）
    description TEXT,                        -- 参数描述
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_id) REFERENCES devices(device_id) ON DELETE CASCADE,
    UNIQUE(device_id, param_name)            -- 同一设备的参数名唯一
);

CREATE INDEX idx_basic_config_device ON device_basic_config(device_id);
```

**数据规模**: 约48条记录（12设备 × 4参数）

bool DeviceConfigManager::migrateFromOldVersion() {
    // 1. 检测数据库版本
    int currentVersion = getDatabaseVersion();
    int targetVersion = LATEST_DATABASE_VERSION;
    
    // 2. 执行增量迁移
    for (int v = currentVersion + 1; v <= targetVersion; v++) {
        if (!executeMigration(v)) {
            rollbackMigration(v);
            return false;
        }
    }
    
    // 3. 更新数据库版本
    setDatabaseVersion(targetVersion);
    return true;
}

### 延迟写入（Debounce）

```cpp
class DeviceConfigManager {
private:
    QTimer *m_saveTimer;
    QMap<int, QVariantMap> m_pendingChanges;
    
    void scheduleDelayedSave(int deviceId, const QVariantMap &changes) {
        m_pendingChanges[deviceId] = changes;
        m_saveTimer->start(1000);  // 1秒后保存
    }
    
    void onSaveTimerTimeout() {
        m_database.transaction();
        for (auto it = m_pendingChanges.begin(); it != m_pendingChanges.end(); ++it) {
            saveDeviceConfig(it.key(), it.value());
        }
        m_database.commit();
        m_pendingChanges.clear();
    }
};
```

**优化效果**:
- 减少数据库写入次数
- 避免频繁的磁盘I/O

bool DeviceConfigManager::saveDigitalProtection(int deviceId, const QVariantMap &protection) {
    // 1. 参数验证
    if (deviceId < 1 || deviceId > 12) {
        qWarning() << "❌ 无效的设备ID:" << deviceId;
        return false;
    }
    
    if (!protection.contains("protection_name")) {
        qWarning() << "❌ 缺少保护名称";
        return false;
    }
    
    // 2. 准备SQL语句
    QSqlQuery query(m_database);
    query.prepare("INSERT OR REPLACE INTO device_digital_protections "
                  "(device_id, protection_name, module_type, ...) "
                  "VALUES (?, ?, ?, ...)");
    
    // 3. 绑定参数
    query.addBindValue(deviceId);
    query.addBindValue(protection["protection_name"]);
    query.addBindValue(protection["module_type"]);
    // ...
    
    // 4. 执行查询
    if (!query.exec()) {
        qWarning() << "❌ 保存失败:" << query.lastError();
        return false;
    }
    
    // 5. 发送信号
    emit deviceConfigChanged(deviceId);
    
    return true;
}

# 统一列表主题风格修复

**日期**：2026-01-26
**任务**：统一开关量输入和模拟量输入的列表按钮主题风格，与电机控制保持一致
**FIX**：100.300.22

---

## ❌ 问题描述

**用户反馈**：
> "开关量输入和模拟量输入，与电机控制的列表按钮主题风格不一样，要统一，按照电机控制的方式"

**问题分析**：
- **电机控制**：使用简洁的工业风格
  - 深蓝灰背景 (#1a1f2e)
  - 标题栏 #252b3d
  - 蓝色边框 (#3d4556)
  - 选中项左侧蓝色激活条 (#2196F3)
  - 列表项高度 60px
  - 无圆角、无闪烁动画

- **开关量输入/模拟量输入**：使用科技感风格
  - 深蓝色背景 (#1a2332)
  - 青色边框 (#00d4ff)
  - 绿色高亮 (#00ff88)
  - 圆角 8px
  - 闪烁动画
  - 悬停缩放效果

**用户期望**：所有列表使用统一的电机控制风格

---

## ✅ 解决方案

### 修改文件

1. **开关量输入页面**：`src/qml/components/device_info/pages/SwitchInputPage.qml`
2. **模拟量输入页面**：`src/qml/components/device_info/pages/AnalogInputPage.qml`

### 修改内容

#### 1. 容器样式统一

**修改前**：
```qml
Rectangle {
    Layout.fillHeight: true
    Layout.preferredWidth: 240
    color: "#1a2332"  // 深蓝色
    radius: 8  // 圆角
    border.color: "#00d4ff"  // 青色边框
    border.width: 1
}
```

**修改后**：
```qml
Rectangle {
    Layout.fillHeight: true
    Layout.preferredWidth: 240
    color: "#1a1f2e"  // 与电机控制一致的深蓝灰背景
    // 移除 radius
    // 移除 border（由内部元素处理）
}
```

#### 2. 标题栏样式统一

**修改前**：
```qml
RowLayout {
    Layout.fillWidth: true
    spacing: 5

    Text {
        text: "开关量列表"
        font.pixelSize: 14
        font.bold: true
        color: "#00ff88"  // 绿色
        Layout.fillWidth: true
    }

    // + 添加按钮
    Rectangle {
        width: 24
        height: 24
        radius: 4
        color: "#34495e"
        border.color: "#00ff88"
        border.width: 1
        // ...
    }
}
```

**修改后**：
```qml
Rectangle {
    Layout.fillWidth: true
    Layout.preferredHeight: 50
    color: "#252b3d"  // 与电机控制一致
    border.color: "#3d4556"
    border.width: 1

    Text {
        anchors.centerIn: parent
        text: "开关量列表"
        font.pixelSize: 16
        font.weight: Font.Bold
        color: "#E0E0E0"  // 浅灰色
    }
}
```

#### 3. 列表项样式统一

**修改前**：
```qml
delegate: Rectangle {
    width: protectionListView.width
    height: 45  // 较小
    radius: 5  // 圆角
    color: root.currentProtectionIndex === index ? "#00AA00" : (model.active ? "#ff4757" : "#2c3e50")
    border.color: root.currentProtectionIndex === index ? "#00FF00" : (model.active ? "#ff6b7a" : "#00d4ff")
    border.width: root.currentProtectionIndex === index ? 2 : 1

    // 闪烁动画（激活状态）
    SequentialAnimation on opacity {
        running: model.active && root.currentProtectionIndex !== index
        loops: Animation.Infinite
        NumberAnimation { to: 0.5; duration: 500 }
        NumberAnimation { to: 1.0; duration: 500 }
    }

    // 悬停缩放效果
    MouseArea {
        hoverEnabled: true
        onEntered: parent.scale = 1.03
        onExited: parent.scale = 1.0
    }
}
```

**修改后**：
```qml
delegate: Rectangle {
    width: protectionListView.width
    height: 60  // 与电机控制一致
    // 移除 radius
    color: root.currentProtectionIndex === index ? "#252b3d" : "transparent"
    border.color: root.currentProtectionIndex === index ? "#2196F3" : "#3d4556"
    border.width: 1

    // ✅ 左侧激活指示条
    Rectangle {
        visible: root.currentProtectionIndex === index
        width: 4
        height: parent.height
        color: "#2196F3"
        anchors.left: parent.left
    }

    // 移除闪烁动画
    // 移除悬停缩放效果
}
```

#### 4. 文本样式统一

**修改前**：
```qml
Text {
    text: model.name
    font.pixelSize: 13  // 较小
    font.bold: root.currentProtectionIndex === index
    color: root.currentProtectionIndex === index ? "white" : (model.active ? "white" : "#00d4ff")  // 青色
    Layout.fillWidth: true
}
```

**修改后**：
```qml
Text {
    text: model.name
    font.pixelSize: 16  // 与电机控制一致
    font.weight: root.currentProtectionIndex === index ? Font.Bold : Font.Normal
    color: root.currentProtectionIndex === index ? "#E0E0E0" : "#9E9E9E"  // 浅灰色
}
```

#### 5. 状态指示器统一

**修改前**：
```qml
Rectangle {
    width: 12
    height: 12
    radius: 6
    color: model.active ? "#ff4757" : "#95a5a6"
    border.color: model.active ? "#ff6b7a" : "#7f8c8d"
    border.width: 1
}
```

**修改后**：
```qml
Rectangle {
    width: 8  // 与电机控制一致
    height: 8
    radius: 4
    color: model.active ? "#F44336" : "#4CAF50"  // 红色激活，绿色正常
    // 移除 border
    anchors.verticalCenter: parent.verticalCenter
}
```

## 🎯 技术要点

### 1. 颜色方案统一

**电机控制配色**：
- 背景色：`#1a1f2e`（深蓝灰）
- 标题栏：`#252b3d`（稍浅的蓝灰）
- 边框色：`#3d4556`（中灰）
- 激活色：`#2196F3`（蓝色）
- 文本色：`#E0E0E0`（浅灰）/ `#9E9E9E`（中灰）
- 状态色：`#4CAF50`（绿色正常）/ `#F44336`（红色激活）

**旧配色（科技感）**：
- 背景色：`#1a2332`（深蓝）
- 边框色：`#00d4ff`（青色）
- 高亮色：`#00ff88`（绿色）
- 激活色：`#00AA00`（绿色）/ `#ff4757`（红色）

### 2. 布局尺寸统一

**电机控制尺寸**：
- 列表宽度：240px
- 标题栏高度：50px
- 列表项高度：60px
- 激活条宽度：4px
- 状态指示器：8×8px

**旧尺寸**：
- 列表宽度：240px（相同）
- 标题栏高度：不固定
- 列表项高度：45px（较小）
- 状态指示器：12×12px（较大）

### 3. 移除的效果

**移除的视觉效果**：
- ❌ 圆角 (radius)
- ❌ 闪烁动画 (SequentialAnimation)
- ❌ 悬停缩放 (scale animation)
- ❌ 添加按钮 (+ button)
- ❌ 分隔线

**保留的功能**：
- ✅ 列表选择
- ✅ 状态指示
- ✅ 鼠标点击
- ✅ 数据加载

### 4. 新增的元素

**左侧激活指示条**：
```qml
Rectangle {
    visible: root.currentProtectionIndex === index
    width: 4
    height: parent.height
    color: "#2196F3"
    anchors.left: parent.left
}
```

**作用**：
- 清晰标识当前选中项
- 与电机控制风格一致
- 替代原来的背景色高亮

## 🔄 对比总结

### 修改前（科技感风格）

**特点**：
- 青色边框、绿色高亮
- 圆角设计
- 闪烁动画
- 悬停缩放效果
- 较小的列表项 (45px)

**适用场景**：
- 科技感强的应用
- 需要吸引注意力的界面
- 动态效果丰富的场景

### 修改后（工业风格）

**特点**：
- 蓝灰色调
- 直角设计
- 无动画效果
- 左侧激活条
- 较大的列表项 (60px)

**适用场景**：
- 工业控制系统
- 需要稳定可靠的界面
- 长时间使用不疲劳

**优势**：
- ✅ 视觉统一，专业感强
- ✅ 减少动画，性能更好
- ✅ 更大的点击区域，易用性好
- ✅ 符合工业控制系统的审美

# FIX 100.300.25.16 完成 - 统一所有页面左侧列表宽度为 240px

**日期**: 2026-01-26
**类型**: UI优化（视觉统一）
**文件**: `src/qml/components/device_info/pages/MotorControlPage.qml`

## 问题描述

用户反馈：
- 电机列表的宽度和开关量输入、模拟量输入的宽度不一致

## 问题分析

### 当前列表宽度配置

| 页面 | 左侧列表宽度 | 说明 |
|------|-------------|------|
| **开关量输入** | 240px ✅ | 标准宽度 |
| **模拟量输入** | 240px ✅ | 标准宽度 |
| **电机控制** | 200px ❌ | 比其他页面窄 40px |

**问题**：
- 电机列表宽度为 200px，比开关量/模拟量列表窄 40px
- 视觉不统一，切换页面时列表宽度会跳变
- 用户体验不佳

### 为什么需要统一宽度？

1. **视觉一致性**：
   - 所有页面的左侧列表应该有相同的宽度
   - 切换页面时不应该有明显的布局跳变

2. **用户体验**：
   - 统一的宽度让用户更容易适应界面
   - 减少视觉干扰，提升专业感

3. **设计规范**：
   - 同类型的元素应该有统一的尺寸
   - 左侧列表都是二级导航，应该使用相同的宽度

## 解决方案

将电机列表的宽度从 200px 调整为 240px，与开关量/模拟量列表统一。

### 修改前

```qml
// MotorControlPage.qml
Loader {
    id: motorListPanel
    width: 200  // ❌ 比其他页面窄
    height: parent.height
    source: "MyMotorListPanel.qml"
}
```

### 修改后

```qml
// MotorControlPage.qml
Loader {
    id: motorListPanel
    // ✅ 2026-01-26 [FIX 100.300.25.16]: 统一列表宽度为 240，与开关量/模拟量一致
    width: 240  // 从 200 改为 240
    height: parent.height
    source: "MyMotorListPanel.qml"
}
```

## 统一后的列表宽度配置

| 页面 | 左侧列表宽度 | 说明 |
|------|-------------|------|
| **开关量输入** | 240px ✅ | 统一 |
| **模拟量输入** | 240px ✅ | 统一 |
| **电机控制** | 240px ✅ | 统一 |

**设计原则**：
- 所有页面的左侧列表宽度统一为 240px
- 右侧区域自动填充剩余空间
- 切换页面时布局稳定，无跳变

## 技术细节

### 为什么选择 240px？

| 宽度 | 优点 | 缺点 |
|------|------|------|
| **200px** | 更紧凑 | 可能显得拥挤，文字可能换行 |
| **240px** ✅ | 足够显示完整文字，视觉舒适 | 占用稍多空间 |
| **280px** | 非常宽敞 | 占用过多空间，右侧区域变小 |

**选择 240px 的原因**：
- 足够显示"1号电机"、"急停"、"速度"等文字
- 不会过于拥挤，也不会占用过多空间
- 已经在开关量/模拟量页面中使用，证明是合适的宽度

### 右侧区域的宽度计算

```qml
Loader {
    id: motorConfigPanel
    width: parent.width - motorListPanel.width - 2
    //     ↑ 总宽度    ↑ 列表宽度(240)   ↑ 分隔线(2)
    height: parent.height
    source: "MotorConfigPanel.qml"
}
```

**计算公式**：
- 右侧宽度 = 总宽度 - 列表宽度(240) - 分隔线(2)
- 列表宽度从 200 改为 240，右侧宽度会减少 40px
- 但右侧区域仍然足够显示电机配置内容

# FIX 100.300.25.6 - 设备设置对话框左侧按钮背景图片

**日期**: 2026-01-26
**类型**: UI统一
**文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

## 问题描述

用户要求：
- 为DeviceSettingsDialog.qml的左侧按钮（基本配置、开关量输入等）添加背景图片
- 未选中状态使用 `dvList.png`
- 选中状态使用 `dvList2.png`

## 解决方案

### 修改左侧按钮背景

为左侧7个类别按钮添加背景图片和States状态管理：

```qml
Button {
    width: parent.width - 20
    height: 40
    text: modelData
    flat: true

    background: Rectangle {
        color: "transparent"  // 透明背景，使用背景图片
        border.color: root.currentCategory === index ? "#2196F3" : "#3d4556"
        border.width: root.currentCategory === index ? 2 : 1
        radius: 2

        // ✅ 添加背景图片（States方式）
        Image {
            id: buttonBackgroundImage
            anchors.fill: parent
            fillMode: Image.Stretch
            z: -1  // 放在最底层

            source: "../../images/dvList.png"

            states: [
                State {
                    name: "selected"
                    when: root.currentCategory === index
                    PropertyChanges {
                        target: buttonBackgroundImage
                        source: "../../images/dvList2.png"
                    }
                },
                State {
                    name: "normal"
                    when: root.currentCategory !== index
                    PropertyChanges {
                        target: buttonBackgroundImage
                        source: "../../images/dvList.png"
                    }
                }
            ]
        }

        // 左侧激活指示条
        Rectangle {
            visible: root.currentCategory === index
            width: 4
            height: parent.height
            color: "#2196F3"
            anchors.left: parent.left
        }
    }

    contentItem: Text {
        text: parent.text
        color: root.currentCategory === index ? "#E0E0E0" : "#9E9E9E"
        font.pixelSize: 14
        font.weight: root.currentCategory === index ? Font.Medium : Font.Normal
        horizontalAlignment: Text.AlignHCenter
        verticalAlignment: Text.AlignVCenter
    }
}
```

## 技术细节

### 按钮列表

左侧7个类别按钮：
1. 基本配置
2. 开关量输入
3. 模拟量输入
4. 电机控制

6. 张紧控制

### States实现

- **selected状态**：`root.currentCategory === index` 时显示 `dvList2.png`
- **normal状态**：`root.currentCategory !== index` 时显示 `dvList.png`
- 使用相对路径 `../../images/` 便于QDS预览

### 相对路径说明

当前文件位置：`src/qml/components/device_info/DeviceSettingsDialog.qml`
图片位置：`src/qml/images/dvList.png`

- 向上两级到 `src/qml/`：`../../`
- 进入images目录：`images/`
- 完整路径：`../../images/dvList.png`

### 视觉层次

1. **背景图片** (z: -1) - dvList.png / dvList2.png
2. **边框** - 蓝色（选中）/ 灰色（未选中）
3. **左侧指示条** - 蓝色竖条（仅选中时显示）
4. **文字** - 浅灰（选中）/ 中灰（未选中）

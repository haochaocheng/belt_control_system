## 技术实现

### 1. 背景图片配置

**Image 组件**：
```qml
Image {
    id: buttonBackgroundImage
    anchors.fill: parent  // 填充整个按钮区域
    fillMode: Image.Stretch  // 拉伸填充
    z: -1  // 放在最底层，文字在上面
    source: "../../../images/DJHeadbutton1.png"  // 默认未选中图片
}
```

**关键属性**：
- `anchors.fill: parent`: 让图片填充整个按钮区域 (120x50)
- `fillMode: Image.Stretch`: 拉伸图片以适应按钮尺寸
- `z: -1`: 确保图片在文字下方
- 相对路径：`../../../images/` 便于 QDS 预览

### 2. States 状态切换

**状态定义**：
```qml
states: [
    State {
        name: "selected"
        when: root.currentTabIndex === index
        PropertyChanges {
            target: buttonBackgroundImage
            source: "../../../images/DJHeadbutton2.png"
        }
    },
    State {
        name: "normal"
        when: root.currentTabIndex !== index
        PropertyChanges {
            target: buttonBackgroundImage
            source: "../../../images/DJHeadbutton1.png"
        }
    }
]
```

**工作原理**：
1. **when 条件**: 根据 `root.currentTabIndex === index` 自动切换状态
2. **selected 状态**: 当前 Tab 被选中时，切换到 DJHeadbutton2.png
3. **normal 状态**: 当前 Tab 未选中时，使用 DJHeadbutton1.png
4. **自动切换**: 当 `root.currentTabIndex` 改变时，states 自动更新

### 3. 保留的视觉元素

**底部激活指示条**（保留）：

Rectangle {

## 技术优势

### 使用 States 的优点

1. **声明式**: 状态切换逻辑清晰，易于理解
2. **自动化**: 根据 `when` 条件自动切换，无需手动管理
3. **可维护**: 添加新状态或修改现有状态很容易
4. **性能**: QML 引擎优化了 states 的切换性能

### 相对路径的优点

1. **QDS 兼容**: 使用相对路径便于 QDS 预览
2. **可移植**: 不依赖绝对路径，项目结构改变时更灵活
3. **清晰**: 路径结构清晰，易于理解资源位置

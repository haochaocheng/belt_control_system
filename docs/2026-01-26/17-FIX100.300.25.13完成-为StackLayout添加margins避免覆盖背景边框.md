# FIX 100.300.25.13 完成 - 为 StackLayout 添加 margins 避免覆盖背景边框

**日期**: 2026-01-26
**类型**: Bug修复（UI布局）
**文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

## 问题描述

用户反馈：
- StackLayout 的内容靠近左上角
- 内容覆盖了背景图片 154.png 的装饰边框

## 问题分析

### 当前布局结构

```qml
Rectangle {
    id: contentArea

    // ✅ 背景图片 154.png（带装饰边框）
    Image {
        anchors.fill: parent
        source: "../../images/154.png"
        fillMode: Image.Stretch
        z: -1
    }

    StackLayout {
        id: contentStack
        anchors.left: parent.left        // ❌ 紧贴左边缘
        anchors.right: parent.right      // ❌ 紧贴右边缘
        anchors.top: parent.top          // ❌ 紧贴上边缘
        anchors.bottom: bottomButtonsContainer.top
        anchors.bottomMargin: 20         // ✅ 底部有 margin
        // ...
    }
}
```

**问题**：
- StackLayout 只有 `bottomMargin: 20`，其他三个方向都紧贴边缘
- 背景图片 154.png 可能有装饰性的边框（阴影、圆角等）
- 内容紧贴边缘会覆盖装饰边框，视觉效果不佳

## 解决方案

为 StackLayout 添加四个方向的 margins：

```qml
StackLayout {
    id: contentStack
    anchors.left: parent.left
    anchors.right: parent.right
    anchors.top: parent.top
    anchors.bottom: bottomButtonsContainer.top
    // ✅ 2026-01-26 [FIX 100.300.25.13]: 添加 margins，让内容在背景图片边框内部显示
    anchors.leftMargin: 15
    anchors.rightMargin: 15
    anchors.topMargin: 15
    anchors.bottomMargin: 20
    currentIndex: root.currentCategory
    // ...
}
```

## 技术原理

### 为什么需要 margins？

1. **背景图片可能有装饰边框**：
   - 阴影效果
   - 圆角边框
   - 渐变边缘
   - 发光效果

2. **内容紧贴边缘的问题**：
   - 覆盖装饰效果
   - 视觉上显得拥挤
   - 难以区分内容区域和背景

3. **添加 margins 的好处**：
   - 内容在边框内部显示
   - 留出视觉呼吸空间
   - 背景装饰效果完整展示

### Margin 值的选择

| 方向 | 值 | 说明 |
|------|---|------|
| **leftMargin** | 15 | 避免覆盖左侧边框 |
| **rightMargin** | 15 | 避免覆盖右侧边框 |
| **topMargin** | 15 | 避免覆盖上侧边框 |
| **bottomMargin** | 20 | 为底部按钮留出更多空间 |

**为什么底部 margin 更大？**
- 底部有 bottomButtonsContainer（底部按钮区域）
- 需要更多空间分隔内容和按钮
- 视觉上更加舒适

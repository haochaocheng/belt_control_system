## ❌ 问题描述

**用户反馈**：
> "开关量和模拟量，保护参数设计区域的风格主题要换成电机控制一样"

**当前状态**：

## 🎯 技术要点

### 1. 颜色方案统一

**电机控制配色**（目标风格）：
- 容器背景：`transparent`（透明）
- 输入框背景：`#2d3548`（深蓝灰）
- 边框色：`#3d4556`（中灰）
- 焦点边框：`#2196F3`（蓝色）
- 标题文本：`#E0E0E0`（浅灰）
- 标签文本：`#9E9E9E`（标签灰）
- 输入文本：`#E0E0E0`（浅灰）

**旧配色**（科技感风格）：
- 容器背景：`#1a2332`（深蓝）
- 输入框背景：`#34495e`（深灰）
- 边框色：`#00d4ff`（青色）/ `#7f8c8d`（灰色）
- 焦点边框：`#3498db`（蓝色）
- 标题文本：`#00d4ff`（青色）
- 标签文本：`#95a5a6`（浅灰）
- 输入文本：`#ecf0f1`（浅灰）

### 2. 尺寸和圆角统一

**电机控制尺寸**（目标尺寸）：
- 标题字体：16px
- 标签字体：14px
- 输入框字体：14px
- 圆角：2px（小圆角）

**旧尺寸**：
- 标题字体：15px
- 标签字体：13px
- 输入框字体：12px
- 圆角：4px（中等圆角）

### 3. 批量替换策略

使用 `replace_all: true` 批量替换相同的颜色值：
```qml
// 标签文本颜色
"#95a5a6" → "#9E9E9E"

// 输入框背景
"#34495e" → "#2d3548"

// 输入文本颜色
"#ecf0f1" → "#E0E0E0"

// 边框颜色
"#7f8c8d" → "#3d4556"

// 焦点边框
"#3498db" → "#2196F3"

// 青色元素
"#00d4ff" → "#3d4556" 或 "#2196F3"

// 圆角
radius: 4 → radius: 2
```

### 4. 保持不变的元素

**按钮样式**：
- 保存按钮：绿色系（#27ae60, #2ecc71）
- 删除按钮：红色系（#c0392b, #e74c3c, #d35400）
- 重置按钮：灰色系（#7f8c8d, #95a5a6）

**原因**：按钮使用语义化颜色（绿色=保存，红色=删除，灰色=重置），不需要改为蓝灰色调。

## 🔍 技术细节

### 为什么使用透明背景？

**电机控制的设计理念**：
- 参数编辑区域不需要额外的视觉边界
- 透明背景让内容更加突出
- 减少视觉层次，简化界面
- 与整体深色背景融为一体

### 为什么使用小圆角（2px）？

**工业风格的特点**：
- 小圆角保持现代感，但不过分圆润
- 2px 圆角几乎不可见，接近直角
- 符合工业控制系统的严谨风格
- 与电机控制完全一致

### 为什么保持按钮的语义化颜色？

**用户体验考虑**：
- 绿色=保存（积极操作）
- 红色=删除（危险操作）
- 灰色=重置（中性操作）
- 语义化颜色帮助用户快速识别操作类型
- 不需要改为蓝灰色调

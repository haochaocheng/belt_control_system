# FIX 100.300.25.10 - 深度调试：列表右侧元素不显示问题

**日期**: 2026-01-26
**类型**: Bug调试
**文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

## 问题描述

用户报告：
- 开关量列表和模拟量列表下面的元素不显示
- 电机控制列表下面的元素也不显示
- 之前的 ScrollView implicitHeight 修复没有解决问题

## 问题分析

### 布局结构对比

#### 1. 开关量/模拟量页面（使用 RowLayout）

```qml
Rectangle {
    RowLayout {
        anchors.fill: parent
        spacing: 15

        // 左侧：列表
        Rectangle {
            Layout.fillHeight: true
            Layout.preferredWidth: 240

            ColumnLayout {
                ListView {
                    Layout.fillWidth: true
                    Layout.fillHeight: true
                }
            }
        }

        // 右侧：参数编辑区域
        Rectangle {
            Layout.fillHeight: true
            Layout.fillWidth: true  // ⚠️ 应该获得剩余宽度

            ColumnLayout {
                ScrollView {
                    ColumnLayout {
                        // 参数字段
                    }
                }
            }
        }
    }
}
```

#### 2. 电机控制页面（使用 Row）

#### 3. DeviceSettingsDialog 中的 StackLayout

```qml
Rectangle {
    id: contentArea
    anchors.left: leftButtonsContainer.right
    anchors.right: parent.right
    anchors.top: topButtonsContainer.bottom
    anchors.bottom: parent.bottom

    StackLayout {
        id: contentStack
        anchors.left: parent.left
        anchors.right: parent.right
        anchors.top: parent.top
        anchors.bottom: bottomButtonsContainer.top
        anchors.bottomMargin: 20
        currentIndex: root.currentCategory

        // ⚠️ 问题可能在这里：Loader 没有明确的尺寸
        Loader {
            id: switchInputPageLoader
            active: root.currentCategory === 1
            source: "pages/SwitchInputPage.qml"
        }
    }
}
```

### 可能的问题

1. **StackLayout 的尺寸问题**：
   - StackLayout 使用 anchors 定位
   - 但 Loader 可能没有获得正确的尺寸
   - 导致加载的页面尺寸为 0 或很小

2. **Loader 的尺寸传递问题**：
   - Loader 默认会根据 item 的 implicitWidth/implicitHeight 调整尺寸
   - 但如果 item 没有设置这些属性，Loader 可能尺寸为 0

3. **RowLayout 的空间分配问题**：
   - `Layout.fillWidth: true` 可能没有正确工作
   - 右侧区域可能没有获得剩余空间

## 预期调试结果

通过日志输出，我们应该能看到：

1. **StackLayout 的尺寸**：
   - 应该是 contentArea 的尺寸减去 bottomMargin
   - 如果宽度或高度为 0，说明 StackLayout 没有正确获得空间

2. **Loader 的尺寸**：
   - 应该继承 StackLayout 的尺寸
   - 如果为 0，说明 Loader 没有正确获得空间

3. **页面 item 的尺寸**：
   - 应该和 Loader 的尺寸一致
   - 如果为 0，说明页面没有正确设置尺寸

4. **右侧区域的尺寸**：
   - 应该是页面宽度减去左侧列表宽度
   - 如果为 0，说明 RowLayout 没有正确分配空间

## 可能的修复方案

根据调试结果，可能需要：

### 方案1：为 Loader 设置明确的尺寸

```qml
Loader {
    Layout.fillWidth: true
    Layout.fillHeight: true
    source: "pages/SwitchInputPage.qml"
}
```

### 方案2：为页面设置 implicitWidth/implicitHeight

```qml
Rectangle {
    id: root
    implicitWidth: 800
    implicitHeight: 600

    RowLayout {
        anchors.fill: parent
        // ...
    }
}
```

### 方案3：使用 anchors.fill 替代 RowLayout

```qml
Rectangle {
    id: root

    Rectangle {  // 左侧列表
        anchors.left: parent.left
        anchors.top: parent.top
        anchors.bottom: parent.bottom
        width: 240
    }

    Rectangle {  // 右侧参数编辑
        anchors.left: leftSide.right
        anchors.right: parent.right
        anchors.top: parent.top
        anchors.bottom: parent.bottom
    }
}
```

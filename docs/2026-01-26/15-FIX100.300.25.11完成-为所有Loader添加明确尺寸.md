# FIX 100.300.25.11 完成 - 为所有 Loader 添加明确尺寸以支持 QDS 预览

**日期**: 2026-01-26
**类型**: Bug修复
**文件**: `src/qml/components/device_info/DeviceSettingsDialog.qml`

## 问题描述

用户在 Qt Design Studio (QDS) 中预览时，发现三个页面的右侧参数编辑区域不显示：
1. **开关量输入页面** - 右侧保护参数设置区域不可见
2. **模拟量输入页面** - 右侧保护参数设置区域不可见
3. **电机控制页面** - 右侧电机配置面板不可见

## 根本原因

**QDS 预览的特殊限制**：

1. **StackLayout 中的 Loader 没有明确尺寸**：
   - Loader 默认根据 item 的 `implicitWidth`/`implicitHeight` 调整尺寸
   - 如果 item 没有设置这些属性，Loader 可能尺寸为 0
   - QDS 预览环境对动态尺寸计算的支持有限

2. **Layout 系统在 QDS 中的限制**：
   - StackLayout 使用 anchors 定位，但内部的 Loader 没有 Layout 属性
   - QDS 可能无法正确推断 Loader 应该占据的空间
   - 导致加载的页面获得 0 或很小的尺寸

## 解决方案

为 StackLayout 中的所有 Loader 添加明确的 Layout 属性：

```qml
Loader {
    id: somePageLoader
    // ✅ 2026-01-26 [FIX 100.300.25.11]: 为 Loader 设置明确尺寸，便于 QDS 预览
    Layout.fillWidth: true
    Layout.fillHeight: true
    active: root.currentCategory === someIndex
    source: "pages/SomePage.qml"
    // ...
}
```

## 技术原理

### Layout.fillWidth 和 Layout.fillHeight 的作用

1. **Layout.fillWidth: true**：
   - 告诉 StackLayout：这个 Loader 应该占据所有可用的水平空间
   - 相当于 `width: parent.width`，但更适合 Layout 系统

2. **Layout.fillHeight: true**：
   - 告诉 StackLayout：这个 Loader 应该占据所有可用的垂直空间
   - 相当于 `height: parent.height`，但更适合 Layout 系统

### 为什么 QDS 需要这些属性

- **运行时环境**：Qt 运行时可以动态计算 Loader 的尺寸
- **QDS 预览环境**：QDS 的预览引擎对动态尺寸计算的支持有限
- **明确尺寸**：通过 Layout 属性明确告诉 QDS 如何分配空间

## 后续优化

如果此修复仍不能完全解决问题，可以考虑：

1. **为页面根元素添加 implicitWidth/implicitHeight**：
```qml
Rectangle {
    id: root
    implicitWidth: 800
    implicitHeight: 600
    // ...
}
```

2. **使用 anchors 替代 RowLayout**（更适合 QDS）：
```qml
Rectangle {  // 左侧列表
    anchors.left: parent.left
    anchors.top: parent.top
    anchors.bottom: parent.bottom
    width: 240
}

Rectangle {  // 右侧参数编辑
    anchors.left: leftSide.right
    anchors.right: parent.right
    anchors.top: parent.top
    anchors.bottom: parent.bottom
}
```

3. **使用直接组件实例替代 Loader**（仅用于 QDS 预览）：
```qml
// 不使用 Loader，直接实例化
SwitchInputPage {
    visible: root.currentCategory === 1
    Layout.fillWidth: true
    Layout.fillHeight: true
}
```

## 总结

通过为 StackLayout 中的所有 Loader 添加 `Layout.fillWidth: true` 和 `Layout.fillHeight: true`，解决了 QDS 预览环境中右侧区域不显示的问题。这是一个针对 QDS 特殊限制的修复，不影响运行时行为。

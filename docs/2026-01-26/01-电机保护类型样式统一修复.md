# 电机保护类型样式统一修复

**日期**：2026-01-26
**问题**：前轴承温度等保护类型的输入框样式不统一，延时显示为白色背景

---

## 🐛 问题描述

### 原始问题
1. **布局不一致**：部分保护类型使用了 Qt 的 SpinBox/ComboBox 控件，背景色为白色
2. **样式不统一**：与基本配置的深色主题不匹配
3. **视觉效果差**：白色背景在深色主题中非常突兀

### 用户要求
- 所有保护类型应该和基本配置保持一致
- 标签和输入框在同一行
- 使用深色背景（#2d3548）
- 统一的边框和文字颜色

---

## ✅ 解决方案

### 1. 统一使用自定义 Rectangle 替代 Qt 控件

**之前（使用 Qt 控件）**：
```qml
SpinBox {
    from: -40
    to: 200
    value: 80
    editable: true
    font.pixelSize: 14
}
```
- ❌ 背景色为白色
- ❌ 样式无法完全自定义
- ❌ 与深色主题不匹配

**之后（使用自定义 Rectangle）**：
```qml
Rectangle {
    width: 120
    height: 36
    color: "#2d3548"  // 深色背景
    border.color: "#3d4556"
    border.width: 1
    radius: 2
    Text {
        anchors.centerIn: parent
        text: "80"
        font.pixelSize: 14
        color: "#E0E0E0"  // 浅色文字
    }
}
```
- ✅ 深色背景
- ✅ 完全自定义样式
- ✅ 与主题完美匹配

### 2. 统一的颜色规范

| 元素 | 颜色 | 说明 |
|------|------|------|
| 输入框背景 | `#2d3548` | 深蓝灰 |
| 输入框边框 | `#3d4556` | 中蓝灰 |
| 输入框文字 | `#E0E0E0` | 浅灰白 |
| 标签文字 | `#9E9E9E` | 中灰 |
| 强调色 | `#2196F3` | 科技蓝 |

### 3. 统一的布局规范

```qml
Row {
    width: parent.width
    spacing: 20

    // 标签（固定宽度120px）
    Text {
        text: "参数名称:"
        width: 120
        font.pixelSize: 14
        color: "#9E9E9E"
        anchors.verticalCenter: parent.verticalCenter
    }

    // 输入框
    Rectangle {
        width: 200  // 或 120，根据内容调整
        height: 36
        color: "#2d3548"
        border.color: "#3d4556"
        border.width: 1
        radius: 2
        Text {
            anchors.centerIn: parent
            text: "值"
            font.pixelSize: 14
            color: "#E0E0E0"
        }
    }
}
```

## 🔄 修复流程

### 步骤 1：修复 FrontBearingTempTab.qml
- 移除所有 Qt 控件（SpinBox, ComboBox, RadioButton）
- 使用自定义 Rectangle 替代
- 应用统一的颜色和样式

### 步骤 2：批量复制到其他文件
```bash
for file in RearBearingTempTab.qml PhaseAWindingTab.qml ...; do
    cp FrontBearingTempTab.qml "$file"
done
```

### 步骤 3：更新注释
```bash
sed -i 's/前轴承温度保护/后轴承温度保护/g' RearBearingTempTab.qml
# ... 其他文件
```

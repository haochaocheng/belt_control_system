# FIX 100.300.25.5 - 模拟量和电机列表背景图片统一

**日期**: 2026-01-26
**类型**: UI统一
**文件**:
- `src/qml/components/device_info/pages/AnalogInputPage.qml`
- `src/qml/components/device_info/pages/MyMotorListPanel.qml`

## 问题描述

用户要求：
- 将模拟量输入列表（速度、张力等）和电机控制列表（电机1等）也添加背景图片
- 与开关量列表保持一致的视觉风格

## 解决方案

### 1. 模拟量输入页面 (AnalogInputPage.qml)

为模拟量列表添加背景图片和居中布局：

```qml
delegate: Rectangle {
    color: "transparent"  // 透明背景，使用背景图片

    // 添加背景图片（States方式）
    Image {
        id: backgroundImage
        anchors.fill: parent
        fillMode: Image.Stretch
        z: -1

        source: "../../../images/bhNameBK.png"

        states: [
            State {
                name: "selected"
                when: root.currentProtectionIndex === index
                PropertyChanges {
                    target: backgroundImage
                    source: "../../../images/bhNameBK1.png"
                }
            },
            State {
                name: "normal"
                when: root.currentProtectionIndex !== index
                PropertyChanges {
                    target: backgroundImage
                    source: "../../../images/bhNameBK.png"
                }
            }
        ]
    }

    // 左侧激活指示条
    Rectangle {
        visible: root.currentProtectionIndex === index
        width: 4
        color: "#2196F3"
        anchors.left: parent.left
    }

    // 模拟量名称居中显示
    Text {
        text: model.name
        anchors.centerIn: parent
    }

    // 状态指示放在最右侧
    Row {
        spacing: 8
        anchors.right: parent.right
        anchors.rightMargin: 20

        Rectangle {
            width: 8
            height: 8
            radius: 2
            color: model.active ? "#F44336" : "#4CAF50"
        }

        Text {
            text: model.active ? "已激活" : "正常"
        }
    }
}
```

delegate: Rectangle {

## 统一的视觉效果

现在所有三个列表页面都具有一致的布局和风格：

1. **开关量列表** (SwitchInputPage.qml)
   - 急停、跑偏、撕裂等

2. **模拟量列表** (AnalogInputPage.qml)
   - 速度、张力、红外温度等

3. **电机列表** (MyMotorListPanel.qml)
   - 1号电机、2号电机等

### 统一的布局结构

```
┌─────────────────────────────────────┐
│ ┃       项目名称           ● 状态   │
└─────────────────────────────────────┘
```

- **左侧**：蓝色激活指示条（选中时显示）
- **中间**：项目名称（水平垂直居中）
- **右侧**：状态指示（状态点 + 状态文字）

### 统一的States实现

所有三个页面都使用相同的States方式：
- `selected` 状态：显示 `bhNameBK1.png`
- `normal` 状态：显示 `bhNameBK.png`
- 使用相对路径 `../../../images/` 便于QDS预览

## 技术细节

### 布局改进

**之前**：使用Column布局，名称和状态垂直排列，左对齐
```qml
Column {
    anchors.left: parent.left
    anchors.leftMargin: 20

    Text { text: model.name }
    Row { /* 状态指示 */ }
}
```

**现在**：使用anchors定位，名称居中，状态右对齐
```qml
Text {
    text: model.name
    anchors.centerIn: parent
}

Row {
    anchors.right: parent.right
    anchors.rightMargin: 20
    /* 状态指示 */
}
```

### 背景图片实现

1. **透明背景**：`color: "transparent"`
2. **图片填充**：`fillMode: Image.Stretch`
3. **底层显示**：`z: -1`
4. **状态切换**：使用States的when条件自动切换

### 相对路径说明

三个文件都位于 `src/qml/components/device_info/pages/`：
- 向上三级到 `src/qml/`：`../../../`
- 进入images目录：`images/`
- 完整路径：`../../../images/bhNameBK.png`

## 设计理念

### 一致性原则

所有设备信息的列表页面应该：
1. 使用相同的布局结构（左指示条 | 中间名称 | 右侧状态）
2. 使用相同的背景图片
3. 使用相同的颜色方案
4. 使用相同的交互方式

### 用户体验

1. **视觉一致性**：减少用户学习成本
2. **信息层次**：名称居中突出，状态信息辅助
3. **操作反馈**：选中项有明确的视觉反馈（背景图片变化 + 蓝色指示条）

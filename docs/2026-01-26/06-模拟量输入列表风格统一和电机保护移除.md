# 模拟量输入列表风格统一和电机保护移除

**日期**：2026-01-26
**任务**：统一模拟量输入列表主题风格，并移除所有电机相关的模拟量保护
**FIX**：100.300.23

---

## ❌ 问题描述

**用户反馈**：
> "问题1，模拟量的风格没有改回来，二是电流1电流2，1号电机温度一下所有的模拟量保护全部删除，因为这个都属于电机控制里设置"

**问题分析**：

### 问题1：列表风格不统一
- **模拟量输入**：使用科技感风格（青色边框、绿色高亮）
- **电机控制**：使用工业风格（蓝灰色调、简洁设计）
- **用户期望**：所有列表使用统一的电机控制风格

### 问题2：电机保护放错位置
- **当前状态**：模拟量输入包含大量电机相关保护
  - 电流一、电流二
  - 1号电机温度、2号电机温度
  - 1号电机X振动、Y振动
  - 2号电机X振动、Y振动
  - 1号电机第一/二/三项绕组
  - 2号电机第一/二/三项绕组
- **问题**：这些保护应该在"电机控制"类别中设置，不应该出现在"模拟量输入"中
- **用户期望**：模拟量输入只保留皮带系统级别的保护

## 🎯 技术要点

### 1. 颜色方案统一

**电机控制配色**（目标风格）：
- 背景色：`#1a1f2e`（深蓝灰）
- 标题栏：`#252b3d`（稍浅的蓝灰）
- 边框色：`#3d4556`（中灰）
- 激活色：`#2196F3`（蓝色）
- 文本色：`#E0E0E0`（浅灰）/ `#9E9E9E`（中灰）
- 状态色：`#4CAF50`（绿色正常）/ `#F44336`（红色激活）

**旧配色**（科技感风格）：
- 背景色：`#1a2332`（深蓝）
- 边框色：`#00d4ff`（青色）
- 高亮色：`#00ff88`（绿色）
- 激活色：`#00AA00`（绿色）/ `#ff4757`（红色）

### 2. 布局尺寸统一

**电机控制尺寸**（目标尺寸）：
- 列表宽度：240px
- 标题栏高度：50px
- 列表项高度：60px
- 激活条宽度：4px
- 状态指示器：8×8px

**旧尺寸**：
- 列表宽度：240px（相同）
- 标题栏高度：不固定
- 列表项高度：45px（较小）
- 状态指示器：12×12px（较大）

### 3. 移除的效果

**移除的视觉效果**：
- ❌ 圆角 (radius)
- ❌ 闪烁动画 (SequentialAnimation)
- ❌ 悬停缩放 (scale animation)
- ❌ 添加按钮 (+ button)
- ❌ 分隔线

**保留的功能**：
- ✅ 列表选择
- ✅ 状态指示
- ✅ 鼠标点击
- ✅ 数据加载

### 4. 新增的元素

**左侧激活指示条**：
```qml
Rectangle {
    visible: root.currentProtectionIndex === index
    width: 4
    height: parent.height
    color: "#2196F3"
    anchors.left: parent.left
}
```

**作用**：
- 清晰标识当前选中项
- 与电机控制风格一致
- 替代原来的背景色高亮

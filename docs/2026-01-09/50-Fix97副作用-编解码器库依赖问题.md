# Fix 97 副作用：编解码器库依赖问题

**日期**: 2026-01-09 19:55
**问题**: 添加硬件编码器后，应用程序缺少多个编解码器库
**根本原因**: 应用程序编译时链接了所有 FFmpeg 编解码器库，但容器运行时没有提供
**状态**: 🔴 **阻塞 - 需要提供所有编解码器库**

---

## 🔍 问题发现

### 用户反馈

> "怎么修改之后这么多连接库，之前不选择硬件编码的时候，也没有这个提示，修改导致的"

**现象**:
```
libx264.so.160 => not found
libwebp.so.6 => not found
libcodec2.so.0.9 => not found
libdav1d.so.4 => not found
libaom.so.0 => not found
librga.so.2 => not found
libyuv.so.2 => not found
libvpx.so.6 => not found
```

### 根本原因

#### 修改前（无硬件编码器）

**PJSIP 编译配置**（build-ubuntu24-apt.ps1 旧版本）:
```powershell
# 只链接 FFmpeg 核心库
export LIBS="-lavcodec -lavformat -lavutil"
```

**应用程序依赖**: 只需要 FFmpeg 核心库（libavcodec, libavformat, libavutil）

#### 修改后（添加硬件编码器）

**PJSIP 编译配置**（build-ubuntu24-apt.ps1 Line 555）:
```bash
# ✅ 2025-12-31 10:15 关键修复：修改 build.mak 添加 FFmpeg 编解码器依赖库
sed -i 's|-lavformat -lavcodec -lswscale -lavutil[^[:space:]]*|-lavformat -lavcodec -lswscale -lavutil -lswresample -lx264 -lx265 -lvpx -laom -lrockchip_mpp|g' build.mak
```

**应用程序依赖**: FFmpeg 核心库 + **所有编解码器库**

### 库缺失列表

| 库名 | 用途 | 优先级 |
|------|------|--------|
| `libx264.so.160` | H.264 编码器（软件） | 🔴 必需 |
| `librga.so.2` | Rockchip RGA 图形加速 | 🔴 必需 |
| `libyuv.so.2` | YUV 格式转换 | 🔴 必需 |
| `libvpx.so.6` | VP8/VP9 编解码器 | 🟡 可选 |
| `libwebp.so.6` | WebP 图像编解码器 | 🟡 可选 |
| `libcodec2.so.0.9` | Codec2 语音编码器 | 🟡 可选 |
| `libdav1d.so.4` | AV1 解码器 | 🟡 可选 |
| `libaom.so.0` | AOM AV1 编解码器 | 🟡 可选 |

## 🎯 解决方案

### 方案 A: 快速修复（添加所有库挂载）⚡

**优点**: 快速，不需要重新构建镜像
**缺点**: 配置复杂，容易遗漏库

**步骤 1**: 检查宿主机库版本

```bash
ssh linaro@192.168.10.188 "ls -la /usr/lib/aarch64-linux-gnu/lib{webp,codec2,dav1d,aom,rga,yuv,vpx}.so* 2>/dev/null"
```

**步骤 2**: 创建符号链接（如果版本不匹配）

```bash
# 例如：如果只有 libwebp.so.7，创建 libwebp.so.6 链接
sudo ln -sf libwebp.so.7 /usr/lib/aarch64-linux-gnu/libwebp.so.6
```

**步骤 3**: 修改 build-ubuntu24-apt.ps1 添加所有库挂载

```powershell
# Line 1416 附近，添加所有编解码器库
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libx264.so.160:/opt/hw-libs/libx264.so.160:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libwebp.so.6:/opt/hw-libs/libwebp.so.6:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libcodec2.so.0.9:/opt/hw-libs/libcodec2.so.0.9:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libdav1d.so.4:/opt/hw-libs/libdav1d.so.4:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libaom.so.0:/opt/hw-libs/libaom.so.0:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/librga.so.2:/opt/hw-libs/librga.so.2:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libyuv.so.2:/opt/hw-libs/libyuv.so.2:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libvpx.so.6:/opt/hw-libs/libvpx.so.6:ro"
```

### 方案 B: 根本解决（库打包到 Docker 镜像）🎯 **推荐**

**优点**:
- ✅ 彻底解决依赖问题
- ✅ 容器启动配置简化
- ✅ 版本一致性保证

**缺点**: 需要重新构建镜像（15-20 分钟）

**修改 1**: build-ubuntu24-apt.ps1 Line 1060-1120

**当前代码**（复制库到 docker/rk3588/lib/）:
```powershell
# 只复制少数几个库
$codecLibs = Get-ChildItem -Path $rk3588CodecLibDir -Filter $pattern -File
foreach ($lib in $codecLibs) {
    if ($lib.Length -gt 1KB) {
        Copy-Item $lib.FullName "$DockerContextDir\lib\" -Force
    }
}
```

**修改后**（复制所有需要的编解码器库）:
```powershell
# ✅ 2026-01-09 20:00 [Fix 97 配套] 复制所有编解码器库到 Docker 镜像
# 原因：应用程序编译时链接了所有 FFmpeg 编解码器依赖库
# 方案：将所有库打包到镜像中，避免运行时卷挂载依赖
$requiredCodecLibs = @(
    "libx264.so.160",       # H.264 编码器
    "libwebp.so.6",         # WebP 编解码器
    "libcodec2.so.0.9",     # Codec2 语音编码器
    "libdav1d.so.4",        # AV1 解码器
    "libaom.so.0",          # AOM AV1 编解码器
    "librga.so.2",          # Rockchip RGA 图形加速
    "libyuv.so.2",          # YUV 格式转换
    "libvpx.so.6"           # VP8/VP9 编解码器
)

Write-Host "    Copying required codec libraries to Docker image..." -ForegroundColor Yellow
foreach ($libName in $requiredCodecLibs) {
    $libPath = Join-Path $rk3588CodecLibDir $libName
    if (Test-Path $libPath) {
        Copy-Item $libPath "$DockerContextDir\lib\" -Force
        Write-Host "      ✓ $libName" -ForegroundColor Green
    } else {
        Write-Host "      ⚠️ $libName not found in rk3588-libs" -ForegroundColor Yellow
    }
}
```

**修改 2**: 简化 build-ubuntu24-apt.ps1 Line 1416（移除卷挂载）

**当前代码**:
```powershell
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/libx264.so.160:/opt/hw-libs/libx264.so.160:ro"
# ... 很多卷挂载配置
```

**修改后**（所有库都在镜像中，不需要卷挂载）:
```powershell
# ✅ 2026-01-09 20:00 [Fix 97 配套] 所有编解码器库已打包到镜像中
# 只需要挂载 RKMPP 和 RGA 库（宿主机专有）
HW_LIBS_VOLUME="-v /usr/lib/aarch64-linux-gnu/librockchip_mpp.so.1:/opt/hw-libs/librockchip_mpp.so.1:ro"
HW_LIBS_VOLUME="$HW_LIBS_VOLUME -v /usr/lib/aarch64-linux-gnu/librga.so.2:/opt/hw-libs/librga.so.2:ro"
HW_LIBS_ENV="-e LD_LIBRARY_PATH=/app/lib:/opt/hw-libs:/usr/lib/aarch64-linux-gnu:/lib/aarch64-linux-gnu"
```

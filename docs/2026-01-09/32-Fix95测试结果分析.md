### 可能原因分析

#### 1. VideoSinkItem 渲染问题 ⭐⭐⭐⭐⭐

**症状**：
- ✅ 视频帧到达 `RemoteVideoManager`
- ❓ 没有 `VideoSinkItem::updatePaintNode()` 日志
- ❓ 没有 `VideoSinkItem::presentFrame()` 日志

**可能原因**：
- `QVideoFrame` 没有正确传递到 `QVideoSink`
- `VideoSinkItem::setVideoSink()` 连接失败
- `ItemHasContents` 标志未启用

**验证方法**：
```cpp
// RemoteVideoManager.cpp 中添加日志
qDebug() << "📹 [VIDEO SINK] Presenting frame to Qt:" << frame.width() << "x" << frame.height();
qDebug() << "📹 [VIDEO SINK] Video sink pointer:" << m_videoSink;
qDebug() << "📹 [VIDEO SINK] Frame valid:" << frame.isValid();
```

#### 2. QML 窗口不可见 ⭐⭐⭐

**可能原因**：
- 对方视频窗口被遮挡
- 窗口尺寸为 0x0
- `visible` 属性为 `false`

**验证方法**：
- 检查 QML 视频窗口的 `width`、`height`、`visible`、`z` 属性
- 检查是否有其他 QML 元素遮挡

#### 3. QVideoSink 连接问题 ⭐⭐⭐⭐

**可能原因**：
- `RemoteVideoManager::m_videoSink` 指针为空
- `RemoteVideoManager` 和 `VideoSinkItem` 连接断开

**验证方法**：
```cpp
// 在 RemoteVideoManager::onCallConnected() 添加
qDebug() << "📹 [CONNECTION CHECK] m_videoSink pointer:" << m_videoSink;
```

#### 4. 视频格式不匹配 ⭐⭐

**当前格式**：
- PJSIP 输出: I420 (30323449)
- 异步处理: NV12 → RGBA

**可能问题**：
- Qt 期望格式与实际格式不匹配
- `QVideoFrameFormat` 设置错误

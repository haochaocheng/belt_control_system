## 🔍 根本原因分析

### hwdevice 的作用

`av_hwdevice_ctx_create()` 创建硬件设备上下文（DRM render node: `/dev/dri/renderD128`）

**在旧工控机**：
- RKMPP 解码器可以在**没有 hwdevice** 的情况下工作（混合模式）
- 输出到系统内存（NV12/I420）

**在新工控机**：
- RKMPP 解码器**必须有 hwdevice** 才能初始化
- 强制输出到 GPU 内存（DRM_PRIME）

### 可能的解决方案

1. **方案 A：接受 DRM_PRIME 格式**
   - 修改 RemoteVideoManager 支持 DRM_PRIME
   - 实现 DRM_PRIME → 系统内存的转换
   - ⚠️ 复杂度高，需要深入了解 DRM API

2. **方案 B：禁用硬件解码器**
   - 使用软件 H.264 解码器
   - ⚠️ CPU 负载会显著增加

3. **方案 C：修改 RKMPP 解码器配置**
   - 研究是否可以强制 RKMPP 输出系统内存格式
   - 尝试不同的 AVOptions
   - ⚠️ 需要深入了解 RKMPP 驱动

4. **方案 D：使用其他硬件解码器**
   - 尝试 `h264_v4l2m2m`（V4L2 硬件解码器）
   - 可能兼容性更好
   - ⚠️ 性能可能不如 RKMPP

1. **不同设备的 RKMPP 驱动行为不同**

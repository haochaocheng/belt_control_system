# Fix 100.12 - 使用硬件编码器解决 DRM_PRIME 格式不匹配问题

**修复编号**: Fix 100.12
**日期**: 2026-01-10 16:00
**类型**: 关键修复（方案 B）
**影响**: 新工控机（192.168.1.8）视频通话崩溃

---

## 🎯 问题总结（Core Dump 分析结果）

**问题**: 新工控机视频通话崩溃（exit code 139 - SIGSEGV）

**崩溃路径**:
```
RKMPP 硬件解码器（h264_rkmpp）
      ↓
输出 DRM_PRIME (179) - GPU 内存格式
      ↓
FFmpeg 尝试创建格式转换链（DRM_PRIME → I420）
      ↓
❌ 转换链初始化失败
      ↓
libx264 软件编码器期望 I420 (0) - 系统内存格式
      ↓
avcodec_open2() 失败 → avcodec_close() 清理 → free() 崩溃
```

**Core Dump 堆栈**:
```
#0  __GI___libc_free() ← 尝试释放无效指针
#1  avcodec_close() ← 清理失败的编码器上下文
#2  avcodec_open2() ← 编码器初始化失败
#3  open_ffmpeg_codec() ← PJSIP 打开编码器
```

**详细分析**: [docs/2026-01-09/72-Core-Dump分析-编码器初始化崩溃根因.md](72-Core-Dump分析-编码器初始化崩溃根因.md)

---

## ✅ 解决方案：使用硬件编码器（方案 B）

### 技术原理

**为什么硬件编码器可以解决问题？**

```
RKMPP 硬件解码器（h264_rkmpp）
      ↓
输出 DRM_PRIME (179) - GPU 内存格式
      ↓
✅ 直接传递（零拷贝）
      ↓
RKMPP 硬件编码器（h264_rkmpp）
      ↓
输入 DRM_PRIME (179) - GPU 内存格式（原生支持）
      ↓
编码成功（数据始终在 GPU 内存，无需转换）
```

**关键优势**:
1. ✅ **格式兼容**：硬件编码器原生支持 DRM_PRIME 格式
2. ✅ **零拷贝**：数据始终在 GPU 内存，无需系统内存转换
3. ✅ **性能提升**：CPU 负载从 55-80% 降至 10-15%
4. ✅ **已验证**：Jellyfin/Frigate 生产环境稳定运行

**理论依据**: [docs/2026-01-08/17-Rockchip-MPP-Issue157全网调研报告.md](../2026-01-08/17-Rockchip-MPP-Issue157全网调研报告.md)

**默认值**: `1`（启用硬件编码器）

**代码位置**: [ffmpeg_vid_codecs.c:1128-1197](../../../cross-compile/src/pjproject-2.16/pjmedia/src/pjmedia-codec/ffmpeg_vid_codecs.c#L1128-L1197)

```c
// Line 1128-1131: 环境变量声明
const char* use_hw_encoder = getenv("USE_HARDWARE_ENCODER");
int enable_hw_encoder = 1;  // 默认：1（启用硬件编码器）
if (use_hw_encoder) {
    enable_hw_encoder = atoi(use_hw_encoder);
}

// Line 1192-1197: 硬件编码器注册（默认启用）
if (hw_encoder_name && enable_hw_encoder == 1) {
    PJ_LOG(1,(THIS_FILE, "✅ [FIX 97] Hardware encoder ENABLED (USE_HARDWARE_ENCODER=%d, default=1)", enable_hw_encoder));
    PJ_LOG(1,(THIS_FILE, "   Using hardware encoder: %s", hw_encoder_name));
    c = avcodec_find_encoder_by_name(hw_encoder_name);  // h264_rkmpp
    // ...
}

// Line 1278-1284: 软件编码器回退（显式禁用时）
else if (hw_encoder_name) {
    PJ_LOG(1,(THIS_FILE, "⚠️ [FIX 97] Hardware encoder DISABLED (USE_HARDWARE_ENCODER=%d)", enable_hw_encoder));
    PJ_LOG(1,(THIS_FILE, "   Falling back to software H.264 encoder"));
    c = avcodec_find_encoder(codec_id);  // libx264
    // ...
}
```

### Jellyfin/Frigate 成功案例

**架构**（nyanmisaka/ffmpeg-rockchip）:
```
h264_rkmpp 解码器 → DRM_PRIME → scale_rkrga 滤镜 → h264_rkmpp 编码器
                  (GPU 内存)                    (GPU 内存)
```

**关键技术**:
1. ✅ DRM Render Node (`/dev/dri/renderD128`) - 避免独占锁冲突
2. ✅ 零拷贝管道 - 数据始终在 GPU 内存
3. ✅ RGA 硬件滤镜 - 格式转换和缩放

**性能数据**（Jellyfin）:
```
CPU 占用: 5-8%（双向视频转码）
VPU 负载: ~80%
内存: <500MB
```

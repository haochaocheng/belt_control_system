## 根本原因分析

### 严重的内存管理错误

**ffmpeg_vid_codecs.c Line 3284**：
```c
AVFrame avframe;  // 栈变量
```

**ffmpeg_vid_codecs.c Line 3405-3410（修改前）**：
```c
// 释放 GPU 帧
av_frame_unref(&avframe);

// 使用系统内存帧替换原始帧
avframe = *sw_frame;           // ❌ 危险的浅拷贝！
av_free(sw_frame);             // ❌ 只释放结构体
```

### 问题分析

| 步骤 | 操作 | 内存状态 | 问题 |
|------|------|---------|------|
| 1 | `AVFrame avframe` | 栈变量，~900 字节 | ✅ 正常 |
| 2 | `sw_frame = av_frame_alloc()` | 堆上分配 AVFrame 结构 | ✅ 正常 |
| 3 | `av_hwframe_transfer_data()` | sw_frame 分配 CPU 内存 buffers（~1MB） | ✅ 正常 |
| 4 | `av_frame_unref(&avframe)` | 释放 avframe 的 DRM_PRIME buffers | ✅ 正常 |
| 5 | `avframe = *sw_frame` | **浅拷贝所有字段**，包括指针 | ❌ **Bug** |
| 6 | `av_free(sw_frame)` | 只释放 AVFrame 结构（~900 字节） | ❌ **Bug** |

### 内存泄漏和崩溃流程

**Step 5 浅拷贝后**：
```c
// avframe 和 sw_frame 都指向同一块 CPU 内存
avframe.data[0] = 0x12345678;  // 指向 1MB CPU buffer
sw_frame->data[0] = 0x12345678;  // 指向同一块内存
```

**Step 6 av_free(sw_frame) 后**：
```c
// sw_frame 指针被释放（AVFrame 结构）
// 但 data buffers（1MB）没有被释放！
avframe.data[0] = 0x12345678;  // 指向 orphaned memory（孤儿内存）
```

**函数返回后**：
```c
// avframe 是栈变量，被销毁
// 但 avframe.data[0] 指向的 1MB 内存没有被释放
// → 内存泄漏
```

**后续访问**：
```c
// 编码器访问 avframe.data[0]（已经被销毁）
// → 悬空指针
// → 段错误（exit 139）
```

### 为什么编码器崩溃

1. **内存泄漏累积**：每次解码都泄漏 ~1MB 内存
2. **资源耗尽**：编码 3-6 帧后，内存压力触发崩溃
3. **悬空指针访问**：编码器读取被销毁的 avframe 数据 → 段错误

---

## 解决方案

### 修复 92：使用 av_frame_move_ref()

**正确的所有权转移**：
```c
// 释放 avframe 原来的 DRM_PRIME buffers
av_frame_unref(&avframe);

// 移动引用（正确的所有权转移）
av_frame_move_ref(&avframe, sw_frame);

// 释放 sw_frame 结构（数据已转移到 avframe）
av_frame_free(&sw_frame);
```

### av_frame_move_ref() 的工作原理

| 操作 | 效果 |
|------|------|
| `av_frame_move_ref(&avframe, sw_frame)` | 移动所有权 |
| avframe.data[0] | 接管 sw_frame 的 data buffers |
| sw_frame->data[0] | 设置为 NULL |
| sw_frame->buf[0] | 设置为 NULL |

**内存状态**：
```c
// 移动前
avframe.data[0] = NULL;
sw_frame->data[0] = 0x12345678;  // 1MB CPU buffer

// 移动后
avframe.data[0] = 0x12345678;  // 接管所有权
sw_frame->data[0] = NULL;       // 清空指针

// av_frame_free(sw_frame) 后
// sw_frame 结构被释放
// avframe 现在拥有 1MB buffer
// 函数返回后，FFmpeg 会自动释放 avframe 的 buffers
// → 无内存泄漏，无悬空指针
```

## 技术总结

### 内存管理对比

| 方案 | 代码 | 内存泄漏 | 悬空指针 | 崩溃 |
|------|------|---------|---------|------|
| **修改前** | `avframe = *sw_frame` | ✅ 1MB/帧 | ✅ 是 | ✅ 3-6 帧后 |
| **修改后** | `av_frame_move_ref()` | ❌ 无 | ❌ 无 | ❌ 稳定 |

### FFmpeg 内存管理最佳实践

| 场景 | 正确做法 | 错误做法 |
|------|---------|---------|
| 拷贝帧 | `av_frame_clone()` | `avframe = *src` |
| 移动帧 | `av_frame_move_ref()` | `avframe = *src` + `av_free()` |
| 释放帧 | `av_frame_free()` | `av_free()` |
| 清空帧 | `av_frame_unref()` | `memset()` |

## 🔍 技术细节

### 环境变量覆盖机制

**Dockerfile ENV**:
```dockerfile
ENV LDFLAGS="-L/usr/lib/aarch64-linux-gnu ..."  # Dockerfile 中设置
```

**脚本中的 export**:
```bash
export LDFLAGS="-L/opt/rk3588-sysroot/usr/lib/aarch64-linux-gnu ..."  # Line 460
```

**优先级**: `export` > `ENV`

**原因**:
- `ENV` 设置的是容器启动时的默认值
- `export` 在当前 shell 中覆盖默认值
- 子进程（configure, make）继承当前 shell 的环境变量

### 符号链接的必要性

**问题**:
```bash
# 容器中存在：
/opt/rk3588-sysroot/usr/lib/aarch64-linux-gnu/libx264.so.164

# 链接器需要：
/opt/rk3588-sysroot/usr/lib/aarch64-linux-gnu/libx264.so
```

**解决**: Fix 100 自动创建符号链接
```bash
ln -sf libx264.so.164 libx264.so
```

**时机**: 在复制 sysroot 后，configure 前（Line 311-337）

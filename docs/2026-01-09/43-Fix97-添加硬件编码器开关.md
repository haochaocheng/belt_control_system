# Fix 97: 添加硬件编码器开关支持

**日期**: 2026-01-09 17:30
**问题**: 用户希望在 SIP 界面选择硬件/软件编码器
**状态**: ✅ **已实现 - 通过环境变量控制**

---

## 🎯 用户需求

### 背景

- ✅ **软件编码器 (libx264)**：当前使用，稳定可靠
- ⚠️ **硬件编码器 (h264_rkmpp)**：性能更好，但被 Fix 53 禁用（MPP Issue #157 冲突）

### 需求

1. **不修改软件编码器代码**（保持稳定性）
2. 添加硬件编码器开关（通过 if 判断）
3. 后续在 SIP 界面添加选择选项

---

## 🔍 现有代码分析

### 编码器选择逻辑（ffmpeg_vid_codecs.c Line 1159-1258）

```c
// Line 1159: 硬件编码器（被禁用）
if (hw_encoder_name && 0) {  // ❌ 强制禁用
    /* RKMPP encoder registration DISABLED */
    // ... 硬件编码器注册代码
}
// Line 1242: 软件编码器（当前使用）
else if (hw_encoder_name) {
    // 回退到 libx264 软件编码器
    c = avcodec_find_encoder(codec_id);  // 查找 libx264
    if (c) {
        init_codec(c, PJ_TRUE, PJ_FALSE);  // 注册软件编码器
    }
}
// Line 1252: 其他编解码器
else {
    c = avcodec_find_encoder(codec_id);
}
```

### 问题

- Line 1159: `if (hw_encoder_name && 0)` - `&& 0` 强制禁用硬件编码器
- 无法动态切换，需要修改源码重新编译

---

## ✅ 解决方案：Fix 97

### 核心思路

通过**环境变量** `USE_HARDWARE_ENCODER` 控制硬件编码器启用/禁用。

### 修改内容

**文件**: `cross-compile/src/pjproject-2.16/pjmedia/src/pjmedia-codec/ffmpeg_vid_codecs.c`

#### 修改 1: 添加环境变量检查（Line 1165-1166）

```c
// ✅ [FIX 97] 通过环境变量控制硬件编码器
const char* use_hw_encoder = getenv("USE_HARDWARE_ENCODER");
if (hw_encoder_name && use_hw_encoder && atoi(use_hw_encoder) == 1) {
    /* RKMPP encoder registration ENABLED by environment variable */
    PJ_LOG(1,(THIS_FILE, "✅ [FIX 97] Hardware encoder ENABLED via USE_HARDWARE_ENCODER=1"));
    PJ_LOG(1,(THIS_FILE, "   Using hardware encoder: %s", hw_encoder_name));
    // ... 原有硬件编码器注册代码
}
```

#### 修改 2: 更新软件编码器日志（Line 1249-1256）

```c
} else if (hw_encoder_name) {
    // ✅ [FIX 97] 硬件编码器未启用（USE_HARDWARE_ENCODER=0 或未设置）
    // 回退到默认 H.264 软件编码器（libx264）
    PJ_LOG(1,(THIS_FILE, "⚠️ [FIX 97] Hardware encoder DISABLED (USE_HARDWARE_ENCODER not set or =0)"));
    PJ_LOG(1,(THIS_FILE, "   Falling back to software H.264 encoder"));
    c = avcodec_find_encoder(codec_id);
    if (c) {
        PJ_LOG(1,(THIS_FILE, "✅ [FIX 97] Found software encoder: %s", c->name));
        init_codec(c, PJ_TRUE, PJ_FALSE);  // ← 保持不变，不修改软件编码器代码
    }
}
```

## ⚠️ 注意事项

### 硬件编码器限制

**MPP Issue #157**: RKMPP 编码器和解码器同时使用可能导致冲突。

**当前策略**:
- ✅ **硬件解码器**：h264_rkmpp（接收对方视频）
- ⚠️ **硬件编码器**：h264_rkmpp（发送本地视频）**可能不稳定**

**症状**:
- 程序崩溃（SIGSEGV）
- `hw_frames_ctx` 共享冲突
- 视频花屏或黑屏

**解决方案**:
- 默认使用软件编码器（libx264）
- 只在确认硬件编码器稳定时启用

### 软件编码器性能

| 指标 | 软件编码器 (libx264) | 硬件编码器 (h264_rkmpp) |
|------|---------------------|------------------------|
| **CPU 使用率** | ~60-80% | ~5-10% |
| **编码延迟** | ~30-50ms | ~5-10ms |
| **视频质量** | ✅ 优秀 | ✅ 优秀 |
| **稳定性** | ✅ 非常稳定 | ⚠️ 可能不稳定 |
| **推荐使用** | ✅ 默认 | 🔸 可选 |


### BADBITSTREAM 错误位置

```
00:17:22.496     vstdec0x7f70010d70  codec decode() error: Bad or corrupted bitstream (PJMEDIA_CODEC_EBADBITSTREAM)
```

**这个错误的根因**：
- 旧代码：`avcodec_receive_frame()` 返回 -11 (EAGAIN)
- 旧代码：没有 Fix 91 的 EAGAIN 处理
- 旧代码：直接返回 PJMEDIA_CODEC_EBADBITSTREAM
- 结果：上层认为解码失败，可能导致资源清理异常

### Fix 91 的修复

```c
/* ✅ 2026-01-09 09:24 [修复 91] 添加 EAGAIN 错误处理 */
if (err == 0) {
    got_picture = PJ_TRUE;
} else if (err == AVERROR(EAGAIN) || err == AVERROR_EOF) {
    PJ_LOG(3,(THIS_FILE, "🔍 [FIX 91] Handle EAGAIN/EOF: err=%d, clearing error", err));
    err = 0;                    // 清除错误
    got_picture = PJ_FALSE;     // 标记没有帧，继续接收数据
}
```

**作用**：
- EAGAIN 不再被当作错误
- 继续接收数据直到有完整的帧
- 避免 BADBITSTREAM 错误

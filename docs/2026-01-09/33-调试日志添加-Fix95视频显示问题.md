## 🔍 调试方案

### 日志追踪链路

```
1. RemoteVideoManager::onCallConnected()

   → 📹 [DEBUG Fix 95] m_videoSink is valid

   → 📹 [VIDEO SINK ITEM] Received frame

4. VideoSinkItem::updatePaintNode()
   → 📹 [PAINT NODE] Rendering frame
```

### 可能的故障点诊断

#### 情况 1：m_videoSink 为空

**日志特征**：
```
✅ 📹 [DEBUG Fix 95] m_videoSink pointer: 0x0
❌ [ERROR Fix 95] m_videoSink is nullptr!
```

**根因**: QVideoSink 未正确连接到 RemoteVideoManager

**解决**: 检查 SipPhoneManager 或 VideoCallManager 中的连接代码

---

#### 情况 2：setVideoFrame() 调用但无信号

**日志特征**：
```
✅ 📹 [DISPLAY FRAME] Presenting to QVideoSink
❌ 没有 [VIDEO SINK ITEM] 日志
```

**根因**: QVideoSink → VideoSinkItem 信号连接断开

**解决**: 检查 VideoSinkItem::setSink() 连接

---

#### 情况 3：信号触发但帧无效

**日志特征**：
```
✅ 📹 [VIDEO SINK ITEM] Received frame ... valid: false
❌ [ERROR Fix 95] VideoSinkItem received invalid frame!
```

**根因**: QVideoFrame 传递过程中失效

**解决**: 检查异步线程 → 主线程的帧传递

---

#### 情况 4：帧接收但未渲染

**日志特征**：
```
✅ 📹 [VIDEO SINK ITEM] Received frame
❌ 没有 [PAINT NODE] 日志
```

**根因**: Qt Scene Graph 未触发渲染，可能是：
- ItemHasContents 未启用
- update() 未调用
- 窗口不可见

**解决**: 检查 QML 窗口属性（visible、width、height）

---

#### 情况 5：渲染调用但图像为空

**日志特征**：
```
✅ 📹 [PAINT NODE] Rendering frame
⚠️ [PAINT NODE] No image yet, returning nullptr
```

**根因**: m_currentImage 未正确设置

**解决**: 检查 toImage() 和格式转换

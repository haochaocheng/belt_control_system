# Fix 97.2 关键修复：FFmpeg 6.0 库路径更正

**日期**: 2026-01-09 21:30
**问题**: 视频电话失败，FFmpeg H264 编解码器缺失
**根本原因**: build-ubuntu24-apt.ps1 中 FFmpeg 库路径配置过期，指向 FFmpeg 4.x 时代的空目录
**状态**: ✅ **已修复 - 更正为 FFmpeg 6.0 真身路径**

---

## 🔍 问题发现

### 用户反馈

视频电话测试失败（voip.md）：
```
⚠️ WARNING: Hardware encoder 'h264_rkmpp' not found - video encoding DISABLED
```

INVITE SDP 只包含 H263-1998，对方 PortSIP 拒绝视频流 → **视频电话失败**。

### 诊断 2: FFmpeg 库路径配置过期

**build-ubuntu24-apt.ps1 Line 1064** 配置的路径：

## ⚠️ 重要教训

### 1. 路径配置必须跟随版本升级

**问题**: FFmpeg 从 4.x 升级到 6.0 后，库路径变更了，但 build-ubuntu24-apt.ps1 没有同步更新。

**教训**:
- ✅ 大版本升级时，检查所有路径配置是否需要更新
- ✅ 路径配置应该有版本标记（注释中说明是 FFmpeg 4.x 还是 6.0）
- ✅ 定期验证路径是否存在（`Test-Path` 失败应该报错而不是静默跳过）

**改进建议**:
```powershell
# ✅ 显式版本标记
$FFmpegVersion = "6.0"
$FFmpegHwLibPath = "$ProjectRoot\docker\rk3588\ffmpeg60-libs\opt\ffmpeg-rockchip\lib"  # FFmpeg 6.0

# ✅ 路径验证
if (-not (Test-Path $FFmpegHwLibPath)) {
    Write-Host "  ❌ ERROR: FFmpeg $FFmpegVersion libraries not found at: $FFmpegHwLibPath" -ForegroundColor Red
    Write-Host "  Please verify FFmpeg 6.0 is properly extracted." -ForegroundColor Yellow
    exit 1
}
```

---

### 2. 静默失败是危险的

**问题**: `if (Test-Path $FFmpegHwLibPath)` 失败后，整个 FFmpeg 库复制块被静默跳过，没有任何错误提示。

**教训**:
- ✅ 关键路径检查失败应该**立即报错退出**，不应该静默跳过
- ✅ 构建日志应该明确显示哪些库被复制，哪些被跳过

**改进建议**:
```powershell
if (Test-Path $FFmpegHwLibPath) {
    # 复制逻辑...
} else {
    # ❌ 不要静默跳过，而是报错退出
    Write-Host "  ❌ ERROR: FFmpeg libraries not found!" -ForegroundColor Red
    Write-Host "  Expected path: $FFmpegHwLibPath" -ForegroundColor Yellow
    exit 1
}
```

---

### 3. FFmpeg 6.0 包含 libpostproc

**问题**: FFmpeg 6.0 包含 `libpostproc.so.57.3.100`，之前的复制逻辑没有包括这个库。

**教训**:
- ✅ FFmpeg 版本升级时，检查库文件列表是否变化
- ✅ 使用通配符模式复制所有库（`libpostproc*.so.*`）

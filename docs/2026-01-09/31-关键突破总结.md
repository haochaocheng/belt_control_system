## 🔍 Fix 94：彻底解决崩溃问题

### 问题：程序在日志打印时崩溃

**Core Dump 证据** (2026-01-09 13:17):
```
#0  __strlen_generic()           ← strlen() 崩溃
#1  __printf_buffer()             ← printf 处理
#2  __vsnprintf_internal()        ← vsnprintf
#3  ___vsnprintf_chk()            ← 安全检查
#4  pj_log()                      ← PJSIP 日志
#5  pj_log_3()                    ← PJSIP 日志
#6  ffmpeg_codec_decode_whole()  ← Decoder 函数（崩溃来源）

寄存器: x21 = 0xffffffffb00f36f8 (无效地址)
```

**根本原因**: `PJ_LOG()` 传递了**无效字符串指针**给 `strlen()`

### 解决方案

**Fix 93**: 注释掉 Encoder 详细日志
- 效果: 运行时间延长 (1.5秒 → 1.8秒)
- 但仍崩溃: 问题迁移到 Decoder

**Fix 94**: 注释掉 Decoder 详细日志
- 禁用位置:
  1. `[CODE-VERSION]` 日志 (Line 3311-3326)
  2. `[DEBUG-VERSION]` 日志 (Line 3385-3389)
  3. `[FIX 91]` EAGAIN 日志 (Line 3482-3483)
  4. 所有 `av_get_pix_fmt_name()` 日志 (5 处)
- **效果**: **彻底解决崩溃** ✅

### 关键发现

**日志打印是导致崩溃的根本原因**：
- 不是内存管理问题 (Fix 92 已解决)
- 不是 EAGAIN 处理问题 (Fix 91 已解决)
- 是**日志格式字符串中的空指针或无效指针**

**为什么 `av_get_pix_fmt_name()` 危险**:
```c
PJ_LOG(3, (THIS_FILE, "Format: %s",
    av_get_pix_fmt_name(format) ? av_get_pix_fmt_name(format) : "unknown"));
```
- `av_get_pix_fmt_name()` 被调用**两次**
- 第二次调用时可能返回不同结果
- 如果返回 NULL，三元运算符检查失效 → 崩溃

## 🔍 Fix 95：解决视频无法显示问题

### 问题：对方视频窗口黑屏

**日志证据** (voip.md Line 1682-1685):
```
01:37:47.373  [FIX 90] Detected DRM_PRIME in FFmpeg 6.0+ branch
01:37:47.373     Original err=0, attempting format conversion...
01:37:47.373  [FIX 76 FORMAT] Decoded frame format: 23 (NV12)  ← ✅ 转换成功
01:37:47.373  codec decode() error: Not found (PJ_ENOTFOUND)   ← ❌ 但返回错误
```

### 根本原因分析

**格式转换不完整**:

| 变量 | Fix 90 前 | Fix 90 后 | 应该是 |
|------|-----------|-----------|--------|
| `avframe.format` | 179 (DRM_PRIME) | **23 (NV12)** ✅ | 23 |
| `ff->dec_ctx->pix_fmt` | 179 (DRM_PRIME) | **179 (DRM_PRIME)** ❌ | **23** |

**错误链**:
1. Fix 90 成功转换 `avframe.format`: 179 → 23
2. **但忘记更新 `ff->dec_ctx->pix_fmt`**，仍然是 179
3. `check_decode_result()` 检测到格式变化: `179 != 23`
4. 尝试将 DRM_PRIME (179) 转换为 PJMEDIA 格式
5. **PJMEDIA 不支持 DRM_PRIME** → 返回 `PJ_ENOTFOUND`
6. 解码失败 → 视频无法显示

### 解决方案 - 一行代码

```c
ff->dec_ctx->pix_fmt = avframe.format;  // 更新为 NV12
```

**修改位置**:
1. Fix 90 分支 (Line 3470) - FFmpeg 6.0+
2. Fix 89 分支 (Line 3574) - FFmpeg 52.72+

**效果**:
- ✅ 解码器上下文格式同步更新为 NV12
- ✅ `check_decode_result()` 不再返回错误
- ✅ 视频帧正常传递到 Qt/SDL
- ✅ **对方视频正常显示** 📹

## 🚀 使用流程

### 1. 启动 EMQX Broker

```powershell
docker start emqx
```

### 2. 启动模拟器（二选一）

**方案A：Python 自动模拟器**
```powershell
.\scripts\2026-02-09\01-start-mqtt-simulator.ps1
```

**方案B：MQTTX 可视化工具**
1. 下载安装 MQTTX
2. 导入配置文件 `config/mqttx_8modules_config.json`
3. 启用脚本自动发送数据

### 3. 启动主机应用

1. 编译运行主机应用
2. 打开设备信息对话框
3. 选择 "MQTT" 类别
4. 切换到 "自动控制" Tab
5. 观察数据实时更新

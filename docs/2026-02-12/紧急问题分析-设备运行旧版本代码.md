## 技术要点

### 为什么旧版本会有问题？

**旧版本的 Canvas**：
```qml
Canvas {
    onPaint: {
        var ctx = getContext("2d")  // ❌ 引擎可能未就绪
        // ... 绘图代码
    }
    // ❌ 没有 Timer，立即绘制
}
```

**新版本的 Canvas**：
```qml
Canvas {
    id: myCanvas
    onPaint: {
        if (!available) return      // ✅ 检查引擎是否可用
        if (width <= 0 || height <= 0) return  // ✅ 检查尺寸
        var ctx = getContext("2d")
        if (!ctx) return            // ✅ 检查上下文
        // ... 绘图代码
    }
    Timer {                         // ✅ 延迟绘制
        interval: 1
        running: true
        repeat: false
        onTriggered: myCanvas.requestPaint()
    }
}
```

### Docker 镜像版本管理

**问题**：
- Docker 镜像一旦构建，内容就固定了
- 代码修改后必须重新构建镜像
- 旧镜像不会自动更新

**解决**：
- 每次代码修改后重新编译
- 使用 `build-ubuntu24-apt.ps1` 自动构建新镜像
- 部署时会自动替换旧镜像

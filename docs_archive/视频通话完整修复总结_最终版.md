**症状**:
- 视频通话建立成功
- 接收视频正常（RX: 3.2K packets, 3.42MB）
- **发送视频为 0（TX: 0 packets, 0B）**
- 对方客户端看不到本机视频

**根本原因**:
```cpp
// risipaccountconfiguration.cpp:346 (修复前)

```

这导致 PJSIP 在 `pjsua_vid.c:1313-1318` 中暂停视频编码器：
```c
if (!acc->cfg.vid_out_auto_transmit && call_med->strm.v.stream) {
    status = pjmedia_vid_stream_pause(call_med->strm.v.stream,
                                      PJMEDIA_DIR_ENCODING);  ← 暂停编码!
}
```

**日志证据**:
```
15:18:19.604 vstenc00000247ab989aa8 .......Encoder stream paused  ← 编码器被暂停
```

**修复方案**:
```cpp
// risipaccountconfiguration.cpp:346 (修复后)
m_data->accountConfig.videoConfig.autoTransmitOutgoing = true;  // ✅ 启用视频发送
```

**预期结果**:
- 视频编码器不再被暂停
- 本地摄像头视频正常发送

## ⚠️ 剩余问题：视频窗口显示

### 问题描述

虽然 SDL2 渲染器工作正常（从日志可以确认），但：
- ❌ 用户在屏幕上**找不到 SDL 窗口**
- ❌ SDL 窗口没有嵌入到 Qt 应用程序中
- ❌ 视频可能在独立窗口中显示，但被隐藏或在屏幕外

### 原因分析

PJSIP 的 SDL 渲染器创建**独立的原生窗口**（不是 Qt 组件），不会自动嵌入到 Qt 应用程序界面中。

从日志可以看到：
```
15:18:19.398 vid_port.c .........Opening device SDL renderer [SDL] for render
15:18:19.562 vid_port.c !.........Device SDL renderer [SDL] opened
```

SDL 设备成功打开，但窗口可能：
1. 在后台或被其他窗口遮挡
2. 创建在屏幕外或第二显示器上
3. 被 `window_hide` 参数隐藏
4. 窗口大小为 0 或最小化

### 临时排查方法

1. **按 Alt+Tab** 切换窗口，查找 "pjmedia-SDL video" 窗口
2. **检查任务栏**，是否有额外的窗口图标
3. **检查所有显示器**（如果有多个显示器）
4. **使用任务管理器**，查看是否有额外的窗口进程

### 长期解决方案：Qt 视频渲染器（必须实现）

要在 Qt 应用程序中正确显示视频，需要实现**自定义 Qt 视频渲染器**，替代 SDL 独立窗口。

#### 实现步骤

**步骤 1: 创建 Qt 视频渲染器类**

创建 `QtVideoRenderer.h` 和 `QtVideoRenderer.cpp`，继承自 `QQuickItem`：

```cpp
class QtVideoRenderer : public QQuickItem
{
    Q_OBJECT
public:
    QtVideoRenderer(QQuickItem *parent = nullptr);

    // 接收 PJSIP 视频帧
    void renderFrame(const pjmedia_frame *frame);

protected:
    QSGNode *updatePaintNode(QSGNode *oldNode, UpdatePaintNodeData *) override;

private:
    QImage m_currentFrame;
    QMutex m_frameMutex;
};
```

**步骤 2: 注册自定义视频设备到 PJSIP**

在 `VideoCallManager` 中注册自定义视频设备工厂：

```cpp
// 创建自定义视频设备工厂
pjmedia_vid_dev_factory* qt_renderer_factory = create_qt_renderer_factory();

// 注册到 PJMEDIA
pjmedia_vid_register_factory(NULL, qt_renderer_factory);
```

**步骤 3: 实现视频帧回调**

实现 PJSIP 视频端口回调，将视频帧传递给 Qt 渲染器：

```cpp
static pj_status_t qt_renderer_put_frame(pjmedia_vid_port *vp,
                                         const pjmedia_frame *frame)
{
    QtVideoRenderer *renderer = (QtVideoRenderer*)user_data;
    renderer->renderFrame(frame);
    return PJ_SUCCESS;
}
```

**步骤 4: 在 QML 中使用**

在 `VideoCallWindow.qml` 中使用自定义渲染器：

```qml
// 远程视频
QtVideoRenderer {
    id: remoteVideoRenderer
    anchors.fill: parent
    objectName: "remoteVideoRenderer"
}

// 本地视频预览
QtVideoRenderer {
    id: localVideoRenderer
    width: 240
    height: 180
    objectName: "localVideoRenderer"
}
```

**步骤 5: 连接 PJSIP 和 Qt 渲染器**

在 `VideoCallManager` 中，创建视频通话时使用 Qt 渲染器：

```cpp
// 设置使用自定义 Qt 渲染器（而非 SDL）
acc_cfg.videoConfig.defaultRenderDevice = qt_renderer_device_id;

// 连接视频流到 Qt 渲染器
connect_video_stream_to_qt_renderer(call_id, remoteVideoRenderer);
```

#### 优点

- ✅ 视频直接显示在 Qt 应用程序界面中
- ✅ 完全控制视频窗口的位置、大小和样式
- ✅ 可以添加 Qt 特效和动画
- ✅ 与应用程序 UI 完美集成
- ✅ 跨平台一致的显示效果

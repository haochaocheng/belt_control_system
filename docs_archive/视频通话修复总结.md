# 视频通话功能修复总结

## 🎯 问题诊断

### 初始错误
```
Unable to find default video device (PJMEDIA_EVID_NODEFDEV)
Creating video window: type=stream, cap_id=0, rend_id=-2
```

### 根本原因
系统只有**捕获设备**（摄像头），缺少**渲染设备**（用于显示视频）：
- 设备 0：Integrated Webcam（Dir=1，仅捕获）
- ❌ 缺失：渲染设备（Dir=2）

## 🔧 技术细节

### 为什么需要两种设备？

PJSIP 视频子系统架构：
```
捕获设备 (Capture)        渲染设备 (Render)
    ↓                          ↓
DirectShow                   SDL2
    ↓                          ↓
Integrated Webcam    →  视频通话窗口显示
```

### 两个 Bug 的关系

```
Bug 1: cap_id=-1 (源码)
  ↓
无法找到捕获设备
  ↓
❌ ERROR: Unable to find capture device

Bug 2: 缺失渲染设备 (配置)
  ↓
无法找到渲染设备
  ↓
❌ ERROR: Unable to find default video device
```

**两个 Bug 都必须修复**，视频通话才能正常工作！

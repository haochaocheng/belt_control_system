## 最终解决方案

### 方案架构

```
Qt Multimedia (QCamera)
    ↓
QVideoSink (视频帧输出)
    ↓
VideoSinkItem (自定义 QQuickItem)
    ↓
Qt Quick Scene Graph (QSGNode 纹理渲染)
    ↓
QML 界面 (完全嵌入显示)
```

### 核心实现：VideoSinkItem

**新增文件：**
- `src/sip_phone/VideoSinkItem.h`
- `src/sip_phone/VideoSinkItem.cpp`

**功能：**
- 继承 `QQuickItem` - Qt Quick 的基础可视化组件
- 接收来自 `QVideoSink` 的视频帧
- 使用 Qt Quick Scene Graph API 渲染视频纹理
- 完全集成在 QML 中，无需独立窗口

**关键代码：**

```cpp
class VideoSinkItem : public QQuickItem {
    Q_OBJECT
    Q_PROPERTY(QVideoSink* sink READ sink WRITE setSink NOTIFY sinkChanged)

protected:
    // 重写渲染节点 - 使用 Scene Graph 渲染视频纹理
    QSGNode* updatePaintNode(QSGNode *oldNode, UpdatePaintNodeData*) override;

private slots:
    // 接收来自 QVideoSink 的视频帧
    void onVideoFrameChanged(const QVideoFrame &frame);
};
```

**渲染流程：**
1. `QVideoSink` 发出 `videoFrameChanged` 信号
2. `VideoSinkItem` 接收 `QVideoFrame`
3. 将视频帧转换为 `QImage` (Format_RGB32)
4. 使用 `QSGSimpleTextureNode` 创建纹理
5. Qt Quick Scene Graph 渲染到屏幕

## 技术对比

### Qt Multimedia VideoOutput vs VideoSinkItem

**Qt VideoOutput（不可用）：**

- ❌ 无法直接使用

**自定义 VideoSinkItem（本方案）：**
- ✅ 完全控制渲染过程
- ✅ 使用 Qt Quick Scene Graph
- ✅ 与 QML 完美集成
- ✅ 可自定义任意功能

### PJSIP SDL vs Qt Multimedia

**PJSIP SDL 方案：**
- 优点：与 PJSIP 视频通话统一
- 缺点：SDL 窗口无法嵌入

**Qt Multimedia 方案（本方案）：**
- 优点：完全集成在 QML 界面
- 缺点：仅用于本机预览（视频通话仍用 PJSIP）

## 问题排查

### 问题 1：视频不显示（黑屏）
**可能原因：**
- 摄像头未启动
- QVideoSink 未连接
- 摄像头被其他程序占用

**排查步骤：**
```
1. 检查控制台是否有 "✅ Camera started"
2. 检查是否有 "✅ First video frame received"
3. 检查是否有摄像头权限
4. 关闭其他使用摄像头的程序
```

### 问题 2：摄像头找不到
**可能原因：**
- 系统无摄像头
- 摄像头驱动未安装

**解决方法：**
```
1. 检查设备管理器中的摄像头
2. 确保摄像头驱动正常
3. 查看控制台 "📹 Available cameras" 输出
```

### 问题 3：视频变形
**可能原因：**
- 视频比例计算错误

**解决方法：**
```
VideoSinkItem 已实现 PreserveAspectFit
如仍有问题，检查 updatePaintNode() 中的比例计算
```

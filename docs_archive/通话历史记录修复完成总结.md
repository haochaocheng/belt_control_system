## 已修复的问题

### ✅ 1. 通话时长缓存（最关键）

**问题**: 通话时长始终显示为 0

**原因**: Risip SDK 动态从 PJSIP 的 `connectDuration.msec` 获取时长，通话结束后 PJSIP 会话被销毁，`callDuration()` 返回 0

**解决方案**: 在通话结束时（CallDisconnected 和 Null 状态）缓存时长到 RisipCall 对象的动态属性

**修改位置**:
- [SipPhoneManager.cpp:1267-1277](src/sip_phone/SipPhoneManager.cpp#L1267-L1277) - CallDisconnected 分支
- [SipPhoneManager.cpp:1299-1309](src/sip_phone/SipPhoneManager.cpp#L1299-L1309) - Null 分支

**关键代码**:
```cpp
// ✅ CRITICAL: 在通话结束前缓存时长到 RisipCall 对象
if (d->currentCall) {
    long duration = d->currentCall->callDuration();
    if (duration > 0) {
        d->currentCall->setProperty("cachedDuration", QVariant::fromValue(duration));
        qDebug() << "✅ 通话结束，缓存时长:" << duration << "ms (" << (duration/1000) << "s)";
    }
}
```

### ✅ 2. 视频通话历史记录（保守修复）

**问题**: 视频通话不会出现在历史记录中

**原因**: 视频通话使用直接 PJSIP API (`pjsua_call_make_call`)，绕过了 Risip 的 `callPhone()` API

**解决方案**: 在视频通话创建成功后手动创建 RisipCall 对象并添加到历史记录

**修改位置**: [SipPhoneManager.cpp:1188-1222](src/sip_phone/SipPhoneManager.cpp#L1188-L1222)

**关键特点**:
- ✅ **不改变现有视频通话逻辑** - 保持 `pjsua_call_make_call` 不变
- ✅ **仅添加历史记录功能** - 手动创建 RisipCall 对象
- ✅ **设置动态属性标记** - `manualCallDirection`, `isVideoCall`, `manualTimestamp`

**关键代码**:
```cpp
// 创建 Buddy 对象
risip::RisipBuddy *buddy = new risip::RisipBuddy(this);
buddy->setAccount(d->currentAccount);
buddy->setContact(number);
buddy->setType(risip::RisipBuddy::Pstn);

// 创建 RisipCall 对象用于历史记录
risip::RisipCall *historyCall = new risip::RisipCall(this);
historyCall->setAccount(d->currentAccount);
historyCall->setBuddy(buddy);

// ⭐ 手动设置 callDirection 和时间戳
historyCall->setProperty("manualCallDirection", 0);  // 0 = Outgoing
historyCall->setProperty("isVideoCall", true);
QDateTime now = QDateTime::currentDateTime();
historyCall->setProperty("manualTimestamp", now);

// 添加到历史记录 Model
risip::RisipCallManager *callManager = risip::RisipCallManager::instance();
QString accountUri = d->currentAccount->configuration()->uri();
auto historyModel = callManager->historyCallModelForAccount(accountUri);
if (historyModel) {
    auto *model = qobject_cast<risip::RisipCallHistoryModel*>(historyModel);
    if (model) {
        model->addCallRecord(historyCall);
        qDebug() << "✅ 视频通话记录已添加到历史";
    }
}
```

## 待修复的问题

### ❓ callDirection = 2 (Unknown) 问题

**现状**: 用户测试显示语音通话 `callDirection = 2`

**Risip SDK 正确行为**:
- `callPhone()` → `callBuddy()` → `call()` → 设置 `callDirection = 0` (Outgoing)
- `initiateIncomingCall()` → 设置 `callDirection = 1` (Incoming)

**可能原因**:
1. 用户之前测试的是视频通话（现在已修复）
2. 有特殊的代码路径导致 `call()` 方法未被调用
3. Risip SDK 本身的 bug

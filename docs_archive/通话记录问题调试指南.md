## 剩余问题分析

### 问题 A: 时长不显示 ❌

**现象**:
- 时间戳显示正常（说明 role binding 工作正常）
- 时长字段为空或显示为 "--:--"（说明数据本身可能是 0）

**可能原因**:

1. **Risip SDK 没有正确计算时长**:
   - RisipCall 对象可能没有记录通话开始时间
   - 通话结束时没有计算 duration

2. **通话记录保存时 duration 为 0**:
   - RisipCallHistoryModel 保存记录时 duration 字段可能为 0
   - 需要检查 Risip SDK 的通话状态处理逻辑

3. **数据类型不匹配**:
   - duration 字段可能是 QString 而不是 int
   - QML formatDuration() 函数期望 int 类型

**调试方法**:

查看控制台输出中的调试信息：
```
📝 Call history item #0:
   callContact: <号码> (type: string)
   callDirection: <0 或 1> (type: number)
   callDuration: <时长> (type: number)  ← 查看这个值
   callTimestamp: <时间戳> (type: object)
```

如果 `callDuration` 显示为 0 或 undefined，说明问题在 Risip SDK 的数据保存逻辑。

### 问题 B: 拨出记录没有 ❌

**现象**:
- 对方拨打本机：有记录 ✅ (incoming calls)
- 本机拨打对方：没有记录 ❌ (outgoing calls)

**可能原因**:

1. **Risip SDK 的 call state handler 只处理 incoming calls**:
   - 可能只在 `PJSIP_INV_STATE_DISCONNECTED` 状态下保存 incoming calls
   - Outgoing calls 可能需要不同的状态码或处理逻辑

2. **Call direction 判断错误**:
   - Risip SDK 可能没有正确识别 outgoing calls
   - CallDirection 字段可能设置错误

3. **Account URI 不匹配**:
   - Outgoing calls 可能使用了不同的 account URI
   - RisipCallHistoryModel 按 account URI 过滤记录，URI 不匹配则不显示

4. **通话未正常结束**:
   - Outgoing calls 可能没有触发正确的 "call ended" 状态
   - 只有正常结束的通话才会保存记录

**调试方法**:

1. 查看通话结束时的日志：
   ```
   # 搜索关键词：
   - "Call state changed"
   - "Saving call history"
   - "Call ended"
   - "DISCONNECTED"
   ```

2. 比较 incoming 和 outgoing calls 的状态变化：
   - Incoming: 状态序列应该是 `EARLY → CONNECTING → CONFIRMED → DISCONNECTED`
   - Outgoing: 检查是否有相同的状态序列

3. 检查 RisipCall 的 direction 字段：
   - 添加日志输出 callDirection 的值
   - 确认 outgoing calls 的 direction 是否正确设置为 0

## 临时解决方案

如果 Risip SDK 的源码无法修改，我们可以在 SipPhoneManager 中：

### 方案 1: 手动保存通话记录

在 `onCallStateChanged` 回调中添加逻辑：

```cpp
// SipPhoneManager.cpp
static void onCallStateChanged(int call_id, pjsip_inv_state state, const char* state_text)
{
    if (state == PJSIP_INV_STATE_DISCONNECTED) {
        // 获取通话信息
        QString remoteNumber = getRemoteNumber(call_id);
        int callDirection = getCallDirection(call_id);  // 0=outgoing, 1=incoming
        int callDuration = getCallDuration(call_id);
        QDateTime timestamp = QDateTime::currentDateTime();

        // 手动添加到 call history model
        RisipCallHistoryModel *model = getCallHistoryModel();
        if (model) {
            model->addRecord(remoteNumber, callDirection, callDuration, timestamp);
        }
    }
}
```

### 方案 2: 使用自定义通话记录模型

创建自己的 CallHistoryModel，不依赖 Risip SDK：

```cpp
// CustomCallHistoryModel.h
class CustomCallHistoryModel : public QAbstractListModel {
    Q_OBJECT
public:
    void addCallRecord(QString contact, int direction, int duration, QDateTime timestamp);
    // ...
};
```

然后在 SipPhoneManager 中使用这个自定义模型。

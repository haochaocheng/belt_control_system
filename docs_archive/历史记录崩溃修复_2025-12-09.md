# 历史记录崩溃问题修复

## 日期
2025-12-09 15:10

## 问题描述

**症状**: 视频通话结束后，点击"历史记录"页面，程序崩溃

**错误信息**:
```
pjsua_call_get_info(id, &pj_ci) error: INVITE session already terminated (PJSIP_ESESSIONTERMINATED)
Qt has caught an exception thrown from an event handler
UNKNOWN EXCEPTION CAUGHT!
```

## 根本原因

### 原因 1: RisipCall::callDuration() 访问已销毁的会话

**问题代码** ([src/risip/core/risipcall.cpp:254](src/risip/core/risipcall.cpp#L254)):
```cpp
long RisipCall::callDuration() const
{
    if(!m_data->pjsipCall)
        return 0.0;

    return m_data->pjsipCall->getInfo().connectDuration.msec;  // ❌ 通话结束后会话已销毁
}
```

**时序问题**:
1. 用户挂断通话 → PJSIP 会话被销毁
2. 用户点击"历史记录" → Model 需要显示通话记录
3. Model 调用 `callDuration()` → 尝试访问已销毁的 PJSIP 会话
4. 抛出异常 → Qt 捕获但不允许异常传播 → **程序崩溃**

### 原因 2: hangupCall() 顺序错误

**问题代码** ([src/sip_phone/SipPhoneManager.cpp:1486-1487](src/sip_phone/SipPhoneManager.cpp#L1486-L1487)):
```cpp
// Hangup the call
d->currentCall->hangup();        // ← PJSIP 会话立即销毁
d->currentCall = nullptr;        // ← currentCall 置空
```

**后果**:
- `hangup()` 会立即销毁 PJSIP 会话
- 之后尝试缓存时长已经太晚（会话已不存在）
- `handleCallStatusChange()` 回调被触发时，`d->currentCall` 已经是 nullptr
- 无法缓存通话时长

---

## 修复方案

### 修复 1: RisipCall::callDuration() 支持缓存读取

**文件**: [src/risip/core/risipcall.cpp:252-272](src/risip/core/risipcall.cpp#L252-L272)

```cpp
long RisipCall::callDuration() const
{
    // ✅ CRITICAL FIX: Check cached duration first (set when call ends)
    // This prevents crash when accessing destroyed PJSIP session
    QVariant cachedDuration = this->property("cachedDuration");
    if (cachedDuration.isValid()) {
        return cachedDuration.toLongLong();
    }

    // If no cache, try to get real-time duration (only works during active call)
    if(!m_data->pjsipCall)
        return 0;

    try {
        return m_data->pjsipCall->getInfo().connectDuration.msec;
    } catch (...) {
        // ✅ Catch any exceptions if session is already destroyed
        qWarning() << "Failed to get call duration (session may be destroyed)";
        return 0;
    }
}
```

**关键改进**:
1. ✅ **优先读取缓存** - 通话结束后使用缓存值
2. ✅ **异常捕获** - 即使访问已销毁会话也不会崩溃
3. ✅ **向后兼容** - 活动通话仍然可以获取实时时长

### 修复 2: hangupCall() 在挂断前缓存时长

**文件**: [src/sip_phone/SipPhoneManager.cpp:1485-1496](src/sip_phone/SipPhoneManager.cpp#L1485-L1496)

```cpp
try {
    d->callTimer->stop();

    // ✅ CRITICAL FIX: Cache duration BEFORE hanging up
    // Otherwise, after hangup() the PJSIP session is destroyed and we can't get duration
    long duration = d->currentCall->callDuration();
    if (duration > 0) {
        d->currentCall->setProperty("cachedDuration", QVariant::fromValue(duration));
        qDebug() << "✅ Caching call duration before hangup:" << duration << "ms (" << (duration/1000) << "s)";
    } else {
        qDebug() << "⚠️ Call duration is 0, not caching";
    }

    // Hangup the call
    d->currentCall->hangup();
    d->currentCall = nullptr;
    ...
}
```

**关键改进**:
1. ✅ **在 hangup() 之前缓存** - 确保 PJSIP 会话仍然有效
2. ✅ **详细日志** - 便于调试和验证
3. ✅ **双重保护** - 结合 `callDuration()` 的修复，提供完整的防护

## 技术细节

### Qt 动态属性机制

```cpp
// 设置动态属性（在 QObject 派生类上）
object->setProperty("cachedDuration", QVariant::fromValue(14532));

// 读取动态属性
QVariant value = object->property("cachedDuration");
if (value.isValid()) {
    long duration = value.toLongLong();
}
```

**优点**:
- ✅ 不需要修改类定义
- ✅ 运行时灵活添加属性
- ✅ 可以存储任意 QVariant 类型
- ✅ 对象销毁时自动清理

### 异常安全编程

```cpp
try {
    return m_data->pjsipCall->getInfo().connectDuration.msec;
} catch (...) {
    qWarning() << "Failed to get call duration (session may be destroyed)";
    return 0;
}
```

**重要性**:
- Qt 不允许异常穿透事件循环
- 必须在 Qt 代码边界捕获所有异常
- PJSIP C++ 异常必须在调用点处理

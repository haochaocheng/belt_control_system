## 问题排查

如果计时器仍然不显示，检查以下项：

### 1. 检查状态文本

在日志中搜索：
```
📇 [CALL STATUS] Status text:
```

**正确输出**：
- 外呼视频：`视频通话中: XXX`（必须包含"通话中"）
- 外呼语音：`与 XXX 通话中`
- 来电：`通话中`

**错误输出**：
- ❌ `视频通话: XXX`（缺少"通话中"）

### 2. 检查计时器启动

在日志中搜索：
```
✅ [UI] Call timer started
```

如果没有这条日志，说明计时器未启动（更深层的问题）。

### 3. 检查 QML 绑定

如果日志正确但界面仍不显示，可能是 QML 绑定问题：
- 检查 `SipPhoneManager.callDuration` 属性
- 检查 `formatDuration()` 函数

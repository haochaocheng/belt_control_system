# 自定义铃声功能实现说明

**实现日期**: 2025-12-10
**功能概述**: 为 SIP 电话系统添加自定义铃声选择功能

---

## 功能特性

### 1. 自定义铃声选择
- ✅ 在设置页面添加"铃声设置"模块
- ✅ 支持从文件系统选择音频文件作为来电铃声
- ✅ 支持多种音频格式:WAV, MP3, OGG, M4A
- ✅ 自动复制选中的铃声文件到应用程序目录
- ✅ 保留原始文件扩展名(不强制转换为WAV)
- ✅ 铃声路径持久化保存(使用 QSettings)

### 2. 铃声管理
- ✅ 显示当前使用的铃声文件名
- ✅ 自动回退机制:
  1. 优先使用用户自定义铃声
  2. 如自定义铃声不存在,使用应用本地铃声
  3. 如本地铃声不存在,使用 Windows 系统默认铃声
- ✅ 实时更新:选择新铃声后立即生效,无需重启应用
- ✅ 智能文件释放:选择新铃声前先切换到系统铃声,避免文件占用

### 3. 用户界面
- ✅ 设置页面新增"铃声设置"模块
- ✅ 显示当前铃声文件名,实时更新
- ✅ "选择自定义铃声"按钮打开文件选择对话框
- ✅ 友好的提示信息(支持的格式、自动复制说明)

## 实现细节

### 1. C++ 后端实现

#### 新增方法 (SipPhoneManager)

**1.1 getRingtonePath()**
```cpp
QString SipPhoneManager::getRingtonePath()
```
- 功能:获取当前使用的铃声文件路径(带 file:/// 前缀)
- 返回:完整的文件 URL 路径
- 回退逻辑:
  - 优先:QSettings 中保存的自定义铃声路径
  - 次级:应用目录下的 `sounds/custom_ringtone.*` (任意扩展名)
  - 默认:`C:/Windows/Media/Ring01.wav` (Windows 系统铃声)

**1.2 getRingtoneFilename()**
```cpp
QString SipPhoneManager::getRingtoneFilename()
```
- 功能:获取当前铃声的显示名称(仅文件名,用于界面显示)
- 返回:文件名 + 标识(如 "custom_ringtone.mp3 (本地)" 或 "Ring01.wav (系统默认)")

**1.3 selectAndSetRingtone()**
```cpp
bool SipPhoneManager::selectAndSetRingtone()
```
- 功能:打开文件对话框选择音频文件,并设置为自定义铃声
- 操作流程:
  1. 打开 QFileDialog 让用户选择音频文件
  2. 创建应用的 `sounds` 目录(如不存在)
  3. **关键优化**:先触发信号切换到系统铃声,释放旧文件
  4. 删除所有旧的自定义铃声文件(支持多种扩展名)
  5. **保留原始扩展名**复制文件到 `sounds/custom_ringtone.<原始扩展名>`
  6. 保存路径到 QSettings
  7. 触发 `ringtonePathChanged` 信号通知 QML
- 返回:成功返回 true,取消或失败返回 false

**关键改进点**:
```cpp
// ✅ 保留原始文件扩展名
QFileInfo fileInfo(selectedFile);
QString extension = fileInfo.suffix().toLower();
QString destPath = soundsDir + "/custom_ringtone." + extension;

// ✅ 先切换到系统铃声,释放旧文件
settings.setValue("ringtone/customPath", "");
emit ringtonePathChanged("file:///C:/Windows/Media/Ring01.wav");
QThread::msleep(100);  // 等待QML切换完成

// ✅ 删除所有可能的旧铃声文件(不同扩展名)
QStringList possibleExtensions = {"wav", "mp3", "ogg", "m4a"};
for (const QString &ext : possibleExtensions) {
    QString oldFile = soundsDir + "/custom_ringtone." + ext;
    if (QFile::exists(oldFile)) {
        QFile::remove(oldFile);
    }
}
```

#### 新增信号

```cpp
void ringtonePathChanged(const QString &ringtonePath);
```
- 功能:铃声路径变化时触发,通知 QML 更新 MediaPlayer 的 source
- 参数:新的铃声路径(带 file:/// 前缀)

1. **MediaPlayer 源绑定**:
```qml
MediaPlayer {
    id: ringtone
    source: "file:///C:/Windows/Media/Ring01.wav"  // ✅ 使用固定系统铃声初始化
    loops: MediaPlayer.Infinite
    audioOutput: ringtoneOutput

    Component.onCompleted: {
        // ✅ 延迟加载自定义铃声
        ringtoneLoadTimer.start()
    }
}

// ✅ 延迟加载定时器
Timer {
    id: ringtoneLoadTimer
    interval: 100
    onTriggered: {
        try {
            var customPath = SipPhoneManager.getRingtonePath()
            if (customPath && customPath !== "") {
                ringtone.source = customPath
            }
        } catch (error) {
            console.log("⚠️ Failed to load custom ringtone")
        }
    }
}
```

2. **监听铃声路径变化**:
```qml
Connections {
    target: SipPhoneManager
    function onRingtonePathChanged(newPath) {
        console.log("🔔 [RINGTONE] Ringtone path changed:", newPath)
        if (newPath && newPath !== "") {
            ringtone.source = newPath
        }
    }
}
```

## 使用说明

### 设置自定义铃声

1. 打开 SIP 电话应用
2. 进入"设置"页面
3. 滚动到"铃声设置"模块
4. 点击"选择自定义铃声"按钮
5. 在弹出的文件选择对话框中选择音频文件(支持 WAV, MP3, OGG, M4A 格式)
6. 点击"打开"完成选择
7. 系统会自动:
   - 切换到系统铃声释放旧文件
   - 删除旧的自定义铃声
   - 复制新文件到应用目录(保留原始扩展名)
   - 保存设置
   - 立即切换到新铃声
8. "当前铃声"显示区域会实时更新为新选择的文件名

### 铃声存储位置

- **自定义铃声存储**: `{应用程序目录}/sounds/custom_ringtone.<扩展名>`
  - 示例: `custom_ringtone.mp3`, `custom_ringtone.wav`
- **配置文件存储**: QSettings (`BeltControl/SipPhone`)
  - 键: `ringtone/customPath`
  - 值: 自定义铃声的完整路径

### 铃声选择优先级

1. **第一优先级**: QSettings 中保存的自定义铃声路径
2. **第二优先级**: 应用本地铃声 (`sounds/custom_ringtone.*`)
3. **默认回退**: Windows 系统铃声 (`C:/Windows/Media/Ring01.wav`)

## 技术要点

### 1. 文件路径格式

- **C++ 路径**: 使用原生路径格式(如 `C:/path/to/file.mp3`)
- **QML MediaPlayer**: 需要 URL 格式(如 `file:///C:/path/to/file.mp3`)
- **转换**: 在 C++ 中使用 `QUrl::fromLocalFile()` 添加 `file:///` 前缀

### 2. QSettings 持久化

- **组织名**: "BeltControl"
- **应用名**: "SipPhone"
- **存储位置**: Windows 注册表
  ```
  HKEY_CURRENT_USER\Software\BeltControl\SipPhone
  ```

### 3. 信号-槽机制

- C++ 端通过 `emit ringtonePathChanged(newPath)` 触发信号
- QML 端通过 `Connections` 监听信号并更新 MediaPlayer 源和显示文本
- 实现实时更新,无需重启应用

### 4. 文件操作

- 使用 `QFile::copy()` 复制文件
- 使用 `QDir::mkpath()` 创建目录
- 使用 `QFile::exists()` 检查文件存在性
- 使用 `QFile::remove()` 删除旧文件
- 使用 `QFileInfo::suffix()` 获取文件扩展名

### 5. 文件释放机制

**问题**: 旧铃声文件可能被 MediaPlayer 占用,无法删除

**解决方案**:
```cpp
// 1. 临时清空设置
settings.setValue("ringtone/customPath", "");
settings.sync();

// 2. 触发信号切换到系统铃声
emit ringtonePathChanged("file:///C:/Windows/Media/Ring01.wav");

// 3. 等待 QML 切换完成
QThread::msleep(100);

// 4. 现在可以安全删除旧文件
QFile::remove(oldFile);
```

### 6. 延迟加载机制

**问题**: MediaPlayer 初始化时调用 C++ 方法可能导致 QML 组件加载失败

**解决方案**:
```qml
MediaPlayer {
    source: "file:///C:/Windows/Media/Ring01.wav"  // 固定路径初始化
    Component.onCompleted: {
        ringtoneLoadTimer.start()  // 延迟加载自定义铃声
    }
}

Timer {
    id: ringtoneLoadTimer
    interval: 100
    onTriggered: {
        try {
            ringtone.source = SipPhoneManager.getRingtonePath()
        } catch (error) {
            // 失败时保持系统铃声
        }
    }
}
```

## 已知限制

1. **文件格式兼容性**:
   - 虽然支持多种格式,但实际播放能力取决于系统的多媒体编解码器
   - 建议使用 WAV 或 MP3 格式以获得最佳兼容性

2. **文件大小**:
   - 建议铃声文件大小不超过 5MB
   - 铃声时长建议 2-5 秒(会循环播放)

3. **平台依赖**:
   - 当前实现针对 Windows 平台
   - 默认系统铃声路径为 `C:/Windows/Media/Ring01.wav`
   - 跨平台移植需要调整默认路径

4. **文件占用**:
   - 虽然实现了释放机制,但在极端情况下(如系统繁忙)可能仍然无法立即删除旧文件
   - 此时会有警告日志,但不影响新铃声的设置和播放

## 问题修复记录

### 问题 1: 拨号界面完全空白

**症状**: 添加 MediaPlayer 后,拨号界面不显示任何控件

**原因**: MediaPlayer 初始化时调用 `SipPhoneManager.getRingtonePath()` 导致组件加载失败

**解决方案**: 使用固定系统铃声路径初始化,通过 Timer 延迟加载自定义铃声

### 问题 2: 设置页面铃声名称不更新

**症状**: 选择新铃声后,"当前铃声"显示不更新

**原因**: `getRingtoneFilename()` 是 Q_INVOKABLE 方法,只在初始化时调用一次

**解决方案**: 添加 Connections 监听 `ringtonePathChanged` 信号,手动更新显示

### 问题 3: 文件复制失败

**症状**:
```
⚠️ [RINGTONE] Failed to remove old ringtone file
❌ [RINGTONE] Failed to copy ringtone file
```

**原因**: 旧铃声文件被 MediaPlayer 占用,无法删除

**解决方案**:
1. 在删除前先触发信号切换到系统铃声,释放文件
2. 保留原始文件扩展名,支持多种格式
3. 删除所有可能的旧铃声文件(不同扩展名)

# 通话历史记录问题根因与修复方案

## 日期
2025-12-09

## 问题总结

用户报告了通话历史记录的多个问题：

1. ❌ **拨出通话不显示** - 视频通话和部分语音通话没有记录
2. ❌ **callDirection = 2 (Unknown)** - 所有通话方向都显示为"未知"，应该是 0 (拨出) 或 1 (接入)
3. ❌ **callDuration = 0** - 所有通话时长都显示为 0，实际通话时长是 16秒 和 11秒
4. ✅ **callTimestamp 正常** - 时间显示正确
5. ⚠️ **callContact 格式不一致** - 导致 UI 列对齐错误

---

## 根因分析

### 问题 1: 视频通话绕过 Risip API

**文件**: [SipPhoneManager.cpp:1177](src/sip_phone/SipPhoneManager.cpp#L1177)

```cpp
// ❌ 视频通话使用直接 PJSIP API，不添加通话记录
status = pjsua_call_make_call(acc_id, &uri, &call_opt, NULL, NULL, &call_id);
```

**对比 - 语音通话**:
```cpp
// ✅ 语音通话使用 Risip API，自动添加记录
d->currentCall = callManager->callPhone(number);
```

**影响**:
- 视频通话完全不会出现在历史记录中
- 没有创建 RisipCall 对象，无法设置 callDirection

---

### 问题 2: callDirection 为何是 2 (Unknown)?

**Risip SDK 机制** (F:\0\risip-master\risip-master\src\risipsdk\risipcall.cpp):

```cpp
// 初始化时设置为 Unknown (2)
m_data->callDirection = Unknown;  // Line 59

// 拨出通话时应该设置为 Outgoing (0)
void RisipCall::call() {
    setCallDirection(RisipCall::Outgoing);  // Line 361
}

// 接入通话时应该设置为 Incoming (1)
void RisipCall::initiateIncomingCall() {
    setCallDirection(RisipCall::Incoming);  // Line 459
}
```

**可能原因**:
1. 视频通话根本没有创建 RisipCall 对象
2. 语音通话创建了 RisipCall，但 `call()` 方法没有被调用
3. 某个代码路径导致 callDirection 没有正确设置

**需要验证**: 用户测试的两个通话（都是语音）为什么 callDirection 都是 2？

---

### 问题 3: callDuration 为何是 0?

**Risip SDK 机制**:

```cpp
// 动态从 PJSIP 获取时长
long RisipCall::callDuration() const {
    if(!m_data->pjsipCall)
        return 0.0;  // ⚠️ 如果 pjsipCall 为 null，返回 0
    return m_data->pjsipCall->getInfo().connectDuration.msec;
}
```

**可能原因**:
1. 通话结束后，`pjsipCall` 对象被销毁
2. PJSIP 会话已终止（PJSIP_ESESSIONTERMINATED），无法再获取 connectDuration
3. Risip 不缓存通话时长，完全依赖 PJSIP 的实时数据

**问题**: 当查看历史记录时，通话早已结束，PJSIP 会话已销毁，所以 `callDuration()` 返回 0。

## 修复方案

### 方案 1: 修复视频通话记录（推荐）✅

**目标**: 让视频通话也使用 Risip API，自动添加记录。

**实现**: 修改 `SipPhoneManager::makeCall()` 以使用 Risip API。

#### 步骤 1: 扩展 Risip API 支持视频通话

在 [SipPhoneManager.cpp](src/sip_phone/SipPhoneManager.cpp) 中:

```cpp
void SipPhoneManager::makeCall(const QString &number, bool videoCall) {
    risip::RisipCallManager *callManager = risip::RisipCallManager::instance();
    if (!callManager) {
        qWarning() << "❌ Call manager not available";
        return;
    }

    // ✅ 使用 Risip API 创建通话（自动添加记录 + 设置 callDirection）
    if (number.startsWith("sip:")) {
        d->currentCall = callManager->callExternalSIP(number);
    } else {
        d->currentCall = callManager->callPhone(number);
    }

    if (!d->currentCall) {
        qWarning() << "❌ Failed to create call";
        return;
    }

    // ✅ 如果是视频通话，在 Risip Call 对象上启用视频
    if (videoCall) {
        addVideoToCall(d->currentCall);
    }

    // 连接信号...
}
```

#### 步骤 2: 实现 addVideoToCall()

```cpp
void SipPhoneManager::addVideoToCall(risip::RisipCall *call) {
    if (!call || !call->pjsipCall()) {
        qWarning() << "❌ Cannot add video: invalid call";
        return;
    }

    pjsua_call_id call_id = call->pjsipCall()->getId();

    // 使用 pjsua_call_set_vid_strm() 添加视频流
    pjsua_call_vid_strm_op op = PJSUA_CALL_VID_STRM_ADD;
    pjsua_call_vid_strm_op_param param;
    pjsua_call_vid_strm_op_param_default(&param);
    param.med_idx = -1;  // Add to next available slot

    pj_status_t status = pjsua_call_set_vid_strm(call_id, op, &param);
    if (status != PJ_SUCCESS) {
        qWarning() << "❌ Failed to add video stream";
    } else {
        qDebug() << "✅ Video stream added to call";
    }
}
```

**优点**:
- ✅ 所有通话（视频/语音）都使用统一的 Risip API
- ✅ callDirection 自动设置正确
- ✅ 通话记录自动添加
- ✅ 代码结构更清晰

**缺点**:
- ⚠️ 需要测试 Risip Call 对象是否支持后续添加视频流
- ⚠️ 可能需要调整 INVITE SDP（确保初始 INVITE 包含视频）

### 方案 2: 手动添加视频通话记录（备选）

**目标**: 保持现有视频通话机制，手动添加记录。

**实现**:

```cpp
void SipPhoneManager::makeCall(const QString &number, bool videoCall) {
    // ...现有视频通话代码...
    status = pjsua_call_make_call(acc_id, &uri, &call_opt, NULL, NULL, &call_id);

    if (status == PJ_SUCCESS) {
        // ✅ 手动创建 RisipCall 并添加到历史记录
        risip::RisipCall *historyCall = new risip::RisipCall(this);

        // 创建 Buddy
        risip::RisipBuddy *buddy = new risip::RisipBuddy(this);
        buddy->setAccount(d->currentAccount);
        buddy->setContact(number);
        buddy->setType(risip::RisipBuddy::Pstn);

        // 设置 Call 信息
        historyCall->setAccount(d->currentAccount);
        historyCall->setBuddy(buddy);
        historyCall->setCallDirection(risip::RisipCall::Outgoing);  // ⭐ 设置方向
        historyCall->createTimestamp();  // ⭐ 设置时间戳

        // 添加到历史记录
        risip::RisipCallManager *callManager = risip::RisipCallManager::instance();
        auto historyModel = callManager->historyCallModelForAccount(d->currentAccount);
        if (historyModel) {
            qobject_cast<risip::RisipCallHistoryModel*>(historyModel)->addCallRecord(historyCall);
            qDebug() << "✅ Video call record added to history";
        }

        // 保存 call_id 用于后续缓存时长
        d->videoCallHistoryMap[call_id] = historyCall;
    }
}
```

**优点**:
- ✅ 最小化改动，保持现有视频通话逻辑
- ✅ callDirection 手动设置为 Outgoing

**缺点**:
- ❌ 代码重复，维护困难
- ❌ 需要同时维护两套通话记录逻辑（Risip + 手动）
- ❌ 仍需解决 callDuration 缓存问题

### 方案 3: 缓存通话时长（必须）⭐

**问题**: 无论使用哪个方案，通话结束后 `callDuration()` 都会返回 0。

**解决**: 在通话结束时缓存时长到 RisipCall 对象。

#### 选项 A: 修改 Risip SDK（不推荐）

修改 [risipcall.cpp](F:\0\risip-master\risip-master\src\risipsdk\risipcall.cpp):

```cpp
class RisipCallPrivateData {
    // ...
    long cachedDuration = 0;  // 添加缓存字段
};

long RisipCall::callDuration() const {
    // 如果已缓存，返回缓存值
    if (m_data->cachedDuration > 0)
        return m_data->cachedDuration;

    // 否则从 PJSIP 获取
    if(!m_data->pjsipCall)
        return 0;
    return m_data->pjsipCall->getInfo().connectDuration.msec;
}

void RisipCall::cacheDuration() {
    if (m_data->pjsipCall) {
        m_data->cachedDuration = m_data->pjsipCall->getInfo().connectDuration.msec;
    }
}
```

在通话结束回调中调用 `cacheDuration()`。

**缺点**: 需要修改第三方 SDK，升级时会丢失修改。

#### 选项 B: 扩展 RisipCall（推荐）✅

创建自定义子类或使用 Qt 的动态属性:

```cpp
void SipPhoneManager::onCallStateChanged(pjsua_call_id call_id, pjsip_inv_state state) {
    if (state == PJSIP_INV_STATE_DISCONNECTED) {
        // 通话结束，缓存时长
        risip::RisipCall *call = findCallById(call_id);
        if (call) {
            long duration = call->callDuration();  // 在 PJSIP 销毁前获取
            call->setProperty("cachedDuration", QVariant::fromValue(duration));
            qDebug() << "✅ Cached call duration:" << duration << "ms";
        }
    }
}
```

修改 Model 的 `data()` 方法:

```cpp
case CallDurationRole: {
    // 先尝试从缓存获取
    QVariant cached = call->property("cachedDuration");
    if (cached.isValid()) {
        return cached.toLongLong();
    }
    // 否则从 PJSIP 获取
    return (qlonglong)call->callDuration();
}
```

**优点**:
- ✅ 不修改 Risip SDK 源码
- ✅ 使用 Qt 的动态属性机制
- ✅ 易于维护

### 方案 4: 修复 Contact 格式不一致

**问题**: QML 显示:
```
callContact: "1006"                    // 只有号码
callContact: "\"Extension 1006\" 1006" // 姓名 + 号码
```

**修复**: 在 QML 中标准化显示:

```qml
Text {
    id: contactLabel
    // ✅ 提取号码部分
    text: {
        var contact = model.callContact
        // 如果包含引号和空格，提取最后的号码部分
        if (contact.includes('"')) {
            var parts = contact.split(' ')
            return parts[parts.length - 1]  // 返回最后一个部分（号码）
        }
        return contact  // 直接返回号码
    }
}
```

或者在 Risip Model 中统一:

```cpp
case CallContactRole: {
    QString contact = call->buddy()->contact();
    // 提取纯号码（去除姓名部分）
    QRegularExpression re("\\b\\d{4,}\\b");  // 匹配 4 位以上数字
    QRegularExpressionMatch match = re.match(contact);
    if (match.hasMatch()) {
        return match.captured(0);
    }
    return contact;
}
```

## 实现内容

### 1. ✅ 多账号管理UI

**文件**: [src/qml/components/sip_phone/pages/SipSettingsPage.qml:198-343](src/qml/components/sip_phone/pages/SipSettingsPage.qml#L198-L343)

#### 功能特性

1. **已保存账号列表**
   - 显示所有保存的SIP账号
   - 每个账号显示SIP URI和服务器地址
   - 默认账号有绿色高亮边框和"默认"标签

2. **账号操作按钮**
   - **"使用"按钮**: 自动填充表单(服务器、端口、用户名)
   - **"设为默认"按钮**: 设置为启动时自动登录的账号
   - **"删除"按钮**: 删除选中的账号

3. **空状态提示**
   - 无保存账号时显示提示信息
   - 引导用户注册第一个账号

#### 技术实现

```qml
ListView {
    id: accountsListView
    model: SipPhoneManager.getAllAccountsModel()  // 使用Risip账号模型

    delegate: Rectangle {
        // 账号信息显示
        Text {
            text: model.uri  // sip:1000@192.168.10.243
        }
        Text {
            text: "服务器: " + model.serverAddress
        }

        // 操作按钮
        Button {
            text: "使用"
            onClicked: {
                // 解析服务器地址并填充表单
                var parts = model.serverAddress.split(":")
                serverInput.text = parts[0]
                portInput.text = parts[1] || "5060"
                usernameInput.text = model.username
            }
        }

        Button {
            text: model.isDefault ? "★默认" : "设为默认"
            onClicked: {
                SipPhoneManager.setAsDefaultAccount(model.uri)
            }
        }

        Button {
            text: "删除"
            onClicked: {
                SipPhoneManager.removeAccount(model.uri)
            }
        }
    }
}
```

### 2. ✅ 通话历史UI

**文件**: [src/qml/components/sip_phone/pages/SipHistoryPage.qml](src/qml/components/sip_phone/pages/SipHistoryPage.qml)

#### 功能特性

1. **历史记录列表**
   - 显示所有通话记录
   - 拨出电话用📤图标,接入电话用📥图标
   - 显示联系人/号码、日期时间、通话时长

2. **筛选功能** (保留原有UI,待数据模型支持)
   - 全部通话
   - 未接来电 (待Risip模型支持)
   - 已拨电话 (待Risip模型支持)

3. **回拨功能**
   - 每条记录旁有📞按钮
   - 点击自动拨打该号码

4. **状态栏**
   - 显示总记录数

#### 技术实现

```qml
ListView {
    id: historyList
    model: SipPhoneManager.getCallHistoryModel()  // 使用Risip历史模型

    delegate: Rectangle {
        // 呼叫方向图标
        Text {
            text: model.direction === 0 ? "📤" : "📥"
        }

        // 联系人/号码
        Text {
            text: model.contact || "未知号码"
        }

        // 时间戳
        Text {
            text: Qt.formatDateTime(model.timestamp, "yyyy-MM-dd")
        }
        Text {
            text: Qt.formatDateTime(model.timestamp, "hh:mm:ss")
        }

        // 通话时长
        Text {
            text: formatDuration(model.duration)  // "02:05" 格式
        }

        // 回拨按钮
        Button {
            text: "📞"
            onClicked: {
                root.callNumber(model.contact)
            }
        }
    }
}
```

## 数据模型集成

### Risip账号模型数据角色

从`SipPhoneManager.getAllAccountsModel()`获取:

| 角色名 | 类型 | 说明 |
|--------|------|------|
| uri | QString | SIP URI (如 "sip:1000@192.168.10.243") |
| username | QString | 用户名 |
| serverAddress | QString | 服务器地址:端口 |
| isDefault | bool | 是否为默认账号 |
| password | QString | 密码(不显示) |

### Risip通话历史模型数据角色

从`SipPhoneManager.getCallHistoryModel()`获取:

| 角色名 | 类型 | 说明 |
|--------|------|------|
| contact | QString | 通话对方号码/联系人 |
| direction | int | 呼叫方向: 0=拨出, 1=接入 |
| duration | int | 通话时长(秒) |
| timestamp | QDateTime | 通话开始时间 |

## 用户工作流程

### 多账号管理工作流

#### 场景1: 添加第二个服务器账号

1. 用户已有账号 `sip:1000@192.168.10.243` (默认)
2. 想添加新账号 `sip:2000@192.168.10.244`
3. 操作步骤:
   - 进入设置页面
   - 在"SIP 服务器配置"中输入新服务器信息
   - 服务器: `192.168.10.244`
   - 用户名: `2000`
   - 密码: `****`
   - 点击"注册账号"
   - 新账号自动添加到"已保存的账号"列表

#### 场景2: 切换服务器

1. 当前使用账号1000,想切换到账号2000
2. 操作步骤:
   - 进入设置页面
   - 在"已保存的账号"列表找到 `sip:2000@...`
   - 点击"使用"按钮
   - 表单自动填充账号2000的信息
   - 点击"注册账号"切换到新服务器

#### 场景3: 设置默认账号

1. 想让账号2000作为启动时的默认账号
2. 操作步骤:
   - 找到 `sip:2000@...` 账号
   - 点击"设为默认"按钮
   - 按钮变为"★默认",边框变为绿色
   - 下次启动自动使用账号2000登录

### 通话历史工作流

#### 场景1: 查看通话记录

1. 进入"历史记录"页面
2. 看到所有通话记录列表
3. 拨出电话显示📤,接入电话显示📥
4. 可以看到:
   - 通话对方号码
   - 通话时间(精确到秒)
   - 通话时长(MM:SS格式)

#### 场景2: 回拨电话

1. 在历史记录中找到想要回拨的号码
2. 点击右侧的📞按钮
3. 自动切换到拨号页面并发起呼叫

## 已知限制

### 多账号管理

1. **密码不显示**
   - 点击"使用"按钮时,密码字段为空
   - 原因: 安全考虑,不从模型读取密码
   - 用户需要手动输入密码

2. **无批量操作**
   - 不支持选择多个账号批量删除
   - 每次只能操作一个账号

### 通话历史

1. **筛选未实现**
   - "未接"和"已拨"筛选按钮存在但未工作
   - 原因: Risip模型可能不提供未接来电标记
   - 需要检查Risip是否有未接来电字段

2. **清空记录未实现**
   - "清空记录"按钮仅打印日志
   - 需要添加C++方法清空模型

3. **无搜索功能**
   - 不支持按号码或日期搜索
   - 建议将来使用QSortFilterProxyModel实现
